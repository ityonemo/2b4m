## Complex arithmetic

The **complex numbers** are defined as
$$\mathbb{C} = \{ a + bi : a, b \in \mathbb{R} \},$$
where $i^2 = -1$. If $z = a + bi$, then $a$ is the **real part** of $z$ and $b$
is the **imaginary part**. To add, we add corresponding parts:
$$z + w = (a + bi) + (c + di) = (a + c) + (b + d)i;$$
and remembering $i^2 = -1$, we multiply like polynomials:
$$(a + bi)(c + di) = (ac - bd) + (ad + bc)i.$$
Every nonzero $z = a + bi$ has a multiplicative inverse
$$z^{-1} = \frac{a - bi}{a^2 + b^2},$$
so $\mathbb{C}^* = \mathbb{C} \setminus \{0\}$ is a group under multiplication.
The **complex conjugate** of $z = a + bi$ is $\overline{z} = a - bi$, and the
**absolute value** or **modulus** is $|z| = \sqrt{a^2 + b^2}$.

## The modulus and its properties

The key structural facts about the modulus — the ones §4.2 uses and Exercise 19
asks to prove — are that $z\overline{z} = |z|^2$, that conjugation preserves the
modulus, and that the modulus is **multiplicative**, $|zw| = |z|\,|w|$. The last
is what makes the circle group $\mathbb{T} = \{ z : |z| = 1 \}$ a group. Each
follows from the projection algebra of $\mathbb{C}$, with no trigonometry.

$z \overline{z} = |z|^2$ (as an embedded real, $|z|^2 = \mathrm{re}(z)^2 +
\mathrm{im}(z)^2$):

> NB: This theorem exists in std in `std/complex/modulus.b4m:69:zTimesConjIsNormSq`.

```2b4m

```

The modulus is multiplicative, $|zw| = |z|\,|w|$ (Exercise 19f):

> NB: This theorem exists in std in `std/complex/modulus.b4m:204:absMul`.

```2b4m
theorem modulusMultiplicative: forall z, w: Complex; abs(mul(z, w)) = rmul(abs(z), abs(w))
proof
  @generalize-z |
    fix z: Complex {
      @generalize-w |
        fix w: Complex {
          @normsq-mul |
            normSq(mul(z, w)) = rmul(normSq(z), normSq(w))
            [using specialize normSqMul(z, w)]
          @z-norm-nonneg |
            less_or_equal(real.ZERO, normSq(z))
            [using specialize normSqNonneg(z)]
          @w-norm-nonneg |
            less_or_equal(real.ZERO, normSq(w))
            [using specialize normSqNonneg(w)]
          // abs(zw) unfolds to √(normSq zw); rewrite normSq(zw) = normSq z · normSq w.
          @abs-mul-refl |
            abs(mul(z, w)) = sqrt(normSq(mul(z, w)))
            [by reflexivity]
          @abs-mul-rewritten |
            abs(mul(z, w)) = sqrt(rmul(normSq(z), normSq(w)))
            [by rewrite normsq-mul abs-mul-refl]
          @sqrt-splits |
            sqrt(rmul(normSq(z), normSq(w))) = rmul(abs(z), abs(w))
            [using specialize real_sqrt.sqrtMulNonneg(normSq(z), normSq(w)) z-norm-nonneg w-norm-nonneg]
          @conclusion-abs-mul |
            abs(mul(z, w)) = rmul(abs(z), abs(w))
            [using chain abs-mul-rewritten sqrt-splits]
        }
      @discharge-w |
        forall w: Complex; abs(mul(z, w)) = rmul(abs(z), abs(w))
        [by generalize generalize-w]
    }
  @conclusion |
    forall z, w: Complex; abs(mul(z, w)) = rmul(abs(z), abs(w))
    [by generalize generalize-z]
qed
```

## Polar form and DeMoivre's theorem

Nonzero complex numbers can also be represented using *polar coordinates*. To specify any
nonzero point on the plane, it suffices to give an angle $\theta$ from the positive $x$
axis in the counterclockwise direction and a distance $r$ from the origin. We can see that
$$z = a + bi = r( \cos \theta + i \sin \theta).$$
Hence,
$$r = |z| = \sqrt{a^2 + b^2}$$
and
$$\begin{aligned}a & = r \cos \theta\\ b & = r \sin \theta.\end{aligned}$$
We sometimes abbreviate $r( \cos \theta + i \sin \theta)$ as $r \operatorname{cis} \theta$.
To assure that the representation of $z$ is well-defined, we also require that
$0^{\circ} \leq \theta < 360^{\circ}$. If the measurement is in radians, then
$0 \leq \theta < 2 \pi$.

The polar representation of a complex number makes it easy to find products and powers of
complex numbers. The proof of the following proposition is straightforward and is left as
an exercise.

**Proposition.** Let $z = r \operatorname{cis} \theta$ and
$w = s \operatorname{cis} \phi$ be two nonzero complex numbers. Then
$$zw = r s \operatorname{cis}( \theta + \phi).$$

**Theorem (DeMoivre).** Let $z = r \operatorname{cis} \theta$ be a nonzero complex number.
Then
$$[r \operatorname{cis} \theta ]^n = r^n \operatorname{cis}( n \theta)$$
for $n = 1, 2, \ldots$.

**Proof.** We will use induction on $n$. For $n = 1$ the theorem is trivial. Assume that
the theorem is true for all $k$ such that $1 \leq k \leq n$. Then
$$\begin{aligned}z^{n+1} & = z^n z\\ & = r^n( \cos n \theta + i \sin n \theta ) r( \cos \theta + i\sin \theta )\\ & = r^{n+1} [( \cos n \theta \cos \theta - \sin n \theta \sin \theta )  + i ( \sin n \theta \cos \theta + \cos n \theta \sin \theta)]\\ & = r^{n+1} [ \cos( n \theta + \theta) + i \sin( n \theta + \theta) ]\\ & = r^{n+1} [ \cos( n +1) \theta + i \sin( n+1) \theta  ].\end{aligned}$$
$\blacksquare$

> *The trigonometry this needs — $\sin$, $\cos$ and $\pi$ with the angle-addition
> formulas and $\cos^2 + \sin^2 = 1$ — cannot be constructed here, so it is adjoined
> to $\mathbb{R}$ axiomatically, as $\sqrt{\ }$ is.*

With $\operatorname{cis}\theta = \cos\theta + i\sin\theta$ and $z^n$ the natural
power on $\mathbb{C}$, the product rule is complex extensionality plus the addition
formulas, and DeMoivre's theorem follows by induction on $n$.

```2b4m
import complex_polar <<< "std/complex/polar.b4m"
import real_scaling <<< "std/real/scaling.b4m"
import peano <<< "std/peano.b4m"

define cis(t) = complex_polar.cis(t)
func cpow = complex_polar.cpow
func scale = real_scaling.scale
sort Nat = peano.Nat

// cis θ · cis φ = cis(θ + φ), and so (r cis θ)(s cis φ) = rs cis(θ + φ).
theorem cisProduct: forall a, b: Real; mul(cis(a), cis(b)) = cis(radd(a, b))
proof
  @generalize-a |
    fix a: Real {
      @generalize-b |
        fix b: Real {
          @re-of-cis-a |
            re(cis(a)) = cos(a)
            [using specialize reOfCis(a)]
          @im-of-cis-a |
            im(cis(a)) = sin(a)
            [using specialize imOfCis(a)]
          @re-of-cis-b |
            re(cis(b)) = cos(b)
            [using specialize reOfCis(b)]
          @im-of-cis-b |
            im(cis(b)) = sin(b)
            [using specialize imOfCis(b)]
          // the real part.
          @re-of-product |
            re(mul(cis(a), cis(b))) = radd(rmul(re(cis(a)), re(cis(b))), rneg(rmul(im(cis(a)), im(cis(b)))))
            [using specialize reMul(cis(a), cis(b))]
          @re-of-product-1 |
            re(mul(cis(a), cis(b))) = radd(rmul(cos(a), re(cis(b))), rneg(rmul(im(cis(a)), im(cis(b)))))
            [by rewrite re-of-cis-a re-of-product]
          @re-of-product-2 |
            re(mul(cis(a), cis(b))) = radd(rmul(cos(a), cos(b)), rneg(rmul(im(cis(a)), im(cis(b)))))
            [by rewrite re-of-cis-b re-of-product-1]
          @re-of-product-3 |
            re(mul(cis(a), cis(b))) = radd(rmul(cos(a), cos(b)), rneg(rmul(sin(a), im(cis(b)))))
            [by rewrite im-of-cis-a re-of-product-2]
          @re-of-product-parts |
            re(mul(cis(a), cis(b))) = radd(rmul(cos(a), cos(b)), rneg(rmul(sin(a), sin(b))))
            [by rewrite im-of-cis-b re-of-product-3]
          @cos-of-sum |
            cos(radd(a, b)) = radd(rmul(cos(a), cos(b)), rneg(rmul(sin(a), sin(b))))
            [using specialize cosAdd(a, b)]
          @cos-of-sum-flipped |
            radd(rmul(cos(a), cos(b)), rneg(rmul(sin(a), sin(b)))) = cos(radd(a, b))
            [by symmetry cos-of-sum]
          @re-matches |
            re(mul(cis(a), cis(b))) = cos(radd(a, b))
            [using chain re-of-product-parts cos-of-sum-flipped]
          // the imaginary part.
          @im-of-product |
            im(mul(cis(a), cis(b))) = radd(rmul(re(cis(a)), im(cis(b))), rmul(im(cis(a)), re(cis(b))))
            [using specialize imMul(cis(a), cis(b))]
          @im-of-product-1 |
            im(mul(cis(a), cis(b))) = radd(rmul(cos(a), im(cis(b))), rmul(im(cis(a)), re(cis(b))))
            [by rewrite re-of-cis-a im-of-product]
          @im-of-product-2 |
            im(mul(cis(a), cis(b))) = radd(rmul(cos(a), sin(b)), rmul(im(cis(a)), re(cis(b))))
            [by rewrite im-of-cis-b im-of-product-1]
          @im-of-product-3 |
            im(mul(cis(a), cis(b))) = radd(rmul(cos(a), sin(b)), rmul(sin(a), re(cis(b))))
            [by rewrite im-of-cis-a im-of-product-2]
          @im-of-product-parts |
            im(mul(cis(a), cis(b))) = radd(rmul(cos(a), sin(b)), rmul(sin(a), cos(b)))
            [by rewrite re-of-cis-b im-of-product-3]
          @sin-of-sum |
            sin(radd(a, b)) = radd(rmul(sin(a), cos(b)), rmul(cos(a), sin(b)))
            [using specialize sinAdd(a, b)]
          @summands-commute |
            radd(rmul(cos(a), sin(b)), rmul(sin(a), cos(b))) = radd(rmul(sin(a), cos(b)), rmul(cos(a), sin(b)))
            [using specialize real.addIsCommutative(rmul(cos(a), sin(b)), rmul(sin(a), cos(b)))]
          @sin-of-sum-flipped |
            radd(rmul(sin(a), cos(b)), rmul(cos(a), sin(b))) = sin(radd(a, b))
            [by symmetry sin-of-sum]
          @im-matches |
            im(mul(cis(a), cis(b))) = sin(radd(a, b))
            [using chain im-of-product-parts summands-commute sin-of-sum-flipped]
          @conclusion-product-is-cis |
            mul(cis(a), cis(b)) = cis(radd(a, b))
            [using specialize cisByParts(radd(a, b), mul(cis(a), cis(b))) re-matches im-matches]
        }
      @discharge-b |
        forall b: Real; mul(cis(a), cis(b)) = cis(radd(a, b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: Real; mul(cis(a), cis(b)) = cis(radd(a, b))
    [by generalize generalize-a]
qed

theorem polarProduct: forall r, s, a, b: Real; mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
proof
  @generalize-r |
    fix r: Real {
      @generalize-s |
        fix s: Real {
          @generalize-a |
            fix a: Real {
              @generalize-b |
                fix b: Real {
                  @regrouped |
                    mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(mul(fromReal(r), fromReal(s)), mul(cis(a), cis(b)))
                    [using assoc_commut(complex.mulIsAssociative, complex.mulIsCommutative, complex.mulLeftSwap)]
                  @moduli-embed |
                    fromReal(rmul(r, s)) = mul(fromReal(r), fromReal(s))
                    [using specialize fromRealMul(r, s)]
                  @moduli-combined |
                    mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), mul(cis(a), cis(b)))
                    [by rewrite moduli-embed regrouped]
                  @angles-add |
                    mul(cis(a), cis(b)) = cis(radd(a, b))
                    [using specialize cisProduct(a, b)]
                  @conclusion-polar-product |
                    mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
                    [by rewrite angles-add moduli-combined]
                }
              @discharge-b |
                forall b: Real; mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
                [by generalize generalize-b]
            }
          @discharge-a |
            forall a, b: Real; mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
            [by generalize generalize-a]
        }
      @discharge-s |
        forall s, a, b: Real; mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
        [by generalize generalize-s]
    }
  @conclusion |
    forall r, s, a, b: Real; mul(mul(fromReal(r), cis(a)), mul(fromReal(s), cis(b))) = mul(fromReal(rmul(r, s)), cis(radd(a, b)))
    [by generalize generalize-r]
qed

// |cis θ| = 1.
theorem modulusOfCis: forall t: Real; abs(cis(t)) = RONE
proof

    fix t: Real {
      @unit-normsq |
        normSq(cis(t)) = RONE
        [using specialize normSqOfCis(t)]
      @unfolded |
        abs(cis(t)) = real.sqrt(normSq(cis(t)))
        [by reflexivity]
      @root-of-one-form |
        abs(cis(t)) = real.sqrt(RONE)
        [by rewrite unit-normsq unfolded]
      @root-of-one |
        real.sqrt(RONE) = RONE
        [using import(real) sqrtOne]
      @conclusion-unit |
        abs(cis(t)) = RONE
        [using chain root-of-one-form root-of-one]
    }
  @conclusion |
    forall t: Real; abs(cis(t)) = RONE
    [by generalize generalize-t]
qed

// DeMoivre: (r cis θ)^n = r^n cis(nθ), with r^n the natural power on ℝ.
theorem deMoivre: forall r, t: Real; forall n: Nat; cpow(mul(fromReal(r), cis(t)), n) = mul(fromReal(rpow(r, n)), cis(scale(n, t)))
proof
  @generalize-r |
    fix r: Real {
      @generalize-t |
        fix t: Real {
          @zeroth-power |
            cpow(mul(fromReal(r), cis(t)), NZERO) = ONE
            [using specialize cpowZero(mul(fromReal(r), cis(t)))]
          @zeroth-real-power |
            rpow(r, NZERO) = RONE
            [using specialize rpowZero(r)]
          @zero-scale |
            scale(NZERO, t) = RZERO
            [using specialize scaleZero(t)]
          @one-is-cis-zero |
            ONE = cis(RZERO)
            [by cite cisZero]
          @one-embedded |
            fromReal(RONE) = ONE
            [by cite fromRealOne]
          @one-times-one |
            mul(ONE, ONE) = ONE
            [using specialize mulOneLeft(ONE)]
          @rhs-reflexive |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t)))
            [by reflexivity]
          @rhs-with-one |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = mul(fromReal(RONE), cis(scale(NZERO, t)))
            [by rewrite zeroth-real-power rhs-reflexive]
          @rhs-with-embedded-one |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = mul(ONE, cis(scale(NZERO, t)))
            [by rewrite one-embedded rhs-with-one]
          @rhs-with-zero-angle |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = mul(ONE, cis(RZERO))
            [by rewrite zero-scale rhs-with-embedded-one]
          @cis-zero-is-one |
            cis(RZERO) = ONE
            [by symmetry one-is-cis-zero]
          @rhs-with-ones |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = mul(ONE, ONE)
            [by rewrite cis-zero-is-one rhs-with-zero-angle]
          @rhs-collapses |
            mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t))) = ONE
            [using chain rhs-with-ones one-times-one]
          @rhs-flipped |
            ONE = mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t)))
            [by symmetry rhs-collapses]
          @base-case |
            cpow(mul(fromReal(r), cis(t)), NZERO) = mul(fromReal(rpow(r, NZERO)), cis(scale(NZERO, t)))
            [using chain zeroth-power rhs-flipped]
          @induction-step |
            fix k: Nat {
              @given-inductive-hypothesis |
                assume cpow(mul(fromReal(r), cis(t)), k) = mul(fromReal(rpow(r, k)), cis(scale(k, t))) {
                  @inductive-hypothesis |
                    cpow(mul(fromReal(r), cis(t)), k) = mul(fromReal(rpow(r, k)), cis(scale(k, t)))
                    [by hypothesis given-inductive-hypothesis]
                  @next-power |
                    cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(cpow(mul(fromReal(r), cis(t)), k), mul(fromReal(r), cis(t)))
                    [using specialize cpowSucc(mul(fromReal(r), cis(t)), k)]
                  @next-power-with-hypothesis |
                    cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(mul(fromReal(rpow(r, k)), cis(scale(k, t))), mul(fromReal(r), cis(t)))
                    [by rewrite inductive-hypothesis next-power]
                  @polar-step |
                    mul(mul(fromReal(rpow(r, k)), cis(scale(k, t))), mul(fromReal(r), cis(t))) = mul(fromReal(rmul(rpow(r, k), r)), cis(radd(scale(k, t), t)))
                    [using specialize polarProduct(rpow(r, k), r, scale(k, t), t)]
                  @next-power-polar |
                    cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(fromReal(rmul(rpow(r, k), r)), cis(radd(scale(k, t), t)))
                    [using chain next-power-with-hypothesis polar-step]
                  @next-real-power |
                    rpow(r, succ(k)) = rmul(rpow(r, k), r)
                    [using specialize rpowSucc(r, k)]
                  @next-scale |
                    scale(succ(k), t) = radd(scale(k, t), t)
                    [using specialize scaleSucc(k, t)]
                  @next-power-with-real-power |
                    cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(fromReal(rpow(r, succ(k))), cis(radd(scale(k, t), t)))
                    [by rewrite next-real-power next-power-polar]
                  @conclusion-step |
                    cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(fromReal(rpow(r, succ(k))), cis(scale(succ(k), t)))
                    [by rewrite next-scale next-power-with-real-power]
                }
              @induction-step-at-k |
                cpow(mul(fromReal(r), cis(t)), k) = mul(fromReal(rpow(r, k)), cis(scale(k, t))) -> cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(fromReal(rpow(r, succ(k))), cis(scale(succ(k), t)))
                [by discharge given-inductive-hypothesis]
            }
          @induction-step-for-all-k |
            forall k: Nat; cpow(mul(fromReal(r), cis(t)), k) = mul(fromReal(rpow(r, k)), cis(scale(k, t))) -> cpow(mul(fromReal(r), cis(t)), succ(k)) = mul(fromReal(rpow(r, succ(k))), cis(scale(succ(k), t)))
            [by generalize induction-step]
          @conclusion-all-n |
            forall n: Nat; cpow(mul(fromReal(r), cis(t)), n) = mul(fromReal(rpow(r, n)), cis(scale(n, t)))
            [using instantiation induction((fun k: Nat => cpow(mul(fromReal(r), cis(t)), k) = mul(fromReal(rpow(r, k)), cis(scale(k, t))))) base-case induction-step-for-all-k]
        }
      @discharge-t |
        forall t: Real; forall n: Nat; cpow(mul(fromReal(r), cis(t)), n) = mul(fromReal(rpow(r, n)), cis(scale(n, t)))
        [by generalize generalize-t]
    }
  @conclusion |
    forall r, t: Real; forall n: Nat; cpow(mul(fromReal(r), cis(t)), n) = mul(fromReal(rpow(r, n)), cis(scale(n, t)))
    [by generalize generalize-r]
qed
```

## The circle group and the roots of unity

The multiplicative group of the complex numbers, $\mathbb{C}^*$, possesses some interesting
subgroups. Whereas $\mathbb{Q}^*$ and $\mathbb{R}^*$ have no interesting subgroups of
finite order, $\mathbb{C}^*$ has many. We first consider the *circle group*,
$$\mathbb{T} = \{ z \in \mathbb{C} : |z| = 1 \}.$$
The following proposition is a direct result of the proposition on the modulus.

**Proposition.** The circle group is a subgroup of $\mathbb{C}^*$.

Although the circle group has infinite order, it has many interesting finite subgroups.
The complex numbers satisfying the equation $z^n=1$ are called the *$n$th roots of unity*.

**Theorem.** If $z^n = 1$, then the $n$th roots of unity are
$$z = \operatorname{cis}\left( \frac{2 k \pi}{n } \right),$$
where $k = 0, 1, \ldots, n-1$. Furthermore, the $n$th roots of unity form a cyclic
subgroup of $\mathbb{T}$ of order $n$.

**Proof.** By DeMoivre's Theorem,
$$z^n = \operatorname{cis} \left( n \frac{2 k \pi}{n } \right) = \operatorname{cis}( 2 k \pi ) = 1.$$
The $z$'s are distinct since the numbers $2 k \pi /n$ are all distinct and are greater than
or equal to 0 but less than $2 \pi$. The fact that these are all of the roots of the
equation $z^n=1$ follows from the corollary that a polynomial of degree $n$ can have at
most $n$ roots. We will leave the proof that the $n$th roots of unity form a cyclic
subgroup of $\mathbb{T}$ as an exercise. $\blacksquare$

A generator for the group of the $n$th roots of unity is called a *primitive $n$th root of
unity*.

> *The circle group $\mathbb{T}$ is the predicate $|z| = 1$, and "$\mathbb{T}$ is a
> subgroup" follows from the multiplicativity of the modulus together with $|1| = 1$ and
> $|z^{-1}| = |z|^{-1}$. But its finite subgroups, the roots of unity, are stated via
> $\operatorname{cis}$, so they inherit the trigonometry gap:*

With $\theta = 2\pi/n$ (which exists for every $n \ge 1$: $2\pi \cdot n^{-1}$), each
$\operatorname{cis}(k\theta)$ is an $n$-th root of unity, by DeMoivre:
$\operatorname{cis}(k\theta)^n = \operatorname{cis}(n \cdot k\theta) =
\operatorname{cis}(k \cdot 2\pi) = \operatorname{cis}(2\pi)^k = 1$. That these are *all*
the roots of $z^n = 1$ (so that the subgroup has order exactly $n$) forwards to "a
polynomial of degree $n$ has at most $n$ roots", a later chapter, and to the injectivity
of $\operatorname{cis}$ on $[0, 2\pi)$, which the trigonometric axioms do not pin down;
those two facts are left in prose. The circle group $\mathbb{T} = \{z : |z| = 1\}$ is a
subgroup of $\mathbb{C}^*$: it contains $1$, is closed under products ($|zw| =
|z||w|$), and under inverses — on $\mathbb{T}$, $z^{-1} = \overline{z}/|z|^2 =
\overline{z}$.

```2b4m
define twoPi = real.twoPi
define onCircle(z) = complex_polar.onCircle(z)

theorem rootAngleExists: forall m: Nat; exists theta: Real; scale(succ(m), theta) = twoPi
proof
  @generalize-m |
    fix m: Nat {
      @n-positive |
        real.less_than(RZERO, toReal(succ(m)))
        [using specialize toRealOfSuccIsPositive(m)]
      @zero-not-below-itself |
        not real.less_than(RZERO, RZERO)
        [using specialize real.lessThanIrreflexive(RZERO)]
      @given-n-zero |
        assume toReal(succ(m)) = RZERO {
          @n-zero |
            toReal(succ(m)) = RZERO
            [by hypothesis given-n-zero]
          @zero-below-itself |
            real.less_than(RZERO, RZERO)
            [by rewrite n-zero n-positive]
        }
      @n-zero-implies |
        toReal(succ(m)) = RZERO -> real.less_than(RZERO, RZERO)
        [by discharge given-n-zero]
      @n-nonzero |
        toReal(succ(m)) != RZERO
        [using tautology n-zero-implies zero-not-below-itself]
      @scale-as-product |
        scale(succ(m), rmul(twoPi, rrecip(toReal(succ(m))))) = rmul(toReal(succ(m)), rmul(twoPi, rrecip(toReal(succ(m)))))
        [using specialize scaleIsProduct(rmul(twoPi, rrecip(toReal(succ(m)))), succ(m))]
      @swapped |
        rmul(toReal(succ(m)), rmul(twoPi, rrecip(toReal(succ(m))))) = rmul(twoPi, rmul(toReal(succ(m)), rrecip(toReal(succ(m)))))
        [using specialize real.mulLeftSwap(toReal(succ(m)), twoPi, rrecip(toReal(succ(m))))]
      @n-times-recip |
        rmul(toReal(succ(m)), rrecip(toReal(succ(m)))) = RONE
        [using specialize real.fieldInverse(toReal(succ(m))) n-nonzero]
      @swapped-cancelled |
        rmul(toReal(succ(m)), rmul(twoPi, rrecip(toReal(succ(m))))) = rmul(twoPi, RONE)
        [by rewrite n-times-recip swapped]
      @times-one |
        rmul(twoPi, RONE) = twoPi
        [using specialize real.mulOneRight(twoPi)]
      @full-turn |
        scale(succ(m), rmul(twoPi, rrecip(toReal(succ(m))))) = twoPi
        [using chain scale-as-product swapped-cancelled times-one]
      @conclusion-angle-exists |
        exists theta: Real; scale(succ(m), theta) = twoPi
        [by witness(rmul(twoPi, rrecip(toReal(succ(m))))) full-turn]
    }
  @conclusion |
    forall m: Nat; exists theta: Real; scale(succ(m), theta) = twoPi
    [by generalize generalize-m]
qed

theorem rootsOfUnity: forall n: Nat; forall theta: Real; scale(n, theta) = twoPi -> forall k: Nat; cpow(cis(scale(k, theta)), n) = ONE
proof
  @generalize-n |
    fix n: Nat {
      @generalize-theta |
        fix theta: Real {
          @given-full-turn |
            assume scale(n, theta) = twoPi {
              @full-turn |
                scale(n, theta) = twoPi
                [by hypothesis given-full-turn]
              @generalize-k |
                fix k: Nat {
                  @de-moivre |
                    cpow(cis(scale(k, theta)), n) = cis(scale(n, scale(k, theta)))
                    [using specialize deMoivreForCis(scale(k, theta), n)]
                  @scales-swap |
                    scale(n, scale(k, theta)) = scale(k, scale(n, theta))
                    [using specialize scaleSwap(k, theta, n)]
                  @as-k-full-turns |
                    cpow(cis(scale(k, theta)), n) = cis(scale(k, scale(n, theta)))
                    [using chain de-moivre scales-swap]
                  @as-k-two-pi |
                    cpow(cis(scale(k, theta)), n) = cis(scale(k, twoPi))
                    [by rewrite full-turn as-k-full-turns]
                  @de-moivre-at-two-pi |
                    cpow(cis(twoPi), k) = cis(scale(k, twoPi))
                    [using specialize deMoivreForCis(twoPi, k)]
                  @two-pi-power-flipped |
                    cis(scale(k, twoPi)) = cpow(cis(twoPi), k)
                    [by symmetry de-moivre-at-two-pi]
                  @one-is-cis-two-pi |
                    ONE = cis(twoPi)
                    [by cite cisTwoPi]
                  @one-power |
                    cpow(ONE, k) = ONE
                    [using specialize cpowOfOne(k)]
                  @cis-two-pi-power |
                    cpow(cis(twoPi), k) = ONE
                    [by rewrite one-is-cis-two-pi one-power]
                  @conclusion-root |
                    cpow(cis(scale(k, theta)), n) = ONE
                    [using chain as-k-two-pi two-pi-power-flipped cis-two-pi-power]
                }
              @discharge-k |
                forall k: Nat; cpow(cis(scale(k, theta)), n) = ONE
                [by generalize generalize-k]
            }
          @full-turn-implies |
            scale(n, theta) = twoPi -> forall k: Nat; cpow(cis(scale(k, theta)), n) = ONE
            [by discharge given-full-turn]
        }
      @discharge-theta |
        forall theta: Real; scale(n, theta) = twoPi -> forall k: Nat; cpow(cis(scale(k, theta)), n) = ONE
        [by generalize generalize-theta]
    }
  @conclusion |
    forall n: Nat; forall theta: Real; scale(n, theta) = twoPi -> forall k: Nat; cpow(cis(scale(k, theta)), n) = ONE
    [by generalize generalize-n]
qed

theorem circleGroupHasOne: onCircle(ONE)
proof
  @re-of-one |
    re(ONE) = RONE
    [by cite reOfOne]
  @im-of-one |
    im(ONE) = RZERO
    [by cite imOfOne]
  @unfolded |
    normSq(ONE) = radd(rmul(re(ONE), re(ONE)), rmul(im(ONE), im(ONE)))
    [by reflexivity]
  @with-re |
    normSq(ONE) = radd(rmul(RONE, RONE), rmul(im(ONE), im(ONE)))
    [by rewrite re-of-one unfolded]
  @with-parts |
    normSq(ONE) = radd(rmul(RONE, RONE), rmul(RZERO, RZERO))
    [by rewrite im-of-one with-re]
  @arithmetic |
    radd(rmul(RONE, RONE), rmul(RZERO, RZERO)) = RONE
    [using polynomial(real)]
  @conclusion |
    onCircle(ONE)
    [using chain with-parts arithmetic]
qed

theorem circleGroupClosedUnderProduct: forall z, w: Complex; onCircle(z) -> onCircle(w) -> onCircle(mul(z, w))
proof
  @generalize-z |
    fix z: Complex {
      @generalize-w |
        fix w: Complex {
          @given-z |
            assume onCircle(z) {
              @given-w |
                assume onCircle(w) {
                  @z-unit |
                    normSq(z) = RONE
                    [by hypothesis given-z]
                  @w-unit |
                    normSq(w) = RONE
                    [by hypothesis given-w]
                  @product-normsq |
                    normSq(mul(z, w)) = rmul(normSq(z), normSq(w))
                    [using specialize normSqMul(z, w)]
                  @product-normsq-z |
                    normSq(mul(z, w)) = rmul(RONE, normSq(w))
                    [by rewrite z-unit product-normsq]
                  @product-normsq-both |
                    normSq(mul(z, w)) = rmul(RONE, RONE)
                    [by rewrite w-unit product-normsq-z]
                  @one-times-one |
                    rmul(RONE, RONE) = RONE
                    [using specialize real.mulOneLeft(RONE)]
                  @conclusion-product-unit |
                    onCircle(mul(z, w))
                    [using chain product-normsq-both one-times-one]
                }
              @w-implies |
                onCircle(w) -> onCircle(mul(z, w))
                [by discharge given-w]
            }
          @z-implies |
            onCircle(z) -> onCircle(w) -> onCircle(mul(z, w))
            [by discharge given-z]
        }
      @discharge-w |
        forall w: Complex; onCircle(z) -> onCircle(w) -> onCircle(mul(z, w))
        [by generalize generalize-w]
    }
  @conclusion |
    forall z, w: Complex; onCircle(z) -> onCircle(w) -> onCircle(mul(z, w))
    [by generalize generalize-z]
qed

theorem circleGroupClosedUnderInverse: forall z: Complex; onCircle(z) -> onCircle(recip(z))
proof
  @generalize-z |
    fix z: Complex {
      @given-z |
        assume onCircle(z) {
          @z-unit |
            normSq(z) = RONE
            [by hypothesis given-z]
          // z ≠ 0, since |0|² = 0 ≠ 1.
          @zero-embedded |
            fromReal(RZERO) = ZERO
            [by cite fromRealZero]
          @re-of-embedded-zero |
            re(fromReal(RZERO)) = RZERO
            [using specialize reOfReal(RZERO)]
          @im-of-embedded-zero |
            im(fromReal(RZERO)) = RZERO
            [using specialize imOfReal(RZERO)]
          @re-of-zero |
            re(ZERO) = RZERO
            [by rewrite zero-embedded re-of-embedded-zero]
          @im-of-zero |
            im(ZERO) = RZERO
            [by rewrite zero-embedded im-of-embedded-zero]
          @normsq-zero-unfolded |
            normSq(ZERO) = radd(rmul(re(ZERO), re(ZERO)), rmul(im(ZERO), im(ZERO)))
            [by reflexivity]
          @normsq-zero-re |
            normSq(ZERO) = radd(rmul(RZERO, RZERO), rmul(im(ZERO), im(ZERO)))
            [by rewrite re-of-zero normsq-zero-unfolded]
          @normsq-zero-parts |
            normSq(ZERO) = radd(rmul(RZERO, RZERO), rmul(RZERO, RZERO))
            [by rewrite im-of-zero normsq-zero-re]
          @zero-arithmetic |
            radd(rmul(RZERO, RZERO), rmul(RZERO, RZERO)) = RZERO
            [using polynomial(real)]
          @normsq-of-zero |
            normSq(ZERO) = RZERO
            [using chain normsq-zero-parts zero-arithmetic]
          @one-not-zero |
            RONE != RZERO
            [using import(real) oneNotZero]
          @given-z-zero |
            assume z = ZERO {
              @z-zero |
                z = ZERO
                [by hypothesis given-z-zero]
              @normsq-z-is-zero |
                normSq(z) = RZERO
                [by rewrite z-zero normsq-of-zero]
              @one-is-normsq |
                RONE = normSq(z)
                [by symmetry z-unit]
              @one-is-zero |
                RONE = RZERO
                [using chain one-is-normsq normsq-z-is-zero]
            }
          @z-zero-implies |
            z = ZERO -> RONE = RZERO
            [by discharge given-z-zero]
          @z-nonzero |
            z != ZERO
            [using tautology z-zero-implies one-not-zero]
          // recip(z) = z̄ · recip(1) = z̄.
          @recip-formula |
            recip(z) = mul(conj(z), recip(fromReal(normSq(z))))
            [using specialize recipIsConjOverNormSq(z) z-nonzero]
          @recip-formula-unit |
            recip(z) = mul(conj(z), recip(fromReal(RONE)))
            [by rewrite z-unit recip-formula]
          @one-embedded |
            fromReal(RONE) = ONE
            [by cite fromRealOne]
          @recip-formula-one |
            recip(z) = mul(conj(z), recip(ONE))
            [by rewrite one-embedded recip-formula-unit]
          @complex-one-not-zero |
            ONE != ZERO
            [using import(complex) oneNotZero]
          @one-times-recip-one |
            mul(ONE, recip(ONE)) = ONE
            [using specialize fieldInverse(ONE) complex-one-not-zero]
          @one-times-recip-one-unfolds |
            mul(ONE, recip(ONE)) = recip(ONE)
            [using specialize mulOneLeft(recip(ONE))]
          @recip-one-is-product |
            recip(ONE) = mul(ONE, recip(ONE))
            [by symmetry one-times-recip-one-unfolds]
          @recip-of-one |
            recip(ONE) = ONE
            [using chain recip-one-is-product one-times-recip-one]
          @recip-is-conj-times-one |
            recip(z) = mul(conj(z), ONE)
            [by rewrite recip-of-one recip-formula-one]
          @conj-times-one |
            mul(conj(z), ONE) = conj(z)
            [using specialize mulOneRight(conj(z))]
          @recip-is-conj |
            recip(z) = conj(z)
            [using chain recip-is-conj-times-one conj-times-one]
          @conj-normsq |
            normSq(conj(z)) = normSq(z)
            [using specialize normSqConj(z)]
          @conj-unit |
            normSq(conj(z)) = RONE
            [using chain conj-normsq z-unit]
          @conclusion-recip-unit |
            onCircle(recip(z))
            [by rewrite recip-is-conj conj-unit]
        }
      @z-implies |
        onCircle(z) -> onCircle(recip(z))
        [by discharge given-z]
    }
  @conclusion |
    forall z: Complex; onCircle(z) -> onCircle(recip(z))
    [by generalize generalize-z]
qed
```
