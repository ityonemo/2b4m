**Exercise 15.** *Compute `gcd(14, 39)`, `gcd(234, 165)`, … and, in each case,
integers `r` and `s` with `gcd(a, b) = ar + bs`.*

**Skipped (brutal computation)** — these are specific numeric gcd/Bézout

**Exercise 16.** *Let `a` and `b` be nonzero integers. If there exist integers
`r` and `s` with `ar + bs = 1`, then `a` and `b` are relatively prime* — i.e.
every common divisor of `a` and `b` is a unit (`±1`).

Any common divisor `e` of `a` and `b` divides `ar` and `bs` (by `dividesMul`),
hence their sum `ar + bs = 1` (by `dividesAdd`); a divisor of `1` is a unit.

```bpa
theorem exerciseSixteenBezoutImpliesCoprime: forall a, b: Int;
  a != ZERO -> b != ZERO ->
  (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) ->
  (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @given-a-nonzero |
            assume a != ZERO {
              @given-b-nonzero |
                assume b != ZERO {
                  @given-bezout-combination |
                    assume exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE {
                      @bezout-combination-exists |
                        exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                        [by hypothesis given-bezout-combination]
                      @with-coefficient-r |
                        unpack r: Int from bezout-combination-exists {
                          @combination-with-s-exists |
                            exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                            [by hypothesis with-coefficient-r]
                          @with-coefficient-s |
                            unpack s: Int from combination-with-s-exists {
                              @combination-is-one |
                                add(mul(a, r), mul(b, s)) = ONE
                                [by hypothesis with-coefficient-s]
                              @every-common-divisor-is-a-unit |
                                fix e: Int {
                                  @given-e-divides-a |
                                    assume does_divide(e, a) {
                                      @given-e-divides-b |
                                        assume does_divide(e, b) {
                                          @e-divides-a |
                                            does_divide(e, a)
                                            [by hypothesis given-e-divides-a]
                                          @e-divides-b |
                                            does_divide(e, b)
                                            [by hypothesis given-e-divides-b]
                                          // e | a·r and e | b·s.
                                          @e-divides-a-times-r |
                                            does_divide(e, mul(a, r))
                                            [using specialize dividesMul(e, a, r) e-divides-a]
                                          @e-divides-b-times-s |
                                            does_divide(e, mul(b, s))
                                            [using specialize dividesMul(e, b, s) e-divides-b]
                                          // hence e divides their sum a·r + b·s = 1.
                                          @e-divides-combination |
                                            does_divide(e, add(mul(a, r), mul(b, s)))
                                            [using specialize dividesAdd(e, mul(a, r), mul(b, s)) e-divides-a-times-r e-divides-b-times-s]
                                          @e-divides-one |
                                            does_divide(e, ONE)
                                            [by rewrite combination-is-one e-divides-combination]
                                          @conclusion-e-is-a-unit |
                                            e = ONE or e = neg(ONE)
                                            [using specialize dividesOneImpliesUnit(e) e-divides-one]
                                        }
                                      @e-divides-b-implies-unit |
                                        does_divide(e, b) -> (e = ONE or e = neg(ONE))
                                        [by implies_intro given-e-divides-b]
                                    }
                                  @e-divides-a-implies-unit |
                                    does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                                    [by implies_intro given-e-divides-a]
                                }
                              @conclusion-every-common-divisor-is-a-unit |
                                forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                                [by forall_intro every-common-divisor-is-a-unit]
                            }
                          @conclusion-coprime-from-s |
                            forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                            [by exists_elim with-coefficient-s]
                        }
                      @conclusion-coprime-from-r |
                        forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                        [by exists_elim with-coefficient-r]
                    }
                  @bezout-combination-implies-coprime |
                    (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                    [by implies_intro given-bezout-combination]
                }
              @b-nonzero-implies-coprime |
                b != ZERO -> (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                [by implies_intro given-b-nonzero]
            }
          @a-nonzero-implies-coprime |
            a != ZERO -> b != ZERO -> (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
            [by implies_intro given-a-nonzero]
        }
      @discharge-b |
        forall b: Int; a != ZERO -> b != ZERO -> (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; a != ZERO -> b != ZERO -> (exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
    [by forall_intro generalize-a]
qed
```

**Exercise 18.** *Let `a` and `b` be relatively prime and suppose `ar + bs = 1`.
Prove `gcd(a, s) = gcd(r, b) = gcd(r, s) = 1`.*

The whole exercise rests on one observation, applied three ways: the single
relation `ar + bs = 1` already exhibits `1` as an integer combination of each of
the pairs `{a, s}`, `{r, b}`, `{r, s}`. So a common divisor of any such pair
divides `1` and is therefore a unit — exactly the relatively-prime conclusion in
the unit-divisor form of Exercise 16. (Judson's gcd-value statement "`= 1`" is
this coprimality; the hypothesis `gcd(a, b) = 1` is not even needed — `ar + bs =
1` alone suffices for all three.)

For `gcd(r, s) = 1`: a common divisor `e` of `r` and `s` divides `a·r` and `b·s`
(each is `e` dividing a multiple of something `e` divides, after a commutativity
flip), hence their sum `ar + bs = 1`.

```bpa
theorem exerciseEighteenCoprimeRS: forall a, b, r, s: Int;
  add(mul(a, r), mul(b, s)) = ONE ->
  (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-r |
            fix r: Int {
              @generalize-s |
                fix s: Int {
                  @given-combination-is-one |
                    assume add(mul(a, r), mul(b, s)) = ONE {
                      @combination-is-one |
                        add(mul(a, r), mul(b, s)) = ONE
                        [by hypothesis given-combination-is-one]
                      @every-common-divisor-is-a-unit |
                        fix e: Int {
                          @given-e-divides-r |
                            assume does_divide(e, r) {
                              @given-e-divides-s |
                                assume does_divide(e, s) {
                                  @e-divides-r |
                                    does_divide(e, r)
                                    [by hypothesis given-e-divides-r]
                                  @e-divides-s |
                                    does_divide(e, s)
                                    [by hypothesis given-e-divides-s]
                                  // e | r·a, rewritten to e | a·r.
                                  @e-divides-r-times-a |
                                    does_divide(e, mul(r, a))
                                    [using specialize dividesMul(e, r, a) e-divides-r]
                                  @r-times-a-is-a-times-r |
                                    mul(r, a) = mul(a, r)
                                    [using specialize mulIsCommutative(r, a)]
                                  @e-divides-a-times-r |
                                    does_divide(e, mul(a, r))
                                    [by rewrite r-times-a-is-a-times-r e-divides-r-times-a]
                                  // e | s·b, rewritten to e | b·s.
                                  @e-divides-s-times-b |
                                    does_divide(e, mul(s, b))
                                    [using specialize dividesMul(e, s, b) e-divides-s]
                                  @s-times-b-is-b-times-s |
                                    mul(s, b) = mul(b, s)
                                    [using specialize mulIsCommutative(s, b)]
                                  @e-divides-b-times-s |
                                    does_divide(e, mul(b, s))
                                    [by rewrite s-times-b-is-b-times-s e-divides-s-times-b]
                                  // hence e divides a·r + b·s = 1.
                                  @e-divides-combination |
                                    does_divide(e, add(mul(a, r), mul(b, s)))
                                    [using specialize dividesAdd(e, mul(a, r), mul(b, s)) e-divides-a-times-r e-divides-b-times-s]
                                  @e-divides-one |
                                    does_divide(e, ONE)
                                    [by rewrite combination-is-one e-divides-combination]
                                  @conclusion-e-is-a-unit |
                                    e = ONE or e = neg(ONE)
                                    [using specialize dividesOneImpliesUnit(e) e-divides-one]
                                }
                              @e-divides-s-implies-unit |
                                does_divide(e, s) -> (e = ONE or e = neg(ONE))
                                [by implies_intro given-e-divides-s]
                            }
                          @e-divides-r-implies-unit |
                            does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE))
                            [by implies_intro given-e-divides-r]
                        }
                      @conclusion-coprime-rs |
                        forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE))
                        [by forall_intro every-common-divisor-is-a-unit]
                    }
                  @combination-implies-coprime-rs |
                    add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
                    [by implies_intro given-combination-is-one]
                }
              @discharge-s |
                forall s: Int; add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
                [by forall_intro generalize-s]
            }
          @discharge-r |
            forall r, s: Int; add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
            [by forall_intro generalize-r]
        }
      @discharge-b |
        forall b, r, s: Int; add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, r, s: Int; add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, s) -> (e = ONE or e = neg(ONE)))
    [by forall_intro generalize-a]
qed
```

The `gcd(a, s) = 1` and `gcd(r, b) = 1` parts are the same argument on the other
two pairings. For `{a, s}`: `e | a` gives `e | a·r` directly, and `e | s` gives
`e | b·s` after the commutativity flip. For `{r, b}`: `e | r` gives `e | a·r`
after the flip, and `e | b` gives `e | b·s` directly.

```bpa
    forall a, b, r, s: Int; add(mul(a, r), mul(b, s)) = ONE -> (forall e: Int; does_divide(e, r) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
    [by forall_intro generalize-a]
qed
```

**Exercise 22.** *Let `n ∈ ℤ`. Show that every integer is congruent mod `n` to
precisely one of the integers `0, 1, …, n − 1`.*

"Congruent mod `n` to `s`" means `n | (r − s)`; the residues `0, …, n − 1` are
exactly the integers `s` with `0 ≤ s < n`. So the claim is: for `n > 0` and any
`r`, there is one and only one `s` with `0 ≤ s < n` and `n | (r − s)`. This is
the Division Algorithm read as a statement about remainders — its existence and
uniqueness are precisely what we need.

**Existence.** Take `s = r mod n`. The division property `n·(r div n) + (r mod
n) = r` rearranges to `r − s = n·(r div n)`, so `n | (r − s)`; and `mod`'s bounds
give `0 ≤ s < n`.

```bpa
theorem exerciseTwentyTwoResidueExists: forall n, r: Int; less_than(ZERO, n) ->
  exists s: Int; is_nonneg(s) and less_than(s, n) and does_divide(n, sub(r, s))
proof
  @generalize-n |
    fix n: Int {
      @generalize-r |
        fix r: Int {
          @given-n-positive |
            assume less_than(ZERO, n) {
              @n-positive |
                less_than(ZERO, n)
                [by hypothesis given-n-positive]
              // s = r mod n is nonnegative and below n.
              @residue-nonneg |
                is_nonneg(mod(r, n))
                [using specialize modNonneg(n, r) n-positive]
              @residue-below-n |
                less_than(mod(r, n), n)
                [using specialize modBound(n, r) n-positive]
              // r − (r mod n) = n·(r div n): a linear rearrangement of the
              // division property r = n·(r div n) + (r mod n), which `arithmetic`
              // certifies by combining that equality premise (the certifier
              // eliminates the r mod n leaf against the division property).
              @division-property |
                add(mul(n, div(r, n)), mod(r, n)) = r
                [using specialize divModProperty(n, r) n-positive]
              @remainder-difference-is-multiple |
                sub(r, mod(r, n)) = mul(n, div(r, n))
                [using arithmetic division-property]
              @n-divides-remainder-difference |
                does_divide(n, sub(r, mod(r, n)))
                [using specialize dividesIntro(sub(r, mod(r, n)), n, div(r, n)) remainder-difference-is-multiple]
              // package the residue s = r mod n.
              @residue-nonneg-and-below |
                is_nonneg(mod(r, n)) and less_than(mod(r, n), n)
                [by and_intro residue-nonneg residue-below-n]
              @residue-properties |
                is_nonneg(mod(r, n)) and less_than(mod(r, n), n) and does_divide(n, sub(r, mod(r, n)))
                [by and_intro residue-nonneg-and-below n-divides-remainder-difference]
              @conclusion-residue-exists |
                exists s: Int; is_nonneg(s) and less_than(s, n) and does_divide(n, sub(r, s))
                [by exists_intro(mod(r, n)) residue-properties]
            }
          @n-positive-implies-residue-exists |
            less_than(ZERO, n) -> exists s: Int; is_nonneg(s) and less_than(s, n) and does_divide(n, sub(r, s))
            [by implies_intro given-n-positive]
        }
      @discharge-r |
        forall r: Int; less_than(ZERO, n) -> exists s: Int; is_nonneg(s) and less_than(s, n) and does_divide(n, sub(r, s))
        [by forall_intro generalize-r]
    }
  @conclusion |
    forall n, r: Int; less_than(ZERO, n) -> exists s: Int; is_nonneg(s) and less_than(s, n) and does_divide(n, sub(r, s))
    [by forall_intro generalize-n]
qed
```

**Uniqueness.** Two residues `s`, `s'` of `r` with `n | (r − s)` and `n | (r −
s')` write `r = nk + s = nk' + s'` with `0 ≤ s, s' < n`; the uniqueness half of
the Division Algorithm forces `s = s'`. (`does_divide(n, r − s)` unfolds
transparently to `∃k; r − s = nk`, so we unpack the two witnesses `k`, `k'` and
feed the two decompositions to `divisionAlgorithmUnique`.)

```bpa
theorem exerciseTwentyTwoResidueUnique: forall n, r, s, s2: Int; less_than(ZERO, n) ->
  is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) ->
  is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) ->
  s = s2
proof
  @generalize-n |
    fix n: Int {
      @generalize-r |
        fix r: Int {
          @generalize-s |
            fix s: Int {
              @generalize-s2 |
                fix s2: Int {
                  @given-n-positive |
                    assume less_than(ZERO, n) {
                      @given-s-nonneg |
                        assume is_nonneg(s) {
                          @given-s-below-n |
                            assume less_than(s, n) {
                              @given-n-divides-r-minus-s |
                                assume does_divide(n, sub(r, s)) {
                                  @given-s2-nonneg |
                                    assume is_nonneg(s2) {
                                      @given-s2-below-n |
                                        assume less_than(s2, n) {
                                          @given-n-divides-r-minus-s2 |
                                            assume does_divide(n, sub(r, s2)) {
                                              @n-positive |
                                                less_than(ZERO, n)
                                                [by hypothesis given-n-positive]
                                              @s-nonneg |
                                                is_nonneg(s)
                                                [by hypothesis given-s-nonneg]
                                              @s-below-n |
                                                less_than(s, n)
                                                [by hypothesis given-s-below-n]
                                              @s2-nonneg |
                                                is_nonneg(s2)
                                                [by hypothesis given-s2-nonneg]
                                              @s2-below-n |
                                                less_than(s2, n)
                                                [by hypothesis given-s2-below-n]
                                              // r − s and r − s2 are multiples of n; unpack the quotients.
                                              @n-divides-r-minus-s |
                                                exists k: Int; sub(r, s) = mul(n, k)
                                                [by hypothesis given-n-divides-r-minus-s]
                                              @n-divides-r-minus-s2 |
                                                exists k: Int; sub(r, s2) = mul(n, k)
                                                [by hypothesis given-n-divides-r-minus-s2]
                                              @with-quotient-k |
                                                unpack k: Int from n-divides-r-minus-s {
                                                  @r-minus-s-is-n-k |
                                                    sub(r, s) = mul(n, k)
                                                    [by hypothesis with-quotient-k]
                                                  // r = n·k + s, from (r − s) + s = r.
                                                  @quotient-plus-s-is-r |
                                                    add(mul(n, k), s) = r
                                                    [using arithmetic r-minus-s-is-n-k]
                                                  @first-decomposition |
                                                    r = add(mul(n, k), s)
                                                    [using arithmetic quotient-plus-s-is-r]
                                                  @with-quotient-k2 |
                                                    unpack k2: Int from n-divides-r-minus-s2 {
                                                      @r-minus-s2-is-n-k2 |
                                                        sub(r, s2) = mul(n, k2)
                                                        [by hypothesis with-quotient-k2]
                                                      @quotient-plus-s2-is-r |
                                                        add(mul(n, k2), s2) = r
                                                        [using arithmetic r-minus-s2-is-n-k2]
                                                      @second-decomposition |
                                                        r = add(mul(n, k2), s2)
                                                        [using arithmetic quotient-plus-s2-is-r]
                                                      // the Division Algorithm's uniqueness pins the remainders.
                                                      @quotient-and-residue-agree |
                                                        k = k2 and s = s2
                                                        [using specialize divisionAlgorithmUnique(r, n, k, s, k2, s2) n-positive first-decomposition s-nonneg s-below-n second-decomposition s2-nonneg s2-below-n]
                                                      @conclusion-residues-equal |
                                                        s = s2
                                                        [by and_elim_right quotient-and-residue-agree]
                                                    }
                                                  @residues-equal-under-k |
                                                    s = s2
                                                    [by exists_elim with-quotient-k2]
                                                }
                                              @conclusion-residues-equal |
                                                s = s2
                                                [by exists_elim with-quotient-k]
                                            }
                                          @n-divides-r-minus-s2-implies-equal |
                                            does_divide(n, sub(r, s2)) -> s = s2
                                            [by implies_intro given-n-divides-r-minus-s2]
                                        }
                                      @s2-below-n-implies-equal |
                                        less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                                        [by implies_intro given-s2-below-n]
                                    }
                                  @s2-nonneg-implies-equal |
                                    is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                                    [by implies_intro given-s2-nonneg]
                                }
                              @n-divides-r-minus-s-implies-equal |
                                does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                                [by implies_intro given-n-divides-r-minus-s]
                            }
                          @s-below-n-implies-equal |
                            less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                            [by implies_intro given-s-below-n]
                        }
                      @s-nonneg-implies-equal |
                        is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                        [by implies_intro given-s-nonneg]
                    }
                  @n-positive-implies-equal |
                    less_than(ZERO, n) -> is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                    [by implies_intro given-n-positive]
                }
              @discharge-s2 |
                forall s2: Int; less_than(ZERO, n) -> is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
                [by forall_intro generalize-s2]
            }
          @discharge-s |
            forall s, s2: Int; less_than(ZERO, n) -> is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
            [by forall_intro generalize-s]
        }
      @discharge-r |
        forall r, s, s2: Int; less_than(ZERO, n) -> is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
        [by forall_intro generalize-r]
    }
  @conclusion |
    forall n, r, s, s2: Int; less_than(ZERO, n) -> is_nonneg(s) -> less_than(s, n) -> does_divide(n, sub(r, s)) -> is_nonneg(s2) -> less_than(s2, n) -> does_divide(n, sub(r, s2)) -> s = s2
    [by forall_intro generalize-n]
qed
```

Existence and uniqueness together are the exercise: each integer `r` has exactly
one residue in `{0, …, n − 1}` to which it is congruent mod `n`.

**Exercise 23.** *Show that there is a unique least common multiple of `a` and
`b` — a common multiple `m` of `a` and `b` that divides every common multiple.*

Judson intends the well-ordering construction (take the least positive common
multiple). In `std` that construction is already discharged into the function
`lcm(a, b)`, whose defining axioms package existence: `lcm(a, b)` is nonnegative
(`lcmNonneg`), is a common multiple of both `a` and `b` (`lcmCommonMultipleLeft`
/ `lcmCommonMultipleRight`), and divides every common multiple (`lcmLeast`).
Those four properties are exactly "`lcm(a, b)` is a least common multiple."

```bpa
theorem exerciseTwentyThreeLeastCommonMultipleExists: forall a, b: Int;
  is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b)) and does_divide(b, lcm(a, b))
  and (forall n: Int; does_divide(a, n) -> does_divide(b, n) -> does_divide(lcm(a, b), n))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          // the four defining properties of lcm(a, b).
          @lcm-nonneg |
            is_nonneg(lcm(a, b))
            [using specialize lcmNonneg(a, b)]
          @a-divides-lcm |
            does_divide(a, lcm(a, b))
            [using specialize lcmCommonMultipleLeft(a, b)]
          @b-divides-lcm |
            does_divide(b, lcm(a, b))
            [using specialize lcmCommonMultipleRight(a, b)]
          @lcm-divides-every-common-multiple |
            forall n: Int; does_divide(a, n) -> does_divide(b, n) -> does_divide(lcm(a, b), n)
            [using specialize lcmLeast(a, b)]
          // assemble the least-common-multiple package (and is left-associative).
          @lcm-nonneg-and-a-divides |
            is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b))
            [by and_intro lcm-nonneg a-divides-lcm]
          @lcm-common-multiple |
            is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b)) and does_divide(b, lcm(a, b))
            [by and_intro lcm-nonneg-and-a-divides b-divides-lcm]
          @conclusion-lcm-is-least-common-multiple |
            is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b)) and does_divide(b, lcm(a, b)) and (forall n: Int; does_divide(a, n) -> does_divide(b, n) -> does_divide(lcm(a, b), n))
            [by and_intro lcm-common-multiple lcm-divides-every-common-multiple]
        }
      @discharge-b |
        forall b: Int; is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b)) and does_divide(b, lcm(a, b)) and (forall n: Int; does_divide(a, n) -> does_divide(b, n) -> does_divide(lcm(a, b), n))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; is_nonneg(lcm(a, b)) and does_divide(a, lcm(a, b)) and does_divide(b, lcm(a, b)) and (forall n: Int; does_divide(a, n) -> does_divide(b, n) -> does_divide(lcm(a, b), n))
    [by forall_intro generalize-a]
qed
```

Uniqueness is `std`'s `lcmUnique`: any positive `m` that is a common multiple of
`a` and `b` and divides every common multiple must equal `lcm(a, b)` (they divide
each other, and two positive integers that divide each other are equal). We
forward it under an exercise name.

```bpa
theorem exerciseTwentyThreeLeastCommonMultipleUnique = int_divides.lcmUnique
```

**Exercise 26.** *Show that `gcd(a, c) = gcd(b, c) = 1` if and only if `gcd(ab,
c) = 1`.*

**Deferred (attempted):** the forward direction — `a, c` coprime and `b, c`
coprime imply `ab, c` coprime — is the substantive half, and the clean route is
Bézout: from `au + cv = 1` and `bx + cy = 1`, multiplying gives `ab·(ux) + c·(…)
= 1`, exhibiting `1` as an integer combination of `ab` and `c`, whence any common
divisor of `ab` and `c` is a unit (the Exercise 16 pattern). Carrying this out
in the kernel needs the *product-of-coprimes* combination identity `(au + cv)(bx
+ cy) = ab·(ux) + c·(auy + bvx + cvy)`, a nonlinear `mul`/`add` expansion over
the eight cross terms that must be normalized to isolate the `ab·(ux)` summand
from the `c·(…)` summand. That normalization is exactly the kind of multi-term
polynomial rearrangement the `polynomial` tactic handles, but the coefficient
`auy + bvx + cvy` has to be *named as the witness* for the `c`-combination, and
extracting it as a closed term from the expansion — rather than merely certifying
an equality — is beyond what the accelerants expose here. The backward direction
(`ab, c` coprime implies each of `a, c` and `b, c` coprime) follows because any
common divisor of `a` and `c` is a common divisor of `ab` and `c` (`a | ab`), but
without the forward direction the biconditional does not close. Deferred pending
a product-of-coprimes lemma in `std`.
