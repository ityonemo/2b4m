# Dihedral Groups (Exercises)

Exercises for Judson **Chapter 5 "Permutation Groups"** that belong to §5.2 — the
dihedral groups and the motion groups of solids (source: `vendor/aata/src/permute.xml`;
© 1997–2026 Judson, GFDL 1.3), following `.claude/rules/aata-guide.md`. The exercises
use `std` **liberally**: the concrete dihedral group of the $n$-gon is
`std/permutation/dihedral.b4m` (§5.2 cites its count), with the rotation $\rho$ and the
reflection $\sigma$ characterized by their values on the letters $0, \ldots, n-1$.

```2b4m
import element <<< "std/element.b4m"
import function <<< "std/function.b4m"
import set_finite <<< "std/set/finite.b4m"
import permutation_dihedral <<< "std/permutation/dihedral.b4m"
import peano <<< "std/peano.b4m"
import peano_order <<< "std/peano/order.b4m"
import cycle_theory <<< "std/permutation/cycle.b4m"

sort Element = element.Element
sort Fn = function.Fn
func apply = function.apply
func compose = function.compose
axiom composeApply = function.composeApply
sort Nat = peano.Nat
const ZERO = peano.ZERO
func succ = peano.succ
func sub = peano.sub
pred less_than = peano.less_than
axiom succInjective = peano.succInjective
theorem lessThanSelf = peano_order.lessThanSelf
theorem lessThanTransitive = peano_order.lessThanTransitive
theorem lessThanIrreflexive = peano_order.lessThanIrreflexive
theorem zeroBelowSucc = cycle_theory.zeroBelowSucc
func numeral = set_finite.numeral
axiom numeralInjective = set_finite.numeralInjective
define isTheRotation(rho, n) = permutation_dihedral.isTheRotation(rho, n)
define isTheReflection(sigma, n) = permutation_dihedral.isTheReflection(sigma, n)
theorem positiveIsASuccessor = permutation_dihedral.positiveIsASuccessor
theorem complementOfOne = permutation_dihedral.complementOfOne
```

## Exercises

**Exercise 14.** Using cycle notation, list the elements of $D_5$; what are $r$ and $s$;
write every element as a product of $r$ and $s$. **Skipped** — a concrete listing of one
group (the general statement, that every element is $r^k$ or $r^k s$, is §5.2's
`dihedralGroupHasTwiceNElements`).

**Exercises 15, 16.** The motion of the cube corresponding to $(12)(34)$ on the diagonals;
the rigid motions of a tetrahedron form $A_4$. **Deferred:** the solids' motion groups
need a concrete cube and tetrahedron — vertices, edges as adjacency, and the motions as
the adjacency-preserving permutations, exactly as `std/permutation/dihedral.b4m` does the
$n$-gon; the $n$-gon's induction along the letters has no analogue for a single solid,
so the 24 (resp. 12) motions would be finite case work.

**Exercise 19.** Prove that $D_n$ is nonabelian for $n \geq 3$: $\rho\sigma$ sends
vertex $0$ to $\rho(0) = 1$, while $\sigma\rho$ sends it to $\sigma(1) = n - 1$, and
$n - 1 \neq 1$ when $n \neq 2$.

```2b4m
theorem dihedralGroupIsNonabelian: forall n: Nat; less_than(succ(succ(ZERO)), n) ->
  forall rho: Fn; forall sigma: Fn; isTheRotation(rho, n) -> isTheReflection(sigma, n) ->
  compose(rho, sigma) != compose(sigma, rho)
proof
  @generalize-n |
    fix n: Nat {
      @given-three-letters |
        assume less_than(succ(succ(ZERO)), n) {
          @three-letters |
            less_than(succ(succ(ZERO)), n)
            [by hypothesis given-three-letters]
          @one-below-two |
            less_than(succ(ZERO), succ(succ(ZERO)))
            [using specialize lessThanSelf(succ(ZERO))]
          @one-in-range |
            less_than(succ(ZERO), n)
            [using specialize lessThanTransitive(succ(ZERO), succ(succ(ZERO)), n) one-below-two three-letters]
          @zero-below-one |
            less_than(ZERO, succ(ZERO))
            [using specialize zeroBelowSucc(ZERO)]
          @n-is-a-successor |
            exists m: Nat; n = succ(m)
            [using specialize positiveIsASuccessor(succ(ZERO), n) one-in-range]
          @generalize-rho |
            fix rho: Fn {
              @generalize-sigma |
                fix sigma: Fn {
                  @given-rotation |
                    assume isTheRotation(rho, n) {
                      @given-reflection |
                        assume isTheReflection(sigma, n) {
                          @rotation |
                            isTheRotation(rho, n)
                            [by hypothesis given-rotation]
                          @reflection |
                            isTheReflection(sigma, n)
                            [by hypothesis given-reflection]
                          @advances |
                            forall i: Nat; less_than(succ(i), n) -> apply(rho, numeral(i)) = numeral(succ(i))
                            [using tautology rotation]
                          @fixes-zero |
                            apply(sigma, numeral(ZERO)) = numeral(ZERO)
                            [using tautology reflection]
                          @complements |
                            forall i: Nat; less_than(ZERO, i) -> less_than(i, n) -> apply(sigma, numeral(i)) = numeral(sub(n, i))
                            [using tautology reflection]

                          // ρσ at vertex 0 is vertex 1
                          @zero-advances |
                            apply(rho, numeral(ZERO)) = numeral(succ(ZERO))
                            [using specialize advances(ZERO) one-in-range]
                          @rho-sigma-unfolds |
                            apply(compose(rho, sigma), numeral(ZERO)) = apply(rho, apply(sigma, numeral(ZERO)))
                            [using specialize composeApply(rho, sigma, numeral(ZERO))]
                          @rho-sigma-after-sigma |
                            apply(compose(rho, sigma), numeral(ZERO)) = apply(rho, numeral(ZERO))
                            [by rewrite fixes-zero rho-sigma-unfolds]
                          @rho-sigma-at-zero |
                            apply(compose(rho, sigma), numeral(ZERO)) = numeral(succ(ZERO))
                            [using chain rho-sigma-after-sigma zero-advances]

                          // σρ at vertex 0 is vertex n - 1
                          @one-reflects |
                            apply(sigma, numeral(succ(ZERO))) = numeral(sub(n, succ(ZERO)))
                            [using specialize complements(succ(ZERO)) zero-below-one one-in-range]
                          @sigma-rho-unfolds |
                            apply(compose(sigma, rho), numeral(ZERO)) = apply(sigma, apply(rho, numeral(ZERO)))
                            [using specialize composeApply(sigma, rho, numeral(ZERO))]
                          @sigma-rho-after-rho |
                            apply(compose(sigma, rho), numeral(ZERO)) = apply(sigma, numeral(succ(ZERO)))
                            [by rewrite zero-advances sigma-rho-unfolds]
                          @sigma-rho-at-zero |
                            apply(compose(sigma, rho), numeral(ZERO)) = numeral(sub(n, succ(ZERO)))
                            [using chain sigma-rho-after-rho one-reflects]

                          // they differ unless n = 2
                          @suppose-commute |
                            assume compose(rho, sigma) = compose(sigma, rho) {
                              @commute |
                                compose(rho, sigma) = compose(sigma, rho)
                                [by hypothesis suppose-commute]
                              @sigma-rho-at-zero-is-one |
                                apply(compose(sigma, rho), numeral(ZERO)) = numeral(succ(ZERO))
                                [by rewrite commute rho-sigma-at-zero]
                              @letters-agree |
                                numeral(sub(n, succ(ZERO))) = numeral(succ(ZERO))
                                [by rewrite sigma-rho-at-zero sigma-rho-at-zero-is-one]
                              @complement-is-one |
                                sub(n, succ(ZERO)) = succ(ZERO)
                                [using specialize numeralInjective(sub(n, succ(ZERO)), succ(ZERO)) letters-agree]
                              @with-last-m |
                                unpack m: Nat from n-is-a-successor {
                                  @n-is-succ-m |
                                    n = succ(m)
                                    [by hypothesis with-last-m]
                                  @complement-of-one-at-succ-m |
                                    sub(succ(m), succ(ZERO)) = m
                                    [using specialize complementOfOne(m)]
                                  @complement-of-one |
                                    sub(n, succ(ZERO)) = m
                                    [by rewrite n-is-succ-m complement-of-one-at-succ-m]
                                  @m-is-one |
                                    m = succ(ZERO)
                                    [by rewrite complement-of-one complement-is-one]
                                  @n-is-two |
                                    n = succ(succ(ZERO))
                                    [by rewrite m-is-one n-is-succ-m]
                                  @conclusion-two-below-itself |
                                    less_than(succ(succ(ZERO)), succ(succ(ZERO)))
                                    [by rewrite n-is-two three-letters]
                                }
                              @two-below-itself |
                                less_than(succ(succ(ZERO)), succ(succ(ZERO)))
                                [by exists_elim with-last-m]
                            }
                          @two-not-below-itself |
                            not less_than(succ(succ(ZERO)), succ(succ(ZERO)))
                            [using specialize lessThanIrreflexive(succ(succ(ZERO)))]
                          @conclusion-do-not-commute |
                            compose(rho, sigma) != compose(sigma, rho)
                            [by not_intro suppose-commute two-below-itself two-not-below-itself]
                        }
                      @conclusion-given-reflection |
                        isTheReflection(sigma, n) -> compose(rho, sigma) != compose(sigma, rho)
                        [by implies_intro given-reflection]
                    }
                  @conclusion-at-sigma |
                    isTheRotation(rho, n) -> isTheReflection(sigma, n) -> compose(rho, sigma) != compose(sigma, rho)
                    [by implies_intro given-rotation]
                }
              @discharge-sigma |
                forall sigma: Fn; isTheRotation(rho, n) -> isTheReflection(sigma, n) -> compose(rho, sigma) != compose(sigma, rho)
                [by forall_intro generalize-sigma]
            }
          @discharge-rho |
            forall rho: Fn; forall sigma: Fn; isTheRotation(rho, n) -> isTheReflection(sigma, n) -> compose(rho, sigma) != compose(sigma, rho)
            [by forall_intro generalize-rho]
        }
      @conclusion-at-n |
        less_than(succ(succ(ZERO)), n) -> forall rho: Fn; forall sigma: Fn; isTheRotation(rho, n) -> isTheReflection(sigma, n) -> compose(rho, sigma) != compose(sigma, rho)
        [by implies_intro given-three-letters]
    }
  @conclusion |
    forall n: Nat; less_than(succ(succ(ZERO)), n) ->
      forall rho: Fn; forall sigma: Fn; isTheRotation(rho, n) -> isTheReflection(sigma, n) ->
      compose(rho, sigma) != compose(sigma, rho)
    [by forall_intro generalize-n]
qed
```

**Exercise 29.** The center of $D_n$: the identity for odd $n$, the identity and the
$180°$ rotation for even $n$. **Deferred:** needs "$\rho^k$ commutes with $\sigma$ iff
$\rho^{2k} = 1$" (from $\sigma\rho^k = \rho^{-k}\sigma$, Exercise 37(b)) and the order
of $\rho$ being exactly $n$ with its parity — the modular arithmetic of Exercise 12 on
the concrete rotation.

**Exercise 37.** (a) $srs = r^{-1}$: in the presentation of §5.2 this is the defining
relation `reflectionInverts`; on the concrete $n$-gon it is proved pointwise on the
vertices as `std/permutation/dihedral.b4m`'s `reflectionReversesTheRotation`
($\sigma\rho(x) = \rho^{-1}\sigma(x)$ for every vertex $x$), and $s^2 = 1$ is
`reflectionSquaredIsIdentity`. (b) $r^k s = s r^{-k}$: **Deferred** — an induction on the
integer exponent from §5.2's `sPastR` (the presentation's $sr = r^{-1}s$), needing the
integer-power laws of `std/group/power.b4m` over the presentation. (c) The order of
$r^k$ is $n/\gcd(k, n)$: **Deferred** — Chapter 4's order theory (`std/group/element-order`)
with $\gcd$ from `std/peano/divides.b4m`, applied to the rotation whose order is $n$
(the powers $\rho^0, \ldots, \rho^{n-1}$ are distinct, `powersOfTheRotationDiffer`).

```2b4m
theorem reflectionReversesTheRotation = permutation_dihedral.reflectionReversesTheRotation
theorem reflectionSquaredIsIdentity = permutation_dihedral.reflectionSquaredIsIdentity
```
