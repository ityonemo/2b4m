# Groups — The Integers mod n (Exercises)

Exercises for Judson **Chapter 3 ("Groups"), §3.1 "Integer Equivalence Classes
and Symmetries"** (source: `vendor/aata/src/groups.xml`; © 1997–2026 Judson,
GFDL 1.3). Exercises for Judson §3.1, per `.claude/rules/aata-guide.md` — `std`
used liberally.

As in the main text, congruence is a relation on $\mathbb Z$: $a \equiv b \pmod
n$ is $n \mid (a - b)$, encoded `does_divide(n, sub(a, b))`. Most of §3.1's
arithmetic-mod-$n$ exercises are the *equivalence-class arithmetic* half of the
proposition Judson states — each reduces to a ring identity of $\mathbb Z$ whose
two sides are equal, so their difference is $0$ and $n \mid 0$. We reuse the
§3.1 import header.

## The recurring lemma: equal integers are congruent

The main text captures this as `congruentOfEqual`; we restate it locally under
the name the exercises call for. If $x = y$ then $x - y = 0$ (`arithmetic`), and
$0 = n \cdot 0$, so $n \mid (x - y)$ — i.e. $x \equiv y \pmod n$.

```bpa
theorem congruentWhenEqual: forall n, x, y: Int; x = y -> does_divide(n, sub(x, y))
proof
  @generalize-n |
    fix n: Int {
      @generalize-x |
        fix x: Int {
          @generalize-y |
            fix y: Int {
              @given-equal |
                assume x = y {
                  @x-equals-y |
                    x = y
                    [by hypothesis given-equal]
                  // x − y = x − x = 0 once y is rewritten to x.
                  @difference-is-zero |
                    sub(x, y) = ZERO
                    [using arithmetic x-equals-y]
                  @n-times-zero |
                    mul(n, ZERO) = ZERO
                    [using specialize mulZeroRight(n)]
                  @zero-is-n-times-zero |
                    ZERO = mul(n, ZERO)
                    [by symmetry n-times-zero]
                  @difference-is-a-multiple |
                    sub(x, y) = mul(n, ZERO)
                    [using chain difference-is-zero zero-is-n-times-zero]
                  @n-divides-difference |
                    does_divide(n, sub(x, y))
                    [using specialize dividesIntro(sub(x, y), n, ZERO) difference-is-a-multiple]
                }
              @conclusion-implication |
                x = y -> does_divide(n, sub(x, y))
                [by implies_intro given-equal]
            }
          @discharge-y |
            forall y: Int; x = y -> does_divide(n, sub(x, y))
            [by forall_intro generalize-y]
        }
      @discharge-x |
        forall x, y: Int; x = y -> does_divide(n, sub(x, y))
        [by forall_intro generalize-x]
    }
  @conclusion |
    forall n, x, y: Int; x = y -> does_divide(n, sub(x, y))
    [by forall_intro generalize-n]
qed
```

Two ring-identity helpers for Exercise 22 (well-definedness of multiplication).
First, multiplication distributes over a difference on the right:
$a(b - c) = ab - ac$.

```bpa
theorem mulSubtractsRight: forall a, b, c: Int; mul(a, sub(b, c)) = sub(mul(a, b), mul(a, c))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @difference-as-add-neg |
                sub(b, c) = add(b, neg(c))
                [using specialize definitionOfSubtraction(b, c)]
              @product-over-sum |
                mul(a, add(b, neg(c))) = add(mul(a, b), mul(a, neg(c)))
                [using specialize mulAddDistribLeft(a, b, neg(c))]
              @product-with-neg |
                mul(a, neg(c)) = neg(mul(a, c))
                [using specialize mulNegRight(a, c)]
              @products-as-add-neg |
                sub(mul(a, b), mul(a, c)) = add(mul(a, b), neg(mul(a, c)))
                [using specialize definitionOfSubtraction(mul(a, b), mul(a, c))]
              @product-of-difference |
                mul(a, sub(b, c)) = sub(mul(a, b), mul(a, c))
                [using chain difference-as-add-neg product-over-sum product-with-neg products-as-add-neg]
            }
          @discharge-c |
            forall c: Int; mul(a, sub(b, c)) = sub(mul(a, b), mul(a, c))
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c: Int; mul(a, sub(b, c)) = sub(mul(a, b), mul(a, c))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c: Int; mul(a, sub(b, c)) = sub(mul(a, b), mul(a, c))
    [by forall_intro generalize-a]
qed
```

Second, the product-difference splitting identity
$ab - a'b' = a(b - b') + b'(a - a')$ (add and subtract $ab'$): the two
`mulSubtractsRight` expansions telescope once the cross term $b'a$ is written
$ab'$ and the tail $b'a'$ is written $a'b'$.

```bpa
theorem productDifferenceSplits:
  forall a, b, ap, bp: Int;
  sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-ap |
            fix ap: Int {
              @generalize-bp |
                fix bp: Int {
                  @first-product-splits |
                    mul(a, sub(b, bp)) = sub(mul(a, b), mul(a, bp))
                    [using specialize mulSubtractsRight(a, b, bp)]
                  @second-product-splits |
                    mul(bp, sub(a, ap)) = sub(mul(bp, a), mul(bp, ap))
                    [using specialize mulSubtractsRight(bp, a, ap)]
                  @cross-term-commutes |
                    mul(bp, a) = mul(a, bp)
                    [using specialize mulIsCommutative(bp, a)]
                  @tail-term-commutes |
                    mul(bp, ap) = mul(ap, bp)
                    [using specialize mulIsCommutative(bp, ap)]
                  // With the two products expanded and the cross/tail terms
                  // commuted, the four leaf products telescope: (ab − ab') +
                  // (ab' − a'b') = ab − a'b'.
                  @leaf-products-telescope |
                    add(sub(mul(a, b), mul(a, bp)), sub(mul(a, bp), mul(ap, bp))) = sub(mul(a, b), mul(ap, bp))
                    [using arithmetic]
                  @conclusion-splits |
                    sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
                    [using chain first-product-splits second-product-splits cross-term-commutes tail-term-commutes leaf-products-telescope]
                }
              @discharge-bp |
                forall bp: Int; sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
                [by forall_intro generalize-bp]
            }
          @discharge-ap |
            forall ap, bp: Int; sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
            [by forall_intro generalize-ap]
        }
      @discharge-b |
        forall b, ap, bp: Int; sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, ap, bp: Int; sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
    [by forall_intro generalize-a]
qed
```

**Exercise 19.** *Prove that $0 + a \equiv a + 0 \equiv a \pmod n$ — the additive
identity in $\mathbb Z_n$.* Both $0 + a$ and $a + 0$ equal $a$ in $\mathbb Z$
(`addZeroLeft`, `addZeroRight`), so each is congruent to $a$.

```bpa
theorem additiveIdentityModN:
  forall n, a: Int;
  does_divide(n, sub(add(ZERO, a), a)) and does_divide(n, sub(add(a, ZERO), a))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @zero-plus-a |
            add(ZERO, a) = a
            [using specialize addZeroLeft(a)]
          @a-plus-zero |
            add(a, ZERO) = a
            [using specialize addZeroRight(a)]
          @left-identity-congruent |
            does_divide(n, sub(add(ZERO, a), a))
            [using specialize congruentWhenEqual(n, add(ZERO, a), a) zero-plus-a]
          @right-identity-congruent |
            does_divide(n, sub(add(a, ZERO), a))
            [using specialize congruentWhenEqual(n, add(a, ZERO), a) a-plus-zero]
          @conclusion-both-identities |
            does_divide(n, sub(add(ZERO, a), a)) and does_divide(n, sub(add(a, ZERO), a))
            [by and_intro left-identity-congruent right-identity-congruent]
        }
      @discharge-a |
        forall a: Int; does_divide(n, sub(add(ZERO, a), a)) and does_divide(n, sub(add(a, ZERO), a))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall n, a: Int; does_divide(n, sub(add(ZERO, a), a)) and does_divide(n, sub(add(a, ZERO), a))
    [by forall_intro generalize-n]
qed
```

**Exercise 20.** *Prove that $a \cdot 1 \equiv a \pmod n$ — the multiplicative
identity in $\mathbb Z_n$.* $a \cdot 1$ is literally $a$ in $\mathbb Z$
(`mulOneRight`), so it is congruent to $a$.

```bpa
theorem multiplicativeIdentityModN:
  forall n, a: Int; does_divide(n, sub(mul(a, ONE), a))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @a-times-one |
            mul(a, ONE) = a
            [using specialize mulOneRight(a)]
          @conclusion-identity-congruent |
            does_divide(n, sub(mul(a, ONE), a))
            [using specialize congruentWhenEqual(n, mul(a, ONE), a) a-times-one]
        }
      @discharge-a |
        forall a: Int; does_divide(n, sub(mul(a, ONE), a))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall n, a: Int; does_divide(n, sub(mul(a, ONE), a))
    [by forall_intro generalize-n]
qed
```

**Exercise 21.** *Prove that for each $a$ there is a $b$ with $a + b \equiv b + a
\equiv 0 \pmod n$ — additive inverses in $\mathbb Z_n$.* Take $b = -a$; then
$a + (-a) = 0$ in $\mathbb Z$ (`addNegRight`), so $n \mid (a + (-a)) - 0$, and
$b + a = -a + a$ is $0$ too.

```bpa
theorem additiveInverseModN:
  forall n, a: Int;
  exists b: Int;
  does_divide(n, sub(add(a, b), ZERO)) and does_divide(n, sub(add(b, a), ZERO))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @a-plus-neg-a |
            add(a, neg(a)) = ZERO
            [using specialize addNegRight(a)]
          @neg-a-plus-a |
            add(neg(a), a) = ZERO
            [using arithmetic a-plus-neg-a]
          @sum-with-inverse-congruent |
            does_divide(n, sub(add(a, neg(a)), ZERO))
            [using specialize congruentWhenEqual(n, add(a, neg(a)), ZERO) a-plus-neg-a]
          @inverse-sum-congruent |
            does_divide(n, sub(add(neg(a), a), ZERO))
            [using specialize congruentWhenEqual(n, add(neg(a), a), ZERO) neg-a-plus-a]
          @both-sums-congruent |
            does_divide(n, sub(add(a, neg(a)), ZERO)) and does_divide(n, sub(add(neg(a), a), ZERO))
            [by and_intro sum-with-inverse-congruent inverse-sum-congruent]
          @inverse-exists |
            exists b: Int; does_divide(n, sub(add(a, b), ZERO)) and does_divide(n, sub(add(b, a), ZERO))
            [by exists_intro(neg(a)) both-sums-congruent]
        }
      @discharge-a |
        forall a: Int; exists b: Int; does_divide(n, sub(add(a, b), ZERO)) and does_divide(n, sub(add(b, a), ZERO))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall n, a: Int; exists b: Int; does_divide(n, sub(add(a, b), ZERO)) and does_divide(n, sub(add(b, a), ZERO))
    [by forall_intro generalize-n]
qed
```

**Exercise 22.** *Prove that addition and multiplication mod $n$ are well
defined: if $a \equiv a' \pmod n$ and $b \equiv b' \pmod n$, then $a + b \equiv
a' + b' \pmod n$ and $ab \equiv a'b' \pmod n$.*

For addition, $(a + b) - (a' + b') = (a - a') + (b - b')$, and $n$ divides a sum
of two things it divides (`dividesAdd`). For multiplication, $ab - a'b' =
a(b - b') + b'(a - a')$ (`productDifferenceSplits`): $n \mid (b - b')$ gives
$n \mid a(b - b')$ and $n \mid (a - a')$ gives $n \mid b'(a - a')$ (`dividesMul`,
up to commuting the factor), and `dividesAdd` closes it.

```bpa
theorem additionWellDefinedModN:
  forall n, a, ap, b, bp: Int;
  does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) ->
  does_divide(n, sub(add(a, b), add(ap, bp)))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @generalize-ap |
            fix ap: Int {
              @generalize-b |
                fix b: Int {
                  @generalize-bp |
                    fix bp: Int {
                      @given-a-congruent |
                        assume does_divide(n, sub(a, ap)) {
                          @given-b-congruent |
                            assume does_divide(n, sub(b, bp)) {
                              @n-divides-a-difference |
                                does_divide(n, sub(a, ap))
                                [by hypothesis given-a-congruent]
                              @n-divides-b-difference |
                                does_divide(n, sub(b, bp))
                                [by hypothesis given-b-congruent]
                              @n-divides-sum-of-differences |
                                does_divide(n, add(sub(a, ap), sub(b, bp)))
                                [using specialize dividesAdd(n, sub(a, ap), sub(b, bp)) n-divides-a-difference n-divides-b-difference]
                              // (a − a') + (b − b') = (a + b) − (a' + b').
                              @sum-of-differences-regroups |
                                add(sub(a, ap), sub(b, bp)) = sub(add(a, b), add(ap, bp))
                                [using arithmetic]
                              @n-divides-sum-difference |
                                does_divide(n, sub(add(a, b), add(ap, bp)))
                                [by rewrite sum-of-differences-regroups n-divides-sum-of-differences]
                            }
                          @conclusion-b-implies |
                            does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
                            [by implies_intro given-b-congruent]
                        }
                      @conclusion-a-implies |
                        does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
                        [by implies_intro given-a-congruent]
                    }
                  @discharge-bp |
                    forall bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
                    [by forall_intro generalize-bp]
                }
              @discharge-b |
                forall b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
                [by forall_intro generalize-b]
            }
          @discharge-ap |
            forall ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
            [by forall_intro generalize-ap]
        }
      @discharge-a |
        forall a, ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall n, a, ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(add(a, b), add(ap, bp)))
    [by forall_intro generalize-n]
qed
```

```bpa
theorem multiplicationWellDefinedModN:
  forall n, a, ap, b, bp: Int;
  does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) ->
  does_divide(n, sub(mul(a, b), mul(ap, bp)))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @generalize-ap |
            fix ap: Int {
              @generalize-b |
                fix b: Int {
                  @generalize-bp |
                    fix bp: Int {
                      @given-a-congruent |
                        assume does_divide(n, sub(a, ap)) {
                          @given-b-congruent |
                            assume does_divide(n, sub(b, bp)) {
                              @n-divides-a-difference |
                                does_divide(n, sub(a, ap))
                                [by hypothesis given-a-congruent]
                              @n-divides-b-difference |
                                does_divide(n, sub(b, bp))
                                [by hypothesis given-b-congruent]
                              // n | (b − b') ⟹ n | (b − b')·a, commuted to a·(b − b').
                              @n-divides-b-difference-times-a |
                                does_divide(n, mul(sub(b, bp), a))
                                [using specialize dividesMul(n, sub(b, bp), a) n-divides-b-difference]
                              @first-term-commutes |
                                mul(sub(b, bp), a) = mul(a, sub(b, bp))
                                [using specialize mulIsCommutative(sub(b, bp), a)]
                              @n-divides-a-times-b-difference |
                                does_divide(n, mul(a, sub(b, bp)))
                                [by rewrite first-term-commutes n-divides-b-difference-times-a]
                              // n | (a − a') ⟹ n | (a − a')·b', commuted to b'·(a − a').
                              @n-divides-a-difference-times-bp |
                                does_divide(n, mul(sub(a, ap), bp))
                                [using specialize dividesMul(n, sub(a, ap), bp) n-divides-a-difference]
                              @second-term-commutes |
                                mul(sub(a, ap), bp) = mul(bp, sub(a, ap))
                                [using specialize mulIsCommutative(sub(a, ap), bp)]
                              @n-divides-bp-times-a-difference |
                                does_divide(n, mul(bp, sub(a, ap)))
                                [by rewrite second-term-commutes n-divides-a-difference-times-bp]
                              @n-divides-split-sum |
                                does_divide(n, add(mul(a, sub(b, bp)), mul(bp, sub(a, ap))))
                                [using specialize dividesAdd(n, mul(a, sub(b, bp)), mul(bp, sub(a, ap))) n-divides-a-times-b-difference n-divides-bp-times-a-difference]
                              // ab − a'b' = a(b − b') + b'(a − a').
                              @product-difference-splits |
                                sub(mul(a, b), mul(ap, bp)) = add(mul(a, sub(b, bp)), mul(bp, sub(a, ap)))
                                [using specialize productDifferenceSplits(a, b, ap, bp)]
                              @n-divides-product-difference |
                                does_divide(n, sub(mul(a, b), mul(ap, bp)))
                                [by rewrite product-difference-splits n-divides-split-sum]
                            }
                          @conclusion-b-implies |
                            does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
                            [by implies_intro given-b-congruent]
                        }
                      @conclusion-a-implies |
                        does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
                        [by implies_intro given-a-congruent]
                    }
                  @discharge-bp |
                    forall bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
                    [by forall_intro generalize-bp]
                }
              @discharge-b |
                forall b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
                [by forall_intro generalize-b]
            }
          @discharge-ap |
            forall ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
            [by forall_intro generalize-ap]
        }
      @discharge-a |
        forall a, ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall n, a, ap, b, bp: Int; does_divide(n, sub(a, ap)) -> does_divide(n, sub(b, bp)) -> does_divide(n, sub(mul(a, b), mul(ap, bp)))
    [by forall_intro generalize-n]
qed
```

**Exercise 23.** *Prove that addition and multiplication mod $n$ are
associative.* The two sides of each associativity are equal integers in
$\mathbb Z$ (`addIsAssociative`, `mulIsAssociative`), so `congruentWhenEqual`
applies to each.

```bpa
theorem additionAssociativeModN:
```

**Exercise 24.** *Prove that multiplication distributes over addition mod $n$:
$a(b + c) \equiv ab + ac \pmod n$.* The two sides are equal integers by the
distributive law of $\mathbb Z$ (`mulAddDistribLeft`), so `congruentWhenEqual`
applies.

```bpa
theorem multiplicationDistributesModN:
  forall n, a, b, c: Int;
  does_divide(n, sub(mul(a, add(b, c)), add(mul(a, b), mul(a, c))))
proof
  @generalize-n |
    fix n: Int {
      @generalize-a |
        fix a: Int {
          @generalize-b |
            fix b: Int {
              @generalize-c |
                fix c: Int {
                  @product-distributes |
                    mul(a, add(b, c)) = add(mul(a, b), mul(a, c))
                    [using specialize mulAddDistribLeft(a, b, c)]
                  @conclusion-distributivity-congruent |
                    does_divide(n, sub(mul(a, add(b, c)), add(mul(a, b), mul(a, c))))
                    [using specialize congruentWhenEqual(n, mul(a, add(b, c)), add(mul(a, b), mul(a, c))) product-distributes]
                }

                forall c: Int; does_divide(n, sub(mul(a, add(b, c)), add(mul(a, b), mul(a, c))))
```
