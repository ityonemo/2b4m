Groups"** (source: `vendor/aata/src/groups.xml`; © 1997–2026 Judson, GFDL 1.3),
following `.claude/rules/aata-guide.md`. Unlike the main text, the exercises use

**Exercise 7.** Let $S = \mathbb{R} \setminus \{-1\}$ with $a * b = a + b + ab$;
prove $(S, *)$ is a group.

**Proved.** The operation is multiplication in disguise: $(1 + a)(1 + b) = 1 + a * b$.
So $*$ is associative and $0$ is its identity because $\cdot$ is associative with
identity $1$; $-1$ is excluded because it is the image of $0$ (the product of two
nonzero shifts $1 + a$, $1 + b$ is nonzero, so $S$ is closed); and the inverse of $a$
is $-a/(1 + a)$, whose shift $1 + a$ is nonzero exactly because $a \ne -1$. This is
`std/real/affine-group.b4m`: the set is the predicated cut `NotMinusOne`, the three
group laws are proved on $\mathbb{R}$ and relativized to the cut, and the guarded
model `AffineGroup` makes $(S, *)$ an instance of `std/group.b4m`. We cite the three
laws over the cut.

```2b4m
import real_affine <<< "std/real/affine-group.b4m"

sort NotMinusOne = real_affine.NotMinusOne
const RZERO = real_affine.ZERO
func star = real_affine.star
func starInverse = real_affine.starInverse

theorem affineStarIsAssociative: forall a, b, c: NotMinusOne; star(star(a, b), c) = star(a, star(b, c))
proof
  @conclusion |
    forall a, b, c: NotMinusOne; star(star(a, b), c) = star(a, star(b, c))
    [using import(real_affine) starAssociativeOnCut]
qed

theorem affineStarHasIdentityZero: forall a: NotMinusOne; star(RZERO, a) = a
proof
  @conclusion |
    forall a: NotMinusOne; star(RZERO, a) = a
    [using import(real_affine) starZeroLeftOnCut]
qed

theorem affineStarHasInverses: forall a: NotMinusOne; star(starInverse(a), a) = RZERO
proof
  @conclusion |
    forall a: NotMinusOne; star(starInverse(a), a) = RZERO
    [using import(real_affine) starInverseLeftOnCut]
qed
```

**Exercise 12.** Prove that $\mathbb{Z}_n$ is a group under addition modulo $n$.

**Proved.** $\mathbb{Z}_n$ is the quotient sort of `std/integer/mod-n.b4m` (a class
map $\mathrm{cls} : \mathbb{Z} \to \mathbb{Z}_n$ with $\mathrm{cls}(a) =

is a homomorphism. The three group laws then lift from $\mathbb{Z}$'s — every class
has a representative, and the law holds on representatives — which is how that file
proves them; its model `ZnGroup` then makes $\mathbb{Z}_n$ an instance of
`std/group.b4m`. We cite the three laws.

**Exercise 13.** Prove that $\mathbb{R}^\ast$, the nonzero reals, is a group
under multiplication.

**Proved.** $\mathbb{R}^\ast$ is the predicated cut `RStar = Real where nonzero` of
`std/real/units.b4m`: $1 \ne 0$, a product of nonzeros is nonzero (no zero divisors in
a field), and the reciprocal of a nonzero is nonzero, so the cut is closed; the field
laws restricted to it are the group laws, and the guarded model `RealUnitsGroup`
makes $\mathbb{R}^\ast$ an instance of `std/group.b4m`. We cite the three laws over
the cut.

```2b4m
import real <<< "std/real.b4m"
import real_units <<< "std/real/units.b4m"

sort RStar = real_units.RStar
const RONE = real.ONE
func rmul = real.mul
func recip = real.recip

theorem nonzeroRealsAssociative: forall x, y, z: RStar; rmul(rmul(x, y), z) = rmul(x, rmul(y, z))
proof
  @conclusion |
    forall x, y, z: RStar; rmul(rmul(x, y), z) = rmul(x, rmul(y, z))
    [using import(real_units) unitsAssoc]
qed

theorem nonzeroRealsHaveIdentity: forall x: RStar; rmul(RONE, x) = x
proof
  @conclusion |
    forall x: RStar; rmul(RONE, x) = x
    [using import(real_units) unitsIdentityLeft]
qed

theorem nonzeroRealsHaveInverses: forall x: RStar; rmul(recip(x), x) = RONE
proof
  @conclusion |
    forall x: RStar; rmul(recip(x), x) = RONE
    [using import(real_units) unitsInverseLeft]

```

**Exercise 15.** Prove or disprove that every group with six elements is
abelian.

**Disproved.** $D_3$, the symmetry group of the triangle, has six elements and is
nonabelian. `std/permutation/dihedral.b4m` builds $D_n$ concretely for $n \ge 3$: a
rotation $\rho$ (the $n$-cycle on the letters $0, \ldots, n-1$), a reflection $\sigma$
(fixing $0$, sending $i \mapsto n - i$), and a sequence listing the $2n$ rigid motions
of the $n$-gon without repetition and exhaustively
(`dihedralGroupHasTwiceNElements`). At $n = 3$ that is six elements, and the §5.2
exercises prove $D_n$ nonabelian for $n \ge 3$ ($\rho\sigma$ sends $0$ to $1$ while
$\sigma\rho$ sends it to $n - 1$). We import that literate chapter and instantiate
both at $3$.

```2b4m
import function <<< "std/function.b4m"
import peano <<< "std/peano.b4m"
import peano_order <<< "std/peano/order.b4m"
import permutation_dihedral <<< "std/permutation/dihedral.b4m"
import dihedral_exercises <<< "5.2-dihedral-groups-exercises.md"

sort Fn = function.Fn
func compose = function.compose
const NZERO = peano.ZERO
func nat_succ = peano.succ
func nadd = peano.add
pred nat_less_than = peano.less_than
sort MotionSeq = permutation_dihedral.Seq
func motionAt = permutation_dihedral.at
define isTheRotation(rho, n) = permutation_dihedral.isTheRotation(rho, n)
define isTheReflection(sigma, n) = permutation_dihedral.isTheReflection(sigma, n)
define isARigidMotion(t, rho, n) = permutation_dihedral.isARigidMotion(t, rho, n)
define THREE = nat_succ(nat_succ(nat_succ(NZERO)))
define listsTheMotions(w, rho, n) = (forall i: Nat; nat_less_than(i, nadd(n, n)) -> isARigidMotion(motionAt(w, i), rho, n)) and (forall i: Nat; forall j: Nat; nat_less_than(i, nadd(n, n)) -> nat_less_than(j, nadd(n, n)) -> motionAt(w, i) = motionAt(w, j) -> i = j) and (forall t: Fn; isARigidMotion(t, rho, n) -> exists i: Nat; nat_less_than(i, nadd(n, n)) and motionAt(w, i) = t)

theorem aGroupOfOrderSixNeedNotBeAbelian: exists rho: Fn; exists sigma: Fn; isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE)) and compose(rho, sigma) != compose(sigma, rho)
proof
  @two-below-three |
    nat_less_than(nat_succ(nat_succ(NZERO)), THREE)
    [using specialize peano_order.lessThanSelf(nat_succ(nat_succ(NZERO)))]
  @triangle-group-exists |
    exists rho: Fn; exists sigma: Fn; isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE))
    [using specialize permutation_dihedral.dihedralGroupHasTwiceNElements(THREE) two-below-three]
  @triangle-group-is-nonabelian |
    forall rho: Fn; forall sigma: Fn; isTheRotation(rho, THREE) -> isTheReflection(sigma, THREE) -> compose(rho, sigma) != compose(sigma, rho)
    [using specialize dihedral_exercises.dihedralGroupIsNonabelian(THREE) two-below-three]
  @with-rotation-rho |
    unpack rho: Fn from triangle-group-exists {
      @sigma-exists |
        exists sigma: Fn; isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE))
        [by hypothesis with-rotation-rho]
      @with-reflection-sigma |
        unpack sigma: Fn from sigma-exists {
          @triangle-group |
            isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE))
            [by hypothesis with-reflection-sigma]
          @rotation |
            isTheRotation(rho, THREE)
            [using tautology triangle-group]
          @reflection |
            isTheReflection(sigma, THREE)
            [using tautology triangle-group]
          @rho-sigma-differs-from-sigma-rho |
            compose(rho, sigma) != compose(sigma, rho)
            [using specialize triangle-group-is-nonabelian(rho, sigma) rotation reflection]
          @six-elements-and-nonabelian |
            isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE)) and compose(rho, sigma) != compose(sigma, rho)
            [using tautology triangle-group rho-sigma-differs-from-sigma-rho]
          @some-sigma |
            exists sigma2: Fn; isTheRotation(rho, THREE) and isTheReflection(sigma2, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE)) and compose(rho, sigma2) != compose(sigma2, rho)
            [by exists_intro(sigma) six-elements-and-nonabelian]
          @conclusion-some-rho-inner |
            exists rho2: Fn; exists sigma2: Fn; isTheRotation(rho2, THREE) and isTheReflection(sigma2, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho2, THREE)) and compose(rho2, sigma2) != compose(sigma2, rho2)
            [by exists_intro(rho) some-sigma]
        }
      @conclusion-some-rho |
        exists rho2: Fn; exists sigma2: Fn; isTheRotation(rho2, THREE) and isTheReflection(sigma2, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho2, THREE)) and compose(rho2, sigma2) != compose(sigma2, rho2)
        [by exists_elim with-reflection-sigma]
    }
  @conclusion |
    exists rho: Fn; exists sigma: Fn; isTheRotation(rho, THREE) and isTheReflection(sigma, THREE) and (exists w: MotionSeq; listsTheMotions(w, rho, THREE)) and compose(rho, sigma) != compose(sigma, rho)
    [by exists_elim with-rotation-rho]
qed
```

**Exercise 25.** Let $a$ and $b$ be elements in a group $G$. Prove that $a b^n
a^{-1} = (a b a^{-1})^n$ for $n \in \mathbb{Z}$.

Judson's hint expands $(aba^{-1})^n = (aba^{-1})(aba^{-1})\cdots(aba^{-1})$ and
telescopes the interior $a^{-1}a = e$ pairs, leaving $ab^na^{-1}$. Formally we
prove it by **bidirectional induction on the integer exponent $n$**, with the
conjugate $c = aba^{-1}$. The load-bearing step is the *conjugation lemma*
$c^{k+1} = (ab^ka^{-1})(aba^{-1}) = ab^{k+1}a^{-1}$ — where the adjacent
$a^{-1}a$ cancels — proved once and used in both the successor and predecessor
directions.

```2b4m
// Conjugation lemma: (a·y·a⁻¹)·(a·z·a⁻¹) = a·(y·z)·a⁻¹ — the interior a⁻¹a
// telescopes. Used to fuse two conjugates in each induction step of Exercise 25.
theorem conjugateProduct: forall a, y, z: G;
  op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
proof
  @generalize-a |
    fix a: G {
      @generalize-y |
        fix y: G {
          @generalize-z |
            fix z: G {
              // regroup the two conjugates so the interior a⁻¹·a is adjacent:
              // (a·y·a⁻¹)·(a·z·a⁻¹) = (a·y)·((a⁻¹·a)·(z·a⁻¹)).
              @expose-interior-inverse |
                op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, y), op(op(inv(a), a), op(z, inv(a))))
                [using assoc(associative)]
              // a⁻¹·a = e.
              @interior-inverse-cancels |
                op(inv(a), a) = e
                [using specialize inverseLeft(a)]
              // the interior cancellation leaves (a·y)·(e·(z·a⁻¹)).
              @after-interior-cancels |
                op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, y), op(e, op(z, inv(a))))
                [by rewrite interior-inverse-cancels expose-interior-inverse]
              // e·(z·a⁻¹) = z·a⁻¹, so we are at (a·y)·(z·a⁻¹).
              @identity-drops-out |
                op(e, op(z, inv(a))) = op(z, inv(a))
                [using specialize identityLeft(op(z, inv(a)))]
              @after-identity-drops |
                op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, y), op(z, inv(a)))
                [by rewrite identity-drops-out after-interior-cancels]
              // reassociate (a·y)·(z·a⁻¹) = (a·(y·z))·a⁻¹.
              @reassociate-remaining |
                op(op(a, y), op(z, inv(a))) = op(op(a, op(y, z)), inv(a))
                [using assoc(associative)]
              @conclusion-conjugate-product |
                op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
                [using chain after-identity-drops reassociate-remaining]
            }
          @discharge-z |
            forall z: G; op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
            [by forall_intro generalize-z]
        }
      @discharge-y |
        forall y, z: G; op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
        [by forall_intro generalize-y]
    }
  @conclusion |
    forall a, y, z: G; op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
    [by forall_intro generalize-a]
qed

// Exercise 25 proper: a·bⁿ·a⁻¹ = (a·b·a⁻¹)ⁿ, by bidirectional induction on n.
theorem conjugatePower: forall a, b: G; forall n: Int;
  op(op(a, power(b, n)), inv(a)) = power(op(op(a, b), inv(a)), n)
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          // base case n = 0: a·b⁰·a⁻¹ = a·e·a⁻¹ = a·a⁻¹ = e = (aba⁻¹)⁰.
          @power-of-b-at-zero |
            power(b, ZERO) = e
            [using specialize powerZero(b)]
          @a-times-identity |
            op(a, e) = a
            [using specialize identityRight(a)]
          @a-cancels-its-inverse |
            op(a, inv(a)) = e
            [using specialize inverseRight(a)]
          @conjugate-power-at-zero |
            power(op(op(a, b), inv(a)), ZERO) = e
            [using specialize powerZero(op(op(a, b), inv(a)))]
          @conjugate-power-at-zero-flipped |
            e = power(op(op(a, b), inv(a)), ZERO)
            [by symmetry conjugate-power-at-zero]
          // a·(b⁰)·a⁻¹ = a·e·a⁻¹ = a·a⁻¹ = e; but first re-fold a·e·a⁻¹ = a·a⁻¹.
          @conjugate-of-identity-collapses |
            op(op(a, power(b, ZERO)), inv(a)) = e
            [using chain power-of-b-at-zero a-times-identity a-cancels-its-inverse]
          @base-case |
            op(op(a, power(b, ZERO)), inv(a)) = power(op(op(a, b), inv(a)), ZERO)
            [using chain conjugate-of-identity-collapses conjugate-power-at-zero-flipped]

          // the conjugation fusion lemma, specialized to this a:
          @conjugates-fuse |
            forall y, z: G; op(op(op(a, y), inv(a)), op(op(a, z), inv(a))) = op(op(a, op(y, z)), inv(a))
            [using specialize conjugateProduct(a)]

          // -- successor step: n = k → n = succ(k) ---------------------------
          @successor-step |
            fix k: Int {
              @given-inductive-hypothesis |
                assume op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) {
                  @inductive-hypothesis |
                    op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k)
                    [by hypothesis given-inductive-hypothesis]
                  // (aba⁻¹)^(succ k) = op((aba⁻¹)^k, aba⁻¹) = op(a·bᵏ·a⁻¹, a·b·a⁻¹) [IH].
                  @conjugate-power-unfolds |
                    power(op(op(a, b), inv(a)), succ(k)) = op(power(op(op(a, b), inv(a)), k), op(op(a, b), inv(a)))
                    [using specialize powerSucc(op(op(a, b), inv(a)), k)]
                  @fold-inductive-hypothesis |
                    op(power(op(op(a, b), inv(a)), k), op(op(a, b), inv(a))) = op(op(op(a, power(b, k)), inv(a)), op(op(a, b), inv(a)))
                    [by rewrite inductive-hypothesis conjugate-power-refl-succ]
                  @conjugate-power-refl-succ |
                    op(power(op(op(a, b), inv(a)), k), op(op(a, b), inv(a))) = op(power(op(op(a, b), inv(a)), k), op(op(a, b), inv(a)))
                    [by reflexivity]
                  // fuse the two conjugates: op(a·bᵏ·a⁻¹, a·b·a⁻¹) = a·(bᵏ·b)·a⁻¹.
                  @conjugates-fuse-at-bk-b |
                    op(op(op(a, power(b, k)), inv(a)), op(op(a, b), inv(a))) = op(op(a, op(power(b, k), b)), inv(a))
                    [by forall_elim(power(b, k), b) conjugates-fuse]
                  // bᵏ·b = b^(succ k).
                  @b-power-succ |
                    power(b, succ(k)) = op(power(b, k), b)
                    [using specialize powerSucc(b, k)]
                  @fused-conjugate-is-succ |
                    op(op(a, op(power(b, k), b)), inv(a)) = op(op(a, power(b, succ(k))), inv(a))
                    [by rewrite b-power-succ fused-conjugate-refl]
                  @fused-conjugate-refl |
                    op(op(a, op(power(b, k), b)), inv(a)) = op(op(a, op(power(b, k), b)), inv(a))
                    [by reflexivity]
                  // chain: (aba⁻¹)^(succ k) = … = a·b^(succ k)·a⁻¹.
                  @conjugate-power-succ-flipped |
                    power(op(op(a, b), inv(a)), succ(k)) = op(op(a, power(b, succ(k))), inv(a))
                    [using chain conjugate-power-unfolds fold-inductive-hypothesis conjugates-fuse-at-bk-b fused-conjugate-is-succ]
                  @conclusion-successor |
                    op(op(a, power(b, succ(k))), inv(a)) = power(op(op(a, b), inv(a)), succ(k))
                    [by symmetry conjugate-power-succ-flipped]
                }
              @inductive-hypothesis-implies-successor |
                op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) -> op(op(a, power(b, succ(k))), inv(a)) = power(op(op(a, b), inv(a)), succ(k))
                [by implies_intro given-inductive-hypothesis]
            }
          @successor-step-all-k |
            forall k: Int; op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) -> op(op(a, power(b, succ(k))), inv(a)) = power(op(op(a, b), inv(a)), succ(k))
            [by forall_intro successor-step]

          // -- predecessor step: n = k → n = prev(k) -------------------------
          @predecessor-step |
            fix k: Int {
              @given-inductive-hypothesis |
                assume op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) {
                  @inductive-hypothesis |
                    op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k)
                    [by hypothesis given-inductive-hypothesis]
                  // (aba⁻¹)^(prev k) = op((aba⁻¹)^k, (aba⁻¹)⁻¹). We instead go via
                  // the conjugate of b⁻¹: a·b⁻¹·a⁻¹ IS the inverse of a·b·a⁻¹.
                  // op((aba⁻¹)^k, a·b⁻¹·a⁻¹) = op(a·bᵏ·a⁻¹, a·b⁻¹·a⁻¹) [IH]
                  //   = a·(bᵏ·b⁻¹)·a⁻¹ = a·b^(prev k)·a⁻¹.
                  @inverse-of-conjugate-base |
                    inv(op(op(a, b), inv(a))) = op(op(a, inv(b)), inv(a))
                    [using chain inverse-of-conjugate double-inverse-of-a]
                  @inverse-of-conjugate |
                    inv(op(op(a, b), inv(a))) = op(inv(inv(a)), op(inv(b), inv(a)))
                    [using chain inv-outer inv-inner]
                  @inv-outer |
                    inv(op(op(a, b), inv(a))) = op(inv(inv(a)), inv(op(a, b)))
                    [using specialize invProduct(op(a, b), inv(a))]
                  @inv-inner |
                    inv(op(a, b)) = op(inv(b), inv(a))
                    [using specialize invProduct(a, b)]
                  @double-inverse-of-a |
                    op(inv(inv(a)), op(inv(b), inv(a))) = op(op(a, inv(b)), inv(a))
                    [using chain invinv-a reassoc-conjugate]
                  @invinv-a |
                    inv(inv(a)) = a
                    [using specialize invInvolution(a)]
                  @reassoc-conjugate |
                    op(a, op(inv(b), inv(a))) = op(op(a, inv(b)), inv(a))
                    [by symmetry conjugate-assoc]
                  @conjugate-assoc |
                    op(op(a, inv(b)), inv(a)) = op(a, op(inv(b), inv(a)))
                    [using specialize associative(a, inv(b), inv(a))]
                  // (aba⁻¹)^(prev k) = op((aba⁻¹)^k, (aba⁻¹)⁻¹).
                  @conjugate-power-unfolds |
                    power(op(op(a, b), inv(a)), prev(k)) = op(power(op(op(a, b), inv(a)), k), inv(op(op(a, b), inv(a))))
                    [using specialize powerPrev(op(op(a, b), inv(a)), k)]
                  @rewrite-inverse-base |
                    power(op(op(a, b), inv(a)), prev(k)) = op(power(op(op(a, b), inv(a)), k), op(op(a, inv(b)), inv(a)))
                    [by rewrite inverse-of-conjugate-base conjugate-power-unfolds]
                  @fold-inductive-hypothesis |
                    op(power(op(op(a, b), inv(a)), k), op(op(a, inv(b)), inv(a))) = op(op(op(a, power(b, k)), inv(a)), op(op(a, inv(b)), inv(a)))
                    [by rewrite inductive-hypothesis fold-ih-prev-refl]
                  @fold-ih-prev-refl |
                    op(power(op(op(a, b), inv(a)), k), op(op(a, inv(b)), inv(a))) = op(power(op(op(a, b), inv(a)), k), op(op(a, inv(b)), inv(a)))
                    [by reflexivity]
                  // fuse: op(a·bᵏ·a⁻¹, a·b⁻¹·a⁻¹) = a·(bᵏ·b⁻¹)·a⁻¹.
                  @conjugates-fuse-at-bk-invb |
                    op(op(op(a, power(b, k)), inv(a)), op(op(a, inv(b)), inv(a))) = op(op(a, op(power(b, k), inv(b))), inv(a))
                    [by forall_elim(power(b, k), inv(b)) conjugates-fuse]
                  // bᵏ·b⁻¹ = b^(prev k).
                  @b-power-prev |
                    power(b, prev(k)) = op(power(b, k), inv(b))
                    [using specialize powerPrev(b, k)]
                  @fused-conjugate-is-prev |
                    op(op(a, op(power(b, k), inv(b))), inv(a)) = op(op(a, power(b, prev(k))), inv(a))
                    [by rewrite b-power-prev fused-conjugate-prev-refl]
                  @fused-conjugate-prev-refl |
                    op(op(a, op(power(b, k), inv(b))), inv(a)) = op(op(a, op(power(b, k), inv(b))), inv(a))
                    [by reflexivity]
                  @conjugate-power-prev-flipped |
                    power(op(op(a, b), inv(a)), prev(k)) = op(op(a, power(b, prev(k))), inv(a))
                    [using chain rewrite-inverse-base fold-inductive-hypothesis conjugates-fuse-at-bk-invb fused-conjugate-is-prev]
                  @conclusion-predecessor |
                    op(op(a, power(b, prev(k))), inv(a)) = power(op(op(a, b), inv(a)), prev(k))
                    [by symmetry conjugate-power-prev-flipped]
                }
              @inductive-hypothesis-implies-predecessor |
                op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) -> op(op(a, power(b, prev(k))), inv(a)) = power(op(op(a, b), inv(a)), prev(k))
                [by implies_intro given-inductive-hypothesis]
            }
          @predecessor-step-all-k |
            forall k: Int; op(op(a, power(b, k)), inv(a)) = power(op(op(a, b), inv(a)), k) -> op(op(a, power(b, prev(k))), inv(a)) = power(op(op(a, b), inv(a)), prev(k))
            [by forall_intro predecessor-step]

          @conjugate-power-over-all-n |
            forall n: Int; op(op(a, power(b, n)), inv(a)) = power(op(op(a, b), inv(a)), n)
            [using instantiation induction((fun n: Int => op(op(a, power(b, n)), inv(a)) = power(op(op(a, b), inv(a)), n))) base-case successor-step-all-k predecessor-step-all-k]
        }
      @discharge-b |
        forall b: G; forall n: Int; op(op(a, power(b, n)), inv(a)) = power(op(op(a, b), inv(a)), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: G; forall n: Int; op(op(a, power(b, n)), inv(a)) = power(op(op(a, b), inv(a)), n)
    [by forall_intro generalize-a]
qed
```

**Exercise 27.** Prove that the inverse of $g_1 g_2 \cdots g_n$ is $g_n^{-1}
g_{n-1}^{-1} \cdots g_1^{-1}$.

The finite product $g_0 g_1 \cdots g_{n-1}$ is the ℕ-indexed left fold
`productUpTo(s, n)` of a group-valued sequence `s`, and its inverse is the
reversed product of inverses `revProductUpTo(s, n)` = $g_{n-1}^{-1} \cdots
g_0^{-1}$. The law is an induction on $n$ whose step applies the binary
$(ab)^{-1} = b^{-1}a^{-1}$ (`invProduct`) once — this is proved in
`std/group/sequence.b4m` as `invOfProduct`, which we cite here.

```2b4m
theorem inverseOfFiniteProduct: forall s: Seq; forall n: Nat;
  inv(productUpTo(s, n)) = revProductUpTo(s, n)
proof
  @conclusion |
    forall s: Seq; forall n: Nat; inv(productUpTo(s, n)) = revProductUpTo(s, n)
    [by cite invOfProduct]
qed
```

**Exercise 31.** Show that if $a^2 = e$ for all elements $a$ in a group $G$,

**Exercise 32.** Show that if $G$ is a finite group of even order, then there is
an $a \in G$, $a \neq e$, with $a^2 = e$.

**Proved** — `std/group/listing.b4m`'s `evenOrderGivesAnInvolution`. "$G$ is finite
of order $n$" is a LISTING: a sequence $w$ whose first $n$ entries are pairwise
distinct and contain every element of $G$ (the same device as Chapter 5's counts).
Judson's pairing argument then runs on the listing: split it into the self-inverse

count is even, and since it contains $e$ it is at least $2$ — the second self-inverse
element is the $a \neq e$ with $a^2 = e$.

**Exercise 33.** Let $G$ be a group with $(ab)^2 = a^2 b^2$ for all $a, b \in
G$. Prove that $G$ is abelian.

**Solution.** From $(ab)(ab) = (aa)(bb)$, re-associate both sides to
$a\,(bab)$ and $a\,(abb)$; left-cancel $a$ to get $(ba)b = (ab)b$; right-cancel
$b$ to get $ba = ab$, i.e. $ab = ba$.

```2b4m
theorem squareOfProductAbelian:
  (forall a, b: G; op(op(a, b), op(a, b)) = op(op(a, a), op(b, b))) -> forall a, b: G; op(a, b) = op(b, a)
proof
  @given-square-of-product-splits |
    assume forall a, b: G; op(op(a, b), op(a, b)) = op(op(a, a), op(b, b)) {
      @square-of-product-splits |
        forall a, b: G; op(op(a, b), op(a, b)) = op(op(a, a), op(b, b))
        [by hypothesis given-square-of-product-splits]
      @cancel-left-law |
        forall a, b, c: G; op(a, b) = op(a, c) -> b = c
        [by cite cancelLeft]
      @cancel-right-law |
        forall b, a, c: G; op(b, a) = op(c, a) -> b = c
        [by cite cancelRight]
      @generalize-a |
        fix a: G {
          @generalize-b |
            fix b: G {
              @square-hypothesis-at-a-b |
                op(op(a, b), op(a, b)) = op(op(a, a), op(b, b))
                [by forall_elim(a, b) square-of-product-splits]
              // regroup abab = a·((ba)·b) and aabb = a·((ab)·b).
              @regroup-left-square |
                op(op(a, b), op(a, b)) = op(a, op(op(b, a), b))
                [using assoc(associative)]
              @regroup-right-square |
                op(op(a, a), op(b, b)) = op(a, op(op(a, b), b))
                [using assoc(associative)]
              // so a·((ba)·b) = a·((ab)·b).
              @left-factored-equation |
                op(a, op(op(b, a), b)) = op(a, op(op(a, b), b))
                [using chain regroup-left-square square-hypothesis-at-a-b regroup-right-square]
              // left-cancel a: (ba)·b = (ab)·b.
              @left-cancellation-at-a |
                op(a, op(op(b, a), b)) = op(a, op(op(a, b), b)) -> op(op(b, a), b) = op(op(a, b), b)
                [by forall_elim(a, op(op(b, a), b), op(op(a, b), b)) cancel-left-law]
              @right-products-equal |
                op(op(b, a), b) = op(op(a, b), b)
                [by modus_ponens left-cancellation-at-a left-factored-equation]
              // right-cancel b: ba = ab.
              @right-cancellation-at-b |
                op(op(b, a), b) = op(op(a, b), b) -> op(b, a) = op(a, b)
                [by forall_elim(op(b, a), b, op(a, b)) cancel-right-law]
              @b-a-equals-a-b |
                op(b, a) = op(a, b)
                [by modus_ponens right-cancellation-at-b right-products-equal]
              @a-b-equals-b-a |
                op(a, b) = op(b, a)
                [by symmetry b-a-equals-a-b]
            }
          @discharge-b |
            forall b: G; op(a, b) = op(b, a)
            [by forall_intro generalize-b]
        }
      @commutes-for-all-a |
        forall a, b: G; op(a, b) = op(b, a)
        [by forall_intro generalize-a]
    }
  @conclusion |
    (forall a, b: G; op(op(a, b), op(a, b)) = op(op(a, a), op(b, b))) -> forall a, b: G; op(a, b) = op(b, a)
    [by implies_intro given-square-of-product-splits]
qed
```
