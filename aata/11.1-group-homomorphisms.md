# Group Homomorphisms

A literate `2b4m` transliteration of **Chapter 11 ("Homomorphisms"), §11.1 "Group
Homomorphisms"** of Thomas W. Judson's *Abstract Algebra: Theory and Applications*
(source: `vendor/aata/src/homomorph.xml`, lines 26–284; © 1997–2026 Judson, GFDL 1.3).
Run `2b4m check aata/11.1-group-homomorphisms.md` to verify.

## The definition

**Definition.** A **homomorphism** of groups between groups $(G, \cdot)$ and
$(H, \circ)$ is a map $\phi : G \rightarrow H$ such that
$$\phi( g_1 \cdot g_2 ) = \phi( g_1 ) \circ \phi( g_2 )$$
for $g_1, g_2 \in G$. The range of $\phi$ in $H$ is called the **homomorphic image**
of $\phi$.

Judson motivates the weaker notion directly: "Two groups are related in the strongest
possible way if they are isomorphic; however, a weaker relationship may exist between
two groups." His example is $S_n$ and $\mathbb{Z}_2$, related by the fact that $S_n$
divides into even and odd permutations exhibiting a $\mathbb{Z}_2$ group structure.

That weakening is exactly one axiom's worth. `std/group/isomorphism.b4m` declares the
same two groups and the same $\phi$, then adds an inverse map $\psi$ with two
round-trip axioms — and *every* structural claim there is proved from those. Drop them
and nothing is left but operation-preservation, which is what makes this the more
widely usable notion.

Two declarations are forced, and both are recorded at the file's head rather than
discovered twice. **Two groups must be declared, not aliased**: namespaces are
identity-by-origin, so `import group` twice names one theory and
`sort G = groupA.Grp` / `sort H = groupB.Grp` would yield the *same* sort. And **$\phi$
is a primitive function, not an `Fn`** — `std/function.b4m`'s `apply(f, x)` is a map on
one sort, and a homomorphism's source and target differ by construction.

```2b4m
import homomorphism <<< "std/group/homomorphism.b4m"

sort G = homomorphism.G
sort H = homomorphism.H
func phi = homomorphism.phi
func opG = homomorphism.opG
func opH = homomorphism.opH
func invG = homomorphism.invG
func invH = homomorphism.invH
const EG = homomorphism.EG
const EH = homomorphism.EH

// the definition, and the file's only axiom about phi
fact phiPreservesOp = homomorphism.phiPreservesOp
```

## What a homomorphism preserves

**Proposition 11.4.** Let $\phi : G_1 \rightarrow G_2$ be a homomorphism of groups.
Then

1. If $e$ is the identity of $G_1$, then $\phi(e)$ is the identity of $G_2$;
2. For any element $g \in G_1$, $\phi(g^{-1}) = [\phi(g)]^{-1}$;
3. If $H_1$ is a subgroup of $G_1$, then $\phi(H_1)$ is a subgroup of $G_2$;
4. If $H_2$ is a subgroup of $G_2$, then $\phi^{-1}(H_2) = \{g \in G_1 : \phi(g) \in H_2\}$
   is a subgroup of $G_1$. Furthermore, if $H_2$ is normal in $G_2$, then
   $\phi^{-1}(H_2)$ is normal in $G_1$.

*Proof (Judson).* (1) Suppose that $e$ and $e'$ are the identities of $G_1$ and $G_2$;
then $e'\phi(e) = \phi(e) = \phi(ee) = \phi(e)\phi(e)$. By cancellation,
$\phi(e) = e'$. (2) This follows from
$\phi(g^{-1})\phi(g) = \phi(g^{-1}g) = \phi(e) = e'$. (3) The set $\phi(H_1)$ is
nonempty since the identity of $G_2$ is in it; and
$xy^{-1} = \phi(a)[\phi(b)]^{-1} = \phi(ab^{-1}) \in \phi(H_1)$. (4) The identity is in
$H_1$ since $\phi(e) = e'$; if $a, b \in H_1$ then
$\phi(ab^{-1}) = \phi(a)[\phi(b)]^{-1}$ is in $H_2$. $\blacksquare$

Parts (1) and (2) transliterate directly. Both run on cancellation in $G_2$, which the
file gets from a `model` of `std/group.b4m` at $H$'s symbols rather than re-proving —
and since a model-transferred fact has no bare local name, each law used is given one
by a one-line shim.

```2b4m
theorem phiPreservesIdentity: phi(EG) = EH
proof
  @conclusion |
    phi(EG) = EH
    [using import(homomorphism) phiPreservesIdentity]
qed

theorem phiPreservesInverses: forall g: G; phi(invG(g)) = invH(phi(g))
proof
  @conclusion |
    forall g: G; phi(invG(g)) = invH(phi(g))
    [using import(homomorphism) phiPreservesInverses]
qed
```

Parts (3) and (4) need a subgroup to speak of, and a subgroup in this corpus is a
**membership predicate** — so $H_1$ is `inSource` on $G$ and $H_2$ is `inTarget` on
$H$, each with the three criteria. The image and preimage are then `define`s, and each
of Judson's "is a subgroup" claims becomes the three closure conditions.

```2b4m
pred inSource = homomorphism.inSource
pred inTarget = homomorphism.inTarget
define inImage(x) = homomorphism.inImage(x)
define inPreimage(g) = homomorphism.inPreimage(g)

// (3) phi(H_1) is a subgroup of G_2
theorem theImageHasTheIdentity: inImage(EH)
proof
  @conclusion |
    inImage(EH)
    [using import(homomorphism) theImageHasTheIdentity]
qed

theorem theImageIsClosedUnderTheOperation: forall x: H; forall y: H;
  inImage(x) -> inImage(y) -> inImage(opH(x, y))
proof
  @conclusion |
    forall x: H; forall y: H; inImage(x) -> inImage(y) -> inImage(opH(x, y))
    [using import(homomorphism) theImageIsClosedUnderTheOperation]
qed

theorem theImageIsClosedUnderInverses: forall x: H; inImage(x) -> inImage(invH(x))
proof
  @conclusion |
    forall x: H; inImage(x) -> inImage(invH(x))
    [using import(homomorphism) theImageIsClosedUnderInverses]
qed

// (4) phi^-1(H_2) is a subgroup of G_1, and normal when H_2 is
theorem thePreimageHasTheIdentity: inPreimage(EG)
proof
  @conclusion |
    inPreimage(EG)
    [using import(homomorphism) thePreimageHasTheIdentity]
qed

theorem thePreimageIsClosedUnderTheOperation: forall a: G; forall b: G;
  inPreimage(a) -> inPreimage(b) -> inPreimage(opG(a, b))
proof
  @conclusion |
    forall a: G; forall b: G; inPreimage(a) -> inPreimage(b) -> inPreimage(opG(a, b))
    [using import(homomorphism) thePreimageIsClosedUnderTheOperation]
qed

theorem thePreimageIsClosedUnderInverses: forall a: G;
  inPreimage(a) -> inPreimage(invG(a))
proof
  @conclusion |
    forall a: G; inPreimage(a) -> inPreimage(invG(a))
    [using import(homomorphism) thePreimageIsClosedUnderInverses]
qed

theorem thePreimageOfANormalSubgroupIsNormal:
  (forall x: H; forall y: H; inTarget(y) -> inTarget(opH(opH(x, y), invH(x)))) ->
  forall g: G; forall n: G; inPreimage(n) -> inPreimage(opG(opG(g, n), invG(g)))
proof
  @conclusion |
    (forall x: H; forall y: H; inTarget(y) -> inTarget(opH(opH(x, y), invH(x)))) ->
      forall g: G; forall n: G; inPreimage(n) -> inPreimage(opG(opG(g, n), invG(g)))
    [using import(homomorphism) thePreimageOfANormalSubgroupIsNormal]
qed
```

## The kernel

**Definition.** Let $\phi : G \rightarrow H$ be a group homomorphism and suppose that
$e$ is the identity of $H$. By Proposition 11.4, $\phi^{-1}(\{e\})$ is a subgroup of
$G$. This subgroup is called the **kernel** of $\phi$, denoted $\ker \phi$.

**Theorem 11.6.** Let $\phi : G \rightarrow H$ be a group homomorphism. Then the kernel
of $\phi$ is a normal subgroup of $G$.

*Proof (Judson).* "In fact, this subgroup is a normal subgroup of $G$ since the trivial
subgroup is normal in $H$." $\blacksquare$

Judson derives it from Proposition 11.4(4) at $H_2 = \{e'\}$ — the kernel *is*
$\phi^{-1}(\{e'\})$. Both routes are in `std`: the general preimage above, and the
kernel directly, whose proof needs no subgroup predicate on $H$ and is the one §11.2
actually cites.

```2b4m
pred inKernel = homomorphism.inKernel
fact inKernelDef = homomorphism.inKernelDef

theorem theKernelHasTheIdentity: inKernel(EG)
proof
  @conclusion |
    inKernel(EG)
    [using import(homomorphism) theKernelHasTheIdentity]
qed

theorem theKernelIsClosedUnderTheOperation: forall a: G; forall b: G;
  inKernel(a) -> inKernel(b) -> inKernel(opG(a, b))
proof
  @conclusion |
    forall a: G; forall b: G; inKernel(a) -> inKernel(b) -> inKernel(opG(a, b))
    [using import(homomorphism) theKernelIsClosedUnderTheOperation]
qed

theorem theKernelIsClosedUnderInverses: forall a: G;
  inKernel(a) -> inKernel(invG(a))
proof
  @conclusion |
    forall a: G; inKernel(a) -> inKernel(invG(a))
    [using import(homomorphism) theKernelIsClosedUnderInverses]
qed

// THEOREM 11.6
theorem theKernelIsNormal: forall g: G; forall n: G;
  inKernel(n) -> inKernel(opG(opG(g, n), invG(g)))
proof
  @conclusion |
    forall g: G; forall n: G; inKernel(n) -> inKernel(opG(opG(g, n), invG(g)))
    [using import(homomorphism) theKernelIsNormal]
qed
```

## A homomorphism is injective exactly when its kernel is trivial

Judson never numbers this, but he uses it throughout §11.2 — it is how the First
Isomorphism Theorem's last step reads "$\ker \psi = \{e\}$" as "$\psi$ is one-to-one",
and how §11.1's $\mathbb{Z}_7 \rightarrow \mathbb{Z}_{12}$ example concludes there is
no injective homomorphism. Both directions are proved, and the forward one is the first
result in the file that needs $G$ to be a *group* rather than a set with a map: it
cancels in $G$.

```2b4m
theorem aTrivialKernelMakesPhiInjective:
  (forall g: G; inKernel(g) -> g = EG) ->
  forall a: G; forall b: G; phi(a) = phi(b) -> a = b
proof
  @conclusion |
    (forall g: G; inKernel(g) -> g = EG) ->
      forall a: G; forall b: G; phi(a) = phi(b) -> a = b
    [using import(homomorphism) aTrivialKernelMakesPhiInjective]
qed

theorem anInjectivePhiHasATrivialKernel:
  (forall a: G; forall b: G; phi(a) = phi(b) -> a = b) ->
  forall g: G; inKernel(g) -> g = EG
proof
  @conclusion |
    (forall a: G; forall b: G; phi(a) = phi(b) -> a = b) ->
      forall g: G; inKernel(g) -> g = EG
    [using import(homomorphism) anInjectivePhiHasATrivialKernel]
qed
```

## What is not transliterated

**Judson's three examples** are concrete instances, each needing its own construction:
$\phi : \mathbb{Z} \rightarrow G$ by $n \mapsto g^n$ (available —
`std/group/generated.b4m` has `power`); $\det : GL_2(\mathbb{R}) \rightarrow
\mathbb{R}^\ast$ (needs a matrix group, which `std` does not have); and
$\theta \mapsto \cos\theta + i\sin\theta$ from $\mathbb{R}$ to the circle group
(`std/complex.b4m` has the ingredients). None is a limit of the language — each is a
construction not yet built.

**The claim "$S_n$ and $\mathbb{Z}_2$ are related by parity"** is the motivating
remark, and the parity map is in `std/permutation/alternating.b4m` (`isEvenPerm` /
`isOddPerm`, with `productOfEvensIsEven`). Writing it as a *homomorphism* onto
$\mathbb{Z}_2$ would mean instantiating this file at those symbols — a model, not new
mathematics.
