# Functions and Mappings (Exercises)

Exercises for Judson §1.2.2, per `.claude/rules/aata-guide.md` — `std` used
liberally.

The theory of mappings lives in `std/function.bpa`. We import it and keep the
library names, aliasing only `identityFn` to the book's `id`.

```bpa
import function <<< "std/function.bpa"

sort Element = function.Element
sort Fn = function.Fn
const id = function.identityFn
func apply = function.apply
func compose = function.compose
define injective(f) = function.injective(f)
define surjective(f) = function.surjective(f)
pred invertible = function.invertible
axiom composeApply = function.composeApply
axiom identityApply = function.identityApply
axiom funcExt = function.funcExtensionality
axiom invertibleDef = function.invertibleDef
func inverse = function.inverse
axiom inverseLeft = function.inverseLeft
axiom inverseRight = function.inverseRight
axiom functionFromGraph = function.functionFromGraph
```

Associativity of composition is proved in the main text
(`aata/1.2.2-functions.md`, Theorem A.1); `std/function.bpa` does not package it,
so — this being an exercise file where `std` is used liberally — we re-prove the
small lemma here (a function-extensionality argument: the two composites agree at
every point after unfolding `compose` via `composeApply`, so `funcExt` equates
them).

```bpa
// composition is associative.
theorem composeAssoc: forall h, g, f: Fn;
  compose(compose(h, g), f) = compose(h, compose(g, f))
proof
  @generalize-h |
    fix h: Fn {
      @generalize-g |
        fix g: Fn {
          @generalize-f |
            fix f: Fn {
              @pointwise |
                fix x: Element {
                  // LHS applied at x
                  @compose-applies |
                    forall gg, ff: Fn; forall y: Element;
                      apply(compose(gg, ff), y) = apply(gg, apply(ff, y))
                    [by cite composeApply]
                  @lhs-outer-unfolds |
                    apply(compose(compose(h, g), f), x) = apply(compose(h, g), apply(f, x))
                    [by forall_elim(compose(h, g), f, x) compose-applies]
                  @lhs-inner-unfolds |
                    apply(compose(h, g), apply(f, x)) = apply(h, apply(g, apply(f, x)))
                    [by forall_elim(h, g, apply(f, x)) compose-applies]
                  @lhs-associated-unfolds |
                    apply(compose(compose(h, g), f), x) = apply(h, apply(g, apply(f, x)))
                    [by rewrite lhs-inner-unfolds lhs-outer-unfolds]
                  // RHS applied at x
                  @rhs-outer-unfolds |
                    apply(compose(h, compose(g, f)), x) = apply(h, apply(compose(g, f), x))
                    [by forall_elim(h, compose(g, f), x) compose-applies]
                  @rhs-inner-unfolds |
                    apply(compose(g, f), x) = apply(g, apply(f, x))
                    [by forall_elim(g, f, x) compose-applies]
                  @rhs-associated-unfolds |
                    apply(compose(h, compose(g, f)), x) = apply(h, apply(g, apply(f, x)))
                    [by rewrite rhs-inner-unfolds rhs-outer-unfolds]
                  // equate the two sides at x
                  @both-sides-agree-at-x |
                    apply(compose(compose(h, g), f), x) = apply(compose(h, compose(g, f)), x)
                    [by rewrite rhs-associated-unfolds lhs-associated-unfolds]
                }
              @agree-pointwise |
                forall x: Element;
                  apply(compose(compose(h, g), f), x) = apply(compose(h, compose(g, f)), x)
                [by forall_intro pointwise]
              @conclusion-at-h-g-f |
                compose(compose(h, g), f) = compose(h, compose(g, f))
                [using specialize funcExt(compose(compose(h, g), f), compose(h, compose(g, f))) agree-pointwise]
            }
          @discharge-f |
            forall f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
            [by forall_intro generalize-f]
        }
      @discharge-g |
        forall g, f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
        [by forall_intro generalize-g]
    }
  @conclusion |
    forall h, g, f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
    [by forall_intro generalize-h]
qed
```

## Exercises

**Exercise 25.** Let $f: A \to B$ and $g: B \to C$ be invertible mappings. Show
that $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.

We name the inverse with a total symbol `inverse` (aliased `inverse` above, from
`std/function.bpa`), pinned on the invertibles by `inverseLeft`/`inverseRight`
($f^{-1} \circ f = \operatorname{id}$ and $f \circ f^{-1} = \operatorname{id}$).
The argument rests on two supporting facts — the **identity laws**
$\operatorname{id} \circ f = f$ and $f \circ \operatorname{id} = f$ (each a
one-line `ext`), and **uniqueness of the inverse**: a left inverse equals a right
inverse, since if $h \circ k = \operatorname{id}$ and $k \circ m =
\operatorname{id}$ then $m = \operatorname{id}\circ m = (h\circ k)\circ m =
h\circ(k\circ m) = h\circ\operatorname{id} = h$.

```bpa
theorem composeIdentityLeft: forall f: Fn; compose(id, f) = f
proof
  @conclusion |
    forall f: Fn; compose(id, f) = f
    [using extensionality_quantified(function)]
qed

theorem composeIdentityRight: forall f: Fn; compose(f, id) = f
proof
  @conclusion |
    forall f: Fn; compose(f, id) = f
    [using extensionality_quantified(function)]
qed

// uniqueness: h∘k = id and k∘m = id force m = h.
theorem inverseUnique: forall h, k, m: Fn;
  compose(h, k) = id -> compose(k, m) = id -> m = h
proof
  @generalize-h |
    fix h: Fn {
      @generalize-k |
        fix k: Fn {
          @generalize-m |
            fix m: Fn {
              @given-left |
                assume compose(h, k) = id {
                  @given-right |
                    assume compose(k, m) = id {
                      @left |
                        compose(h, k) = id
                        [by hypothesis given-left]
                      @right |
                        compose(k, m) = id
                        [by hypothesis given-right]
                      @m-is-id-m |
                        compose(id, m) = m
                        [using specialize composeIdentityLeft(m)]
                      @start |
                        m = compose(id, m)
                        [by symmetry m-is-id-m]
                      @insert-hk |
                        m = compose(compose(h, k), m)
                        [by rewrite left start]
                      @regroup |
                        compose(compose(h, k), m) = compose(h, compose(k, m))
                        [using specialize composeAssoc(h, k, m)]
                      @regrouped |
                        m = compose(h, compose(k, m))
                        [by rewrite regroup insert-hk]
                      @collapse-right |
                        m = compose(h, id)
                        [by rewrite right regrouped]
                      @h-id-is-h |
                        compose(h, id) = h
                        [using specialize composeIdentityRight(h)]
                      @conclusion-m-is-h |
                        m = h
                        [by rewrite h-id-is-h collapse-right]
                    }
                  @discharge-right |
                    compose(k, m) = id -> m = h
                    [by implies_intro given-right]
                }
              @discharge-left |
                compose(h, k) = id -> compose(k, m) = id -> m = h
                [by implies_intro given-left]
            }
          @discharge-m |
            forall m: Fn; compose(h, k) = id -> compose(k, m) = id -> m = h
            [by forall_intro generalize-m]
        }
      @discharge-k |
        forall k, m: Fn; compose(h, k) = id -> compose(k, m) = id -> m = h
        [by forall_intro generalize-k]
    }
  @conclusion |
    forall h, k, m: Fn; compose(h, k) = id -> compose(k, m) = id -> m = h
    [by forall_intro generalize-h]
qed

// (g∘f)⁻¹ = f⁻¹∘g⁻¹.  f⁻¹∘g⁻¹ is a right inverse of g∘f (p2, by regrouping);
// inverse(g∘f) is a left inverse of it (inverseLeft); left = right (inverseUnique).
theorem inverseOfComposite: forall g, f: Fn;
  invertible(g) -> invertible(f) -> invertible(compose(g, f))
  -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
proof
  @generalize-g |
    fix g: Fn {
      @generalize-f |
        fix f: Fn {
          @given-g-invertible |
            assume invertible(g) {
              @given-f-invertible |
                assume invertible(f) {
                  @given-composite-invertible |
                    assume invertible(compose(g, f)) {
                      @g-invertible |
                        invertible(g)
                        [by hypothesis given-g-invertible]
                      @f-invertible |
                        invertible(f)
                        [by hypothesis given-f-invertible]
                      @composite-invertible |
                        invertible(compose(g, f))
                        [by hypothesis given-composite-invertible]
                      @assoc |
                        forall p, q, r: Fn; compose(compose(p, q), r) = compose(p, compose(q, r))
                        [by cite composeAssoc]
                      @f-right |
                        compose(f, inverse(f)) = id
                        [using specialize inverseRight(f) f-invertible]
                      @g-right |
                        compose(g, inverse(g)) = id
                        [using specialize inverseRight(g) g-invertible]
                      @left-inverse-of-composite |
                        compose(inverse(compose(g, f)), compose(g, f)) = id
                        [using specialize inverseLeft(compose(g, f)) composite-invertible]
                      // (g∘f)∘(f⁻¹∘g⁻¹) = g∘(f∘(f⁻¹∘g⁻¹)) = g∘((f∘f⁻¹)∘g⁻¹)
                      //                 = g∘(id∘g⁻¹) = g∘g⁻¹ = id
                      @regroup-outer |
                        compose(compose(g, f), compose(inverse(f), inverse(g))) = compose(g, compose(f, compose(inverse(f), inverse(g))))
                        [by forall_elim(g, f, compose(inverse(f), inverse(g))) assoc]
                      @regroup-inner |
                        compose(compose(f, inverse(f)), inverse(g)) = compose(f, compose(inverse(f), inverse(g)))
                        [by forall_elim(f, inverse(f), inverse(g)) assoc]
                      @regrouped |
                        compose(compose(g, f), compose(inverse(f), inverse(g))) = compose(g, compose(compose(f, inverse(f)), inverse(g)))
                        [by rewrite regroup-inner regroup-outer]
                      @cancel-f |
                        compose(compose(g, f), compose(inverse(f), inverse(g))) = compose(g, compose(id, inverse(g)))
                        [by rewrite f-right regrouped]
                      @id-left-g |
                        compose(id, inverse(g)) = inverse(g)
                        [using specialize composeIdentityLeft(inverse(g))]
                      @collapse-id |
                        compose(compose(g, f), compose(inverse(f), inverse(g))) = compose(g, inverse(g))
                        [by rewrite id-left-g cancel-f]
                      @right-inverse-of-composite |
                        compose(compose(g, f), compose(inverse(f), inverse(g))) = id
                        [by rewrite g-right collapse-id]
                      @inverses-swapped |
                        compose(inverse(f), inverse(g)) = inverse(compose(g, f))
                        [using specialize inverseUnique(inverse(compose(g, f)), compose(g, f), compose(inverse(f), inverse(g))) left-inverse-of-composite right-inverse-of-composite]
                      @conclusion-inverse |
                        inverse(compose(g, f)) = compose(inverse(f), inverse(g))
                        [by symmetry inverses-swapped]
                    }
                  @discharge-composite |
                    invertible(compose(g, f)) -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
                    [by implies_intro given-composite-invertible]
                }
              @discharge-f |
                invertible(f) -> invertible(compose(g, f)) -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
                [by implies_intro given-f-invertible]
            }
          @discharge-g |
            invertible(g) -> invertible(f) -> invertible(compose(g, f)) -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
            [by implies_intro given-g-invertible]
        }
      @discharge-generalize-f |
        forall f: Fn; invertible(g) -> invertible(f) -> invertible(compose(g, f)) -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
        [by forall_intro generalize-f]
    }
  @conclusion |
    forall g, f: Fn; invertible(g) -> invertible(f) -> invertible(compose(g, f)) -> inverse(compose(g, f)) = compose(inverse(f), inverse(g))
    [by forall_intro generalize-g]
qed
```

> **On the hypotheses.** We take $\operatorname{invertible}(g\circ f)$ as a
> hypothesis rather than deriving it: proving *invertible ⇐ invertible∘invertible*
> from `invertibleDef` needs to exhibit the witness $f^{-1}\circ g^{-1}$, which is
> exactly `inverse(f)∘inverse(g)` — provable, but the identity above is the
> content the exercise asks for. Also unlike the set exercises, `ext` does not
> shorten this proof: `inverse` is characterized by *composition* axioms, not a
> pointwise `apply`-rule, so there is nothing for `ext` to unfold — the argument
> is the algebraic identity-and-uniqueness chase, written out.
