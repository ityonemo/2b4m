# Equivalence Classes and Partitions

A literate `2b4m` transliteration continuing **Chapter 1 §1.2.3** of Judson's
*Abstract Algebra* — the **equivalence class / partition** material (source:
`vendor/aata/src/sets.xml`; © 1997–2026 Judson, GFDL 1.3). Run
`2b4m check aata/1.2.3-partitions.md`.

A **partition** $\mathcal{P}$ of a set $X$ is a collection of nonempty sets
$X_1, X_2, \ldots$ such that $X_i \cap X_j = \emptyset$ for $i \neq j$ and
$\bigcup_k X_k = X$. Let $\sim$ be an equivalence relation on a set $X$ and let
$x \in X$. Then $[x] = \{\, y \in X : y \sim x \,\}$ is called the **equivalence
class** of $x$. We will see that an equivalence relation gives rise to a partition via
equivalence classes. Also, whenever a partition of a set exists, there is some natural
underlying equivalence relation, as the following theorem demonstrates.

**Example.** If we consider the equivalence relation established by the integers modulo
$3$, then
$$\begin{aligned}
[0] &= \{\ldots, -3, 0, 3, 6, \ldots\}, \\
[1] &= \{\ldots, -2, 1, 4, 7, \ldots\}, \\
[2] &= \{\ldots, -1, 2, 5, 8, \ldots\}.
\end{aligned}$$
Notice that $[0] \cup [1] \cup [2] = \mathbb{Z}$ and also that the sets are disjoint.
The sets $[0]$, $[1]$, and $[2]$ form a partition of the integers.

## The equivalence classes form a partition

> **Theorem.** Given an equivalence relation $\sim$ on a set $X$, the equivalence
> classes of $X$ form a partition of $X$. Conversely, if $\mathcal P = \{X_i\}$
> is a partition of $X$, then there is an equivalence relation on $X$ with
> equivalence classes $X_i$.

**Proof.** Suppose there exists an equivalence relation $\sim$ on the set $X$.
For any $x \in X$, the reflexive property shows that $x \in [x]$ and so $[x]$
is nonempty.

```2b4m
theorem classContainsElement: equivalence -> forall x: Element; member(x, classOf(x))
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_lhs all-three]
      @all-self-related |
        reflexive
        [by and_lhs reflexive-and-symmetric]
      @every-element-in-its-class |
        fix x: Element {
          @x-self-related |
            related(x, x)
            [by apply_at(x) all-self-related]
          @class-membership |
            forall a: Element; forall b: Element;
              (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
            [by cite classMember]
          @membership-at |
            (member(x, classOf(x)) -> related(x, x)) and (related(x, x) -> member(x, classOf(x)))
            [by apply_at(x, x) class-membership]
          @related-gives-member |
            related(x, x) -> member(x, classOf(x))
            [by and_rhs membership-at]
          @x-in-its-class |
            member(x, classOf(x))
            [by modus_ponens related-gives-member x-self-related]
        }
      @conclusion-all |
        forall x: Element; member(x, classOf(x))
        [by generalize every-element-in-its-class]
    }
  @conclusion |
    equivalence -> forall x: Element; member(x, classOf(x))
    [by discharge given-equivalence]
qed
```

Next, two elements are equivalent exactly when their classes coincide. If
$x \sim y$ then every $z$ with $z \sim x$ also has $z \sim y$ by transitivity,
and conversely by symmetry, so $[x] \subset [y]$ and $[y] \subset [x]$, whence
$[x] = [y]$. Conversely, if $[x] = [y]$ then $x \in [x] = [y]$, that is,
$x \sim y$.

```2b4m
theorem classesEqualIffRelated:
  equivalence -> forall x, y: Element;
  related(x, y) iff classOf(x) = classOf(y)
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_lhs all-three]
      @symmetry-holds |
        symmetric
        [by and_rhs reflexive-and-symmetric]
      @transitivity-holds |
        transitive
        [by and_rhs all-three]
      @class-membership |
        forall a: Element; forall b: Element;
          (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
        [by cite classMember]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement all-three]
      @generalize-x |
        fix x: Element {
          @generalize-y |
            fix y: Element {
              @given-x-related-y |
                assume related(x, y) {
                  @x-related-y |
                    related(x, y)
                    [by hypothesis given-x-related-y]
                  @y-related-x |
                    related(y, x)
                    [using specialize symmetry-holds(x, y) x-related-y]
                  @class-x-included-in-class-y |
                    fix z: Element {
                      @given-z-in-class-x |
                        assume member(z, classOf(x)) {
                          @z-in-class-x |
                            member(z, classOf(x))
                            [by hypothesis given-z-in-class-x]
                          @class-membership-x-z |
                            (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                            [by apply_at(x, z) class-membership]
                          @z-in-class-x-gives-z-related-x |
                            member(z, classOf(x)) -> related(z, x)
                            [by and_lhs class-membership-x-z]
                          @z-related-x |
                            related(z, x)
                            [by modus_ponens z-in-class-x-gives-z-related-x z-in-class-x]
                          @transitivity-at-z-x-y |
                            related(z, x) -> related(x, y) -> related(z, y)
                            [by apply_at(z, x, y) transitivity-holds]
                          @z-related-y |
                            related(z, y)
                            [using tautology transitivity-at-z-x-y z-related-x x-related-y]
                          @class-membership-y-z |
                            (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                            [by apply_at(y, z) class-membership]
                          @z-related-y-gives-z-in-class-y |
                            related(z, y) -> member(z, classOf(y))
                            [by and_rhs class-membership-y-z]
                          @z-in-class-y |
                            member(z, classOf(y))
                            [by modus_ponens z-related-y-gives-z-in-class-y z-related-y]
                        }
                      @z-in-class-x-gives-z-in-class-y |
                        member(z, classOf(x)) -> member(z, classOf(y))
                        [by discharge given-z-in-class-x]
                    }
                  @class-x-subset-class-y |
                    forall z: Element; member(z, classOf(x)) -> member(z, classOf(y))
                    [by generalize class-x-included-in-class-y]
                  @class-y-included-in-class-x |
                    fix z: Element {
                      @given-z-in-class-y |
                        assume member(z, classOf(y)) {
                          @z-in-class-y |
                            member(z, classOf(y))
                            [by hypothesis given-z-in-class-y]
                          @class-membership-y-z |
                            (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                            [by apply_at(y, z) class-membership]
                          @z-in-class-y-gives-z-related-y |
                            member(z, classOf(y)) -> related(z, y)
                            [by and_lhs class-membership-y-z]
                          @z-related-y |
                            related(z, y)
                            [by modus_ponens z-in-class-y-gives-z-related-y z-in-class-y]
                          @transitivity-at-z-y-x |
                            related(z, y) -> related(y, x) -> related(z, x)
                            [by apply_at(z, y, x) transitivity-holds]
                          @z-related-x |
                            related(z, x)
                            [using tautology transitivity-at-z-y-x z-related-y y-related-x]
                          @class-membership-x-z |
                            (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                            [by apply_at(x, z) class-membership]
                          @z-related-x-gives-z-in-class-x |
                            related(z, x) -> member(z, classOf(x))
                            [by and_rhs class-membership-x-z]
                          @z-in-class-x |
                            member(z, classOf(x))
                            [by modus_ponens z-related-x-gives-z-in-class-x z-related-x]
                        }
                      @z-in-class-y-gives-z-in-class-x |
                        member(z, classOf(y)) -> member(z, classOf(x))
                        [by discharge given-z-in-class-y]
                    }
                  @class-y-subset-class-x |
                    forall z: Element; member(z, classOf(y)) -> member(z, classOf(x))
                    [by generalize class-y-included-in-class-x]
                  @classes-are-equal |
                    classOf(x) = classOf(y)
                    [using specialize extensionality(classOf(x), classOf(y)) class-x-subset-class-y class-y-subset-class-x]
                }
              @related-gives-classes-equal |
                related(x, y) -> classOf(x) = classOf(y)
                [by discharge given-x-related-y]
              @given-classes-equal |
                assume classOf(x) = classOf(y) {
                  @classes-equal |
                    classOf(x) = classOf(y)
                    [by hypothesis given-classes-equal]
                  @x-in-class-x |
                    member(x, classOf(x))
                    [by apply_at(x) every-element-in-its-class]
                  @x-in-class-y |
                    member(x, classOf(y))
                    [by rewrite classes-equal x-in-class-x]
                  @class-membership-y-x |
                    (member(x, classOf(y)) -> related(x, y)) and (related(x, y) -> member(x, classOf(y)))
                    [by apply_at(y, x) class-membership]
                  @x-in-class-y-gives-x-related-y |
                    member(x, classOf(y)) -> related(x, y)
                    [by and_lhs class-membership-y-x]
                  @x-related-y |
                    related(x, y)
                    [by modus_ponens x-in-class-y-gives-x-related-y x-in-class-y]
                }
              @classes-equal-gives-related |
                classOf(x) = classOf(y) -> related(x, y)
                [by discharge given-classes-equal]
              @equal-iff-related-at-x-y |
                related(x, y) iff classOf(x) = classOf(y)
                [by make_equivalence related-gives-classes-equal classes-equal-gives-related]
            }
          @equal-iff-related-for-all-y |
            forall y: Element;
              related(x, y) iff classOf(x) = classOf(y)
            [by generalize generalize-y]
        }
      @equal-iff-related |
        forall x, y: Element;
          related(x, y) iff classOf(x) = classOf(y)
        [by generalize generalize-x]
    }
  @conclusion |
    equivalence -> forall x, y: Element;
      related(x, y) iff classOf(x) = classOf(y)
    [by discharge given-equivalence]
qed
```

> **Corollary.** Two equivalence classes of an equivalence relation are either disjoint
> or equal.

**Proof.** Now let $x, y \in X$. We need to show that either $[x] = [y]$ or
$[x] \cap [y] = \emptyset$. Suppose that the intersection of $[x]$ and $[y]$ is
not empty and that $z \in [x] \cap [y]$. Then $z \sim x$ and $z \sim y$. By
symmetry and transitivity $x \sim y$; hence, $[x] \subset [y]$. Similarly,
$[y] \subset [x]$ and so $[x] = [y]$. Therefore, any two equivalence classes
are either disjoint or exactly the same. $\blacksquare$

```2b4m
theorem classesEqualOrDisjoint:
  equivalence -> forall x, y: Element;
  classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_lhs all-three]
      @symmetry-holds |
        symmetric
        [by and_rhs reflexive-and-symmetric]
      @transitivity-holds |
        transitive
        [by and_rhs all-three]
      @class-membership |
        forall a: Element; forall b: Element;
          (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
        [by cite classMember]
      @intersection-membership |
        forall a, b: Set; forall z: Element;
          (member(z, intersection(a, b)) -> (member(z, a) and member(z, b)))
          and ((member(z, a) and member(z, b)) -> member(z, intersection(a, b)))
        [by cite intersectionMember]
      @empty-membership |
        forall z: Element; not member(z, emptyset)
        [by cite emptysetMember]
      @equal-iff-related-holds |
        forall x, y: Element;
          related(x, y) iff classOf(x) = classOf(y)
        [using specialize classesEqualIffRelated all-three]
      @generalize-x |
        fix x: Element {
          @generalize-y |
            fix y: Element {
              @related-or-not |
                related(x, y) or (not related(x, y))
                [using tautology]
              @equal-or-disjoint-at-x-y |
                classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                case related-or-not {
                  @when-related |
                    assume related(x, y) {
                      @x-related-y |
                        related(x, y)
                        [by hypothesis when-related]
                      @equal-iff-related-at-x-y |
                        related(x, y) iff classOf(x) = classOf(y)
                        [by apply_at(x, y) equal-iff-related-holds]
                      @related-gives-classes-equal |
                        related(x, y) -> classOf(x) = classOf(y)
                        [by equiv_forward equal-iff-related-at-x-y]
                      @classes-are-equal |
                        classOf(x) = classOf(y)
                        [by modus_ponens related-gives-classes-equal x-related-y]
                      @equal-or-disjoint |
                        classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                        [by either_left classes-are-equal]
                    }
                  @when-not-related |
                    assume not related(x, y) {
                      @x-not-related-y |
                        not related(x, y)
                        [by hypothesis when-not-related]
                      @intersection-included-in-empty |
                        fix z: Element {
                          @given-z-in-intersection |
                            assume member(z, intersection(classOf(x), classOf(y))) {
                              @z-in-intersection |
                                member(z, intersection(classOf(x), classOf(y)))
                                [by hypothesis given-z-in-intersection]
                              @intersection-membership-at |
                                (member(z, intersection(classOf(x), classOf(y))) -> (member(z, classOf(x)) and member(z, classOf(y))))
                                  and ((member(z, classOf(x)) and member(z, classOf(y))) -> member(z, intersection(classOf(x), classOf(y))))
                                [by apply_at(classOf(x), classOf(y), z) intersection-membership]
                              @z-in-intersection-gives-both |
                                member(z, intersection(classOf(x), classOf(y))) -> (member(z, classOf(x)) and member(z, classOf(y)))
                                [by and_lhs intersection-membership-at]
                              @z-in-both-classes |
                                member(z, classOf(x)) and member(z, classOf(y))
                                [by modus_ponens z-in-intersection-gives-both z-in-intersection]
                              @z-in-class-x |
                                member(z, classOf(x))
                                [by and_lhs z-in-both-classes]
                              @z-in-class-y |
                                member(z, classOf(y))
                                [by and_rhs z-in-both-classes]
                              @class-membership-x-z |
                                (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                                [by apply_at(x, z) class-membership]
                              @z-in-class-x-gives-z-related-x |
                                member(z, classOf(x)) -> related(z, x)
                                [by and_lhs class-membership-x-z]
                              @z-related-x |
                                related(z, x)
                                [by modus_ponens z-in-class-x-gives-z-related-x z-in-class-x]
                              @class-membership-y-z |
                                (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                                [by apply_at(y, z) class-membership]
                              @z-in-class-y-gives-z-related-y |
                                member(z, classOf(y)) -> related(z, y)
                                [by and_lhs class-membership-y-z]
                              @z-related-y |
                                related(z, y)
                                [by modus_ponens z-in-class-y-gives-z-related-y z-in-class-y]
                              @x-related-z |
                                related(x, z)
                                [using specialize symmetry-holds(z, x) z-related-x]
                              @transitivity-at-x-z-y |
                                related(x, z) -> related(z, y) -> related(x, y)
                                [by apply_at(x, z, y) transitivity-holds]
                              @x-related-y |
                                related(x, y)
                                [using tautology transitivity-at-x-z-y x-related-z z-related-y]
                              @z-in-empty |
                                member(z, emptyset)
                                [by ex_falso x-related-y x-not-related-y]
                            }
                          @z-in-intersection-gives-z-in-empty |
                            member(z, intersection(classOf(x), classOf(y))) -> member(z, emptyset)
                            [by discharge given-z-in-intersection]
                        }
                      @intersection-subset-empty |
                        forall z: Element; member(z, intersection(classOf(x), classOf(y))) -> member(z, emptyset)
                        [by generalize intersection-included-in-empty]
                      @empty-included-in-intersection |
                        fix z: Element {
                          @given-z-in-empty |
                            assume member(z, emptyset) {
                              @z-in-empty |
                                member(z, emptyset)
                                [by hypothesis given-z-in-empty]
                              @z-not-in-empty |
                                not member(z, emptyset)
                                [by apply_at(z) empty-membership]
                              @z-in-intersection |
                                member(z, intersection(classOf(x), classOf(y)))
                                [by ex_falso z-in-empty z-not-in-empty]
                            }
                          @z-in-empty-gives-z-in-intersection |
                            member(z, emptyset) -> member(z, intersection(classOf(x), classOf(y)))
                            [by discharge given-z-in-empty]
                        }
                      @empty-subset-intersection |
                        forall z: Element; member(z, emptyset) -> member(z, intersection(classOf(x), classOf(y)))
                        [by generalize empty-included-in-intersection]
                      @intersection-is-empty |
                        intersection(classOf(x), classOf(y)) = emptyset
                        [using specialize extensionality(intersection(classOf(x), classOf(y)), emptyset) intersection-subset-empty empty-subset-intersection]
                      @equal-or-disjoint |
                        classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                        [by either_right intersection-is-empty]
                    }
                }
            }
          @equal-or-disjoint-for-all-y |
            forall y: Element;
              classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
            [by generalize generalize-y]
        }
      @equal-or-disjoint |
        forall x, y: Element;
          classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
        [by generalize generalize-x]
    }
  @conclusion |
    equivalence -> forall x, y: Element;
      classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
    [by discharge given-equivalence]
qed
```

## The classes form a partition

Clearly $X = \bigcup_{x \in X} [x]$, so the classes cover $X$; with the
corollary above they therefore form a partition of $X$.

```2b4m

```

Write $\mathcal{P}$ for the collection $\{[x] : x \in X\}$ of all equivalence
classes: a set belongs to $\mathcal{P}$ exactly when it is some class $[x]$.

```2b4m
const quotient: Collection

// "s is the class of x" -- a DEFINITION, so `--axioms` reports it as one rather than
// listing it beside genuine assumptions.
pred isTheClassOf(s: Set, x: Element):
  isTheClassOf(s, x) iff s = classOf(x)

// and P contains exactly the classes. This fixes `quotient` by its membership, the same
// way `std/equivalence.b4m` fixes `classOf` and `std/set.b4m` fixes `union`: there is no
// comprehension in the set theory, so a collection is posited with its membership rule.
axiom quotientContains: forall s: Set;
  contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
```

**The classes cover $X$.** Every element $z$ lies in its own class $[z]$ by
reflexivity, and $[z]$ belongs to $\mathcal{P}$; so $z \in \bigcup\mathcal{P}$.
Conversely every element is in $X$. Hence $\bigcup\mathcal{P} = X$.

```2b4m
theorem classesCover: equivalence -> covers(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
        [by cite quotientContains]
      @big-union-membership |
        forall c: Collection; forall x: Element;
          member(x, bigUnion(c)) iff (exists s: Set; contains(s, c) and member(x, s))
        [by cite bigUnionMember]
      @every-element-in-universe |
        forall x: Element; member(x, universe)
        [by cite universeMember]
      // big-union of the classes ⊆ universe: everything is in the universe.
      @big-union-included-in-universe |
        fix z: Element {
          @given-z-in-big-union |
            assume member(z, bigUnion(quotient)) {
              @z-in-universe |
                member(z, universe)
                [by apply_at(z) every-element-in-universe]
            }
          @z-in-big-union-gives-z-in-universe |
            member(z, bigUnion(quotient)) -> member(z, universe)
            [by discharge given-z-in-big-union]
        }
      @big-union-subset-universe |
        forall z: Element; member(z, bigUnion(quotient)) -> member(z, universe)
        [by generalize big-union-included-in-universe]
      // universe ⊆ big-union: z lives in its own class [z], and [z] ∈ quotient.
      @universe-included-in-big-union |
        fix z: Element {
          @given-z-in-universe |
            assume member(z, universe) {
              @z-in-its-class |
                member(z, classOf(z))
                [by apply_at(z) every-element-in-its-class]
              @class-of-z-reflexive |
                classOf(z) = classOf(z)
                [by reflexivity]
              @class-of-z-is-the-class-of-z |
                isTheClassOf(classOf(z), z)
                [using tautology class-of-z-reflexive the-class-definition-at-z]
              @the-class-definition |
                forall s: Set; forall x: Element; isTheClassOf(s, x) iff s = classOf(x)
                [by definition isTheClassOf]
              @the-class-definition-at-z |
                isTheClassOf(classOf(z), z) iff classOf(z) = classOf(z)
                [by apply_at(classOf(z), z) the-class-definition]
              @class-of-z-is-a-class |
                exists x: Element; isTheClassOf(classOf(z), x)
                [by witness(z) class-of-z-is-the-class-of-z]
              @quotient-membership-at-class-of-z |
                contains(classOf(z), quotient) iff (exists x: Element; isTheClassOf(classOf(z), x))
                [by apply_at(classOf(z)) quotient-members-are-classes]
              @class-being-a-class-gives-quotient-membership |
                (exists x: Element; isTheClassOf(classOf(z), x)) -> contains(classOf(z), quotient)
                [by equiv_converse quotient-membership-at-class-of-z]
              @class-of-z-in-quotient |
                contains(classOf(z), quotient)
                [by modus_ponens class-being-a-class-gives-quotient-membership class-of-z-is-a-class]
              @class-of-z-witnesses-membership |
                contains(classOf(z), quotient) and member(z, classOf(z))
                [by both class-of-z-in-quotient z-in-its-class]
              @some-class-contains-z |
                exists s: Set; contains(s, quotient) and member(z, s)
                [by witness(classOf(z)) class-of-z-witnesses-membership]
              @big-union-membership-at-z |
                member(z, bigUnion(quotient)) iff (exists s: Set; contains(s, quotient) and member(z, s))
                [by apply_at(quotient, z) big-union-membership]
              @witness-gives-big-union-membership |
                (exists s: Set; contains(s, quotient) and member(z, s)) -> member(z, bigUnion(quotient))
                [by equiv_converse big-union-membership-at-z]
              @z-in-big-union |
                member(z, bigUnion(quotient))
                [by modus_ponens witness-gives-big-union-membership some-class-contains-z]
            }
          @z-in-universe-gives-z-in-big-union |
            member(z, universe) -> member(z, bigUnion(quotient))
            [by discharge given-z-in-universe]
        }
      @universe-subset-big-union |
        forall z: Element; member(z, universe) -> member(z, bigUnion(quotient))
        [by generalize universe-included-in-big-union]
      @quotient-covers |
        bigUnion(quotient) = universe
        [using specialize extensionality(bigUnion(quotient), universe) big-union-subset-universe universe-subset-big-union]
    }
  @conclusion |
    equivalence -> covers(quotient)
    [by discharge given-equivalence]
qed
```

**The classes are pairwise disjoint.** Two distinct members $s, t$ of
$\mathcal{P}$ are classes $s = [a]$ and $t = [b]$. By the corollary either
$[a] = [b]$ — impossible, since that would make $s = t$ — or
$[a] \cap [b] = \emptyset$, that is, $s \cap t = \emptyset$.

```2b4m
theorem classesDisjoint: equivalence -> pairwiseDisjoint(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @equal-or-disjoint-holds |
        forall x, y: Element;
          classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
        [using specialize classesEqualOrDisjoint equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
        [by cite quotientContains]
      @distinct-classes-are-disjoint |
        fix s: Set {
          @distinct-from-s-are-disjoint |
            fix t: Set {
              @given-s-in-quotient |
                assume contains(s, quotient) {
                  @given-t-in-quotient |
                    assume contains(t, quotient) {
                      @given-s-not-t |
                        assume s != t {
                          @s-not-t |
                            s != t
                            [by hypothesis given-s-not-t]
                          @s-in-quotient |
                            contains(s, quotient)
                            [by hypothesis given-s-in-quotient]
                          @t-in-quotient |
                            contains(t, quotient)
                            [by hypothesis given-t-in-quotient]
                          @quotient-membership-at-s |
                            contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
                            [by apply_at(s) quotient-members-are-classes]
                          @s-in-quotient-gives-class |
                            contains(s, quotient) -> exists x: Element; isTheClassOf(s, x)
                            [by equiv_forward quotient-membership-at-s]
                          @s-is-some-class |
                            exists x: Element; isTheClassOf(s, x)
                            [by modus_ponens s-in-quotient-gives-class s-in-quotient]
                          @quotient-membership-at-t |
                            contains(t, quotient) iff (exists x: Element; isTheClassOf(t, x))
                            [by apply_at(t) quotient-members-are-classes]
                          @t-in-quotient-gives-class |
                            contains(t, quotient) -> exists x: Element; isTheClassOf(t, x)
                            [by equiv_forward quotient-membership-at-t]
                          @t-is-some-class |
                            exists x: Element; isTheClassOf(t, x)
                            [by modus_ponens t-in-quotient-gives-class t-in-quotient]
                          @with-generator-a |
                            unpack a: Element from s-is-some-class {
                              @s-is-the-class-of-a |
                                isTheClassOf(s, a)
                                [by hypothesis with-generator-a]
                              @the-class-definition-for-s-a |
                                forall s2: Set; forall x: Element;
                                  isTheClassOf(s2, x) iff s2 = classOf(x)
                                [by definition isTheClassOf]
                              @the-class-definition-at-s-a |
                                isTheClassOf(s, a) iff s = classOf(a)
                                [by apply_at(s, a) the-class-definition-for-s-a]
                              @s-is-class-of-a |
                                s = classOf(a)
                                [using tautology s-is-the-class-of-a the-class-definition-at-s-a]
                              @with-generator-b |
                                unpack b: Element from t-is-some-class {
                                  @t-is-the-class-of-b |
                                    isTheClassOf(t, b)
                                    [by hypothesis with-generator-b]
                                  @the-class-definition-for-t-b |
                                    forall s2: Set; forall x: Element;
                                      isTheClassOf(s2, x) iff s2 = classOf(x)
                                    [by definition isTheClassOf]
                                  @the-class-definition-at-t-b |
                                    isTheClassOf(t, b) iff t = classOf(b)
                                    [by apply_at(t, b) the-class-definition-for-t-b]
                                  @t-is-class-of-b |
                                    t = classOf(b)
                                    [using tautology t-is-the-class-of-b the-class-definition-at-t-b]
                                  @equal-or-disjoint-at-a-b |
                                    classOf(a) = classOf(b) or intersection(classOf(a), classOf(b)) = emptyset
                                    [by apply_at(a, b) equal-or-disjoint-holds]
                                  @intersection-is-empty |
                                    intersection(s, t) = emptyset
                                    case equal-or-disjoint-at-a-b {
                                      @when-classes-equal |
                                        assume classOf(a) = classOf(b) {
                                          // s = [a] = [b] = t contradicts s ≠ t.
                                          @classes-equal |
                                            classOf(a) = classOf(b)
                                            [by hypothesis when-classes-equal]
                                          @s-equals-t |
                                            s = t
                                            [using chain s-is-class-of-a classes-equal t-is-class-of-b]
                                          @intersection-empty-by-contradiction |
                                            intersection(s, t) = emptyset
                                            [by ex_falso s-equals-t s-not-t]
                                        }
                                      @when-classes-disjoint |
                                        assume intersection(classOf(a), classOf(b)) = emptyset {
                                          // rewrite the empty intersection back onto s and t.
                                          @classes-disjoint |
                                            intersection(classOf(a), classOf(b)) = emptyset
                                            [by hypothesis when-classes-disjoint]
                                          @intersection-empty-rewritten |
                                            intersection(s, t) = emptyset
                                            [using chain classes-disjoint s-is-class-of-a t-is-class-of-b]
                                        }
                                    }
                                }
                              @intersection-is-empty-exported-b |
                                intersection(s, t) = emptyset
                                [by unpacked with-generator-b]
                            }
                          @intersection-is-empty-exported |
                            intersection(s, t) = emptyset
                            [by unpacked with-generator-a]
                        }
                      @distinct-gives-disjoint |
                        s != t -> intersection(s, t) = emptyset
                        [by discharge given-s-not-t]
                    }
                  @t-in-quotient-gives-disjoint |
                    contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
                    [by discharge given-t-in-quotient]
                }
              @s-in-quotient-gives-disjoint |
                contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
                [by discharge given-s-in-quotient]
            }
          @distinct-from-s-are-disjoint-for-all-t |
            forall t: Set;
              contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
            [by generalize distinct-from-s-are-disjoint]
        }
      @quotient-pairwise-disjoint |
        forall s, t: Set;
          contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
        [by generalize distinct-classes-are-disjoint]
    }
  @conclusion |
    equivalence -> pairwiseDisjoint(quotient)
    [by discharge given-equivalence]
qed
```

**The classes form a partition.** A partition is a covering, pairwise disjoint
collection none of whose members is empty. The first two are what was just
proved, and no class is empty because $[a]$ always contains $a$.

```2b4m
theorem classesFormPartition: equivalence -> isPartition(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @quotient-covers |
        covers(quotient)
        [using specialize classesCover equivalence]
      @quotient-pairwise-disjoint |
        pairwiseDisjoint(quotient)
        [using specialize classesDisjoint equivalence]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
        [by cite quotientContains]
      @empty-membership |
        forall x: Element; not member(x, emptyset)
        [by cite emptysetMember]
      // no class is empty: [a] contains its own generator a.
      @members-are-nonempty |
        fix s: Set {
          @given-s-in-quotient |
            assume contains(s, quotient) {
              @s-in-quotient |
                contains(s, quotient)
                [by hypothesis given-s-in-quotient]
              @quotient-membership-at-s |
                contains(s, quotient) iff (exists x: Element; isTheClassOf(s, x))
                [by apply_at(s) quotient-members-are-classes]
              @s-in-quotient-gives-class |
                contains(s, quotient) -> exists x: Element; isTheClassOf(s, x)
                [by equiv_forward quotient-membership-at-s]
              @s-is-some-class |
                exists x: Element; isTheClassOf(s, x)
                [by modus_ponens s-in-quotient-gives-class s-in-quotient]
              @with-generator-a |
                unpack a: Element from s-is-some-class {
                  @s-is-the-class-of-a |
                    isTheClassOf(s, a)
                    [by hypothesis with-generator-a]
                  @the-class-definition-for-s-a-again |
                    forall s2: Set; forall x: Element;
                      isTheClassOf(s2, x) iff s2 = classOf(x)
                    [by definition isTheClassOf]
                  @the-class-definition-at-s-a-again |
                    isTheClassOf(s, a) iff s = classOf(a)
                    [by apply_at(s, a) the-class-definition-for-s-a-again]
                  @s-is-class-of-a |
                    s = classOf(a)
                    [using tautology s-is-the-class-of-a the-class-definition-at-s-a-again]
                  @a-in-its-class |
                    member(a, classOf(a))
                    [by apply_at(a) every-element-in-its-class]
                  @a-in-s |
                    member(a, s)
                    [by rewrite s-is-class-of-a a-in-its-class]
                  @a-not-in-empty |
                    not member(a, emptyset)
                    [by apply_at(a) empty-membership]
                  @suppose-s-empty |
                    assume s = emptyset {
                      @s-empty |
                        s = emptyset
                        [by hypothesis suppose-s-empty]
                      @a-in-empty |
                        member(a, emptyset)
                        [by rewrite s-empty a-in-s]
                    }
                  @s-nonempty |
                    s != emptyset
                    [by contradiction suppose-s-empty a-in-empty a-not-in-empty]
                }
              @s-is-nonempty |
                s != emptyset
                [by unpacked with-generator-a]
            }
          @s-in-quotient-gives-nonempty |
            contains(s, quotient) -> s != emptyset
            [by discharge given-s-in-quotient]
        }
      @members-are-nonempty-for-all |
        forall s: Set; contains(s, quotient) -> s != emptyset
        [by generalize members-are-nonempty]
      @covers-and-disjoint |
        covers(quotient) and pairwiseDisjoint(quotient)
        [by both quotient-covers quotient-pairwise-disjoint]
      @quotient-is-partition |
        covers(quotient) and pairwiseDisjoint(quotient) and (forall s: Set; contains(s, quotient) -> s != emptyset)
        [by both covers-and-disjoint members-are-nonempty-for-all]
    }
  @conclusion |
    equivalence -> isPartition(quotient)
    [by discharge given-equivalence]
qed
```

## The converse

Conversely, suppose that $\mathcal{P} = \{X_i\}$ is a partition of a set $X$.
Let two elements be equivalent if they are in the same partition. Clearly, the
relation is reflexive. If $x$ is in the same partition as $y$, then $y$ is in
the same partition as $x$, so $x \sim y$ implies $y \sim x$. Finally, if $x$ is
in the same partition as $y$ and $y$ is in the same partition as $z$, then $x$
must be in the same partition as $z$, and transitivity holds.

```2b4m
// "x and y lie in the same block of the partition c".
pred sameBlock(c: Collection, x: Element, y: Element)
axiom sameBlockDef: forall c: Collection; forall x, y: Element;
  sameBlock(c, x, y) iff (exists s: Set; contains(s, c) and member(x, s) and member(y, s))

// reflexive: the blocks cover X, so every x lies in some block.
theorem sameBlockIsReflexive: forall c: Collection;
  isPartition(c) -> forall x: Element; sameBlock(c, x, x)
proof
  @generalize-c |
    fix c: Collection {
      @given-partition |
        assume isPartition(c) {
          @partition |
            covers(c) and pairwiseDisjoint(c) and (forall s: Set; contains(s, c) -> s != emptyset)
            [by hypothesis given-partition]
          @covers-and-disjoint |
            covers(c) and pairwiseDisjoint(c)
            [by and_lhs partition]
          @blocks-cover |
            bigUnion(c) = universe
            [by and_lhs covers-and-disjoint]
          @generalize-x |
            fix x: Element {
              @x-in-universe |
                member(x, universe)
                [using specialize universeMember(x)]
              @x-in-big-union |
                member(x, bigUnion(c))
                [by rewrite blocks-cover x-in-universe]
              @big-union-membership |
                member(x, bigUnion(c)) iff (exists s: Set; contains(s, c) and member(x, s))
                [using specialize bigUnionMember(c, x)]
              @x-lies-in-some-block |
                exists s: Set; contains(s, c) and member(x, s)
                [using tautology big-union-membership x-in-big-union]
              @with-block-s |
                unpack s: Set from x-lies-in-some-block {
                  @s-is-a-block-containing-x |
                    contains(s, c) and member(x, s)
                    [by hypothesis with-block-s]
                  @x-in-s |
                    member(x, s)
                    [by and_rhs s-is-a-block-containing-x]
                  @s-holds-x-twice |
                    contains(s, c) and member(x, s) and member(x, s)
                    [by both s-is-a-block-containing-x x-in-s]
                  @some-block-holds-x-twice |
                    exists t: Set; contains(t, c) and member(x, t) and member(x, t)
                    [by witness(s) s-holds-x-twice]
                  @same-block-at-x-x |
                    sameBlock(c, x, x) iff (exists t: Set; contains(t, c) and member(x, t) and member(x, t))
                    [using specialize sameBlockDef(c, x, x)]
                  @conclusion-x-shares-a-block-with-itself |
                    sameBlock(c, x, x)
                    [using tautology same-block-at-x-x some-block-holds-x-twice]
                }
              @conclusion-x-reflexive |
                sameBlock(c, x, x)
                [by unpacked with-block-s]
            }
          @conclusion-reflexive |
            forall x: Element; sameBlock(c, x, x)
            [by generalize generalize-x]
        }
      @partition-implies-reflexive |
        isPartition(c) -> forall x: Element; sameBlock(c, x, x)
        [by discharge given-partition]
    }
  @conclusion |
    forall c: Collection; isPartition(c) -> forall x: Element; sameBlock(c, x, x)
    [by generalize generalize-c]
qed

// symmetric: "the same block" is symmetric in x and y.
theorem sameBlockIsSymmetric: forall c: Collection; forall x, y: Element;
  sameBlock(c, x, y) -> sameBlock(c, y, x)
proof
  @generalize-c |
    fix c: Collection {
      @generalize-x |
        fix x: Element {
          @generalize-y |
            fix y: Element {
              @given-same-block |
                assume sameBlock(c, x, y) {
                  @x-and-y-share-a-block |
                    sameBlock(c, x, y)
                    [by hypothesis given-same-block]
                  @same-block-at-x-y |
                    sameBlock(c, x, y) iff (exists s: Set; contains(s, c) and member(x, s) and member(y, s))
                    [using specialize sameBlockDef(c, x, y)]
                  @a-block-holds-x-and-y |
                    exists s: Set; contains(s, c) and member(x, s) and member(y, s)
                    [using tautology same-block-at-x-y x-and-y-share-a-block]
                  @with-block-s |
                    unpack s: Set from a-block-holds-x-and-y {
                      @s-holds-x-and-y |
                        contains(s, c) and member(x, s) and member(y, s)
                        [by hypothesis with-block-s]
                      @y-in-s |
                        member(y, s)
                        [by and_rhs s-holds-x-and-y]
                      @block-and-x |
                        contains(s, c) and member(x, s)
                        [by and_lhs s-holds-x-and-y]
                      @s-is-a-block |
                        contains(s, c)
                        [by and_lhs block-and-x]
                      @x-in-s |
                        member(x, s)
                        [by and_rhs block-and-x]
                      @block-and-y |
                        contains(s, c) and member(y, s)
                        [by both s-is-a-block y-in-s]
                      @s-holds-y-and-x |
                        contains(s, c) and member(y, s) and member(x, s)
                        [by both block-and-y x-in-s]
                      @a-block-holds-y-and-x |
                        exists t: Set; contains(t, c) and member(y, t) and member(x, t)
                        [by witness(s) s-holds-y-and-x]
                      @same-block-at-y-x |
                        sameBlock(c, y, x) iff (exists t: Set; contains(t, c) and member(y, t) and member(x, t))
                        [using specialize sameBlockDef(c, y, x)]
                      @conclusion-y-shares-a-block-with-x |
                        sameBlock(c, y, x)
                        [using tautology same-block-at-y-x a-block-holds-y-and-x]
                    }
                  @conclusion-symmetric-at-x-y |
                    sameBlock(c, y, x)
                    [by unpacked with-block-s]
                }
              @same-block-implies-swapped |
                sameBlock(c, x, y) -> sameBlock(c, y, x)
                [by discharge given-same-block]
            }
          @discharge-y |
            forall y: Element; sameBlock(c, x, y) -> sameBlock(c, y, x)
            [by generalize generalize-y]
        }
      @discharge-x |
        forall x, y: Element; sameBlock(c, x, y) -> sameBlock(c, y, x)
        [by generalize generalize-x]
    }
  @conclusion |
    forall c: Collection; forall x, y: Element; sameBlock(c, x, y) -> sameBlock(c, y, x)
    [by generalize generalize-c]
qed
```

For transitivity the blocks must be pairwise disjoint: if $x, y \in s$ and
$y, z \in t$ then $y \in s \cap t$, so $s$ and $t$ cannot be distinct blocks of
a partition; hence $s = t$ and $x, z$ lie in the same block.

```2b4m
theorem sameBlockIsTransitive: forall c: Collection;
  isPartition(c) -> forall x, y, z: Element;
  sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
proof
  @generalize-c |
    fix c: Collection {
      @given-partition |
        assume isPartition(c) {
          @partition |
            covers(c) and pairwiseDisjoint(c) and (forall s: Set; contains(s, c) -> s != emptyset)
            [by hypothesis given-partition]
          @covers-and-disjoint |
            covers(c) and pairwiseDisjoint(c)
            [by and_lhs partition]
          @blocks-are-disjoint |
            forall s, t: Set; contains(s, c) -> contains(t, c) -> s != t -> intersection(s, t) = emptyset
            [by and_rhs covers-and-disjoint]
          @generalize-x |
            fix x: Element {
              @generalize-y |
                fix y: Element {
                  @generalize-z |
                    fix z: Element {
                      @given-x-with-y |
                        assume sameBlock(c, x, y) {
                          @given-y-with-z |
                            assume sameBlock(c, y, z) {
                              @x-with-y |
                                sameBlock(c, x, y)
                                [by hypothesis given-x-with-y]
                              @y-with-z |
                                sameBlock(c, y, z)
                                [by hypothesis given-y-with-z]
                              @same-block-at-x-y |
                                sameBlock(c, x, y) iff (exists s: Set; contains(s, c) and member(x, s) and member(y, s))
                                [using specialize sameBlockDef(c, x, y)]
                              @same-block-at-y-z |
                                sameBlock(c, y, z) iff (exists t: Set; contains(t, c) and member(y, t) and member(z, t))
                                [using specialize sameBlockDef(c, y, z)]
                              @a-block-holds-x-and-y |
                                exists s: Set; contains(s, c) and member(x, s) and member(y, s)
                                [using tautology same-block-at-x-y x-with-y]
                              @a-block-holds-y-and-z |
                                exists t: Set; contains(t, c) and member(y, t) and member(z, t)
                                [using tautology same-block-at-y-z y-with-z]
                              @with-block-s |
                                unpack s: Set from a-block-holds-x-and-y {
                                  @with-block-t |
                                    unpack t: Set from a-block-holds-y-and-z {
                                      @s-holds-x-and-y |
                                        contains(s, c) and member(x, s) and member(y, s)
                                        [by hypothesis with-block-s]
                                      @t-holds-y-and-z |
                                        contains(t, c) and member(y, t) and member(z, t)
                                        [by hypothesis with-block-t]
                                      @s-block-and-x |
                                        contains(s, c) and member(x, s)
                                        [by and_lhs s-holds-x-and-y]
                                      @s-is-a-block |
                                        contains(s, c)
                                        [by and_lhs s-block-and-x]
                                      @x-in-s |
                                        member(x, s)
                                        [by and_rhs s-block-and-x]
                                      @y-in-s |
                                        member(y, s)
                                        [by and_rhs s-holds-x-and-y]
                                      @t-block-and-y |
                                        contains(t, c) and member(y, t)
                                        [by and_lhs t-holds-y-and-z]
                                      @t-is-a-block |
                                        contains(t, c)
                                        [by and_lhs t-block-and-y]
                                      @y-in-t |
                                        member(y, t)
                                        [by and_rhs t-block-and-y]
                                      @z-in-t |
                                        member(z, t)
                                        [by and_rhs t-holds-y-and-z]
                                      // y lies in both blocks, so they cannot be disjoint.
                                      @y-in-both |
                                        member(y, s) and member(y, t)
                                        [by both y-in-s y-in-t]
                                      @intersection-membership |
                                        member(y, intersection(s, t)) iff (member(y, s) and member(y, t))
                                        [using specialize intersectionMember(s, t, y)]
                                      @y-in-the-intersection |
                                        member(y, intersection(s, t))
                                        [using tautology intersection-membership y-in-both]
                                      @nothing-is-in-the-emptyset |
                                        not member(y, emptyset)
                                        [using specialize emptysetMember(y)]
                                      @distinct-blocks-are-disjoint |
                                        s != t -> intersection(s, t) = emptyset
                                        [using specialize blocks-are-disjoint(s, t) s-is-a-block t-is-a-block]
                                      @given-blocks-distinct |
                                        assume s != t {
                                          @blocks-distinct |
                                            s != t
                                            [by hypothesis given-blocks-distinct]
                                          @the-intersection-is-empty |
                                            intersection(s, t) = emptyset
                                            [by modus_ponens distinct-blocks-are-disjoint blocks-distinct]
                                          @y-in-the-emptyset |
                                            member(y, emptyset)
                                            [by rewrite the-intersection-is-empty y-in-the-intersection]
                                          @conclusion-blocks-coincide |
                                            s = t
                                            [by ex_falso y-in-the-emptyset nothing-is-in-the-emptyset]
                                        }
                                      @distinctness-is-absurd |
                                        s != t -> s = t
                                        [by discharge given-blocks-distinct]
                                      @blocks-coincide |
                                        s = t
                                        [using tautology distinctness-is-absurd]
                                      @z-in-s |
                                        member(z, s)
                                        [by rewrite blocks-coincide z-in-t]
                                      @s-block-and-x-again |
                                        contains(s, c) and member(x, s)
                                        [by both s-is-a-block x-in-s]
                                      @s-holds-x-and-z |
                                        contains(s, c) and member(x, s) and member(z, s)
                                        [by both s-block-and-x-again z-in-s]
                                      @a-block-holds-x-and-z |
                                        exists u: Set; contains(u, c) and member(x, u) and member(z, u)
                                        [by witness(s) s-holds-x-and-z]
                                      @same-block-at-x-z |
                                        sameBlock(c, x, z) iff (exists u: Set; contains(u, c) and member(x, u) and member(z, u))
                                        [using specialize sameBlockDef(c, x, z)]
                                      @conclusion-x-shares-a-block-with-z |
                                        sameBlock(c, x, z)
                                        [using tautology same-block-at-x-z a-block-holds-x-and-z]
                                    }
                                  @conclusion-x-with-z-under-s |
                                    sameBlock(c, x, z)
                                    [by unpacked with-block-t]
                                }
                              @conclusion-x-with-z |
                                sameBlock(c, x, z)
                                [by unpacked with-block-s]
                            }
                          @y-with-z-implies-x-with-z |
                            sameBlock(c, y, z) -> sameBlock(c, x, z)
                            [by discharge given-y-with-z]
                        }
                      @transitive-at-x-y-z |
                        sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
                        [by discharge given-x-with-y]
                    }
                  @discharge-z |
                    forall z: Element; sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
                    [by generalize generalize-z]
                }
              @discharge-y |
                forall y, z: Element; sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
                [by generalize generalize-y]
            }
          @conclusion-transitive |
            forall x, y, z: Element; sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
            [by generalize generalize-x]
        }
      @partition-implies-transitive |
        isPartition(c) -> forall x, y, z: Element;
          sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
        [by discharge given-partition]
    }
  @conclusion |
    forall c: Collection; isPartition(c) -> forall x, y, z: Element;
      sameBlock(c, x, y) -> sameBlock(c, y, z) -> sameBlock(c, x, z)
    [by generalize generalize-c]
qed
```
