# Equivalence Classes and Partitions

A literate `bpa` transliteration continuing **Chapter 1 §1.2.3** of Judson's
*Abstract Algebra* — the **equivalence class / partition** material (source:
`vendor/aata/src/sets.xml`; © 1997–2026 Judson, GFDL 1.3). It builds on the
relation theory of `aata/1.2.3-relations.md`; here the equivalence **classes**
are modeled as sets. Run `bpa check aata/1.2.3-partitions.md`.

The bridge theory `std/equivalence.bpa` imports sets and relations over one
shared element sort and adds the class constructor `classOf(x) = [x] =
{ y : y ∼ x }`, fixed by `member(y, classOf(x)) ↔ related(y, x)`. With it, the
**heart** of the equivalence⟺partition theorem is provable by first-order
reasoning over membership and the relation axioms:

- each class is **nonempty** (`x ∈ [x]`, by reflexivity);
- **`[x] = [y]` iff `x ∼ y`** (the class determines the element up to ∼);
- any two classes are **equal or disjoint**.

The final *packaging* of the classes into a **partition** — a *set of sets*
$\mathcal P = \{X_i\}$ with $\bigcup_i X_i = X$ — needs one level more than
`std/set.bpa`'s flat membership: a *collection* (a set of sets). That is exactly
`std/collection.bpa`, which adds `contains(s, c)` (a `Set` is in a `Collection`),
`bigUnion(c)` (the union of every set in a collection), a `universe`, and the
`covers` / `pairwiseDisjoint` / `isPartition` predicates. With it, the packaging
goes through: the classes assemble into a **quotient** collection that covers the
universe and is pairwise-disjoint, i.e. **is a partition**.

```bpa
import eq <<< "std/equivalence.bpa"

sort Element = eq.Element
sort Set = eq.Set
const emptyset = eq.emptyset
func union = eq.union
func intersection = eq.intersection
func classOf = eq.classOf
pred member = eq.member
pred related = eq.related
define reflexive = eq.reflexive
define symmetric = eq.symmetric
define transitive = eq.transitive
define equivalence = eq.equivalence
axiom intersectionMember = eq.intersectionMember
axiom emptysetMember = eq.emptysetMember
axiom extensionality = eq.extensionality
axiom classMember = eq.classMember
```

## The equivalence classes form a partition

> **Theorem.** Given an equivalence relation $\sim$ on a set $X$, the equivalence
> classes of $X$ form a partition of $X$. Conversely, if $\mathcal P = \{X_i\}$
> is a partition of $X$, then there is an equivalence relation on $X$ with
> equivalence classes $X_i$.

We prove the first-order-tractable heart of the forward direction. First, each
class contains its own generator, so classes are nonempty.

```bpa
theorem classContainsElement: equivalence -> forall x: Element; member(x, classOf(x))
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_elim_left all-three]
      @all-self-related |
        reflexive
        [by and_elim_left reflexive-and-symmetric]
      @every-element-in-its-class |
        fix x: Element {
          @x-self-related |
            related(x, x)
            [by forall_elim(x) all-self-related]
          @class-membership |
            forall a: Element; forall b: Element;
              (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
            [by cite classMember]
          @membership-at |
            (member(x, classOf(x)) -> related(x, x)) and (related(x, x) -> member(x, classOf(x)))
            [by forall_elim(x, x) class-membership]
          @related-gives-member |
            related(x, x) -> member(x, classOf(x))
            [by and_elim_right membership-at]
          @x-in-its-class |
            member(x, classOf(x))
            [by modus_ponens related-gives-member x-self-related]
        }
      @conclusion-all |
        forall x: Element; member(x, classOf(x))
        [by forall_intro every-element-in-its-class]
    }
  @conclusion |
    equivalence -> forall x: Element; member(x, classOf(x))
    [by implies_intro given-equivalence]
qed
```

Next, the key lemma: two elements are equivalent exactly when their classes
coincide. (Proof to fill: `x ∼ y` gives `[x] = [y]` by extensionality — for any
`z`, `z ∼ x ⟺ z ∼ y` by symmetry and transitivity; conversely `[x] = [y]` puts
`x ∈ [y]`, i.e. `x ∼ y`.)

```bpa
theorem classesEqualIffRelated:
  equivalence -> forall x, y: Element;
  related(x, y) iff classOf(x) = classOf(y)
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_elim_left all-three]
      @symmetry-holds |
        symmetric
        [by and_elim_right reflexive-and-symmetric]
      @transitivity-holds |
        transitive
        [by and_elim_right all-three]
      @class-membership |
        forall a: Element; forall b: Element;
          (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
        [by cite classMember]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement all-three]
      @generalize-x |
        fix x: Element {
          @generalize-y |
            fix y: Element {
              @given-x-related-y |
                assume related(x, y) {
                  @x-related-y |
                    related(x, y)
                    [by hypothesis given-x-related-y]
                  @y-related-x |
                    related(y, x)
                    [using specialize symmetry-holds(x, y) x-related-y]
                  @class-x-included-in-class-y |
                    fix z: Element {
                      @given-z-in-class-x |
                        assume member(z, classOf(x)) {
                          @z-in-class-x |
                            member(z, classOf(x))
                            [by hypothesis given-z-in-class-x]
                          @class-membership-x-z |
                            (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                            [by forall_elim(x, z) class-membership]
                          @z-in-class-x-gives-z-related-x |
                            member(z, classOf(x)) -> related(z, x)
                            [by and_elim_left class-membership-x-z]
                          @z-related-x |
                            related(z, x)
                            [by modus_ponens z-in-class-x-gives-z-related-x z-in-class-x]
                          @transitivity-at-z-x-y |
                            related(z, x) -> related(x, y) -> related(z, y)
                            [by forall_elim(z, x, y) transitivity-holds]
                          @z-related-y |
                            related(z, y)
                            [using tautology transitivity-at-z-x-y z-related-x x-related-y]
                          @class-membership-y-z |
                            (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                            [by forall_elim(y, z) class-membership]
                          @z-related-y-gives-z-in-class-y |
                            related(z, y) -> member(z, classOf(y))
                            [by and_elim_right class-membership-y-z]
                          @z-in-class-y |
                            member(z, classOf(y))
                            [by modus_ponens z-related-y-gives-z-in-class-y z-related-y]
                        }
                      @z-in-class-x-gives-z-in-class-y |
                        member(z, classOf(x)) -> member(z, classOf(y))
                        [by implies_intro given-z-in-class-x]
                    }
                  @class-x-subset-class-y |
                    forall z: Element; member(z, classOf(x)) -> member(z, classOf(y))
                    [by forall_intro class-x-included-in-class-y]
                  @class-y-included-in-class-x |
                    fix z: Element {
                      @given-z-in-class-y |
                        assume member(z, classOf(y)) {
                          @z-in-class-y |
                            member(z, classOf(y))
                            [by hypothesis given-z-in-class-y]
                          @class-membership-y-z |
                            (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                            [by forall_elim(y, z) class-membership]
                          @z-in-class-y-gives-z-related-y |
                            member(z, classOf(y)) -> related(z, y)
                            [by and_elim_left class-membership-y-z]
                          @z-related-y |
                            related(z, y)
                            [by modus_ponens z-in-class-y-gives-z-related-y z-in-class-y]
                          @transitivity-at-z-y-x |
                            related(z, y) -> related(y, x) -> related(z, x)
                            [by forall_elim(z, y, x) transitivity-holds]
                          @z-related-x |
                            related(z, x)
                            [using tautology transitivity-at-z-y-x z-related-y y-related-x]
                          @class-membership-x-z |
                            (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                            [by forall_elim(x, z) class-membership]
                          @z-related-x-gives-z-in-class-x |
                            related(z, x) -> member(z, classOf(x))
                            [by and_elim_right class-membership-x-z]
                          @z-in-class-x |
                            member(z, classOf(x))
                            [by modus_ponens z-related-x-gives-z-in-class-x z-related-x]
                        }
                      @z-in-class-y-gives-z-in-class-x |
                        member(z, classOf(y)) -> member(z, classOf(x))
                        [by implies_intro given-z-in-class-y]
                    }
                  @class-y-subset-class-x |
                    forall z: Element; member(z, classOf(y)) -> member(z, classOf(x))
                    [by forall_intro class-y-included-in-class-x]
                  @classes-are-equal |
                    classOf(x) = classOf(y)
                    [using specialize extensionality(classOf(x), classOf(y)) class-x-subset-class-y class-y-subset-class-x]
                }
              @related-gives-classes-equal |
                related(x, y) -> classOf(x) = classOf(y)
                [by implies_intro given-x-related-y]
              @given-classes-equal |
                assume classOf(x) = classOf(y) {
                  @classes-equal |
                    classOf(x) = classOf(y)
                    [by hypothesis given-classes-equal]
                  @x-in-class-x |
                    member(x, classOf(x))
                    [by forall_elim(x) every-element-in-its-class]
                  @x-in-class-y |
                    member(x, classOf(y))
                    [by rewrite classes-equal x-in-class-x]
                  @class-membership-y-x |
                    (member(x, classOf(y)) -> related(x, y)) and (related(x, y) -> member(x, classOf(y)))
                    [by forall_elim(y, x) class-membership]
                  @x-in-class-y-gives-x-related-y |
                    member(x, classOf(y)) -> related(x, y)
                    [by and_elim_left class-membership-y-x]
                  @x-related-y |
                    related(x, y)
                    [by modus_ponens x-in-class-y-gives-x-related-y x-in-class-y]
                }
              @classes-equal-gives-related |
                classOf(x) = classOf(y) -> related(x, y)
                [by implies_intro given-classes-equal]
              @equal-iff-related-at-x-y |
                related(x, y) iff classOf(x) = classOf(y)
                [by iff_intro related-gives-classes-equal classes-equal-gives-related]
            }
          @equal-iff-related-for-all-y |
            forall y: Element;
              related(x, y) iff classOf(x) = classOf(y)
            [by forall_intro generalize-y]
        }
      @equal-iff-related |
        forall x, y: Element;
          related(x, y) iff classOf(x) = classOf(y)
        [by forall_intro generalize-x]
    }
  @conclusion |
    equivalence -> forall x, y: Element;
      related(x, y) iff classOf(x) = classOf(y)
    [by implies_intro given-equivalence]
qed
```

And the heart of the partition property: any two classes are equal or disjoint.
(Proof to fill: if some `z ∈ [x] ∩ [y]` then `z ∼ x` and `z ∼ y`, so `x ∼ y`,
so `[x] = [y]` by the lemma; otherwise the intersection is empty.)

```bpa
theorem classesEqualOrDisjoint:
  equivalence -> forall x, y: Element;
  classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_elim_left all-three]
      @symmetry-holds |
        symmetric
        [by and_elim_right reflexive-and-symmetric]
      @transitivity-holds |
        transitive
        [by and_elim_right all-three]
      @class-membership |
        forall a: Element; forall b: Element;
          (member(b, classOf(a)) -> related(b, a)) and (related(b, a) -> member(b, classOf(a)))
        [by cite classMember]
      @intersection-membership |
        forall a, b: Set; forall z: Element;
          (member(z, intersection(a, b)) -> (member(z, a) and member(z, b)))
          and ((member(z, a) and member(z, b)) -> member(z, intersection(a, b)))
        [by cite intersectionMember]
      @empty-membership |
        forall z: Element; not member(z, emptyset)
        [by cite emptysetMember]
      @equal-iff-related-holds |
        forall x, y: Element;
          related(x, y) iff classOf(x) = classOf(y)
        [using specialize classesEqualIffRelated all-three]
      @generalize-x |
        fix x: Element {
          @generalize-y |
            fix y: Element {
              @related-or-not |
                related(x, y) or (not related(x, y))
                [using tautology]
              @equal-or-disjoint-at-x-y |
                classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                case related-or-not {
                  @when-related |
                    assume related(x, y) {
                      @x-related-y |
                        related(x, y)
                        [by hypothesis when-related]
                      @equal-iff-related-at-x-y |
                        related(x, y) iff classOf(x) = classOf(y)
                        [by forall_elim(x, y) equal-iff-related-holds]
                      @related-gives-classes-equal |
                        related(x, y) -> classOf(x) = classOf(y)
                        [by iff_elim_forward equal-iff-related-at-x-y]
                      @classes-are-equal |
                        classOf(x) = classOf(y)
                        [by modus_ponens related-gives-classes-equal x-related-y]
                      @equal-or-disjoint |
                        classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                        [by or_intro_left classes-are-equal]
                    }
                  @when-not-related |
                    assume not related(x, y) {
                      @x-not-related-y |
                        not related(x, y)
                        [by hypothesis when-not-related]
                      @intersection-included-in-empty |
                        fix z: Element {
                          @given-z-in-intersection |
                            assume member(z, intersection(classOf(x), classOf(y))) {
                              @z-in-intersection |
                                member(z, intersection(classOf(x), classOf(y)))
                                [by hypothesis given-z-in-intersection]
                              @intersection-membership-at |
                                (member(z, intersection(classOf(x), classOf(y))) -> (member(z, classOf(x)) and member(z, classOf(y))))
                                  and ((member(z, classOf(x)) and member(z, classOf(y))) -> member(z, intersection(classOf(x), classOf(y))))
                                [by forall_elim(classOf(x), classOf(y), z) intersection-membership]
                              @z-in-intersection-gives-both |
                                member(z, intersection(classOf(x), classOf(y))) -> (member(z, classOf(x)) and member(z, classOf(y)))
                                [by and_elim_left intersection-membership-at]
                              @z-in-both-classes |
                                member(z, classOf(x)) and member(z, classOf(y))
                                [by modus_ponens z-in-intersection-gives-both z-in-intersection]
                              @z-in-class-x |
                                member(z, classOf(x))
                                [by and_elim_left z-in-both-classes]
                              @z-in-class-y |
                                member(z, classOf(y))
                                [by and_elim_right z-in-both-classes]
                              @class-membership-x-z |
                                (member(z, classOf(x)) -> related(z, x)) and (related(z, x) -> member(z, classOf(x)))
                                [by forall_elim(x, z) class-membership]
                              @z-in-class-x-gives-z-related-x |
                                member(z, classOf(x)) -> related(z, x)
                                [by and_elim_left class-membership-x-z]
                              @z-related-x |
                                related(z, x)
                                [by modus_ponens z-in-class-x-gives-z-related-x z-in-class-x]
                              @class-membership-y-z |
                                (member(z, classOf(y)) -> related(z, y)) and (related(z, y) -> member(z, classOf(y)))
                                [by forall_elim(y, z) class-membership]
                              @z-in-class-y-gives-z-related-y |
                                member(z, classOf(y)) -> related(z, y)
                                [by and_elim_left class-membership-y-z]
                              @z-related-y |
                                related(z, y)
                                [by modus_ponens z-in-class-y-gives-z-related-y z-in-class-y]
                              @x-related-z |
                                related(x, z)
                                [using specialize symmetry-holds(z, x) z-related-x]
                              @transitivity-at-x-z-y |
                                related(x, z) -> related(z, y) -> related(x, y)
                                [by forall_elim(x, z, y) transitivity-holds]
                              @x-related-y |
                                related(x, y)
                                [using tautology transitivity-at-x-z-y x-related-z z-related-y]
                              @z-in-empty |
                                member(z, emptyset)
                                [by absurd x-related-y x-not-related-y]
                            }
                          @z-in-intersection-gives-z-in-empty |
                            member(z, intersection(classOf(x), classOf(y))) -> member(z, emptyset)
                            [by implies_intro given-z-in-intersection]
                        }
                      @intersection-subset-empty |
                        forall z: Element; member(z, intersection(classOf(x), classOf(y))) -> member(z, emptyset)
                        [by forall_intro intersection-included-in-empty]
                      @empty-included-in-intersection |
                        fix z: Element {
                          @given-z-in-empty |
                            assume member(z, emptyset) {
                              @z-in-empty |
                                member(z, emptyset)
                                [by hypothesis given-z-in-empty]
                              @z-not-in-empty |
                                not member(z, emptyset)
                                [by forall_elim(z) empty-membership]
                              @z-in-intersection |
                                member(z, intersection(classOf(x), classOf(y)))
                                [by absurd z-in-empty z-not-in-empty]
                            }
                          @z-in-empty-gives-z-in-intersection |
                            member(z, emptyset) -> member(z, intersection(classOf(x), classOf(y)))
                            [by implies_intro given-z-in-empty]
                        }
                      @empty-subset-intersection |
                        forall z: Element; member(z, emptyset) -> member(z, intersection(classOf(x), classOf(y)))
                        [by forall_intro empty-included-in-intersection]
                      @intersection-is-empty |
                        intersection(classOf(x), classOf(y)) = emptyset
                        [using specialize extensionality(intersection(classOf(x), classOf(y)), emptyset) intersection-subset-empty empty-subset-intersection]
                      @equal-or-disjoint |
                        classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
                        [by or_intro_right intersection-is-empty]
                    }
                }
            }
          @equal-or-disjoint-for-all-y |
            forall y: Element;
              classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
            [by forall_intro generalize-y]
        }
      @equal-or-disjoint |
        forall x, y: Element;
          classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
        [by forall_intro generalize-x]
    }
  @conclusion |
    equivalence -> forall x, y: Element;
      classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
    [by implies_intro given-equivalence]
qed
```

## The classes form a partition

To *package* the classes we move up one level, to `std/collection.bpa`, whose
`Collection` is a set of `Set`s (over the same shared `Element` sort). It adds
the union-of-a-collection `bigUnion`, a `universe` every element belongs to, and
the `covers` / `pairwiseDisjoint` / `isPartition` predicates a partition needs.

```bpa
import coll <<< "std/collection.bpa"

sort Collection = coll.Collection
pred contains = coll.contains
func bigUnion = coll.bigUnion
const universe = coll.universe
define covers(c: Collection) = coll.covers(c)
define pairwiseDisjoint(c: Collection) = coll.pairwiseDisjoint(c)
define isPartition(c: Collection) = coll.isPartition(c)
axiom bigUnionMember = coll.bigUnionMember
axiom universeMember = coll.universeMember
```

The **quotient** is the collection $\mathcal P = \{[x] : x \in X\}$ — the set of
all equivalence classes. We name it `quotient` and fix its members by a single
definitional axiom: a set is *in* the quotient exactly when it *is* some class
$[x]$. This is honest — it just names the set-builder $\{[x] : x \in X\}$; it
adds no fact about `classOf` beyond "the quotient's members are the classes".

```bpa
const quotient: Collection
axiom quotientContains: forall s: Set;
  contains(s, quotient) iff (exists x: Element; s = classOf(x))
```

**The classes cover the universe.** Every element `z` lives in its own class
`[z]` (by reflexivity, `classContainsElement`), and `[z]` is a member of the
quotient (`quotientContains` with `x = z`); so `z` belongs to some member set of
the quotient, i.e. `z ∈ ⋃quotient`. Conversely everything is in the universe. By
set extensionality `⋃quotient = universe`, which is by definition `covers`.

```bpa
theorem classesCover: equivalence -> covers(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; s = classOf(x))
        [by cite quotientContains]
      @big-union-membership |
        forall c: Collection; forall x: Element;
          member(x, bigUnion(c)) iff (exists s: Set; contains(s, c) and member(x, s))
        [by cite bigUnionMember]
      @every-element-in-universe |
        forall x: Element; member(x, universe)
        [by cite universeMember]
      // big-union of the classes ⊆ universe: everything is in the universe.
      @big-union-included-in-universe |
        fix z: Element {
          @given-z-in-big-union |
            assume member(z, bigUnion(quotient)) {
              @z-in-universe |
                member(z, universe)
                [by forall_elim(z) every-element-in-universe]
            }
          @z-in-big-union-gives-z-in-universe |
            member(z, bigUnion(quotient)) -> member(z, universe)
            [by implies_intro given-z-in-big-union]
        }
      @big-union-subset-universe |
        forall z: Element; member(z, bigUnion(quotient)) -> member(z, universe)
        [by forall_intro big-union-included-in-universe]
      // universe ⊆ big-union: z lives in its own class [z], and [z] ∈ quotient.
      @universe-included-in-big-union |
        fix z: Element {
          @given-z-in-universe |
            assume member(z, universe) {
              @z-in-its-class |
                member(z, classOf(z))
                [by forall_elim(z) every-element-in-its-class]
              @class-of-z-reflexive |
                classOf(z) = classOf(z)
                [by reflexivity]
              @class-of-z-is-a-class |
                exists x: Element; classOf(z) = classOf(x)
                [by exists_intro(z) class-of-z-reflexive]
              @quotient-membership-at-class-of-z |
                contains(classOf(z), quotient) iff (exists x: Element; classOf(z) = classOf(x))
                [by forall_elim(classOf(z)) quotient-members-are-classes]
              @class-being-a-class-gives-quotient-membership |
                (exists x: Element; classOf(z) = classOf(x)) -> contains(classOf(z), quotient)
                [by iff_elim_backward quotient-membership-at-class-of-z]
              @class-of-z-in-quotient |
                contains(classOf(z), quotient)
                [by modus_ponens class-being-a-class-gives-quotient-membership class-of-z-is-a-class]
              @class-of-z-witnesses-membership |
                contains(classOf(z), quotient) and member(z, classOf(z))
                [by and_intro class-of-z-in-quotient z-in-its-class]
              @some-class-contains-z |
                exists s: Set; contains(s, quotient) and member(z, s)
                [by exists_intro(classOf(z)) class-of-z-witnesses-membership]
              @big-union-membership-at-z |
                member(z, bigUnion(quotient)) iff (exists s: Set; contains(s, quotient) and member(z, s))
                [by forall_elim(quotient, z) big-union-membership]
              @witness-gives-big-union-membership |
                (exists s: Set; contains(s, quotient) and member(z, s)) -> member(z, bigUnion(quotient))
                [by iff_elim_backward big-union-membership-at-z]
              @z-in-big-union |
                member(z, bigUnion(quotient))
                [by modus_ponens witness-gives-big-union-membership some-class-contains-z]
            }
          @z-in-universe-gives-z-in-big-union |
            member(z, universe) -> member(z, bigUnion(quotient))
            [by implies_intro given-z-in-universe]
        }
      @universe-subset-big-union |
        forall z: Element; member(z, universe) -> member(z, bigUnion(quotient))
        [by forall_intro universe-included-in-big-union]
      @quotient-covers |
        bigUnion(quotient) = universe
        [using specialize extensionality(bigUnion(quotient), universe) big-union-subset-universe universe-subset-big-union]
    }
  @conclusion |
    equivalence -> covers(quotient)
    [by implies_intro given-equivalence]
qed
```

**The classes are pairwise-disjoint.** Two distinct members `s, t` of the
quotient are classes `s = [a]`, `t = [b]` (`quotientContains`). By the
equal-or-disjoint lemma, either `[a] = [b]` — impossible, since that would make
`s = t` — or `[a] ∩ [b]` is empty; rewriting back through `s = [a]`, `t = [b]`
gives `s ∩ t = ∅`. That is by definition `pairwiseDisjoint`.

```bpa
theorem classesDisjoint: equivalence -> pairwiseDisjoint(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @equal-or-disjoint-holds |
        forall x, y: Element;
          classOf(x) = classOf(y) or intersection(classOf(x), classOf(y)) = emptyset
        [using specialize classesEqualOrDisjoint equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; s = classOf(x))
        [by cite quotientContains]
      @distinct-classes-are-disjoint |
        fix s: Set {
          @distinct-from-s-are-disjoint |
            fix t: Set {
              @given-s-in-quotient |
                assume contains(s, quotient) {
                  @given-t-in-quotient |
                    assume contains(t, quotient) {
                      @given-s-not-t |
                        assume s != t {
                          @s-not-t |
                            s != t
                            [by hypothesis given-s-not-t]
                          @s-in-quotient |
                            contains(s, quotient)
                            [by hypothesis given-s-in-quotient]
                          @t-in-quotient |
                            contains(t, quotient)
                            [by hypothesis given-t-in-quotient]
                          @quotient-membership-at-s |
                            contains(s, quotient) iff (exists x: Element; s = classOf(x))
                            [by forall_elim(s) quotient-members-are-classes]
                          @s-in-quotient-gives-class |
                            contains(s, quotient) -> exists x: Element; s = classOf(x)
                            [by iff_elim_forward quotient-membership-at-s]
                          @s-is-some-class |
                            exists x: Element; s = classOf(x)
                            [by modus_ponens s-in-quotient-gives-class s-in-quotient]
                          @quotient-membership-at-t |
                            contains(t, quotient) iff (exists x: Element; t = classOf(x))
                            [by forall_elim(t) quotient-members-are-classes]
                          @t-in-quotient-gives-class |
                            contains(t, quotient) -> exists x: Element; t = classOf(x)
                            [by iff_elim_forward quotient-membership-at-t]
                          @t-is-some-class |
                            exists x: Element; t = classOf(x)
                            [by modus_ponens t-in-quotient-gives-class t-in-quotient]
                          @with-generator-a |
                            unpack a: Element from s-is-some-class {
                              @s-is-class-of-a |
                                s = classOf(a)
                                [by hypothesis with-generator-a]
                              @with-generator-b |
                                unpack b: Element from t-is-some-class {
                                  @t-is-class-of-b |
                                    t = classOf(b)
                                    [by hypothesis with-generator-b]
                                  @equal-or-disjoint-at-a-b |
                                    classOf(a) = classOf(b) or intersection(classOf(a), classOf(b)) = emptyset
                                    [by forall_elim(a, b) equal-or-disjoint-holds]
                                  @intersection-is-empty |
                                    intersection(s, t) = emptyset
                                    case equal-or-disjoint-at-a-b {
                                      @when-classes-equal |
                                        assume classOf(a) = classOf(b) {
                                          // s = [a] = [b] = t contradicts s ≠ t.
                                          @classes-equal |
                                            classOf(a) = classOf(b)
                                            [by hypothesis when-classes-equal]
                                          @s-equals-t |
                                            s = t
                                            [using chain s-is-class-of-a classes-equal t-is-class-of-b]
                                          @intersection-empty-by-contradiction |
                                            intersection(s, t) = emptyset
                                            [by absurd s-equals-t s-not-t]
                                        }
                                      @when-classes-disjoint |
                                        assume intersection(classOf(a), classOf(b)) = emptyset {
                                          // rewrite the empty intersection back onto s and t.
                                          @classes-disjoint |
                                            intersection(classOf(a), classOf(b)) = emptyset
                                            [by hypothesis when-classes-disjoint]
                                          @intersection-empty-rewritten |
                                            intersection(s, t) = emptyset
                                            [using chain classes-disjoint s-is-class-of-a t-is-class-of-b]
                                        }
                                    }
                                }
                              @intersection-is-empty-exported-b |
                                intersection(s, t) = emptyset
                                [by exists_elim with-generator-b]
                            }
                          @intersection-is-empty-exported |
                            intersection(s, t) = emptyset
                            [by exists_elim with-generator-a]
                        }
                      @distinct-gives-disjoint |
                        s != t -> intersection(s, t) = emptyset
                        [by implies_intro given-s-not-t]
                    }
                  @t-in-quotient-gives-disjoint |
                    contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
                    [by implies_intro given-t-in-quotient]
                }
              @s-in-quotient-gives-disjoint |
                contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
                [by implies_intro given-s-in-quotient]
            }
          @distinct-from-s-are-disjoint-for-all-t |
            forall t: Set;
              contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
            [by forall_intro distinct-from-s-are-disjoint]
        }
      @quotient-pairwise-disjoint |
        forall s, t: Set;
          contains(s, quotient) -> contains(t, quotient) -> s != t -> intersection(s, t) = emptyset
        [by forall_intro distinct-classes-are-disjoint]
    }
  @conclusion |
    equivalence -> pairwiseDisjoint(quotient)
    [by implies_intro given-equivalence]
qed
```

**The classes form a partition.** A partition (`isPartition`) is a covering,
pairwise-disjoint collection none of whose members is empty. The first two are
the theorems just proved; no class is empty because `[a]` always contains its own
generator `a` (so if `[a] = ∅` then `a ∈ ∅`, impossible). The three combine into
`isPartition(quotient)`.

```bpa
theorem classesFormPartition: equivalence -> isPartition(quotient)
proof
  @given-equivalence |
    assume equivalence {
      @equivalence |
        equivalence
        [by hypothesis given-equivalence]
      @quotient-covers |
        covers(quotient)
        [using specialize classesCover equivalence]
      @quotient-pairwise-disjoint |
        pairwiseDisjoint(quotient)
        [using specialize classesDisjoint equivalence]
      @every-element-in-its-class |
        forall x: Element; member(x, classOf(x))
        [using specialize classContainsElement equivalence]
      @quotient-members-are-classes |
        forall s: Set;
          contains(s, quotient) iff (exists x: Element; s = classOf(x))
        [by cite quotientContains]
      @empty-membership |
        forall x: Element; not member(x, emptyset)
        [by cite emptysetMember]
      // no class is empty: [a] contains its own generator a.
      @members-are-nonempty |
        fix s: Set {
          @given-s-in-quotient |
            assume contains(s, quotient) {
              @s-in-quotient |
                contains(s, quotient)
                [by hypothesis given-s-in-quotient]
              @quotient-membership-at-s |
                contains(s, quotient) iff (exists x: Element; s = classOf(x))
                [by forall_elim(s) quotient-members-are-classes]
              @s-in-quotient-gives-class |
                contains(s, quotient) -> exists x: Element; s = classOf(x)
                [by iff_elim_forward quotient-membership-at-s]
              @s-is-some-class |
                exists x: Element; s = classOf(x)
                [by modus_ponens s-in-quotient-gives-class s-in-quotient]
              @with-generator-a |
                unpack a: Element from s-is-some-class {
                  @s-is-class-of-a |
                    s = classOf(a)
                    [by hypothesis with-generator-a]
                  @a-in-its-class |
                    member(a, classOf(a))
                    [by forall_elim(a) every-element-in-its-class]
                  @a-in-s |
                    member(a, s)
                    [by rewrite s-is-class-of-a a-in-its-class]
                  @a-not-in-empty |
                    not member(a, emptyset)
                    [by forall_elim(a) empty-membership]
                  @suppose-s-empty |
                    assume s = emptyset {
                      @s-empty |
                        s = emptyset
                        [by hypothesis suppose-s-empty]
                      @a-in-empty |
                        member(a, emptyset)
                        [by rewrite s-empty a-in-s]
                    }
                  @s-nonempty |
                    s != emptyset
                    [by not_intro suppose-s-empty a-in-empty a-not-in-empty]
                }
              @s-is-nonempty |
                s != emptyset
                [by exists_elim with-generator-a]
            }
          @s-in-quotient-gives-nonempty |
            contains(s, quotient) -> s != emptyset
            [by implies_intro given-s-in-quotient]
        }
      @members-are-nonempty-for-all |
        forall s: Set; contains(s, quotient) -> s != emptyset
        [by forall_intro members-are-nonempty]
      @covers-and-disjoint |
        covers(quotient) and pairwiseDisjoint(quotient)
        [by and_intro quotient-covers quotient-pairwise-disjoint]
      @quotient-is-partition |
        covers(quotient) and pairwiseDisjoint(quotient) and (forall s: Set; contains(s, quotient) -> s != emptyset)
        [by and_intro covers-and-disjoint members-are-nonempty-for-all]
    }
  @conclusion |
    equivalence -> isPartition(quotient)
    [by implies_intro given-equivalence]
qed
```
