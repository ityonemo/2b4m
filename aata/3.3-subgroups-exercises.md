# Groups — Subgroups (Exercises)

Exercises for Judson §3.3, per `.claude/rules/aata-guide.md` — `std` used
liberally. The companion to `aata/3.3-subgroups.md`; source
`vendor/aata/src/groups.xml` (© 1997–2026 Judson, GFDL 1.3). Run
`2b4m check aata/3.3-subgroups-exercises.md`.

We reuse the main text's import header, aliasing the group `G` and its
identity/operation/inverse from `std/subgroup.b4m`, which also carries the group
axioms (associativity, the two-sided identity and inverse laws) and the subgroup
membership predicate `inH` with its three closure conditions. The provable
exercises below build a *membership predicate* for the set in question (the
center, a centralizer, a conjugate) and prove the three subgroup-criterion
conditions for it — the same pattern the main text uses for the intersection.

```2b4m
import subgroup <<< "std/subgroup.b4m"

sort G = subgroup.Grp
const e = subgroup.E

// associative with a two-sided identity and two-sided inverses).
```

## Exercises

**Exercise 34.** *Find all the subgroups of $\mathbb{Z}_3 \times \mathbb{Z}_3$,
and use them to show $\mathbb{Z}_3 \times \mathbb{Z}_3 \neq \mathbb{Z}_9$.*

**Proved (the distinguishing content); the enumeration skipped.** The direct product of
two groups is `std/group/product.b4m` (the pair sort with componentwise operation, a model
of `std/group.b4m` so its theorems transfer), instantiated at $\mathbb{Z}_n \times
\mathbb{Z}_n$ in `std/integer/mod-n-product.b4m`. What separates the two nine-element
groups is not the list of subgroups but the exponent: *every* element of $\mathbb{Z}_3
\times \mathbb{Z}_3$ satisfies $x + x + x = 0$, because each component does; whereas in
$\mathbb{Z}_9$ the class of $1$ does not ($9 \nmid 3$). No isomorphism can hold, since
$x + x + x = 0$ is preserved by any isomorphism. Listing the four proper subgroups is
finite enumeration and is **skipped**; the inequality is the mathematical content.

```2b4m
import mod_n_product <<< "std/integer/mod-n-product.b4m"

sort ZnPair = mod_n_product.ZnPair
sort Zn = mod_n_product.Zn

theorem productOfThreesIsNotTheCyclicNine: (mod_n_product.N = mod_n_product.THREE -> forall p: ZnPair; mod_n_product.znProdOp(mod_n_product.znProdOp(p, p), p) = mod_n_product.znProdE) and (mod_n_product.N = mod_n_product.NINE -> mod_n_product.add(mod_n_product.add(mod_n_product.cls(mod_n_product.IONE), mod_n_product.cls(mod_n_product.IONE)), mod_n_product.cls(mod_n_product.IONE)) != mod_n_product.ZERO)
proof
  @every-pair-cubes-to-the-identity |
    mod_n_product.N = mod_n_product.THREE -> forall p: ZnPair; mod_n_product.znProdOp(mod_n_product.znProdOp(p, p), p) = mod_n_product.znProdE
    [using import(mod_n_product) everyPairCubedIsIdentityModThree]
  @one-tripled-is-not-zero |
    mod_n_product.N = mod_n_product.NINE -> mod_n_product.add(mod_n_product.add(mod_n_product.cls(mod_n_product.IONE), mod_n_product.cls(mod_n_product.IONE)), mod_n_product.cls(mod_n_product.IONE)) != mod_n_product.ZERO
    [using import(mod_n_product) classOfOneTripledIsNotZeroModNine]
  @conclusion |
    (mod_n_product.N = mod_n_product.THREE -> forall p: ZnPair; mod_n_product.znProdOp(mod_n_product.znProdOp(p, p), p) = mod_n_product.znProdE) and (mod_n_product.N = mod_n_product.NINE -> mod_n_product.add(mod_n_product.add(mod_n_product.cls(mod_n_product.IONE), mod_n_product.cls(mod_n_product.IONE)), mod_n_product.cls(mod_n_product.IONE)) != mod_n_product.ZERO)
    [by both every-pair-cubes-to-the-identity one-tripled-is-not-zero]
qed
```

**Exercise 37.** *Let $H = \{2^k : k \in \mathbb{Z}\}$. Show that $H$ is a
subgroup of $\mathbb{Q}^*$.*

**Proved.** Integer powers $x^k$ ($k \in \mathbb{Z}$) on the reals are
`std/real/units-power.b4m`, which makes $\mathbb{R}^*$ a model of the group-power
theory, so the cyclic subgroup $\langle x \rangle = \{x^k\}$ of `std/group/generated.b4m`
transfers: it contains $1 = x^0$, and is closed under products ($x^m x^n = x^{m+n}$) and
inverses ($(x^m)^{-1} = x^{-m}$). Here $x = 2 \ne 0$. That $H$ sits inside
$\mathbb{Q}^*$ (not just $\mathbb{R}^*$) is the first conjunct: every $2^k$ is nonzero,
and rational because $\mathbb{Q} \subseteq \mathbb{R}$ (`isRational` in `std/real.b4m`)
is closed under $\cdot 2$ and $\cdot 2^{-1}$ — a two-directional induction on $k$.
```2b4m
import real <<< "std/real.b4m"
import real_units <<< "std/real/units.b4m"
import real_units_power <<< "std/real/units-power.b4m"
import integer <<< "std/integer.b4m"

sort Real = real.Real
const RZERO = real.ZERO
const RONE = real.ONE
func radd = real.add
func rmul = real.mul
func rneg = real.neg
func rrecip = real.recip
pred rless_than = real.less_than
pred isRational = real.isRational
pred nonzero = real_units.nonzero
func ipow = real_units_power.ipow
define isPowerOf(g, x) = real_units_power.isPowerOf(g, x)
define TWO = radd(RONE, RONE)
sort Int = integer.Int
const IZERO = integer.ZERO
func isucc = integer.succ
func iprev = integer.prev
func iadd = integer.add
func ineg = integer.neg
theorem intInduction = integer.induction

// 2 = 1 + 1 > 0, so 2 ≠ 0.
theorem twoIsNonzero: nonzero(TWO) and TWO != RZERO
proof
  @zero-below-one |
    rless_than(RZERO, RONE)
    [using import(real) zeroLessThanOne]
  @shifted-by-one |
    rless_than(radd(RZERO, RONE), radd(RONE, RONE))
    [using specialize real.lessThanAddRight(RZERO, RONE, RONE) zero-below-one]
  @zero-plus-one |
    radd(RZERO, RONE) = RONE
    [using specialize real.addZeroLeft(RONE)]
  @one-below-two |
    rless_than(RONE, TWO)
    [by rewrite zero-plus-one shifted-by-one]
  @zero-below-two |
    rless_than(RZERO, TWO)
    [using specialize real.lessThanTransitive(RZERO, RONE, TWO) zero-below-one one-below-two]
  @suppose-two-is-zero |
    assume TWO = RZERO {
      @two-is-zero |
        TWO = RZERO
        [by hypothesis suppose-two-is-zero]
      @two-at-most-zero |
        rless_than(TWO, RZERO) or TWO = RZERO
        [using tautology two-is-zero]
      @zero-below-itself |
        rless_than(RZERO, RZERO)
        [using specialize real.lessThanThenLessOrEqual(RZERO, TWO, RZERO) zero-below-two two-at-most-zero]
    }
  @zero-not-below-itself |
    not rless_than(RZERO, RZERO)
    [using specialize real.lessThanIrreflexive(RZERO)]
  @two-not-zero |
    TWO != RZERO
    [by contradiction suppose-two-is-zero zero-below-itself zero-not-below-itself]
  @nonzero-characterized |
    nonzero(TWO) iff TWO != RZERO
    [using specialize real_units.nonzeroCharacterization(TWO)]
  @conclusion |
    nonzero(TWO) and TWO != RZERO
    [using tautology nonzero-characterized two-not-zero]
qed

// every power of 2 is rational: 1 is, and each step multiplies by 2 or by 1/2.
theorem powersOfTwoAreRational: forall k: Int; isRational(ipow(TWO, k))
proof
  @one-rational |
    isRational(RONE)
    [using import(real) isRationalOne]
  @two-rational |
    isRational(TWO)
    [using specialize real.isRationalAdd(RONE, RONE) one-rational one-rational]
  @two-facts |
    nonzero(TWO) and TWO != RZERO
    [by cite twoIsNonzero]
  @two-not-zero |
    TWO != RZERO
    [by and_rhs two-facts]
  @half-rational |
    isRational(rrecip(TWO))
    [using specialize real.isRationalRecip(TWO) two-rational two-not-zero]
  @zeroth-power |
    ipow(TWO, IZERO) = RONE
    [using specialize real_units_power.ipowZero(TWO)]
  @base-case |
    isRational(ipow(TWO, IZERO))
    [by rewrite zeroth-power one-rational]
  @step-up |
    fix k2: Int {
      @given-power-rational |
        assume isRational(ipow(TWO, k2)) {
          @power-rational |
            isRational(ipow(TWO, k2))
            [by hypothesis given-power-rational]
          @next-unfolds |
            ipow(TWO, isucc(k2)) = rmul(ipow(TWO, k2), TWO)
            [using specialize real_units_power.ipowSucc(TWO, k2)]
          @product-rational |
            isRational(rmul(ipow(TWO, k2), TWO))
            [using specialize real.isRationalMul(ipow(TWO, k2), TWO) power-rational two-rational]
          @conclusion-next-rational |
            isRational(ipow(TWO, isucc(k2)))
            [by rewrite next-unfolds product-rational]
        }
      @conclusion-step-up |
        isRational(ipow(TWO, k2)) -> isRational(ipow(TWO, isucc(k2)))
        [by discharge given-power-rational]
    }
  @step-up-for-all |
    forall k2: Int; isRational(ipow(TWO, k2)) -> isRational(ipow(TWO, isucc(k2)))
    [by generalize step-up]
  @step-down |
    fix k2: Int {
      @given-power-rational |
        assume isRational(ipow(TWO, k2)) {
          @power-rational |
            isRational(ipow(TWO, k2))
            [by hypothesis given-power-rational]
          @previous-unfolds |
            ipow(TWO, iprev(k2)) = rmul(ipow(TWO, k2), rrecip(TWO))
            [using specialize real_units_power.ipowPrev(TWO, k2)]
          @product-rational |
            isRational(rmul(ipow(TWO, k2), rrecip(TWO)))
            [using specialize real.isRationalMul(ipow(TWO, k2), rrecip(TWO)) power-rational half-rational]
          @conclusion-previous-rational |
            isRational(ipow(TWO, iprev(k2)))
            [by rewrite previous-unfolds product-rational]
        }
      @conclusion-step-down |
        isRational(ipow(TWO, k2)) -> isRational(ipow(TWO, iprev(k2)))
        [by discharge given-power-rational]
    }
  @step-down-for-all |
    forall k2: Int; isRational(ipow(TWO, k2)) -> isRational(ipow(TWO, iprev(k2)))
    [by generalize step-down]
  @conclusion |
    forall k: Int; isRational(ipow(TWO, k))
    [using instantiation intInduction((fun k: Int => isRational(ipow(TWO, k)))) base-case step-up-for-all step-down-for-all]
qed

// EXERCISE 37: H = {2^k} lies in ℚ* and is a subgroup — 1 ∈ H, closed under products and
// inverses (the cyclic-subgroup theorems of ℝ*, at g = 2).
theorem powersOfTwoFormASubgroup: (forall x: Real; isPowerOf(TWO, x) -> (nonzero(x) and isRational(x))) and isPowerOf(TWO, RONE) and (forall x, y: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))) and (forall x: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, rrecip(x)))
proof
  @two-facts |
    nonzero(TWO) and TWO != RZERO
    [by cite twoIsNonzero]
  @two-nonzero |
    nonzero(TWO)
    [by and_lhs two-facts]
  // every member is a nonzero rational.
  @generalize-member |
    fix x: Real {
      @given-power |
        assume isPowerOf(TWO, x) {
          @is-a-power |
            exists k: Int; x = ipow(TWO, k)
            [by hypothesis given-power]
          @with-exponent-k |
            unpack k: Int from is-a-power {
              @x-is-power |
                x = ipow(TWO, k)
                [by hypothesis with-exponent-k]
              @power-nonzero |
                nonzero(ipow(TWO, k))
                [using specialize real_units_power.ipowIsNonzero(TWO, k) two-nonzero]
              @power-rational |
                isRational(ipow(TWO, k))
                [using specialize powersOfTwoAreRational(k)]
              @x-nonzero |
                nonzero(x)
                [by rewrite x-is-power power-nonzero]
              @x-rational |
                isRational(x)
                [by rewrite x-is-power power-rational]
              @conclusion-x-is-a-nonzero-rational |
                nonzero(x) and isRational(x)
                [using tautology x-nonzero x-rational]
            }
          @conclusion-member-is-a-nonzero-rational |
            nonzero(x) and isRational(x)
            [by unpacked with-exponent-k]
        }
      @power-implies-nonzero-rational |
        isPowerOf(TWO, x) -> (nonzero(x) and isRational(x))
        [by discharge given-power]
    }
  @members-are-nonzero-rationals |
    forall x: Real; isPowerOf(TWO, x) -> (nonzero(x) and isRational(x))
    [by generalize generalize-member]
  @one-is-a-power |
    isPowerOf(TWO, RONE)
    [using specialize real_units_power.powersContainOne(TWO) two-nonzero]
  // closure under products.
  @generalize-x |
    fix x: Real {
      @generalize-y |
        fix y: Real {
          @given-x-power |
            assume isPowerOf(TWO, x) {
              @given-y-power |
                assume isPowerOf(TWO, y) {
                  @x-power |
                    isPowerOf(TWO, x)
                    [by hypothesis given-x-power]
                  @y-power |
                    isPowerOf(TWO, y)
                    [by hypothesis given-y-power]
                  @x-facts |
                    nonzero(x) and isRational(x)
                    [using specialize members-are-nonzero-rationals(x) x-power]
                  @y-facts |
                    nonzero(y) and isRational(y)
                    [using specialize members-are-nonzero-rationals(y) y-power]
                  @x-nonzero |
                    nonzero(x)
                    [by and_lhs x-facts]
                  @y-nonzero |
                    nonzero(y)
                    [by and_lhs y-facts]
                  @conclusion-product-is-a-power |
                    isPowerOf(TWO, rmul(x, y))
                    [using specialize real_units_power.powersClosedUnderProduct(TWO, x, y) two-nonzero x-nonzero y-nonzero x-power y-power]
                }
              @y-power-implies |
                isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))
                [by discharge given-y-power]
            }
          @x-power-implies |
            isPowerOf(TWO, x) -> isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))
            [by discharge given-x-power]
        }
      @discharge-y |
        forall y: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))
        [by generalize generalize-y]
    }
  @closed-under-product |
    forall x, y: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))
    [by generalize generalize-x]
  // closure under inverses.
  @generalize-z |
    fix z: Real {
      @given-z-power |
        assume isPowerOf(TWO, z) {
          @z-power |
            isPowerOf(TWO, z)
            [by hypothesis given-z-power]
          @z-facts |
            nonzero(z) and isRational(z)
            [using specialize members-are-nonzero-rationals(z) z-power]
          @z-nonzero |
            nonzero(z)
            [by and_lhs z-facts]
          @conclusion-inverse-is-a-power |
            isPowerOf(TWO, rrecip(z))
            [using specialize real_units_power.powersClosedUnderRecip(TWO, z) two-nonzero z-nonzero z-power]
        }
      @z-power-implies |
        isPowerOf(TWO, z) -> isPowerOf(TWO, rrecip(z))
        [by discharge given-z-power]
    }
  @closed-under-inverse |
    forall x: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, rrecip(x))
    [by generalize generalize-z]
  @conclusion |
    (forall x: Real; isPowerOf(TWO, x) -> (nonzero(x) and isRational(x))) and isPowerOf(TWO, RONE) and (forall x, y: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, y) -> isPowerOf(TWO, rmul(x, y))) and (forall x: Real; isPowerOf(TWO, x) -> isPowerOf(TWO, rrecip(x)))
    [using tautology members-are-nonzero-rationals one-is-a-power closed-under-product closed-under-inverse]
qed
```

**Exercise 39.** *Let $\mathbb{T} = \{z \in \mathbb{C}^* : |z| = 1\}$. Prove
that $\mathbb{T}$ is a subgroup of $\mathbb{C}^*$ (the circle group).*

**Proved.** Membership is $|z|^2 = 1$ (`onCircle` in `std/complex/polar.b4m`, stated
with the norm-square $\mathrm{re}(z)^2 + \mathrm{im}(z)^2$ so no square root is
needed). The three subgroup conditions are the circle theorems of that file: $1$ is on
the circle, $|zw|^2 = |z|^2|w|^2 = 1$, and $|z^{-1}|^2 = 1/|z|^2 = 1$. That $\mathbb{T}
\subseteq \mathbb{C}^*$ is the fourth conjunct: $|0|^2 = 0 \ne 1$, so nothing on the
circle is zero.
```2b4m
import complex <<< "std/complex.b4m"
import complex_modulus <<< "std/complex/modulus.b4m"
import complex_polar <<< "std/complex/polar.b4m"

sort Complex = complex.Complex
const CZERO = complex.ZERO
const CONE = complex.ONE
func cmul = complex.mul
func crecip = complex.recip
func re = complex.re
func im = complex.im
func fromReal = complex.fromReal
define normSq(z) = complex_modulus.normSq(z)
define onCircle(z) = complex_polar.onCircle(z)

theorem circleGroupIsASubgroup: onCircle(CONE) and (forall z, w: Complex; onCircle(z) -> onCircle(w) -> onCircle(cmul(z, w))) and (forall z: Complex; onCircle(z) -> onCircle(crecip(z))) and (forall z: Complex; onCircle(z) -> z != CZERO)
proof
  @one-on-circle |
    onCircle(CONE)
    [using import(complex_polar) circleHasOne]
  @closed-under-product |
    forall z, w: Complex; onCircle(z) -> onCircle(w) -> onCircle(cmul(z, w))
    [using import(complex_polar) circleClosedUnderProduct]
  @closed-under-inverse |
    forall z: Complex; onCircle(z) -> onCircle(crecip(z))
    [using import(complex_polar) circleClosedUnderInverse]

  // |0|² = 0: both parts of 0 = fromReal(0) vanish.
  @zero-embeds |
    fromReal(RZERO) = CZERO
    [using import(complex) fromRealZero]
  @re-of-embedded-zero |
    re(fromReal(RZERO)) = RZERO
    [using specialize complex.reOfReal(RZERO)]
  @im-of-embedded-zero |
    im(fromReal(RZERO)) = RZERO
    [using specialize complex.imOfReal(RZERO)]
  @re-of-zero |
    re(CZERO) = RZERO
    [by rewrite zero-embeds re-of-embedded-zero]
  @im-of-zero |
    im(CZERO) = RZERO
    [by rewrite zero-embeds im-of-embedded-zero]
  @zero-times-zero |
    rmul(RZERO, RZERO) = RZERO
    [using specialize real.mulZeroLeft(RZERO)]
  @re-square-of-zero |
    rmul(re(CZERO), re(CZERO)) = RZERO
    [by rewrite re-of-zero zero-times-zero]
  @im-square-of-zero |
    rmul(im(CZERO), im(CZERO)) = RZERO
    [by rewrite im-of-zero zero-times-zero]
  @norm-sq-of-zero-reflexive |
    normSq(CZERO) = normSq(CZERO)
    [by reflexivity]
  @im-square-dropped |
    normSq(CZERO) = radd(rmul(re(CZERO), re(CZERO)), RZERO)
    [by rewrite im-square-of-zero norm-sq-of-zero-reflexive]
  @plus-zero |
    radd(rmul(re(CZERO), re(CZERO)), RZERO) = rmul(re(CZERO), re(CZERO))
    [using specialize real.addZeroRight(rmul(re(CZERO), re(CZERO)))]
  @norm-sq-of-zero |
    normSq(CZERO) = RZERO
    [using chain im-square-dropped plus-zero re-square-of-zero]
  @zero-is-norm-sq-of-zero |
    RZERO = normSq(CZERO)
    [by symmetry norm-sq-of-zero]
  @one-not-zero |
    RONE != RZERO
    [using import(real) oneNotZero]
  @generalize-z |
    fix z: Complex {
      @given-on-circle |
        assume onCircle(z) {
          @on-circle |
            normSq(z) = RONE
            [by hypothesis given-on-circle]
          @suppose-zero |
            assume z = CZERO {
              @z-is-zero |
                z = CZERO
                [by hypothesis suppose-zero]
              @zero-on-circle |
                normSq(CZERO) = RONE
                [by rewrite z-is-zero on-circle]
              @zero-is-one |
                RZERO = RONE
                [using chain zero-is-norm-sq-of-zero zero-on-circle]
              @one-is-zero |
                RONE = RZERO
                [by symmetry zero-is-one]
            }
          @conclusion-nonzero |
            z != CZERO
            [by contradiction suppose-zero one-is-zero one-not-zero]
        }
      @on-circle-implies-nonzero |
        onCircle(z) -> z != CZERO
        [by discharge given-on-circle]
    }
  @circle-avoids-zero |
    forall z: Complex; onCircle(z) -> z != CZERO
    [by generalize generalize-z]
  @conclusion |
    onCircle(CONE) and (forall z, w: Complex; onCircle(z) -> onCircle(w) -> onCircle(cmul(z, w))) and (forall z: Complex; onCircle(z) -> onCircle(crecip(z))) and (forall z: Complex; onCircle(z) -> z != CZERO)
    [using tautology one-on-circle closed-under-product closed-under-inverse circle-avoids-zero]
qed
```

**Exercise 46.** *Prove or disprove: if $H$ and $K$ are subgroups of $G$, then
$H \cup K$ is a subgroup of $G$.*

**Disproved** (Judson's hint: look at $S_3$). With $S_3$ the permutations of the
three letters $0, 1, 2$ (`std/permutation/count.b4m`'s `permutesTheSegment`), take
$H = \{1, (0\,1)\}$ and $K = \{1, (1\,2)\}$. Both pass the one-step test
(§3.3's one-step subgroup test, $h k^{-1} \in H$) and lie inside $S_3$, but $(0\,1)(1\,2)$ sends
$0 \mapsto 1$ and $1 \mapsto 2$, so it is neither the identity nor either
transposition: $H \cup K$ is not closed. The block below builds the letters, the values
of the maps, and the two subgroups, and states the disproof.

```2b4m
theorem lettersDiffer: forall a: Nat; forall b: Nat; a != b -> numeral(a) != numeral(b)
proof
  @generalize-a |
    fix a: Nat {
      @generalize-b |
        fix b: Nat {
          @given-indices-differ |
            assume a != b {
              @indices-differ |
                a != b
                [by hypothesis given-indices-differ]
              @suppose-letters-equal |
                assume numeral(a) = numeral(b) {
                  @letters-equal |
                    numeral(a) = numeral(b)
                    [by hypothesis suppose-letters-equal]
                  @indices-equal |
                    a = b
                    [using specialize numeralInjective(a, b) letters-equal]
                }
              @conclusion-letters-differ |
                numeral(a) != numeral(b)
                [by contradiction suppose-letters-equal indices-equal indices-differ]
            }
          @conclusion-at-b |
            a != b -> numeral(a) != numeral(b)
            [by discharge given-indices-differ]
        }
      @discharge-b |
        forall b: Nat; a != b -> numeral(a) != numeral(b)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: Nat; forall b: Nat; a != b -> numeral(a) != numeral(b)
    [by generalize generalize-a]
qed

// Two maps that disagree at a point differ.
theorem mapsDisagreeingDiffer: forall f: Fn; forall g: Fn; forall x: Element; forall y: Element; forall z: Element;
  apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
proof
  @generalize-f |
    fix f: Fn {
      @generalize-g |
        fix g: Fn {
          @generalize-x |
            fix x: Element {
              @generalize-y |
                fix y: Element {
                  @generalize-z |
                    fix z: Element {
                      @given-f-value |
                        assume apply(f, x) = y {
                          @given-g-value |
                            assume apply(g, x) = z {
                              @given-values-differ |
                                assume y != z {
                                  @f-value |
                                    apply(f, x) = y
                                    [by hypothesis given-f-value]
                                  @g-value |
                                    apply(g, x) = z
                                    [by hypothesis given-g-value]
                                  @values-differ |
                                    y != z
                                    [by hypothesis given-values-differ]
                                  @suppose-equal |
                                    assume f = g {
                                      @equal |
                                        f = g
                                        [by hypothesis suppose-equal]
                                      @g-value-is-y |
                                        apply(g, x) = y
                                        [by rewrite equal f-value]
                                      @values-agree |
                                        y = z
                                        [by rewrite g-value-is-y g-value]
                                    }
                                  @conclusion-differ |
                                    f != g
                                    [by contradiction suppose-equal values-agree values-differ]
                                }
                              @conclusion-given-values-differ |
                                y != z -> f != g
                                [by discharge given-values-differ]
                            }
                          @conclusion-given-g-value |
                            apply(g, x) = z -> y != z -> f != g
                            [by discharge given-g-value]
                        }
                      @conclusion-at-z |
                        apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
                        [by discharge given-f-value]
                    }
                  @discharge-z |
                    forall z: Element; apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
                    [by generalize generalize-z]
                }
              @discharge-y |
                forall y: Element; forall z: Element; apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
                [by generalize generalize-y]
            }
          @discharge-x |
            forall x: Element; forall y: Element; forall z: Element; apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
            [by generalize generalize-x]
        }
      @discharge-g |
        forall g: Fn; forall x: Element; forall y: Element; forall z: Element; apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
        [by generalize generalize-g]
    }
  @conclusion |
    forall f: Fn; forall g: Fn; forall x: Element; forall y: Element; forall z: Element;
      apply(f, x) = y -> apply(g, x) = z -> y != z -> f != g
    [by generalize generalize-f]
qed

// -- H = {1, (0 1)} passes the one-step test (the one-step subgroup test) and is abelian ----------

theorem firstSubgroupOneStep: forall h1: Fn; forall h2: Fn;
  inFirstSubgroup(h1) -> inFirstSubgroup(h2) -> inFirstSubgroup(compose(h1, inverse(h2)))
proof
  @inverse-of-identity |
    inverse(identityFn) = identityFn
    [by cite inverseOfIdentity]
  @inverse-of-swap |
    inverse(swapZeroOne) = swapZeroOne
    [using specialize transpositionIsItsOwnInverse(numeral(ZERO), numeral(succ(ZERO)))]
  @identity-squared |
    compose(identityFn, identityFn) = identityFn
    [using specialize composeIdentityLeft(identityFn)]
  @identity-then-swap |
    compose(identityFn, swapZeroOne) = swapZeroOne
    [using specialize composeIdentityLeft(swapZeroOne)]
  @swap-then-identity |
    compose(swapZeroOne, identityFn) = swapZeroOne
    [using specialize composeIdentityRight(swapZeroOne)]
  @swap-squared |
    compose(swapZeroOne, swapZeroOne) = identityFn
    [using specialize transpositionIsAnInvolution(numeral(ZERO), numeral(succ(ZERO)))]
  @generalize-h1 |
    fix h1: Fn {
      @generalize-h2 |
        fix h2: Fn {
          @given-h1 |
            assume inFirstSubgroup(h1) {
              @given-h2 |
                assume inFirstSubgroup(h2) {
                  @h1-in |
                    inFirstSubgroup(h1)
                    [by hypothesis given-h1]
                  @h2-in |
                    inFirstSubgroup(h2)
                    [by hypothesis given-h2]
                  @conclusion-quotient-in |
                    inFirstSubgroup(compose(h1, inverse(h2)))
                    case h1-in {
                      @when-h1-identity |
                        assume h1 = identityFn {
                          @h1-is-identity |
                            h1 = identityFn
                            [by hypothesis when-h1-identity]
                          @conclusion-from-identity |
                            inFirstSubgroup(compose(h1, inverse(h2)))
                            case h2-in {
                              @when-h2-identity |
                                assume h2 = identityFn {
                                  @h2-is-identity |
                                    h2 = identityFn
                                    [by hypothesis when-h2-identity]
                                  @quotient |
                                    compose(h1, inverse(h2)) = identityFn
                                    [using simplify h1-is-identity h2-is-identity inverse-of-identity identity-squared]
                                  @conclusion-identity-identity |
                                    inFirstSubgroup(compose(h1, inverse(h2)))
                                    [using tautology quotient]
                                }
                              @when-h2-swap |
                                assume h2 = swapZeroOne {
                                  @h2-is-swap |
                                    h2 = swapZeroOne
                                    [by hypothesis when-h2-swap]
                                  @quotient |
                                    compose(h1, inverse(h2)) = swapZeroOne
                                    [using simplify h1-is-identity h2-is-swap inverse-of-swap identity-then-swap]
                                  @conclusion-identity-swap |
                                    inFirstSubgroup(compose(h1, inverse(h2)))
                                    [using tautology quotient]
                                }
                            }
                        }
                      @when-h1-swap |
                        assume h1 = swapZeroOne {
                          @h1-is-swap |
                            h1 = swapZeroOne
                            [by hypothesis when-h1-swap]
                          @conclusion-from-swap |
                            inFirstSubgroup(compose(h1, inverse(h2)))
                            case h2-in {
                              @when-h2-identity |
                                assume h2 = identityFn {
                                  @h2-is-identity |
                                    h2 = identityFn
                                    [by hypothesis when-h2-identity]
                                  @quotient |
                                    compose(h1, inverse(h2)) = swapZeroOne
                                    [using simplify h1-is-swap h2-is-identity inverse-of-identity swap-then-identity]
                                  @conclusion-swap-identity |
                                    inFirstSubgroup(compose(h1, inverse(h2)))
                                    [using tautology quotient]
                                }
                              @when-h2-swap |
                                assume h2 = swapZeroOne {
                                  @h2-is-swap |
                                    h2 = swapZeroOne
                                    [by hypothesis when-h2-swap]
                                  @quotient |
                                    compose(h1, inverse(h2)) = identityFn
                                    [using simplify h1-is-swap h2-is-swap inverse-of-swap swap-squared]
                                  @conclusion-swap-swap |
                                    inFirstSubgroup(compose(h1, inverse(h2)))
                                    [using tautology quotient]
                                }
                            }
                        }
                    }
                }
              @conclusion-given-h2 |
                inFirstSubgroup(h2) -> inFirstSubgroup(compose(h1, inverse(h2)))
                [by discharge given-h2]
            }
          @conclusion-at-h1-h2 |
            inFirstSubgroup(h1) -> inFirstSubgroup(h2) -> inFirstSubgroup(compose(h1, inverse(h2)))
            [by discharge given-h1]
        }
      @discharge-h2 |
        forall h2: Fn; inFirstSubgroup(h1) -> inFirstSubgroup(h2) -> inFirstSubgroup(compose(h1, inverse(h2)))
        [by generalize generalize-h2]
    }
  @conclusion |
    forall h1: Fn; forall h2: Fn; inFirstSubgroup(h1) -> inFirstSubgroup(h2) -> inFirstSubgroup(compose(h1, inverse(h2)))
    [by generalize generalize-h1]
qed
```

**Exercise 47.** *Prove or disprove: if $H$ and $K$ are subgroups of $G$, then
$HK = \{hk : h \in H,\ k \in K\}$ is a subgroup of $G$. What if $G$ is abelian?*

**Disproved in general, proved for abelian $G$.** Membership in $HK$ is the
existential "$x = hk$ for some $h \in H$, $k \in K$". In $S_3$ with the same $H = \{1,
(0\,1)\}$ and $K = \{1, (1\,2)\}$ as Exercise 46, $HK = \{1, (0\,1), (1\,2),
(0\,1)(1\,2)\}$ contains $(1\,2)$ and $(0\,1)$ but not their product $(1\,2)(0\,1)$,
which sends $0 \mapsto 2$ and $1 \mapsto 0$ and so differs from each of the four members
at a letter — $HK$ is not closed. When $G$ is abelian, $HK$ passes the one-step test:
$(h_1 k_1)(h_2 k_2)^{-1} = h_1 k_1 k_2^{-1} h_2^{-1} = (h_1 h_2^{-1})(k_1 k_2^{-1})$ after
commuting, and $e = e \cdot e$. The second subgroup $K$ is `std/subgroup.b4m`'s
`inSubgroup2`.

**Exercise 48.** *Let $G$ be a group. Show that the **center**
$Z(G) = \{x \in G : gx = xg \text{ for all } g \in G\}$ is a subgroup of $G$.*

Membership in $Z(G)$ is the *commuting condition* `forall g: G; op(g, x) =
op(x, g)`. We verify the three subgroup criteria for it. **(i)** the identity
commutes with every $g$ (both sides equal $g$); **(ii)** if $x$ and $y$ each
commute with every $g$, so does $xy$, by reassociating $g(xy)=(gx)y=(xg)y=$
$x(gy)=x(yg)=(xy)g$; **(iii)** if $x$ commutes with every $g$, so does $x^{-1}$,
from $x^{-1}g = x^{-1}(g\,e) = x^{-1}(g(xx^{-1})) = x^{-1}((gx)x^{-1}) =
x^{-1}((xg)x^{-1}) = (x^{-1}x)(gx^{-1}) = gx^{-1}$.

```2b4m
// (i) identity: e commutes with every g.
theorem centerHasIdentity: forall g: G; op(g, e) = op(e, g)
proof
  @generalize-g |
    fix g: G {
      @g-times-identity |
        op(g, e) = g
        [using specialize grpIdentityRight(g)]
      @identity-times-g |
        op(e, g) = g
        [using specialize grpIdentityLeft(g)]
      @conclusion-identity-commutes |
        op(g, e) = op(e, g)
        [using chain g-times-identity identity-times-g]
    }
  @conclusion |
    forall g: G; op(g, e) = op(e, g)
    [by generalize generalize-g]
qed

// (iii) inverse: if x commutes with every g, so does x⁻¹.
theorem centerClosedInverse: forall x: G;
  (forall g: G; op(g, x) = op(x, g)) ->
  (forall g: G; op(g, inv(x)) = op(inv(x), g))
proof
  @generalize-x |
    fix x: G {
      @given-x-commutes |
        assume forall g: G; op(g, x) = op(x, g) {
          @x-commutes |
            forall g: G; op(g, x) = op(x, g)
            [by hypothesis given-x-commutes]
          @generalize-g |
            fix g: G {
              @x-commutes-at-g |
                op(g, x) = op(x, g)
                [by apply_at(g) x-commutes]
              // g·x⁻¹ = x⁻¹·(x·g·x⁻¹) style: expand identities and reassociate.
              @g-times-identity |
                op(g, e) = g
                [using specialize grpIdentityRight(g)]
              @x-times-invx-is-identity |
                op(x, inv(x)) = e
                [using specialize grpInverseRight(x)]
              @reassociate-g-x-invx |
                op(op(g, x), inv(x)) = op(g, op(x, inv(x)))
                [using specialize grpAssoc(g, x, inv(x))]
              @reassociate-x-g-invx |
                op(op(x, g), inv(x)) = op(x, op(g, inv(x)))
                [using specialize grpAssoc(x, g, inv(x))]
              @reassociate-invx-x-rest |
                op(op(inv(x), x), op(g, inv(x))) = op(inv(x), op(x, op(g, inv(x))))
                [using specialize grpAssoc(inv(x), x, op(g, inv(x)))]
              @invx-times-x |
                op(inv(x), x) = e
                [using specialize grpInverseLeft(x)]
              @strip-identity-left |
                op(e, op(g, inv(x))) = op(g, inv(x))
                [using specialize grpIdentityLeft(op(g, inv(x)))]
              // x⁻¹g = x⁻¹(g·e) = x⁻¹(g(xx⁻¹)) = x⁻¹((gx)x⁻¹) = x⁻¹((xg)x⁻¹)
              //      = x⁻¹(x(gx⁻¹)) = (x⁻¹x)(gx⁻¹) = e(gx⁻¹) = gx⁻¹
              @invx-g-is-g-invx |
                op(inv(x), g) = op(g, inv(x))
                [using chain g-times-identity x-times-invx-is-identity reassociate-g-x-invx x-commutes-at-g reassociate-x-g-invx reassociate-invx-x-rest invx-times-x strip-identity-left]
              @conclusion-invx-commutes-at-g |
                op(g, inv(x)) = op(inv(x), g)
                [by symmetry invx-g-is-g-invx]
            }
          @conclusion-invx-commutes |
            forall g: G; op(g, inv(x)) = op(inv(x), g)
            [by generalize generalize-g]
        }
      @x-commutes-implies-invx-commutes |
        (forall g: G; op(g, x) = op(x, g)) -> (forall g: G; op(g, inv(x)) = op(inv(x), g))
        [by discharge given-x-commutes]
    }
  @conclusion |
    forall x: G; (forall g: G; op(g, x) = op(x, g)) -> (forall g: G; op(g, inv(x)) = op(inv(x), g))
    [by generalize generalize-x]
qed

// (ii) closed under op: if x and y each commute with every g, so does x·y.
theorem centerClosedOp: forall x, y: G;
  (forall g: G; op(g, x) = op(x, g)) ->
  (forall g: G; op(g, y) = op(y, g)) ->
  (forall g: G; op(g, op(x, y)) = op(op(x, y), g))
proof
  @generalize-x |
    fix x: G {
      @generalize-y |
        fix y: G {
          @given-x-commutes |
            assume forall g: G; op(g, x) = op(x, g) {
              @given-y-commutes |
                assume forall g: G; op(g, y) = op(y, g) {
                  @x-commutes |
                    forall g: G; op(g, x) = op(x, g)
                    [by hypothesis given-x-commutes]
                  @y-commutes |
                    forall g: G; op(g, y) = op(y, g)
                    [by hypothesis given-y-commutes]
                  @generalize-g |
                    fix g: G {
                      @x-commutes-at-g |
                        op(g, x) = op(x, g)
                        [by apply_at(g) x-commutes]
                      @y-commutes-at-g |
                        op(g, y) = op(y, g)
                        [by apply_at(g) y-commutes]
                      @reassociate-g-x-y |
                        op(op(g, x), y) = op(g, op(x, y))
                        [using specialize grpAssoc(g, x, y)]
                      @reassociate-x-g-y |
                        op(op(x, g), y) = op(x, op(g, y))
                        [using specialize grpAssoc(x, g, y)]
                      @reassociate-x-y-g |
                        op(op(x, y), g) = op(x, op(y, g))
                        [using specialize grpAssoc(x, y, g)]
                      // g(xy) = (gx)y = (xg)y = x(gy) = x(yg) = (xy)g
                      @conclusion-xy-commutes-at-g |
                        op(g, op(x, y)) = op(op(x, y), g)
                        [using chain reassociate-g-x-y x-commutes-at-g reassociate-x-g-y y-commutes-at-g reassociate-x-y-g]
                    }
                  @conclusion-xy-commutes |
                    forall g: G; op(g, op(x, y)) = op(op(x, y), g)
                    [by generalize generalize-g]
                }
              @y-commutes-implies-xy-commutes |
                (forall g: G; op(g, y) = op(y, g)) -> (forall g: G; op(g, op(x, y)) = op(op(x, y), g))
                [by discharge given-y-commutes]
            }
          @x-commutes-implies-rest |
            (forall g: G; op(g, x) = op(x, g)) -> (forall g: G; op(g, y) = op(y, g)) -> (forall g: G; op(g, op(x, y)) = op(op(x, y), g))
            [by discharge given-x-commutes]
        }
      @discharge-y |
        forall y: G; (forall g: G; op(g, x) = op(x, g)) -> (forall g: G; op(g, y) = op(y, g)) -> (forall g: G; op(g, op(x, y)) = op(op(x, y), g))
        [by generalize generalize-y]
    }
  @conclusion |
    forall x, y: G; (forall g: G; op(g, x) = op(x, g)) -> (forall g: G; op(g, y) = op(y, g)) -> (forall g: G; op(g, op(x, y)) = op(op(x, y), g))
    [by generalize generalize-x]
qed
```

**Exercise 49.** *Let $a, b \in G$. If $a^4 b = ba$ and $a^3 = e$, prove $ab =
ba$.*

Following Judson's hint, $ba = a^4 b = a^3(ab) = e(ab) = ab$: regroup $a^4b$ as
$a^3 \cdot (ab)$ (associativity), substitute $a^3 = e$, and drop the identity.
We write $a^4$ and $a^3$ as explicit `op`-towers.

```2b4m
theorem exerciseFortyNineCommute: forall a, b: G;
  op(op(op(op(a, a), a), a), b) = op(b, a) ->
  op(op(a, a), a) = e ->
  op(a, b) = op(b, a)
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          @given-a4b-is-ba |
            assume op(op(op(op(a, a), a), a), b) = op(b, a) {
              @given-a3-is-identity |
                assume op(op(a, a), a) = e {
                  @a4b-is-ba |
                    op(op(op(op(a, a), a), a), b) = op(b, a)
                    [by hypothesis given-a4b-is-ba]
                  @a3-is-identity |
                    op(op(a, a), a) = e
                    [by hypothesis given-a3-is-identity]
                  // a⁴b = a³·(ab): regroup the last two factors.
                  @regroup-a4b |
                    op(op(op(op(a, a), a), a), b) = op(op(op(a, a), a), op(a, b))
                    [using specialize grpAssoc(op(op(a, a), a), a, b)]
                  // substitute a³ = e, then e·(ab) = ab.
                  @identity-times-ab |
                    op(e, op(a, b)) = op(a, b)
                    [using specialize grpIdentityLeft(op(a, b))]
                  // ba = a⁴b = a³·(ab) = e·(ab) = ab
                  @ba-is-ab |
                    op(b, a) = op(a, b)
                    [using chain a4b-is-ba regroup-a4b a3-is-identity identity-times-ab]
                  @conclusion-ab-is-ba |
                    op(a, b) = op(b, a)
                    [by symmetry ba-is-ab]
                }
              @a3-identity-implies-commute |
                op(op(a, a), a) = e -> op(a, b) = op(b, a)
                [by discharge given-a3-is-identity]
            }
          @a4b-implies-rest |
            op(op(op(op(a, a), a), a), b) = op(b, a) -> op(op(a, a), a) = e -> op(a, b) = op(b, a)
            [by discharge given-a4b-is-ba]
        }
      @discharge-b |
        forall b: G; op(op(op(op(a, a), a), a), b) = op(b, a) -> op(op(a, a), a) = e -> op(a, b) = op(b, a)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: G; op(op(op(op(a, a), a), a), b) = op(b, a) -> op(op(a, a), a) = e -> op(a, b) = op(b, a)
    [by generalize generalize-a]
qed
```

**Exercise 50.** *Give an example of an infinite group in which every nontrivial
subgroup is infinite.*

**Proved** for $(\mathbb{Z}, +)$. "Infinite" is stated without a cardinality: a set of
integers is UNBOUNDED ABOVE — for every bound $b$ it has a member beyond $b$ — and an
unbounded set cannot be listed by finitely many elements (a finite list has a largest
entry). $\mathbb{Z}$ itself is unbounded ($b < b + 1$). A subgroup $S$ of $\mathbb{Z}$
is any predicate closed under addition and negation; NONTRIVIAL means it has a member
$m \ne 0$. Then $S$ has a positive member $p$ ($m$ or $-m$), and by induction the
multiples $p, 2p, 3p, \ldots$ all lie in $S$ with $(k+1)p > k$ (each step adds
$p \ge 1$), so $S$ has a member above every bound. The subgroup is an opaque predicate
whose closure conditions are the theorem's hypotheses — nothing is assumed of it.
```2b4m
import int_order <<< "std/integer/order.b4m"

func imul = integer.mul
pred nonneg = integer.nonneg
pred int_less_than = int_order.less_than
axiom nonnegInduction = integer.nonnegInduction

// a subgroup S ≤ ℤ: an opaque membership predicate; the theorem carries its closure.
pred inS(n: Int)

// b < b + 1: ℤ is unbounded above.
theorem integersAreUnbounded: forall b: Int; exists x: Int; int_less_than(b, x)
proof
  @generalize-b |
    fix b: Int {
      @predecessor-below |
        int_less_than(iprev(isucc(b)), isucc(b))
        [using specialize int_order.prevLessThanSelf(isucc(b))]
      @predecessor-of-successor |
        iprev(isucc(b)) = b
        [using specialize integer.prevSucc(b)]
      @successor-above |
        int_less_than(b, isucc(b))
        [by rewrite predecessor-of-successor predecessor-below]
      @conclusion-successor-witnesses |
        exists x: Int; int_less_than(b, x)
        [by witness(isucc(b)) successor-above]
    }
  @conclusion |
    forall b: Int; exists x: Int; int_less_than(b, x)
    [by generalize generalize-b]
qed

// a < b and 0 < c give a + 1 < b + c: the gaps add (b = a + (d + 1), c = e + 1, so
// b + c = (a + 1) + ((d + e) + 1)).
theorem successorStaysBelowSumWithPositive: forall a, b, c: Int; int_less_than(a, b) -> int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @given-below |
                assume int_less_than(a, b) {
                  @given-positive |
                    assume int_less_than(IZERO, c) {
                      @below |
                        int_less_than(a, b)
                        [by hypothesis given-below]
                      @positive |
                        int_less_than(IZERO, c)
                        [by hypothesis given-positive]
                      @gap-to-b-exists |
                        exists d: Int; nonneg(d) and iadd(a, isucc(d)) = b
                        [using specialize integer.lessThanElim(a, b) below]
                      @gap-to-c-exists |
                        exists gapToC: Int; nonneg(gapToC) and iadd(IZERO, isucc(gapToC)) = c
                        [using specialize integer.lessThanElim(IZERO, c) positive]
                      @with-gap-d |
                        unpack d: Int from gap-to-b-exists {
                          @d-facts |
                            nonneg(d) and iadd(a, isucc(d)) = b
                            [by hypothesis with-gap-d]
                          @d-nonneg |
                            nonneg(d)
                            [by and_lhs d-facts]
                          @b-is-a-plus-gap |
                            iadd(a, isucc(d)) = b
                            [by and_rhs d-facts]
                          @with-gap-c |
                            unpack gapToC: Int from gap-to-c-exists {
                              @gapToC-facts |
                                nonneg(gapToC) and iadd(IZERO, isucc(gapToC)) = c
                                [by hypothesis with-gap-c]
                              @gapToC-nonneg |
                                nonneg(gapToC)
                                [by and_lhs gapToC-facts]
                              @c-is-zero-plus-gap |
                                iadd(IZERO, isucc(gapToC)) = c
                                [by and_rhs gapToC-facts]
                              @zero-plus-gap |
                                iadd(IZERO, isucc(gapToC)) = isucc(gapToC)
                                [using specialize integer.addZeroLeft(isucc(gapToC))]
                              @gap-is-c |
                                isucc(gapToC) = c
                                [by rewrite zero-plus-gap c-is-zero-plus-gap]
                              @witness-nonneg |
                                nonneg(iadd(d, gapToC))
                                [using specialize integer.nonnegAdd(d, gapToC) d-nonneg gapToC-nonneg]
                              // the sum b + c, with both gaps exposed.
                              @sum-reflexive |
                                iadd(b, c) = iadd(b, c)
                                [by reflexivity]
                              @sum-with-b-exposed |
                                iadd(b, c) = iadd(iadd(a, isucc(d)), c)
                                [by rewrite b-is-a-plus-gap sum-reflexive]
                              @sum-with-both-exposed |
                                iadd(iadd(a, isucc(d)), c) = iadd(iadd(a, isucc(d)), isucc(gapToC))
                                [by rewrite gap-is-c sum-with-b-reflexive]
                              @sum-with-b-reflexive |
                                iadd(iadd(a, isucc(d)), c) = iadd(iadd(a, isucc(d)), c)
                                [by reflexivity]
                              @succ-out-of-c |
                                iadd(iadd(a, isucc(d)), isucc(gapToC)) = isucc(iadd(iadd(a, isucc(d)), gapToC))
                                [using specialize integer.addSuccRight(iadd(a, isucc(d)), gapToC)]
                              @succ-out-of-d |
                                iadd(a, isucc(d)) = isucc(iadd(a, d))
                                [using specialize integer.addSuccRight(a, d)]
                              @inner-succ-exposed |
                                isucc(iadd(iadd(a, isucc(d)), gapToC)) = isucc(iadd(isucc(iadd(a, d)), gapToC))
                                [by rewrite succ-out-of-d inner-reflexive]
                              @inner-reflexive |
                                isucc(iadd(iadd(a, isucc(d)), gapToC)) = isucc(iadd(iadd(a, isucc(d)), gapToC))
                                [by reflexivity]
                              @succ-out-left |
                                iadd(isucc(iadd(a, d)), gapToC) = isucc(iadd(iadd(a, d), gapToC))
                                [using specialize integer.addSuccLeft(iadd(a, d), gapToC)]
                              @inner-both-succ |
                                isucc(iadd(isucc(iadd(a, d)), gapToC)) = isucc(isucc(iadd(iadd(a, d), gapToC)))
                                [by rewrite succ-out-left inner-both-reflexive]
                              @inner-both-reflexive |
                                isucc(iadd(isucc(iadd(a, d)), gapToC)) = isucc(iadd(isucc(iadd(a, d)), gapToC))
                                [by reflexivity]
                              @sum-is-double-successor |
                                iadd(b, c) = isucc(isucc(iadd(iadd(a, d), gapToC)))
                                [using chain sum-with-b-exposed sum-with-both-exposed succ-out-of-c inner-succ-exposed inner-both-succ]
                              // the candidate a + 1 plus the combined gap (d + gapToC) + 1 is the same.
                              @candidate-succ-out |
                                iadd(isucc(a), isucc(iadd(d, gapToC))) = isucc(iadd(isucc(a), iadd(d, gapToC)))
                                [using specialize integer.addSuccRight(isucc(a), iadd(d, gapToC))]
                              @candidate-succ-left |
                                iadd(isucc(a), iadd(d, gapToC)) = isucc(iadd(a, iadd(d, gapToC)))
                                [using specialize integer.addSuccLeft(a, iadd(d, gapToC))]
                              @candidate-regrouped |
                                iadd(iadd(a, d), gapToC) = iadd(a, iadd(d, gapToC))
                                [using specialize integer.addIsAssociative(a, d, gapToC)]
                              @candidate-regrouped-flipped |
                                iadd(a, iadd(d, gapToC)) = iadd(iadd(a, d), gapToC)
                                [by symmetry candidate-regrouped]
                              @candidate-inner |
                                isucc(iadd(isucc(a), iadd(d, gapToC))) = isucc(isucc(iadd(a, iadd(d, gapToC))))
                                [by rewrite candidate-succ-left candidate-inner-reflexive]
                              @candidate-inner-reflexive |
                                isucc(iadd(isucc(a), iadd(d, gapToC))) = isucc(iadd(isucc(a), iadd(d, gapToC)))
                                [by reflexivity]
                              @candidate-regrouped-inner |
                                isucc(isucc(iadd(a, iadd(d, gapToC)))) = isucc(isucc(iadd(iadd(a, d), gapToC)))
                                [by rewrite candidate-regrouped-flipped candidate-regrouped-reflexive]
                              @candidate-regrouped-reflexive |
                                isucc(isucc(iadd(a, iadd(d, gapToC)))) = isucc(isucc(iadd(a, iadd(d, gapToC))))
                                [by reflexivity]
                              @candidate-is-double-successor |
                                iadd(isucc(a), isucc(iadd(d, gapToC))) = isucc(isucc(iadd(iadd(a, d), gapToC)))
                                [using chain candidate-succ-out candidate-inner candidate-regrouped-inner]
                              @double-successor-is-sum |
                                isucc(isucc(iadd(iadd(a, d), gapToC))) = iadd(b, c)
                                [by symmetry sum-is-double-successor]
                              @candidate-reaches-sum |
                                iadd(isucc(a), isucc(iadd(d, gapToC))) = iadd(b, c)
                                [using chain candidate-is-double-successor double-successor-is-sum]
                              @conclusion-successor-below-sum |
                                int_less_than(isucc(a), iadd(b, c))
                                [using specialize integer.lessThanIntro(isucc(a), iadd(d, gapToC), iadd(b, c)) witness-nonneg candidate-reaches-sum]
                            }
                          @conclusion-with-d |
                            int_less_than(isucc(a), iadd(b, c))
                            [by unpacked with-gap-c]
                        }
                      @conclusion-below-sum |
                        int_less_than(isucc(a), iadd(b, c))
                        [by unpacked with-gap-d]
                    }
                  @positive-implies |
                    int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
                    [by discharge given-positive]
                }
              @below-implies |
                int_less_than(a, b) -> int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
                [by discharge given-below]
            }
          @discharge-c |
            forall c: Int; int_less_than(a, b) -> int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
            [by generalize generalize-c]
        }
      @discharge-b |
        forall b: Int; forall c: Int; int_less_than(a, b) -> int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b, c: Int; int_less_than(a, b) -> int_less_than(IZERO, c) -> int_less_than(isucc(a), iadd(b, c))
    [by generalize generalize-a]
qed

// EXERCISE 50: a nontrivial subgroup S of ℤ is unbounded above — so infinite.
theorem nontrivialSubgroupOfIntegersIsUnbounded: (forall x, y: Int; inS(x) -> inS(y) -> inS(iadd(x, y))) -> (forall x: Int; inS(x) -> inS(ineg(x))) -> forall m: Int; inS(m) -> m != IZERO -> forall b: Int; exists x: Int; inS(x) and int_less_than(b, x)
proof
  @given-closed-under-add |
    assume forall x, y: Int; inS(x) -> inS(y) -> inS(iadd(x, y)) {
      @given-closed-under-neg |
        assume forall x: Int; inS(x) -> inS(ineg(x)) {
          @closed-under-add |
            forall x, y: Int; inS(x) -> inS(y) -> inS(iadd(x, y))
            [by hypothesis given-closed-under-add]
          @closed-under-neg |
            forall x: Int; inS(x) -> inS(ineg(x))
            [by hypothesis given-closed-under-neg]
          @generalize-m |
            fix m: Int {
              @given-member |
                assume inS(m) {
                  @given-nonzero |
                    assume m != IZERO {
                      @m-in |
                        inS(m)
                        [by hypothesis given-member]
                      @m-nonzero |
                        m != IZERO
                        [by hypothesis given-nonzero]
                      @neg-m-in |
                        inS(ineg(m))
                        [using specialize closed-under-neg(m) m-in]
                      // a POSITIVE member: m or −m.
                      @sign-split |
                        int_less_than(IZERO, m) or m = IZERO or int_less_than(m, IZERO)
                        [using specialize integer.signTrichotomy(m)]
                      @positive-member-exists |
                        exists p: Int; inS(p) and int_less_than(IZERO, p)
                        case sign-split {
                          @when-positive |
                            assume int_less_than(IZERO, m) {
                              @m-positive |
                                int_less_than(IZERO, m)
                                [by hypothesis when-positive]
                              @m-qualifies |
                                inS(m) and int_less_than(IZERO, m)
                                [using tautology m-in m-positive]
                              @conclusion-m-is-positive-member |
                                exists p: Int; inS(p) and int_less_than(IZERO, p)
                                [by witness(m) m-qualifies]
                            }
                          @when-zero |
                            assume m = IZERO {
                              @m-zero |
                                m = IZERO
                                [by hypothesis when-zero]
                              @conclusion-excluded |
                                exists p: Int; inS(p) and int_less_than(IZERO, p)
                                [using tautology m-zero m-nonzero]
                            }
                          @when-negative |
                            assume int_less_than(m, IZERO) {
                              @m-negative |
                                int_less_than(m, IZERO)
                                [by hypothesis when-negative]
                              @neg-m-positive |
                                int_less_than(IZERO, ineg(m))
                                [using specialize int_order.negativeNegIsPositive(m) m-negative]
                              @neg-m-qualifies |
                                inS(ineg(m)) and int_less_than(IZERO, ineg(m))
                                [using tautology neg-m-in neg-m-positive]
                              @conclusion-neg-m-is-positive-member |
                                exists p: Int; inS(p) and int_less_than(IZERO, p)
                                [by witness(ineg(m)) neg-m-qualifies]
                            }
                        }
                      @generalize-b |
                        fix b: Int {
                          @with-positive-p |
                            unpack p: Int from positive-member-exists {
                              @p-facts |
                                inS(p) and int_less_than(IZERO, p)
                                [by hypothesis with-positive-p]
                              @p-in |
                                inS(p)
                                [by and_lhs p-facts]
                              @p-positive |
                                int_less_than(IZERO, p)
                                [by and_rhs p-facts]
                              // induction on k ≥ 0: (k+1)·p ∈ S and k < (k+1)·p.
                              @first-multiple-unfolds |
                                imul(isucc(IZERO), p) = iadd(imul(IZERO, p), p)
                                [using specialize integer.mulSuccLeft(IZERO, p)]
                              @zero-times-p |
                                imul(IZERO, p) = IZERO
                                [using specialize integer.mulZeroLeft(p)]
                              @first-multiple-collapses |
                                imul(isucc(IZERO), p) = iadd(IZERO, p)
                                [by rewrite zero-times-p first-multiple-unfolds]
                              @zero-plus-p |
                                iadd(IZERO, p) = p
                                [using specialize integer.addZeroLeft(p)]
                              @first-multiple-is-p |
                                imul(isucc(IZERO), p) = p
                                [using chain first-multiple-collapses zero-plus-p]
                              @first-multiple-in |
                                inS(imul(isucc(IZERO), p))
                                [by rewrite first-multiple-is-p p-in]
                              @zero-below-first-multiple |
                                int_less_than(IZERO, imul(isucc(IZERO), p))
                                [by rewrite first-multiple-is-p p-positive]
                              @base-case |
                                inS(imul(isucc(IZERO), p)) and int_less_than(IZERO, imul(isucc(IZERO), p))
                                [using tautology first-multiple-in zero-below-first-multiple]

                                          @inductive-hypothesis |

                                            [by hypothesis given-inductive-hypothesis]

                                            [by and_lhs inductive-hypothesis]

                                            [by and_rhs inductive-hypothesis]

                                            [using specialize integer.mulSuccLeft(isucc(k), p)]

                                            [using specialize closed-under-add(imul(isucc(k), p), p) multiple-in p-in]
                                          @next-multiple-in |

                                            [by rewrite next-multiple-unfolds sum-in]

                                          @successor-below-next-multiple |

                                            [using tautology next-multiple-in successor-below-next-multiple]

                                        [by discharge given-inductive-hypothesis]

                                [by generalize induction-step]

                                      @bound-negative |

                                        [using specialize integer.lessThanTransitive(b, IZERO, p) bound-negative p-positive]
                                      @p-qualifies |
```

**Exercise 51.** *If $xy = x^{-1}y^{-1}$ for all $x, y \in G$, prove that $G$ is
abelian.*

Setting $x = e$ gives $y = e^{-1}y^{-1} = y^{-1}$, so every element is its own
inverse. Then $xy = (xy)^{-1} = y^{-1}x^{-1} = yx$ — the middle equality is the
inverse-of-a-product law, `invProduct`, which Judson has by §3.2; we cite it from
`std/subgroup.b4m` (aliased above) rather than re-deriving it.

```2b4m
// Ex 51: xy = x⁻¹y⁻¹ for all x, y ⟹ G is abelian.
// Setting x = e gives y = y⁻¹ (every element is its own inverse); then
// xy = (xy)⁻¹ = y⁻¹x⁻¹ = yx.
theorem exerciseFiftyOneAbelian:
  (forall x, y: G; op(x, y) = op(inv(x), inv(y))) ->
  (forall x, y: G; op(x, y) = op(y, x))
proof
  @given-hypothesis |
    assume forall x, y: G; op(x, y) = op(inv(x), inv(y)) {
      @hypothesis |
        forall x, y: G; op(x, y) = op(inv(x), inv(y))
        [by hypothesis given-hypothesis]
      // inv(e) = e, from the left-inverse and right-identity laws.
      @inve-e-is-identity |
        op(inv(e), e) = e
        [using specialize grpInverseLeft(e)]
      @inve-e-is-inve |
        op(inv(e), e) = inv(e)
        [using specialize grpIdentityRight(inv(e))]
      @inverse-of-identity |
        inv(e) = e
        [using chain inve-e-is-inve inve-e-is-identity]
      // self-inverse: instantiate the hypothesis at x = e.
      @every-element-self-inverse |
        fix y: G {
          @hypothesis-at-e-y |
            op(e, y) = op(inv(e), inv(y))
            [by apply_at(e, y) hypothesis]
          @identity-times-y |
            op(e, y) = y
            [using specialize grpIdentityLeft(y)]
          @identity-times-invy |
            op(e, inv(y)) = inv(y)
            [using specialize grpIdentityLeft(inv(y))]
          // y = e·y = e⁻¹·y⁻¹ = e·y⁻¹ = y⁻¹
          @y-is-invy |
            y = inv(y)
            [using chain identity-times-y hypothesis-at-e-y inverse-of-identity identity-times-invy]
          @conclusion-y-is-self-inverse |
            inv(y) = y
            [by symmetry y-is-invy]
        }
      @self-inverse |
        forall y: G; inv(y) = y
        [by generalize every-element-self-inverse]
      @generalize-x |
        fix x: G {
          @generalize-y |
            fix y: G {
              @inv-of-xy |
                inv(op(x, y)) = op(inv(y), inv(x))
                [using specialize invProduct(x, y)]
              @xy-self-inverse |
                inv(op(x, y)) = op(x, y)
                [by apply_at(op(x, y)) self-inverse]
              @invy-is-y |
                inv(y) = y
                [by apply_at(y) self-inverse]
              @invx-is-x |
                inv(x) = x
                [by apply_at(x) self-inverse]
              // xy = (xy)⁻¹ = y⁻¹x⁻¹ = yx
              @xy-is-yx |
                op(x, y) = op(y, x)
                [using chain xy-self-inverse inv-of-xy invy-is-y invx-is-x]
            }
          @discharge-y |
            forall y: G; op(x, y) = op(y, x)
            [by generalize generalize-y]
        }
      @commutes-for-all |
        forall x, y: G; op(x, y) = op(y, x)
        [by generalize generalize-x]
    }
  @conclusion |
    (forall x, y: G; op(x, y) = op(inv(x), inv(y))) -> (forall x, y: G; op(x, y) = op(y, x))
    [by discharge given-hypothesis]
qed
```

**Exercise 53.** *Let $H$ be a subgroup of $G$ and
$C(H) = \{g \in G : gh = hg \text{ for all } h \in H\}$. Prove $C(H)$ (the
**centralizer** of $H$) is a subgroup of $G$.*

Structurally this is Exercise 48 with the commuting condition *guarded* by
$h \in H$: membership is `forall h: G; inH(h) -> op(g, h) = op(h, g)`. The same
three arguments go through, now discharging the `inH(h)` hypothesis before each
use — **(i)** the identity centralizes $H$; **(ii)** the centralizer is closed
under the operation; **(iii)** it is closed under inverses.

```2b4m
// (i) identity: e commutes with every subgroup element.
theorem centralizerHasIdentity: forall h: G; inH(h) -> op(e, h) = op(h, e)
proof
  @generalize-h |
    fix h: G {
      @given-h-in-H |
        assume inH(h) {
          @identity-times-h |
            op(e, h) = h
            [using specialize grpIdentityLeft(h)]
          @h-times-identity |
            op(h, e) = h
            [using specialize grpIdentityRight(h)]
          @conclusion-identity-commutes-with-h |
            op(e, h) = op(h, e)
            [using chain identity-times-h h-times-identity]
        }
      @h-in-H-implies-identity-commutes |
        inH(h) -> op(e, h) = op(h, e)
        [by discharge given-h-in-H]
    }
  @conclusion |
    forall h: G; inH(h) -> op(e, h) = op(h, e)
    [by generalize generalize-h]
qed

// (ii) closed under op: if g1 and g2 each commute with every h ∈ H, so does g1·g2.
theorem centralizerClosedOp: forall g1, g2: G;
  (forall h: G; inH(h) -> op(g1, h) = op(h, g1)) ->
  (forall h: G; inH(h) -> op(g2, h) = op(h, g2)) ->
  (forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2)))
proof
  @generalize-g1 |
    fix g1: G {
      @generalize-g2 |
        fix g2: G {
          @given-g1-central |
            assume forall h: G; inH(h) -> op(g1, h) = op(h, g1) {
              @given-g2-central |
                assume forall h: G; inH(h) -> op(g2, h) = op(h, g2) {
                  @g1-central |
                    forall h: G; inH(h) -> op(g1, h) = op(h, g1)
                    [by hypothesis given-g1-central]
                  @g2-central |
                    forall h: G; inH(h) -> op(g2, h) = op(h, g2)
                    [by hypothesis given-g2-central]
                  @generalize-h |
                    fix h: G {
                      @given-h-in-H |
                        assume inH(h) {
                          @h-in-H |
                            inH(h)
                            [by hypothesis given-h-in-H]
                          @g1-commutes-with-h |
                            op(g1, h) = op(h, g1)
                            [using specialize g1-central(h) h-in-H]
                          @g2-commutes-with-h |
                            op(g2, h) = op(h, g2)
                            [using specialize g2-central(h) h-in-H]
                          @reassociate-g1-g2-h |
                            op(op(g1, g2), h) = op(g1, op(g2, h))
                            [using specialize grpAssoc(g1, g2, h)]
                          @reassociate-g1-h-g2 |
                            op(op(g1, h), g2) = op(g1, op(h, g2))
                            [using specialize grpAssoc(g1, h, g2)]
                          @reassociate-h-g1-g2 |
                            op(op(h, g1), g2) = op(h, op(g1, g2))
                            [using specialize grpAssoc(h, g1, g2)]
                          // (g1g2)h = g1(g2h) = g1(hg2) = (g1h)g2 = (hg1)g2 = h(g1g2)
                          @conclusion-product-commutes-with-h |
                            op(op(g1, g2), h) = op(h, op(g1, g2))
                            [using chain reassociate-g1-g2-h g2-commutes-with-h reassociate-g1-h-g2 g1-commutes-with-h reassociate-h-g1-g2]
                        }
                      @h-in-H-implies-product-commutes |
                        inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2))
                        [by discharge given-h-in-H]
                    }
                  @conclusion-product-central |
                    forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2))
                    [by generalize generalize-h]
                }
              @g2-central-implies-product-central |
                (forall h: G; inH(h) -> op(g2, h) = op(h, g2)) -> (forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2)))
                [by discharge given-g2-central]
            }
          @g1-central-implies-rest |
            (forall h: G; inH(h) -> op(g1, h) = op(h, g1)) -> (forall h: G; inH(h) -> op(g2, h) = op(h, g2)) -> (forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2)))
            [by discharge given-g1-central]
        }
      @discharge-g2 |
        forall g2: G; (forall h: G; inH(h) -> op(g1, h) = op(h, g1)) -> (forall h: G; inH(h) -> op(g2, h) = op(h, g2)) -> (forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2)))
        [by generalize generalize-g2]
    }
  @conclusion |
    forall g1, g2: G; (forall h: G; inH(h) -> op(g1, h) = op(h, g1)) -> (forall h: G; inH(h) -> op(g2, h) = op(h, g2)) -> (forall h: G; inH(h) -> op(op(g1, g2), h) = op(h, op(g1, g2)))
    [by generalize generalize-g1]
qed

// (iii) inverse: if g commutes with every h ∈ H, so does g⁻¹.
theorem centralizerClosedInverse: forall g: G;
  (forall h: G; inH(h) -> op(g, h) = op(h, g)) ->
  (forall h: G; inH(h) -> op(inv(g), h) = op(h, inv(g)))
proof
  @generalize-g |
    fix g: G {
      @given-g-central |
        assume forall h: G; inH(h) -> op(g, h) = op(h, g) {
          @g-central |
            forall h: G; inH(h) -> op(g, h) = op(h, g)
            [by hypothesis given-g-central]
          @generalize-h |
            fix h: G {
              @given-h-in-H |
                assume inH(h) {
                  @h-in-H |
                    inH(h)
                    [by hypothesis given-h-in-H]
                  @g-commutes-with-h |
                    op(g, h) = op(h, g)
                    [using specialize g-central(h) h-in-H]
                  @h-times-identity |
                    op(h, e) = h
                    [using specialize grpIdentityRight(h)]
                  @g-times-invg-is-identity |
                    op(g, inv(g)) = e
                    [using specialize grpInverseRight(g)]
                  @reassociate-h-g-invg |
                    op(op(h, g), inv(g)) = op(h, op(g, inv(g)))
                    [using specialize grpAssoc(h, g, inv(g))]
                  @reassociate-g-h-invg |
                    op(op(g, h), inv(g)) = op(g, op(h, inv(g)))
                    [using specialize grpAssoc(g, h, inv(g))]
                  @reassociate-invg-g-rest |
                    op(op(inv(g), g), op(h, inv(g))) = op(inv(g), op(g, op(h, inv(g))))
                    [using specialize grpAssoc(inv(g), g, op(h, inv(g)))]
                  @invg-times-g |
                    op(inv(g), g) = e
                    [using specialize grpInverseLeft(g)]
                  @strip-identity-left |
                    op(e, op(h, inv(g))) = op(h, inv(g))
                    [using specialize grpIdentityLeft(op(h, inv(g)))]
                  // g⁻¹h = g⁻¹(h·e) = g⁻¹(h(g g⁻¹)) = g⁻¹((hg)g⁻¹) = g⁻¹((gh)g⁻¹)
                  //      = g⁻¹(g(hg⁻¹)) = (g⁻¹g)(hg⁻¹) = e(hg⁻¹) = hg⁻¹
                  @conclusion-inverse-commutes-with-h |
                    op(inv(g), h) = op(h, inv(g))
                    [using chain h-times-identity g-times-invg-is-identity reassociate-h-g-invg g-commutes-with-h reassociate-g-h-invg reassociate-invg-g-rest invg-times-g strip-identity-left]
                }
              @h-in-H-implies-inverse-commutes |
                inH(h) -> op(inv(g), h) = op(h, inv(g))
                [by discharge given-h-in-H]
            }
          @conclusion-inverse-central |
            forall h: G; inH(h) -> op(inv(g), h) = op(h, inv(g))
            [by generalize generalize-h]
        }
      @g-central-implies-inverse-central |
        (forall h: G; inH(h) -> op(g, h) = op(h, g)) -> (forall h: G; inH(h) -> op(inv(g), h) = op(h, inv(g)))
        [by discharge given-g-central]
    }
  @conclusion |
    forall g: G; (forall h: G; inH(h) -> op(g, h) = op(h, g)) -> (forall h: G; inH(h) -> op(inv(g), h) = op(h, inv(g)))
    [by generalize generalize-g]
qed
```

**Exercise 54.** *Let $H$ be a subgroup of $G$ and $g \in G$. Show that the
**conjugate** $gHg^{-1} = \{ghg^{-1} : h \in H\}$ is a subgroup of $G$.*

Membership in $gHg^{-1}$ is existential: $k \in gHg^{-1}$ iff `exists h: G;
inH(h) and k = op(op(g, h), inv(g))`. The three criteria each supply a witness
$h'$ from the subgroup $H$ and the corresponding conjugation identity —
**(i)** $e = geg^{-1}$ (witness $e$); **(ii)** $(ghg^{-1})(gh'g^{-1}) =
g(hh')g^{-1}$ (witness $hh'$, using $g^{-1}g = e$; this is `conjugateProduct`);
**(iii)** $(ghg^{-1})^{-1} = gh^{-1}g^{-1}$ (witness $h^{-1}$, using `invProduct`
twice and `invInvolution`; this is `conjugateInverse`). We first prove the two
conjugation identities, then the three membership theorems.

```2b4m
// (ghg⁻¹)⁻¹ = g·h⁻¹·g⁻¹.
theorem conjugateInverse: forall g, h: G;
  inv(op(op(g, h), inv(g))) = op(op(g, inv(h)), inv(g))
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @inverse-outer |
            inv(op(op(g, h), inv(g))) = op(inv(inv(g)), inv(op(g, h)))
            [using specialize invProduct(op(g, h), inv(g))]
          @double-inverse-g |
            inv(inv(g)) = g
            [using specialize invInvolution(g)]
          @inverse-gh |
            inv(op(g, h)) = op(inv(h), inv(g))
            [using specialize invProduct(g, h)]
          @reassociate |
            op(op(g, inv(h)), inv(g)) = op(g, op(inv(h), inv(g)))
            [using specialize grpAssoc(g, inv(h), inv(g))]
          // (ghg⁻¹)⁻¹ = g⁻¹⁻¹·(gh)⁻¹ = g·(h⁻¹g⁻¹) = (gh⁻¹)g⁻¹
          @conclusion-conjugate-inverse |
            inv(op(op(g, h), inv(g))) = op(op(g, inv(h)), inv(g))
            [using chain inverse-outer double-inverse-g inverse-gh reassociate]
        }
      @discharge-h |
        forall h: G; inv(op(op(g, h), inv(g))) = op(op(g, inv(h)), inv(g))
        [by generalize generalize-h]
    }
  @conclusion |
    forall g, h: G; inv(op(op(g, h), inv(g))) = op(op(g, inv(h)), inv(g))
    [by generalize generalize-g]
qed

theorem conjugateProduct: forall g, h, h2: G;
  op(op(op(g, h), inv(g)), op(op(g, h2), inv(g))) = op(op(g, op(h, h2)), inv(g))
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @generalize-h2 |
            fix h2: G {
              @invg-g-is-identity |
                op(inv(g), g) = e
                [using specialize grpInverseLeft(g)]
              @reassociate-inner |
                op(op(inv(g), g), op(h2, inv(g))) = op(inv(g), op(g, op(h2, inv(g))))
                [using specialize grpAssoc(inv(g), g, op(h2, inv(g)))]
              @strip-identity-inner |
                op(e, op(h2, inv(g))) = op(h2, inv(g))
                [using specialize grpIdentityLeft(op(h2, inv(g)))]
              @inner-collapses |
                op(inv(g), op(g, op(h2, inv(g)))) = op(h2, inv(g))
                [using chain reassociate-inner invg-g-is-identity strip-identity-inner]
              @conclusion-conjugate-product |
                op(op(op(g, h), inv(g)), op(op(g, h2), inv(g))) = op(op(g, op(h, h2)), inv(g))
                [using simplify grpAssoc inner-collapses]
            }
          @discharge-h2 |
            forall h2: G; op(op(op(g, h), inv(g)), op(op(g, h2), inv(g))) = op(op(g, op(h, h2)), inv(g))
            [by generalize generalize-h2]
        }
      @discharge-h |
        forall h, h2: G; op(op(op(g, h), inv(g)), op(op(g, h2), inv(g))) = op(op(g, op(h, h2)), inv(g))
        [by generalize generalize-h]
    }
  @conclusion |
    forall g, h, h2: G; op(op(op(g, h), inv(g)), op(op(g, h2), inv(g))) = op(op(g, op(h, h2)), inv(g))
    [by generalize generalize-g]
qed

// Ex 54, condition 1 (identity): e ∈ gHg⁻¹, witnessed by h = e (g·e·g⁻¹ = e).
theorem conjugateHasIdentity: forall g: G;
  exists h: G; inH(h) and e = op(op(g, h), inv(g))
proof
  @generalize-g |
    fix g: G {
      @identity-in-H |
        inH(e)
        [by cite subgroupHasIdentity]
      @g-times-identity |
        op(g, e) = g
        [using specialize grpIdentityRight(g)]
      @g-times-invg |
        op(g, inv(g)) = e
        [using specialize grpInverseRight(g)]
      @conjugate-of-identity-is-identity |
        op(op(g, e), inv(g)) = e
        [using chain g-times-identity g-times-invg]
      @identity-is-conjugate |
        e = op(op(g, e), inv(g))
        [by symmetry conjugate-of-identity-is-identity]
      @identity-is-conjugate-member |
        inH(e) and e = op(op(g, e), inv(g))
        [by both identity-in-H identity-is-conjugate]
      @conclusion-identity-in-conjugate |
        exists h: G; inH(h) and e = op(op(g, h), inv(g))
        [by witness(e) identity-is-conjugate-member]
    }
  @conclusion |
    forall g: G; exists h: G; inH(h) and e = op(op(g, h), inv(g))
    [by generalize generalize-g]
qed

// Ex 54, condition 2 (products): gHg⁻¹ is closed under the operation.
theorem conjugateClosedOp: forall g, k, m: G;
  (exists h: G; inH(h) and k = op(op(g, h), inv(g))) ->
  (exists h: G; inH(h) and m = op(op(g, h), inv(g))) ->
  (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
proof
  @generalize-g |
    fix g: G {
      @generalize-k |
        fix k: G {
          @generalize-m |
            fix m: G {
              @given-k-in-conjugate |
                assume exists h: G; inH(h) and k = op(op(g, h), inv(g)) {
                  @given-m-in-conjugate |
                    assume exists h: G; inH(h) and m = op(op(g, h), inv(g)) {
                      @k-in-conjugate |
                        exists h: G; inH(h) and k = op(op(g, h), inv(g))
                        [by hypothesis given-k-in-conjugate]
                      @with-witness-for-k |
                        unpack hk: G from k-in-conjugate {
                          @m-in-conjugate |
                            exists h: G; inH(h) and m = op(op(g, h), inv(g))
                            [by hypothesis given-m-in-conjugate]
                          @with-witness-for-m |
                            unpack hm: G from m-in-conjugate {
                              @hk-membership |
                                inH(hk) and k = op(op(g, hk), inv(g))
                                [by hypothesis with-witness-for-k]
                              @hm-membership |
                                inH(hm) and m = op(op(g, hm), inv(g))
                                [by hypothesis with-witness-for-m]
                              @hk-in-H |
                                inH(hk)
                                [by and_lhs hk-membership]
                              @k-is-conjugate-of-hk |
                                k = op(op(g, hk), inv(g))
                                [by and_rhs hk-membership]
                              @hm-in-H |
                                inH(hm)
                                [by and_lhs hm-membership]
                              @m-is-conjugate-of-hm |
                                m = op(op(g, hm), inv(g))
                                [by and_rhs hm-membership]
                              @product-of-witnesses-in-H |
                                inH(op(hk, hm))
                                [using specialize subgroupClosedOp(hk, hm) hk-in-H hm-in-H]
                              @conjugates-multiply |
                                op(op(op(g, hk), inv(g)), op(op(g, hm), inv(g))) = op(op(g, op(hk, hm)), inv(g))
                                [using specialize conjugateProduct(g, hk, hm)]
                              // op(k,m) = (g·hk·g⁻¹)(g·hm·g⁻¹) = g·(hk·hm)·g⁻¹
                              @product-is-conjugate |
                                op(k, m) = op(op(g, op(hk, hm)), inv(g))
                                [using chain k-is-conjugate-of-hk m-is-conjugate-of-hm conjugates-multiply]
                              @product-is-conjugate-member |
                                inH(op(hk, hm)) and op(k, m) = op(op(g, op(hk, hm)), inv(g))
                                [by both product-of-witnesses-in-H product-is-conjugate]
                              @conclusion-product-in-conjugate |
                                exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g))
                                [by witness(op(hk, hm)) product-is-conjugate-member]
                            }
                          @product-in-conjugate-from-m |
                            exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g))
                            [by unpacked with-witness-for-m]
                        }
                      @product-in-conjugate-from-k |
                        exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g))
                        [by unpacked with-witness-for-k]
                    }
                  @m-membership-implies-product |
                    (exists h: G; inH(h) and m = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
                    [by discharge given-m-in-conjugate]
                }
              @k-membership-implies-rest |
                (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and m = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
                [by discharge given-k-in-conjugate]
            }
          @discharge-m |
            forall m: G; (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and m = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
            [by generalize generalize-m]
        }
      @discharge-k |
        forall k, m: G; (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and m = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
        [by generalize generalize-k]
    }
  @conclusion |
    forall g, k, m: G; (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and m = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and op(k, m) = op(op(g, h), inv(g)))
    [by generalize generalize-g]
qed

// Ex 54, condition 3 (inverses): gHg⁻¹ is closed under inverses.
theorem conjugateClosedInverse: forall g, k: G;
  (exists h: G; inH(h) and k = op(op(g, h), inv(g))) ->
  (exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g)))
proof
  @generalize-g |
    fix g: G {
      @generalize-k |
        fix k: G {
          @given-k-in-conjugate |
            assume exists h: G; inH(h) and k = op(op(g, h), inv(g)) {
              @k-in-conjugate |
                exists h: G; inH(h) and k = op(op(g, h), inv(g))
                [by hypothesis given-k-in-conjugate]
              @with-witness-for-k |
                unpack hk: G from k-in-conjugate {
                  @hk-membership |
                    inH(hk) and k = op(op(g, hk), inv(g))
                    [by hypothesis with-witness-for-k]
                  @hk-in-H |
                    inH(hk)
                    [by and_lhs hk-membership]
                  @k-is-conjugate-of-hk |
                    k = op(op(g, hk), inv(g))
                    [by and_rhs hk-membership]
                  @inverse-witness-in-H |
                    inH(inv(hk))
                    [using specialize subgroupClosedInverse(hk) hk-in-H]
                  @conjugate-inverse-formula |
                    inv(op(op(g, hk), inv(g))) = op(op(g, inv(hk)), inv(g))
                    [using specialize conjugateInverse(g, hk)]
                  // inv(k) = (g·hk·g⁻¹)⁻¹ = g·hk⁻¹·g⁻¹
                  @inverse-is-conjugate |
                    inv(k) = op(op(g, inv(hk)), inv(g))
                    [using chain k-is-conjugate-of-hk conjugate-inverse-formula]
                  @inverse-is-conjugate-member |
                    inH(inv(hk)) and inv(k) = op(op(g, inv(hk)), inv(g))
                    [by both inverse-witness-in-H inverse-is-conjugate]
                  @conclusion-inverse-in-conjugate |
                    exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g))
                    [by witness(inv(hk)) inverse-is-conjugate-member]
                }
              @inverse-in-conjugate |
                exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g))
                [by unpacked with-witness-for-k]
            }
          @k-membership-implies-inverse |
            (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g)))
            [by discharge given-k-in-conjugate]
        }
      @discharge-k |
        forall k: G; (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g)))
        [by generalize generalize-k]
    }
  @conclusion |
    forall g, k: G; (exists h: G; inH(h) and k = op(op(g, h), inv(g))) -> (exists h: G; inH(h) and inv(k) = op(op(g, h), inv(g)))
    [by generalize generalize-g]
qed
```
