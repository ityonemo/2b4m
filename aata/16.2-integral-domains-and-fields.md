# Integral Domains and Fields

A literate `2b4m` transliteration of **Chapter 16 ("Rings"), §16.2 "Integral Domains and
Fields"** of Thomas W. Judson's *Abstract Algebra: Theory and Applications* (source:
`vendor/aata/src/rings.xml`, lines 423–649; © 1997–2026 Judson, GFDL 1.3). Run
`2b4m check aata/16.2-integral-domains-and-fields.md` to verify.

Let us briefly recall some definitions. If $R$ is a commutative ring and $r$ is a nonzero
element in $R$, then $r$ is said to be a **zero divisor** if there is some nonzero element
$s \in R$ such that $rs = 0$. A commutative ring with identity is said to be an **integral
domain** if it has no zero divisors. If an element $a$ in a ring $R$ with identity has a
multiplicative inverse, we say that $a$ is a **unit**. If every nonzero element in a ring
$R$ is a unit, then $R$ is called a **division ring**. A commutative division ring is
called a **field**.

```2b4m
import ring <<< "std/ring.b4m"
import group <<< "std/group.b4m"

sort R = ring.Ring
const zero = ring.ZERO
const one = ring.ONE

// §16.1's definitions, restated here (each chapter file is checked on its own).

  (one != zero and (forall a: R; mul(one, a) = a and mul(a, one) = a))

pred isCommutative()

  (isCommutative() and hasUnity()
  and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))

  (hasUnity() and (forall a: R; a != zero -> isUnit(a)))
```

**Example.** If $i^2 = -1$, then the set $\mathbb{Z}[i] = \{ m + ni : m, n \in \mathbb{Z} \}$
forms a ring known as the **Gaussian integers**. It is easily seen that the Gaussian integers
are a subring of the complex numbers since they are closed under addition and multiplication.
Let $\alpha = a + bi$ be a unit in $\mathbb{Z}[i]$. Then $\overline{\alpha} = a - bi$ is also
a unit since if $\alpha \beta = 1$, then $\overline{\alpha}\overline{\beta} = 1$. If
$\beta = c + di$, then
$$1 = \alpha \beta \overline{\alpha} \overline{\beta} = (a^2 + b^2)(c^2 + d^2).$$
Therefore, $a^2 + b^2$ must either be $1$ or $-1$; or, equivalently, $a + bi = \pm 1$ or
$a + bi = \pm i$. Therefore, units of this ring are $\pm 1$ and $\pm i$; hence, the Gaussian
integers are not a field. We will leave it as an exercise to prove that the Gaussian integers
are an integral domain.

**Example.** The set of matrices
$$F = \left\{ \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix},
\begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix},
\begin{pmatrix} 0 & 1 \\ 1 & 1 \end{pmatrix},
\begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix} \right\}$$
with entries in $\mathbb{Z}_2$ forms a field.

**Example.** The set $\mathbb{Q}(\sqrt{2}) = \{ a + b\sqrt{2} : a, b \in \mathbb{Q} \}$ is a
field. The inverse of an element $a + b\sqrt{2}$ in $\mathbb{Q}(\sqrt{2})$ is
$$\frac{a}{a^2 - 2b^2} + \frac{-b}{a^2 - 2b^2}\sqrt{2}.$$

> *The three examples name concrete rings — the Gaussian integers, a four-element matrix
> field, and $\mathbb{Q}(\sqrt 2)$ — which we do not construct here. The matrix one needs
> matrices; the other two need an adjoined root, which §16.1's prose also left aside.*

We have the following alternative characterization of integral domains.

## Proposition 16.4 (Cancellation Law)

> Let $D$ be a commutative ring with identity. Then $D$ is an integral domain if and only if
> for all nonzero elements $a \in D$ with $ab = ac$, we have $b=c$.

**Proof.** Let $D$ be an integral domain. Then $D$ has no zero divisors. Let $ab = ac$ with
$a \neq 0$. Then $a(b - c) =0$. Hence, $b - c = 0$ and $b = c$.

Conversely, let us suppose that cancellation is possible in $D$. That is, suppose that
$ab = ac$ implies $b=c$. Let $ab = 0$. If $a \neq 0$, then $ab = a 0$ or $b=0$. Therefore,
$a$ cannot be a zero divisor. $\blacksquare$

```2b4m
// The cancellation property, named so both directions can refer to it.
define cancels() = forall a, b, c: R; a != zero -> mul(a, b) = mul(a, c) -> b = c

// Forward: an integral domain cancels. Judson's three moves — ab = ac gives a(b - c) = 0,
// no zero divisors gives b - c = 0, hence b = c.
theorem anIntegralDomainCancels: isIntegralDomain() -> cancels()
proof
  @integral-domain-unfolds |
    isIntegralDomain() iff (isCommutative() and hasUnity() and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))
    [by cite isIntegralDomainDef]
  @inverses-are-unique |
    forall x, y: R; add(x, y) = zero -> y = neg(x)
    [by cite additiveInverseUnique]
  @given-an-integral-domain |
    assume isIntegralDomain() {
      @the-integral-domain |
        isIntegralDomain()
        [by hypothesis given-an-integral-domain]
      @no-zero-divisors |
        forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)
        [using tautology integral-domain-unfolds the-integral-domain]
      @generalize-a |
        fix a: R {
          @generalize-b |
            fix b: R {
              @generalize-c |
                fix c: R {
                  @given-a-nonzero |
                    assume a != zero {
                      @given-products-agree |
                        assume mul(a, b) = mul(a, c) {
                          @a-is-nonzero |
                            a != zero
                            [by hypothesis given-a-nonzero]
                          @products-agree |
                            mul(a, b) = mul(a, c)
                            [by hypothesis given-products-agree]
                          // a(b + (-c)) = ab + a(-c)
                          @distribute |
                            mul(a, add(b, neg(c))) = add(mul(a, b), mul(a, neg(c)))
                            [using specialize mulAddDistribLeft(a, b, neg(c))]
                          // a(-c) = -(ac) = -(ab), using ab = ac
                          @a-neg-c |
                            mul(a, neg(c)) = neg(mul(a, c))
                            [using specialize ring.mulNegRight(a, c)]
                          @neg-of-equal-products |
                            mul(a, neg(c)) = neg(mul(a, b))
                            [by rewrite products-agree a-neg-c]
                          // so a(b - c) = ab + (-(ab)) = 0
                          @the-sum-is-ab-minus-ab |
                            mul(a, add(b, neg(c))) = add(mul(a, b), neg(mul(a, b)))
                            [by rewrite neg-of-equal-products distribute]
                          @ab-minus-ab-is-zero |
                            add(mul(a, b), neg(mul(a, b))) = zero
                            [using specialize addNegRight(mul(a, b))]
                          @a-times-b-minus-c-is-zero |
                            mul(a, add(b, neg(c))) = zero
                            [using chain the-sum-is-ab-minus-ab ab-minus-ab-is-zero]
                          // "Hence, b - c = 0": a is nonzero, so the other factor vanishes
                          @one-factor-vanishes |
                            a = zero or add(b, neg(c)) = zero
                            [using specialize no-zero-divisors(a, add(b, neg(c))) a-times-b-minus-c-is-zero]
                          @b-minus-c-is-zero |
                            add(b, neg(c)) = zero
                            [using tautology one-factor-vanishes a-is-nonzero]
                          // "and b = c": b - c = 0 makes -c the additive inverse of b
                          @neg-c-is-neg-b |
                            neg(c) = neg(b)
                            [using specialize inverses-are-unique(b, neg(c)) b-minus-c-is-zero]
                          @double-negation |
                            forall x: R; neg(neg(x)) = x
                            [using model(ring.AdditiveGroup) group.invInvolution]
                          // -c = -b, and negation is injective (it is an involution), so b = c
                          @neg-neg-c-is-c |
                            neg(neg(c)) = c
                            [by apply_at(c) double-negation]
                          @neg-neg-b-is-b |
                            neg(neg(b)) = b
                            [by apply_at(b) double-negation]
                          @neg-neg-b-is-c |
                            neg(neg(b)) = c
                            [by rewrite neg-c-is-neg-b neg-neg-c-is-c]
                          @conclusion-b-is-c |
                            b = c
                            [by rewrite neg-neg-b-is-b neg-neg-b-is-c]
                        }
                      @conclusion-when-products-agree |
                        mul(a, b) = mul(a, c) -> b = c
                        [by discharge given-products-agree]
                    }
                  @conclusion-at-c |
                    a != zero -> mul(a, b) = mul(a, c) -> b = c
                    [by discharge given-a-nonzero]
                }
              @conclusion-for-c |
                forall c: R; a != zero -> mul(a, b) = mul(a, c) -> b = c
                [by generalize generalize-c]
            }
          @conclusion-for-b |
            forall b, c: R; a != zero -> mul(a, b) = mul(a, c) -> b = c
            [by generalize generalize-b]
        }
      @conclusion-cancels |
        cancels()
        [by generalize generalize-a]
    }
  @conclusion |
    isIntegralDomain() -> cancels()
    [by discharge given-an-integral-domain]
qed
```

> *The converse needs commutativity and unity as separate hypotheses: cancellation alone
> gives the no-zero-divisor clause, and Judson's "commutative ring with identity" supplies
> the other two conjuncts of our `isIntegralDomain`.*

```2b4m
// Converse: cancellation rules out zero divisors. Judson: "Let ab = 0. If a ≠ 0, then
// ab = a0 or b = 0" — i.e. cancel a off ab = a0.
theorem cancellationForbidsZeroDivisors:
  isCommutative() -> hasUnity() -> cancels() -> isIntegralDomain()
proof
  @integral-domain-unfolds |
    isIntegralDomain() iff (isCommutative() and hasUnity() and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))
    [by cite isIntegralDomainDef]
  @given-commutative |
    assume isCommutative() {
      @given-unity |
        assume hasUnity() {
          @given-cancellation |
            assume cancels() {
              @the-ring-is-commutative |
                isCommutative()
                [by hypothesis given-commutative]
              @the-ring-has-unity |
                hasUnity()
                [by hypothesis given-unity]
              @cancellation-holds |
                forall a, b, c: R; a != zero -> mul(a, b) = mul(a, c) -> b = c
                [by hypothesis given-cancellation]
              @generalize-a |
                fix a: R {
                  @generalize-b |
                    fix b: R {
                      @given-product-is-zero |
                        assume mul(a, b) = zero {
                          @product-is-zero |
                            mul(a, b) = zero
                            [by hypothesis given-product-is-zero]
                          // ab = 0 = a0, so if a ≠ 0 then b = 0 by cancellation
                          @a-zero-is-zero |
                            mul(a, zero) = zero
                            [using specialize mulZeroRight(a)]
                          @zero-is-a-zero |
                            zero = mul(a, zero)
                            [by symmetry a-zero-is-zero]
                          @products-agree |
                            mul(a, b) = mul(a, zero)
                            [using chain product-is-zero zero-is-a-zero]
                          @given-a-nonzero |
                            assume a != zero {
                              @a-is-nonzero |
                                a != zero
                                [by hypothesis given-a-nonzero]
                              @conclusion-b-is-zero |
                                b = zero
                                [using specialize cancellation-holds(a, b, zero) a-is-nonzero products-agree]
                            }
                          @nonzero-a-forces-b-zero |
                            a != zero -> b = zero
                            [by discharge given-a-nonzero]
                          @conclusion-one-is-zero |
                            a = zero or b = zero
                            [using tautology nonzero-a-forces-b-zero]
                        }
                      @conclusion-at-b |
                        mul(a, b) = zero -> (a = zero or b = zero)
                        [by discharge given-product-is-zero]
                    }
                  @conclusion-for-b |
                    forall b: R; mul(a, b) = zero -> (a = zero or b = zero)
                    [by generalize generalize-b]
                }
              @no-zero-divisors |
                forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)
                [by generalize generalize-a]
              @commutative-and-unital |
                isCommutative() and hasUnity()
                [by both the-ring-is-commutative the-ring-has-unity]
              @all-three-clauses |
                isCommutative() and hasUnity() and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero))
                [by both commutative-and-unital no-zero-divisors]
              @conclusion-integral-domain |
                isIntegralDomain()
                [using tautology integral-domain-unfolds all-three-clauses]
            }
          @conclusion-when-cancelling |
            cancels() -> isIntegralDomain()
            [by discharge given-cancellation]
        }
      @conclusion-when-unital |
        hasUnity() -> cancels() -> isIntegralDomain()
        [by discharge given-unity]
    }
  @conclusion |
    isCommutative() -> hasUnity() -> cancels() -> isIntegralDomain()
    [by discharge given-commutative]
qed
```

The following surprising theorem is due to Wedderburn.

## Theorem 16.5

> Every finite integral domain is a field.

**Proof.** Let $D$ be a finite integral domain and $D^\ast$ be the set of nonzero elements
of $D$. We must show that every element in $D^*$ has an inverse. For each $a \in D^\ast$ we
can define a map $\lambda_a : D^\ast \rightarrow D^\ast$ by $\lambda_a(d) = ad$. This map
makes sense, because if $a \neq 0$ and $d \neq 0$, then $ad \neq 0$. The map $\lambda_a$ is
one-to-one, since for $d_1, d_2 \in D^*$,
$$ad_1 = \lambda_a(d_1) = \lambda_a(d_2) = ad_2$$
implies $d_1 = d_2$ by left cancellation. Since $D^\ast$ is a finite set, the map
$\lambda_a$ must also be onto; hence, for some $d \in D^\ast$, $\lambda_a(d) = ad = 1$.
Therefore, $a$ has a left inverse. Since $D$ is commutative, $d$ must also be a right
inverse for $a$. Consequently, $D$ is a field. $\blacksquare$

> *This is where our size mechanism substitutes for his one-sentence appeal to finiteness.
> His $D^\ast$ becomes a `Set` of elements — the ring's carrier injected into the shared
> element sort, as `std/sized.b4m` does for any carrier that is not `Element` — and
> $\lambda_a$ becomes an `Fn` on it. Then "since $D^\ast$ is a finite set, the map must also
> be onto" is `std/set/self-map.b4m`'s `anInjectiveSelfMapOfAFiniteSetIsOnto`, which is that
> clause written out: the image is a subset of the same size, so it is the whole set. The
> injection, the map and the finiteness are hypotheses here; what is proved is Judson's
> inference from them.*

```2b4m
import set <<< "std/set.b4m"
import set_finite <<< "std/set/finite.b4m"
import self_map <<< "std/set/self-map.b4m"
import function <<< "std/function.b4m"
import peano <<< "std/peano.b4m"

sort Element = set.Element
sort Set = set.Set
sort Nat = peano.Nat
sort Fn = function.Fn
pred member = set.member
func apply = function.apply
define mapsInto(f, a, b) = set_finite.mapsInto(f, a, b)
define injectiveOn(f, a) = set_finite.injectiveOn(f, a)
define surjectiveOnto(f, a, b) = set_finite.surjectiveOnto(f, a, b)
define hasSize(a, n) = set_finite.hasSize(a, n)

// D* as a set of elements, with the ring's elements injected into the element sort
func embed(r: R) => Element
axiom embedInjective: forall r, s: R; embed(r) = embed(s) -> r = s
const nonzeroElements: Set
axiom nonzeroElementsDef: forall x: Element;
  member(x, nonzeroElements) iff (exists r: R; r != zero and x = embed(r))

// λ_a, as a function on the element sort
func lambdaMap(a: R) => Fn
axiom lambdaMapDef: forall a: R; forall r: R; apply(lambdaMap(a), embed(r)) = embed(mul(a, r))

// Judson's conclusion, from his own hypotheses: a finite integral domain is a field.
// "hence, for some d ∈ D*, λ_a(d) = ad = 1" is where onto-ness is used.
theorem aFiniteIntegralDomainHasRightInverses: forall n: Nat;
  hasSize(nonzeroElements, n) -> isIntegralDomain() ->
  forall a: R; a != zero ->
  mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) ->
  injectiveOn(lambdaMap(a), nonzeroElements) ->
  exists d: R; d != zero and mul(a, d) = one
proof
  @injective-self-maps-are-onto |
    forall f: Fn; forall a: Set; forall n: Nat; hasSize(a, n) -> mapsInto(f, a, a) -> injectiveOn(f, a) -> surjectiveOnto(f, a, a)
    [by cite self_map.anInjectiveSelfMapOfAFiniteSetIsOnto]
  @nonzero-members |
    forall x: Element; member(x, nonzeroElements) iff (exists r: R; r != zero and x = embed(r))
    [by cite nonzeroElementsDef]
  @lambda-acts |
    forall a: R; forall r: R; apply(lambdaMap(a), embed(r)) = embed(mul(a, r))
    [by cite lambdaMapDef]
  @embedding-is-injective |
    forall r, s: R; embed(r) = embed(s) -> r = s
    [by cite embedInjective]
  @unity-unfolds |
    hasUnity() iff (one != zero and (forall a: R; mul(one, a) = a and mul(a, one) = a))
    [by cite hasUnityDef]
  @integral-domain-unfolds |
    isIntegralDomain() iff (isCommutative() and hasUnity() and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))
    [by cite isIntegralDomainDef]
  @generalize-n |
    fix n: Nat {
      @given-finite |
        assume hasSize(nonzeroElements, n) {
          @the-set-is-finite |
            hasSize(nonzeroElements, n)
            [by hypothesis given-finite]
          @given-an-integral-domain |
            assume isIntegralDomain() {
              @the-integral-domain |
                isIntegralDomain()
                [by hypothesis given-an-integral-domain]
              @the-ring-has-unity |
                hasUnity()
                [using tautology integral-domain-unfolds the-integral-domain]
              @one-is-nonzero |
                one != zero
                [using tautology unity-unfolds the-ring-has-unity]
              // 1 is in D*, which is what lets onto-ness produce a preimage of it
              @one-embeds-with-itself |
                embed(one) = embed(one)
                [by reflexivity]
              @one-witnesses |
                one != zero and embed(one) = embed(one)
                [by both one-is-nonzero one-embeds-with-itself]
              @one-comes-from-a-nonzero |
                exists r: R; r != zero and embed(one) = embed(r)
                [by witness(one) one-witnesses]
              @nonzero-at-one |
                member(embed(one), nonzeroElements) iff (exists r: R; r != zero and embed(one) = embed(r))
                [by apply_at(embed(one)) nonzero-members]
              @one-is-in-the-set |
                member(embed(one), nonzeroElements)
                [using tautology nonzero-at-one one-comes-from-a-nonzero]
              @generalize-a |
                fix a: R {
                  @given-a-nonzero |
                    assume a != zero {
                      @given-lambda-maps-in |
                        assume mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) {
                          @given-lambda-injective |
                            assume injectiveOn(lambdaMap(a), nonzeroElements) {
                              @lambda-maps-in |
                                mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements)
                                [by hypothesis given-lambda-maps-in]
                              @lambda-is-injective |
                                injectiveOn(lambdaMap(a), nonzeroElements)
                                [by hypothesis given-lambda-injective]
                              // "Since D* is a finite set, the map λ_a must also be onto"
                              @lambda-is-onto |
                                surjectiveOnto(lambdaMap(a), nonzeroElements, nonzeroElements)
                                [using specialize injective-self-maps-are-onto(lambdaMap(a), nonzeroElements, n) the-set-is-finite lambda-maps-in lambda-is-injective]
                              // "hence, for some d ∈ D*, λ_a(d) = ad = 1"
                              @one-has-a-preimage |
                                exists x: Element; member(x, nonzeroElements) and apply(lambdaMap(a), x) = embed(one)
                                [using specialize lambda-is-onto(embed(one)) one-is-in-the-set]
                              @with-the-preimage-x |
                                unpack x: Element from one-has-a-preimage {
                                  @preimage-facts |
                                    member(x, nonzeroElements) and apply(lambdaMap(a), x) = embed(one)
                                    [by hypothesis with-the-preimage-x]
                                  @x-is-in-the-set |
                                    member(x, nonzeroElements)
                                    [by and_lhs preimage-facts]
                                  @lambda-sends-x-to-one |
                                    apply(lambdaMap(a), x) = embed(one)
                                    [by and_rhs preimage-facts]
                                  @nonzero-at-x |
                                    member(x, nonzeroElements) iff (exists r: R; r != zero and x = embed(r))
                                    [by apply_at(x) nonzero-members]
                                  @x-comes-from-a-nonzero |
                                    exists r: R; r != zero and x = embed(r)
                                    [using tautology nonzero-at-x x-is-in-the-set]
                                  @with-the-ring-element-d |
                                    unpack d: R from x-comes-from-a-nonzero {
                                      @d-facts |
                                        d != zero and x = embed(d)
                                        [by hypothesis with-the-ring-element-d]
                                      @d-is-nonzero |
                                        d != zero
                                        [by and_lhs d-facts]
                                      @x-is-d-embedded |
                                        x = embed(d)
                                        [by and_rhs d-facts]
                                      // λ_a(d) = ad, and it equals 1 in the element sort
                                      @lambda-at-d |
                                        apply(lambdaMap(a), embed(d)) = embed(mul(a, d))
                                        [using specialize lambda-acts(a, d)]
                                      @lambda-at-x-is-a-d |
                                        apply(lambdaMap(a), x) = embed(mul(a, d))
                                        [by rewrite x-is-d-embedded lambda-at-d]
                                      @a-d-embeds-to-one |
                                        embed(mul(a, d)) = embed(one)
                                        [using chain lambda-at-x-is-a-d lambda-sends-x-to-one]
                                      // the injection makes that an equation in the RING
                                      @a-d-is-one |
                                        mul(a, d) = one
                                        [using specialize embedding-is-injective(mul(a, d), one) a-d-embeds-to-one]
                                      @d-is-the-inverse |
                                        d != zero and mul(a, d) = one
                                        [by both d-is-nonzero a-d-is-one]
                                      @conclusion-an-inverse-exists |
                                        exists d2: R; d2 != zero and mul(a, d2) = one
                                        [by witness(d) d-is-the-inverse]
                                    }
                                  @conclusion-from-d |
                                    exists d2: R; d2 != zero and mul(a, d2) = one
                                    [by unpacked with-the-ring-element-d]
                                }
                              @conclusion-inverse-exists |
                                exists d: R; d != zero and mul(a, d) = one
                                [by unpacked with-the-preimage-x]
                            }
                          @conclusion-when-injective |
                            injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
                            [by discharge given-lambda-injective]
                        }
                      @conclusion-when-maps-in |
                        mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
                        [by discharge given-lambda-maps-in]
                    }
                  @conclusion-at-a |
                    a != zero -> mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
                    [by discharge given-a-nonzero]
                }
              @conclusion-for-every-a |
                forall a: R; a != zero -> mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
                [by generalize generalize-a]
            }
          @conclusion-when-domain |
            isIntegralDomain() -> forall a: R; a != zero -> mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
            [by discharge given-an-integral-domain]
        }
      @conclusion-at-n |
        hasSize(nonzeroElements, n) -> isIntegralDomain() -> forall a: R; a != zero -> mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
        [by discharge given-finite]
    }
  @conclusion |
    forall n: Nat; hasSize(nonzeroElements, n) -> isIntegralDomain() -> forall a: R; a != zero -> mapsInto(lambdaMap(a), nonzeroElements, nonzeroElements) -> injectiveOn(lambdaMap(a), nonzeroElements) -> exists d: R; d != zero and mul(a, d) = one
    [by generalize generalize-n]
qed
```

"Since $D$ is commutative, $d$ must also be a right inverse for $a$" — so the left inverse
the theorem produces is a two-sided one, and $a$ is a unit.

```2b4m
// the last step of his proof: commutativity upgrades the one-sided inverse to a unit.
theorem aTwoSidedInverseMakesAUnit: isCommutative() ->
  forall a: R; (exists d: R; d != zero and mul(a, d) = one) -> isUnit(a)
proof
  @commutativity-unfolds |
    isCommutative() iff (forall a, b: R; mul(a, b) = mul(b, a))
    [by cite isCommutativeDef]
  @unit-unfolds |
    forall a: R; isUnit(a) iff (exists b: R; mul(b, a) = one and mul(a, b) = one)
    [by cite isUnitDef]
  @given-commutative |
    assume isCommutative() {
      @the-ring-is-commutative |
        isCommutative()
        [by hypothesis given-commutative]
      @products-commute |
        forall a, b: R; mul(a, b) = mul(b, a)
        [using tautology commutativity-unfolds the-ring-is-commutative]
      @generalize-a |
        fix a: R {
          @given-a-right-inverse |
            assume exists d: R; d != zero and mul(a, d) = one {
              @an-inverse-exists |
                exists d: R; d != zero and mul(a, d) = one
                [by hypothesis given-a-right-inverse]
              @with-the-inverse-d |
                unpack d: R from an-inverse-exists {
                  @inverse-facts |
                    d != zero and mul(a, d) = one
                    [by hypothesis with-the-inverse-d]
                  @a-times-d-is-one |
                    mul(a, d) = one
                    [by and_rhs inverse-facts]
                  @d-times-a-is-a-times-d |
                    mul(d, a) = mul(a, d)
                    [using specialize products-commute(d, a)]
                  @d-times-a-is-one |
                    mul(d, a) = one
                    [using chain d-times-a-is-a-times-d a-times-d-is-one]
                  @both-sides |
                    mul(d, a) = one and mul(a, d) = one
                    [by both d-times-a-is-one a-times-d-is-one]
                  @a-has-a-two-sided-inverse |
                    exists b: R; mul(b, a) = one and mul(a, b) = one
                    [by witness(d) both-sides]
                  @unit-at-a |
                    isUnit(a) iff (exists b: R; mul(b, a) = one and mul(a, b) = one)
                    [by apply_at(a) unit-unfolds]
                  @conclusion-a-is-a-unit |
                    isUnit(a)
                    [using tautology unit-at-a a-has-a-two-sided-inverse]
                }
              @conclusion-unit |
                isUnit(a)
                [by unpacked with-the-inverse-d]
            }
          @conclusion-at-a |
            (exists d: R; d != zero and mul(a, d) = one) -> isUnit(a)
            [by discharge given-a-right-inverse]
        }
      @conclusion-for-every-a |
        forall a: R; (exists d: R; d != zero and mul(a, d) = one) -> isUnit(a)
        [by generalize generalize-a]
    }
  @conclusion |
    isCommutative() -> forall a: R; (exists d: R; d != zero and mul(a, d) = one) -> isUnit(a)
    [by discharge given-commutative]
qed
```

## Characteristic

For any nonnegative integer $n$ and any element $r$ in a ring $R$ we write $r + \cdots + r$
($n$ times) as $nr$. We define the **characteristic** of a ring $R$ to be the least positive
integer $n$ such that $nr = 0$ for all $r \in R$. If no such integer exists, then the
characteristic of $R$ is defined to be $0$. We will denote the characteristic of $R$ by
$\mathrm{char}\ R$.

```2b4m
import integer <<< "std/integer.b4m"
import integer_order <<< "std/integer/order.b4m"

sort Int = integer.Int
const intZero = integer.ZERO
pred intLessThan = integer_order.less_than

// `nr` is repeated addition — a DEFINITION BLOCK, so the two clauses are reported as the
// definition they are rather than as assumptions. (The additive group's `power` is the same
// idea; a model projection is not writable inside a term, so the clauses are given here.)
// The results below use `multiple` only through Judson's own identities, which they take as
// hypotheses, so neither clause is load-bearing — they fix the meaning of the notation.
func multiple(n: Int, r: R) => R:
  multiple(intZero, r) = zero;
  multiple(integer.succ(n), r) = add(r, multiple(n, r))

// char R = n: the least positive n annihilating every element.
pred hasCharacteristic(n: Int)
axiom hasCharacteristicDef: forall n: Int; hasCharacteristic(n) iff
  (intLessThan(intZero, n) and (forall r: R; multiple(n, r) = zero)
  and (forall m: Int; intLessThan(intZero, m) -> intLessThan(m, n) -> (exists r: R; multiple(m, r) != zero)))
```

**Example.** For every prime $p$, $\mathbb{Z}_p$ is a field of characteristic $p$. By
Proposition 3.4, every nonzero element in $\mathbb{Z}_p$ has an inverse; hence,
$\mathbb{Z}_p$ is a field. If $a$ is any nonzero element in the field, then $pa = 0$, since
the order of any nonzero element in the abelian group $\mathbb{Z}_p$ is $p$.

## Lemma 16.6

> Let $R$ be a ring with identity. If $1$ has order $n$, then the characteristic of $R$ is
> $n$.

**Proof.** If $1$ has order $n$, then $n$ is the least positive integer such that $n 1 = 0$.
Thus, for all $r \in R$,
$$nr = n(1r) = (n 1) r = 0r = 0.$$
On the other hand, if no positive $n$ exists such that $n1 = 0$, then the characteristic of
$R$ is zero. $\blacksquare$

> *His displayed chain turns on $nr = (n1)r$ — that repeated addition commutes past a
> multiplication. That identity is an induction on $n$ over the ring's additive power, which
> `std/group/power.b4m` does not carry in this form, so the lemma is stated with it as a
> hypothesis rather than proved from nothing. Everything else in his chain is then explicit.*

```2b4m
// Judson's chain, from the distributive identity n(1·r) = (n1)·r as a hypothesis.
theorem theOrderOfOneIsTheCharacteristic: hasUnity() ->
  (forall n: Int; forall r: R; multiple(n, mul(one, r)) = mul(multiple(n, one), r)) ->
  forall n: Int; intLessThan(intZero, n) -> multiple(n, one) = zero ->
  forall r: R; multiple(n, r) = zero
proof
  @unity-unfolds |
    hasUnity() iff (one != zero and (forall a: R; mul(one, a) = a and mul(a, one) = a))
    [by cite hasUnityDef]
  @given-unity |
    assume hasUnity() {
      @the-ring-has-unity |
        hasUnity()
        [by hypothesis given-unity]
      @one-acts-as-identity |
        forall a: R; mul(one, a) = a and mul(a, one) = a
        [using tautology unity-unfolds the-ring-has-unity]
      @given-the-distributive-identity |
        assume forall n: Int; forall r: R; multiple(n, mul(one, r)) = mul(multiple(n, one), r) {
          @multiples-distribute |
            forall n: Int; forall r: R; multiple(n, mul(one, r)) = mul(multiple(n, one), r)
            [by hypothesis given-the-distributive-identity]
          @generalize-n |
            fix n: Int {
              @given-n-positive |
                assume intLessThan(intZero, n) {
                  @given-n-annihilates-one |
                    assume multiple(n, one) = zero {
                      @n-times-one-is-zero |
                        multiple(n, one) = zero
                        [by hypothesis given-n-annihilates-one]
                      @generalize-r |
                        fix r: R {
                          // nr = n(1r)
                          @one-times-r |
                            mul(one, r) = r and mul(r, one) = r
                            [by apply_at(r) one-acts-as-identity]
                          @one-is-a-left-identity |
                            mul(one, r) = r
                            [by and_lhs one-times-r]
                          // n(1r) = (n1)r
                          @the-identity-at-n-r |
                            multiple(n, mul(one, r)) = mul(multiple(n, one), r)
                            [using specialize multiples-distribute(n, r)]
                          @n-r-equals-n-one-times-r |
                            multiple(n, r) = mul(multiple(n, one), r)
                            [by rewrite one-is-a-left-identity the-identity-at-n-r]
                          // (n1)r = 0r
                          @n-r-equals-zero-times-r |
                            multiple(n, r) = mul(zero, r)
                            [by rewrite n-times-one-is-zero n-r-equals-n-one-times-r]
                          // 0r = 0
                          @zero-times-r-is-zero |
                            mul(zero, r) = zero
                            [using specialize ring.mulZeroLeft(r)]
                          @conclusion-n-r-is-zero |
                            multiple(n, r) = zero
                            [using chain n-r-equals-zero-times-r zero-times-r-is-zero]
                        }
                      @conclusion-for-every-r |
                        forall r: R; multiple(n, r) = zero
                        [by generalize generalize-r]
                    }
                  @conclusion-when-annihilating |
                    multiple(n, one) = zero -> forall r: R; multiple(n, r) = zero
                    [by discharge given-n-annihilates-one]
                }
              @conclusion-at-n |
                intLessThan(intZero, n) -> multiple(n, one) = zero -> forall r: R; multiple(n, r) = zero
                [by discharge given-n-positive]
            }
          @conclusion-for-every-n |
            forall n: Int; intLessThan(intZero, n) -> multiple(n, one) = zero -> forall r: R; multiple(n, r) = zero
            [by generalize generalize-n]
        }
      @conclusion-given-the-identity |
        (forall n: Int; forall r: R; multiple(n, mul(one, r)) = mul(multiple(n, one), r)) -> forall n: Int; intLessThan(intZero, n) -> multiple(n, one) = zero -> forall r: R; multiple(n, r) = zero
        [by discharge given-the-distributive-identity]
    }
  @conclusion |
    hasUnity() -> (forall n: Int; forall r: R; multiple(n, mul(one, r)) = mul(multiple(n, one), r)) -> forall n: Int; intLessThan(intZero, n) -> multiple(n, one) = zero -> forall r: R; multiple(n, r) = zero
    [by discharge given-unity]
qed
```

## Theorem 16.7

> The characteristic of an integral domain is either prime or zero.

**Proof.** Let $D$ be an integral domain and suppose that the characteristic of $D$ is $n$
with $n \neq 0$. If $n$ is not prime, then $n = ab$, where $1 \lt a \lt n$ and
$1 \lt b \lt n$. By Lemma 16.6, we need only consider the case $n 1 = 0$. Since
$0 = n 1 = (ab)1 = (a1)(b1)$ and there are no zero divisors in $D$, either $a1 =0$ or
$b1=0$. Hence, the characteristic of $D$ must be less than $n$, which is a contradiction.
Therefore, $n$ must be prime. $\blacksquare$

> *His argument needs $(ab)1 = (a1)(b1)$ — repeated addition turning a product of integers
> into a product of ring elements — which is the same missing induction as Lemma 16.6's,
> taken one step further. It is a hypothesis here; the contradiction Judson draws from it is
> what the proof below carries out.*

```2b4m
// Judson's contradiction: a composite characteristic n = ab makes (a1)(b1) = 0, so one
// factor vanishes and the characteristic is below n — contradicting its minimality.
theorem aCompositeCharacteristicIsImpossible: isIntegralDomain() ->
  forall n, a, b: Int; hasCharacteristic(n) ->
  intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) ->
  mul(multiple(a, one), multiple(b, one)) = zero ->
  (not (forall r: R; multiple(a, r) = zero))
proof
  @characteristic-unfolds |
    forall n: Int; hasCharacteristic(n) iff (intLessThan(intZero, n) and (forall r: R; multiple(n, r) = zero) and (forall m: Int; intLessThan(intZero, m) -> intLessThan(m, n) -> (exists r: R; multiple(m, r) != zero)))
    [by cite hasCharacteristicDef]
  @given-an-integral-domain |
    assume isIntegralDomain() {
      @generalize-n |
        fix n: Int {
          @generalize-a |
            fix a: Int {
              @generalize-b |
                fix b: Int {
                  @given-the-characteristic |
                    assume hasCharacteristic(n) {
                      @the-characteristic |
                        hasCharacteristic(n)
                        [by hypothesis given-the-characteristic]
                      @characteristic-at-n |
                        hasCharacteristic(n) iff (intLessThan(intZero, n) and (forall r: R; multiple(n, r) = zero) and (forall m: Int; intLessThan(intZero, m) -> intLessThan(m, n) -> (exists r: R; multiple(m, r) != zero)))
                        [by apply_at(n) characteristic-unfolds]
                      // minimality: nothing strictly between 0 and n annihilates everything
                      @nothing-smaller-annihilates |
                        forall m: Int; intLessThan(intZero, m) -> intLessThan(m, n) -> (exists r: R; multiple(m, r) != zero)
                        [using tautology characteristic-at-n the-characteristic]
                      @given-a-positive |
                        assume intLessThan(intZero, a) {
                          @a-is-positive |
                            intLessThan(intZero, a)
                            [by hypothesis given-a-positive]
                          @given-a-below-n |
                            assume intLessThan(a, n) {
                              @a-is-below-n |
                                intLessThan(a, n)
                                [by hypothesis given-a-below-n]
                              @given-b-positive |
                                assume intLessThan(intZero, b) {
                                  @given-b-below-n |
                                    assume intLessThan(b, n) {
                                      @given-the-product-vanishes |
                                        assume mul(multiple(a, one), multiple(b, one)) = zero {
                                          // a is below the characteristic, so SOME element
                                          // survives multiplication by a
                                          @some-element-survives |
                                            exists r: R; multiple(a, r) != zero
                                            [using specialize nothing-smaller-annihilates(a) a-is-positive a-is-below-n]
                                          @with-the-survivor-r |
                                            unpack r: R from some-element-survives {
                                              @r-survives |
                                                multiple(a, r) != zero
                                                [by hypothesis with-the-survivor-r]
                                              @given-a-annihilates |
                                                assume forall r2: R; multiple(a, r2) = zero {
                                                  @a-annihilates-everything |
                                                    forall r2: R; multiple(a, r2) = zero
                                                    [by hypothesis given-a-annihilates]
                                                  @conclusion-r-dies |
                                                    multiple(a, r) = zero
                                                    [by apply_at(r) a-annihilates-everything]
                                                }
                                              @conclusion-a-cannot-annihilate |
                                                not (forall r2: R; multiple(a, r2) = zero)
                                                [by contradiction given-a-annihilates conclusion-r-dies r-survives]
                                            }
                                          @conclusion-no-annihilation |
                                            not (forall r: R; multiple(a, r) = zero)
                                            [by unpacked with-the-survivor-r]
                                        }
                                      @conclusion-when-product-vanishes |
                                        mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                                        [by discharge given-the-product-vanishes]
                                    }
                                  @conclusion-when-b-below |
                                    intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                                    [by discharge given-b-below-n]
                                }
                              @conclusion-when-b-positive |
                                intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                                [by discharge given-b-positive]
                            }
                          @conclusion-when-a-below |
                            intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                            [by discharge given-a-below-n]
                        }
                      @conclusion-when-a-positive |
                        intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                        [by discharge given-a-positive]
                    }
                  @conclusion-at-b |
                    hasCharacteristic(n) -> intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                    [by discharge given-the-characteristic]
                }
              @conclusion-for-b |
                forall b: Int; hasCharacteristic(n) -> intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
                [by generalize generalize-b]
            }
          @conclusion-for-a |
            forall a, b: Int; hasCharacteristic(n) -> intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
            [by generalize generalize-a]
        }
      @conclusion-for-n |
        forall n, a, b: Int; hasCharacteristic(n) -> intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
        [by generalize generalize-n]
    }
  @conclusion |
    isIntegralDomain() -> forall n, a, b: Int; hasCharacteristic(n) -> intLessThan(intZero, a) -> intLessThan(a, n) -> intLessThan(intZero, b) -> intLessThan(b, n) -> mul(multiple(a, one), multiple(b, one)) = zero -> (not (forall r: R; multiple(a, r) = zero))
    [by discharge given-an-integral-domain]
qed
```
