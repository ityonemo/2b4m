Run `2b4m check aata/9.2-direct-products.md` to verify.

The direct product lives in `std/group/product.b4m`.

## External direct products

**Definition.** Let $G$ and $H$ be groups. The **external direct product**
$G \times H$ is the set of ordered pairs $(g, h)$ with $g \in G$ and $h \in H$, under
the componentwise operation
$$(g_1, h_1)(g_2, h_2) = (g_1 g_2,\ h_1 h_2).$$

As in §9.1, the two factors are *declared* independently rather than aliased from one
import — identity-by-origin would otherwise collapse them to a single sort, and a
product of a group with itself is not what the theory is about. `product.b4m` declares
both and keeps them symmetric, which is the content.

```2b4m
import product <<< "std/group/product.b4m"
import group <<< "std/group.b4m"

// the two factors and their structure
sort G = product.G
sort H = product.H
const eG = product.EG
const eH = product.EH
func opG = product.opG
func opH = product.opH

// the product: pairs, their projections, and the componentwise operation
sort Pair = product.Pair
func pair = product.pair
func fst = product.fst
func snd = product.snd
func prodOp = product.prodOp
const prodE = product.prodE
```

The componentwise operation really is componentwise — the projections of a product are
the products of the projections:

```2b4m
fact fstOfProduct = product.fstOfProduct
fact sndOfProduct = product.sndOfProduct

// inputs the proofs below cite
const EG = product.EG
const EH = product.EH
fact fstPair = product.fstPair
fact opGAssoc = product.opGAssoc
fact opGIdentityLeft = product.opGIdentityLeft
fact opGInverseLeft = product.opGInverseLeft
fact opHAssoc = product.opHAssoc
fact opHIdentityLeft = product.opHIdentityLeft
fact opHInverseLeft = product.opHInverseLeft
fact pairExtensionality = product.pairExtensionality
fact prodEDef = product.prodEDef
func prodInv = product.prodInv
fact prodInvDef = product.prodInvDef
fact prodOpDef = product.prodOpDef
fact sndPair = product.sndPair

model ProductGroup {
  group.Grp: Pair
  group.E: prodE
  group.op: prodOp
  group.inverse: prodInv
  group.opAssoc <- prodAssoc
  group.opIdentityLeft <- prodIdentityLeft
  group.opInverseLeft <- prodInverseLeft
}
```

**Proposition 9.13.** $G \times H$ is a group under the componentwise operation.

The three group laws are proved over the pair sort, and `model ProductGroup` then makes
$G \times H$ a group so `std/group.b4m`'s whole corpus transfers to it:

```2b4m
theorem prodAssoc: forall p, q, r: Pair; prodOp(prodOp(p, q), r) = prodOp(p, prodOp(q, r))
proof
  @conclusion |
    forall p, q, r: Pair; prodOp(prodOp(p, q), r) = prodOp(p, prodOp(q, r))
    [using simplify_quantified prodOpDef fstPair sndPair opGAssoc opHAssoc]
qed
theorem prodIdentityLeft: forall p: Pair; prodOp(prodE, p) = p
proof
  @conclusion |
    forall p: Pair; prodOp(prodE, p) = p
    [using simplify_quantified prodOpDef prodEDef fstPair sndPair opGIdentityLeft opHIdentityLeft pairExtensionality]
qed
theorem prodInverseLeft: forall p: Pair; prodOp(prodInv(p), p) = prodE
proof
  @conclusion |
    forall p: Pair; prodOp(prodInv(p), p) = prodE
    [using simplify_quantified prodOpDef prodInvDef prodEDef fstPair sndPair opGInverseLeft opHInverseLeft]
qed
```

Judson notes the identity is $(e, e)$ and the inverse of $(g, h)$ is
$(g^{-1}, h^{-1})$; the right-handed laws and cancellation come through the model
rather than being re-proved:

```2b4m
theorem prodIdentityRight: forall p: Pair; prodOp(p, prodE) = p
proof
  @conclusion |
    forall p: Pair; prodOp(p, prodE) = p
    [using model(ProductGroup) group.opIdentityRight]
qed
theorem prodInverseRight: forall p: Pair; prodOp(p, prodInv(p)) = prodE
proof
  @conclusion |
    forall p: Pair; prodOp(p, prodInv(p)) = prodE
    [using model(ProductGroup) group.opInverseRight]
qed
theorem prodCancelLeft: forall a, b, c: Pair; prodOp(a, b) = prodOp(a, c) -> b = c
proof
  @conclusion |
    forall a, b, c: Pair; prodOp(a, b) = prodOp(a, c) -> b = c
    [using model(ProductGroup) group.cancelLeft]
qed
```

## Theorem 9.17 — the order of a tuple

**Theorem 9.17.** Let $(g_1, \ldots, g_n) \in \prod G_i$. If $g_i$ has finite order
$r_i$ in $G_i$, then the order of $(g_1, \ldots, g_n)$ in $\prod G_i$ is the least
common multiple of $r_1, \ldots, r_n$.

**Example.** Let $(8, 56) \in \mathbb{Z}_{12} \times \mathbb{Z}_{60}$. Since
$\gcd(8,12) = 4$, the order of 8 is $12/4 = 3$; similarly the order of 56 in
$\mathbb{Z}_{60}$ is 15. The least common multiple of 3 and 15 is 15, so $(8,56)$ has
order 15.

The theorem rests on a single structural fact: a pair is the identity exactly when
*both* components are. So the exponents that kill $(g, h)$ are precisely the common
multiples of the two component orders, and the least of those is the lcm.

```2b4m
theorem pairIsIdentityIffComponentsAre: forall p: Pair;
  p = prodE iff (fst(p) = EG and snd(p) = EH)
proof
  @generalize-p |
    fix p: Pair {
      @identity-is-the-pair-of-identities |
        prodE = pair(EG, EH)
        [by cite prodEDef]
      @p-is-its-projections |
        pair(fst(p), snd(p)) = p
        [using specialize pairExtensionality(p)]
      // forward: p = prodE makes each projection the corresponding identity
      @given-p-is-the-identity |
        assume p = prodE {
          @p-is-the-identity |
            p = prodE
            [by hypothesis given-p-is-the-identity]
          @p-is-the-identity-pair |
            p = pair(EG, EH)
            [using chain p-is-the-identity identity-is-the-pair-of-identities]
          @first-projection-of-the-identity-pair |
            fst(pair(EG, EH)) = EG
            [using specialize fstPair(EG, EH)]
          @second-projection-of-the-identity-pair |
            snd(pair(EG, EH)) = EH
            [using specialize sndPair(EG, EH)]
          @first-projection-is-eg |
            fst(p) = EG
            [by rewrite p-is-the-identity-pair first-projection-of-the-identity-pair]
          @second-projection-is-eh |
            snd(p) = EH
            [by rewrite p-is-the-identity-pair second-projection-of-the-identity-pair]
          @conclusion-both-components |
            fst(p) = EG and snd(p) = EH
            [by both first-projection-is-eg second-projection-is-eh]
        }
      @forward |
        p = prodE -> (fst(p) = EG and snd(p) = EH)
        [by discharge given-p-is-the-identity]
      // backward: both projections at the identities rebuild prodE by extensionality
      @given-both-components |
        assume fst(p) = EG and snd(p) = EH {
          @both-components |
            fst(p) = EG and snd(p) = EH
            [by hypothesis given-both-components]
          @first-is-eg |
            fst(p) = EG
            [by and_lhs both-components]
          @second-is-eh |
            snd(p) = EH
            [by and_rhs both-components]
          @rebuilt-with-eg |
            pair(EG, snd(p)) = p
            [by rewrite first-is-eg p-is-its-projections]
          @rebuilt-with-both |
            pair(EG, EH) = p
            [by rewrite second-is-eh rebuilt-with-eg]
          @identity-rebuilt |
            prodE = p
            [using chain identity-is-the-pair-of-identities rebuilt-with-both]
          @conclusion-p-is-the-identity |
            p = prodE
            [by symmetry identity-rebuilt]
        }
      @backward |
        (fst(p) = EG and snd(p) = EH) -> p = prodE
        [by discharge given-both-components]
      @conclusion-iff |
        p = prodE iff (fst(p) = EG and snd(p) = EH)
        [by make_equivalence forward backward]
    }
  @conclusion |
    forall p: Pair; p = prodE iff (fst(p) = EG and snd(p) = EH)
    [by generalize generalize-p]
qed
```

The step from there to "the order *is* the lcm" additionally needs `power` over the
pair sort and the lcm's minimality, which `std/integer/lattice.b4m` has for integers
but which has not been connected to a product's element orders. The $k = 3$ instance
is available as a worked case:

```2b4m
theorem cubeIsIdentityComponentwise: forall p: Pair; opG(opG(fst(p), fst(p)), fst(p)) = EG -> opH(opH(snd(p), snd(p)), snd(p)) = EH -> prodOp(prodOp(p, p), p) = prodE
proof
  @generalize-p |
    fix p: Pair {
      @given-first-cubes-to-identity |
        assume opG(opG(fst(p), fst(p)), fst(p)) = EG {
          @given-second-cubes-to-identity |
            assume opH(opH(snd(p), snd(p)), snd(p)) = EH {
              @first-cubes-to-identity |
                opG(opG(fst(p), fst(p)), fst(p)) = EG
                [by hypothesis given-first-cubes-to-identity]
              @second-cubes-to-identity |
                opH(opH(snd(p), snd(p)), snd(p)) = EH
                [by hypothesis given-second-cubes-to-identity]
              @conclusion-cube-is-identity |
                prodOp(prodOp(p, p), p) = prodE
                [using simplify prodOpDef prodEDef fstPair sndPair first-cubes-to-identity second-cubes-to-identity]
            }
          @second-implies |
            opH(opH(snd(p), snd(p)), snd(p)) = EH -> prodOp(prodOp(p, p), p) = prodE
            [by discharge given-second-cubes-to-identity]
        }
      @first-implies |
        opG(opG(fst(p), fst(p)), fst(p)) = EG -> opH(opH(snd(p), snd(p)), snd(p)) = EH -> prodOp(prodOp(p, p), p) = prodE
        [by discharge given-first-cubes-to-identity]
    }
  @conclusion |
    forall p: Pair; opG(opG(fst(p), fst(p)), fst(p)) = EG -> opH(opH(snd(p), snd(p)), snd(p)) = EH -> prodOp(prodOp(p, p), p) = prodE
    [by generalize generalize-p]
qed
```

## Theorem 9.21 — when a product of cyclic groups is cyclic

**Theorem 9.21.** The group $\mathbb{Z}_m \times \mathbb{Z}_n$ is isomorphic to
$\mathbb{Z}_{mn}$ if and only if $\gcd(m,n) = 1$.

*Proof sketch (Judson).* For the forward direction he proves the contrapositive: if
$\gcd(m,n) = d > 1$ then $mn/d$ is divisible by both $m$ and $n$, so
$(a,b) + \cdots + (a,b)$ ($mn/d$ times) $= (0,0)$ for *every* $(a,b)$ — no element has
order $mn$, so the product is not cyclic.

Not transliterated. It needs an isomorphism *between two concrete groups*
($\mathbb{Z}_m \times \mathbb{Z}_n$ and $\mathbb{Z}_{mn}$) with $m$ and $n$ as
parameters, and `std/integer/mod-n.b4m` fixes its modulus as a single constant `N` —
there is one $\mathbb{Z}_n$ per file, not a family indexed by $n$. `std/integer/mod-n-product.b4m`
models ℤ_n × ℤ_n for a single modulus, which is the diagonal case rather than the
general one. See `CHAPTER9-PAINPOINTS`.

**Example.** $\mathbb{Z}_2 \times \mathbb{Z}_3 \cong \mathbb{Z}_6$, because $(1,1)$
generates the product — unlike $\mathbb{Z}_2 \times \mathbb{Z}_2$, which is not
isomorphic to $\mathbb{Z}_4$. Both are concrete computations in small groups.

## Internal direct products

Judson's §9.2 closes with **internal** direct products: $G$ is the internal direct
product of subgroups $H$ and $K$ when $G = HK$, $H \cap K = \{e\}$, and $hk = kh$ for
all $h \in H$, $k \in K$ — and then $G \cong H \times K$. This needs subgroup
*products* and *intersections* as subgroups, which `std/subgroup.b4m` expresses as
membership predicates; the theorem is an isomorphism between a group and a product,
which runs into the same two-concrete-groups limit as Theorem 9.21. Recorded as prose.
