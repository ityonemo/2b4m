## Congruence modulo $n$

Recall from Chapter 1 (§1.2, Example) the equivalence relation of **congruence
modulo $n$** on the integers: $a$ is congruent to $b$ modulo $n$, written
$a \equiv b \pmod n$, exactly when $n$ divides $a - b$. The equivalence classes
under this relation are the sets

$$[a] = \{ \ldots, a - 2n,\ a - n,\ a,\ a + n,\ a + 2n, \ldots \},$$

and $\mathbb Z_n = \{[0], [1], \ldots, [n-1]\}$ is the set of these $n$ classes.

We encode $a \equiv b \pmod n$ directly as the relation on $\mathbb Z$; the
packaging of the classes into the set $\mathbb Z_n$ (a set of sets) is not
needed for the proposition Judson proves.

```bpa
// a ≡ b (mod n)  ⟺  n | (a − b).
define congruent(a, b, n) = does_divide(n, sub(a, b))
```

## The proposition on equivalence classes in $\mathbb Z_n$

> **Proposition.** Let $\mathbb Z_n$ be the set of equivalence classes of the
> integers mod $n$ and $a, b, c \in \mathbb Z_n$.
>
> 1. Addition and multiplication are commutative modulo $n$:
>    $$a + b \equiv b + a \pmod n \qquad ab \equiv ba \pmod n.$$
> 2. Addition and multiplication are associative modulo $n$.
> 3. There are additive and multiplicative identities.
> 4. Multiplication distributes over addition.
> 5. For every integer $a$ there is an additive inverse $-a$.
> 6. Let $a$ be a nonzero integer. Then $\gcd(a, n) = 1$ if and only if there
>    exists a multiplicative inverse $b$ for $a$ modulo $n$; that is, a nonzero
>    integer $b$ such that $ab \equiv 1 \pmod n$.
>
> *We will prove (1) and (6) and leave the remaining properties to be proven in
> the exercises.*

Judson proves (1) and (6) in the running text and leaves parts (2)–(5) as this
section's exercises. We prove all six properties inline in the main text here; a
dedicated exercises pass over the AATA corpus (not yet run for the Chapter 2–3
main-text sections) will later fold (2)–(5) into an `## Exercises` section as
pointers back to these proofs. Each of (1)–(5) goes through by the same argument:
the two sides are *equal* integers (a ring law of $\mathbb Z$), so their difference
is $0$ and $n \mid 0$; (6) is the Bézout argument for multiplicative inverses.

### (1) Addition and multiplication are commutative modulo $n$

> Addition and multiplication are commutative modulo $n$ since the remainder of
> $a + b$ divided by $n$ is the same as the remainder of $b + a$ divided by $n$.

At the level of the congruence relation this is immediate: $a + b$ and $b + a$
are *equal* integers (commutativity of $+$ in $\mathbb Z$), so their difference
is $0$, and $n \mid 0$. Same for multiplication.

```bpa
// n | 0 for every n: 0 = n·0.  (The additive-commutativity witness below.)
theorem dividesZero: forall n: Int; does_divide(n, ZERO)
proof
  @generalize-n |
    fix n: Int {
      @n-times-zero-is-zero |
        mul(n, ZERO) = ZERO
        [using specialize mulZeroRight(n)]
      @zero-is-multiple |
        ZERO = mul(n, ZERO)
        [by symmetry n-times-zero-is-zero]
      @n-divides-zero |
        does_divide(n, ZERO)
        [using specialize dividesIntro(ZERO, n, ZERO) zero-is-multiple]
    }
  @conclusion |
    forall n: Int; does_divide(n, ZERO)
    [by forall_intro generalize-n]
qed
```

The recurring move in Judson's proof of (1)–(5) is: *the two sides are the same
integer, so their difference is $0$ and $n \mid 0$.* We capture it once — if
$a = b$ then $a \equiv b \pmod n$ — and reuse it for each part. The difference
$a - b$ collapses to $0$ (`arithmetic`), which is $n \cdot 0$, so $n$ divides it.

```bpa
theorem congruentOfEqual: forall a, b, n: Int; a = b -> congruent(a, b, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-n |
            fix n: Int {
              @given-equal |
                assume a = b {
                  @a-equals-b |
                    a = b
                    [by hypothesis given-equal]
                  // a − b = a − a = 0 once b is rewritten to a.
                  @self-difference-is-zero |
                    sub(a, a) = ZERO
                    [using arithmetic]
                  @difference-is-zero |
                    sub(a, b) = ZERO
                    [using arithmetic a-equals-b self-difference-is-zero]
                  @n-times-zero |
                    mul(n, ZERO) = ZERO
                    [using specialize mulZeroRight(n)]
                  @zero-is-n-times-zero |
                    ZERO = mul(n, ZERO)
                    [by symmetry n-times-zero]
                  @difference-is-a-multiple |
                    sub(a, b) = mul(n, ZERO)
                    [using chain difference-is-zero zero-is-n-times-zero]
                  @conclusion-congruent |
                    congruent(a, b, n)
                    [using specialize dividesIntro(sub(a, b), n, ZERO) difference-is-a-multiple]
                }
              @conclusion-implication |
                a = b -> congruent(a, b, n)
                [by implies_intro given-equal]
            }
          @discharge-n |
            forall n: Int; a = b -> congruent(a, b, n)
            [by forall_intro generalize-n]
        }
      @discharge-b |
        forall b, n: Int; a = b -> congruent(a, b, n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, n: Int; a = b -> congruent(a, b, n)
    [by forall_intro generalize-a]
qed
```

**Addition is commutative modulo $n$.** $a + b$ and $b + a$ are the *same*
integer, so their difference is $0$ and $n \mid 0$.

```bpa
theorem addCongruentCommutes: forall a, b, n: Int; congruent(add(a, b), add(b, a), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-n |
            fix n: Int {
              // add(a, b) and add(b, a) are the same integer.
              @sum-commutes |
                add(a, b) = add(b, a)
                [using specialize addIsCommutative(a, b)]
              @conclusion-congruent |
                congruent(add(a, b), add(b, a), n)
                [using specialize congruentOfEqual(add(a, b), add(b, a), n) sum-commutes]
            }
          @discharge-n |
            forall n: Int; congruent(add(a, b), add(b, a), n)
            [by forall_intro generalize-n]
        }
      @discharge-b |
        forall b, n: Int; congruent(add(a, b), add(b, a), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, n: Int; congruent(add(a, b), add(b, a), n)
    [by forall_intro generalize-a]
qed
```

**Multiplication is commutative modulo $n$.** Identical: $ab$ and $ba$ are the
*same* integer (commutativity of $\cdot$ in $\mathbb Z$), so their difference is

### (2) Addition and multiplication are associative modulo $n$

> $(a + b) + c \equiv a + (b + c) \pmod n$ and $(ab)c \equiv a(bc) \pmod n$.

Again the two sides are *equal* integers — associativity of $+$ and $\cdot$ in
$\mathbb Z$ — so `congruentOfEqual` applies.

```bpa
theorem addCongruentAssociates:
  forall a, b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @generalize-n |
                fix n: Int {
                  @sum-associates |
                    add(add(a, b), c) = add(a, add(b, c))
                    [using specialize addIsAssociative(a, b, c)]
                  @conclusion-congruent |
                    congruent(add(add(a, b), c), add(a, add(b, c)), n)
                    [using specialize congruentOfEqual(add(add(a, b), c), add(a, add(b, c)), n) sum-associates]
                }
              @discharge-n |
                forall n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
                [by forall_intro generalize-n]
            }
          @discharge-c |
            forall c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
```

### (3) Additive and multiplicative identities modulo $n$

> $a + 0 \equiv a \pmod n$ and $a \cdot 1 \equiv a \pmod n$.

$a + 0$ and $a \cdot 1$ are literally $a$ in $\mathbb Z$ (`addZeroRight`,
`mulOneRight`), so each is congruent to $a$.

```bpa
theorem addZeroCongruent: forall a, n: Int; congruent(add(a, ZERO), a, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-n |
        fix n: Int {
          @add-zero |
            add(a, ZERO) = a
            [using specialize addZeroRight(a)]
          @conclusion-congruent |
            congruent(add(a, ZERO), a, n)
            [using specialize congruentOfEqual(add(a, ZERO), a, n) add-zero]
        }
      @discharge-n |
        forall n: Int; congruent(add(a, ZERO), a, n)
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall a, n: Int; congruent(add(a, ZERO), a, n)
    [by forall_intro generalize-a]
qed
```

```bpa
theorem mulOneCongruent: forall a, n: Int; congruent(mul(a, ONE), a, n)

    [by forall_intro generalize-a]
```

### (4) Multiplication distributes over addition modulo $n$

> $a(b + c) \equiv ab + ac \pmod n$.

$a(b+c)$ and $ab + ac$ are equal integers by the distributive law of $\mathbb Z$
(`mulAddDistribLeft`).

```bpa
theorem mulDistributesCongruent:
  forall a, b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @generalize-n |
                fix n: Int {
                  @distributes |
                    mul(a, add(b, c)) = add(mul(a, b), mul(a, c))
                    [using specialize mulAddDistribLeft(a, b, c)]
                  @conclusion-congruent |
                    congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
                    [using specialize congruentOfEqual(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n) distributes]
                }
              @discharge-n |
                forall n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
                [by forall_intro generalize-n]
            }
          @discharge-c |
            forall c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
    [by forall_intro generalize-a]
qed
```

### (5) Additive inverses modulo $n$

> For every integer $a$ there is an additive inverse $-a$: $a + (-a) \equiv 0
> \pmod n$.

$a + (-a) = 0$ in $\mathbb Z$ (`addNegRight`), so $a + (-a) \equiv 0 \pmod n$.

```bpa
theorem addInverseCongruent: forall a, n: Int; congruent(add(a, neg(a)), ZERO, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-n |
        fix n: Int {
          @add-inverse |
            add(a, neg(a)) = ZERO
            [using specialize addNegRight(a)]
          @conclusion-congruent |
            congruent(add(a, neg(a)), ZERO, n)
            [using specialize congruentOfEqual(add(a, neg(a)), ZERO, n) add-inverse]
        }
      @discharge-n |
        forall n: Int; congruent(add(a, neg(a)), ZERO, n)
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall a, n: Int; congruent(add(a, neg(a)), ZERO, n)
    [by forall_intro generalize-a]
qed
```


### (6) Units modulo $n$: coprimality is exactly invertibility

> Let $a$ be a nonzero integer. Then $\gcd(a, n) = 1$ if and only if there
> exists a multiplicative inverse $b$ for $a$ modulo $n$; that is, an integer
> $b$ such that $ab \equiv 1 \pmod n$.

This is the substantive part. We express "$\gcd(a,n) = 1$" the way Chapter 2
does — there is no `gcd` *function* in that development; coprimality is
*characterized* by "every common divisor of $a$ and $n$ is $\pm 1$", the exact
hypothesis the Bézout corollary `coprimeBezout` consumes. (Judson says
"nonzero $b$"; a unit class is automatically nonzero, so we do not carry the
nonzero clause as a hypothesis.)

```bpa
// a, n coprime: their only common divisors are ±1 (the Chapter-2 characterization).
define coprime(a, n) =
  forall e: Int; does_divide(e, a) -> does_divide(e, n) -> (e = ONE or e = neg(ONE))
```

A small linear identity the converse uses: $x - (x - y) = y$. (Proving it on
plain variables keeps the numeral $1$ out of the arithmetic step at the call
site, where $y = 1$.)

```bpa
theorem subSubCancel: forall x, y: Int; sub(x, sub(x, y)) = y
proof
  @generalize-x |
    fix x: Int {
      @generalize-y |
        fix y: Int {
          @conclusion-cancel |
            sub(x, sub(x, y)) = y
            [using arithmetic]
        }
      @discharge-y |
        forall y: Int; sub(x, sub(x, y)) = y
        [by forall_intro generalize-y]
    }
  @conclusion |
    forall x, y: Int; sub(x, sub(x, y)) = y
    [by forall_intro generalize-x]
qed
```

> **(⇒)** Suppose $a, n$ coprime. Bézout gives $r, s$ with $ar + ns = 1$. Then
> $ar - 1 = -(ns) = n(-s)$, so $n \mid ar - 1$, i.e. $ar \equiv 1 \pmod n$;
> taking $b = r$ gives $ab \equiv 1 \pmod n$.
>
> **(⇐)** Suppose $ab \equiv 1 \pmod n$. Then $n \mid ab - 1$, so $ab - nk = 1$
> for some $k$. Any common divisor $e$ of $a$ and $n$ divides $ab$ and $nk$,
> hence divides $ab - nk = 1$; so $e = \pm 1$ (`dividesOneImpliesUnit`). Thus
> $a, n$ are coprime.

```bpa
theorem unitIffCoprime:
  forall a, n: Int;
  a != ZERO -> n != ZERO ->
  (coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n)))
proof
  @generalize-a |
    fix a: Int {
      @generalize-n |
        fix n: Int {
          @given-a-nonzero |
            assume a != ZERO {
              @given-n-nonzero |
                assume n != ZERO {
                  @a-nonzero |
                    a != ZERO
                    [by hypothesis given-a-nonzero]
                  @n-nonzero |
                    n != ZERO
                    [by hypothesis given-n-nonzero]
                  // (⇒) coprime ⟹ an inverse exists, with witness b = r from Bézout.
                  @coprime-gives-inverse |
                    assume coprime(a, n) {
                      @coprime-hypothesis |
                        coprime(a, n)
                        [by hypothesis coprime-gives-inverse]
                      @bezout-holds |
                        exists r: Int; exists s: Int; add(mul(a, r), mul(n, s)) = ONE
                        [using specialize coprimeBezout(a, n) a-nonzero n-nonzero coprime-hypothesis]
                      @with-bezout-r |
                        unpack r: Int from bezout-holds {
                          @s-exists |
                            exists s: Int; add(mul(a, r), mul(n, s)) = ONE
                            [by hypothesis with-bezout-r]
                          @with-bezout-s |
                            unpack s: Int from s-exists {
                              @bezout-equation |
                                add(mul(a, r), mul(n, s)) = ONE
                                [by hypothesis with-bezout-s]
                              // ar − 1 = −(ns): the linear identity x − (x + y) = −y in the opaque
                              // products, then substitute ar + ns = 1.
                              @diff-of-sum |
                                sub(mul(a, r), add(mul(a, r), mul(n, s))) = neg(mul(n, s))
                                [using arithmetic]
                              @diff-is-neg-ns |
                                sub(mul(a, r), ONE) = neg(mul(n, s))
                                [by rewrite bezout-equation diff-of-sum]
                              @neg-ns-is-n-times-neg-s |
                                mul(n, neg(s)) = neg(mul(n, s))
                                [using specialize mulNegRight(n, s)]
                              @diff-is-n-times-neg-s |
                                sub(mul(a, r), ONE) = mul(n, neg(s))
                                [using chain diff-is-neg-ns neg-ns-is-n-times-neg-s]
                              @n-divides-diff |
                                does_divide(n, sub(mul(a, r), ONE))
                                [using specialize dividesIntro(sub(mul(a, r), ONE), n, neg(s)) diff-is-n-times-neg-s]
                              @ar-congruent-one |
                                congruent(mul(a, r), ONE, n)
                                [using tautology n-divides-diff]
                              @inverse-from-s |
                                exists b: Int; congruent(mul(a, b), ONE, n)
                                [by exists_intro(r) ar-congruent-one]
                            }
                          @inverse-from-r |
                            exists b: Int; congruent(mul(a, b), ONE, n)
                            [by exists_elim with-bezout-s]
                        }
                      @inverse-exists |
                        exists b: Int; congruent(mul(a, b), ONE, n)
                        [by exists_elim with-bezout-r]
                    }
                  @coprime-implies-inverse |
                    coprime(a, n) -> (exists b: Int; congruent(mul(a, b), ONE, n))
                    [by implies_intro coprime-gives-inverse]
                  // (⇐) an inverse ⟹ coprime: any common divisor divides 1.
                  @inverse-gives-coprime |
                    assume exists b: Int; congruent(mul(a, b), ONE, n) {
                      @inverse-hypothesis |
                        exists b: Int; congruent(mul(a, b), ONE, n)
                        [by hypothesis inverse-gives-coprime]
                      @with-inverse-b |
                        unpack b: Int from inverse-hypothesis {
                          @ab-congruent-one |
                            congruent(mul(a, b), ONE, n)
                            [by hypothesis with-inverse-b]
                          @n-divides-ab-minus-one |
                            does_divide(n, sub(mul(a, b), ONE))
                            [using tautology ab-congruent-one]
                          @with-witness-k |
                            unpack k: Int from n-divides-ab-minus-one {
                              @ab-minus-one-is-nk |
                                sub(mul(a, b), ONE) = mul(n, k)
                                [by hypothesis with-witness-k]
                              // ab − nk = 1: the identity x − (x − y) = y in the opaque
                              // product ab, then substitute ab − 1 = nk.
                              @diff-of-diff |
                                sub(mul(a, b), sub(mul(a, b), ONE)) = ONE
                                [using specialize subSubCancel(mul(a, b), ONE)]
                              @ab-minus-nk-is-one |
                                sub(mul(a, b), mul(n, k)) = ONE
                                [by rewrite ab-minus-one-is-nk diff-of-diff]
                              @generalize-e |
                                fix e: Int {
                                  @e-divides-a-case |
                                    assume does_divide(e, a) {
                                      @e-divides-n-case |
                                        assume does_divide(e, n) {
                                          @e-divides-a |
                                            does_divide(e, a)
                                            [by hypothesis e-divides-a-case]
                                          @e-divides-n |
                                            does_divide(e, n)
                                            [by hypothesis e-divides-n-case]
                                          @e-divides-ab |
                                            does_divide(e, mul(a, b))
                                            [using specialize dividesMul(e, a, b) e-divides-a]
                                          @e-divides-nk |
                                            does_divide(e, mul(n, k))
                                            [using specialize dividesMul(e, n, k) e-divides-n]
                                          @e-divides-difference |
                                            does_divide(e, sub(mul(a, b), mul(n, k)))
                                            [using specialize dividesSubtracts(e, mul(a, b), mul(n, k)) e-divides-ab e-divides-nk]
                                          @e-divides-one |
                                            does_divide(e, ONE)
                                            [by rewrite ab-minus-nk-is-one e-divides-difference]
                                          @e-is-unit |
                                            e = ONE or e = neg(ONE)
                                            [using specialize dividesOneImpliesUnit(e) e-divides-one]
                                        }
                                      @e-divides-n-implies-unit |
                                        does_divide(e, n) -> (e = ONE or e = neg(ONE))
                                        [by implies_intro e-divides-n-case]
                                    }
                                  @e-divides-a-implies |
                                    does_divide(e, a) -> does_divide(e, n) -> (e = ONE or e = neg(ONE))
                                    [by implies_intro e-divides-a-case]
                                }
                              @conclusion-common-divisors |
                                forall e: Int; does_divide(e, a) -> does_divide(e, n) -> (e = ONE or e = neg(ONE))
                                [by forall_intro generalize-e]
                              @coprime-with-witness |
                                coprime(a, n)
                                [using tautology conclusion-common-divisors]
                            }
                          @coprime-from-witness |
                            coprime(a, n)
                            [by exists_elim with-witness-k]
                        }
                      @coprime-from-inverse |
                        coprime(a, n)
                        [by exists_elim with-inverse-b]
                    }
                  @inverse-implies-coprime |
                    (exists b: Int; congruent(mul(a, b), ONE, n)) -> coprime(a, n)
                    [by implies_intro inverse-gives-coprime]
                  @conclusion-iff |
                    coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n))
                    [by iff_intro coprime-implies-inverse inverse-implies-coprime]
                }
              @n-nonzero-implies |
                n != ZERO -> (coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n)))
                [by implies_intro given-n-nonzero]
            }
          @a-nonzero-implies |
            a != ZERO -> n != ZERO -> (coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n)))
            [by implies_intro given-a-nonzero]
        }
      @discharge-n |
        forall n: Int; a != ZERO -> n != ZERO -> (coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n)))
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall a, n: Int; a != ZERO -> n != ZERO -> (coprime(a, n) iff (exists b: Int; congruent(mul(a, b), ONE, n)))
    [by forall_intro generalize-a]
qed
```
