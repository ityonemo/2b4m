## Definitions and Notation

In general, the permutations of a set $X$ form a group $S_X$. If $X$ is a finite
set, we can assume $X = \{1, 2, \ldots, n\}$. In this case we write $S_n$ instead
of $S_X$. The following theorem says that $S_n$ is a group. We call this group
the **symmetric group** on $n$ letters.

> **Theorem.** The symmetric group on $n$ letters, $S_n$, is a group with $n!$
> elements, where the binary operation is the composition of maps.

**Proof.** The identity of $S_n$ is just the identity map that sends $1$ to $1$, $2$ to
$2$, …, $n$ to $n$. If $f : S_n \rightarrow S_n$ is a permutation, then $f^{-1}$ exists,
since $f$ is one-to-one and onto; hence, every permutation has an inverse. Composition of
maps is associative, which makes the group operation associative. We leave the proof that
$|S_n| = n!$ as an exercise. $\blacksquare$

Though it is natural to multiply elements in a group from left to right, functions are
composed from right to left. Let $\sigma$ and $\tau$ be permutations on a set $X$. To
compose $\sigma$ and $\tau$ as functions, we calculate
$(\sigma \circ \tau)(x) = \sigma(\tau(x))$ — that is, we do $\tau$ first, then
$\sigma$. There are several ways to approach this inconsistency. **We will adopt the
convention of multiplying permutations right to left.** To compute $\sigma\tau$, do
$\tau$ first and then $\sigma$; that is, by $\sigma\tau(x)$ we mean
$\sigma(\tau(x))$.

```2b4m
// S_X: the permutations of X — the invertible self-maps, under composition.
sort Perm = Fn where invertible

// Judson's three claims, each over the permutations.

// (i) composition of maps is associative, which makes the group operation
//     associative. (It holds for ALL maps; a fortiori for permutations.)
theorem composeIsAssociative: forall h, g, f: Perm;
  compose(compose(h, g), f) = compose(h, compose(g, f))
proof
  @generalize-h |
    fix h: Perm {
      @generalize-g |
        fix g: Perm {
          @generalize-f |
            fix f: Perm {
              @associativity-of-composition |
                compose(compose(h, g), f) = compose(h, compose(g, f))
                [using specialize function_invertible.composeAssoc(h, g, f)]
            }
          @discharge-f |
            forall f: Perm; compose(compose(h, g), f) = compose(h, compose(g, f))
            [by generalize generalize-f]
        }
      @discharge-g |
        forall g, f: Perm; compose(compose(h, g), f) = compose(h, compose(g, f))
        [by generalize generalize-g]
    }
  @conclusion |
    forall h, g, f: Perm; compose(compose(h, g), f) = compose(h, compose(g, f))
    [by generalize generalize-h]
qed

// (ii) the identity of S_n is just the identity map that sends 1 to 1, 2 to 2,
//      ..., n to n.
theorem identityIsAPermutation: invertible(identityFn)
proof
  @conclusion |
    invertible(identityFn)
    [by cite function_invertible.identityInvertible]
qed

theorem identityActsAsTheGroupIdentity: forall f: Perm; compose(identityFn, f) = f
proof
  @generalize-f |
    fix f: Perm {
      @identity-composes-away |
        compose(identityFn, f) = f
        [using specialize function_invertible.composeIdentityLeft(f)]
    }
  @conclusion |
    forall f: Perm; compose(identityFn, f) = f
    [by generalize generalize-f]
qed

// (iii) if f is a permutation, then f^{-1} exists, since f is one-to-one and
//       onto; hence every permutation has an inverse.
theorem everyPermutationHasAnInverse: forall f: Perm;
  invertible(inverse(f)) and compose(inverse(f), f) = identityFn
proof
  @generalize-f |
    fix f: Perm {
      @f-is-invertible |
        invertible(f)
        [by predicate generalize-f]
      @the-inverse-is-a-permutation |
        invertible(inverse(f))
        [using specialize function_invertible.inverseInvertible(f) f-is-invertible]
      @the-inverse-undoes-f |
        compose(inverse(f), f) = identityFn
        [using specialize function.inverseLeft(f) f-is-invertible]
      @conclusion-inverse |
        invertible(inverse(f)) and compose(inverse(f), f) = identityFn
        [by both the-inverse-is-a-permutation the-inverse-undoes-f]
    }
  @conclusion |
    forall f: Perm; invertible(inverse(f)) and compose(inverse(f), f) = identityFn
    [by generalize generalize-f]
qed

// and the composition of two permutations is a permutation — the closure that
// makes composition a binary operation ON S_X at all.
theorem permutationsAreClosedUnderComposition: forall g, f: Perm; invertible(compose(g, f))
proof
  @generalize-g |
    fix g: Perm {
      @g-is-invertible |
        invertible(g)
        [by predicate generalize-g]
      @generalize-f |
        fix f: Perm {
          @f-is-invertible |
            invertible(f)
            [by predicate generalize-f]
          @the-composite-is-a-permutation |
            invertible(compose(g, f))
            [using specialize function_invertible.composeInvertible(g, f) g-is-invertible f-is-invertible]
        }
      @discharge-f |
        forall f: Perm; invertible(compose(g, f))
        [by generalize generalize-f]
    }
  @conclusion |
    forall g, f: Perm; invertible(compose(g, f))
    [by generalize generalize-g]
qed
```

Closure, associativity, an identity, and inverses: $S_X$ is a group under
composition.

> *There is no cardinality function, so "$|S_n| = n!$" is stated as a listing: a
> sequence of $n!$ permutations of the letters $\{0, \ldots, n-1\}$, no entry repeated,
> in which every permutation of those letters appears.*

**The $n!$ elements.** A permutation of $n$ letters bijects the segment
$\{0, \ldots, n-1\}$ onto itself and fixes every point outside it. A permutation of
$n+1$ letters sending the top letter $n$ to $k$ is $(k\ n)$ times a permutation fixing
$n$ — that is, a permutation of $n$ letters — so the permutations of $n+1$ letters
fall into $n+1$ blocks of $n!$ each: block $k$ is $(k\ n)$ composed with each
permutation of $n$ letters. Two entries from different blocks send the top letter to
different places; two from the same block differ after undoing the swap.

```2b4m
proof

    invertible(identityFn)

  @singleton-exists |
    exists w: Seq; at(w, ZERO) = identityFn and permutation_sequence.productUpTo(w, succ(ZERO)) = identityFn
    [using specialize seqSingleton(identityFn) identity-invertible]
  @zero-factorial-is-one |
    factorial(ZERO) = ONE
    [by cite factorialZero]
  @one-is-succ-zero |
    ONE = succ(ZERO)
    [by cite oneIsSuccZero]
  @zero-factorial-is-succ-zero |
    factorial(ZERO) = succ(ZERO)
    [using chain zero-factorial-is-one one-is-succ-zero]
  @zero-segment-is-empty |
    segment(ZERO) = emptyset

  @identity-permutes-nothing |
    permutes(identityFn, segment(ZERO))

    forall x: Element; (not member(x, segment(ZERO))) -> apply(identityFn, x) = x

                        i = j

                        at(w, i) = at(w, j) -> i = j
                        [using tautology indices-equal]

                    less_than(j, succ(ZERO)) -> at(w, i) = at(w, j) -> i = j
                    [by discharge given-j-below-one-too]
                }
              @conclusion-injective-at-i-j |
                less_than(i, succ(ZERO)) -> less_than(j, succ(ZERO)) -> at(w, i) = at(w, j) -> i = j
                [by discharge given-i-below-one]
            }
          @discharge-j-for-injective |
            forall j: Nat; less_than(i, succ(ZERO)) -> less_than(j, succ(ZERO)) -> at(w, i) = at(w, j) -> i = j
            [by generalize generalize-j-for-injective]
        }
      @singleton-injective |
        forall i: Nat; forall j: Nat; less_than(i, succ(ZERO)) -> less_than(j, succ(ZERO)) -> at(w, i) = at(w, j) -> i = j
        [by generalize generalize-i-for-injective]

        fix t: Fn {
          @given-t-permutes |
            assume permutesTheSegment(t, ZERO) {
              @t-permutes |
                permutesTheSegment(t, ZERO)

              @with-all-blocks-u |
                unpack u: Seq from all-blocks-exist {
                  @all-blocks |
                    enumeratesTheBlocksBelow(u, mul(succ(n), factorial(n)), n, succ(n))
                    [by hypothesis with-all-blocks-u]
                  @u-enumerates |
                    enumerates(u, succ(n), mul(succ(n), factorial(n)))
                    [using specialize allTheBlocksEnumerate(n, mul(succ(n), factorial(n)), u) all-blocks]
                  @next-factorial-unfolds |
                    factorial(succ(n)) = mul(succ(n), factorial(n))
                    [using specialize factorialSucc(n)]
                  @u-enumerates-next-factorial |
                    enumerates(u, succ(n), factorial(succ(n)))
                    [by rewrite next-factorial-unfolds u-enumerates]
                  @conclusion-witness-u |
                    exists w3: Seq; enumerates(w3, succ(n), factorial(succ(n)))
                    [by witness(u) u-enumerates-next-factorial]
                }
              @conclusion-with-u |
                exists w3: Seq; enumerates(w3, succ(n), factorial(succ(n)))
                [by unpacked with-all-blocks-u]
            }
          @conclusion-step |
            exists w3: Seq; enumerates(w3, succ(n), factorial(succ(n)))
            [by unpacked with-enumeration-w]
        }
      @induction-step-at-n |
        (exists w2: Seq; enumerates(w2, n, factorial(n))) -> (exists w3: Seq; enumerates(w3, succ(n), factorial(succ(n))))
        [by discharge given-inductive-hypothesis]
    }
  @induction-step-for-all-n |
    forall n: Nat; (exists w2: Seq; enumerates(w2, n, factorial(n))) -> (exists w3: Seq; enumerates(w3, succ(n), factorial(succ(n))))
    [by generalize induction-step]
  @conclusion |
    forall n: Nat; exists w: Seq; enumerates(w, n, factorial(n))
    [using instantiation induction((fun n: Nat => exists w: Seq; enumerates(w, n, factorial(n)))) base-case induction-step-for-all-n]
qed
```

A subgroup of $S_n$ is called a **permutation group**.

### Cycle Notation

The notation that we have used to represent permutations up to this point is
cumbersome, to say the least. To work effectively with permutation groups, we
need a more streamlined method of writing down and manipulating permutations.

A permutation $\sigma \in S_X$ is a **cycle of length $k$** if there exist
elements $a_1, a_2, \ldots, a_k \in X$ such that
$$\sigma(a_1) = a_2, \quad \sigma(a_2) = a_3, \quad \ldots, \quad \sigma(a_k) = a_1$$
and $\sigma(x) = x$ for all other elements $x \in X$. We will write $(a_1, a_2,
\ldots, a_k)$ to denote the cycle $\sigma$. Cycles are the building blocks of all
permutations. Two cycles $\sigma, \tau \in S_X$ are **disjoint** if $a \neq
\sigma(a)$ implies $\tau(a) = a$, and $b \neq \tau(b)$ implies $\sigma(b) = b$.

> **Proposition.** Let $\sigma$ and $\tau$ be two disjoint cycles in $S_X$. Then
> $\sigma\tau = \tau\sigma$.
>
> **Theorem.** Every permutation in $S_n$ can be written as the product of
> disjoint cycles.

A cycle $(a_0\, a_1 \ldots a_k)$ is taken in the factorized form established further
down, $(a_0\, a_1 \ldots a_k) = (a_0\, a_k) \cdots (a_0\, a_2)(a_0\, a_1)$, and the
action Judson uses as his definition — advance, wrap around, fix the rest — is then
proved of it for a list of distinct points. Two cycles are disjoint exactly when their
supports, the sets of points they move, do not meet; the proposition in fact holds for
any two permutations with disjoint supports, cycles or not. The decomposition theorem
is proved for a permutation moving finitely many points, which is what
$\sigma \in S_n$ means, by Judson's argument: peel off the cycle of one orbit, and
induct on the size of the support.

```2b4m
// disjoint supports.
define disjointSupports(f, g) = permutation.disjointSupports(f, g)
theorem disjointCyclesCommute: forall f: Perm; forall g: Perm;
  disjointSupports(f, g) -> compose(f, g) = compose(g, f)
proof
  @generalize-f |
    fix f: Perm {
      @generalize-g |
        fix g: Perm {
          @given-disjoint |
            assume disjointSupports(f, g) {
              @disjoint |
                disjointSupports(f, g)
                [by hypothesis given-disjoint]
              @f-moved-is-g-fixed |
                forall x: Element; member(x, support(f)) -> (not member(x, support(g)))
                [using specialize disjointSupportsPointwise(f, g) disjoint]
              @pointwise |
                fix x: Element {
                  @f-then-g-at-x |
                    apply(compose(f, g), x) = apply(f, apply(g, x))
                    [using specialize composeApply(f, g, x)]
                  @g-then-f-at-x |
                    apply(compose(g, f), x) = apply(g, apply(f, x))
                    [using specialize composeApply(g, f, x)]
                  @f-membership-at-x |
                    member(x, support(f)) iff apply(f, x) != x
                    [using specialize supportMember(f, x)]
                  @g-membership-at-x |
                    member(x, support(g)) iff apply(g, x) != x
                    [using specialize supportMember(g, x)]
                  @x-moved-by-f-or-not |
                    member(x, support(f)) or (not member(x, support(f)))
                    [using tautology]
                  @composites-agree-at-x |
                    apply(f, apply(g, x)) = apply(g, apply(f, x))
                    case x-moved-by-f-or-not {
                      @when-f-moves-x |
                        assume member(x, support(f)) {
                          // g fixes x and fixes f(x), so both composites give f(x)
                          @x-in-support-f |
                            member(x, support(f))
                            [by hypothesis when-f-moves-x]
                          @x-not-in-support-g |
                            not member(x, support(g))
                            [using specialize f-moved-is-g-fixed(x) x-in-support-f]
                          @g-fixes-x |
                            apply(g, x) = x
                            [using tautology g-membership-at-x x-not-in-support-g]
                          @image-in-support-f |
                            member(apply(f, x), support(f))
                            [using specialize permutationPreservesItsSupport(f, x) x-in-support-f]
                          @image-not-in-support-g |
                            not member(apply(f, x), support(g))
                            [using specialize f-moved-is-g-fixed(apply(f, x)) image-in-support-f]
                          @g-membership-at-image |
                            member(apply(f, x), support(g)) iff apply(g, apply(f, x)) != apply(f, x)
                            [using specialize supportMember(g, apply(f, x))]
                          @g-fixes-image |
                            apply(g, apply(f, x)) = apply(f, x)
                            [using tautology g-membership-at-image image-not-in-support-g]
                          @f-x-is-f-x |
                            apply(f, x) = apply(f, x)
                            [by reflexivity]
                          @f-of-g-x-is-f-x |
                            apply(f, apply(g, x)) = apply(f, x)
                            [by rewrite g-fixes-x f-x-is-f-x]
                          @conclusion-when-f-moves |
                            apply(f, apply(g, x)) = apply(g, apply(f, x))
                            [by rewrite g-fixes-image f-of-g-x-is-f-x]
                        }
                      @when-f-fixes-x |
                        assume not member(x, support(f)) {
                          @x-not-in-support-f |
                            not member(x, support(f))
                            [by hypothesis when-f-fixes-x]
                          @f-fixes-x |
                            apply(f, x) = x
                            [using tautology f-membership-at-x x-not-in-support-f]
                          @x-moved-by-g-or-not |
                            member(x, support(g)) or (not member(x, support(g)))
                            [using tautology]
                          @conclusion-when-f-fixes |
                            apply(f, apply(g, x)) = apply(g, apply(f, x))
                            case x-moved-by-g-or-not {
                              @when-g-moves-x |
                                assume member(x, support(g)) {
                                  // f fixes g(x), so both composites give g(x)
                                  @x-in-support-g |
                                    member(x, support(g))
                                    [by hypothesis when-g-moves-x]
                                  @image-in-support-g |
                                    member(apply(g, x), support(g))
                                    [using specialize permutationPreservesItsSupport(g, x) x-in-support-g]
                                  @f-moved-is-g-fixed-at-image |
                                    member(apply(g, x), support(f)) -> (not member(apply(g, x), support(g)))
                                    [using specialize f-moved-is-g-fixed(apply(g, x))]
                                  @image-not-in-support-f |
                                    not member(apply(g, x), support(f))
                                    [using tautology f-moved-is-g-fixed-at-image image-in-support-g]
                                  @f-membership-at-image |
                                    member(apply(g, x), support(f)) iff apply(f, apply(g, x)) != apply(g, x)
                                    [using specialize supportMember(f, apply(g, x))]
                                  @f-fixes-image |
                                    apply(f, apply(g, x)) = apply(g, x)
                                    [using tautology f-membership-at-image image-not-in-support-f]
                                  @g-x-is-g-x |
                                    apply(g, x) = apply(g, x)
                                    [by reflexivity]
                                  @g-of-f-x-is-g-x |
                                    apply(g, apply(f, x)) = apply(g, x)
                                    [by rewrite f-fixes-x g-x-is-g-x]
                                  @conclusion-when-g-moves |
                                    apply(f, apply(g, x)) = apply(g, apply(f, x))
                                    [by rewrite g-of-f-x-is-g-x f-fixes-image]
                                }
                              @when-g-fixes-x |
                                assume not member(x, support(g)) {
                                  // both fix x, so both composites give x
                                  @x-not-in-support-g |
                                    not member(x, support(g))
                                    [by hypothesis when-g-fixes-x]
                                  @g-fixes-x |
                                    apply(g, x) = x
                                    [using tautology g-membership-at-x x-not-in-support-g]
                                  @f-of-g-x-is-x |
                                    apply(f, apply(g, x)) = x
                                    [by rewrite g-fixes-x f-fixes-x]
                                  @g-of-f-x-is-x |
                                    apply(g, apply(f, x)) = x
                                    [by rewrite f-fixes-x g-fixes-x]
                                  @conclusion-when-both-fix |
                                    apply(f, apply(g, x)) = apply(g, apply(f, x))
                                    [by rewrite g-of-f-x-is-x f-of-g-x-is-x]
                                }
                            }
                        }
                    }
                  @f-then-g-is-g-then-f-at-x |
                    apply(compose(f, g), x) = apply(g, apply(f, x))
                    [by rewrite composites-agree-at-x f-then-g-at-x]
                  @conclusion-agree-at-x |
                    apply(compose(f, g), x) = apply(compose(g, f), x)
                    [by rewrite g-then-f-at-x f-then-g-is-g-then-f-at-x]
                }
              @composites-agree-everywhere |
                forall x: Element; apply(compose(f, g), x) = apply(compose(g, f), x)
                [by generalize pointwise]
              @conclusion-composites-equal |
                compose(f, g) = compose(g, f)
                [using specialize funcExtensionality(compose(f, g), compose(g, f)) composites-agree-everywhere]
            }
          @conclusion-implication |
            disjointSupports(f, g) -> compose(f, g) = compose(g, f)
            [by discharge given-disjoint]
        }
      @discharge-g |
        forall g: Perm; disjointSupports(f, g) -> compose(f, g) = compose(g, f)
        [by generalize generalize-g]
    }
  @conclusion |
    forall f: Perm; forall g: Perm; disjointSupports(f, g) -> compose(f, g) = compose(g, f)
    [by generalize generalize-f]
qed
```

### Transpositions

The simplest permutation is a cycle of length $2$. Such cycles are called
**transpositions**. Since
$$(a_1, a_2, \ldots, a_n) = (a_1, a_n)(a_1, a_{n-1}) \cdots (a_1, a_3)(a_1, a_2),$$
any cycle can be written as the product of transpositions, leading to the
following proposition.

> **Proposition.** Any permutation of a finite set containing at least two
> elements can be written as the product of transpositions.

The displayed identity is the form a cycle is taken in, one transposition at a time,
so a cycle is a product of transpositions by construction; and the proposition follows
from the decomposition into disjoint cycles by concatenating each cycle's
transpositions. The "at least two elements" is not needed: the identity is the empty
product. Below, the parity results take "a product of transpositions" as a hypothesis
about a permutation, and this proposition is what discharges it for every permutation
of a finite set.

```2b4m
import transpositions <<< "std/permutation/transpositions.b4m"

define isATransposition(t) = transpositions.isATransposition(t)
define isAProductOfTranspositions(g) = transpositions.isAProductOfTranspositions(g)
fact cycleIsAProductOfTranspositions = transpositions.cycleIsAProductOfTranspositions
fact everyPermutationIsAProductOfTranspositions = transpositions.everyPermutationOfAFiniteSetIsAProductOfTranspositions
```

As we can see, there is no unique way to represent a permutation as the product
of transpositions. For instance, we can write the identity permutation as
$(1\,2)(1\,2)$, as $(1\,3)(2\,4)(1\,3)(2\,4)$, and in many other ways. However,
as it turns out, **no permutation can be written as the product of both an even
number of transpositions and an odd number of transpositions.** For instance, we
could represent the permutation $(1\,6)$ by
$$(2\,3)(1\,6)(2\,3) \qquad\text{or by}\qquad (3\,5)(1\,6)(1\,3)(1\,6)(1\,3)(3\,5)(5\,6),$$
but $(1\,6)$ will always be the product of an odd number of transpositions.

Judson proves this in two moves: first a lemma about the identity, then the general
statement.

> **Lemma.** If the identity is written as the product of $r$ transpositions, $\identity =
> \tau_1 \tau_2 \cdots \tau_r$, then $r$ is an even number.

**Proof.** Induct on $r$, rewriting the last two transpositions by one of four
identities — $(ab)(ab) = \identity$, $(bc)(ab) = (ac)(bc)$, $(cd)(ab) = (ab)(cd)$,
$(ac)(ab) = (ab)(bc)$ — so that either the product shortens by two or the last occurrence
of a symbol $a$ moves one place left. Repeating, either two adjacent transpositions cancel
or $a$ reaches the first position, which is impossible because the identity fixes $a$.

> *Judson's rewrite terminates by a lexicographic measure — the product's length, then
> the position of $a$'s last occurrence. We are doing it as two **nested ordinary**
> inductions instead: strong induction on the factor count for the outer loop, plain
> descending induction on that position for the inner. The outer measure does not move
> while the inner runs, so no pair of measures is ever compared and no well-founded
> induction is needed.*

```2b4m
// The parity argument runs over finite PRODUCTS of permutations — sequences of
// permutations and their products, from `std/permutation/sequence.b4m` — and the one
// property of transpositions it uses is that a transposition squares to the identity,
// which `std/permutation.b4m` proves. Judson's group-theoretic notation (e, σ⁻¹, juxtaposed
// products) is kept through the aliases below.
import permutation_sequence <<< "std/permutation/sequence.b4m"
import permutation_parity <<< "std/permutation/parity.b4m"

// A TRANSPOSITION exchanges two DISTINCT points and fixes the rest — `std/permutation.b4m`'s
// `transposition(u, v)` with u ≠ v. A map IS a transposition when it is one of those. (Without
// u ≠ v, (a a) = id would be a "product of one transposition", contradicting the parity lemma.)
func transposition = permutation.transposition
define isTransposition(t) = exists u: Element; exists v: Element; u != v and t = transposition(u, v)

// A transposition is its own inverse — the ONLY property of transpositions the parity
// argument uses, and it is PROVED: (u v)(u v) is the identity.
theorem transpositionSelfInverse: forall t: G; isTransposition(t) -> op(t, t) = e
proof
  @generalize-t |
    fix t: G {
      @given-transposition |
        assume isTransposition(t) {
          @the-two-points-exist |
            exists u: Element; exists v: Element; u != v and t = transposition(u, v)
            [by hypothesis given-transposition]
          @with-first-point-u |
            unpack u: Element from the-two-points-exist {
              @the-second-point-exists |
                exists v: Element; u != v and t = transposition(u, v)
                [by hypothesis with-first-point-u]
              @with-second-point-v |
                unpack v: Element from the-second-point-exists {
                  @the-points-and-the-transposition |
                    u != v and t = transposition(u, v)
                    [by hypothesis with-second-point-v]
                  @t-is-the-transposition |
                    t = transposition(u, v)
                    [by and_rhs the-points-and-the-transposition]
                  @transposition-squares-to-identity |
                    op(transposition(u, v), transposition(u, v)) = e
                    [using specialize permutation.transpositionIsAnInvolution(u, v)]
                  @conclusion-t-squares-to-identity |
                    op(t, t) = e
                    [by rewrite t-is-the-transposition transposition-squares-to-identity]
                }
              @conclusion-with-u |
                op(t, t) = e
                [by unpacked with-second-point-v]
            }
          @conclusion-squares-to-identity |
            op(t, t) = e
            [by unpacked with-first-point-u]
        }
      @conclusion-implication |
        isTransposition(t) -> op(t, t) = e
        [by discharge given-transposition]
    }
  @conclusion |
    forall t: G; isTransposition(t) -> op(t, t) = e
    [by generalize generalize-t]
qed

define allTranspositions(s, n) = forall i: Nat; less_than(i, n) -> isTransposition(at(s, i))

theorem transpositionIsItsOwnInverse: forall t: G; isTransposition(t) -> inv(t) = t
proof

            [by predicate generalize-t]
          @t-is-the-inverse |
            t = inv(t)
            [using specialize permutation_sequence.leftInverseIsTheInverse(t, t) t-is-a-permutation squares-to-identity]
          @conclusion-own-inverse |
            inv(t) = t
            [by symmetry t-is-the-inverse]

// reading that Judson's terminating rewrite needs well-founded induction on a lexicographic
// measure, which 2b4m lacks. That reading was wrong: the argument is two NESTED ORDINARY
// inductions — strong induction on the factor count for the outer loop, plain descending
// induction on the position of a chosen letter's last occurrence for the inner — and the outer
// measure never moves while the inner runs, so no pair is ever compared. Both are in the
// library. The other two supposed obstacles were also illusory: this chapter runs over
// CONCRETE permutations, so the pointwise action lemmas apply, which is what makes Judson's
// four rewrite identities provable.

theorem identityIsEvenLength: forall s: Seq; forall r: Nat;

proof
  @conclusion |
    forall s: Seq; forall r: Nat; allTranspositions(s, r) -> productUpTo(s, r) = e -> divides(TWO, r)
    [using import(permutation_parity) identityIsEvenLengthForAnySequence]

// EVEN / ODD, as Judson defines them: a permutation is even (odd) when it is SOME product
// of an even (odd) number of transpositions.
define isEvenPerm(g) = exists s: Seq; exists m: Nat;
  allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)

// The arithmetic Judson leaves silent when he writes "σ_m ⋯ σ_1": reversing an index keeps
// it in range — i < n implies n-(i+1) < n. (`subStrictlyDecreases`: 0 < b and b < a+1 give
// a-b < a; here b = i+1, which is positive, and i < n gives i+1 < n+1.)
theorem reversedIndexInRange: forall n: Nat; forall i: Nat;
  less_than(i, n) -> less_than(sub(n, succ(i)), n)
proof
  @generalize-n |
    fix n: Nat {
      @generalize-i |
        fix i: Nat {
          @given-i-below-n |
            assume less_than(i, n) {
              @i-below-n |
                less_than(i, n)
                [by hypothesis given-i-below-n]
              // 0 < i+1 : witness d = i in `lessThanIntro` (0 + succ(i) = succ(i)).
              @zero-plus-successor |
                add(ZERO, succ(i)) = succ(i)
                [using specialize peano.addZeroLeft(succ(i))]
              @successor-is-positive |
                less_than(ZERO, succ(i))
                [using specialize peano_order.lessThanIntro(ZERO, i, succ(i)) zero-plus-successor]
              @successor-below-successor |
                less_than(succ(i), succ(n))
                [using specialize peano_order.succPreservesOrder(i, n) i-below-n]
              @conclusion-in-range |
                less_than(sub(n, succ(i)), n)
                [using specialize peano_subtraction.subStrictlyDecreases(succ(i), n) successor-is-positive successor-below-successor]
            }
          @conclusion-implication |
            less_than(i, n) -> less_than(sub(n, succ(i)), n)
            [by discharge given-i-below-n]
        }
      @discharge-i |
        forall i: Nat; less_than(i, n) -> less_than(sub(n, succ(i)), n)
        [by generalize generalize-i]
    }
  @conclusion |
    forall n: Nat; forall i: Nat; less_than(i, n) -> less_than(sub(n, succ(i)), n)
    [by generalize generalize-n]
qed

// A REVERSED transposition sequence is still a transposition sequence, and its product is
// the inverse of the original's. (Judson: "the inverse of σ is σ_m ⋯ σ_1" — he can say it
// in one line because each σ_i is its own inverse.)
theorem reversedIsTranspositions: forall s: Seq; forall n: Nat;
  allTranspositions(s, n) ->
  exists r: Seq; allTranspositions(r, n) and productUpTo(r, n) = inv(productUpTo(s, n))
proof
  @generalize-s |
    fix s: Seq {
      @generalize-n |
        fix n: Nat {
          @given-all-transpositions |
            assume allTranspositions(s, n) {
              @the-reversal-exists |
                exists r: Seq;
                  (forall i: Nat; less_than(i, n) -> at(r, i) = at(s, sub(n, succ(i))))
                  and productUpTo(r, n) = revProductUpTo(s, n)
                [using specialize seqReverse(s, n)]
              @with-reversal-r |
                unpack r: Seq from the-reversal-exists {
                  @reversal-properties |
                    (forall i: Nat; less_than(i, n) -> at(r, i) = at(s, sub(n, succ(i))))
                      and productUpTo(r, n) = revProductUpTo(s, n)
                    [by hypothesis with-reversal-r]
                  @entries-are-s-entries |
                    forall i: Nat; less_than(i, n) -> at(r, i) = at(s, sub(n, succ(i)))
                    [by and_lhs reversal-properties]
                  @product-is-the-reversed-product |
                    productUpTo(r, n) = revProductUpTo(s, n)
                    [by and_rhs reversal-properties]
                  @reversed-product-is-the-inverse |
                    inv(productUpTo(s, n)) = revProductUpTo(s, n)
                    [using specialize invOfProduct(s, n)]
                  @product-of-r-is-the-inverse |
                    productUpTo(r, n) = inv(productUpTo(s, n))
                    [using chain product-is-the-reversed-product reversed-product-is-the-inverse]
                  @s-entries-are-transpositions |
                    allTranspositions(s, n)
                    [by hypothesis given-all-transpositions]
                  @reversed-index-in-range |
                    forall i: Nat; less_than(i, n) -> less_than(sub(n, succ(i)), n)
                    [using specialize reversedIndexInRange(n)]
                  // r's entries ARE s's entries at reversed indices. The carryover needs the
                  // arithmetic Judson leaves silent: i < n implies n-(i+1) < n, so the
                  // per-entry hypothesis on s applies at the reversed index.
                  // per entry: fix i below n, rewrite r's entry to s's at the reversed
                  // index, and apply s's hypothesis THERE (which needs the index bound).
                  @generalize-entry |
                    fix i: Nat {
                      @given-i-below-n |
                        assume less_than(i, n) {
                          @i-below-n |
                            less_than(i, n)
                            [by hypothesis given-i-below-n]
                          @r-entry-is-an-s-entry |
                            at(r, i) = at(s, sub(n, succ(i)))
                            [using specialize entries-are-s-entries(i) i-below-n]
                          @reversed-index-below-n |
                            less_than(sub(n, succ(i)), n)
                            [using specialize reversed-index-in-range(i) i-below-n]
                          @s-entry-is-a-transposition |
                            isTransposition(at(s, sub(n, succ(i))))
                            [using specialize s-entries-are-transpositions(sub(n, succ(i))) reversed-index-below-n]
                          @conclusion-entry |
                            isTransposition(at(r, i))
                            [by rewrite r-entry-is-an-s-entry s-entry-is-a-transposition]
                        }
                      @conclusion-entry-implication |
                        less_than(i, n) -> isTransposition(at(r, i))
                        [by discharge given-i-below-n]
                    }
                  @every-entry-of-r-is-a-transposition |
                    forall i: Nat; less_than(i, n) -> isTransposition(at(r, i))
                    [by generalize generalize-entry]
                  @r-is-a-transposition-sequence-with-the-inverse-product |
                    (forall i: Nat; less_than(i, n) -> isTransposition(at(r, i)))
                      and productUpTo(r, n) = inv(productUpTo(s, n))
                    [by both every-entry-of-r-is-a-transposition product-of-r-is-the-inverse]
                  @conclusion-witness |
                    exists r2: Seq; allTranspositions(r2, n) and productUpTo(r2, n) = inv(productUpTo(s, n))
                    [by witness(r) r-is-a-transposition-sequence-with-the-inverse-product]
                }
              @conclusion-unpacked |
                exists r2: Seq; allTranspositions(r2, n) and productUpTo(r2, n) = inv(productUpTo(s, n))
                [by unpacked with-reversal-r]
            }
          @conclusion-implication |
            allTranspositions(s, n) ->
              exists r2: Seq; allTranspositions(r2, n) and productUpTo(r2, n) = inv(productUpTo(s, n))
            [by discharge given-all-transpositions]
        }
      @discharge-n |
        forall n: Nat; allTranspositions(s, n) ->
          exists r2: Seq; allTranspositions(r2, n) and productUpTo(r2, n) = inv(productUpTo(s, n))
        [by generalize generalize-n]
    }
  @conclusion |
    forall s: Seq; forall n: Nat; allTranspositions(s, n) ->
      exists r2: Seq; allTranspositions(r2, n) and productUpTo(r2, n) = inv(productUpTo(s, n))
    [by generalize generalize-s]
qed

// CONCATENATION preserves "every entry is a transposition". An index below n+m lands in
// EITHER the first segment (i < n, where u agrees with t) or the second (n <= i, where
// i = n + (i-n) and u agrees with r at the offset i-n). The second branch is the one that
// needs arithmetic: `addSubCancel` recovers i from its offset, and the offset is below m.
theorem concatenationPreservesTranspositions: forall u: Seq; forall t: Seq; forall r: Seq; forall n: Nat; forall m: Nat;
  (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) ->
  (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) ->
  allTranspositions(t, n) -> allTranspositions(r, m) ->
  allTranspositions(u, add(n, m))
proof
  @generalize-u |
    fix u: Seq {
      @generalize-t |
        fix t: Seq {
          @generalize-r |
            fix r: Seq {
              @generalize-n |
                fix n: Nat {
                  @generalize-m |
                    fix m: Nat {
                      @given-u-agrees-with-t |
                        assume (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) {
                          @given-u-agrees-with-r |
                            assume (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) {
                              @given-t-transpositions |
                                assume allTranspositions(t, n) {
                                  @given-r-transpositions |
                                    assume allTranspositions(r, m) {
                                      @u-agrees-with-t |
                                        forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)
                                        [by hypothesis given-u-agrees-with-t]
                                      @u-agrees-with-r |
                                        forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)
                                        [by hypothesis given-u-agrees-with-r]
                                      @t-transpositions |
                                        allTranspositions(t, n)
                                        [by hypothesis given-t-transpositions]
                                      @r-transpositions |
                                        allTranspositions(r, m)
                                        [by hypothesis given-r-transpositions]
                                      @generalize-index |
                                        fix i: Nat {
                                          @given-i-in-range |
                                            assume less_than(i, add(n, m)) {
                                              @i-in-range |
                                                less_than(i, add(n, m))
                                                [by hypothesis given-i-in-range]
                                              @i-before-or-after-n |
                                                less_than(i, n) or i = n or less_than(n, i)
                                                [using specialize peano_order.trichotomy(i, n)]
                                              @conclusion-entry |
                                                isTransposition(at(u, i))
                                                case i-before-or-after-n {
                                                  // FIRST SEGMENT: u agrees with t at i.
                                                  @when-in-t |
                                                    assume less_than(i, n) {
                                                      @i-below-n |
                                                        less_than(i, n)
                                                        [by hypothesis when-in-t]
                                                      @u-entry-is-t-entry |
                                                        at(u, i) = at(t, i)
                                                        [using specialize u-agrees-with-t(i) i-below-n]
                                                      @t-entry-is-a-transposition |
                                                        isTransposition(at(t, i))
                                                        [using specialize t-transpositions(i) i-below-n]
                                                      @conclusion-when-in-t |
                                                        isTransposition(at(u, i))
                                                        [by rewrite u-entry-is-t-entry t-entry-is-a-transposition]
                                                    }
                                                  // BOUNDARY: i = n is the second segment's
                                                  // first slot, offset 0 (n + 0 = n).
                                                  @when-at-the-boundary |
                                                    assume i = n {
                                                      @i-is-n |
                                                        i = n
                                                        [by hypothesis when-at-the-boundary]
                                                      // i = n and i < n+m give n < n+m, and
                                                      // cancelling n on the left leaves 0 < m.
                                                      @n-below-total |
                                                        less_than(n, add(n, m))
                                                        [by rewrite i-is-n i-in-range]
                                                      @n-plus-zero-is-n |
                                                        add(n, ZERO) = n
                                                        [using specialize peano.addZeroRight(n)]
                                                      @n-plus-zero-below-total |
                                                        less_than(add(n, ZERO), add(n, m))
                                                        [by rewrite n-plus-zero-is-n n-below-total]
                                                      @m-is-positive |
                                                        less_than(ZERO, m)
                                                        [using specialize peano_order.lessThanAddCancelLeft(n, ZERO, m) n-plus-zero-below-total]
                                                      @u-entry-at-offset-zero |
                                                        at(u, add(n, ZERO)) = at(r, ZERO)
                                                        [using specialize u-agrees-with-r(ZERO) m-is-positive]
                                                      @n-plus-zero |
                                                        add(n, ZERO) = n
                                                        [using specialize peano.addZeroRight(n)]
                                                      @u-entry-at-n |
                                                        at(u, n) = at(r, ZERO)
                                                        [by rewrite n-plus-zero u-entry-at-offset-zero]
                                                      @r-first-is-a-transposition |
                                                        isTransposition(at(r, ZERO))
                                                        [using specialize r-transpositions(ZERO) m-is-positive]
                                                      @u-entry-at-n-is-a-transposition |
                                                        isTransposition(at(u, n))
                                                        [by rewrite u-entry-at-n r-first-is-a-transposition]
                                                      @conclusion-when-at-the-boundary |
                                                        isTransposition(at(u, i))
                                                        [by rewrite i-is-n u-entry-at-n-is-a-transposition]
                                                    }
                                                  // SECOND SEGMENT: n < i, so i = n + (i-n)
                                                  // with the offset i-n below m.
                                                  @when-in-r |
                                                    assume less_than(n, i) {
                                                      @n-below-i |
                                                        less_than(n, i)
                                                        [by hypothesis when-in-r]
                                                      @successor-exceeds-i |
                                                        less_than(i, succ(i))
                                                        [using specialize peano_order.lessThanSelf(i)]
                                                      // n < i means n <= i, so (i-n) + n = i
                                                      // (`addSubCancel`, whose bound is
                                                      // spelled n < succ(i)).
                                                      @n-below-successor-of-i |
                                                        less_than(n, succ(i))
                                                        [using specialize peano_order.lessThanTransitive(n, i, succ(i)) n-below-i successor-exceeds-i]
                                                      @offset-plus-n-is-i |
                                                        add(sub(i, n), n) = i
                                                        [using specialize peano_subtraction.addSubCancel(n, i) n-below-successor-of-i]
                                                      @offset-recovers-i |
                                                        add(n, sub(i, n)) = i
                                                        [using simplify offset-plus-n-is-i peano.addIsCommutative]
                                                      // i < n+m rewritten through that gives
                                                      // n + (i-n) < n + m, and cancelling n
                                                      // on the left leaves (i-n) < m.
                                                      @offset-form-below-total |
                                                        less_than(add(n, sub(i, n)), add(n, m))
                                                        [by rewrite offset-recovers-i i-in-range]
                                                      @offset-below-m |
                                                        less_than(sub(i, n), m)
                                                        [using specialize peano_order.lessThanAddCancelLeft(n, sub(i, n), m) offset-form-below-total]
                                                      @u-entry-at-offset |
                                                        at(u, add(n, sub(i, n))) = at(r, sub(i, n))
                                                        [using specialize u-agrees-with-r(sub(i, n)) offset-below-m]
                                                      @u-entry-is-r-entry |
                                                        at(u, i) = at(r, sub(i, n))
                                                        [by rewrite offset-recovers-i u-entry-at-offset]
                                                      @r-entry-is-a-transposition |
                                                        isTransposition(at(r, sub(i, n)))
                                                        [using specialize r-transpositions(sub(i, n)) offset-below-m]
                                                      @conclusion-when-in-r |
                                                        isTransposition(at(u, i))
                                                        [by rewrite u-entry-is-r-entry r-entry-is-a-transposition]
                                                    }
                                                }
                                            }
                                          @conclusion-entry-implication |
                                            less_than(i, add(n, m)) -> isTransposition(at(u, i))
                                            [by discharge given-i-in-range]
                                        }
                                      @conclusion-all |
                                        allTranspositions(u, add(n, m))
                                        [by generalize generalize-index]
                                    }
                                  @conclusion-r |
                                    allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                                    [by discharge given-r-transpositions]
                                }
                              @conclusion-t |
                                allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                                [by discharge given-t-transpositions]
                            }
                          @conclusion-agrees-r |
                            (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                            [by discharge given-u-agrees-with-r]
                        }
                      @conclusion-agrees-t |
                        (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) -> (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                        [by discharge given-u-agrees-with-t]
                    }
                  @discharge-m |
                    forall m: Nat; (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) -> (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                    [by generalize generalize-m]
                }
              @discharge-n |
                forall n: Nat; forall m: Nat; (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) -> (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
                [by generalize generalize-n]
            }
          @discharge-r |
            forall r: Seq; forall n: Nat; forall m: Nat; (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) -> (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
            [by generalize generalize-r]
        }
      @discharge-t |
        forall t: Seq; forall r: Seq; forall n: Nat; forall m: Nat; (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) -> (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) -> allTranspositions(t, n) -> allTranspositions(r, m) -> allTranspositions(u, add(n, m))
        [by generalize generalize-t]
    }
  @conclusion |
    forall u: Seq; forall t: Seq; forall r: Seq; forall n: Nat; forall m: Nat;
      (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)) ->
      (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)) ->
      allTranspositions(t, n) -> allTranspositions(r, m) ->
      allTranspositions(u, add(n, m))
    [by generalize generalize-u]
qed

// JUDSON'S THEOREM — parity is well defined. If σ is a product of an EVEN number of
// transpositions, then ANY product of transpositions equal to σ has even length.
//
// Judson's argument, verbatim: σ = σ₁⋯σ_m = τ₁⋯τ_n with m even. The inverse of σ is
// σ_m⋯σ₁, so 1 = σ·σ_m⋯σ₁ = τ₁⋯τ_n·σ_m⋯σ₁ — a product of n+m transpositions equal to the
// identity. By the lemma n+m is even; m is even; so n is even.
theorem parityIsWellDefined: forall sigma: G; forall s: Seq; forall m: Nat; forall t: Seq; forall n: Nat;
  allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) ->
  allTranspositions(t, n) -> productUpTo(t, n) = sigma ->
  divides(TWO, n)
proof
  @generalize-sigma |
    fix sigma: G {
      @generalize-s |
        fix s: Seq {
          @generalize-m |
            fix m: Nat {
              @generalize-t |
                fix t: Seq {
                  @generalize-n |
                    fix n: Nat {
                      @given-s-transpositions |
                        assume allTranspositions(s, m) {
                          @given-s-product |
                            assume productUpTo(s, m) = sigma {
                              @given-m-even |
                                assume divides(TWO, m) {
                                  @given-t-transpositions |
                                    assume allTranspositions(t, n) {
                                      @given-t-product |
                                        assume productUpTo(t, n) = sigma {
                                          @s-transpositions |
                                            allTranspositions(s, m)
                                            [by hypothesis given-s-transpositions]
                                          @t-transpositions |
                                            allTranspositions(t, n)
                                            [by hypothesis given-t-transpositions]
                                          @s-product |
                                            productUpTo(s, m) = sigma
                                            [by hypothesis given-s-product]
                                          @t-product |
                                            productUpTo(t, n) = sigma
                                            [by hypothesis given-t-product]
                                          @m-even |
                                            divides(TWO, m)
                                            [by hypothesis given-m-even]
                                          // σ⁻¹ as a transposition product: reverse s.
                                          @reversal-exists |
                                            exists r: Seq; allTranspositions(r, m) and productUpTo(r, m) = inv(productUpTo(s, m))
                                            [using specialize reversedIsTranspositions(s, m) s-transpositions]
                                          @with-reversal |
                                            unpack r: Seq from reversal-exists {
                                              @reversal-facts |
                                                allTranspositions(r, m) and productUpTo(r, m) = inv(productUpTo(s, m))
                                                [by hypothesis with-reversal]
                                              @r-transpositions |
                                                allTranspositions(r, m)
                                                [by and_lhs reversal-facts]
                                              @r-product-is-inverse |
                                                productUpTo(r, m) = inv(productUpTo(s, m))
                                                [by and_rhs reversal-facts]
                                              // 1 = τ₁⋯τ_n · σ_m⋯σ₁ : concatenate t with r.
                                              @concat-exists |
                                                exists u: Seq;
                                                  (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i))
                                                  and (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i))
                                                  and productUpTo(u, add(n, m)) = op(productUpTo(t, n), productUpTo(r, m))
                                                [using specialize seqConcat(t, r, n, m)]
                                              @with-concat |
                                                unpack u: Seq from concat-exists {
                                                  @concat-facts |
                                                    (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i))
                                                      and (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i))
                                                      and productUpTo(u, add(n, m)) = op(productUpTo(t, n), productUpTo(r, m))
                                                    [by hypothesis with-concat]
                                                  // the conjunction nests LEFT: (A and B) and C
                                                  @u-agreement-pair |
                                                    (forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i))
                                                      and (forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i))
                                                    [by and_lhs concat-facts]
                                                  @u-agrees-with-t |
                                                    forall i: Nat; less_than(i, n) -> at(u, i) = at(t, i)
                                                    [by and_lhs u-agreement-pair]
                                                  @u-agrees-with-r |
                                                    forall i: Nat; less_than(i, m) -> at(u, add(n, i)) = at(r, i)
                                                    [by and_rhs u-agreement-pair]
                                                  @concat-product |
                                                    productUpTo(u, add(n, m)) = op(productUpTo(t, n), productUpTo(r, m))
                                                    [by and_rhs concat-facts]
                                                  // the joined product is σ·σ⁻¹ = 1.
                                                  @r-product-is-sigma-inverse |
                                                    productUpTo(r, m) = inv(sigma)
                                                    [by rewrite s-product r-product-is-inverse]
                                                  @joined-is-sigma-times-its-inverse |
                                                    productUpTo(u, add(n, m)) = op(sigma, inv(sigma))
                                                    [using simplify concat-product t-product r-product-is-sigma-inverse]
                                                  @sigma-is-a-permutation |
                                                    invertible(sigma)
                                                    [by predicate generalize-sigma]
                                                  @sigma-times-inverse-is-identity |
                                                    op(sigma, inv(sigma)) = e
                                                    [using specialize function.inverseRight(sigma) sigma-is-a-permutation]
                                                  @joined-is-identity |
                                                    productUpTo(u, add(n, m)) = e
                                                    [using chain joined-is-sigma-times-its-inverse sigma-times-inverse-is-identity]
                                                  @joined-is-transpositions |
                                                    allTranspositions(u, add(n, m))
                                                    [using specialize concatenationPreservesTranspositions(u, t, r, n, m) u-agrees-with-t u-agrees-with-r t-transpositions r-transpositions]
                                                  @joined-length-is-even |
                                                    divides(TWO, add(n, m))
                                                    [using specialize identityIsEvenLength(u, add(n, m)) joined-is-transpositions joined-is-identity]
                                                  // 2 | (n+m) and 2 | m give 2 | (n+m)-m = n.
                                                  @total-minus-m-is-even |
                                                    divides(TWO, sub(add(n, m), m))
                                                    [using specialize peano_divides.dividesSub(TWO, add(n, m), m) joined-length-is-even m-even]
                                                  @total-minus-m-is-n |
                                                    sub(add(n, m), m) = n
                                                    [using specialize peano_subtraction.subAddCancel(n, m)]
                                                  @conclusion-n-even |
                                                    divides(TWO, n)
                                                    [by rewrite total-minus-m-is-n total-minus-m-is-even]
                                                }
                                              @conclusion-concat |
                                                divides(TWO, n)
                                                [by unpacked with-concat]
                                            }
                                          @conclusion-reversal |
                                            divides(TWO, n)
                                            [by unpacked with-reversal]
                                        }
                                      @conclusion-t-product |
                                        productUpTo(t, n) = sigma -> divides(TWO, n)
                                        [by discharge given-t-product]
                                    }
                                  @conclusion-t-transpositions |
                                    allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                                    [by discharge given-t-transpositions]
                                }
                              @conclusion-m-even |
                                divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                                [by discharge given-m-even]
                            }
                          @conclusion-s-product |
                            productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                            [by discharge given-s-product]
                        }
                      @conclusion-s-transpositions |
                        allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                        [by discharge given-s-transpositions]
                    }
                  @discharge-n |
                    forall n: Nat; allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                    [by generalize generalize-n]
                }
              @discharge-t |
                forall t: Seq; forall n: Nat; allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
                [by generalize generalize-t]
            }
          @discharge-m |
            forall m: Nat; forall t: Seq; forall n: Nat; allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
            [by generalize generalize-m]
        }
      @discharge-s |
        forall s: Seq; forall m: Nat; forall t: Seq; forall n: Nat; allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) -> allTranspositions(t, n) -> productUpTo(t, n) = sigma -> divides(TWO, n)
        [by generalize generalize-s]
    }
  @conclusion |
    forall sigma: G; forall s: Seq; forall m: Nat; forall t: Seq; forall n: Nat;
      allTranspositions(s, m) -> productUpTo(s, m) = sigma -> divides(TWO, m) ->
      allTranspositions(t, n) -> productUpTo(t, n) = sigma ->
      divides(TWO, n)
    [by generalize generalize-sigma]
qed
```

### The Alternating Groups

One of the most important subgroups of $S_n$ is the set of all even permutations, $A_n$.
The group $A_n$ is called the **alternating group on $n$ letters**.

> **Theorem.** The set $A_n$ is a subgroup of $S_n$.

**Proof.** Three lines, one per subgroup condition, each resting only on the parity
theory above — no cycle structure, no counting.

```2b4m
// -- THE ALTERNATING GROUP ---------------------------------------------------

fact productUpToZero = permutation_sequence.productUpToZero
fact dividesZero = peano_divides.dividesZero
fact seqSingleton = permutation_sequence.seqSingleton

// nothing is below ZERO, so every entry-below-ZERO claim holds vacuously.
theorem nothingBelowZeroIsATransposition: forall s: Seq;
  forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i))
proof
  @generalize-s |
    fix s: Seq {
      @generalize-i |
        fix i: Nat {
          @nothing-is-below-zero |
            not less_than(i, ZERO)
            [using specialize peano.notLessThanZero(i)]
          @vacuous |
            less_than(i, ZERO) -> isTransposition(at(s, i))
            [using tautology nothing-is-below-zero]
        }
      @discharge-i |
        forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i))
        [by generalize generalize-i]
    }
  @conclusion |
    forall s: Seq; forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i))
    [by generalize generalize-s]
qed

// (i) the IDENTITY is even: it is the EMPTY product of transpositions, and 0 is even.
theorem identityIsEven: isEvenPerm(e)
proof
  @the-identity-is-a-permutation |
    invertible(e)
    [by cite identityIsAPermutation]
  @some-sequence-exists |
    exists s: Seq; at(s, ZERO) = e and productUpTo(s, succ(ZERO)) = e
    [using specialize seqSingleton(e) the-identity-is-a-permutation]
  @with-a-sequence |
    unpack s: Seq from some-sequence-exists {
      // its length-ZERO product is the identity, and vacuously every entry below
      // ZERO is a transposition.
      @empty-product |
        productUpTo(s, ZERO) = e
        [using specialize productUpToZero(s)]
      @vacuously-transpositions |
        forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i))
        [using specialize nothingBelowZeroIsATransposition(s)]
      @zero-is-even |
        divides(TWO, ZERO)
        [using specialize dividesZero(TWO)]
      @first-two |
        (forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i)))
          and productUpTo(s, ZERO) = e
        [by both vacuously-transpositions empty-product]
      @all-three |
        (forall i: Nat; less_than(i, ZERO) -> isTransposition(at(s, i)))
          and productUpTo(s, ZERO) = e
          and divides(TWO, ZERO)
        [by both first-two zero-is-even]
      @inner-witness |
        exists m: Nat; allTranspositions(s, m) and productUpTo(s, m) = e and divides(TWO, m)
        [by witness(ZERO) all-three]
      @conclusion-witness |
        isEvenPerm(e)
        [by witness(s) inner-witness]
    }
  @conclusion |
    isEvenPerm(e)
    [by unpacked with-a-sequence]
qed

// (ii) an EVEN permutation's INVERSE is even. Judson: "the inverse of any transposition is
// itself, so σ^{-1} = σ_r ⋯ σ_1 is also in A_n" — the reversed sequence, same length, so
// the same parity.
theorem inverseOfEvenIsEven: forall g: G; isEvenPerm(g) -> isEvenPerm(inv(g))
proof
  @generalize-g |
    fix g: G {
      @given-even |
        assume isEvenPerm(g) {
          @the-witness |
            exists s: Seq; exists m: Nat;
              allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
            [by hypothesis given-even]
          @with-sequence |
            unpack s: Seq from the-witness {
              @inner |
                exists m: Nat; allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                [by hypothesis with-sequence]
              @with-length |
                unpack m: Nat from inner {
                  @facts |
                    allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                    [by hypothesis with-length]
                  @first-two |
                    allTranspositions(s, m) and productUpTo(s, m) = g
                    [by and_lhs facts]
                  @transpositions |
                    allTranspositions(s, m)
                    [by and_lhs first-two]
                  @product-is-g |
                    productUpTo(s, m) = g
                    [by and_rhs first-two]
                  @m-is-even |
                    divides(TWO, m)
                    [by and_rhs facts]
                  // the REVERSED sequence: same length m, still transpositions, product is g^-1
                  @reversal-exists |
                    exists r: Seq; allTranspositions(r, m) and productUpTo(r, m) = inv(productUpTo(s, m))
                    [using specialize reversedIsTranspositions(s, m) transpositions]
                  @with-reversal |
                    unpack r: Seq from reversal-exists {
                      @reversal-facts |
                        allTranspositions(r, m) and productUpTo(r, m) = inv(productUpTo(s, m))
                        [by hypothesis with-reversal]
                      @r-transpositions |
                        allTranspositions(r, m)
                        [by and_lhs reversal-facts]
                      @r-product |
                        productUpTo(r, m) = inv(productUpTo(s, m))
                        [by and_rhs reversal-facts]
                      @r-product-is-g-inverse |
                        productUpTo(r, m) = inv(g)
                        [by rewrite product-is-g r-product]
                      @r-first-two |
                        allTranspositions(r, m) and productUpTo(r, m) = inv(g)
                        [by both r-transpositions r-product-is-g-inverse]
                      @r-all-three |
                        allTranspositions(r, m) and productUpTo(r, m) = inv(g) and divides(TWO, m)
                        [by both r-first-two m-is-even]
                      @inner-witness |
                        exists m2: Nat; allTranspositions(r, m2) and productUpTo(r, m2) = inv(g) and divides(TWO, m2)
                        [by witness(m) r-all-three]
                      @conclusion-witness |
                        isEvenPerm(inv(g))
                        [by witness(r) inner-witness]
                    }
                  @conclusion-reversal |
                    isEvenPerm(inv(g))
                    [by unpacked with-reversal]
                }
              @conclusion-length |
                isEvenPerm(inv(g))
                [by unpacked with-length]
            }
          @conclusion-sequence |
            isEvenPerm(inv(g))
            [by unpacked with-sequence]
        }
      @conclusion-implication |
        isEvenPerm(g) -> isEvenPerm(inv(g))
        [by discharge given-even]
    }
  @conclusion |
    forall g: G; isEvenPerm(g) -> isEvenPerm(inv(g))
    [by generalize generalize-g]
qed

// (iii) the PRODUCT of two even permutations is even — Judson's "since the product of two
// even permutations must also be an even permutation, A_n is closed". Concatenate the two
// transposition sequences: the lengths add, and even + even is even.
theorem productOfEvensIsEven: forall g: G; forall h: G;
  isEvenPerm(g) -> isEvenPerm(h) -> isEvenPerm(op(g, h))
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @given-g-even |
            assume isEvenPerm(g) {
              @given-h-even |
                assume isEvenPerm(h) {
                  @g-witness |
                    exists s: Seq; exists m: Nat;
                      allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                    [by hypothesis given-g-even]
                  @h-witness |
                    exists t: Seq; exists n: Nat;
                      allTranspositions(t, n) and productUpTo(t, n) = h and divides(TWO, n)
                    [by hypothesis given-h-even]
                  @with-g-seq |
                    unpack s: Seq from g-witness {
                      @g-inner |
                        exists m: Nat; allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                        [by hypothesis with-g-seq]
                      @with-g-len |
                        unpack m: Nat from g-inner {
                          @g-facts |
                            allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                            [by hypothesis with-g-len]
                          @g-pair |
                            allTranspositions(s, m) and productUpTo(s, m) = g
                            [by and_lhs g-facts]
                          @g-transpositions |
                            allTranspositions(s, m)
                            [by and_lhs g-pair]
                          @g-product |
                            productUpTo(s, m) = g
                            [by and_rhs g-pair]
                          @g-even |
                            divides(TWO, m)
                            [by and_rhs g-facts]
                          @with-h-seq |
                            unpack t: Seq from h-witness {
                              @h-inner |
                                exists n: Nat; allTranspositions(t, n) and productUpTo(t, n) = h and divides(TWO, n)
                                [by hypothesis with-h-seq]
                              @with-h-len |
                                unpack n: Nat from h-inner {
                                  @h-facts |
                                    allTranspositions(t, n) and productUpTo(t, n) = h and divides(TWO, n)
                                    [by hypothesis with-h-len]
                                  @h-pair |
                                    allTranspositions(t, n) and productUpTo(t, n) = h
                                    [by and_lhs h-facts]
                                  @h-transpositions |
                                    allTranspositions(t, n)
                                    [by and_lhs h-pair]
                                  @h-product |
                                    productUpTo(t, n) = h
                                    [by and_rhs h-pair]
                                  @h-even |
                                    divides(TWO, n)
                                    [by and_rhs h-facts]
                                  // concatenate s (length m) with t (length n)
                                  @concat-exists |
                                    exists u: Seq;
                                      (forall i: Nat; less_than(i, m) -> at(u, i) = at(s, i))
                                      and (forall i: Nat; less_than(i, n) -> at(u, add(m, i)) = at(t, i))
                                      and productUpTo(u, add(m, n)) = op(productUpTo(s, m), productUpTo(t, n))
                                    [using specialize seqConcat(s, t, m, n)]
                                  @with-concat |
                                    unpack u: Seq from concat-exists {
                                      @concat-facts |
                                        (forall i: Nat; less_than(i, m) -> at(u, i) = at(s, i))
                                          and (forall i: Nat; less_than(i, n) -> at(u, add(m, i)) = at(t, i))
                                          and productUpTo(u, add(m, n)) = op(productUpTo(s, m), productUpTo(t, n))
                                        [by hypothesis with-concat]
                                      @agreement-pair |
                                        (forall i: Nat; less_than(i, m) -> at(u, i) = at(s, i))
                                          and (forall i: Nat; less_than(i, n) -> at(u, add(m, i)) = at(t, i))
                                        [by and_lhs concat-facts]
                                      @agrees-with-s |
                                        forall i: Nat; less_than(i, m) -> at(u, i) = at(s, i)
                                        [by and_lhs agreement-pair]
                                      @agrees-with-t |
                                        forall i: Nat; less_than(i, n) -> at(u, add(m, i)) = at(t, i)
                                        [by and_rhs agreement-pair]
                                      @concat-product |
                                        productUpTo(u, add(m, n)) = op(productUpTo(s, m), productUpTo(t, n))
                                        [by and_rhs concat-facts]
                                      @u-transpositions |
                                        allTranspositions(u, add(m, n))
                                        [using specialize concatenationPreservesTranspositions(u, s, t, m, n) agrees-with-s agrees-with-t g-transpositions h-transpositions]
                                      @product-with-g |
                                        productUpTo(u, add(m, n)) = op(g, productUpTo(t, n))
                                        [by rewrite g-product concat-product]
                                      @product-is-gh |
                                        productUpTo(u, add(m, n)) = op(g, h)
                                        [by rewrite h-product product-with-g]
                                      @length-is-even |
                                        divides(TWO, add(m, n))
                                        [using specialize dividesAdd(TWO, m, n) g-even h-even]
                                      @u-pair |
                                        allTranspositions(u, add(m, n)) and productUpTo(u, add(m, n)) = op(g, h)
                                        [by both u-transpositions product-is-gh]
                                      @u-all-three |
                                        allTranspositions(u, add(m, n)) and productUpTo(u, add(m, n)) = op(g, h) and divides(TWO, add(m, n))
                                        [by both u-pair length-is-even]
                                      @inner-witness |
                                        exists k: Nat; allTranspositions(u, k) and productUpTo(u, k) = op(g, h) and divides(TWO, k)
                                        [by witness(add(m, n)) u-all-three]
                                      @conclusion-witness |
                                        isEvenPerm(op(g, h))
                                        [by witness(u) inner-witness]
                                    }
                                  @conclusion-concat |
                                    isEvenPerm(op(g, h))
                                    [by unpacked with-concat]
                                }
                              @conclusion-h-len |
                                isEvenPerm(op(g, h))
                                [by unpacked with-h-len]
                            }
                          @conclusion-h-seq |
                            isEvenPerm(op(g, h))
                            [by unpacked with-h-seq]
                        }
                      @conclusion-g-len |
                        isEvenPerm(op(g, h))
                        [by unpacked with-g-len]
                    }
                  @conclusion-g-seq |
                    isEvenPerm(op(g, h))
                    [by unpacked with-g-seq]
                }
              @conclusion-h |
                isEvenPerm(h) -> isEvenPerm(op(g, h))
                [by discharge given-h-even]
            }
          @conclusion-g |
            isEvenPerm(g) -> isEvenPerm(h) -> isEvenPerm(op(g, h))
            [by discharge given-g-even]
        }
      @discharge-h |
        forall h: G; isEvenPerm(g) -> isEvenPerm(h) -> isEvenPerm(op(g, h))
        [by generalize generalize-h]
    }
  @conclusion |
    forall g: G; forall h: G; isEvenPerm(g) -> isEvenPerm(h) -> isEvenPerm(op(g, h))
    [by generalize generalize-g]
qed
```

> **Proposition.** The number of even permutations in $S_n$, $n \geq 2$, is equal to the
> number of odd permutations; hence the order of $A_n$ is $n!/2$.

**Proof.** Fix the transposition $\sigma = (0\ 1)$. The map
$\lambda_\sigma(\tau) = \sigma\tau$ carries the even permutations to the odd ones and
back, so the two must contain the same number of elements. Splitting the listing of
$S_n$ into its even entries — a listing of $A_n$, of length $p$ — and its non-even
entries, of length $q$ with $p + q = n!$, the pairing gives $p = q$ and hence $2p = n!$:
every $\sigma\tau$ with $\tau$ even is a non-even entry, and every non-even entry
$\rho$ is $\sigma(\sigma\rho)$ with $\sigma\rho$ even. Two facts from the earlier
sections feed this: every permutation of $n$ letters is even or odd, since it has finite
support and so is a product of transpositions whose count is even or odd; and none is
both, since $2$ does not divide two consecutive numbers. And $\lambda_\sigma$ flips
parity, since prepending $\sigma$ to a product of $m$ transpositions gives a product of
$m+1$.

```2b4m
  forall p: Nat; forall q: Nat; forall v: Seq; forall v2: Seq;
  (forall i: Nat; forall j: Nat; less_than(i, p) -> less_than(j, p) -> at(v, i) = at(v, j) -> i = j) ->
  (forall i: Nat; forall j: Nat; less_than(i, q) -> less_than(j, q) -> at(v2, i) = at(v2, j) -> i = j) ->

  (forall j: Nat; less_than(j, q) -> exists i: Nat; less_than(i, p) and at(v2, j) = compose(s, at(v, i))) ->

                                            [using specialize matchSpecIsTotalAndSingleValued(s, v, p, v2, q) v2-injective forward]

// A permutation of n letters moves only letters, so its support (a subset of the segment)
// is finite.
theorem permutationOfLettersHasFiniteSupport: forall t: Fn; forall n: Nat;
  permutesTheSegment(t, n) -> isFinite(support(t))
proof
  @generalize-t |
    fix t: Fn {
      @generalize-n |
        fix n: Nat {
          @given-permutes |
            assume permutesTheSegment(t, n) {
              @permutes |
                permutesTheSegment(t, n)
                [by hypothesis given-permutes]
              @t-fixes-outside |
                forall x: Element; (not member(x, segment(n))) -> apply(t, x) = x
                [using tautology permutes]
              @generalize-x |
                fix x: Element {
                  @given-x-moved |
                    assume member(x, support(t)) {
                      @x-in-support |
                        member(x, support(t))
                        [by hypothesis given-x-moved]
                      @support-membership |
                        member(x, support(t)) iff apply(t, x) != x
                        [using specialize supportMember(t, x)]
                      @x-moved |
                        apply(t, x) != x
                        [using tautology support-membership x-in-support]
                      @x-in-or-out |
                        member(x, segment(n)) or (not member(x, segment(n)))
                        [using tautology]
                      @conclusion-x-in-segment |
                        member(x, segment(n))
                        case x-in-or-out {
                          @when-in |
                            assume member(x, segment(n)) {
                              @conclusion-in |
                                member(x, segment(n))
                                [by hypothesis when-in]
                            }
                          @when-out |
                            assume not member(x, segment(n)) {
                              @x-out |
                                not member(x, segment(n))
                                [by hypothesis when-out]
                              @x-fixed |
                                apply(t, x) = x
                                [using specialize t-fixes-outside(x) x-out]
                              @conclusion-out-ex_falso |
                                member(x, segment(n))
                                [by ex_falso x-fixed x-moved]
                            }
                        }
                    }
                  @conclusion-subset-at-x |
                    member(x, support(t)) -> member(x, segment(n))
                    [by discharge given-x-moved]
                }
              @support-in-segment |
                subset(support(t), segment(n))
                [by generalize generalize-x]
              @segment-has-size-n |
                hasSize(segment(n), n)
                [using specialize equinumerousReflexive(segment(n))]
              @support-has-a-size |
                exists m: Nat; hasSize(support(t), m) and peano_order.less_or_equal(m, n)
                [using specialize subsetOfFiniteIsFinite(n, segment(n), support(t)) segment-has-size-n support-in-segment]
              @with-size-m |
                unpack m: Nat from support-has-a-size {
                  @size-facts |
                    hasSize(support(t), m) and peano_order.less_or_equal(m, n)
                    [by hypothesis with-size-m]
                  @support-has-size-m |
                    hasSize(support(t), m)
                    [by and_lhs size-facts]
                  @conclusion-support-finite |
                    isFinite(support(t))
                    [by witness(m) support-has-size-m]
                }
              @conclusion-finite |
                isFinite(support(t))
                [by unpacked with-size-m]
            }
          @conclusion-at-n |
            permutesTheSegment(t, n) -> isFinite(support(t))
            [by discharge given-permutes]
        }
      @discharge-n |
        forall n: Nat; permutesTheSegment(t, n) -> isFinite(support(t))
        [by generalize generalize-n]
    }
  @conclusion |
    forall t: Fn; forall n: Nat; permutesTheSegment(t, n) -> isFinite(support(t))
    [by generalize generalize-t]
qed

// Every permutation of n letters is even or odd: it is a product of some r transpositions
// (§5.1's proposition that any permutation of a finite set of at least two
// elements is a product of transpositions, its support being finite), and r is even or odd.
theorem permutationOfLettersIsEvenOrOdd: forall t: Fn; forall n: Nat;
  permutesTheSegment(t, n) -> (isEvenPerm(t) or isOddPerm(t))
proof
  @generalize-t |
    fix t: Fn {
      @generalize-n |
        fix n: Nat {
          @given-permutes |
            assume permutesTheSegment(t, n) {
              @permutes |
                permutesTheSegment(t, n)
                [by hypothesis given-permutes]
              @t-invertible |
                invertible(t)
                [using tautology permutes]
              @support-finite |
                isFinite(support(t))
                [using specialize permutationOfLettersHasFiniteSupport(t, n) permutes]
              @product-exists |
                exists w: Seq; exists r: Nat; allTranspositions(w, r) and productUpTo(w, r) = t
                [using specialize everyPermutationIsAProductOfTranspositions(t) support-finite]
              @with-sequence-w |
                unpack w: Seq from product-exists {
                  @after-w |
                    exists r: Nat; allTranspositions(w, r) and productUpTo(w, r) = t
                    [by hypothesis with-sequence-w]
                  @with-length-r |
                    unpack r: Nat from after-w {
                      @product-facts |
                        allTranspositions(w, r) and productUpTo(w, r) = t
                        [by hypothesis with-length-r]
                      @all-transpositions |
                        allTranspositions(w, r)
                        [by and_lhs product-facts]
                      @product-is-t |
                        productUpTo(w, r) = t
                        [by and_rhs product-facts]
                      @r-even-or-odd |
                        divides(TWO, r) or divides(TWO, succ(r))
                        [using specialize evenOrOdd(r)]
                      @conclusion-parity |
                        isEvenPerm(t) or isOddPerm(t)
                        case r-even-or-odd {
                          @when-r-even |
                            assume divides(TWO, r) {
                              @r-even |
                                divides(TWO, r)
                                [by hypothesis when-r-even]
                              @even-witness-facts |
                                allTranspositions(w, r) and productUpTo(w, r) = t and divides(TWO, r)
                                [using tautology all-transpositions product-is-t r-even]
                              @even-with-r |
                                exists m: Nat; allTranspositions(w, m) and productUpTo(w, m) = t and divides(TWO, m)
                                [by witness(r) even-witness-facts]
                              @t-even |
                                isEvenPerm(t)
                                [by witness(w) even-with-r]
                              @conclusion-when-even |
                                isEvenPerm(t) or isOddPerm(t)
                                [by either_left t-even]
                            }
                          @when-r-odd |
                            assume divides(TWO, succ(r)) {
                              @r-odd |
                                divides(TWO, succ(r))
                                [by hypothesis when-r-odd]
                              @odd-witness-facts |
                                allTranspositions(w, r) and productUpTo(w, r) = t and divides(TWO, succ(r))
                                [using tautology all-transpositions product-is-t r-odd]
                              @odd-with-r |
                                exists m: Nat; allTranspositions(w, m) and productUpTo(w, m) = t and divides(TWO, succ(m))
                                [by witness(r) odd-witness-facts]
                              @t-odd |
                                isOddPerm(t)
                                [by witness(w) odd-with-r]
                              @conclusion-when-odd |
                                isEvenPerm(t) or isOddPerm(t)
                                [by either_right t-odd]
                            }
                        }
                    }
                  @conclusion-with-r |
                    isEvenPerm(t) or isOddPerm(t)
                    [by unpacked with-length-r]
                }
              @conclusion-even-or-odd |
                isEvenPerm(t) or isOddPerm(t)
                [by unpacked with-sequence-w]
            }
          @conclusion-at-n |
            permutesTheSegment(t, n) -> (isEvenPerm(t) or isOddPerm(t))
            [by discharge given-permutes]
        }
      @discharge-n |
        forall n: Nat; permutesTheSegment(t, n) -> (isEvenPerm(t) or isOddPerm(t))
        [by generalize generalize-n]
    }
  @conclusion |
    forall t: Fn; forall n: Nat; permutesTheSegment(t, n) -> (isEvenPerm(t) or isOddPerm(t))
    [by generalize generalize-t]
qed

// 2 does not divide two consecutive numbers: it would divide their difference, 1.
theorem twoDividesNoTwoConsecutive: forall m: Nat; divides(TWO, m) -> (not divides(TWO, succ(m)))
proof
  @generalize-m |
    fix m: Nat {
      @given-m-even |
        assume divides(TWO, m) {
          @m-even |
            divides(TWO, m)
            [by hypothesis given-m-even]
          @suppose-succ-even |
            assume divides(TWO, succ(m)) {
              @succ-even |
                divides(TWO, succ(m))
                [by hypothesis suppose-succ-even]
              @two-divides-the-difference |
                divides(TWO, sub(succ(m), m))
                [using specialize dividesSub(TWO, succ(m), m) succ-even m-even]
              @one-is-succ-zero |
                peano.ONE = succ(ZERO)
                [by cite oneIsSuccZero]
              @one-plus-m-unfolds |
                add(succ(ZERO), m) = succ(add(ZERO, m))
                [using specialize addSuccLeft(ZERO, m)]
              @zero-plus-m |
                add(ZERO, m) = m
                [using specialize addZeroLeft(m)]
              @succ-zero-plus-m |
                add(succ(ZERO), m) = succ(m)
                [by rewrite zero-plus-m one-plus-m-unfolds]
              @one-plus-m |
                add(peano.ONE, m) = succ(m)
                [by rewrite one-is-succ-zero succ-zero-plus-m]
              @difference-cancels |
                sub(add(peano.ONE, m), m) = peano.ONE
                [using specialize subAddCancel(peano.ONE, m)]
              @difference-is-one |
                sub(succ(m), m) = peano.ONE
                [by rewrite one-plus-m difference-cancels]
              @two-divides-one |
                divides(TWO, peano.ONE)
                [by rewrite difference-is-one two-divides-the-difference]
            }
          @two-does-not-divide-one |
            not divides(TWO, peano.ONE)
            [by cite twoNotDivideOne]
          @conclusion-succ-not-even |
            not divides(TWO, succ(m))
            [by contradiction suppose-succ-even two-divides-one two-does-not-divide-one]
        }
      @conclusion-at-m |
        divides(TWO, m) -> (not divides(TWO, succ(m)))
        [by discharge given-m-even]
    }
  @conclusion |
    forall m: Nat; divides(TWO, m) -> (not divides(TWO, succ(m)))
    [by generalize generalize-m]
qed

                    exists m: Nat; allTranspositions(s, m) and productUpTo(s, m) = t and divides(TWO, m)
```

```2b4m
// m + 2 is the second successor of m (TWO is 1 + 1).
theorem addingTwo: forall m: Nat; add(m, TWO) = succ(succ(m))
proof
  @generalize-m |
    fix m: Nat {
      @one-is-succ-zero |
        peano.ONE = succ(ZERO)
        [by cite oneIsSuccZero]
      @two-unfolds |
        add(succ(ZERO), peano.ONE) = succ(add(ZERO, peano.ONE))
        [using specialize addSuccLeft(ZERO, peano.ONE)]
      @zero-plus-one |
        add(ZERO, peano.ONE) = peano.ONE
        [using specialize addZeroLeft(peano.ONE)]
      @succ-zero-plus-one |
        add(succ(ZERO), peano.ONE) = succ(peano.ONE)
        [by rewrite zero-plus-one two-unfolds]
      @two-is-succ-one |
        TWO = succ(peano.ONE)
        [by rewrite one-is-succ-zero succ-zero-plus-one]
      @m-plus-succ-one-unfolds |
        add(m, succ(peano.ONE)) = succ(add(m, peano.ONE))
        [using specialize addSuccRight(m, peano.ONE)]
      @m-plus-succ-zero-unfolds |
        add(m, succ(ZERO)) = succ(add(m, ZERO))
        [using specialize addSuccRight(m, ZERO)]
      @m-plus-zero |
        add(m, ZERO) = m
        [using specialize addZeroRight(m)]
      @m-plus-succ-zero |
        add(m, succ(ZERO)) = succ(m)
        [by rewrite m-plus-zero m-plus-succ-zero-unfolds]
      @m-plus-one |
        add(m, peano.ONE) = succ(m)
        [by rewrite one-is-succ-zero m-plus-succ-zero]
      @m-plus-succ-one |
        add(m, succ(peano.ONE)) = succ(succ(m))
        [by rewrite m-plus-one m-plus-succ-one-unfolds]
      @conclusion-m-plus-two |
        add(m, TWO) = succ(succ(m))
        [by rewrite two-is-succ-one m-plus-succ-one]
    }
  @conclusion |
    forall m: Nat; add(m, TWO) = succ(succ(m))
    [by generalize generalize-m]
qed

// λ_σ sends even to odd: prepend σ to an even-length product, and m + 2 is even with m.
theorem transpositionTimesEvenIsOdd: forall sigma: Fn; isTransposition(sigma) ->
  forall g: Fn; isEvenPerm(g) -> isOddPerm(op(sigma, g))
proof
  @generalize-sigma |
    fix sigma: Fn {
      @given-transposition |
        assume isTransposition(sigma) {
          @is-transposition |
            isTransposition(sigma)
            [by hypothesis given-transposition]
          @generalize-g |
            fix g: Fn {
              @given-even |
                assume isEvenPerm(g) {
                  @even |
                    isEvenPerm(g)
                    [by hypothesis given-even]
                  @with-sequence-s |
                    unpack s: Seq from even {
                      @after-s |
                        exists m: Nat; allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                        [by hypothesis with-sequence-s]
                      @with-length-m |
                        unpack m: Nat from after-s {
                          @even-facts |
                            allTranspositions(s, m) and productUpTo(s, m) = g and divides(TWO, m)
                            [by hypothesis with-length-m]
                          @all-transpositions |
                            allTranspositions(s, m)
                            [using tautology even-facts]
                          @product-is-g |
                            productUpTo(s, m) = g
                            [using tautology even-facts]
                          @m-even |
                            divides(TWO, m)
                            [using tautology even-facts]
                          @prepended-exists |
                            exists pre: Seq; allTranspositions(pre, succ(m)) and productUpTo(pre, succ(m)) = op(sigma, productUpTo(s, m))
                            [using specialize prependingATransposition(sigma, s, m) is-transposition all-transpositions]
                          @two-divides-two |
                            divides(TWO, TWO)
                            [using specialize dividesRefl(TWO)]
                          @sum-even |
                            divides(TWO, add(m, TWO))
                            [using specialize dividesAdd(TWO, m, TWO) m-even two-divides-two]
                          @m-plus-two |
                            add(m, TWO) = succ(succ(m))
                            [using specialize addingTwo(m)]
                          @succ-succ-m-even |
                            divides(TWO, succ(succ(m)))
                            [by rewrite m-plus-two sum-even]
                          @with-prepended-pre |
                            unpack pre: Seq from prepended-exists {

                                allTranspositions(pre, succ(m)) and productUpTo(pre, succ(m)) = op(sigma, productUpTo(s, m))

                                [by and_rhs prepended-facts]
                              @prepended-product-is-sigma-g |
                                productUpTo(pre, succ(m)) = op(sigma, g)
                                [by rewrite product-is-g prepended-product]
                              @odd-witness-facts |
                                allTranspositions(pre, succ(m)) and productUpTo(pre, succ(m)) = op(sigma, g) and divides(TWO, succ(succ(m)))
                                [using tautology all-prepended prepended-product-is-sigma-g succ-succ-m-even]
                              @odd-with-length |
                                exists m2: Nat; allTranspositions(pre, m2) and productUpTo(pre, m2) = op(sigma, g) and divides(TWO, succ(m2))
                                [by witness(succ(m)) odd-witness-facts]
                              @conclusion-sigma-g-odd |
                                isOddPerm(op(sigma, g))
                                [by witness(pre) odd-with-length]
                            }
                          @conclusion-with-pre |
                            isOddPerm(op(sigma, g))
                            [by unpacked with-prepended-pre]
                        }
                      @conclusion-with-m |
                        isOddPerm(op(sigma, g))
                        [by unpacked with-length-m]
                    }
                  @conclusion-odd |
                    isOddPerm(op(sigma, g))
                    [by unpacked with-sequence-s]
                }
              @conclusion-at-g |
                isEvenPerm(g) -> isOddPerm(op(sigma, g))
                [by discharge given-even]
            }
          @discharge-g |
            forall g: Fn; isEvenPerm(g) -> isOddPerm(op(sigma, g))
            [by generalize generalize-g]
        }
      @conclusion-at-sigma |
        isTransposition(sigma) -> forall g: Fn; isEvenPerm(g) -> isOddPerm(op(sigma, g))
        [by discharge given-transposition]
    }
  @conclusion |
    forall sigma: Fn; isTransposition(sigma) -> forall g: Fn; isEvenPerm(g) -> isOddPerm(op(sigma, g))
    [by generalize generalize-sigma]
qed

// THE PROPOSITION: for n ≥ 2, the even permutations of n letters — A_n — are listed by a
// sequence of h entries with h + h = n!. Split the listing of S_n by evenness into v (length
// p) and v2 (length q); σ = (0 1) pairs the two listings off (λ_σ flips parity and undoes
// itself), so p = q, and p + q = n!.
theorem alternatingGroupHasHalfTheElements: forall n: Nat; less_than(peano.ONE, n) ->
  exists v: Seq; exists h: Nat; ((forall j: Nat; less_than(j, h) -> (permutesTheSegment(at(v, j), n) and isEvenPerm(at(v, j)))) and (forall i: Nat; forall j: Nat; less_than(i, h) -> less_than(j, h) -> at(v, i) = at(v, j) -> i = j) and (forall t: Fn; permutesTheSegment(t, n) -> isEvenPerm(t) -> exists j: Nat; less_than(j, h) and at(v, j) = t)) and add(h, h) = factorial(n)

    fix n: Nat {

            less_than(ZERO, peano.ONE) and (forall k: Nat; not (less_than(ZERO, k) and less_than(k, peano.ONE)))

            less_than(ZERO, peano.ONE)
```
