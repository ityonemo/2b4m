## Normal subgroups

**Definition.** A subgroup $H$ of a group $G$ is **normal** in $G$ if $gH = Hg$ for all
$g \in G$. That is, a normal subgroup of a group $G$ is one in which the right and left
cosets are precisely the same.

> *There is no sort of subsets of a group here, so a coset $gH$ is carried by its
> membership predicate and "$gH = Hg$" is extensional agreement of the left- and
> right-coset predicates.*

**Examples.** Every subgroup of an abelian group is normal, since $gh = hg$ makes
$gH = Hg$ automatic. In $S_3$, the subgroup $\{(1), (12)\}$ is *not* normal —
$(123)H = \{(123),(13)\}$ while $H(123) = \{(123),(23)\}$ — but
$N = \{(1),(123),(132)\}$ is, since its two cosets are $N$ itself and
$(12)N = N(12) = \{(12),(13),(23)\}$.

## Theorem 10.3 — the conjugation characterization

**Theorem 10.3.** Let $G$ be a group and $N$ be a subgroup of $G$. Then the following
statements are equivalent.

1. The subgroup $N$ is normal in $G$.
2. For all $g \in G$, $gNg^{-1} \subset N$.
3. For all $g \in G$, $gNg^{-1} = N$.

**Proof.** (1) ⇒ (2). Since $N$ is normal in $G$, $gN = Ng$ for all $g \in G$.
Hence, for a given $g \in G$ and $n \in N$, there exists an $n'$ in $N$ such that
$gn = n'g$. Therefore, $gng^{-1} = n' \in N$, or $gNg^{-1} \subset N$.

(2) ⇒ (3). Let $g \in G$. Since $gNg^{-1} \subset N$, we need only show
$N \subset gNg^{-1}$. For $n \in N$, $g^{-1}n(g^{-1})^{-1} \in N$. Hence,
$g^{-1}ng = n'$ for some $n' \in N$, and therefore $n = gn'g^{-1}$ is in $gNg^{-1}$.
$\blacksquare$

Conditions (2) and (3) say the same thing here, containment in both directions being
agreement, so the theorem is the equivalence of the coset form with the conjugation
form. Forward: there exists $n'$ with $gn = n'g$. Backward: conjugate by $g^{-1}$ and
collapse $(g^{-1})^{-1} = g$.

```2b4m
theorem conjugationLandsInTheSubgroupIffCosetsCoincide:
  (forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x))
  iff
  (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))))
proof
  // ── (1) ⇒ (2): if gN = Ng then gng⁻¹ ∈ N.
  // "there exists n' in N such that gn = n'g; therefore gng⁻¹ = n' ∈ N"
  @given-cosets-coincide |
    assume forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x) {
      @cosets-coincide |
        forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x)
        [by hypothesis given-cosets-coincide]
      @conjugation-lands |
        forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))
        [by generalize conjugation-at-g]
      @conjugation-at-g |
        fix g: Grp {
          @inner-n |
            fix n: Grp {
              @given-n-in-n |
                assume inSubgroup(n) {
                  @n-in-n |
                    inSubgroup(n)
                    [by hypothesis given-n-in-n]
                  // gn ∈ gN, so gn ∈ Ng: gn = n'g for some n' ∈ N
                  @product-is-in-the-left-coset |
                    inCoset(g, op(g, n))
                    [using specialize coset.translationLandsInTheCoset(g, n) n-in-n]
                  @coincide-at-the-product |
                    inCoset(g, op(g, n)) iff inRightCoset(g, op(g, n))
                    [using specialize cosets-coincide(g, op(g, n))]
                  @product-is-in-the-right-coset |
                    inRightCoset(g, op(g, n))
                    [using tautology product-is-in-the-left-coset coincide-at-the-product]
                  @witness-exists |
                    exists h: Grp; inSubgroup(h) and op(g, n) = op(h, g)
                    [using tautology product-is-in-the-right-coset]
                  @with-the-witness |
                    unpack m: Grp from witness-exists {
                      @witness-facts |
                        inSubgroup(m) and op(g, n) = op(m, g)
                        [by hypothesis with-the-witness]
                      @m-in-n |
                        inSubgroup(m)
                        [by and_lhs witness-facts]
                      @product-splits |
                        op(g, n) = op(m, g)
                        [by and_rhs witness-facts]
                      // gng⁻¹ = (mg)g⁻¹ = m(gg⁻¹) = m
                      @regroup |
                        op(op(m, g), inverse(g)) = op(m, op(g, inverse(g)))
                        [using specialize grpAssoc(m, g, inverse(g))]
                      @g-cancels |
                        op(g, inverse(g)) = E
                        [using specialize grpInverseRight(g)]
                      @regrouped-at-identity |
                        op(op(m, g), inverse(g)) = op(m, E)
                        [by rewrite g-cancels regroup]
                      @m-times-identity |
                        op(m, E) = m
                        [using specialize grpIdentityRight(m)]
                      @conjugate-of-the-witness |
                        op(op(m, g), inverse(g)) = m
                        [using chain regrouped-at-identity m-times-identity]
                      @conjugate-rewritten |
                        op(op(g, n), inverse(g)) = m
                        [by rewrite product-splits conjugate-of-the-witness]
                      @conclusion-inner |
                        inSubgroup(op(op(g, n), inverse(g)))
                        [by rewrite conjugate-rewritten m-in-n]
                    }
                  @conclusion-conjugate-in-n |
                    inSubgroup(op(op(g, n), inverse(g)))
                    [by unpacked with-the-witness]
                }
              @n-implies |
                inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))
                [by discharge given-n-in-n]
            }
          @discharge-n |
            forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))
            [by generalize inner-n]
        }
    }
  @forward |
    (forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x))
      -> (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))))
    [by discharge given-cosets-coincide]
  // ── (2) ⇒ (1): conjugation into N forces the cosets to agree, both directions.
  @given-conjugation-lands |
    assume forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))) {
      @conjugation-lands-hyp |
        forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))
        [by hypothesis given-conjugation-lands]
      @cosets-agree |
        forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x)
        [by generalize agree-at-g]
      @agree-at-g |
        fix g: Grp {
          @inner-x |
            fix x: Grp {
              // LEFT ⇒ RIGHT: x = gn, and x = (gng⁻¹)g with gng⁻¹ ∈ N
              @given-x-in-the-left-coset |
                assume inCoset(g, x) {
                  @x-in-the-left-coset |
                    inCoset(g, x)
                    [by hypothesis given-x-in-the-left-coset]
                  @left-witness-exists |
                    exists h: Grp; inSubgroup(h) and x = op(g, h)
                    [using tautology x-in-the-left-coset]
                  @with-left-witness |
                    unpack n: Grp from left-witness-exists {
                      @left-facts |
                        inSubgroup(n) and x = op(g, n)
                        [by hypothesis with-left-witness]
                      @n-in-n |
                        inSubgroup(n)
                        [by and_lhs left-facts]
                      @x-is-g-times-n |
                        x = op(g, n)
                        [by and_rhs left-facts]
                      @conjugate-in-n |
                        inSubgroup(op(op(g, n), inverse(g)))
                        [using specialize conjugation-lands-hyp(g, n) n-in-n]
                      // (gng⁻¹)g = gn, so x = (gng⁻¹)g exhibits x ∈ Ng
                      @regroup-back |
                        op(op(op(g, n), inverse(g)), g) = op(op(g, n), op(inverse(g), g))
                        [using specialize grpAssoc(op(g, n), inverse(g), g)]
                      @inverse-cancels |
                        op(inverse(g), g) = E
                        [using specialize grpInverseLeft(g)]
                      @regrouped |
                        op(op(op(g, n), inverse(g)), g) = op(op(g, n), E)
                        [by rewrite inverse-cancels regroup-back]
                      @times-identity |
                        op(op(g, n), E) = op(g, n)
                        [using specialize grpIdentityRight(op(g, n))]
                      @conjugate-times-g |
                        op(op(op(g, n), inverse(g)), g) = op(g, n)
                        [using chain regrouped times-identity]
                      @conjugate-times-g-is-x |
                        op(op(op(g, n), inverse(g)), g) = x
                        [by rewrite x-is-g-times-n conjugate-times-g]
                      @x-is-the-conjugate-times-g |
                        x = op(op(op(g, n), inverse(g)), g)
                        [by symmetry conjugate-times-g-is-x]
                      @pair |
                        inSubgroup(op(op(g, n), inverse(g)))
                          and x = op(op(op(g, n), inverse(g)), g)
                        [by both conjugate-in-n x-is-the-conjugate-times-g]
                      @conclusion-right-member |
                        exists h: Grp; inSubgroup(h) and x = op(h, g)
                        [by witness(op(op(g, n), inverse(g))) pair]
                    }
                  @right-membership |
                    exists h: Grp; inSubgroup(h) and x = op(h, g)
                    [by unpacked with-left-witness]
                  @conclusion-in-the-right-coset |
                    inRightCoset(g, x)
                    [using tautology right-membership]
                }
              @left-implies-right |
                inCoset(g, x) -> inRightCoset(g, x)
                [by discharge given-x-in-the-left-coset]
              // RIGHT ⇒ LEFT: x = ng, and x = g(g⁻¹ng) with g⁻¹ng ∈ N (conjugate by g⁻¹)
              @given-x-in-the-right-coset |
                assume inRightCoset(g, x) {
                  @x-in-the-right-coset |
                    inRightCoset(g, x)
                    [by hypothesis given-x-in-the-right-coset]
                  @right-witness-exists |
                    exists h: Grp; inSubgroup(h) and x = op(h, g)
                    [using tautology x-in-the-right-coset]
                  @with-right-witness |
                    unpack n: Grp from right-witness-exists {
                      @right-facts |
                        inSubgroup(n) and x = op(n, g)
                        [by hypothesis with-right-witness]
                      @n-in-n-again |
                        inSubgroup(n)
                        [by and_lhs right-facts]
                      @x-is-n-times-g |
                        x = op(n, g)
                        [by and_rhs right-facts]
                      // conjugating by g⁻¹: g⁻¹n(g⁻¹)⁻¹ = g⁻¹ng ∈ N
                      @conjugate-by-the-inverse |
                        inSubgroup(op(op(inverse(g), n), inverse(inverse(g))))
                        [using specialize conjugation-lands-hyp(inverse(g), n) n-in-n-again]
                      @inverse-of-the-inverse |
                        inverse(inverse(g)) = g
                        [using specialize invInvolution(g)]
                      @conjugate-is-in-n |
                        inSubgroup(op(op(inverse(g), n), g))
                        [by rewrite inverse-of-the-inverse conjugate-by-the-inverse]
                      // g(g⁻¹ng) = ng, so x = g·(g⁻¹ng) exhibits x ∈ gN
                      @regroup-left |
                        op(op(g, inverse(g)), op(n, g)) = op(g, op(inverse(g), op(n, g)))
                        [using specialize grpAssoc(g, inverse(g), op(n, g))]
                      @g-inverse-cancels |
                        op(g, inverse(g)) = E
                        [using specialize grpInverseRight(g)]
                      @identity-times-ng |
                        op(E, op(n, g)) = op(n, g)
                        [using specialize grpIdentityLeft(op(n, g))]
                      @regrouped-left |
                        op(E, op(n, g)) = op(g, op(inverse(g), op(n, g)))
                        [by rewrite g-inverse-cancels regroup-left]
                      @ng-is-g-times |
                        op(n, g) = op(g, op(inverse(g), op(n, g)))
                        [by rewrite identity-times-ng regrouped-left]
                      // and g⁻¹(ng) = (g⁻¹n)g, so the inner factor is the conjugate above
                      @inner-regroup |
                        op(op(inverse(g), n), g) = op(inverse(g), op(n, g))
                        [using specialize grpAssoc(inverse(g), n, g)]
                      @ng-is-g-times-the-conjugate |
                        op(n, g) = op(g, op(op(inverse(g), n), g))
                        [by rewrite inner-regroup ng-is-g-times]
                      @x-is-g-times-the-conjugate |
                        x = op(g, op(op(inverse(g), n), g))
                        [by rewrite x-is-n-times-g ng-is-g-times-the-conjugate]
                      @pair-left |
                        inSubgroup(op(op(inverse(g), n), g))
                          and x = op(g, op(op(inverse(g), n), g))
                        [by both conjugate-is-in-n x-is-g-times-the-conjugate]
                      @conclusion-left-member |
                        exists h: Grp; inSubgroup(h) and x = op(g, h)
                        [by witness(op(op(inverse(g), n), g)) pair-left]
                    }
                  @left-membership |
                    exists h: Grp; inSubgroup(h) and x = op(g, h)
                    [by unpacked with-right-witness]
                  @conclusion-in-the-left-coset |
                    inCoset(g, x)
                    [using tautology left-membership]
                }
              @right-implies-left |
                inRightCoset(g, x) -> inCoset(g, x)
                [by discharge given-x-in-the-right-coset]
              @conclusion-agree-at-x |
                inCoset(g, x) iff inRightCoset(g, x)
                [by make_equivalence left-implies-right right-implies-left]
            }
          @discharge-x |
            forall x: Grp; inCoset(g, x) iff inRightCoset(g, x)
            [by generalize inner-x]
        }
    }
  @backward |
    (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))))
      -> (forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x))
    [by discharge given-conjugation-lands]
  @conclusion |
    (forall g: Grp; forall x: Grp; inCoset(g, x) iff inRightCoset(g, x))
      iff
      (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))))
    [by make_equivalence forward backward]
qed
```

## Factor groups

**Definition.** If $N$ is a normal subgroup of $G$, the cosets of $N$ in $G$ form a
group $G/N$ — the **factor group** of $G$ mod $N$ — under
$(aN)(bN) = abN$, of order $[G:N]$.

**Theorem 10.4.** Let $N$ be a normal subgroup of a group $G$. The cosets of $N$ in $G$
form a group $G/N$ of order $[G:N]$.

**Proof.** The group operation on $G/N$ is $(aN)(bN) = abN$. This operation must
be shown to be well-defined; that is, group multiplication must be independent of the
choice of coset representative. Let $aN = bN$ and $cN = dN$. We must show that
$$(aN)(cN) = acN = bdN = (bN)(dN).$$
Then $a = bn_1$ and $c = dn_2$ for some $n_1, n_2 \in N$. Hence
$$acN = bn_1dn_2N = bn_1dN = bn_1Nd = bNd = bdN.$$
$\blacksquare$

Well-definedness is the content. Since $aN = bN$ holds exactly when
$a^{-1}b \in N$ (§6.1), the statement reads: if $a, b$ represent the same coset and
$c, d$ do, then so do $ac$ and $bd$. The middle step $bn_1N = bNn_1 = bN$ is where
normality enters, and it appears as the hypothesis.

```2b4m
theorem theFactorOperationIsWellDefined:
  (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))) ->
  forall a: Grp; forall b: Grp; forall c: Grp; forall d: Grp;
  inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
  inSubgroup(op(inverse(op(a, c)), op(b, d)))
proof
  @given-normal |
    assume forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g))) {
      @normal |
        forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))
        [by hypothesis given-normal]
      @well-defined |
        forall a: Grp; forall b: Grp; forall c: Grp; forall d: Grp;
          inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
          inSubgroup(op(inverse(op(a, c)), op(b, d)))
        [by generalize at-a]
      @at-a |
        fix a: Grp {
          @at-b |
            fix b: Grp {
              @at-c |
                fix c: Grp {
                  @at-d |
                    fix d: Grp {
                      @given-a-b |
                        assume inSubgroup(op(inverse(a), b)) {
                          @a-to-b |
                            inSubgroup(op(inverse(a), b))
                            [by hypothesis given-a-b]
                          @given-c-d |
                            assume inSubgroup(op(inverse(c), d)) {
                              @c-to-d |
                                inSubgroup(op(inverse(c), d))
                                [by hypothesis given-c-d]
                              // (ac)⁻¹(bd) = c⁻¹(a⁻¹b)d = c⁻¹ n d  where n = a⁻¹b ∈ N.
                              // Normality turns c⁻¹nd into (c⁻¹n c)(c⁻¹d): the first factor
                              // is a conjugate of n, the second is c⁻¹d ∈ N, and N is closed.
                              @conjugate-of-n |
                                inSubgroup(op(op(inverse(c), op(inverse(a), b)), inverse(inverse(c))))
                                [using specialize normal(inverse(c), op(inverse(a), b)) a-to-b]
                              @double-inverse |
                                inverse(inverse(c)) = c
                                [using specialize invInvolution(c)]
                              @conjugate-tidied |
                                inSubgroup(op(op(inverse(c), op(inverse(a), b)), c))
                                [by rewrite double-inverse conjugate-of-n]
                              @product-in-n |
                                inSubgroup(op(op(op(inverse(c), op(inverse(a), b)), c), op(inverse(c), d)))
                                [using specialize subgroupClosedOp(op(op(inverse(c), op(inverse(a), b)), c), op(inverse(c), d)) conjugate-tidied c-to-d]
                              // that product IS (ac)⁻¹(bd); `simplify` closes the algebra,
                              // which is four associativity steps and two cancellations
                              // c(c⁻¹d) = d collapses the inner pair; then it is pure
                              // associativity plus (ac)⁻¹ = c⁻¹a⁻¹.
                              @c-regroup |
                                op(op(c, inverse(c)), d) = op(c, op(inverse(c), d))
                                [using specialize grpAssoc(c, inverse(c), d)]
                              @c-times-its-inverse |
                                op(c, inverse(c)) = E
                                [using specialize grpInverseRight(c)]
                              @identity-times-d |
                                op(E, d) = op(c, op(inverse(c), d))
                                [by rewrite c-times-its-inverse c-regroup]
                              @d-alone |
                                op(E, d) = d
                                [using specialize grpIdentityLeft(d)]
                              @c-cancels-into-d |
                                op(c, op(inverse(c), d)) = d
                                [using chain identity-times-d-flipped d-alone]
                              @identity-times-d-flipped |
                                op(c, op(inverse(c), d)) = op(E, d)
                                [by symmetry identity-times-d]
                              @the-product-is-the-quotient |
                                op(op(op(inverse(c), op(inverse(a), b)), c), op(inverse(c), d))
                                  = op(inverse(op(a, c)), op(b, d))
                                [using simplify c-cancels-into-d grpAssoc invProduct]
                              @conclusion-well-defined |
                                inSubgroup(op(inverse(op(a, c)), op(b, d)))
                                [by rewrite the-product-is-the-quotient product-in-n]
                            }
                          @c-d-implies |
                            inSubgroup(op(inverse(c), d)) -> inSubgroup(op(inverse(op(a, c)), op(b, d)))
                            [by discharge given-c-d]
                        }
                      @a-b-implies |
                        inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
                          inSubgroup(op(inverse(op(a, c)), op(b, d)))
                        [by discharge given-a-b]
                    }
                  @discharge-d |
                    forall d: Grp; inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
                      inSubgroup(op(inverse(op(a, c)), op(b, d)))
                    [by generalize at-d]
                }
              @discharge-c |
                forall c: Grp; forall d: Grp; inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
                  inSubgroup(op(inverse(op(a, c)), op(b, d)))
                [by generalize at-c]
            }
          @discharge-b |
            forall b: Grp; forall c: Grp; forall d: Grp; inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
              inSubgroup(op(inverse(op(a, c)), op(b, d)))
            [by generalize at-b]
        }
    }
  @conclusion |
    (forall g: Grp; forall n: Grp; inSubgroup(n) -> inSubgroup(op(op(g, n), inverse(g)))) ->
      forall a: Grp; forall b: Grp; forall c: Grp; forall d: Grp;
      inSubgroup(op(inverse(a), b)) -> inSubgroup(op(inverse(c), d)) ->
      inSubgroup(op(inverse(op(a, c)), op(b, d)))
    [by discharge given-normal]
qed
```

The remainder of the theorem is easy: $eN = N$ is the identity and $g^{-1}N$ is the
inverse of $gN$, so the cosets of $N$ form a group under this operation.

> *With no sort of subsets of a group, the cosets cannot themselves carry the operation:
> $G/N$ is a quotient sort with a class map $\mathrm{cls}$ onto it, congruent exactly when
> $a^{-1}b \in N$, which is §6.1's criterion.*

theorem theFactorGroupIsAssociative: forall x, y, z: Quot; opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
proof
  @generalize-x |
    fix x: Quot {
      @generalize-y |
        fix y: Quot {
          @generalize-z |
            fix z: Quot {
              @x-has-a-rep |
                exists a: FactorG; x = cls(a)
                [using specialize clsSurjective(x)]
              @with-x-rep |
                unpack a: FactorG from x-has-a-rep {
                  @x-is-cls-a |
                    x = cls(a)
                    [by hypothesis with-x-rep]
                  @y-has-a-rep |
                    exists b: FactorG; y = cls(b)
                    [using specialize clsSurjective(y)]
                  @with-y-rep |
                    unpack b: FactorG from y-has-a-rep {
                      @y-is-cls-b |
                        y = cls(b)
                        [by hypothesis with-y-rep]
                      @z-has-a-rep |
                        exists c: FactorG; z = cls(c)
                        [using specialize clsSurjective(z)]
                      @with-z-rep |
                        unpack c: FactorG from z-has-a-rep {
                          @z-is-cls-c |
                            z = cls(c)
                            [by hypothesis with-z-rep]
                          @the-left-inner |
                            opQ(cls(a), cls(b)) = cls(opG(a, b))
                            [using specialize opQHom(a, b)]
                          @the-left |
                            opQ(cls(opG(a, b)), cls(c)) = cls(opG(opG(a, b), c))
                            [using specialize opQHom(opG(a, b), c)]
                          @the-right-inner |
                            opQ(cls(b), cls(c)) = cls(opG(b, c))
                            [using specialize opQHom(b, c)]
                          @the-right |
                            opQ(cls(a), cls(opG(b, c))) = cls(opG(a, opG(b, c)))
                            [using specialize opQHom(a, opG(b, c))]
                          @g-is-associative |
                            opG(opG(a, b), c) = opG(a, opG(b, c))
                            [using specialize opGAssoc(a, b, c)]
                          @conclusion-at-reps |
                            opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
                            [using simplify x-is-cls-a y-is-cls-b z-is-cls-c the-left-inner the-left the-right-inner the-right g-is-associative]
                        }
                      @conclusion-after-z |
                        opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
                        [by unpacked with-z-rep]
                    }
                  @conclusion-after-y |
                    opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
                    [by unpacked with-y-rep]
                }
              @conclusion-after-x |
                opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
                [by unpacked with-x-rep]
            }
          @discharge-z |
            forall z: Quot; opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
            [by generalize generalize-z]
        }
      @discharge-y |
        forall y, z: Quot; opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
        [by generalize generalize-y]
    }
  @conclusion |
    forall x, y, z: Quot; opQ(opQ(x, y), z) = opQ(x, opQ(y, z))
    [by generalize generalize-x]
qed

The class map $G \to G/N$ is itself a homomorphism, and its kernel is exactly $N$ —
both of which Judson takes up in §11.2.

theorem theCanonicalMapIsAHomomorphism: forall a: FactorG; forall b: FactorG; cls(opG(a, b)) = opQ(cls(a), cls(b))
proof
  @generalize-a |
    fix a: FactorG {
      @generalize-b |
        fix b: FactorG {
          @the-product-of-classes |
            opQ(cls(a), cls(b)) = cls(opG(a, b))
            [using specialize opQHom(a, b)]
          @conclusion-at-a-and-b |
            cls(opG(a, b)) = opQ(cls(a), cls(b))
            [by symmetry the-product-of-classes]
        }
      @discharge-b |
        forall b: FactorG; cls(opG(a, b)) = opQ(cls(a), cls(b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: FactorG; forall b: FactorG; cls(opG(a, b)) = opQ(cls(a), cls(b))
    [by generalize generalize-a]
qed

theorem theCanonicalMapsKernelIsN: forall g: FactorG; cls(g) = EQ iff inN(g)
proof
  @generalize-g |
    fix g: FactorG {
      @the-identity-is-a-class |
        EQ = cls(EG)
        [by cite eqIsClsIdentity]
      @the-congruence-at-the-identity |
        cls(EG) = cls(g) iff inN(opG(invG(EG), g))
        [using specialize clsCongruent(EG, g)]
      // invG(EG) = EG, so invG(EG)·g collapses to g
      @the-identitys-inverse |
        invG(EG) = EG
        [by cite inverseIdentityG]
      @the-congruence-collapsed |
        cls(EG) = cls(g) iff inN(opG(EG, g))
        [by rewrite the-identitys-inverse the-congruence-at-the-identity]
      @g-absorbs-the-identity |
        opG(EG, g) = g
        [using specialize opGIdentityLeft(g)]
      @the-congruence-at-g |
        cls(EG) = cls(g) iff inN(g)
        [by rewrite g-absorbs-the-identity the-congruence-collapsed]
      @the-congruence-with-the-identity-class |
        EQ = cls(g) iff inN(g)
        [by rewrite the-identity-is-a-class the-congruence-at-g]
      // orient the equation the way the statement reads
      @given-g-is-killed |
        assume cls(g) = EQ {
          @g-is-killed |
            cls(g) = EQ
            [by hypothesis given-g-is-killed]
          @the-identity-is-gs-class |
            EQ = cls(g)
            [by symmetry g-is-killed]
          @conclusion-g-is-in-n |
            inN(g)
            [using tautology the-congruence-with-the-identity-class the-identity-is-gs-class]
        }
      @killed-implies-in-n |
        cls(g) = EQ -> inN(g)
        [by discharge given-g-is-killed]
      @given-g-is-in-n |
        assume inN(g) {
          @g-is-in-n |
            inN(g)
            [by hypothesis given-g-is-in-n]
          @the-identity-is-gs-class |
            EQ = cls(g)
            [using tautology the-congruence-with-the-identity-class g-is-in-n]
          @conclusion-g-is-killed |
            cls(g) = EQ
            [by symmetry the-identity-is-gs-class]
        }
      @in-n-implies-killed |
        inN(g) -> cls(g) = EQ
        [by discharge given-g-is-in-n]
      @conclusion-at-g |
        cls(g) = EQ iff inN(g)
        [by make_equivalence killed-implies-in-n in-n-implies-killed]
    }
  @conclusion |
    forall g: FactorG; cls(g) = EQ iff inN(g)
    [by generalize generalize-g]
qed
