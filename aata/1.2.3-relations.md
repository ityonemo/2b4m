## Equivalence Relations and Partitions

A fundamental notion in mathematics is that of equality. We can generalize
equality with equivalence relations and equivalence classes. An **equivalence
relation** on a set $X$ is a relation $R \subset X \times X$ such that

- $(x, x) \in R$ for all $x \in X$ (**reflexive** property);
- $(x, y) \in R$ implies $(y, x) \in R$ (**symmetric** property);
- $(x, y)$ and $(y, z) \in R$ imply $(x, z) \in R$ (**transitive** property).

Given an equivalence relation $R$ on a set $X$, we usually write $x \sim y$
instead of $(x, y) \in R$.

Judson gives four examples of equivalence relations, each over a concrete domain:

- **Fractions.** For integers $p, q, r, s$ with $q, s$ nonzero, define
  $p/q \sim r/s$ if $ps = qr$. Reflexivity and symmetry are clear. For transitivity,
  suppose $p/q \sim r/s$ and $r/s \sim t/u$. Then $ps = qr$ and $ru = st$, so
  $psu = qru = qst$; since $s \neq 0$, $pu = qt$, and $p/q \sim t/u$.
- **Derivatives.** For differentiable $f, g$ on $\mathbb{R}$, let
  $f(x) \sim g(x)$ if $f'(x) = g'(x)$.
- **Circles.** For $(x_1,y_1), (x_2,y_2) \in \mathbb{R}^2$, define
  $(x_1,y_1) \sim (x_2,y_2)$ if $x_1^2 + y_1^2 = x_2^2 + y_2^2$.
- **Similar matrices.** For $2 \times 2$ real matrices, $A \sim B$ if there is an
  invertible $P$ with $PAP^{-1} = B$. Matrices related this way are called **similar**.

> *These four need the rationals, calculus, $\mathbb{R}^2$ and matrices respectively, none
> of which this section's single abstract element sort provides, so they are recorded as
> prose. The structural results below hold of any equivalence relation, these included.*

Directly from the definition, an equivalence relation *is* each of its three
constituent properties: `equivalence` is a transparent `define` for
`reflexive and symmetric and transitive`, so each projection is an `and`-elimination.

```2b4m
theorem equivalenceIsReflexive: equivalence -> reflexive
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_lhs all-three]
      @conclusion-reflexive |
        reflexive
        [by and_lhs reflexive-and-symmetric]
    }
  @conclusion |
    equivalence -> reflexive
    [by discharge given-equivalence]
qed

theorem equivalenceIsSymmetric: equivalence -> symmetric
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_lhs all-three]
      @conclusion-symmetric |
        symmetric
        [by and_rhs reflexive-and-symmetric]
    }
  @conclusion |
    equivalence -> symmetric
    [by discharge given-equivalence]
qed

theorem equivalenceIsTransitive: equivalence -> transitive
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @conclusion-transitive |
        transitive
        [by and_rhs all-three]
    }
  @conclusion |
    equivalence -> transitive
    [by discharge given-equivalence]
qed
```
