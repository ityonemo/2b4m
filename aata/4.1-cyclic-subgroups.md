Subgroups"** of Thomas W. Judson's *Abstract Algebra: Theory and Applications*
(source: `vendor/aata/src/cyclic.xml`; © 1997–2026 Judson, GFDL 1.3). The book's
prose is reproduced in order — the cyclic subgroup $\langle a \rangle$, the
definitions of cyclic group / generator / order, and the four structural results
of the section — each followed by a machine-checked `bpa` proof. Run
`bpa check aata/4.1-cyclic-subgroups.md` to verify.

**Import horizon.** Following Judson's cumulative development, the *objects* he
already has in hand by Chapter 4 are imported; the *theorems he proves in §4.1*
are transcribed as real proofs (not aliased from a `std/` library that packages
them). So we import the group theory (Ch 3), the integer-exponent power $g^n$

## Cyclic Subgroups

Often a subgroup will depend entirely on a single element of the group; that is,
knowing that particular element will allow us to compute any other element in the
subgroup.

Suppose that we consider $3 \in \mathbb{Z}$ and look at all multiples (both
positive and negative) of $3$. As a set, this is
$$3\mathbb{Z} = \{ \ldots, -3, 0, 3, 6, \ldots \}.$$
It is easy to see that $3\mathbb{Z}$ is a subgroup of the integers. This subgroup
is completely determined by the element $3$ since we can obtain all of the other
elements of the group by taking multiples of $3$. Every element in the subgroup
is "generated" by $3$.

If $H = \{ 2^n : n \in \mathbb{Z} \}$, then $H$ is a subgroup of the
multiplicative group of nonzero rational numbers, $\mathbb{Q}^*$. If $a = 2^m$
and $b = 2^n$ are in $H$, then $ab^{-1} = 2^m 2^{-n} = 2^{m-n}$ is also in $H$.
By the subgroup criterion (§3.3), $H$ is a subgroup of $\mathbb{Q}^*$ determined
by the element $2$.

**Theorem (§4.1).** *Let $G$ be a group and $a$ be any element in $G$. Then the
set*
$$\langle a \rangle = \{ a^k : k \in \mathbb{Z} \}$$
*is a subgroup of $G$. Furthermore, $\langle a \rangle$ is the smallest subgroup
of $G$ that contains $a$.*

Judson's proof: the identity is in $\langle a \rangle$ since $a^0 = e$. If $g$
and $h$ are any two elements in $\langle a \rangle$, then $g = a^m$ and $h = a^n$
for some integers $m, n$, so $gh = a^m a^n = a^{m+n}$ is again in $\langle a
\rangle$. Finally, if $g = a^n$, then the inverse $g^{-1} = a^{-n}$ is also in
$\langle a \rangle$. Any subgroup $H$ containing $a$ must contain all powers of
$a$ by closure, so $H$ contains $\langle a \rangle$; hence $\langle a \rangle$ is
the smallest such subgroup.

Because `bpa` cannot quantify over group elements as a predicate, we fix the
generator as a constant $a$ and write $\langle a \rangle$ as the membership
predicate $\mathrm{inCyclic}(g) \equiv \exists k;\ g = a^k$. The three subgroup
conditions are the three parts of Judson's proof.

```bpa
// the fixed generator a and its cyclic subgroup ⟨a⟩ = { a^k : k ∈ ℤ }.
const a: G
define inCyclic(g) = exists k: Int; g = power(a, k)

// the identity is in ⟨a⟩: a^0 = e.
theorem cyclicContainsIdentity: inCyclic(e)
proof
  @power-zero |
    power(a, ZERO) = e
    [using specialize group_power.powerZero(a)]
  @e-is-a-power |
    e = power(a, ZERO)
    [by symmetry power-zero]
  @conclusion |
    inCyclic(e)
    [by exists_intro(ZERO) e-is-a-power]
qed
```

If $g = a^m$ and $h = a^n$ are in $\langle a \rangle$, then $gh = a^m a^n =
a^{m+n} \in \langle a \rangle$ — the closure under the operation.

```bpa
theorem cyclicClosedUnderOp: forall g, h: G; inCyclic(g) -> inCyclic(h) -> inCyclic(op(g, h))
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @given-g |
            assume inCyclic(g) {
              @given-h |
                assume inCyclic(h) {
                  @g-power |
                    exists k: Int; g = power(a, k)
                    [by hypothesis given-g]
                  @h-power |
                    exists k: Int; h = power(a, k)
                    [by hypothesis given-h]
                  @with-m |
                    unpack m: Int from g-power {
                      @g-is-am |
                        g = power(a, m)
                        [by hypothesis with-m]
                      @with-n |
                        unpack n: Int from h-power {
                          @h-is-an |
                            h = power(a, n)
                            [by hypothesis with-n]
                          // a^m·a^n = a^{m+n}.
                          @powers-add |
                            op(power(a, m), power(a, n)) = power(a, add(m, n))
                            [using specialize group_power.powerAdd(a, m, n)]
                          @gh-refl |
                            op(g, h) = op(g, h)
                            [by reflexivity]
                          @gh-with-m |
                            op(g, h) = op(power(a, m), h)
                            [by rewrite g-is-am gh-refl]
                          @gh-as-powers |
                            op(g, h) = op(power(a, m), power(a, n))
                            [by rewrite h-is-an gh-with-m]
                          @gh-is-power |
                            op(g, h) = power(a, add(m, n))
                            [using chain gh-as-powers powers-add]
                          @conclusion-inner |
                            inCyclic(op(g, h))
                            [by exists_intro(add(m, n)) gh-is-power]
                        }
                      @conclusion-with-m |
                        inCyclic(op(g, h))
                        [by exists_elim with-n]
                    }
                  @conclusion-op |
                    inCyclic(op(g, h))
                    [by exists_elim with-m]
                }
              @h-implies |
                inCyclic(h) -> inCyclic(op(g, h))
                [by implies_intro given-h]
            }
          @g-implies |
            inCyclic(g) -> inCyclic(h) -> inCyclic(op(g, h))
            [by implies_intro given-g]
        }
      @discharge-h |
        forall h: G; inCyclic(g) -> inCyclic(h) -> inCyclic(op(g, h))
        [by forall_intro generalize-h]
    }
  @conclusion |
    forall g, h: G; inCyclic(g) -> inCyclic(h) -> inCyclic(op(g, h))
    [by forall_intro generalize-g]
qed
```

And if $g = a^n$, its inverse $g^{-1} = a^{-n}$ is in $\langle a \rangle$ — the
closure under inverses.

```bpa
theorem cyclicClosedUnderInverse: forall g: G; inCyclic(g) -> inCyclic(inv(g))
proof
  @generalize-g |
    fix g: G {
      @given-g |
        assume inCyclic(g) {
          @g-power |
            exists k: Int; g = power(a, k)
            [by hypothesis given-g]
          @with-k |
            unpack k: Int from g-power {
              @g-is-ak |
                g = power(a, k)
                [by hypothesis with-k]
              // (a^k)⁻¹ = a^{−k}.
              @inverse-neg-power |
                power(a, neg(k)) = inv(power(a, k))
                [using specialize group_power.powerNegInverse(a, k)]
              @inv-refl |
                inv(g) = inv(g)
                [by reflexivity]
              @inv-as-inv-power |
                inv(g) = inv(power(a, k))
                [by rewrite g-is-ak inv-refl]
              @inv-is-power |
                inv(g) = power(a, neg(k))
                [by rewrite inverse-neg-power inv-as-inv-power]
              @conclusion-inner |
                inCyclic(inv(g))
                [by exists_intro(neg(k)) inv-is-power]
            }
          @conclusion-inv |
            inCyclic(inv(g))
            [by exists_elim with-k]
        }
      @g-implies |
        inCyclic(g) -> inCyclic(inv(g))
        [by implies_intro given-g]
    }
  @conclusion |
    forall g: G; inCyclic(g) -> inCyclic(inv(g))
    [by forall_intro generalize-g]
qed
```

Having the identity, closure under products, and closure under inverses,
$\langle a \rangle$ is a subgroup. And any subgroup $H$ containing $a$ must
contain every power of $a$ by closure, so $\langle a \rangle \subseteq H$;
$\langle a \rangle$ is therefore the smallest subgroup containing $a$.

If we are using the "$+$" notation, as in the case of the integers under
addition, we write $\langle a \rangle = \{ na : n \in \mathbb{Z} \}$.

For $a \in G$, we call $\langle a \rangle$ the **cyclic subgroup** generated by
$a$. If $G$ contains some element $a$ such that $G = \langle a \rangle$, then $G$
is a **cyclic group**. In this case $a$ is a **generator** of $G$. If $a$ is an
element of a group $G$, we define the **order** of $a$ to be the smallest
positive integer $n$ such that $a^n = e$, and we write $|a| = n$. If there is no
such integer $n$, we say that the order of $a$ is infinite.

Both $1$ and $5$ generate $\mathbb{Z}_6$; hence, $\mathbb{Z}_6$ is a cyclic
group. Not every element of a cyclic group is a generator: the order of $2 \in
\mathbb{Z}_6$ is $3$, and the cyclic subgroup generated by $2$ is $\langle 2
\rangle = \{ 0, 2, 4 \}$. The groups $\mathbb{Z}$ and $\mathbb{Z}_n$ are cyclic;
$1$ and $-1$ generate $\mathbb{Z}$. The group of units $U(9) = \{ 1, 2, 4, 5, 7,
8 \}$ in $\mathbb{Z}_9$ is cyclic, generated by $2$. Not every group is cyclic:
the symmetry group $S_3$ of an equilateral triangle has every subgroup cyclic,
yet no single element generates the whole group. (These examples live over the
concrete sorts $\mathbb{Z}_n$, $U(n)$, $S_3$ that `bpa` does not model, so they
are recorded here as prose.)

**Theorem (§4.1).** *Every cyclic group is abelian.*

Judson's proof: let $G$ be cyclic with generator $a$. If $g$ and $h$ are in $G$,
write $g = a^r$ and $h = a^s$. Then
$$g h = a^r a^s = a^{r+s} = a^{s+r} = a^s a^r = h g,$$
so $G$ is abelian. We transcribe exactly this chain — `powerAdd` forward, the
commutativity of integer addition on the exponents, then `powerAdd` backward.

```bpa
theorem cyclicIsAbelian: forall g, h: G; inCyclic(g) -> inCyclic(h) -> op(g, h) = op(h, g)
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @given-g |
            assume inCyclic(g) {
              @given-h |
                assume inCyclic(h) {
                  @g-power |
                    exists k: Int; g = power(a, k)
                    [by hypothesis given-g]
                  @h-power |
                    exists k: Int; h = power(a, k)
                    [by hypothesis given-h]
                  @with-r |
                    unpack r: Int from g-power {
                      @g-is-ar |
                        g = power(a, r)
                        [by hypothesis with-r]
                      @with-s |
                        unpack s: Int from h-power {
                          @h-is-as |
                            h = power(a, s)
                            [by hypothesis with-s]
                          // a^r·a^s = a^{r+s}.
                          @gh-powers |
                            op(power(a, r), power(a, s)) = power(a, add(r, s))
                            [using specialize group_power.powerAdd(a, r, s)]
                          // a^s·a^r = a^{s+r}.
                          @hg-powers |
                            op(power(a, s), power(a, r)) = power(a, add(s, r))
                            [using specialize group_power.powerAdd(a, s, r)]
                          // r+s = s+r.
                          @exponents-commute |
                            add(r, s) = add(s, r)
                            [using specialize integer.addIsCommutative(r, s)]
                          @same-power-refl |
                            power(a, add(r, s)) = power(a, add(r, s))
                            [by reflexivity]
                          @same-power |
                            power(a, add(r, s)) = power(a, add(s, r))
                            [by rewrite exponents-commute same-power-refl]
                          @hg-flipped |
                            power(a, add(s, r)) = op(power(a, s), power(a, r))
                            [by symmetry hg-powers]
                          // a^r·a^s = a^{r+s} = a^{s+r} = a^s·a^r.
                          @powers-commute |
                            op(power(a, r), power(a, s)) = op(power(a, s), power(a, r))
                            [using chain gh-powers same-power hg-flipped]
                          @gh-left |
                            op(g, power(a, s)) = op(power(a, s), power(a, r))
                            [by rewrite g-is-ar powers-commute]
                          @gh-both |
                            op(g, h) = op(power(a, s), power(a, r))
                            [by rewrite h-is-as gh-left]
                          @gh-right |
                            op(g, h) = op(h, power(a, r))
                            [by rewrite h-is-as gh-both]
                          @conclusion-inner |
                            op(g, h) = op(h, g)
                            [by rewrite g-is-ar gh-right]
                        }
                      @conclusion-with-r |
                        op(g, h) = op(h, g)
                        [by exists_elim with-s]
                    }
                  @conclusion-commute |
                    op(g, h) = op(h, g)
                    [by exists_elim with-r]
                }
              @h-implies |
                inCyclic(h) -> op(g, h) = op(h, g)
                [by implies_intro given-h]
            }
          @g-implies |
            inCyclic(g) -> inCyclic(h) -> op(g, h) = op(h, g)
            [by implies_intro given-g]
        }
      @discharge-h |
        forall h: G; inCyclic(g) -> inCyclic(h) -> op(g, h) = op(h, g)
        [by forall_intro generalize-h]
    }
  @conclusion |
    forall g, h: G; inCyclic(g) -> inCyclic(h) -> op(g, h) = op(h, g)
    [by forall_intro generalize-g]
qed
```

### Subgroups of Cyclic Groups

We can ask which subgroups a cyclic group possesses.

**Theorem (§4.1).** *Every subgroup of a cyclic group is cyclic.*

Judson's proof uses the division algorithm and well-ordering. Let $G = \langle a
\rangle$ and let $H$ be a subgroup of $G$. If $H = \{e\}$ it is trivially cyclic.
Otherwise $H$ contains some $g \neq e$, say $g = a^n$; since $H$ is a subgroup,
$g^{-1} = a^{-n} \in H$ too, so $H$ contains a positive power of $a$. Let $m$ be
the smallest natural number with $a^m \in H$ (it exists by well-ordering). We
claim $h = a^m$ generates $H$: for any $h' = a^k \in H$, the division algorithm
gives $k = mq + r$ with $0 \leq r < m$, so
$$a^k = a^{mq+r} = (a^m)^q a^r = h^q a^r, \quad\text{hence}\quad a^r = a^k h^{-q}.$$
Since $a^k \in H$ and $h^{-q} \in H$, we get $a^r \in H$; but $m$ was the least
positive exponent with $a^m \in H$, so $r = 0$ and $k = mq$. Therefore $h' = a^k
= (a^m)^q = h^q$, and $H$ is generated by $h$.

We formalize the heart of this argument. An arbitrary subgroup $H$ of $G$ is a
membership predicate `inH` closed under the identity, product, and inverse; its
distinguished generator is $a^m$ for the least positive exponent $m$ with $a^m
\in H$ (the well-ordering step, taken here as the hypotheses `mInH`, `mPositive`,
`mLeast`). The claim is that every $a^k \in H$ is a power of $a^m$.

> **Why the extra lemma `memberPowerInH`.** Judson writes "$h^q \in H$" and
> "$h^{-q} \in H$" in one breath — "by closure." For a machine-checked proof that
> elision has to be discharged: that *all* integer powers $x^q$ of a subgroup
> member $x$ lie in $H$ is not a single closure axiom but a **bidirectional
> induction on $q$** (base $x^0 = e \in H$; step $x^{q+1} = x^q x \in H$ and
> $x^{q-1} = x^q x^{-1} \in H$, each by one closure application). Judson's ambient
> "$H$ is a subgroup" carries this for granted; the kernel does not, so we prove it
> inline as `memberPowerInH` and then apply it to $x = a^m$ to get $a^{mq} = (a^m)^q
> \in H$. This is the only step of Judson's argument that is elided in the book and
> spelled out here.

```bpa
// an arbitrary subgroup H of G: contains e, closed under product and inverse.
pred inH(g: G)
axiom subgroupHasIdentity: inH(e)
axiom subgroupClosedOp: forall x, y: G; inH(x) -> inH(y) -> inH(op(x, y))
axiom subgroupClosedInverse: forall x: G; inH(x) -> inH(inv(x))

// all integer powers of a member stay in H — the "by closure" step Judson elides,
// proved by bidirectional induction on the exponent q.
theorem memberPowerInH: forall x: G; inH(x) -> forall q: Int; inH(power(x, q))
proof
  @generalize-x |
    fix x: G {
      @given-x-in-H |
        assume inH(x) {
          @x-in-H |
            inH(x)
            [by hypothesis given-x-in-H]
          @x-inverse-in-H |
            inH(inv(x))
            [using specialize subgroupClosedInverse(x) x-in-H]
          // base: x^0 = e ∈ H.
          @power-zero |
            power(x, ZERO) = e
            [using specialize group_power.powerZero(x)]
          @identity-in-H |
            inH(e)
            [by cite subgroupHasIdentity]
          @base-case |
            inH(power(x, ZERO))
            [by rewrite power-zero identity-in-H]
          @power-at-succ |
            forall b: G; forall q: Int; power(b, succ(q)) = op(power(b, q), b)
            [using import(group_power) powerSucc]
          @power-at-prev |
            forall b: G; forall q: Int; power(b, prev(q)) = op(power(b, q), inv(b))
            [using import(group_power) powerPrev]
          // successor step: x^q ∈ H ⟹ x^{q+1} = x^q·x ∈ H.
          @successor-step |
            fix q: Int {
              @given-ih |
                assume inH(power(x, q)) {
                  @ih |
                    inH(power(x, q))
                    [by hypothesis given-ih]
                  @succ-unfolds |
                    power(x, succ(q)) = op(power(x, q), x)
                    [by forall_elim(x, q) power-at-succ]
                  @product-in-H |
                    inH(op(power(x, q), x))
                    [using specialize subgroupClosedOp(power(x, q), x) ih x-in-H]
                  @conclusion-succ |
                    inH(power(x, succ(q)))
                    [by rewrite succ-unfolds product-in-H]
                }
              @ih-implies-succ |
                inH(power(x, q)) -> inH(power(x, succ(q)))
                [by implies_intro given-ih]
            }
          @successor-step-all |
            forall q: Int; inH(power(x, q)) -> inH(power(x, succ(q)))
            [by forall_intro successor-step]
          // predecessor step: x^q ∈ H ⟹ x^{q−1} = x^q·x⁻¹ ∈ H.
          @predecessor-step |
            fix q: Int {
              @given-ih |
                assume inH(power(x, q)) {
                  @ih |
                    inH(power(x, q))
                    [by hypothesis given-ih]
                  @prev-unfolds |
                    power(x, prev(q)) = op(power(x, q), inv(x))
                    [by forall_elim(x, q) power-at-prev]
                  @product-in-H |
                    inH(op(power(x, q), inv(x)))
                    [using specialize subgroupClosedOp(power(x, q), inv(x)) ih x-inverse-in-H]
                  @conclusion-prev |
                    inH(power(x, prev(q)))
                    [by rewrite prev-unfolds product-in-H]
                }
              @ih-implies-prev |
                inH(power(x, q)) -> inH(power(x, prev(q)))
                [by implies_intro given-ih]
            }
          @predecessor-step-all |
            forall q: Int; inH(power(x, q)) -> inH(power(x, prev(q)))
            [by forall_intro predecessor-step]
          @all-powers-in-H |
            forall q: Int; inH(power(x, q))
            [using instantiation integer.induction((fun q: Int => inH(power(x, q)))) base-case successor-step-all predecessor-step-all]
        }
      @x-implies |
        inH(x) -> forall q: Int; inH(power(x, q))
        [by implies_intro given-x-in-H]
    }
  @conclusion |
    forall x: G; inH(x) -> forall q: Int; inH(power(x, q))
    [by forall_intro generalize-x]
qed

// its least positive generating exponent m: a^m ∈ H, m > 0, and m is minimal.
const m: Int
axiom mInH: inH(power(a, m))
axiom mPositive: less_than(ZERO, m)
axiom mLeast: forall j: Int; less_than(ZERO, j) -> inH(power(a, j)) -> int_divides.at_most(m, j)

// every element a^k of H is a power of a^m: writing k = mq + r (division algorithm),
// a^r = (a^{mq})⁻¹·a^k ∈ H forces r = 0 (else m ≤ r < m), so a^k = (a^m)^q = h^q.
theorem subgroupElementIsPowerOfGenerator: forall k: Int; inH(power(a, k)) -> divides(m, k)
proof
  @generalize-k |
    fix k: Int {
      @given-ak-in-H |
        assume inH(power(a, k)) {
          @ak-in-H |
            inH(power(a, k))
            [by hypothesis given-ak-in-H]
          @m-positive |
            less_than(ZERO, m)
            [by cite mPositive]
          @am-in-H |
            inH(power(a, m))
            [by cite mInH]
          // division algorithm: k = m·q + r, 0 ≤ r < m.
          @div-alg |
            exists q: Int; exists r: Int; k = add(mul(m, q), r) and is_nonneg(r) and less_than(r, m)
            [using specialize int_divides.divisionAlgorithmExists(k, m) m-positive]
          @with-q |
            unpack q: Int from div-alg {
              @rem-exists |
                exists r: Int; k = add(mul(m, q), r) and is_nonneg(r) and less_than(r, m)
                [by hypothesis with-q]
              @with-r |
                unpack r: Int from rem-exists {
                  @div-facts |
                    k = add(mul(m, q), r) and is_nonneg(r) and less_than(r, m)
                    [by hypothesis with-r]
                  @k-split |
                    k = add(mul(m, q), r)
                    [using tautology div-facts]
                  @r-nonneg |
                    is_nonneg(r)
                    [using tautology div-facts]
                  @r-less-m |
                    less_than(r, m)
                    [using tautology div-facts]
                  // a^{mq} = (a^m)^q ∈ H (powers of the member a^m, by memberPowerInH).
                  @amq-is-am-q |
                    power(power(a, m), q) = power(a, mul(m, q))
                    [using specialize group_power.powerMul(a, m, q)]
                  @am-powers-in-H |
                    forall j: Int; inH(power(power(a, m), j))
                    [using specialize memberPowerInH(power(a, m)) am-in-H]
                  @am-q-in-H |
                    inH(power(power(a, m), q))
                    [by forall_elim(q) am-powers-in-H]
                  @amq-in-H |
                    inH(power(a, mul(m, q)))
                    [by rewrite amq-is-am-q am-q-in-H]
                  // a^{mq}·a^r = a^{mq+r} = a^k.
                  @powers-add |
                    op(power(a, mul(m, q)), power(a, r)) = power(a, add(mul(m, q), r))
                    [using specialize group_power.powerAdd(a, mul(m, q), r)]
                  @power-k-refl |
                    power(a, k) = power(a, k)
                    [by reflexivity]
                  @sum-is-k |
                    power(a, add(mul(m, q), r)) = power(a, k)
                    [by rewrite k-split power-k-refl]
                  @amq-ar-is-ak |
                    op(power(a, mul(m, q)), power(a, r)) = power(a, k)
                    [using chain powers-add sum-is-k]
                  // solve for a^r: multiply a^{mq}·a^r = a^k on the left by (a^{mq})⁻¹.
                  @left-multiply |
                    op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r))) = op(inv(power(a, mul(m, q))), power(a, k))
                    [by rewrite amq-ar-is-ak left-multiply-refl]
                  @left-multiply-refl |
                    op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r))) = op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r)))
                    [by reflexivity]
                  // regroup the LHS: (a^{mq})⁻¹·(a^{mq}·a^r) = ((a^{mq})⁻¹·a^{mq})·a^r = e·a^r = a^r.
                  @lhs-reassociates |
                    op(op(inv(power(a, mul(m, q))), power(a, mul(m, q))), power(a, r)) = op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r)))
                    [using specialize group.opAssoc(inv(power(a, mul(m, q))), power(a, mul(m, q)), power(a, r))]
                  @inverse-cancels |
                    op(inv(power(a, mul(m, q))), power(a, mul(m, q))) = e
                    [using specialize group.opInverseLeft(power(a, mul(m, q)))]
                  @lhs-with-e |
                    op(e, power(a, r)) = op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r)))
                    [by rewrite inverse-cancels lhs-reassociates]
                  @e-times-ar |
                    op(e, power(a, r)) = power(a, r)
                    [using specialize group.opIdentityLeft(power(a, r))]
                  @ar-is-lhs |
                    power(a, r) = op(inv(power(a, mul(m, q))), op(power(a, mul(m, q)), power(a, r)))
                    [using chain e-times-ar-flipped lhs-with-e]
                  @e-times-ar-flipped |
                    power(a, r) = op(e, power(a, r))
                    [by symmetry e-times-ar]
                  @ar-recovered |
                    power(a, r) = op(inv(power(a, mul(m, q))), power(a, k))
                    [using chain ar-is-lhs left-multiply]
                  // both factors are in H, so a^r ∈ H.
                  @amq-inv-in-H |
                    inH(inv(power(a, mul(m, q))))
                    [using specialize subgroupClosedInverse(power(a, mul(m, q))) amq-in-H]
                  @ar-product-in-H |
                    inH(op(inv(power(a, mul(m, q))), power(a, k)))
                    [using specialize subgroupClosedOp(inv(power(a, mul(m, q))), power(a, k)) amq-inv-in-H ak-in-H]
                  @ar-in-H |
                    inH(power(a, r))
                    [by rewrite ar-recovered ar-product-in-H]
                  // minimality forces r = 0: if 0 < r, then a^r ∈ H with r < m makes m
                  // the-least-positive fail (m ≤ r contradicts r < m); r ≥ 0 then gives r = 0.
                  @given-r-positive |
                    assume less_than(ZERO, r) {
                      @r-positive |
                        less_than(ZERO, r)
                        [by hypothesis given-r-positive]
                      @m-at-most-r |
                        int_divides.at_most(m, r)
                        [using specialize mLeast(r) r-positive ar-in-H]
                      // m ≤ r means m < r or m = r; either way not(r < m).
                      @m-le-r |
                        less_than(m, r) or m = r
                        [using tautology m-at-most-r]
                      @not-r-less-m |
                        not less_than(r, m)
                        case m-le-r {
                          @when-m-less-r |
                            assume less_than(m, r) {
                              @m-less-r |
                                less_than(m, r)
                                [by hypothesis when-m-less-r]
                              @suppose-r-less-m |
                                assume less_than(r, m) {
                                  @r-less-m-here |
                                    less_than(r, m)
                                    [by hypothesis suppose-r-less-m]
                                  @m-less-m |
                                    less_than(m, m)
                                    [using specialize int_divides.lessThanTransitive(m, r, m) m-less-r r-less-m-here]
                                  @not-m-less-m |
                                    not less_than(m, m)
                                    [using specialize int_divides.lessThanIrreflexive(m)]
                                }
                              @conclusion-not-less-strict |
                                not less_than(r, m)
                                [by not_intro suppose-r-less-m m-less-m not-m-less-m]
                            }
                          @when-m-equals-r |
                            assume m = r {
                              @m-eq-r |
                                m = r
                                [by hypothesis when-m-equals-r]
                              @not-r-less-r |
                                not less_than(r, r)
                                [using specialize int_divides.lessThanIrreflexive(r)]
                              @conclusion-not-less-equal |
                                not less_than(r, m)
                                [by rewrite m-eq-r not-r-less-r]
                            }
                        }
                    }
                  @not-r-positive |
                    not less_than(ZERO, r)
                    [by not_intro given-r-positive r-less-m not-r-less-m]
                  @r-is-zero |
                    r = ZERO
                    [using specialize int_divides.nonnegNotPositiveIsZero(r) r-nonneg not-r-positive]
                  @k-is-mq |
                    k = add(mul(m, q), ZERO)
                    [by rewrite r-is-zero k-split]
                  @mq-plus-zero |
                    add(mul(m, q), ZERO) = mul(m, q)
                    [using specialize integer.addZeroRight(mul(m, q))]
                  @k-is-multiple |
                    k = mul(m, q)
                    [using chain k-is-mq mq-plus-zero]
                  @conclusion-divides |
                    divides(m, k)
                    [by exists_intro(q) k-is-multiple]
                }
              @conclusion-with-r |
                divides(m, k)
                [by exists_elim with-r]
            }
          @conclusion-with-q |
            divides(m, k)
            [by exists_elim with-q]
        }
      @ak-implies |
        inH(power(a, k)) -> divides(m, k)
        [by implies_intro given-ak-in-H]
    }
  @conclusion |
    forall k: Int; inH(power(a, k)) -> divides(m, k)
    [by forall_intro generalize-k]
qed
```

Having shown every $a^k \in H$ is a multiple power $(a^m)^q$, $H = \langle a^m
\rangle$ is cyclic, generated by $h = a^m$. As a corollary, the subgroups of
$\mathbb{Z}$ are exactly $n\mathbb{Z}$ for $n = 0, 1, 2, \ldots$.

**Proposition (§4.1).** *Let $G$ be a cyclic group of order $n$ and suppose that
$a$ is a generator. Then $a^k = e$ if and only if $n$ divides $k$.*

Judson's proof. Suppose first $a^k = e$. By the division algorithm, $k = nq + r$
with $0 \leq r < n$; hence
$$e = a^k = a^{nq+r} = a^{nq} a^r = e\, a^r = a^r.$$
Since the smallest positive integer $m$ with $a^m = e$ is $n$, we must have $r =
0$, so $n \mid k$. Conversely, if $n \mid k$ then $k = ns$, and
$$a^k = a^{ns} = (a^n)^s = e^s = e.$$

The order $n$ of $a$ enters as a positive exponent that kills $a$ and is minimal
(`orderKills`, `orderPositive`, `orderMinimal` — the definition of $|a| = n$).

```bpa
// the order n of the generator a: n > 0, a^n = e, and n is least among positive
// exponents killing a (the definition |a| = n).
const n: Int
axiom orderPositive: less_than(ZERO, n)
axiom orderKills: power(a, n) = e
axiom orderMinimal: forall j: Int; less_than(ZERO, j) -> less_than(j, n) -> power(a, j) != e

// a^{n·s} = e for every s: (a^n)^s = e^s = e.
theorem orderMultipleKills: forall s: Int; power(a, mul(n, s)) = e
proof
  @generalize-s |
    fix s: Int {
      @power-mul |
        power(power(a, n), s) = power(a, mul(n, s))
        [using specialize group_power.powerMul(a, n, s)]
      @an-is-e |
        power(a, n) = e
        [by cite orderKills]
      @en-refl |
        power(power(a, n), s) = power(power(a, n), s)
        [by reflexivity]
      @base-is-e |
        power(power(a, n), s) = power(e, s)
        [by rewrite an-is-e en-refl]
      @e-to-s |
        power(e, s) = e
        [using specialize group_power.powerOfIdentity(s)]
      @power-mul-flipped |
        power(a, mul(n, s)) = power(power(a, n), s)
        [by symmetry power-mul]
      @conclusion-multiple |
        power(a, mul(n, s)) = e
        [using chain power-mul-flipped base-is-e e-to-s]
    }
  @conclusion |
    forall s: Int; power(a, mul(n, s)) = e
    [by forall_intro generalize-s]
qed

// forward: a^k = e ⟹ n | k. Division algorithm k = nq + r, 0 ≤ r < n; then a^r =
// a^k = e, and minimality of n forces r = 0.
theorem powerIsIdentityForward: forall k: Int; power(a, k) = e -> divides(n, k)
proof
  @generalize-k |
    fix k: Int {
      @given-killed |
        assume power(a, k) = e {
          @ak-is-e |
            power(a, k) = e
            [by hypothesis given-killed]
          @n-positive |
            less_than(ZERO, n)
            [by cite orderPositive]
          @div-alg |
            exists q: Int; exists r: Int; k = add(mul(n, q), r) and is_nonneg(r) and less_than(r, n)
            [using specialize int_divides.divisionAlgorithmExists(k, n) n-positive]
          @with-q |
            unpack q: Int from div-alg {
              @rem-exists |
                exists r: Int; k = add(mul(n, q), r) and is_nonneg(r) and less_than(r, n)
                [by hypothesis with-q]
              @with-r |
                unpack r: Int from rem-exists {
                  @div-facts |
                    k = add(mul(n, q), r) and is_nonneg(r) and less_than(r, n)
                    [by hypothesis with-r]
                  @k-split |
                    k = add(mul(n, q), r)
                    [using tautology div-facts]
                  @r-nonneg |
                    is_nonneg(r)
                    [using tautology div-facts]
                  @r-less-n |
                    less_than(r, n)
                    [using tautology div-facts]
                  // a^{nq}·a^r = a^{nq+r} = a^k = e, and a^{nq} = e, so a^r = e.
                  @powers-add |
                    op(power(a, mul(n, q)), power(a, r)) = power(a, add(mul(n, q), r))
                    [using specialize group_power.powerAdd(a, mul(n, q), r)]
                  @nq-kills |
                    power(a, mul(n, q)) = e
                    [using specialize orderMultipleKills(q)]
                  @e-times-ar |
                    op(e, power(a, r)) = power(a, add(mul(n, q), r))
                    [by rewrite nq-kills powers-add]
                  @identity-left |
                    op(e, power(a, r)) = power(a, r)
                    [using specialize group.opIdentityLeft(power(a, r))]
                  @ar-is-sum |
                    power(a, r) = power(a, add(mul(n, q), r))
                    [using chain identity-left-flipped e-times-ar]
                  @identity-left-flipped |
                    power(a, r) = op(e, power(a, r))
                    [by symmetry identity-left]
                  @sum-is-k |
                    power(a, add(mul(n, q), r)) = power(a, k)
                    [by rewrite k-split ak-refl]
                  @ak-refl |
                    power(a, k) = power(a, k)
                    [by reflexivity]
                  @ar-is-e |
                    power(a, r) = e
                    [using chain ar-is-sum sum-is-k ak-is-e]
                  // minimality: r < n and a^r = e force not(0 < r); with r ≥ 0, r = 0.
                  @given-r-positive |
                    assume less_than(ZERO, r) {
                      @r-positive |
                        less_than(ZERO, r)
                        [by hypothesis given-r-positive]
                      @ar-nonzero |
                        power(a, r) != e
                        [using specialize orderMinimal(r) r-positive r-less-n]
                    }
                  @not-r-positive |
                    not less_than(ZERO, r)
                    [by not_intro given-r-positive ar-is-e ar-nonzero]
                  @r-is-zero |
                    r = ZERO
                    [using specialize int_divides.nonnegNotPositiveIsZero(r) r-nonneg not-r-positive]
                  @k-is-nq |
                    k = add(mul(n, q), ZERO)
                    [by rewrite r-is-zero k-split]
                  @nq-plus-zero |
                    add(mul(n, q), ZERO) = mul(n, q)
                    [using specialize integer.addZeroRight(mul(n, q))]
                  @k-is-multiple |
                    k = mul(n, q)
                    [using chain k-is-nq nq-plus-zero]
                  @conclusion-divides |
                    divides(n, k)
                    [by exists_intro(q) k-is-multiple]
                }
              @conclusion-with-r |
                divides(n, k)
                [by exists_elim with-r]
            }
          @conclusion-with-q |
            divides(n, k)
            [by exists_elim with-q]
        }
      @killed-implies |
        power(a, k) = e -> divides(n, k)
        [by implies_intro given-killed]
    }
  @conclusion |
    forall k: Int; power(a, k) = e -> divides(n, k)
    [by forall_intro generalize-k]
qed

// converse: n | k ⟹ a^k = e. Write k = ns; a^k = a^{ns} = (a^n)^s = e^s = e.
theorem powerIsIdentityBackward: forall k: Int; divides(n, k) -> power(a, k) = e
proof
  @generalize-k |
    fix k: Int {
      @given-divides |
        assume divides(n, k) {
          @n-divides-k |
            exists s: Int; k = mul(n, s)
            [by hypothesis given-divides]
          @with-s |
            unpack s: Int from n-divides-k {
              @k-is-ns |
                k = mul(n, s)
                [by hypothesis with-s]
              @ns-kills |
                power(a, mul(n, s)) = e
                [using specialize orderMultipleKills(s)]
              @conclusion-killed |
                power(a, k) = e
                [by rewrite k-is-ns ns-kills]
            }
          @conclusion-with-s |
            power(a, k) = e
            [by exists_elim with-s]
        }
      @divides-implies |
        divides(n, k) -> power(a, k) = e
        [by implies_intro given-divides]
    }
  @conclusion |
    forall k: Int; divides(n, k) -> power(a, k) = e
    [by forall_intro generalize-k]
qed

// the proposition: a^k = e ⟺ n | k.
theorem powerIsIdentityIffOrderDivides: forall k: Int; power(a, k) = e iff divides(n, k)
proof
  @generalize-k |
    fix k: Int {
      @forward |
        power(a, k) = e -> divides(n, k)
        [using specialize powerIsIdentityForward(k)]
      @backward |
        divides(n, k) -> power(a, k) = e
        [using specialize powerIsIdentityBackward(k)]
      @conclusion-iff |
        power(a, k) = e iff divides(n, k)
        [by iff_intro forward backward]
    }
  @conclusion |
    forall k: Int; power(a, k) = e iff divides(n, k)
    [by forall_intro generalize-k]
qed
```

**Theorem (§4.1).** *Let $G$ be a cyclic group of order $n$ and suppose that $a
\in G$ is a generator. If $b = a^k$, then the order of $b$ is $n/d$, where $d =
\gcd(k, n)$.*

Judson's proof. We seek the smallest $M$ with $e = b^M = a^{kM}$. By the previous
proposition this is the smallest $M$ such that $n \mid kM$, or equivalently
$(n/d) \mid M(k/d)$. Since $d = \gcd(k, n)$, the cofactors $n/d$ and $k/d$ are
relatively prime, so for $n/d$ to divide $M(k/d)$ it must divide $M$; the
smallest such $M$ is $n/d$.

We write the cofactors as $K$ and $M_0$ with $k = dK$, $n = dM_0$ ($M_0 = n/d$,
$K = k/d$), and their coprimality as a Bézout identity $K\,x + M_0\,y = 1$ (which
holds because $d = \gcd(k, n)$ — dividing the gcd's Bézout identity through by
$d$). The two halves of "the order of $b$ is $M_0$" are that $M_0$ kills $b$ and
that $M_0$ is minimal; the coprime-divisibility step $M_0 \mid K m \Rightarrow M_0
\mid m$ is Euclid's lemma, a Chapter-2 prerequisite.

The kill half: $b^{M_0} = a^{k M_0} = a^{dK M_0} = a^{K (d M_0)} = a^{Kn} =
(a^n)^K = e$.

```bpa
// cofactors K = k/d, M0 = n/d with k = dK, n = dM0, and their coprimality as a
// Bézout identity (d = gcd(k,n) gives it after dividing through by d).
const d0: Int
const cofactorK: Int
const cofactorM: Int
const bezoutX: Int
const bezoutY: Int
const k0: Int
const b0: G
axiom dPositive: less_than(ZERO, d0)
axiom orderCofactorPositive: less_than(ZERO, cofactorM)
axiom kSplit: mul(d0, cofactorK) = k0
axiom nSplit: n = mul(d0, cofactorM)
axiom cofactorBezout: add(mul(cofactorK, bezoutX), mul(cofactorM, bezoutY)) = integer.ONE
axiom bIsAk: b0 = power(a, k0)

// b^{M0} = e: a^{k·M0} = a^{K·(d·M0)} = a^{K·n} = (a^n)^K = e.
theorem powerOfPowerKills: power(b0, cofactorM) = e
proof
  @b-is-ak |
    b0 = power(a, k0)
    [by cite bIsAk]
  @bm-refl |
    power(b0, cofactorM) = power(b0, cofactorM)
    [by reflexivity]
  @bm-as-ak |
    power(b0, cofactorM) = power(power(a, k0), cofactorM)
    [by rewrite b-is-ak bm-refl]
  @power-mul |
    power(power(a, k0), cofactorM) = power(a, mul(k0, cofactorM))
    [using specialize group_power.powerMul(a, k0, cofactorM)]
  @bm-is-akm |
    power(b0, cofactorM) = power(a, mul(k0, cofactorM))
    [using chain bm-as-ak power-mul]
  // k·M0 = (dK)·M0 = K·(dM0) = K·n.
  @k-is-dk |
    mul(d0, cofactorK) = k0
    [by cite kSplit]
  @n-is-dm |
    n = mul(d0, cofactorM)
    [by cite nSplit]
  @km-regroups |
    mul(mul(d0, cofactorK), cofactorM) = mul(cofactorK, mul(d0, cofactorM))
    [using polynomial(integer)]
  @km-with-k |
    mul(k0, cofactorM) = mul(cofactorK, mul(d0, cofactorM))
    [by rewrite k-is-dk km-regroups]
  @km-with-n |
    mul(k0, cofactorM) = mul(cofactorK, n)
    [by rewrite n-is-dm km-with-k]
  @kn-is-nk |
    mul(cofactorK, n) = mul(n, cofactorK)
    [using specialize integer.mulIsCommutative(cofactorK, n)]
  @km-is-nk |
    mul(k0, cofactorM) = mul(n, cofactorK)
    [using chain km-with-n kn-is-nk]
  @bm-is-ank |
    power(b0, cofactorM) = power(a, mul(n, cofactorK))
    [using chain bm-is-akm km-is-nk]
  @nk-kills |
    power(a, mul(n, cofactorK)) = e
    [using specialize orderMultipleKills(cofactorK)]
  @conclusion-kills |
    power(b0, cofactorM) = e
    [using chain bm-is-ank nk-kills]
qed
```

The minimal half: if $b^m = e$ for $0 < m < M_0$, then $a^{km} = e$, so $n \mid
km$ (the proposition); writing $n = dM_0$, $k = dK$ and cancelling $d$ gives $M_0
\mid Km$; coprimality (Euclid) gives $M_0 \mid m$; but then $M_0 \leq m < M_0$,
impossible.

```bpa
theorem powerOfPowerMinimal: forall mm: Int; less_than(ZERO, mm) -> less_than(mm, cofactorM) -> power(b0, mm) != e
proof
  @generalize-m |
    fix mm: Int {
      @given-m-positive |
        assume less_than(ZERO, mm) {
          @given-m-less |
            assume less_than(mm, cofactorM) {
              @m-positive |
                less_than(ZERO, mm)
                [by hypothesis given-m-positive]
              @m-less-order |
                less_than(mm, cofactorM)
                [by hypothesis given-m-less]
              @given-killed |
                assume power(b0, mm) = e {
                  @bm-killed |
                    power(b0, mm) = e
                    [by hypothesis given-killed]
                  // b^mm = a^{km}, so a^{km} = e ⟹ n | km.
                  @b-is-ak |
                    b0 = power(a, k0)
                    [by cite bIsAk]
                  @bm-refl |
                    power(b0, mm) = power(b0, mm)
                    [by reflexivity]
                  @bm-as-ak |
                    power(b0, mm) = power(power(a, k0), mm)
                    [by rewrite b-is-ak bm-refl]
                  @power-mul |
                    power(power(a, k0), mm) = power(a, mul(k0, mm))
                    [using specialize group_power.powerMul(a, k0, mm)]
                  @akm-killed |
                    power(a, mul(k0, mm)) = e
                    [using chain power-mul-flipped bm-as-ak-flipped bm-killed]
                  @power-mul-flipped |
                    power(a, mul(k0, mm)) = power(power(a, k0), mm)
                    [by symmetry power-mul]
                  @bm-as-ak-flipped |
                    power(power(a, k0), mm) = power(b0, mm)
                    [by symmetry bm-as-ak]
                  @n-divides-km |
                    divides(n, mul(k0, mm))
                    [using specialize powerIsIdentityForward(mul(k0, mm)) akm-killed]
                  @with-t |
                    unpack t: Int from n-divides-km {
                      @km-is-nt |
                        mul(k0, mm) = mul(n, t)
                        [by hypothesis with-t]
                      // dKm = km = nt = dM0·t; cancel d ⟹ Km = M0·t, i.e. M0 | Km.
                      @k-is-dk |
                        mul(d0, cofactorK) = k0
                        [by cite kSplit]
                      @n-is-dm |
                        n = mul(d0, cofactorM)
                        [by cite nSplit]
                      // km = dM0·t (substitute n = dM0 in km = nt).
                      @km-eq-dmt-via-n |
                        mul(k0, mm) = mul(mul(d0, cofactorM), t)
                        [by rewrite n-is-dm km-is-nt]
                      // (dK)m = dM0·t (substitute k0 = dK on the left).
                      @km-eq-dmt |
                        mul(mul(d0, cofactorK), mm) = mul(mul(d0, cofactorM), t)
                        [by rewrite k-is-dk km-eq-dmt-via-n]
                      @left-regroup |
                        mul(mul(d0, cofactorK), mm) = mul(d0, mul(cofactorK, mm))
                        [using polynomial(integer)]
                      @right-regroup |
                        mul(mul(d0, cofactorM), t) = mul(d0, mul(cofactorM, t))
                        [using polynomial(integer)]
                      @d-km-eq-d-mt |
                        mul(d0, mul(cofactorK, mm)) = mul(d0, mul(cofactorM, t))
                        [using chain left-regroup-flipped km-eq-dmt right-regroup]
                      @left-regroup-flipped |
                        mul(d0, mul(cofactorK, mm)) = mul(mul(d0, cofactorK), mm)
                        [by symmetry left-regroup]
                      @d-positive |
                        less_than(ZERO, d0)
                        [by cite dPositive]
                      @km-eq-mt |
                        mul(cofactorK, mm) = mul(cofactorM, t)
                        [using specialize int_divides.mulCancelLeft(d0, mul(cofactorK, mm), mul(cofactorM, t)) d-positive d-km-eq-d-mt]
                      @m0-divides-km |
                        divides(cofactorM, mul(cofactorK, mm))
                        [by exists_intro(t) km-eq-mt]
                      // Euclid: M0 coprime to K, M0 | K·mm ⟹ M0 | mm.
                      @bezout-one |
                        add(mul(cofactorK, bezoutX), mul(cofactorM, bezoutY)) = integer.ONE
                        [by cite cofactorBezout]
                      @bezout-swap |
                        add(mul(cofactorM, bezoutY), mul(cofactorK, bezoutX)) = add(mul(cofactorK, bezoutX), mul(cofactorM, bezoutY))
                        [using polynomial(integer)]
                      @bezout-m-form |
                        add(mul(cofactorM, bezoutY), mul(cofactorK, bezoutX)) = integer.ONE
                        [by rewrite bezout-one bezout-swap]
                      @m0-divides-m |
                        divides(cofactorM, mm)
                        [using specialize int_divides.euclidFromBezout(cofactorM, cofactorK, mm, bezoutY, bezoutX) bezout-m-form m0-divides-km]
                      // 0 < M0, 0 < mm, M0 | mm ⟹ M0 ≤ mm; contradicts mm < M0.
                      @m0-at-most |
                        int_divides.at_most(cofactorM, mm)
                        [using specialize int_divides.divisorAtMost(cofactorM, mm) order-cofactor-positive m-positive m0-divides-m]
                      @m0-le-m |
                        less_than(cofactorM, mm) or cofactorM = mm
                        [using tautology m0-at-most]
                      @not-m-less |
                        not less_than(mm, cofactorM)
                        case m0-le-m {
                          @when-strict |
                            assume less_than(cofactorM, mm) {
                              @strict |
                                less_than(cofactorM, mm)
                                [by hypothesis when-strict]
                              @suppose-m-less |
                                assume less_than(mm, cofactorM) {
                                  @m-less-here |
                                    less_than(mm, cofactorM)
                                    [by hypothesis suppose-m-less]
                                  @m0-less-m0 |
                                    less_than(cofactorM, cofactorM)
                                    [using specialize int_divides.lessThanTransitive(cofactorM, mm, cofactorM) strict m-less-here]
                                  @not-m0-less-m0 |
                                    not less_than(cofactorM, cofactorM)
                                    [using specialize int_divides.lessThanIrreflexive(cofactorM)]
                                }
                              @conclusion-strict |
                                not less_than(mm, cofactorM)
                                [by not_intro suppose-m-less m0-less-m0 not-m0-less-m0]
                            }
                          @when-equal |
                            assume cofactorM = mm {
                              @m0-eq-m |
                                cofactorM = mm
                                [by hypothesis when-equal]
                              @not-m-less-m |
                                not less_than(mm, mm)
                                [using specialize int_divides.lessThanIrreflexive(mm)]
                              @conclusion-equal |
                                not less_than(mm, cofactorM)
                                [by rewrite m0-eq-m not-m-less-m]
                            }
                        }
                      @order-cofactor-positive |
                        less_than(ZERO, cofactorM)
                        [by cite orderCofactorPositive]
                    }
                  @not-m-less-exported |
                    not less_than(mm, cofactorM)
                    [by exists_elim with-t]
                }
              @conclusion-neq |
                power(b0, mm) != e
                [by not_intro given-killed m-less-order not-m-less-exported]
            }
          @m-less-implies |
            less_than(mm, cofactorM) -> power(b0, mm) != e
            [by implies_intro given-m-less]
        }
      @m-positive-implies |
        less_than(ZERO, mm) -> less_than(mm, cofactorM) -> power(b0, mm) != e
        [by implies_intro given-m-positive]
    }
  @conclusion |
    forall mm: Int; less_than(ZERO, mm) -> less_than(mm, cofactorM) -> power(b0, mm) != e
    [by forall_intro generalize-m]
qed
```

So $b = a^k$ has order $M_0 = n/d$ — it is killed by $M_0$ and by nothing
smaller. As a corollary, the generators of $\mathbb{Z}_n$ are exactly the
integers $r$ with $1 \leq r < n$ and $\gcd(r, n) = 1$; for example, every $r$
coprime to $16$ generates $\mathbb{Z}_{16}$. (These statements about the concrete
group $\mathbb{Z}_n$ are recorded as prose.)
