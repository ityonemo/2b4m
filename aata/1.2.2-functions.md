# Functions

A literate `bpa` transliteration of **Chapter 1 ("Preliminaries"), §1.2.2
"Cartesian Products and Mappings"** of Thomas W. Judson's *Abstract Algebra:
Theory and Applications* (source: `vendor/aata/src/sets.xml`; © 1997–2026
Judson, GFDL 1.3). The book's prose is reproduced in order; each result the book
states is followed by a machine-checked `bpa` proof. Run
`bpa check aata/1.2.2-functions.md` to verify every proof block below.

The theory of mappings lives in `std/function.bpa`: functions are opaque `Fn`
objects over a fixed element domain `Element`, with `apply`, `compose`, an
identity map, and the `injective` / `surjective` / `invertible` properties.
`injective` / `surjective` are transparent `define`s (each IS its pointwise
body, so a proof gets the body for free); `invertible` stays an opaque `pred`
fixed by its defining axiom, plus **function extensionality** (maps agreeing
at every point are equal). We import it and keep the library names, aliasing
only `identityFn` to the book's `id`.

```bpa
import function <<< "std/function.bpa"

sort Element = function.Element
sort Fn = function.Fn
const id = function.identityFn
func apply = function.apply
func compose = function.compose
define injective(f: Fn) = function.injective(f)
define surjective(f: Fn) = function.surjective(f)
pred invertible = function.invertible
axiom composeApply = function.composeApply
axiom identityApply = function.identityApply
axiom funcExt = function.funcExtensionality
axiom invertibleDef = function.invertibleDef
func inverse = function.inverse
axiom inverseLeft = function.inverseLeft
axiom inverseRight = function.inverseRight
axiom functionFromGraph = function.functionFromGraph
```

> *Modeling note. `std/function.bpa` models every map as `f : Element ->
> Element` — a single element domain, which is all the results below need. So
> the book's **Cartesian product** `A × B` (ordered pairs) and its account of a
> function as a set of pairs `f ⊂ A × B` are not encoded: they would need a
> `Element × Element` pair sort and a set-of-pairs theory this file does not
> build. `bpa` instead takes `apply(f, x)` as primitive — the same `f(x) = b`,
> without the underlying pair set — and fixes a function by what `apply` does to
> it. The prose below is reproduced in full; where it depends on pairs (the
> product examples, "well-defined") it is exposition, not a formal claim.*

## Cartesian Products and Mappings

Given sets $A$ and $B$, we can define a new set $A \times B$, called the **Cartesian product** of $A$ and $B$, as a set of ordered pairs. That is,

$$A \times B = \{ (a,b) : a \in A \text{ and } b \in B \}$$.

**Example.** If $A = \{ x, y \}$, $B = \{ 1, 2, 3 \}$, and $C = \emptyset$, then $A \times B$ is the set

$$\{ (x, 1), (x, 2), (x, 3), (y, 1), (y, 2), (y, 3) \}$$

and

$$A \times C = \emptyset$$.

We define the **Cartesian product of $n$ sets** to be

$$A_1 \times \cdots \times A_n = \{ (a_1, \ldots, a_n): a_i \in A_i \text{ for } i = 1, \ldots, n \}$$.

If $A = A_1 = A_2 = \cdots = A_n$, we often write $A^n$ for $A \times \cdots \times A$ (where $A$ would be written $n$ times). For example, the set ${\mathbb R}^3$ consists of all of 3-tuples of real numbers.

Subsets of $A \times B$ are called **relations**. We will define a **mapping** or **function** $f \subset A \times B$ from a set $A$ to a set $B$ to be the special type of relation where each element $a \in A$ has a unique element $b \in B$ such that $(a, b) \in f$. Another way of saying this is that for every element in $A$, $f$ assigns a unique element in $B$. We usually write $f:A \rightarrow B$ or $A \stackrel{f}{\rightarrow} B$. Instead of writing down ordered pairs $(a,b) \in A \times B$, we write $f(a) = b$ or $f : a \mapsto b$. The set $A$ is called the **domain** of $f$ and

$$f(A) = \{ f(a) : a \in A \} \subset B$$

is called the **range** or **image** of $f$. We can think of the elements in the function's domain as input values and the elements in the function's range as output values.

**Example.** Suppose $A = \{1, 2, 3 \}$ and $B = \{a, b, c \}$. In the figure below we define relations $f$ and $g$ from $A$ to $B$. The relation $f$ is a mapping, but $g$ is not because $1 \in A$ is not assigned to a unique element in $B$; that is, $g(1) = a$ and $g(1) = b$.

*(Figure omitted: Mappings and relations — two sets of ovals, A and B, relating 1, 2, 3 to a, b, c. The first mapping, f, sends 1 to b and 2 and 3 to c. The second relation, g, sends 1 to a and b, 2 to c, and 3 to a.)*

Given a function $f : A \rightarrow B$, it is often possible to write a list describing what the function does to each specific element in the domain. However, not all functions can be described in this manner. For example, the function $f: {\mathbb R} \rightarrow {\mathbb R}$ that sends each real number to its cube is a mapping that must be described by writing $f(x) = x^3$ or $f:x \mapsto x^3$.

Consider the relation $f : {\mathbb Q} \rightarrow {\mathbb Z}$ given by $f(p/q) = p$. We know that $1/2 = 2/4$, but is $f(1/2) = 1$ or $2$? This relation cannot be a mapping because it is not well-defined. A relation is **well-defined** if each element in the domain is assigned to a *unique* element in the range.

If $f:A \rightarrow B$ is a map and the image of $f$ is $B$, i.e., $f(A) = B$, then $f$ is said to be **onto** or **surjective**. In other words, if there exists an $a \in A$ for each $b \in B$ such that $f(a) = b$, then $f$ is onto. A map is **one-to-one** or **injective** if $a_1 \neq a_2$ implies $f(a_1) \neq f(a_2)$. Equivalently, a function is one-to-one if $f(a_1) = f(a_2)$ implies $a_1 = a_2$. A map that is both one-to-one and onto is called **bijective**.

**Example.** Let $f:{\mathbb Z} \rightarrow {\mathbb Q}$ be defined by $f(n) = n/1$. Then $f$ is one-to-one but not onto. Define $g : {\mathbb Q} \rightarrow {\mathbb Z}$ by $g(p/q) = p$ where $p/q$ is a rational number expressed in its lowest terms with a positive denominator. The function $g$ is onto but not one-to-one.

Given two functions, we can construct a new function by using the range of the first function as the domain of the second function. Let $f : A \rightarrow B$ and $g : B \rightarrow C$ be mappings. Define a new map, the **composition** of $f$ and $g$ from $A$ to $C$, by $(g \circ f)(x) = g(f(x))$.

*(Figure omitted: Composition of maps — two sets of ovals, A and B, relating 1, 2, 3 to a, b, c and a, b, c to X, Y, Z. The first mapping, f, sends 1 to b, 2 to c, and 3 to a. The second relation, g, sends a and b to Z and c to X. The bottom map, g∘f, sends 1 and 3 to Z and 2 to X.)*

**Example.** Consider the functions $f: A \rightarrow B$ and $g: B \rightarrow C$ that are defined in the figure above (top). The composition of these functions, $g \circ f: A \rightarrow C$, is defined in the figure above (bottom).

**Example.** Let $f(x) = x^2$ and $g(x) = 2x + 5$. Then

$$(f \circ g)(x) = f(g(x)) = (2x + 5)^2 = 4x^2 + 20x + 25$$

and

$$(g \circ f)(x) = g(f(x)) = 2x^2 + 5$$.

In general, order makes a difference; that is, in most cases $f \circ g \neq g \circ f$.

**Example.** Sometimes it is the case that $f \circ g= g \circ f$. Let $f(x) = x^3$ and $g(x) = \sqrt[3]{x}$. Then

$$(f \circ g )(x) = f(g(x)) = f( \sqrt[3]{x}\, ) = (\sqrt[3]{x}\, )^3 = x$$

and

$$(g \circ f )(x) = g(f(x)) = g( x^3) = \sqrt[3]{ x^3} = x$$.

**Example.** Given a $2 \times 2$ matrix

$$A =
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}$$,

we can define a map $T_A : {\mathbb R}^2 \rightarrow {\mathbb R}^2$ by

$$T_A (x,y) = (ax + by, cx +dy)$$

for $(x,y)$ in ${\mathbb R}^2$. This is actually matrix multiplication; that is,

$$\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
\begin{pmatrix}
x \\ y
\end{pmatrix}
=
\begin{pmatrix}
ax + by \\
cx +dy
\end{pmatrix}$$.

Maps from ${\mathbb R}^n$ to ${\mathbb R}^m$ given by matrices are called **linear maps** or **linear transformations**.

**Example.** Suppose that $S = \{ 1,2,3  \}$. Define a map $\pi :S\rightarrow S$ by

$$\pi( 1 )  = 2, \qquad \pi( 2 )  = 1, \qquad \pi( 3 )  = 3$$.

This is a bijective map. An alternative way to write $\pi$ is

$$\begin{pmatrix}
1 & 2 & 3 \\
\pi(1) & \pi(2) & \pi(3)
\end{pmatrix}
=
\begin{pmatrix}
1 & 2 & 3 \\
2 & 1 & 3
\end{pmatrix}$$.

For any set $S$, a one-to-one and onto mapping $\pi : S \rightarrow S$ is called a **permutation** of $S$.

## Theorem

> Let $f : A \rightarrow B$, $g : B \rightarrow C$, and $h : C \rightarrow D$. Then
>
> 1. The composition of mappings is associative; that is, $(h \circ g) \circ f = h \circ (g \circ f)$;
> 2. If $f$ and $g$ are both one-to-one, then the mapping $g \circ f$ is one-to-one;
> 3. If $f$ and $g$ are both onto, then the mapping $g \circ f$ is onto;
> 4. If $f$ and $g$ are bijective, then so is $g \circ f$.

We formalize all four parts. **(1) associativity** is a function-extensionality
argument: the two composites agree at every point `x` after unfolding
`compose` via `composeApply`, so `funcExt` equates them.

```bpa
// Theorem A.1: composition is associative.
theorem composeAssoc: forall h, g, f: Fn;
  compose(compose(h, g), f) = compose(h, compose(g, f))
proof
  @generalize-h |
    fix h: Fn {
      @generalize-g |
        fix g: Fn {
          @generalize-f |
            fix f: Fn {
              @pointwise |
                fix x: Element {
                  // LHS applied at x
                  @compose-applies |
                    forall gg, ff: Fn; forall y: Element;
                      apply(compose(gg, ff), y) = apply(gg, apply(ff, y))
                    [by cite composeApply]
                  @lhs-outer-unfolds |
                    apply(compose(compose(h, g), f), x) = apply(compose(h, g), apply(f, x))
                    [by forall_elim(compose(h, g), f, x) compose-applies]
                  @lhs-inner-unfolds |
                    apply(compose(h, g), apply(f, x)) = apply(h, apply(g, apply(f, x)))
                    [by forall_elim(h, g, apply(f, x)) compose-applies]
                  @lhs-associated-unfolds |
                    apply(compose(compose(h, g), f), x) = apply(h, apply(g, apply(f, x)))
                    [by rewrite lhs-inner-unfolds lhs-outer-unfolds]
                  // RHS applied at x
                  @rhs-outer-unfolds |
                    apply(compose(h, compose(g, f)), x) = apply(h, apply(compose(g, f), x))
                    [by forall_elim(h, compose(g, f), x) compose-applies]
                  @rhs-inner-unfolds |
                    apply(compose(g, f), x) = apply(g, apply(f, x))
                    [by forall_elim(g, f, x) compose-applies]
                  @rhs-associated-unfolds |
                    apply(compose(h, compose(g, f)), x) = apply(h, apply(g, apply(f, x)))
                    [by rewrite rhs-inner-unfolds rhs-outer-unfolds]
                  // equate the two sides at x
                  @both-sides-agree-at-x |
                    apply(compose(compose(h, g), f), x) = apply(compose(h, compose(g, f)), x)
                    [by rewrite rhs-associated-unfolds lhs-associated-unfolds]
                }
              @agree-pointwise |
                forall x: Element;
                  apply(compose(compose(h, g), f), x) = apply(compose(h, compose(g, f)), x)
                [by forall_intro pointwise]
              @conclusion-at-h-g-f |
                compose(compose(h, g), f) = compose(h, compose(g, f))
                [using specialize funcExt(compose(compose(h, g), f), compose(h, compose(g, f))) agree-pointwise]
            }
          @discharge-f |
            forall f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
            [by forall_intro generalize-f]
        }
      @discharge-g |
        forall g, f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
        [by forall_intro generalize-g]
    }
  @conclusion |
    forall h, g, f: Fn; compose(compose(h, g), f) = compose(h, compose(g, f))
    [by forall_intro generalize-h]
qed
```

**(2) injective ∘ injective is injective** (the book's exercise): if
`(g∘f)(a) = (g∘f)(b)` then `g(f(a)) = g(f(b))`; `g` injective gives
`f(a) = f(b)`; `f` injective gives `a = b`.

```bpa
// Theorem A.2: inj ∘ inj is injective.
// If (g∘f)(a)=(g∘f)(b) then g(f(a))=g(f(b)); g injective gives f(a)=f(b); f
// injective gives a=b.
theorem composeInjective: forall g, f: Fn;
  injective(g) -> injective(f) -> injective(compose(g, f))
proof
  @generalize-g |
    fix g: Fn {
      @generalize-f |
        fix f: Fn {
          @given-g-injective |
            assume injective(g) {
              @given-f-injective |
                assume injective(f) {
                  // injective is a transparent define: injective(g) IS its
                  // pointwise body, so the hypotheses ARE the pointwise forms.
                  @g-is-pointwise-injective |
                    forall a, b: Element; apply(g, a) = apply(g, b) -> a = b
                    [by hypothesis given-g-injective]
                  @f-is-pointwise-injective |
                    forall a, b: Element; apply(f, a) = apply(f, b) -> a = b
                    [by hypothesis given-f-injective]
                  @generalize-a |
                    fix a: Element {
                      @generalize-b |
                        fix b: Element {
                          @given-composite-agrees |
                            assume apply(compose(g, f), a) = apply(compose(g, f), b) {
                              @compose-applies |
                                forall gg, ff: Fn; forall x: Element;
                                  apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                                [by cite composeApply]
                              @composite-a-unfolds |
                                apply(compose(g, f), a) = apply(g, apply(f, a))
                                [by forall_elim(g, f, a) compose-applies]
                              @composite-b-unfolds |
                                apply(compose(g, f), b) = apply(g, apply(f, b))
                                [by forall_elim(g, f, b) compose-applies]
                              @composites-agree |
                                apply(compose(g, f), a) = apply(compose(g, f), b)
                                [by hypothesis given-composite-agrees]
                              // rewrite both composites to g(f(-)): g(f(a)) = g(f(b))
                              @g-of-fa-agrees-with-composite-b |
                                apply(g, apply(f, a)) = apply(compose(g, f), b)
                                [by rewrite composite-a-unfolds composites-agree]
                              @g-of-fa-equals-g-of-fb |
                                apply(g, apply(f, a)) = apply(g, apply(f, b))
                                [by rewrite composite-b-unfolds g-of-fa-agrees-with-composite-b]
                              // g injective on f(a), f(b) => f(a) = f(b)
                              @fa-equals-fb |
                                apply(f, a) = apply(f, b)
                                [using specialize g-is-pointwise-injective(apply(f, a), apply(f, b)) g-of-fa-equals-g-of-fb]
                              // f injective => a = b
                              @a-equals-b |
                                a = b
                                [using specialize f-is-pointwise-injective(a, b) fa-equals-fb]
                            }
                          @composite-injective-at-a-b |
                            apply(compose(g, f), a) = apply(compose(g, f), b) -> a = b
                            [by implies_intro given-composite-agrees]
                        }
                      @discharge-b |
                        forall b: Element; apply(compose(g, f), a) = apply(compose(g, f), b) -> a = b
                        [by forall_intro generalize-b]
                    }
                  // the pointwise body IS injective(compose(g, f)) (transparent).
                  @composite-is-injective |
                    injective(compose(g, f))
                    [by forall_intro generalize-a]
                }
              @f-injective-implies-composite-injective |
                injective(f) -> injective(compose(g, f))
                [by implies_intro given-f-injective]
            }
          @g-injective-implies-composite-injective |
            injective(g) -> injective(f) -> injective(compose(g, f))
            [by implies_intro given-g-injective]
        }
      @discharge-f |
        forall f: Fn; injective(g) -> injective(f) -> injective(compose(g, f))
        [by forall_intro generalize-f]
    }
  @conclusion |
    forall g, f: Fn; injective(g) -> injective(f) -> injective(compose(g, f))
    [by forall_intro generalize-g]
qed
```

**(3) onto ∘ onto is onto** (the book's proof): given `c`, surjectivity of `g`
yields `b` with `g(b) = c`, then surjectivity of `f` yields `a` with
`f(a) = b`, and `(g∘f)(a) = g(f(a)) = g(b) = c`.

```bpa
// Theorem A.3: onto ∘ onto is onto (the book's proof (3)).
// Given c, g onto gives b with g(b)=c; f onto gives a with f(a)=b; then
// (g∘f)(a) = g(f(a)) = g(b) = c.
theorem composeSurjective: forall g, f: Fn;
  surjective(g) -> surjective(f) -> surjective(compose(g, f))
proof
  @generalize-g |
    fix g: Fn {
      @generalize-f |
        fix f: Fn {
          @given-g-surjective |
            assume surjective(g) {
              @given-f-surjective |
                assume surjective(f) {
                  // surjective is a transparent define: surjective(g) IS its
                  // pointwise body, so the hypotheses ARE the pointwise forms.
                  @g-is-pointwise-surjective |
                    forall y: Element; exists x: Element; apply(g, x) = y
                    [by hypothesis given-g-surjective]
                  @f-is-pointwise-surjective |
                    forall y: Element; exists x: Element; apply(f, x) = y
                    [by hypothesis given-f-surjective]
                  @generalize-c |
                    fix c: Element {
                      // g onto: get b with g(b) = c
                      @c-has-g-preimage |
                        exists x: Element; apply(g, x) = c
                        [by forall_elim(c) g-is-pointwise-surjective]
                      @with-g-preimage-b |
                        unpack b: Element from c-has-g-preimage {
                          @g-maps-b-to-c |
                            apply(g, b) = c
                            [by hypothesis with-g-preimage-b]
                          // f onto: get a with f(a) = b
                          @b-has-f-preimage |
                            exists x: Element; apply(f, x) = b
                            [by forall_elim(b) f-is-pointwise-surjective]
                          @with-f-preimage-a |
                            unpack a: Element from b-has-f-preimage {
                              @f-maps-a-to-b |
                                apply(f, a) = b
                                [by hypothesis with-f-preimage-a]
                              @compose-applies |
                                forall gg, ff: Fn; forall x: Element;
                                  apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                                [by cite composeApply]
                              @composite-a-unfolds |
                                apply(compose(g, f), a) = apply(g, apply(f, a))
                                [by forall_elim(g, f, a) compose-applies]
                              // g(f(a)) = g(b) = c
                              @composite-a-equals-g-of-b |
                                apply(compose(g, f), a) = apply(g, b)
                                [by rewrite f-maps-a-to-b composite-a-unfolds]
                              @composite-maps-a-to-c |
                                apply(compose(g, f), a) = c
                                [by rewrite g-maps-b-to-c composite-a-equals-g-of-b]
                              @composite-has-preimage-a |
                                exists x: Element; apply(compose(g, f), x) = c
                                [by exists_intro(a) composite-maps-a-to-c]
                            }
                          @composite-hits-c-via-f |
                            exists x: Element; apply(compose(g, f), x) = c
                            [by exists_elim with-f-preimage-a]
                        }
                      @composite-hits-c |
                        exists x: Element; apply(compose(g, f), x) = c
                        [by exists_elim with-g-preimage-b]
                    }
                  // the pointwise body IS surjective(compose(g, f)) (transparent).
                  @composite-is-surjective |
                    surjective(compose(g, f))
                    [by forall_intro generalize-c]
                }
              @f-surjective-implies-composite-surjective |
                surjective(f) -> surjective(compose(g, f))
                [by implies_intro given-f-surjective]
            }
          @g-surjective-implies-composite-surjective |
            surjective(g) -> surjective(f) -> surjective(compose(g, f))
            [by implies_intro given-g-surjective]
        }
      @discharge-f |
        forall f: Fn; surjective(g) -> surjective(f) -> surjective(compose(g, f))
        [by forall_intro generalize-f]
    }
  @conclusion |
    forall g, f: Fn; surjective(g) -> surjective(f) -> surjective(compose(g, f))
    [by forall_intro generalize-g]
qed
```

**(4) bijective ∘ bijective is bijective** follows from (2) and (3) — reading
"bijective" as `injective and surjective`, exactly the book's definition.

```bpa
// Theorem A.4: bij ∘ bij is bij (bijective = injective and surjective).
theorem composeBijective: forall g, f: Fn;
  (injective(g) and surjective(g)) -> (injective(f) and surjective(f))
  -> (injective(compose(g, f)) and surjective(compose(g, f)))
proof
  @generalize-g |
    fix g: Fn {
      @generalize-f |
        fix f: Fn {
          @given-g-bijective |
            assume injective(g) and surjective(g) {
              @given-f-bijective |
                assume injective(f) and surjective(f) {
                  @g-is-bijective |
                    injective(g) and surjective(g)
                    [by hypothesis given-g-bijective]
                  @f-is-bijective |
                    injective(f) and surjective(f)
                    [by hypothesis given-f-bijective]
                  @g-is-injective |
                    injective(g)
                    [by and_elim_left g-is-bijective]
                  @g-is-surjective |
                    surjective(g)
                    [by and_elim_right g-is-bijective]
                  @f-is-injective |
                    injective(f)
                    [by and_elim_left f-is-bijective]
                  @f-is-surjective |
                    surjective(f)
                    [by and_elim_right f-is-bijective]
                  @composite-is-injective |
                    injective(compose(g, f))
                    [using specialize composeInjective(g, f) g-is-injective f-is-injective]
                  @composite-is-surjective |
                    surjective(compose(g, f))
                    [using specialize composeSurjective(g, f) g-is-surjective f-is-surjective]
                  @composite-is-bijective |
                    injective(compose(g, f)) and surjective(compose(g, f))
                    [by and_intro composite-is-injective composite-is-surjective]
                }
              @f-bijective-implies-composite-bijective |
                (injective(f) and surjective(f)) -> (injective(compose(g, f)) and surjective(compose(g, f)))
                [by implies_intro given-f-bijective]
            }
          @g-bijective-implies-composite-bijective |
            (injective(g) and surjective(g)) -> (injective(f) and surjective(f))
              -> (injective(compose(g, f)) and surjective(compose(g, f)))
            [by implies_intro given-g-bijective]
        }
      @discharge-f |
        forall f: Fn;
          (injective(g) and surjective(g)) -> (injective(f) and surjective(f))
          -> (injective(compose(g, f)) and surjective(compose(g, f)))
        [by forall_intro generalize-f]
    }
  @conclusion |
    forall g, f: Fn;
      (injective(g) and surjective(g)) -> (injective(f) and surjective(f))
      -> (injective(compose(g, f)) and surjective(compose(g, f)))
    [by forall_intro generalize-g]
qed
```

**Proof (book).** We will prove (1) and (3). Part (2) is left as an exercise. Part (4) follows directly from (2) and (3).

(1) We must show that

$$h \circ (g \circ f) = (h \circ g) \circ f$$.

For $a \in A$ we have

$$\begin{aligned}
(h \circ (g \circ f))(a) & = h((g \circ f)(a)) \\
& = h(g(f(a))) \\
& = (h \circ g)(f(a)) \\
& = ((h \circ g) \circ f)(a)
\end{aligned}$$.

(3) Assume that $f$ and $g$ are both onto functions. Given $c \in C$, we must show that there exists an $a \in A$ such that $(g \circ f)(a) = g(f(a)) = c$. However, since $g$ is onto, there is an element $b \in B$ such that $g(b) = c$. Similarly, there is an $a \in A$ such that $f(a) = b$. Accordingly,

$$(g \circ f)(a) = g(f(a)) = g(b) = c$$.

If $S$ is any set, we will use $\operatorname{id}_S$ or $\operatorname{id}$ to denote the **identity mapping** from $S$ to itself. Define this map by $\operatorname{id}(s) = s$ for all $s \in S$. A map $g: B \rightarrow A$ is an **inverse mapping** of $f: A \rightarrow B$ if $g \circ f = \operatorname{id}_A$ and $f \circ g = \operatorname{id}_B$; in other words, the inverse function of a function simply "undoes" the function. A map is said to be **invertible** if it has an inverse. We usually write $f^{-1}$ for the inverse of $f$.

**Example.** The function $f(x) = x^3$ has inverse $f^{-1}(x) = \sqrt[3]{x}$ by the earlier commuting-composition example.

**Example.** The natural logarithm and the exponential functions, $f(x) = \ln x$ and $f^{-1}(x) = e^x$, are inverses of each other provided that we are careful about choosing domains. Observe that

$$f(f^{-1}(x)) = f(e^x) = \ln e^x = x$$

and

$$f^{-1}(f(x)) = f^{-1}(\ln x) = e^{\ln x} = x$$

whenever composition makes sense.

**Example.** Suppose that

$$A =
\begin{pmatrix}
3 & 1 \\
5 & 2
\end{pmatrix}$$.

Then $A$ defines a map from ${\mathbb R}^2$ to ${\mathbb R}^2$ by

$$T_A (x,y) = (3x +  y, 5x + 2y)$$.

We can find an inverse map of $T_A$ by simply inverting the matrix $A$; that is, $T_A^{-1} = T_{A^{-1}}$. In this example,

$$A^{-1} =
\begin{pmatrix}
2  & -1 \\
-5 &  3
\end{pmatrix};$$

hence, the inverse map is given by

$$T_A^{-1} (x,y) = (2x -  y, -5x + 3y)$$.

It is easy to check that

$$T^{-1}_A \circ T_A (x,y) = T_A \circ T_A^{-1} (x,y) = (x,y)$$.

Not every map has an inverse. If we consider the map

$$T_B (x,y) = (3x , 0 )$$

given by the matrix

$$B =
\begin{pmatrix}
3 & 0 \\
0 & 0
\end{pmatrix}$$,

then an inverse map would have to be of the form

$$T_B^{-1} (x,y) = (ax + by, cx +dy)$$

and

$$(x,y) = T_B \circ T_B^{-1} (x,y) = (3ax + 3by, 0)$$

for all $x$ and $y$. Clearly this is impossible because $y$ might not be $0$.

**Example.** Given the permutation

$$\pi =
\begin{pmatrix}
1 & 2 & 3 \\
2 & 3 & 1
\end{pmatrix}$$

on $S = \{ 1,2,3 \}$, it is easy to see that the permutation defined by

$$\pi^{-1} =
\begin{pmatrix}
1 & 2 & 3 \\
3 & 1 & 2
\end{pmatrix}$$

is the inverse of $\pi$. In fact, any bijective mapping possesses an inverse, as we will see in the next theorem.

## Theorem

> A mapping is invertible if and only if it is both one-to-one and onto.

Reading "bijective" as `injective and surjective`, the biconditional splits
into two implications. We prove the **forward** direction (invertible ⇒
bijective) and mark the **backward** direction, which `bpa` cannot yet encode.

**Forward — invertible ⇒ injective.** From `g∘f = id` we get `g(f(a)) = a`, so
`f(a₁) = f(a₂)` forces `a₁ = g(f(a₁)) = g(f(a₂)) = a₂`.

```bpa
// Theorem B, forward (part 1): invertible ⇒ injective.
theorem invertibleImpliesInjective: forall f: Fn; invertible(f) -> injective(f)
proof
  @generalize-f |
    fix f: Fn {
      @given-f-invertible |
        assume invertible(f) {
          @invertible-unfolds |
            forall ff: Fn;
              invertible(ff) iff
              (exists gg: Fn; compose(gg, ff) = id and compose(ff, gg) = id)
            [by cite invertibleDef]
          @f-invertible-unfolds |
            invertible(f) iff
              (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id)
            [by forall_elim(f) invertible-unfolds]
          @f-invertible-gives-inverse |
            invertible(f) ->
              (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id)
            [by iff_elim_forward f-invertible-unfolds]
          @f-is-invertible |
            invertible(f)
            [by hypothesis given-f-invertible]
          @inverse-exists |
            exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id
            [by modus_ponens f-invertible-gives-inverse f-is-invertible]
          @with-inverse-g |
            unpack g: Fn from inverse-exists {
              @g-is-two-sided-inverse |
                compose(g, f) = id and compose(f, g) = id
                [by hypothesis with-inverse-g]
              @g-cancels-f-on-left |
                compose(g, f) = id
                [by and_elim_left g-is-two-sided-inverse]
              // now show injectivity: f(a)=f(b) -> a=b
              @generalize-a |
                fix a: Element {
                  @generalize-b |
                    fix b: Element {
                      @given-fa-equals-fb |
                        assume apply(f, a) = apply(f, b) {
                          @compose-applies |
                            forall gg, ff: Fn; forall x: Element;
                              apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                            [by cite composeApply]
                          // g(f(a)) = (g∘f)(a) = id(a) = a  ; same for b
                          @composite-a-unfolds |
                            apply(compose(g, f), a) = apply(g, apply(f, a))
                            [by forall_elim(g, f, a) compose-applies]
                          @composite-b-unfolds |
                            apply(compose(g, f), b) = apply(g, apply(f, b))
                            [by forall_elim(g, f, b) compose-applies]
                          @identity-applies |
                            forall x: Element; apply(id, x) = x
                            [by cite identityApply]
                          // (g∘f)(a) = a: rewrite compose(g,f)->id in gfa's LHS,
                          // then id(a)->a.
                          @id-of-a-equals-g-of-fa |
                            apply(id, a) = apply(g, apply(f, a))
                            [by rewrite g-cancels-f-on-left composite-a-unfolds]
                          @id-fixes-a |
                            apply(id, a) = a
                            [by forall_elim(a) identity-applies]
                          @a-equals-g-of-fa |
                            a = apply(g, apply(f, a))
                            [by rewrite id-fixes-a id-of-a-equals-g-of-fa]
                          @id-of-b-equals-g-of-fb |
                            apply(id, b) = apply(g, apply(f, b))
                            [by rewrite g-cancels-f-on-left composite-b-unfolds]
                          @id-fixes-b |
                            apply(id, b) = b
                            [by forall_elim(b) identity-applies]
                          @b-equals-g-of-fb |
                            b = apply(g, apply(f, b))
                            [by rewrite id-fixes-b id-of-b-equals-g-of-fb]
                          // f(a)=f(b) => g(f(a))=g(f(b)); chain to a=b
                          @fa-equals-fb |
                            apply(f, a) = apply(f, b)
                            [by hypothesis given-fa-equals-fb]
                          @g-of-fa-reflexive |
                            apply(g, apply(f, a)) = apply(g, apply(f, a))
                            [by reflexivity]
                          @g-of-fa-equals-g-of-fb |
                            apply(g, apply(f, a)) = apply(g, apply(f, b))
                            [by rewrite fa-equals-fb g-of-fa-reflexive]
                          // a = g(f(a)) = g(f(b)) = b
                          @a-equals-g-of-fb |
                            a = apply(g, apply(f, b))
                            [by rewrite a-equals-g-of-fa g-of-fa-equals-g-of-fb]
                          @a-equals-b |
                            a = b
                            [by rewrite b-equals-g-of-fb a-equals-g-of-fb]
                        }
                      @f-injective-at-a-b |
                        apply(f, a) = apply(f, b) -> a = b
                        [by implies_intro given-fa-equals-fb]
                    }
                  @discharge-b |
                    forall b: Element; apply(f, a) = apply(f, b) -> a = b
                    [by forall_intro generalize-b]
                }
              // the pointwise body IS injective(f) (transparent define).
              @f-is-injective |
                injective(f)
                [by forall_intro generalize-a]
            }
          @f-is-injective-from-inverse |
            injective(f)
            [by exists_elim with-inverse-g]
        }
      @f-invertible-implies-injective |
        invertible(f) -> injective(f)
        [by implies_intro given-f-invertible]
    }
  @conclusion |
    forall f: Fn; invertible(f) -> injective(f)
    [by forall_intro generalize-f]
qed
```

**Forward — invertible ⇒ surjective.** From `f∘g = id` we get `f(g(b)) = b`, so
`x = g(b)` is a preimage of any `b`.

```bpa
// Theorem B, forward (part 2): invertible ⇒ surjective.
// From f∘g = id: for any y, f(g(y)) = y, so x := g(y) is a preimage.
theorem invertibleImpliesSurjective: forall f: Fn; invertible(f) -> surjective(f)
proof
  @generalize-f |
    fix f: Fn {
      @given-f-invertible |
        assume invertible(f) {
          @invertible-unfolds |
            forall ff: Fn;
              invertible(ff) iff
              (exists gg: Fn; compose(gg, ff) = id and compose(ff, gg) = id)
            [by cite invertibleDef]
          @f-invertible-unfolds |
            invertible(f) iff
              (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id)
            [by forall_elim(f) invertible-unfolds]
          @f-invertible-gives-inverse |
            invertible(f) ->
              (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id)
            [by iff_elim_forward f-invertible-unfolds]
          @f-is-invertible |
            invertible(f)
            [by hypothesis given-f-invertible]
          @inverse-exists |
            exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id
            [by modus_ponens f-invertible-gives-inverse f-is-invertible]
          @with-inverse-g |
            unpack g: Fn from inverse-exists {
              @g-is-two-sided-inverse |
                compose(g, f) = id and compose(f, g) = id
                [by hypothesis with-inverse-g]
              @f-cancels-g-on-left |
                compose(f, g) = id
                [by and_elim_right g-is-two-sided-inverse]
              @generalize-y |
                fix y: Element {
                  // witness x = g(y): f(g(y)) = (f∘g)(y) = id(y) = y
                  @compose-applies |
                    forall gg, ff: Fn; forall x: Element;
                      apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                    [by cite composeApply]
                  @composite-at-y-unfolds |
                    apply(compose(f, g), y) = apply(f, apply(g, y))
                    [by forall_elim(f, g, y) compose-applies]
                  @identity-applies |
                    forall x: Element; apply(id, x) = x
                    [by cite identityApply]
                  @id-of-y-equals-f-of-gy |
                    apply(id, y) = apply(f, apply(g, y))
                    [by rewrite f-cancels-g-on-left composite-at-y-unfolds]
                  @id-fixes-y |
                    apply(id, y) = y
                    [by forall_elim(y) identity-applies]
                  @y-equals-f-of-gy |
                    y = apply(f, apply(g, y))
                    [by rewrite id-fixes-y id-of-y-equals-f-of-gy]
                  @f-maps-gy-to-y |
                    apply(f, apply(g, y)) = y
                    [by symmetry y-equals-f-of-gy]
                  @y-has-preimage |
                    exists x: Element; apply(f, x) = y
                    [by exists_intro(apply(g, y)) f-maps-gy-to-y]
                }
              // the pointwise body IS surjective(f) (transparent define).
              @f-is-surjective |
                surjective(f)
                [by forall_intro generalize-y]
            }
          @f-is-surjective-from-inverse |
            surjective(f)
            [by exists_elim with-inverse-g]
        }
      @f-invertible-implies-surjective |
        invertible(f) -> surjective(f)
        [by implies_intro given-f-invertible]
    }
  @conclusion |
    forall f: Fn; invertible(f) -> surjective(f)
    [by forall_intro generalize-f]
qed
```

**Forward — invertible ⇒ bijective** is the conjunction of the two.

```bpa
// Theorem B, forward (combined): invertible ⇒ bijective.
theorem invertibleImpliesBijective: forall f: Fn;
  invertible(f) -> (injective(f) and surjective(f))
proof
  @generalize-f |
    fix f: Fn {
      @given-f-invertible |
        assume invertible(f) {
          @f-is-invertible |
            invertible(f)
            [by hypothesis given-f-invertible]
          @f-is-injective |
            injective(f)
            [using specialize invertibleImpliesInjective(f) f-is-invertible]
          @f-is-surjective |
            surjective(f)
            [using specialize invertibleImpliesSurjective(f) f-is-invertible]
          @f-is-bijective |
            injective(f) and surjective(f)
            [by and_intro f-is-injective f-is-surjective]
        }
      @f-invertible-implies-bijective |
        invertible(f) -> (injective(f) and surjective(f))
        [by implies_intro given-f-invertible]
    }
  @conclusion |
    forall f: Fn; invertible(f) -> (injective(f) and surjective(f))
    [by forall_intro generalize-f]
qed
```

**Backward — bijective ⇒ invertible.** The book "defines $g$ by $g(b) = a$", the
unique preimage of $b$. That is a DEFINITE DESCRIPTION: the graph
$\operatorname{spec}(b, a) := f(a) = b$ is total (surjectivity) and single-valued
(injectivity), so `functionFromGraph` realizes it as a function $g$ with
$f(g(b)) = b$ for all $b$. That gives $f \circ g = \operatorname{id}$ pointwise;
$g \circ f = \operatorname{id}$ then follows because $f$ is injective. `funcExt`
lifts both pointwise identities to `compose` equalities, discharging `invertibleDef`'s
`exists g`. (This is the ONE result in the file that rests on the `functionFromGraph`
axiom-schema — definite description, conservative, disclosed in std/function.bpa.)

```bpa
theorem bijectiveImpliesInvertible: forall f: Fn;
  (injective(f) and surjective(f)) -> invertible(f)
proof
  @generalize-f |
    fix f: Fn {
      @given-bijective |
        assume injective(f) and surjective(f) {
          @bijective-hyp |
            injective(f) and surjective(f)
            [by hypothesis given-bijective]
          @f-injective |
            injective(f)
            [by and_elim_left bijective-hyp]
          @f-surjective |
            surjective(f)
            [by and_elim_right bijective-hyp]
          // injective / surjective are transparent defines: injective(f) IS the
          // pointwise implication and surjective(f) IS the pointwise existential,
          // so f-injective / f-surjective are used directly as those bodies below.

          // the graph spec(b, a) := apply(f, a) = b is total and single-valued.
          @total-unique-proof |
            fix b: Element {
              @exists-preimage |
                exists x: Element; apply(f, x) = b
                [by forall_elim(b) f-surjective]
              @with-preimage |
                unpack a: Element from exists-preimage {
                  @f-a-is-b |
                    apply(f, a) = b
                    [by hypothesis with-preimage]
                  // uniqueness: any a2 with f(a2)=b equals a.
                  @unique |
                    fix a2: Element {
                      @given-f-a2-b |
                        assume apply(f, a2) = b {
                          @f-a2-is-b |
                            apply(f, a2) = b
                            [by hypothesis given-f-a2-b]
                          @f-a2-is-f-a |
                            apply(f, a2) = apply(f, a)
                            [by rewrite f-a-is-b f-a2-is-b]
                          @a2-is-a |
                            a2 = a
                            [using specialize f-injective(a2, a) f-a2-is-f-a]
                          @a-is-a2 |
                            a = a2
                            [by symmetry a2-is-a]
                        }
                      @a2-implies-a |
                        apply(f, a2) = b -> a = a2
                        [by implies_intro given-f-a2-b]
                    }
                  @all-a2 |
                    forall a2: Element; apply(f, a2) = b -> a = a2
                    [by forall_intro unique]
                  @preimage-and-unique |
                    apply(f, a) = b and (forall a2: Element; apply(f, a2) = b -> a = a2)
                    [by and_intro f-a-is-b all-a2]
                  @exists-unique-preimage |
                    exists x: Element; apply(f, x) = b and (forall x2: Element; apply(f, x2) = b -> x = x2)
                    [by exists_intro(a) preimage-and-unique]
                }
              @preimage-unique-b |
                exists x: Element; apply(f, x) = b and (forall x2: Element; apply(f, x2) = b -> x = x2)
                [by exists_elim with-preimage]
            }
          @total-unique |
            forall y: Element; exists x: Element;
              apply(f, x) = y and (forall x2: Element; apply(f, x2) = y -> x = x2)
            [by forall_intro total-unique-proof]

          // definite description: the total+unique graph is realized by some g.
          @description |
            (forall y: Element; exists x: Element;
              apply(f, x) = y and (forall x2: Element; apply(f, x2) = y -> x = x2))
              -> (exists g: Fn; forall y: Element; apply(f, apply(g, y)) = y)
            [using instantiation functionFromGraph((fun y, x: Element => apply(f, x) = y))]
          @realizer-exists |
            exists g: Fn; forall y: Element; apply(f, apply(g, y)) = y
            [by modus_ponens description total-unique]

          @with-realizer |
            unpack g: Fn from realizer-exists {
              @f-g-pointwise |
                forall y: Element; apply(f, apply(g, y)) = y
                [by hypothesis with-realizer]

              // f ∘ g = id, pointwise then lifted by funcExt.
              @compose-f-g-pointwise |
                fix y: Element {
                  @f-of-g-y |
                    apply(f, apply(g, y)) = y
                    [by forall_elim(y) f-g-pointwise]
                  @compose-apply |
                    forall gg, ff: Fn; forall x: Element;
                      apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                    [by cite composeApply]
                  @compose-apply-fg |
                    forall x: Element; apply(compose(f, g), x) = apply(f, apply(g, x))
                    [by forall_elim(f, g) compose-apply]
                  @compose-fg-at-y |
                    apply(compose(f, g), y) = apply(f, apply(g, y))
                    [by forall_elim(y) compose-apply-fg]
                  @compose-fg-is-y |
                    apply(compose(f, g), y) = y
                    [by rewrite f-of-g-y compose-fg-at-y]
                  @identity-apply |
                    forall x: Element; apply(id, x) = x
                    [by cite identityApply]
                  @id-at-y |
                    apply(id, y) = y
                    [by forall_elim(y) identity-apply]
                  @compose-fg-eq-id-y |
                    apply(compose(f, g), y) = apply(id, y)
                    [by rewrite id-at-y compose-fg-is-y]
                }
              @compose-fg-agree |
                forall y: Element; apply(compose(f, g), y) = apply(id, y)
                [by forall_intro compose-f-g-pointwise]
              @func-ext |
                forall ff, gg: Fn;
                  (forall x: Element; apply(ff, x) = apply(gg, x)) -> ff = gg
                [by cite funcExt]
              @funcext-at-fg |
                (forall x: Element; apply(compose(f, g), x) = apply(id, x)) -> compose(f, g) = id
                [by forall_elim(compose(f, g), id) func-ext]
              @compose-fg-is-id |
                compose(f, g) = id
                [by modus_ponens funcext-at-fg compose-fg-agree]

              // g ∘ f = id: for each a, f(g(f(a))) = f(a) (from f∘g=id at b=f(a)),
              // and f injective gives g(f(a)) = a.
              @compose-g-f-pointwise |
                fix a: Element {
                  @f-g-at-fa |
                    apply(f, apply(g, apply(f, a))) = apply(f, a)
                    [by forall_elim(apply(f, a)) f-g-pointwise]
                  @g-f-a-is-a |
                    apply(g, apply(f, a)) = a
                    [using specialize f-injective(apply(g, apply(f, a)), a) f-g-at-fa]
                  @compose-apply |
                    forall gg, ff: Fn; forall x: Element;
                      apply(compose(gg, ff), x) = apply(gg, apply(ff, x))
                    [by cite composeApply]
                  @compose-apply-gf |
                    forall x: Element; apply(compose(g, f), x) = apply(g, apply(f, x))
                    [by forall_elim(g, f) compose-apply]
                  @compose-gf-at-a |
                    apply(compose(g, f), a) = apply(g, apply(f, a))
                    [by forall_elim(a) compose-apply-gf]
                  @compose-gf-is-a |
                    apply(compose(g, f), a) = a
                    [by rewrite g-f-a-is-a compose-gf-at-a]
                  @identity-apply |
                    forall x: Element; apply(id, x) = x
                    [by cite identityApply]
                  @id-at-a |
                    apply(id, a) = a
                    [by forall_elim(a) identity-apply]
                  @compose-gf-eq-id-a |
                    apply(compose(g, f), a) = apply(id, a)
                    [by rewrite id-at-a compose-gf-is-a]
                }
              @compose-gf-agree |
                forall a: Element; apply(compose(g, f), a) = apply(id, a)
                [by forall_intro compose-g-f-pointwise]
              @funcext-at-gf |
                (forall x: Element; apply(compose(g, f), x) = apply(id, x)) -> compose(g, f) = id
                [by forall_elim(compose(g, f), id) func-ext]
              @compose-gf-is-id |
                compose(g, f) = id
                [by modus_ponens funcext-at-gf compose-gf-agree]

              // g is a two-sided inverse of f, so f is invertible.
              @g-two-sided |
                compose(g, f) = id and compose(f, g) = id
                [by and_intro compose-gf-is-id compose-fg-is-id]
              @inverse-exists |
                exists h: Fn; compose(h, f) = id and compose(f, h) = id
                [by exists_intro(g) g-two-sided]
              @invertible-def |
                forall ff: Fn;
                  invertible(ff) iff (exists gg: Fn; compose(gg, ff) = id and compose(ff, gg) = id)
                [by cite invertibleDef]
              @invertible-def-at-f |
                invertible(f) iff (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id)
                [by forall_elim(f) invertible-def]
              @invertible-backward |
                (exists gg: Fn; compose(gg, f) = id and compose(f, gg) = id) -> invertible(f)
                [by iff_elim_backward invertible-def-at-f]
              @f-invertible |
                invertible(f)
                [by modus_ponens invertible-backward inverse-exists]
            }
          @conclusion-invertible |
            invertible(f)
            [by exists_elim with-realizer]
        }
      @bijective-implies-invertible |
        (injective(f) and surjective(f)) -> invertible(f)
        [by implies_intro given-bijective]
    }
  @conclusion |
    forall f: Fn; (injective(f) and surjective(f)) -> invertible(f)
    [by forall_intro generalize-f]
qed
```

**Proof (book).** Suppose first that $f:A \rightarrow B$ is invertible with inverse $g: B \rightarrow A$. Then $g \circ f = \operatorname{id}_A$ is the identity map; that is, $g(f(a)) = a$. If $a_1, a_2 \in A$ with $f(a_1) = f(a_2)$, then $a_1 = g(f(a_1)) = g(f(a_2)) = a_2$. Consequently, $f$ is one-to-one. Now suppose that $b \in B$. To show that $f$ is onto, it is necessary to find an $a \in A$ such that $f(a) = b$, but $f(g(b)) = b$ with $g(b) \in A$. Let $a = g(b)$.

Conversely, let $f$ be bijective and let $b \in B$. Since $f$ is onto, there exists an $a \in A$ such that $f(a) = b$. Because $f$ is one-to-one, $a$ must be unique. Define $g$ by letting $g(b) = a$. We have now constructed the inverse of $f$.
