# The Multiplicative Group of Complex Numbers (Exercises)

Exercises for Judson **§4.2 "The Multiplicative Group of Complex Numbers"**
(source: `vendor/aata/src/cyclic.xml`; © 1997–2026 Judson, GFDL 1.3), following
`.claude/rules/aata-guide.md`. The **modulus identities** (Exercise 19, all six parts)
are proved; the numeric computations are **Skipped**.

The complex-arithmetic exercises (Exercises 15–18) — evaluating sums, products,
conjugates and powers of specific complex numbers, and converting between rectangular
and polar form — are **Skipped** as brute numeric evaluation: `2b4m` has no
computational evaluator, so each would be a hand-expanded arithmetic identity rather
than a proof. The roots-of-unity exercises (20, 21 — list and graph the 5th/6th roots,
identify the primitive ones) are **Skipped** for the same reason; the general theorem
they instantiate, that the $n$th roots of unity are the $\operatorname{cis}(2k\pi/n)$,
is proved in §4.2.

We import the complex modulus, aliased to the book's notation.

```2b4m
import complex <<< "std/complex.b4m"
import complex_modulus <<< "std/complex.b4m"
import real <<< "std/real.b4m"

sort C = complex.Complex
func mul = complex.mul
func conj = complex.conj
func abs = complex_modulus.abs
func normSq = complex_modulus.normSq
```

## Exercise 19 — modulus identities

**Prove each of the following.** (a) $|z| = |\overline{z}|$ — (b) $z\overline{z}
= |z|^2$ — (c) $z^{-1} = \overline{z}/|z|^2$ — (d) $|z + w| \le |z| + |w|$ — (e)
$|z - w| \ge \big||z| - |w|\big|$ — (f) $|zw| = |z|\,|w|$.

Parts (a), (b), (f) follow from $\mathbb{C}$'s projection algebra, with no
trigonometry. Part (b) is stated with $|z|^2$ as the embedded real $\mathrm{re}(z)^2 +
\mathrm{im}(z)^2$.

**(a) $|\overline{z}| = |z|$** — conjugation preserves the modulus.

> NB: This theorem exists in std in `std/complex/modulus.b4m:116:absConj`.

```2b4m
theorem modulusOfConjugate: forall z: C; abs(conj(z)) = abs(z)
proof
  @conclusion |
    forall z: C; abs(conj(z)) = abs(z)
    [using import(complex_modulus) absConj]
qed
```

**(b) $z\overline{z} = |z|^2$** — the product of $z$ with its conjugate is the
norm-square, embedded as a real.

```2b4m
theorem conjugateProductIsNormSq: forall z: C; mul(z, conj(z)) = complex.fromReal(normSq(z))
proof
  @conclusion |
    forall z: C; mul(z, conj(z)) = complex.fromReal(normSq(z))
    [using import(complex_modulus) zTimesConjIsNormSq]
qed
```

**(f) $|zw| = |z|\,|w|$** — the modulus is multiplicative.

```2b4m
theorem modulusMultiplicative: forall z, w: C; abs(mul(z, w)) = real.mul(abs(z), abs(w))
proof
  @conclusion |
    forall z, w: C; abs(mul(z, w)) = real.mul(abs(z), abs(w))
    [using import(complex_modulus) absMul]
qed
```

**(c) $z^{-1} = \overline{z}/|z|^2$** — for $z \ne 0$, the reciprocal is
$\overline{z}$ times the reciprocal of the (embedded, nonzero) real $|z|^2$. The
candidate $w = \overline{z} \cdot (|z|^2)^{-1}$ has $zw = (z\overline{z})(|z|^2)^{-1} =
1$ by (b), and inverses are unique. The hypothesis $z \ne 0$ is what makes $|z|^2$
invertible: $|z|^2 = \mathrm{re}(z)^2 + \mathrm{im}(z)^2$ is a sum of two nonnegative
reals, so it vanishes only when both parts do, that is, when $z = 0$.

```2b4m
theorem reciprocalIsConjugateOverNormSq: forall z: C; z != complex.ZERO -> complex.recip(z) = mul(conj(z), complex.recip(complex.fromReal(normSq(z))))
proof
  @conclusion |
    forall z: C; z != complex.ZERO -> complex.recip(z) = mul(conj(z), complex.recip(complex.fromReal(normSq(z))))
    [using import(complex_modulus) recipIsConjOverNormSq]
qed
```

**(d) $|z + w| \le |z| + |w|$** — the triangle inequality. Expanding in parts,
$|z + w|^2 = |z|^2 + |w|^2 + 2\,\mathrm{re}(z\overline{w})$, and Cauchy–Schwarz gives
$\mathrm{re}(z\overline{w}) \le |z|\,|w|$: its square is at most
$\mathrm{re}(z\overline{w})^2 + \mathrm{im}(z\overline{w})^2 = |z\overline{w}|^2 =
|z|^2|w|^2$, and a nonnegative number dominates whatever has the smaller square. So
$|z + w|^2 \le (|z| + |w|)^2$, and the square root is monotone on the nonnegatives.

```2b4m
theorem triangleInequality: forall z, w: C; real.less_or_equal(abs(complex.add(z, w)), real.add(abs(z), abs(w)))
proof
  @conclusion |
    forall z, w: C; real.less_or_equal(abs(complex.add(z, w)), real.add(abs(z), abs(w)))
    [using import(complex_modulus) triangleInequality]
qed
```

**(e) $|z - w| \ge \big||z| - |w|\big|$** — the reverse triangle inequality, stated as
the pair $|z| - |w| \le |z - w|$ and $|w| - |z| \le |z - w|$ (which is what
$\big||z| - |w|\big| \le |z - w|$ says). Apply (d) to $z = (z - w) + w$ and to $w = (w - z)
+ z$, using $|w - z| = |z - w|$.

```2b4m
theorem reverseTriangleInequality: forall z, w: C; real.less_or_equal(real.add(abs(z), real.neg(abs(w))), abs(complex.add(z, complex.neg(w)))) and real.less_or_equal(real.add(abs(w), real.neg(abs(z))), abs(complex.add(z, complex.neg(w))))
proof
  @conclusion |
    forall z, w: C; real.less_or_equal(real.add(abs(z), real.neg(abs(w))), abs(complex.add(z, complex.neg(w)))) and real.less_or_equal(real.add(abs(w), real.neg(abs(z))), abs(complex.add(z, complex.neg(w))))
    [using import(complex_modulus) reverseTriangleInequality]
qed
```
