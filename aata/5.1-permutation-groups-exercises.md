# Permutation Groups (Exercises)

Exercises for Judson **Chapter 5 "Permutation Groups"** that belong to §5.1 (source:
`vendor/aata/src/permute.xml`; © 1997–2026 Judson, GFDL 1.3), following
`.claude/rules/aata-guide.md`. The exercises use `std` **liberally** — the permutation
library under `std/permutation/` — and import the main text `5.1-permutation-groups.md`
for its parity vocabulary (`isTransposition`, `isEvenPerm`, `isOddPerm`) and its results.
The dihedral and solid-motion exercises (14, 15, 16, 19, 29, 37) are in
`5.2-dihedral-groups-exercises.md`.

As in §5.1, "$S_n$" is the permutations of $n$ letters: a `Perm` that bijects the
segment $\{0, \ldots, n-1\}$ onto itself and fixes the rest (`permutesTheSegment`).

// letters differ when their indices do
theorem lettersDiffer: forall a: Nat; forall b: Nat; a != b -> numeral(a) != numeral(b)
proof
  @generalize-a |
    fix a: Nat {
      @generalize-b |
        fix b: Nat {
          @given-indices-differ |
            assume a != b {
              @indices-differ |
                a != b
                [by hypothesis given-indices-differ]
              @suppose-letters-equal |
                assume numeral(a) = numeral(b) {
                  @letters-equal |
                    numeral(a) = numeral(b)
                    [by hypothesis suppose-letters-equal]
                  @indices-equal |
                    a = b
                    [using specialize numeralInjective(a, b) letters-equal]
                }
              @conclusion-letters-differ |
                numeral(a) != numeral(b)
                [by contradiction suppose-letters-equal indices-equal indices-differ]
            }
          @conclusion-at-b |
            a != b -> numeral(a) != numeral(b)
            [by discharge given-indices-differ]
        }
      @discharge-b |
        forall b: Nat; a != b -> numeral(a) != numeral(b)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: Nat; forall b: Nat; a != b -> numeral(a) != numeral(b)
    [by generalize generalize-a]
qed

theorem zeroIsNotOne: ZERO != succ(ZERO)
proof
  @suppose-equal |
    assume ZERO = succ(ZERO) {
      @equal |
        ZERO = succ(ZERO)
        [by hypothesis suppose-equal]
      @flipped |
        succ(ZERO) = ZERO
        [by symmetry equal]
    }
  @succ-zero-not-zero |
    succ(ZERO) != ZERO
    [using specialize succNotZero(ZERO)]
  @conclusion |
    ZERO != succ(ZERO)
    [by contradiction suppose-equal flipped succ-zero-not-zero]
qed

theorem twoIsNotOne: succ(succ(ZERO)) != succ(ZERO)

## Exercises

**Exercises 1–3, 5–11.** Write permutations in cycle notation; compute products;
express as products of transpositions; list the subgroups of $S_4$ and $A_4$; orders
of elements in $S_7$, $A_7$, $A_{10}$, $A_8$; elements of largest order in $S_n$;
cycle structures in $A_5$, $A_6$. **Skipped** — concrete computations in particular
small symmetric groups (finite case enumeration, not proof content), consistent with the
corpus's treatment of brute numeric exercises.

**Exercise 4.** Find $(a_1, a_2, \ldots, a_n)^{-1}$; the answer is
$(a_1, a_n, a_{n-1}, \ldots, a_2)$. **Deferred:** the cycle on a `Points` list is
`std/permutation/cycle.b4m`'s `cycle(s, n)`; the inverse cycle needs the REVERSED list
(a `pointsReverse` postulate, as `seqReverse` for sequences) and then the pointwise
comparison of $\sigma^{-1}$ with the cycle on it.

**Exercise 12.** $\sigma$ of order $n$: $\sigma^i = \sigma^j$ iff $i \equiv j \pmod n$.
**Deferred:** the order of an element and its integer powers are Chapter 4's
(`std/group/element-order` over ℤ exponents); the statement transfers to `Perm` through
the group model but the order theory's modular lemma is not yet in `std`.

**Exercise 13.** The order of a product of disjoint cycles is the lcm of their lengths.
**Deferred:** needs the least common multiple in `std/peano` and the order of a cycle
(its length, from `cycleAdvances`/`cycleWrapsAround`), then that disjoint cycles commute
(`disjointCyclesCommute`, §5.1) to spread a power over the product.

**Exercise 17.** Prove that $S_n$ is nonabelian for $n \geq 3$. Judson's hint computes
$(1\,2\,3)(1\,2)$ and $(1\,2)(1\,2\,3)$; two transpositions do the same job with less
machinery: $(0\,1)(1\,2)$ sends letter $1$ to $2$, while $(1\,2)(0\,1)$ sends it to $0$.

```2b4m
theorem symmetricGroupIsNonabelian: forall n: Nat; less_than(succ(succ(ZERO)), n) ->
  exists f: Fn; exists g: Fn; permutesTheSegment(f, n) and permutesTheSegment(g, n) and compose(f, g) != compose(g, f)
proof
  @generalize-n |
    fix n: Nat {
      @given-three-letters |
        assume less_than(succ(succ(ZERO)), n) {
          @two-in-range |
            less_than(succ(succ(ZERO)), n)
            [by hypothesis given-three-letters]
          @one-below-two |
            less_than(succ(ZERO), succ(succ(ZERO)))
            [using specialize lessThanSelf(succ(ZERO))]
          @one-in-range |
            less_than(succ(ZERO), n)
            [using specialize lessThanTransitive(succ(ZERO), succ(succ(ZERO)), n) one-below-two two-in-range]
          @zero-below-one |
            less_than(ZERO, succ(ZERO))
            [using specialize zeroBelowSucc(ZERO)]
          @zero-in-range |
            less_than(ZERO, n)
            [using specialize lessThanTransitive(ZERO, succ(ZERO), n) zero-below-one one-in-range]
          @first-swap-permutes |
            permutesTheSegment(transposition(numeral(ZERO), numeral(succ(ZERO))), n)
            [using specialize swappingTwoLetters(n, ZERO, succ(ZERO)) zero-in-range one-in-range]
          @second-swap-permutes |
            permutesTheSegment(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), n)
            [using specialize swappingTwoLetters(n, succ(ZERO), succ(succ(ZERO))) one-in-range two-in-range]

          // (0 1)(1 2) sends letter 1 to letter 2
          @zero-not-one |
            ZERO != succ(ZERO)
            [by cite zeroIsNotOne]
          @zero-not-two |
            ZERO != succ(succ(ZERO))
            [by cite zeroIsNotTwo]
          @two-not-zero |
            succ(succ(ZERO)) != ZERO
            [by cite twoIsNotZero]
          @two-not-one |
            succ(succ(ZERO)) != succ(ZERO)
            [by cite twoIsNotOne]
          @letter-two-not-zero |
            numeral(succ(succ(ZERO))) != numeral(ZERO)
            [using specialize lettersDiffer(succ(succ(ZERO)), ZERO) two-not-zero]
          @letter-two-not-one |
            numeral(succ(succ(ZERO))) != numeral(succ(ZERO))
            [using specialize lettersDiffer(succ(succ(ZERO)), succ(ZERO)) two-not-one]
          @letter-zero-not-one |
            numeral(ZERO) != numeral(succ(ZERO))
            [using specialize lettersDiffer(ZERO, succ(ZERO)) zero-not-one]
          @letter-zero-not-two |
            numeral(ZERO) != numeral(succ(succ(ZERO)))
            [using specialize lettersDiffer(ZERO, succ(succ(ZERO))) zero-not-two]
          @second-swap-at-one |
            apply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), numeral(succ(ZERO))) = numeral(succ(succ(ZERO)))
            [using specialize transpositionAtFirst(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))]
          @first-swap-at-two |
            apply(transposition(numeral(ZERO), numeral(succ(ZERO))), numeral(succ(succ(ZERO)))) = numeral(succ(succ(ZERO)))
            [using specialize transpositionElsewhere(numeral(ZERO), numeral(succ(ZERO)), numeral(succ(succ(ZERO)))) letter-two-not-zero letter-two-not-one]
          @first-then-second-unfolds |
            apply(compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))), numeral(succ(ZERO))) = apply(transposition(numeral(ZERO), numeral(succ(ZERO))), apply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), numeral(succ(ZERO))))
            [using specialize composeApply(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), numeral(succ(ZERO)))]
          @first-then-second-after-inner |
            apply(compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))), numeral(succ(ZERO))) = apply(transposition(numeral(ZERO), numeral(succ(ZERO))), numeral(succ(succ(ZERO))))
            [by rewrite second-swap-at-one first-then-second-unfolds]
          @first-then-second-at-one |
            apply(compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))), numeral(succ(ZERO))) = numeral(succ(succ(ZERO)))
            [using chain first-then-second-after-inner first-swap-at-two]

          // (1 2)(0 1) sends letter 1 to letter 0
          @first-swap-at-one |
            apply(transposition(numeral(ZERO), numeral(succ(ZERO))), numeral(succ(ZERO))) = numeral(ZERO)
            [using specialize transpositionAtSecond(numeral(ZERO), numeral(succ(ZERO)))]
          @second-swap-at-zero |
            apply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), numeral(ZERO)) = numeral(ZERO)
            [using specialize transpositionElsewhere(numeral(succ(ZERO)), numeral(succ(succ(ZERO))), numeral(ZERO)) letter-zero-not-one letter-zero-not-two]
          @second-then-first-unfolds |
            apply(compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO)))), numeral(succ(ZERO))) = apply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), apply(transposition(numeral(ZERO), numeral(succ(ZERO))), numeral(succ(ZERO))))
            [using specialize composeApply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO))), numeral(succ(ZERO)))]
          @second-then-first-after-inner |
            apply(compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO)))), numeral(succ(ZERO))) = apply(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), numeral(ZERO))
            [by rewrite first-swap-at-one second-then-first-unfolds]
          @second-then-first-at-one |
            apply(compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO)))), numeral(succ(ZERO))) = numeral(ZERO)
            [using chain second-then-first-after-inner second-swap-at-zero]

          // so the two products differ
          @suppose-commute |
            assume compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))) = compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO)))) {
              @commute |
                compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))) = compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO))))
                [by hypothesis suppose-commute]
              @second-then-first-at-one-is-two |
                apply(compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO)))), numeral(succ(ZERO))) = numeral(succ(succ(ZERO)))
                [by rewrite commute first-then-second-at-one]
              @letters-zero-and-two-agree |
                numeral(ZERO) = numeral(succ(succ(ZERO)))
                [by rewrite second-then-first-at-one second-then-first-at-one-is-two]
            }
          @products-differ |
            compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))) != compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO))))
            [by contradiction suppose-commute letters-zero-and-two-agree letter-zero-not-two]
          @witnesses |
            permutesTheSegment(transposition(numeral(ZERO), numeral(succ(ZERO))), n) and permutesTheSegment(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), n) and compose(transposition(numeral(ZERO), numeral(succ(ZERO))), transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))) != compose(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO)))), transposition(numeral(ZERO), numeral(succ(ZERO))))
            [using tautology first-swap-permutes second-swap-permutes products-differ]
          @with-g |
            exists g: Fn; permutesTheSegment(transposition(numeral(ZERO), numeral(succ(ZERO))), n) and permutesTheSegment(g, n) and compose(transposition(numeral(ZERO), numeral(succ(ZERO))), g) != compose(g, transposition(numeral(ZERO), numeral(succ(ZERO))))
            [by witness(transposition(numeral(succ(ZERO)), numeral(succ(succ(ZERO))))) witnesses]
          @conclusion-nonabelian |
            exists f: Fn; exists g: Fn; permutesTheSegment(f, n) and permutesTheSegment(g, n) and compose(f, g) != compose(g, f)
            [by witness(transposition(numeral(ZERO), numeral(succ(ZERO)))) with-g]
        }
      @conclusion-at-n |
        less_than(succ(succ(ZERO)), n) -> exists f: Fn; exists g: Fn; permutesTheSegment(f, n) and permutesTheSegment(g, n) and compose(f, g) != compose(g, f)
        [by discharge given-three-letters]
    }
  @conclusion |
    forall n: Nat; less_than(succ(succ(ZERO)), n) ->
      exists f: Fn; exists g: Fn; permutesTheSegment(f, n) and permutesTheSegment(g, n) and compose(f, g) != compose(g, f)
    [by generalize generalize-n]
qed
```

**Exercise 24.** Show that a $3$-cycle is an even permutation. By Exercise 20 a
$3$-cycle $(a_0\,a_1\,a_2)$ is $(a_0\,a_2)(a_0\,a_1)$, a product of two transpositions.

```2b4m
theorem twoIsSuccSuccZero: TWO = succ(succ(ZERO))
proof
  @one-is-succ-zero |
    peano.ONE = succ(ZERO)
    [by cite oneIsSuccZero]
  @two-unfolds |
    peano.add(succ(ZERO), succ(ZERO)) = succ(peano.add(ZERO, succ(ZERO)))
    [using specialize addSuccLeft(ZERO, succ(ZERO))]
  @zero-plus-one |
    peano.add(ZERO, succ(ZERO)) = succ(ZERO)
    [using specialize addZeroLeft(succ(ZERO))]
  @two-in-successors |
    peano.add(succ(ZERO), succ(ZERO)) = succ(succ(ZERO))
    [by rewrite zero-plus-one two-unfolds]
  @conclusion |
    TWO = succ(succ(ZERO))
    [by rewrite one-is-succ-zero two-in-successors]
qed

theorem threeCycleIsEven: forall s: Points; distinct(s, succ(succ(succ(ZERO)))) ->
  isEvenPerm(cycle(s, succ(succ(succ(ZERO)))))
proof
  @generalize-s |
    fix s: Points {
      @given-distinct |
        assume distinct(s, succ(succ(succ(ZERO)))) {
          @list-distinct |
            distinct(s, succ(succ(succ(ZERO))))
            [by hypothesis given-distinct]
          @product-exists |
            exists w: Seq; allTranspositions(w, succ(succ(ZERO))) and productUpTo(w, succ(succ(ZERO))) = cycle(s, succ(succ(succ(ZERO))))
            [using specialize cycleIsAProductOfTranspositions(s, succ(succ(ZERO))) list-distinct]
          @two-is-two |
            TWO = succ(succ(ZERO))
            [by cite twoIsSuccSuccZero]
          @two-divides-two |
            divides(TWO, TWO)
            [using specialize dividesRefl(TWO)]
          @two-divides-the-length |
            divides(TWO, succ(succ(ZERO)))
            [by rewrite two-is-two two-divides-two]
          @with-sequence-w |
            unpack w: Seq from product-exists {
              @product-facts |
                allTranspositions(w, succ(succ(ZERO))) and productUpTo(w, succ(succ(ZERO))) = cycle(s, succ(succ(succ(ZERO))))
                [by hypothesis with-sequence-w]
              @even-witness-facts |
                allTranspositions(w, succ(succ(ZERO))) and productUpTo(w, succ(succ(ZERO))) = cycle(s, succ(succ(succ(ZERO)))) and divides(TWO, succ(succ(ZERO)))
                [using tautology product-facts two-divides-the-length]
              @even-with-length |
                exists m: Nat; allTranspositions(w, m) and productUpTo(w, m) = cycle(s, succ(succ(succ(ZERO)))) and divides(TWO, m)
                [by witness(succ(succ(ZERO))) even-witness-facts]
              @conclusion-even |
                isEvenPerm(cycle(s, succ(succ(succ(ZERO)))))
                [by witness(w) even-with-length]
            }
          @conclusion-three-cycle-even |
            isEvenPerm(cycle(s, succ(succ(succ(ZERO)))))
            [by unpacked with-sequence-w]
        }
      @conclusion-at-s |
        distinct(s, succ(succ(succ(ZERO)))) -> isEvenPerm(cycle(s, succ(succ(succ(ZERO)))))
        [by discharge given-distinct]
    }
  @conclusion |
    forall s: Points; distinct(s, succ(succ(succ(ZERO)))) -> isEvenPerm(cycle(s, succ(succ(succ(ZERO)))))
    [by generalize generalize-s]
qed
```

**Exercise 27.** $\lambda_g(a) = ga$ is a permutation of $G$: one-to-one by left
cancellation, and onto since $b = g(g^{-1}b)$.

```2b4m
sort G = group.Grp
const e = group.E
func op = group.op
func inv = group.inverse
axiom opAssoc = group.opAssoc
axiom opIdentityLeft = group.opIdentityLeft
theorem opInverseRight = group.opInverseRight
theorem cancelLeft = group.cancelLeft

theorem leftTranslationIsAPermutation: forall g: G;
  (forall a: G; forall b: G; op(g, a) = op(g, b) -> a = b) and (forall b: G; exists a: G; op(g, a) = b)
proof
  @generalize-g |
    fix g: G {
      @generalize-a |
        fix a: G {
          @generalize-b |
            fix b: G {
              @conclusion-one-to-one-at-a-b |
                op(g, a) = op(g, b) -> a = b
                [using specialize cancelLeft(g, a, b)]
            }
          @discharge-b |
            forall b: G; op(g, a) = op(g, b) -> a = b
            [by generalize generalize-b]
        }
      @one-to-one |
        forall a: G; forall b: G; op(g, a) = op(g, b) -> a = b
        [by generalize generalize-a]
      @generalize-b-for-onto |
        fix b: G {
          @reassociated |
            op(op(g, inv(g)), b) = op(g, op(inv(g), b))
            [using specialize opAssoc(g, inv(g), b)]
          @g-times-its-inverse |
            op(g, inv(g)) = e
            [using specialize opInverseRight(g)]
          @identity-times-b |
            op(e, b) = op(g, op(inv(g), b))
            [by rewrite g-times-its-inverse reassociated]
          @identity-acts |
            op(e, b) = b
            [using specialize opIdentityLeft(b)]
          @preimage-hits-b |
            op(g, op(inv(g), b)) = b
            [by rewrite identity-times-b identity-acts]
          @conclusion-onto-at-b |
            exists a: G; op(g, a) = b
            [by witness(op(inv(g), b)) preimage-hits-b]
        }
      @onto |
        forall b: G; exists a: G; op(g, a) = b
        [by generalize generalize-b-for-onto]
      @conclusion-permutation |
        (forall a: G; forall b: G; op(g, a) = op(g, b) -> a = b) and (forall b: G; exists a: G; op(g, a) = b)
        [by both one-to-one onto]
    }
  @conclusion |
    forall g: G; (forall a: G; forall b: G; op(g, a) = op(g, b) -> a = b) and (forall b: G; exists a: G; op(g, a) = b)
    [by generalize generalize-g]
qed
```

**Exercise 31.** $\alpha \sim \beta$ when $\sigma\alpha\sigma^{-1} = \beta$ for some
$\sigma$ is an equivalence relation on $S_n$: reflexive with $\sigma$ the identity,
symmetric with $\sigma^{-1}$, transitive with the product of the two conjugators.

```2b4m
define conjugate(a, b) = exists s: Fn; invertible(s) and compose(compose(s, a), inverse(s)) = b

theorem conjugacyIsReflexive: forall a: Fn; conjugate(a, a)
proof
  @generalize-a |
    fix a: Fn {
      @identity-invertible |
        invertible(identityFn)
        [by cite identityIsAPermutation]
      @identity-on-the-left |
        compose(identityFn, a) = a
        [using specialize composeIdentityLeft(a)]
      @inverse-of-identity |
        inverse(identityFn) = identityFn
        [by cite inverseOfIdentity]
      @identity-on-the-right |
        compose(a, identityFn) = a
        [using specialize composeIdentityRight(a)]
      @conjugated-by-identity |
        compose(compose(identityFn, a), inverse(identityFn)) = a
        [using simplify identity-on-the-left inverse-of-identity identity-on-the-right]
      @witness-facts |
        invertible(identityFn) and compose(compose(identityFn, a), inverse(identityFn)) = a
        [by both identity-invertible conjugated-by-identity]
      @conclusion-reflexive |
        conjugate(a, a)
        [by witness(identityFn) witness-facts]
    }
  @conclusion |
    forall a: Fn; conjugate(a, a)
    [by generalize generalize-a]
qed

theorem conjugacyIsSymmetric: forall a: Fn; forall b: Fn; conjugate(a, b) -> conjugate(b, a)
proof
  @generalize-a |
    fix a: Fn {
      @generalize-b |
        fix b: Fn {
          @given-conjugate |
            assume conjugate(a, b) {
              @conjugate-a-b |
                conjugate(a, b)
                [by hypothesis given-conjugate]
              @with-conjugator-s |
                unpack s: Fn from conjugate-a-b {
                  @conjugator-facts |
                    invertible(s) and compose(compose(s, a), inverse(s)) = b
                    [by hypothesis with-conjugator-s]
                  @s-invertible |
                    invertible(s)
                    [by and_lhs conjugator-facts]
                  @b-is-conjugated-a |
                    compose(compose(s, a), inverse(s)) = b
                    [by and_rhs conjugator-facts]
                  @inverse-invertible |
                    invertible(inverse(s))
                    [using specialize inverseIsAPermutation(s) s-invertible]
                  @inverse-of-inverse |
                    inverse(inverse(s)) = s
                    [using specialize inverseInvolution(s)]
                  @inverse-undoes-s |
                    compose(inverse(s), s) = identityFn
                    [using specialize inverseLeft(s) s-invertible]
                  // s⁻¹ (s a s⁻¹) s = a
                  @first-reassociation |
                    compose(compose(inverse(s), compose(s, a)), inverse(s)) = compose(inverse(s), compose(compose(s, a), inverse(s)))
                    [using specialize composeAssoc(inverse(s), compose(s, a), inverse(s))]
                  @second-reassociation |
                    compose(compose(inverse(s), s), a) = compose(inverse(s), compose(s, a))
                    [using specialize composeAssoc(inverse(s), s, a)]
                  @inner-cancels |
                    compose(identityFn, a) = compose(inverse(s), compose(s, a))
                    [by rewrite inverse-undoes-s second-reassociation]
                  @identity-on-the-left |
                    compose(identityFn, a) = a
                    [using specialize composeIdentityLeft(a)]
                  @inner-is-a |
                    compose(inverse(s), compose(s, a)) = a
                    [by rewrite inner-cancels identity-on-the-left]
                  @left-conjugation-collapses |
                    compose(a, inverse(s)) = compose(inverse(s), compose(compose(s, a), inverse(s)))
                    [by rewrite inner-is-a first-reassociation]
                  @left-conjugation-is-b |
                    compose(a, inverse(s)) = compose(inverse(s), b)
                    [by rewrite b-is-conjugated-a left-conjugation-collapses]
                  @third-reassociation |
                    compose(compose(a, inverse(s)), s) = compose(a, compose(inverse(s), s))
                    [using specialize composeAssoc(a, inverse(s), s)]
                  @right-cancels |
                    compose(compose(a, inverse(s)), s) = compose(a, identityFn)
                    [by rewrite inverse-undoes-s third-reassociation]
                  @identity-on-the-right |
                    compose(a, identityFn) = a
                    [using specialize composeIdentityRight(a)]
                  @conjugating-back-a |
                    compose(compose(a, inverse(s)), s) = a
                    [using chain right-cancels identity-on-the-right]
                  @conjugating-back-b |
                    compose(compose(inverse(s), b), s) = a
                    [by rewrite left-conjugation-is-b conjugating-back-a]
                  @conjugating-back |
                    compose(compose(inverse(s), b), inverse(inverse(s))) = a
                    [by rewrite inverse-of-inverse conjugating-back-b]
                  @witness-facts |
                    invertible(inverse(s)) and compose(compose(inverse(s), b), inverse(inverse(s))) = a
                    [by both inverse-invertible conjugating-back]
                  @conclusion-witness-inverse |
                    conjugate(b, a)
                    [by witness(inverse(s)) witness-facts]
                }
              @conclusion-symmetric |
                conjugate(b, a)
                [by unpacked with-conjugator-s]
            }
          @conclusion-at-b |
            conjugate(a, b) -> conjugate(b, a)
            [by discharge given-conjugate]
        }
      @discharge-b |
        forall b: Fn; conjugate(a, b) -> conjugate(b, a)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: Fn; forall b: Fn; conjugate(a, b) -> conjugate(b, a)
    [by generalize generalize-a]
qed

theorem conjugacyIsTransitive: forall a: Fn; forall b: Fn; forall c: Fn; conjugate(a, b) -> conjugate(b, c) -> conjugate(a, c)
proof
  @generalize-a |
    fix a: Fn {
      @generalize-b |
        fix b: Fn {
          @generalize-c |
            fix c: Fn {
              @given-first |
                assume conjugate(a, b) {
                  @given-second |
                    assume conjugate(b, c) {
                      @conjugate-a-b |
                        conjugate(a, b)
                        [by hypothesis given-first]
                      @conjugate-b-c |
                        conjugate(b, c)
                        [by hypothesis given-second]
                      @with-conjugator-s |
                        unpack s: Fn from conjugate-a-b {
                          @first-facts |
                            invertible(s) and compose(compose(s, a), inverse(s)) = b
                            [by hypothesis with-conjugator-s]
                          @s-invertible |
                            invertible(s)
                            [by and_lhs first-facts]
                          @b-is-conjugated-a |
                            compose(compose(s, a), inverse(s)) = b
                            [by and_rhs first-facts]
                          @with-conjugator-t |
                            unpack t: Fn from conjugate-b-c {
                              @second-facts |
                                invertible(t) and compose(compose(t, b), inverse(t)) = c
                                [by hypothesis with-conjugator-t]
                              @t-invertible |
                                invertible(t)
                                [by and_lhs second-facts]
                              @c-is-conjugated-b |
                                compose(compose(t, b), inverse(t)) = c
                                [by and_rhs second-facts]
                              @product-invertible |
                                invertible(compose(t, s))
                                [using specialize composeIsAPermutation(t, s) t-invertible s-invertible]
                              @inverse-of-the-product |
                                inverse(compose(t, s)) = compose(inverse(s), inverse(t))
                                [using specialize inverseOfComposite(t, s) t-invertible s-invertible]
                              // (t s) a (s⁻¹ t⁻¹) = t (s a s⁻¹) t⁻¹ = t b t⁻¹ = c
                              @first-reassociation |
                                compose(compose(compose(t, s), a), compose(inverse(s), inverse(t))) = compose(compose(t, s), compose(a, compose(inverse(s), inverse(t))))
                                [using specialize composeAssoc(compose(t, s), a, compose(inverse(s), inverse(t)))]
                              @second-reassociation |
                                compose(compose(t, s), compose(a, compose(inverse(s), inverse(t)))) = compose(t, compose(s, compose(a, compose(inverse(s), inverse(t)))))
                                [using specialize composeAssoc(t, s, compose(a, compose(inverse(s), inverse(t))))]
                              @third-reassociation |
                                compose(compose(a, inverse(s)), inverse(t)) = compose(a, compose(inverse(s), inverse(t)))
                                [using specialize composeAssoc(a, inverse(s), inverse(t))]
                              @fourth-reassociation |
                                compose(compose(s, compose(a, inverse(s))), inverse(t)) = compose(s, compose(compose(a, inverse(s)), inverse(t)))
                                [using specialize composeAssoc(s, compose(a, inverse(s)), inverse(t))]
                              @fifth-reassociation |
                                compose(compose(s, a), inverse(s)) = compose(s, compose(a, inverse(s)))
                                [using specialize composeAssoc(s, a, inverse(s))]
                              @inner-in-s-terms |
                                compose(compose(s, compose(a, inverse(s))), inverse(t)) = compose(s, compose(a, compose(inverse(s), inverse(t))))
                                [by rewrite third-reassociation fourth-reassociation]
                              @inner-is-conjugated-a-then-t |
                                compose(compose(compose(s, a), inverse(s)), inverse(t)) = compose(s, compose(a, compose(inverse(s), inverse(t))))
                                [by rewrite fifth-reassociation inner-in-s-terms]
                              @inner-is-b-then-t |
                                compose(b, inverse(t)) = compose(s, compose(a, compose(inverse(s), inverse(t))))
                                [by rewrite b-is-conjugated-a inner-is-conjugated-a-then-t]
                              @whole-in-t-terms |
                                compose(compose(compose(t, s), a), compose(inverse(s), inverse(t))) = compose(t, compose(s, compose(a, compose(inverse(s), inverse(t)))))
                                [using chain first-reassociation second-reassociation]
                              @whole-is-t-b-inverse-t |
                                compose(compose(compose(t, s), a), compose(inverse(s), inverse(t))) = compose(t, compose(b, inverse(t)))
                                [by rewrite inner-is-b-then-t whole-in-t-terms]
                              @sixth-reassociation |
                                compose(compose(t, b), inverse(t)) = compose(t, compose(b, inverse(t)))
                                [using specialize composeAssoc(t, b, inverse(t))]
                              @whole-is-conjugated-b |
                                compose(compose(compose(t, s), a), compose(inverse(s), inverse(t))) = compose(compose(t, b), inverse(t))
                                [by rewrite sixth-reassociation whole-is-t-b-inverse-t]
                              @whole-is-c |
                                compose(compose(compose(t, s), a), compose(inverse(s), inverse(t))) = c
                                [using chain whole-is-conjugated-b c-is-conjugated-b]
                              @whole-with-the-product-inverse |
                                compose(compose(compose(t, s), a), inverse(compose(t, s))) = c
                                [by rewrite inverse-of-the-product whole-is-c]
                              @witness-facts |
                                invertible(compose(t, s)) and compose(compose(compose(t, s), a), inverse(compose(t, s))) = c
                                [by both product-invertible whole-with-the-product-inverse]
                              @conclusion-witness-product |
                                conjugate(a, c)
                                [by witness(compose(t, s)) witness-facts]
                            }
                          @conclusion-with-t |
                            conjugate(a, c)
                            [by unpacked with-conjugator-t]
                        }
                      @conclusion-transitive |
                        conjugate(a, c)
                        [by unpacked with-conjugator-s]
                    }
                  @conclusion-given-second |
                    conjugate(b, c) -> conjugate(a, c)
                    [by discharge given-second]
                }
              @conclusion-at-c |
                conjugate(a, b) -> conjugate(b, c) -> conjugate(a, c)
                [by discharge given-first]
            }
          @discharge-c |
            forall c: Fn; conjugate(a, b) -> conjugate(b, c) -> conjugate(a, c)
            [by generalize generalize-c]
        }
      @discharge-b |
        forall b: Fn; forall c: Fn; conjugate(a, b) -> conjugate(b, c) -> conjugate(a, c)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: Fn; forall b: Fn; forall c: Fn; conjugate(a, b) -> conjugate(b, c) -> conjugate(a, c)
    [by generalize generalize-a]
qed
```
