# Cyclic Subgroups (Exercises)

Exercises for Judson **§4.1 "Cyclic Subgroups"** (source:
`vendor/aata/src/cyclic.xml`; © 1997–2026 Judson, GFDL 1.3), following
`.claude/rules/aata-guide.md`. The exercises use `std` **liberally** — including
`std/cyclic.b4m`, `std/group/order.b4m`, and the concrete `std/integer/mod-n.b4m`
(ℤ_n / U(n)). Results the main text proves are **forwarded** (a prose pointer, no
re-proof); brute numeric computations are **skipped**; and results needing
machinery `2b4m` does not yet have (an order-of-element *function* over an arbitrary
group, direct products) are **Deferred** with the construction named in place.

Comparing orders of different elements ($|a| = |a^{-1}|$, $|ab| = |ba|$) needs the
order stated as a first-class object over arbitrary elements. Rather than an order
*function* `ord : G → ℕ` (which would need a choice/definite-description operator
`2b4m` lacks, to extract the least period), `std/group/order.b4m` provides the order
as a single-valued **relation** `hasOrder(g, n)` — "$n$ is the order of $g$" — with
`orderIsUnique` (an element has at most one order). This lets orders be stated and
compared with no new primitive, and is what Exercises 23, 27, 30 and 31 below are
proved from. The cyclic subgroup $\langle g \rangle$ of a *variable* $g$ is likewise a
two-place relation `inGenerated(g, x)` ("$x$ is an integer power of $g$", from
`std/group/generated.b4m`), which is what lets Exercises 27, 30 and 37 quantify over
generators. Exercises still needing more (direct products, the order-of-product law)
remain Deferred with the missing piece named.

We import the group + order machinery, aliased to the book's notation.

```2b4m
import group_power <<< "std/group/power.b4m"
import group_order <<< "std/group.b4m"
import int_divides <<< "std/integer/divides.b4m"

sort G = group_power.Grp
const e = group_power.E
func op = group_power.op
func inv = group_power.inverse
func power = group_power.power
sort Int = group_power.Int
const ZERO = group_power.ZERO
const ONE = int_divides.ONE
func succ = group_power.succ
func gcd = int_divides.gcd
func mul = int_divides.mul
pred less_than = int_divides.less_than
pred hasOrder = group_order.hasOrder
define inGenerated(g, x) = group_order.inGenerated(g, x)
```

**10. Elements of finite order in $\mathbb{Z}$, $\mathbb{Q}^*$, $\mathbb{R}^*$.**
**$\mathbb{Z}$ proved; $\mathbb{Q}^*$, $\mathbb{R}^*$ deferred.** In $(\mathbb{Z}, +)$
the $n$-th power of $k$ is the $n$-fold sum $nk$, so $k$ has finite order exactly when
some positive $n$ has $nk = 0$ — which forces $k = 0$ (a positive factor cannot kill a
nonzero integer), and $0$ itself is killed by $n = 1$. So the only element of finite
order is $0$. The multiplicative groups $\mathbb{Q}^*$, $\mathbb{R}^*$ (answer: $\pm
1$) need real powers and an order argument ($|x| > 1 \Rightarrow |x|^n > 1$) that
`std/real.b4m` does not yet carry.

```2b4m
theorem finiteOrderInIntegersIsZero: forall k: Int; (exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO) iff k = ZERO
proof
  @generalize-k |
    fix k: Int {
      @given-killed |
        assume exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO {
          @killer-exists |
            exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO
            [by hypothesis given-killed]
          @with-killer-n |
            unpack n: Int from killer-exists {
              @killer-facts |
                less_than(ZERO, n) and mul(n, k) = ZERO
                [by hypothesis with-killer-n]
              @n-positive |
                less_than(ZERO, n)
                [by and_elim_left killer-facts]
              @n-kills-k |
                mul(n, k) = ZERO
                [by and_elim_right killer-facts]
              @conclusion-k-zero |
                k = ZERO
                [using specialize int_divides.positiveFactorZeroForcesZero(n, k) n-positive n-kills-k]
            }
          @k-zero |
            k = ZERO
            [by exists_elim with-killer-n]
        }
      @given-zero |
        assume k = ZERO {
          @k-is-zero |
            k = ZERO
            [by hypothesis given-zero]
          @one-positive |
            less_than(ZERO, ONE)
            [using import(int_divides) zeroLessThanOne]
          @one-times-zero |
            mul(ONE, ZERO) = ZERO
            [using specialize int_divides.mulZeroRight(ONE)]
          @one-times-k |
            mul(ONE, k) = ZERO
            [by rewrite k-is-zero one-times-zero]
          @one-kills-k |
            less_than(ZERO, ONE) and mul(ONE, k) = ZERO
            [by and_intro one-positive one-times-k]
          @conclusion-killed |
            exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO
            [by exists_intro(ONE) one-kills-k]
        }
      @forward |
        (exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO) -> k = ZERO
        [by implies_intro given-killed]
      @backward |
        k = ZERO -> exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO
        [by implies_intro given-zero]
      @conclusion-iff |
        (exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO) iff k = ZERO
        [by iff_intro forward backward]
    }
  @conclusion |
    forall k: Int; (exists n: Int; less_than(ZERO, n) and mul(n, k) = ZERO) iff k = ZERO
    [by forall_intro generalize-k]
qed
```

**23. Order relations.** (a) $|a| = |a^{-1}|$ — (b) $|a| = |g^{-1}ag|$ — (c) $|ab|
= |ba|$.

**(a) is proved.** Using the `hasOrder` relation: if $n$ is the order of $a$, then
$n$ is the order of $a^{-1}$. The proof (in `std/group/order.b4m` as
`inverseHasSameOrder`) observes $(a^{-1})^k = (a^k)^{-1}$, so $(a^{-1})^k = e
\iff a^k = e$ — hence $a^{-1}$ is killed by exactly the same exponents as $a$, so
they share both the killing period and its minimality.

```2b4m
theorem inverseHasSameOrder: forall a: G; forall n: Int; hasOrder(a, n) -> hasOrder(inv(a), n)
proof
  @conclusion |
    forall a: G; forall n: Int; hasOrder(a, n) -> hasOrder(inv(a), n)
    [using import(group_order) inverseHasSameOrder]
qed
```

**(b) is proved.** $|a| = |g^{-1}ag|$: conjugation is a power-preserving map,
$(g^{-1}ag)^k = g^{-1}a^k g$ (`conjugatePower` in `std/group/order.b4m`, by induction
on the integer exponent both ways, cancelling $g g^{-1}$ in the middle), so $(g^{-1}ag)^k
= e \iff a^k = e$ — the conjugate is killed by exactly the exponents that kill $a$,
hence has the same order.

```2b4m
theorem conjugateHasSameOrder: forall g, a: G; forall n: Int; hasOrder(a, n) -> hasOrder(op(op(inv(g), a), g), n)
proof
  @conclusion |
    forall g, a: G; forall n: Int; hasOrder(a, n) -> hasOrder(op(op(inv(g), a), g), n)
    [using import(group_order) conjugateHasSameOrder]
qed
```

**(c) is proved.** $|ab| = |ba|$, since $ba = a^{-1}(ab)a$ is a conjugate of $ab$
and (b) applies.

```2b4m
theorem productsHaveSameOrder: forall a, b: G; forall n: Int; hasOrder(op(a, b), n) -> hasOrder(op(b, a), n)
proof
  @conclusion |
    forall a, b: G; forall n: Int; hasOrder(op(a, b), n) -> hasOrder(op(b, a), n)
    [using import(group_order) productsHaveSameOrder]
qed
```

**26. $\mathbb{Z}_p$ has no nontrivial subgroups for $p$ prime.** **Proved** — without
Lagrange. Let $H$ be a subgroup of $\mathbb{Z}_n$ (a predicate containing $0$ and closed
under $+$ and $-$; it is then closed under all integer multiples $k \cdot x$). If $H$
contains some $[a] \ne 0$ then $n \nmid a$, so for *prime* $n$ the only common divisors
of $a$ and $n$ are $\pm 1$, and Bézout gives $ra + sn = 1$; hence $[1] = r[a] + [sn] =
r[a] \in H$, and $[1]$ generates $\mathbb{Z}_n$. So $H = \{0\}$ or $H = \mathbb{Z}_n$
(`primeModulusHasNoProperSubgroups` in `std/integer/mod-n-prime.b4m`, a schema over the
subgroup predicate). The modulus is `std/integer/mod-n.b4m`'s constant $N$; primality is
the hypothesis.

```2b4m
import mod_n_prime <<< "std/integer/mod-n-prime.b4m"

sort Zn = mod_n_prime.Zn
const N = mod_n_prime.N
const ZN_ZERO = mod_n_prime.ZERO
func zadd = mod_n_prime.add
func zneg = mod_n_prime.neg
define is_prime(p) = mod_n_prime.is_prime(p)
theorem primeModulusHasNoProperSubgroups = mod_n_prime.primeModulusHasNoProperSubgroups

// an arbitrary subgroup H of ℤ_N: contains 0, closed under + and −.
pred inH(x: Zn)
axiom subgroupOfZnHasZero: inH(ZN_ZERO)
axiom subgroupOfZnClosedAdd: forall x, y: Zn; inH(x) -> inH(y) -> inH(zadd(x, y))
axiom subgroupOfZnClosedNeg: forall x: Zn; inH(x) -> inH(zneg(x))

theorem primeModulusHasNoNontrivialSubgroups: is_prime(N) -> ((forall x: Zn; inH(x) -> x = ZN_ZERO) or (forall x: Zn; inH(x)))
proof
  @zero-in-h |
    inH(ZN_ZERO)
    [by cite subgroupOfZnHasZero]
  @h-closed-add |
    forall x, y: Zn; inH(x) -> inH(y) -> inH(zadd(x, y))
    [by cite subgroupOfZnClosedAdd]
  @h-closed-neg |
    forall x: Zn; inH(x) -> inH(zneg(x))
    [by cite subgroupOfZnClosedNeg]
  @conclusion |
    is_prime(N) -> ((forall x: Zn; inH(x) -> x = ZN_ZERO) or (forall x: Zn; inH(x)))
    [using instantiation primeModulusHasNoProperSubgroups(inH) zero-in-h h-closed-add h-closed-neg]
qed
```

**27. $|\langle g \rangle \cap \langle h \rangle|$ for $|g| = 15$, $|h| = 16$.**
**Proved** — the intersection is $\{e\}$, so it has one element. Rather than
computing $\gcd(15, 16) = 1$ and appealing to Exercise 30, the consecutive orders give
it directly: an $x$ in both subgroups is killed by $15$ and by $16$, so $x = x^{16} =
x^{15} \cdot x = e \cdot x$ — i.e. $x = e$ (`consecutiveKillersGiveTrivialIntersection`
in `std/group/generated.b4m`, stated for any $m$ and $m + 1$). The numerals are
successor towers: $16 = \mathrm{succ}(15)$.

```2b4m
define FIFTEEN = succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(succ(ZERO)))))))))))))))

theorem intersectionOfOrdersFifteenAndSixteenIsTrivial: forall g, h: G; hasOrder(g, FIFTEEN) -> hasOrder(h, succ(FIFTEEN)) -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @given-g-order |
            assume hasOrder(g, FIFTEEN) {
              @given-h-order |
                assume hasOrder(h, succ(FIFTEEN)) {
                  @g-order-facts |
                    less_than(ZERO, FIFTEEN) and power(g, FIFTEEN) = e and (forall m: Int; less_than(ZERO, m) -> less_than(m, FIFTEEN) -> power(g, m) != e)
                    [by hypothesis given-g-order]
                  @h-order-facts |
                    less_than(ZERO, succ(FIFTEEN)) and power(h, succ(FIFTEEN)) = e and (forall m: Int; less_than(ZERO, m) -> less_than(m, succ(FIFTEEN)) -> power(h, m) != e)
                    [by hypothesis given-h-order]
                  @fifteen-kills-g |
                    power(g, FIFTEEN) = e
                    [using tautology g-order-facts]
                  @sixteen-kills-h |
                    power(h, succ(FIFTEEN)) = e
                    [using tautology h-order-facts]
                  @conclusion-intersection-trivial |
                    forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
                    [using specialize group_order.consecutiveKillersGiveTrivialIntersection(g, h, FIFTEEN) fifteen-kills-g sixteen-kills-h]
                }
              @h-order-implies |
                hasOrder(h, succ(FIFTEEN)) -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
                [by implies_intro given-h-order]
            }
          @g-order-implies |
            hasOrder(g, FIFTEEN) -> hasOrder(h, succ(FIFTEEN)) -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
            [by implies_intro given-g-order]
        }
      @discharge-h |
        forall h: G; hasOrder(g, FIFTEEN) -> hasOrder(h, succ(FIFTEEN)) -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
        [by forall_intro generalize-h]
    }
  @conclusion |
    forall g, h: G; hasOrder(g, FIFTEEN) -> hasOrder(h, succ(FIFTEEN)) -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
    [by forall_intro generalize-g]
qed
```

**29. $\mathbb{Z}_n$ has an even number of generators for $n > 2$.** **Proved** —
and proved for every finite group at once, with $\mathbb{Z}_n$ getting it by model
transfer. `std/group/listing.b4m`'s `generatorsOfAFiniteGroupAreEvenInNumber` says:
a listing of $n > 2$ distinct elements covering a group yields a listing of its
generators of even length — the generators are closed under $g \mapsto g^{-1}$ (the
inverse of a generator generates) and none is its own inverse (if $g = g^{-1}$ every
power of $g$ is $e$ or $g$, so the group has at most two elements), so they pair off
(`pairedListingHasEvenLength`). `std/integer/mod-n-listing.b4m` then does two things:
it LISTS $\mathbb{Z}_n$ — the classes $\mathrm{cls}(0), \ldots, \mathrm{cls}(n-1)$ are
pairwise distinct (congruent representatives below $n$ are equal, the bounded-remainder
lemma) and are all the classes (reduce any representative by the division algorithm),
which is also "$\mathbb{Z}_n$ has exactly $n$ elements" — and it declares
$\mathbb{Z}_n$ a model of the listed-group stack (`ZnListing`: the group axioms by
$\mathbb{Z}_n$'s lifted laws, the integer powers by `znPower`, the sequence postulates
by a sort of sequences of classes), so the abstract theorem becomes
`znHasAnEvenNumberOfGenerators` with one citation. Judson's pairing $r \leftrightarrow
n - r$ is the group inverse $\mathrm{cls}(r) \mapsto -\mathrm{cls}(r)$; the hypothesis
$n > 2$ crosses from $\mathbb{Z}$ to the index sort through the embedding.

```2b4m
import mod_n_listing <<< "std/integer/mod-n-listing.b4m"

// 2 < N -> exists v: ZnSeq; exists p: Nat; (the first p entries of v generate ℤ_n) and
//   (they are pairwise distinct) and (every generator is one of them) and 2 | p
theorem znHasAnEvenNumberOfGenerators = mod_n_listing.znHasAnEvenNumberOfGenerators
```

**30. $\gcd(|a|,|b|) = 1 \Rightarrow \langle a \rangle \cap \langle b \rangle =
\{e\}$.** **Proved.** An $x$ in both subgroups is a power of $a$, so $x^{|a|} =
(a^{|a|})^i = e$, and likewise $x^{|b|} = e$. Since the only common divisors of $|a|$
and $|b|$ are $\pm 1$, Bézout gives $r, s$ with $r|a| + s|b| = 1$, and then $x = x^1 =
x^{r|a|} x^{s|b|} = e$. (This avoids naming the order of $x$ at all — the
order-divides route needs $x$ to *have* an order, which is a finiteness fact.)

```2b4m
theorem coprimeOrdersGiveTrivialIntersection: forall g, h: G; forall m, n: Int; hasOrder(g, m) -> hasOrder(h, n) -> gcd(m, n) = ONE -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
proof
  @conclusion |
    forall g, h: G; forall m, n: Int; hasOrder(g, m) -> hasOrder(h, n) -> gcd(m, n) = ONE -> forall x: G; inGenerated(g, x) -> inGenerated(h, x) -> x = e
    [using import(group_order) coprimeOrdersGiveTrivialIntersection]
qed
```

**31. The torsion subgroup** (elements of finite order in an abelian $G$ form a
subgroup). **Proved.** "$g$ has finite order" is *some positive exponent kills $g$*
(`hasFiniteOrder`, no order function needed). The subgroup criterion: $e^1 = e$; if
$g^n = e$ then $(g^{-1})^n = (g^n)^{-1} = e$; and if $g^m = e$ and $h^n = e$ then, $G$
being abelian, $(gh)^{mn} = g^{mn} h^{mn} = (g^m)^n (h^n)^m = e$ — the one place
commutativity enters (`powerProductAbelian`).

```2b4m
define hasFiniteOrder(g) = group_order.hasFiniteOrder(g)

theorem torsionHasIdentity: hasFiniteOrder(e)
proof
  @conclusion |
    hasFiniteOrder(e)
    [using import(group_order) identityHasFiniteOrder]
qed

theorem torsionClosedUnderInverse: forall g: G; hasFiniteOrder(g) -> hasFiniteOrder(inv(g))
proof
  @conclusion |
    forall g: G; hasFiniteOrder(g) -> hasFiniteOrder(inv(g))
    [using import(group_order) inverseHasFiniteOrder]
qed

theorem torsionClosedUnderOpAbelian: forall g, h: G; hasFiniteOrder(g) -> hasFiniteOrder(h) -> hasFiniteOrder(op(g, h))
proof
  @conclusion |
    forall g, h: G; hasFiniteOrder(g) -> hasFiniteOrder(h) -> hasFiniteOrder(op(g, h))
    [using import(group_order) productHasFiniteOrderAbelian]
qed
```

**32. In a cyclic group $G = \langle x \rangle$ of order $n$, if $y = x^k$ with
$\gcd(k,n) = 1$ then $y$ generates $G$.** **Forwarded** — this is the content of
the main-text theorem on the order of a power (§4.1, `powerOfPowerKills` /
`powerOfPowerMinimal`): when $d = \gcd(k,n) = 1$, the order of $y = x^k$ is $n/d =
n$, so $y$ has the same order as $x$ and thus generates $G$. See §4.1.

**33. An abelian $G$ with two order-2 cyclic subgroups has a subgroup of order 4.**
**Proved.** Two distinct cyclic subgroups of order 2 are $\{e, a\}$ and $\{e, b\}$ with
$|a| = |b| = 2$ and $a \ne b$; order 2 means $a \ne e$ and $a^2 = e$. Then $K = \{e, a, b,
ab\}$ contains $e$, is closed under the operation (each of $a$, $b$ permutes $K$ by left
multiplication, and $x(ab) = a(bx)$ — commutativity is used here) and under inverses
(every member is its own inverse: $(ab)^2 = a^2 b^2 = e$), and its four members are
pairwise distinct: $ab = e$ would give $b = a^{-1} = a$, while $ab = a$ or $ab = b$
cancels to $b = e$ or $a = e$. So $K$ is a subgroup of order 4 (the internal product
$\{e,a\}\{e,b\}$, a Klein four-group; `std/group/klein.b4m`).

```2b4m
define TWO = succ(succ(ZERO))
define inK(a, b, x) = group_order.inKlein(a, b, x)

theorem twoInvolutionsSpanAnOrderFourSubgroup: forall a, b: G; hasOrder(a, TWO) -> hasOrder(b, TWO) -> a != b -> (inK(a, b, e) and (forall x, y: G; inK(a, b, x) -> inK(a, b, y) -> inK(a, b, op(x, y))) and (forall x: G; inK(a, b, x) -> inK(a, b, inv(x))) and (a != e and b != e and e != op(a, b) and a != op(a, b) and b != op(a, b)))
proof
  @conclusion |
    forall a, b: G; hasOrder(a, TWO) -> hasOrder(b, TWO) -> a != b -> (inK(a, b, e) and (forall x, y: G; inK(a, b, x) -> inK(a, b, y) -> inK(a, b, op(x, y))) and (forall x: G; inK(a, b, x) -> inK(a, b, inv(x))) and (a != e and b != e and e != op(a, b) and a != op(a, b) and b != op(a, b)))
    [using import(group_order) twoInvolutionsSpanAnOrderFourSubgroup]
qed
```

**37. If $G$ has no proper nontrivial subgroups then $G$ is cyclic.** **Proved.**
Judson's argument only ever looks at *cyclic* subgroups: any $g \ne e$ has
$\langle g \rangle = G$, else $\langle g \rangle \ni g$ is a proper nontrivial subgroup.
So the hypothesis is stated for the cyclic subgroups — every $\langle g \rangle$ is
$\{e\}$ or all of $G$ — which is *weaker* than "no proper nontrivial subgroups" (a
first-order statement over elements, not over subgroups), and the conclusion is that
some $g$ generates. If every element is $e$ then $e$ generates; otherwise pick $g \ne
e$ (classically, from the failure of "every element is $e$"), and $\langle g \rangle$
is not $\{e\}$, so it is everything.

```2b4m
theorem noProperSubgroupsGivesCyclic: (forall g: G; (forall x: G; inGenerated(g, x) -> x = e) or (forall x: G; inGenerated(g, x))) -> exists g: G; forall x: G; inGenerated(g, x)
proof
  @conclusion |
    (forall g: G; (forall x: G; inGenerated(g, x) -> x = e) or (forall x: G; inGenerated(g, x))) -> exists g: G; forall x: G; inGenerated(g, x)
    [using import(group_order) noProperCyclicSubgroupsGivesCyclic]
qed
```
