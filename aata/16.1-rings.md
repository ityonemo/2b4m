A nonempty set $R$ is a **ring** if it has two closed binary operations, addition and
multiplication, satisfying the following conditions.

1. $a + b = b + a$ for $a, b \in R$.
2. $(a + b) + c = a + ( b + c)$ for $a, b, c \in R$.
3. There is an element $0$ in $R$ such that $a + 0 = a$ for all $a \in R$.
4. For every element $a \in R$, there exists an element $-a$ in $R$ such that $a + (-a) = 0$.
5. $(ab) c = a ( b c)$ for $a, b, c \in R$.
6. For $a, b, c \in R$,
   $$\begin{aligned} a( b + c) &= ab + ac \\ (a + b)c &= ac + bc. \end{aligned}$$

This last condition, the distributive axiom, relates the binary operations of addition and
multiplication. Notice that the first four axioms simply require that a ring be an abelian
group under addition, so we could also have defined a ring to be an abelian group $(R, +)$
together with a second binary operation satisfying the fifth and sixth conditions given above.

If there is an element $1 \in R$ such that $1 \neq 0$ and $1a = a1 = a$ for each element
$a \in R$, we say that $R$ is a ring with **unity** or **identity**. A ring $R$ for which
$ab = ba$ for all $a, b$ in $R$ is called a **commutative ring**. A commutative ring $R$
with identity is called an **integral domain** if, for every $a, b \in R$ such that $ab = 0$,
either $a = 0$ or $b = 0$. A **division ring** is a ring $R$, with an identity, in which
every nonzero element in $R$ is a **unit**; that is, for each $a \in R$ with $a \neq 0$,
there exists a unique element $a^{-1}$ such that $a^{-1} a = a a^{-1} = 1$. A commutative
division ring is called a **field**. The relationship among rings, integral domains,
division rings, and fields is shown in Figure 16.1.

> *The figure is a diagram of implications between the five kinds of ring, which we state
> as predicates rather than draw.*

```2b4m
// unity, commutativity, and the three derived kinds, each exactly as the text defines it.
const one = ring.ONE

// (A definition block cannot nest a quantifier inside a clause, so each of these is a
// `pred` with its characterizing axiom written out — the same shape std/subgroup.b4m uses.)
pred hasUnity()
axiom hasUnityDef: hasUnity() iff
  (one != zero and (forall a: R; mul(one, a) = a and mul(a, one) = a))

pred isCommutative()
axiom isCommutativeDef: isCommutative() iff (forall a, b: R; mul(a, b) = mul(b, a))

pred isIntegralDomain()
axiom isIntegralDomainDef: isIntegralDomain() iff
  (isCommutative() and hasUnity()
  and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))

pred isUnit(a: R)
axiom isUnitDef: forall a: R; isUnit(a) iff (exists b: R; mul(b, a) = one and mul(a, b) = one)

pred isDivisionRing()
axiom isDivisionRingDef: isDivisionRing() iff
  (hasUnity() and (forall a: R; a != zero -> isUnit(a)))

pred isField()
axiom isFieldDef: isField() iff (isCommutative() and isDivisionRing())
```

The relationships the figure draws are immediate from these definitions: a field is a
commutative division ring, and every division ring has an identity.

**Example.** As we have mentioned previously, the integers form a ring. In fact,
$\mathbb{Z}$ is an integral domain. Certainly if $a b = 0$ for two integers $a$ and $b$,
either $a=0$ or $b=0$. However, $\mathbb{Z}$ is not a field. There is no integer that is
the multiplicative inverse of $2$, since $1/2$ is not an integer. The only integers with
multiplicative inverses are $1$ and $-1$.

**Example.** Under the ordinary operations of addition and multiplication, all of the
familiar number systems are rings: the rationals, $\mathbb{Q}$; the real numbers,
$\mathbb{R}$; and the complex numbers, $\mathbb{C}$. Each of these rings is a field.

**Example.** We can define the product of two elements $a$ and $b$ in $\mathbb{Z}_n$ by
$ab \pmod{n}$. For instance, in $\mathbb{Z}_{12}$, $5 \cdot 7 \equiv 11 \pmod{12}$. This
product makes the abelian group $\mathbb{Z}_n$ into a ring. Certainly $\mathbb{Z}_n$ is a
commutative ring; however, it may fail to be an integral domain. If we consider
$3 \cdot 4 \equiv 0 \pmod{12}$ in $\mathbb{Z}_{12}$, it is easy to see that a product of
two nonzero elements in the ring can be equal to zero.

> *Judson's worked arithmetic in $\mathbb{Z}_{12}$ is a numeric example, which we do not
> transliterate.*

A nonzero element $a$ in a commutative ring $R$ is called a **zero divisor** if there is a
nonzero element $b$ in $R$ such that $ab = 0$. In the previous example, $3$ and $4$ are
zero divisors in $\mathbb{Z}_{12}$.

```2b4m
pred isZeroDivisor(a: R)
axiom isZeroDivisorDef: forall a: R;
  isZeroDivisor(a) iff (a != zero and (exists b: R; b != zero and mul(a, b) = zero))
```

An integral domain is precisely a commutative ring with identity that has no zero divisors —
the condition in its definition says exactly that no nonzero element annihilates a nonzero
one.

```2b4m
theorem anIntegralDomainHasNoZeroDivisors: isIntegralDomain() -> forall a: R; not isZeroDivisor(a)
proof
  @integral-domain-unfolds |
    isIntegralDomain() iff (isCommutative() and hasUnity() and (forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)))
    [by cite isIntegralDomainDef]
  @given-an-integral-domain |
    assume isIntegralDomain() {
      @the-integral-domain |
        isIntegralDomain()
        [by hypothesis given-an-integral-domain]
      @no-annihilating-pair |
        forall a, b: R; mul(a, b) = zero -> (a = zero or b = zero)
        [using tautology integral-domain-unfolds the-integral-domain]
      @generalize-a |
        fix a: R {
          @zero-divisor-unfolds |
            isZeroDivisor(a) iff (a != zero and (exists b: R; b != zero and mul(a, b) = zero))
            [using specialize isZeroDivisorDef(a)]
          @given-a-is-a-zero-divisor |
            assume isZeroDivisor(a) {
              @a-is-a-zero-divisor |
                isZeroDivisor(a)
                [by hypothesis given-a-is-a-zero-divisor]
              @a-is-nonzero-with-a-partner |
                a != zero and (exists b: R; b != zero and mul(a, b) = zero)
                [using tautology zero-divisor-unfolds a-is-a-zero-divisor]
              @a-is-nonzero |
                a != zero
                [by and_lhs a-is-nonzero-with-a-partner]
              @a-has-a-partner |
                exists b: R; b != zero and mul(a, b) = zero
                [by and_rhs a-is-nonzero-with-a-partner]
              @with-the-partner-b |
                unpack b: R from a-has-a-partner {
                  @partner-facts |
                    b != zero and mul(a, b) = zero
                    [by hypothesis with-the-partner-b]
                  @b-is-nonzero |
                    b != zero
                    [by and_lhs partner-facts]
                  @product-is-zero |
                    mul(a, b) = zero
                    [by and_rhs partner-facts]
                  @one-of-them-is-zero |
                    a = zero or b = zero
                    [using specialize no-annihilating-pair(a, b) product-is-zero]
                  @conclusion-contradiction |
                    a = zero
                    [using tautology one-of-them-is-zero b-is-nonzero]
                }
              @a-is-zero |
                a = zero
                [by unpacked with-the-partner-b]
              @conclusion-absurd |
                a = zero and a != zero
                [by both a-is-zero a-is-nonzero]
            }
          @being-a-zero-divisor-is-absurd |
            isZeroDivisor(a) -> (a = zero and a != zero)
            [by discharge given-a-is-a-zero-divisor]
          @conclusion-not-a-zero-divisor |
            not isZeroDivisor(a)
            [using tautology being-a-zero-divisor-is-absurd]
        }
      @conclusion-no-zero-divisors |
        forall a: R; not isZeroDivisor(a)
        [by generalize generalize-a]
    }
  @conclusion |
    isIntegralDomain() -> forall a: R; not isZeroDivisor(a)
    [by discharge given-an-integral-domain]
qed
```

**Example.** In calculus the continuous real-valued functions on an interval $[a,b]$ form a
commutative ring. We add or multiply two functions by adding or multiplying the values of
the functions. If $f(x) = x^2$ and $g(x) = \cos x$, then
$(f+g)(x) = f(x) + g(x) = x^2 + \cos x$ and $(fg)(x) = f(x) g(x) = x^2 \cos x$.

**Example.** The $2 \times 2$ matrices with entries in $\mathbb{R}$ form a ring under the
usual operations of matrix addition and multiplication. This ring is noncommutative, since
it is usually the case that $AB \neq BA$. Also, notice that we can have $AB = 0$ when
neither $A$ nor $B$ is zero.

**Example.** For an example of a noncommutative division ring, let
$$1 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}, \quad
\mathbf{i} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}, \quad
\mathbf{j} = \begin{pmatrix} 0 & i \\ i & 0 \end{pmatrix}, \quad
\mathbf{k} = \begin{pmatrix} i & 0 \\ 0 & -i \end{pmatrix}$$
where $i^2 = -1$. These elements satisfy the following relations:
$$\begin{aligned}
\mathbf{i}^2 = \mathbf{j}^2 &= \mathbf{k}^2 = -1 \\
\mathbf{i}\mathbf{j} &= \mathbf{k} \\
\mathbf{j}\mathbf{k} &= \mathbf{i} \\
\mathbf{k}\mathbf{i} &= \mathbf{j} \\
\mathbf{j}\mathbf{i} &= -\mathbf{k} \\
\mathbf{k}\mathbf{j} &= -\mathbf{i} \\
\mathbf{i}\mathbf{k} &= -\mathbf{j}.
\end{aligned}$$
Let $\mathbb{H}$ consist of elements of the form $a + b\mathbf{i} + c\mathbf{j} + d\mathbf{k}$,
where $a, b, c, d$ are real numbers. Equivalently, $\mathbb{H}$ can be considered to be the
set of all $2 \times 2$ matrices of the form
$$\begin{pmatrix} \alpha & \beta \\ -\overline{\beta} & \overline{\alpha} \end{pmatrix}$$
where $\alpha = a + di$ and $\beta = b + ci$ are complex numbers. We can define addition and
multiplication on $\mathbb{H}$ either by the usual matrix operations or in terms of the
generators $1$, $\mathbf{i}$, $\mathbf{j}$, and $\mathbf{k}$:
$$\begin{aligned}
&(a_1 + b_1\mathbf{i} + c_1\mathbf{j} + d_1\mathbf{k}) + (a_2 + b_2\mathbf{i} + c_2\mathbf{j} + d_2\mathbf{k}) \\
&= (a_1 + a_2) + (b_1 + b_2)\mathbf{i} + (c_1 + c_2)\mathbf{j} + (d_1 + d_2)\mathbf{k}
\end{aligned}$$
and
$$(a_1 + b_1\mathbf{i} + c_1\mathbf{j} + d_1\mathbf{k})(a_2 + b_2\mathbf{i} + c_2\mathbf{j} + d_2\mathbf{k}) = \alpha + \beta\mathbf{i} + \gamma\mathbf{j} + \delta\mathbf{k}$$
where
$$\begin{aligned}
\alpha &= a_1 a_2 - b_1 b_2 - c_1 c_2 - d_1 d_2 \\
\beta &= a_1 b_2 + a_2 b_1 + c_1 d_2 - d_1 c_2 \\
\gamma &= a_1 c_2 - b_1 d_2 + c_1 a_2 + d_1 b_2 \\
\delta &= a_1 d_2 + b_1 c_2 - c_1 b_2 + d_1 a_2.
\end{aligned}$$
Though multiplication looks complicated, it is actually a straightforward computation if we
remember that we just add and multiply elements in $\mathbb{H}$ like polynomials and keep in
mind the relationships between the generators $\mathbf{i}$, $\mathbf{j}$, and $\mathbf{k}$.
The ring $\mathbb{H}$ is called the ring of **quaternions**.

To show that the quaternions are a division ring, we must be able to find an inverse for
each nonzero element. Notice that
$$(a + b\mathbf{i} + c\mathbf{j} + d\mathbf{k})(a - b\mathbf{i} - c\mathbf{j} - d\mathbf{k}) = a^2 + b^2 + c^2 + d^2.$$
This element can be zero only if $a$, $b$, $c$, and $d$ are all zero. So if
$a + b\mathbf{i} + c\mathbf{j} + d\mathbf{k} \neq 0$,
$$(a + b\mathbf{i} + c\mathbf{j} + d\mathbf{k})\left(\frac{a - b\mathbf{i} - c\mathbf{j} - d\mathbf{k}}{a^2 + b^2 + c^2 + d^2}\right) = 1.$$

> *The four preceding examples — function rings, matrix rings, and the quaternions —
> all need a construction we do not have: matrices, and a sort of real-valued functions
> carrying their own ring structure. They are stated here and not constructed.*

## Proposition 16.2

> Let $R$ be a ring with $a, b \in R$. Then
>
> 1. $a0 = 0a = 0$;
> 2. $a(-b) = (-a)b = -ab$;
> 3. $(-a)(-b) = ab$.

**Proof.** To prove (1), observe that
$$a0 = a(0+0) = a0 + a0;$$
hence, $a0 = 0$. Similarly, $0a = 0$. For (2), we have $ab + a(-b) = a(b-b) = a0 = 0$;
consequently, $-ab = a(-b)$. Similarly, $-ab = (-a)b$. Part (3) follows directly from (2)
since $(-a)(-b) = -(a(-b)) = -(-ab) = ab$. $\blacksquare$

```2b4m
// (1) a0 = 0. Judson's two moves: 0 = 0 + 0 makes a0 = a0 + a0 by distributivity, and
// then cancelling a0 against itself on the left leaves a0 = 0.
fact addNegLeft = ring.addNegLeft
fact addZeroLeft = ring.addZeroLeft

theorem mulZeroRightIsZero: forall a: R; mul(a, zero) = zero
proof
  @generalize-a |
    fix a: R {
      @zero-is-zero-plus-zero |
        add(zero, zero) = zero
        [using specialize addZeroLeft(zero)]
      @a-times-the-sum |
        mul(a, add(zero, zero)) = add(mul(a, zero), mul(a, zero))
        [using specialize mulAddDistribLeft(a, zero, zero)]
      // Judson's displayed equation: a0 = a(0+0) = a0 + a0
      @a-zero-doubles |
        mul(a, zero) = add(mul(a, zero), mul(a, zero))
        [using chain zero-is-zero-plus-zero a-times-the-sum]
      // "hence a0 = 0": write the left side as 0 + a0 and cancel a0 off the right
      @left-side-as-zero-plus |
        add(zero, mul(a, zero)) = mul(a, zero)
        [using specialize addZeroLeft(mul(a, zero))]
      @zero-plus-equals-doubled |
        add(zero, mul(a, zero)) = add(mul(a, zero), mul(a, zero))
        [by rewrite a-zero-doubles left-side-as-zero-plus]
      @cancel-right |
        forall b, x, c: R; add(b, x) = add(c, x) -> b = c
        [using model(ring.AdditiveGroup) group.cancelRight]
      @zero-is-a-zero |
        zero = mul(a, zero)
        [using specialize cancel-right(zero, mul(a, zero), mul(a, zero)) zero-plus-equals-doubled]
      @conclusion-a-zero-is-zero |
        mul(a, zero) = zero
        [by symmetry zero-is-a-zero]
    }
  @conclusion |
    forall a: R; mul(a, zero) = zero
    [by generalize generalize-a]
qed
```

> *Part (2), first half: the two "similarly" halves of his argument are separate theorems

```2b4m
// ab + a(-b) = a(b + (-b)) = a0 = 0, so a(-b) is THE additive inverse of ab — which is
// what `additiveInverseUnique` turns into the equation Judson writes.
fact additiveInverseUnique = ring.additiveInverseUnique

theorem mulNegRightIsNegMul: forall a, b: R; mul(a, neg(b)) = neg(mul(a, b))
proof
  @inverses-are-unique |
    forall x, y: R; add(x, y) = zero -> y = neg(x)
    [by cite additiveInverseUnique]
  @generalize-a |
    fix a: R {
      @generalize-b |
        fix b: R {
          // a(b + (-b)) = ab + a(-b), the distributive step
          @a-times-b-minus-b |
            mul(a, add(b, neg(b))) = add(mul(a, b), mul(a, neg(b)))
            [using specialize mulAddDistribLeft(a, b, neg(b))]
          @b-minus-b-is-zero |
            add(b, neg(b)) = zero
            [using specialize addNegRight(b)]
          // so ab + a(-b) = a0
          @the-sum-is-a-zero |
            add(mul(a, b), mul(a, neg(b))) = mul(a, zero)
            [using chain a-times-b-minus-b b-minus-b-is-zero]
          @a-zero-is-zero |
            mul(a, zero) = zero
            [using specialize mulZeroRightIsZero(a)]
          // = 0
          @the-sum-is-zero |
            add(mul(a, b), mul(a, neg(b))) = zero
            [using chain the-sum-is-a-zero a-zero-is-zero]
          @conclusion-a-neg-b |
            mul(a, neg(b)) = neg(mul(a, b))
            [using specialize inverses-are-unique(mul(a, b), mul(a, neg(b))) the-sum-is-zero]
        }
      @conclusion-for-b |
        forall b: R; mul(a, neg(b)) = neg(mul(a, b))
        [by generalize generalize-b]
```

> *Part (3), following his displayed chain of three equalities.*

```2b4m
// the three equalities of his chain, in order. `negNeg` is the additive group's
// involution, transferred.
theorem negMulNegIsMul: forall a, b: R; mul(neg(a), neg(b)) = mul(a, b)
proof
  @double-negation |
    forall x: R; neg(neg(x)) = x
    [using model(ring.AdditiveGroup) group.invInvolution]
  @generalize-a |
    fix a: R {
      @generalize-b |
        fix b: R {
          // (-a)(-b) = -(a(-b)), by (2) applied on the left factor
          @first-step |
            mul(neg(a), neg(b)) = neg(mul(a, neg(b)))
            [using specialize mulNegLeftIsNegMul(a, neg(b))]
          // a(-b) = -ab, by (2) again
          @inner-step |
            mul(a, neg(b)) = neg(mul(a, b))
            [using specialize mulNegRightIsNegMul(a, b)]
          // so -(a(-b)) = -(-ab)
          @second-step |
            mul(neg(a), neg(b)) = neg(neg(mul(a, b)))
            [by rewrite inner-step first-step]
          // and -(-ab) = ab
          @third-step |
            neg(neg(mul(a, b))) = mul(a, b)
            [by apply_at(mul(a, b)) double-negation]
          @conclusion-neg-times-neg |
            mul(neg(a), neg(b)) = mul(a, b)
            [using chain second-step third-step]
        }
      @conclusion-for-b |
        forall b: R; mul(neg(a), neg(b)) = mul(a, b)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: R; mul(neg(a), neg(b)) = mul(a, b)
    [by generalize generalize-a]
qed
```

## Subrings

Just as we have subgroups of groups, we have an analogous class of substructures for rings.
A **subring** $S$ of a ring $R$ is a subset $S$ of $R$ such that $S$ is also a ring under
the inherited operations from $R$.

**Example.** The ring $n\mathbb{Z}$ is a subring of $\mathbb{Z}$. Notice that even though
the original ring may have an identity, we do not require that its subring have an identity.
We have the following chain of subrings:
$$\mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}.$$

The following proposition gives us some easy criteria for determining whether or not a
subset of a ring is indeed a subring. (We will leave the proof of this proposition as an
exercise.)

## Proposition 16.3

> Let $R$ be a ring and $S$ a subset of $R$. Then $S$ is a subring of $R$ if and only if
> the following conditions are satisfied.
>
> 1. $S \neq \emptyset$.
> 2. $rs \in S$ for all $r, s \in S$.
> 3. $r-s \in S$ for all $r, s \in S$.

> *With no sort of subsets of a ring, a subring is carried the way §3.3 carries a subgroup:
> a membership predicate on $R$, with Judson's three conditions as its defining axioms
> rather than as a criterion derived from "$S$ is itself a ring". So the biconditional above
> is not a theorem we can state — the right-hand side IS our definition — and what we prove
> instead is that the conditions deliver what being a ring requires: the inherited
> operations are closed on $S$, and $S$ contains $0$ and is closed under negation.*

```2b4m
// Judson's three conditions, as the definition of a subring.
pred inSubring(r: R)
axiom subringIsNonempty: exists r: R; inSubring(r)
axiom subringClosedUnderMul: forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(mul(r, s))
axiom subringClosedUnderSub: forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, neg(s)))

// What the conditions buy, in the order a ring's axioms need it: 0 is in S (take r - r),
// then negatives (0 - s), then sums (r - (-s)).
theorem aSubringContainsZero: inSubring(zero)
proof
  @closed-under-subtraction |
    forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, neg(s)))
    [by cite subringClosedUnderSub]
  @the-subring-is-nonempty |
    exists r: R; inSubring(r)
    [by cite subringIsNonempty]
  @with-a-member-r |
    unpack r: R from the-subring-is-nonempty {
      @r-is-a-member |
        inSubring(r)
        [by hypothesis with-a-member-r]
      @r-minus-r-is-a-member |
        inSubring(add(r, neg(r)))
        [using specialize closed-under-subtraction(r, r) r-is-a-member r-is-a-member]
      @r-minus-r-is-zero |
        add(r, neg(r)) = zero
        [using specialize addNegRight(r)]
      @conclusion-zero-is-a-member |
        inSubring(zero)
        [by rewrite r-minus-r-is-zero r-minus-r-is-a-member]
    }
  @conclusion |
    inSubring(zero)
    [by unpacked with-a-member-r]
qed

theorem aSubringIsClosedUnderNegation: forall s: R; inSubring(s) -> inSubring(neg(s))
proof
  @closed-under-subtraction |
    forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, neg(s)))
    [by cite subringClosedUnderSub]
  @zero-is-a-member |
    inSubring(zero)
    [by cite aSubringContainsZero]
  @generalize-s |
    fix s: R {
      @given-s-is-a-member |
        assume inSubring(s) {
          @s-is-a-member |
            inSubring(s)
            [by hypothesis given-s-is-a-member]
          @zero-minus-s-is-a-member |
            inSubring(add(zero, neg(s)))
            [using specialize closed-under-subtraction(zero, s) zero-is-a-member s-is-a-member]
          @zero-minus-s-is-neg-s |
            add(zero, neg(s)) = neg(s)
            [using specialize addZeroLeft(neg(s))]
          @conclusion-neg-s-is-a-member |
            inSubring(neg(s))
            [by rewrite zero-minus-s-is-neg-s zero-minus-s-is-a-member]
        }
      @conclusion-at-s |
        inSubring(s) -> inSubring(neg(s))
        [by discharge given-s-is-a-member]
    }
  @conclusion |
    forall s: R; inSubring(s) -> inSubring(neg(s))
    [by generalize generalize-s]
qed

theorem aSubringIsClosedUnderAddition: forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, s))
proof
  @closed-under-subtraction |
    forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, neg(s)))
    [by cite subringClosedUnderSub]
  @closed-under-negation |
    forall s: R; inSubring(s) -> inSubring(neg(s))
    [by cite aSubringIsClosedUnderNegation]
  @double-negation |
    forall x: R; neg(neg(x)) = x
    [using model(ring.AdditiveGroup) group.invInvolution]
  @generalize-r |
    fix r: R {
      @generalize-s |
        fix s: R {
          @given-r-is-a-member |
            assume inSubring(r) {
              @given-s-is-a-member |
                assume inSubring(s) {
                  @r-is-a-member |
                    inSubring(r)
                    [by hypothesis given-r-is-a-member]
                  @s-is-a-member |
                    inSubring(s)
                    [by hypothesis given-s-is-a-member]
                  // r + s = r - (-s), and both r and -s are in S
                  @neg-s-is-a-member |
                    inSubring(neg(s))
                    [using specialize closed-under-negation(s) s-is-a-member]
                  @r-minus-neg-s-is-a-member |
                    inSubring(add(r, neg(neg(s))))
                    [using specialize closed-under-subtraction(r, neg(s)) r-is-a-member neg-s-is-a-member]
                  @neg-neg-s-is-s |
                    neg(neg(s)) = s
                    [by apply_at(s) double-negation]
                  @conclusion-sum-is-a-member |
                    inSubring(add(r, s))
                    [by rewrite neg-neg-s-is-s r-minus-neg-s-is-a-member]
                }
              @conclusion-after-s |
                inSubring(s) -> inSubring(add(r, s))
                [by discharge given-s-is-a-member]
            }
          @conclusion-after-r |
            inSubring(r) -> inSubring(s) -> inSubring(add(r, s))
            [by discharge given-r-is-a-member]
        }
      @conclusion-for-s |
        forall s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, s))
        [by generalize generalize-s]
    }
  @conclusion |
    forall r, s: R; inSubring(r) -> inSubring(s) -> inSubring(add(r, s))
    [by generalize generalize-r]
qed
```

**Example.** Let $R = \mathbb{M}_2(\mathbb{R})$ be the ring of $2 \times 2$ matrices with
entries in $\mathbb{R}$. If $T$ is the set of upper triangular matrices in $R$; i.e.,
$$T = \left\{ \begin{pmatrix} a & b \\ 0 & c \end{pmatrix} : a, b, c \in \mathbb{R} \right\}$$
then $T$ is a subring of $R$. If
$$A = \begin{pmatrix} a & b \\ 0 & c \end{pmatrix} \quad \text{and} \quad
B = \begin{pmatrix} a' & b' \\ 0 & c' \end{pmatrix}$$
are in $T$, then clearly $A-B$ is also in $T$. Also,
$$AB = \begin{pmatrix} a a' & ab' + bc' \\ 0 & cc' \end{pmatrix}$$
is in $T$.

> *As with the earlier matrix examples, this one needs matrices, which we do not construct.*
