# Sets and Set Operations (Exercises)

Exercises for Judson §1.2.1, per `.claude/rules/aata-guide.md` — `std` used
liberally.

The theory of sets lives in `std/set.b4m`. We import it and keep the library
names.

```2b4m
import set <<< "std/set.b4m"

sort Element = set.Element
sort Set = set.Set
const emptyset = set.emptyset
func union = set.union
func intersection = set.intersection
func difference = set.difference
func complement = set.complement
pred member = set.member
define subset(a, b) = forall x: Element; member(x, a) -> member(x, b)
fact unionMember = set.unionMember
fact intersectionMember = set.intersectionMember
fact differenceMember = set.differenceMember
fact complementMember = set.complementMember
fact emptysetMember = set.emptysetMember
fact extensionality = set.extensionality
```

## Exercises

Most of the set identities below are the same **element-chase** the section's
propositions use — *$x \in \text{LHS}$ if and only if $x \in \text{RHS}$* — and the
hand version of that argument is written out in full in the main text (see
`unionCommutative` in `aata/1.2.1-sets.md`). Exercise 8 is the exception: it is a
biconditional between a containment and an equation, so it is proved by a double
inclusion rather than by a single chase.

**Exercise 8.** Prove $A \subset B$ if and only if $A \cap B = A$.

Forward, a double inclusion: $A \cap B \subset A$ always, and $A \subset A \cap B$
because every element of $A$ is also in $B$. Backward, rewriting $A \cap B = A$ in the
membership characterization turns "$x \in A$" into "$x \in A$ and $x \in B$", so a member
of $A$ is a member of $B$.

```2b4m
theorem subsetIffIntersectionIsTheSubset: forall a, b: Set;
  subset(a, b) iff intersection(a, b) = a
proof
  @generalize-a |
    fix a: Set {
      @generalize-b |
        fix b: Set {
          @given-a-inside-b |
            assume subset(a, b) {
              @every-member-of-a-is-in-b |
                forall x: Element; member(x, a) -> member(x, b)
                [by hypothesis given-a-inside-b]
              @generalize-x-downward |
                fix x: Element {
                  @intersection-membership-splits |
                    member(x, intersection(a, b)) iff (member(x, a) and member(x, b))
                    [using specialize intersectionMember(a, b, x)]
                  @conclusion-x-in-the-intersection-is-in-a |
                    member(x, intersection(a, b)) -> member(x, a)
                    [using tautology intersection-membership-splits]
                }
              @the-intersection-sits-inside-a |
                forall x: Element; member(x, intersection(a, b)) -> member(x, a)
                [by generalize generalize-x-downward]
              @generalize-x-upward |
                fix x: Element {
                  @intersection-membership-splits-again |
                    member(x, intersection(a, b)) iff (member(x, a) and member(x, b))
                    [using specialize intersectionMember(a, b, x)]
                  @x-in-a-is-in-b |
                    member(x, a) -> member(x, b)
                    [using specialize every-member-of-a-is-in-b(x)]
                  @conclusion-x-in-a-is-in-the-intersection |
                    member(x, a) -> member(x, intersection(a, b))
                    [using tautology intersection-membership-splits-again x-in-a-is-in-b]
                }
              @a-sits-inside-the-intersection |
                forall x: Element; member(x, a) -> member(x, intersection(a, b))
                [by generalize generalize-x-upward]
              @conclusion-the-intersection-is-a |
                intersection(a, b) = a
                [using specialize extensionality(intersection(a, b), a)
                  the-intersection-sits-inside-a a-sits-inside-the-intersection]
            }
          @a-inside-b-gives-the-equation |
            subset(a, b) -> intersection(a, b) = a
            [by discharge given-a-inside-b]
          @given-the-equation |
            assume intersection(a, b) = a {
              @the-intersection-is-a |
                intersection(a, b) = a
                [by hypothesis given-the-equation]
              @generalize-x-backward |
                fix x: Element {
                  @intersection-membership-splits-backward |
                    member(x, intersection(a, b)) iff (member(x, a) and member(x, b))
                    [using specialize intersectionMember(a, b, x)]
                  @membership-in-a-splits |
                    member(x, a) iff (member(x, a) and member(x, b))
                    [by rewrite the-intersection-is-a intersection-membership-splits-backward]
                  @conclusion-x-in-a-is-in-b |
                    member(x, a) -> member(x, b)
                    [using tautology membership-in-a-splits]
                }
              @conclusion-a-is-inside-b |
                subset(a, b)
                [by generalize generalize-x-backward]
            }
          @the-equation-gives-a-inside-b |
            intersection(a, b) = a -> subset(a, b)
            [by discharge given-the-equation]
          @conclusion-at-a-b |
            subset(a, b) iff intersection(a, b) = a
            [by make_equivalence a-inside-b-gives-the-equation the-equation-gives-a-inside-b]
        }
      @discharge-b |
        forall b: Set; subset(a, b) iff intersection(a, b) = a
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: Set; subset(a, b) iff intersection(a, b) = a
    [by generalize generalize-a]
qed
```

**Exercise 10.** Prove $A \cup B = (A \cap B) \cup (A \setminus B) \cup (B \setminus A)$
(every element of $A \cup B$ lies in exactly one of the three disjoint pieces).

```2b4m
theorem unionAsThreePieces: forall a, b: Set;
  union(a, b) = union(union(intersection(a, b), difference(a, b)), difference(b, a))
proof
  @element-chase |
    forall a, b: Set;
      union(a, b) = union(union(intersection(a, b), difference(a, b)), difference(b, a))
    [using extensionality_quantified(extensionality) unionMember intersectionMember differenceMember]
qed
```

**Exercise 13.** Prove $(A \cup B) \setminus B = A \setminus B$.

```2b4m
theorem unionMinusRight: forall a, b: Set; difference(union(a, b), b) = difference(a, b)

  @element-chase |

```

**Exercise 14.** Prove $A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)$.

```2b4m
theorem differenceOverUnion: forall a, b, c: Set;
  difference(a, union(b, c)) = intersection(difference(a, b), difference(a, c))
proof
  @element-chase |
    forall a, b, c: Set;
      difference(a, union(b, c)) = intersection(difference(a, b), difference(a, c))
    [using extensionality_quantified(extensionality) unionMember intersectionMember differenceMember]
qed
```

**Exercise 15.** Prove $A \cap (B \setminus C) = (A \cap B) \setminus (A \cap C)$.

```2b4m
theorem intersectionOverDifference: forall a, b, c: Set;

```

**Exercise 16.** Prove $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$
— the **symmetric difference**, written two ways.

```2b4m
theorem symmetricDifference: forall a, b: Set;
  union(difference(a, b), difference(b, a)) = difference(union(a, b), intersection(a, b))
proof
  @element-chase |
    forall a, b: Set;
      union(difference(a, b), difference(b, a)) = difference(union(a, b), intersection(a, b))
    [using extensionality_quantified(extensionality) unionMember intersectionMember differenceMember]
qed
```
