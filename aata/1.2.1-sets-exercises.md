# Sets and Set Operations (Exercises)

Exercises for Judson §1.2.1, per `.claude/rules/aata-guide.md` — `std` used
liberally.

The theory of sets lives in `std/set.bpa`. We import it and keep the library
names.

```bpa
import set <<< "std/set.bpa"

sort Element = set.Element
sort Set = set.Set
const emptyset = set.emptyset
func union = set.union
func intersection = set.intersection
func difference = set.difference
func complement = set.complement
pred member = set.member
axiom unionMember = set.unionMember
axiom intersectionMember = set.intersectionMember
axiom differenceMember = set.differenceMember
axiom complementMember = set.complementMember
axiom emptysetMember = set.emptysetMember
axiom extensionality = set.extensionality
```

## Exercises

The exercises for §1.2 ask for a handful of further set identities. Each is the
same **element-chase** the section's propositions use — *$x \in \text{LHS}$ if
and only if $x \in \text{RHS}$* — so each is discharged by the `ext` tactic in a
single line: `ext` reduces the equation through extensionality, fixes an element,
unfolds the membership operators, and closes the resulting propositional
biconditional (`ext_quantified(set)` peels the outer `forall` first). The
verbose hand version of exactly this argument is written out in full in the main
text (see `unionCommutative` in `aata/1.2.1-sets.md`).

**Exercise 8.** Prove $(A \cup B) \setminus B = A \setminus B$.

```bpa
theorem unionMinusRight: forall a, b: Set; difference(union(a, b), b) = difference(a, b)
proof
  @element-chase |
    forall a, b: Set; difference(union(a, b), b) = difference(a, b)
    [using ext_quantified(set)]
qed
```

**Exercise 6.** Prove $A \cup B = (A \cap B) \cup (A \setminus B) \cup (B \setminus A)$
(every element of $A \cup B$ lies in exactly one of the three disjoint pieces).

```bpa
theorem unionAsThreePieces: forall a, b: Set;
  union(a, b) = union(union(intersection(a, b), difference(a, b)), difference(b, a))
proof
  @element-chase |
    forall a, b: Set;
      union(a, b) = union(union(intersection(a, b), difference(a, b)), difference(b, a))
    [using ext_quantified(set)]
qed
```

**Exercise 10.** Prove $A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)$.

```bpa
theorem differenceOverUnion: forall a, b, c: Set;
  difference(a, union(b, c)) = intersection(difference(a, b), difference(a, c))
proof
  @element-chase |
    forall a, b, c: Set;
      difference(a, union(b, c)) = intersection(difference(a, b), difference(a, c))
    [using ext_quantified(set)]
qed
```

**Exercise 11.** Prove $A \cap (B \setminus C) = (A \cap B) \setminus (A \cap C)$.

```bpa
theorem intersectionOverDifference: forall a, b, c: Set;
  intersection(a, difference(b, c)) = difference(intersection(a, b), intersection(a, c))
proof
  @element-chase |
    forall a, b, c: Set;
      intersection(a, difference(b, c)) = difference(intersection(a, b), intersection(a, c))
    [using ext_quantified(set)]
qed
```

**Exercise 12.** Prove $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$
— the **symmetric difference**, written two ways.

```bpa
theorem symmetricDifference: forall a, b: Set;
  union(difference(a, b), difference(b, a)) = difference(union(a, b), intersection(a, b))
proof
  @element-chase |
    forall a, b: Set;
      union(difference(a, b), difference(b, a)) = difference(union(a, b), intersection(a, b))
    [using ext_quantified(set)]
qed
```

**Deferred (Exercise 9).** $A \subset B \iff A \cap B = A$ is a biconditional
over the subset relation $\subset$, which `std/set.bpa` does not yet model as a
predicate.
