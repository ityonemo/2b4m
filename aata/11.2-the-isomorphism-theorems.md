## Factor groups and homomorphic images

Although it is not evident at first, factor groups correspond exactly to homomorphic
images, and we can use factor groups to study homomorphisms. We already know that with
every group homomorphism $\phi : G \rightarrow H$ we can associate a normal subgroup of
$G$, $\ker \phi$. The converse is also true; that is, every normal subgroup of a group
$G$ gives rise to a homomorphism of groups.

**Definition.** Let $H$ be a normal subgroup of $G$. Define the **natural** or
**canonical homomorphism** $\phi : G \rightarrow G/H$ by $\phi(g) = gH$. This is indeed
a homomorphism, since
$$\phi(g_1 g_2) = g_1 g_2 H = g_1 H g_2 H = \phi(g_1)\phi(g_2).$$
The kernel of this homomorphism is $H$. Both halves of that claim:

```2b4m
import group_factor <<< "std/group/factor.b4m"

sort G = group_factor.G
sort Quot = group_factor.Quot
const EG = group_factor.EG
const EQ = group_factor.EQ
func opG = group_factor.opG
func invG = group_factor.invG

func invQ = group_factor.invQ

// the canonical homomorphism, and its kernel
theorem theCanonicalMapIsAHomomorphism: forall a: G; forall b: G; cls(opG(a, b)) = opQ(cls(a), cls(b))
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          @the-product-of-classes |
            opQ(cls(a), cls(b)) = cls(opG(a, b))
            [using specialize opQHom(a, b)]
          @conclusion-at-a-and-b |
            cls(opG(a, b)) = opQ(cls(a), cls(b))
            [by symmetry the-product-of-classes]
        }
      @discharge-b |
        forall b: G; cls(opG(a, b)) = opQ(cls(a), cls(b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: G; forall b: G; cls(opG(a, b)) = opQ(cls(a), cls(b))
    [by generalize generalize-a]
qed

theorem theCanonicalMapsKernelIsN: forall g: G; cls(g) = EQ iff inN(g)
proof
  @generalize-g |
    fix g: G {
      @the-identity-is-a-class |
        EQ = cls(EG)
        [by cite eqIsClsIdentity]
      @the-congruence-at-the-identity |
        cls(EG) = cls(g) iff inN(opG(invG(EG), g))
        [using specialize clsCongruent(EG, g)]
      // invG(EG) = EG, so invG(EG)·g collapses to g
      @the-identitys-inverse |
        invG(EG) = EG
        [by cite inverseIdentityG]
      @the-congruence-collapsed |
        cls(EG) = cls(g) iff inN(opG(EG, g))
        [by rewrite the-identitys-inverse the-congruence-at-the-identity]
      @g-absorbs-the-identity |
        opG(EG, g) = g
        [using specialize opGIdentityLeft(g)]
      @the-congruence-at-g |
        cls(EG) = cls(g) iff inN(g)
        [by rewrite g-absorbs-the-identity the-congruence-collapsed]
      @the-congruence-with-the-identity-class |
        EQ = cls(g) iff inN(g)
        [by rewrite the-identity-is-a-class the-congruence-at-g]
      // orient the equation the way the statement reads
      @given-g-is-killed |
        assume cls(g) = EQ {
          @g-is-killed |
            cls(g) = EQ
            [by hypothesis given-g-is-killed]
          @the-identity-is-gs-class |
            EQ = cls(g)
            [by symmetry g-is-killed]
          @conclusion-g-is-in-n |
            inN(g)
            [using tautology the-congruence-with-the-identity-class the-identity-is-gs-class]
        }
      @killed-implies-in-n |
        cls(g) = EQ -> inN(g)
        [by discharge given-g-is-killed]
      @given-g-is-in-n |
        assume inN(g) {
          @g-is-in-n |
            inN(g)
            [by hypothesis given-g-is-in-n]
          @the-identity-is-gs-class |
            EQ = cls(g)
            [using tautology the-congruence-with-the-identity-class g-is-in-n]
          @conclusion-g-is-killed |
            cls(g) = EQ
            [by symmetry the-identity-is-gs-class]
        }
      @in-n-implies-killed |
        inN(g) -> cls(g) = EQ
        [by discharge given-g-is-in-n]
      @conclusion-at-g |
        cls(g) = EQ iff inN(g)
        [by make_equivalence killed-implies-in-n in-n-implies-killed]
    }
  @conclusion |
    forall g: G; cls(g) = EQ iff inN(g)
    [by generalize generalize-g]
qed
```

> *Every theorem in this section concludes with a $\cong$, and that relation cannot be
> named here: a group is a sort with operations and axioms, not a value inhabiting a sort
> of groups, so "for all groups $G$, $H$ …" has no form. Each theorem below is therefore
> written as the declared groups, the map, and the map's properties — every instance of
> $\cong$ is provable, only the quantification is not.*

## First Isomorphism Theorem

**Theorem 11.10 (First Isomorphism Theorem).** If $\psi : G \rightarrow H$ is a group
homomorphism with $K = \ker \psi$, then $K$ is normal in $G$. Let
$\phi : G \rightarrow G/K$ be the canonical homomorphism. Then there exists a unique
isomorphism $\eta : G/K \rightarrow \psi(G)$ such that $\psi = \eta\phi$.

**Proof.** Define $\eta : G/K \rightarrow \psi(G)$ by $\eta(gK) = \psi(g)$. We
first show that $\eta$ is a well-defined map. If $g_1K = g_2K$, then for some $k \in K$,
$g_1k = g_2$; consequently,
$\eta(g_1K) = \psi(g_1) = \psi(g_1)\psi(k) = \psi(g_1k) = \psi(g_2) = \eta(g_2K)$.
We must also show that $\eta$ is a homomorphism:
$\eta(g_1Kg_2K) = \eta(g_1g_2K) = \psi(g_1g_2) = \psi(g_1)\psi(g_2) =
\eta(g_1K)\eta(g_2K)$. Clearly $\eta$ is onto $\psi(G)$. To show $\eta$ is one-to-one,
suppose $\eta(g_1K) = \eta(g_2K)$. Then $\psi(g_1) = \psi(g_2)$, so
$\psi(g_1^{-1}g_2) = e$, so $g_1^{-1}g_2$ is in the kernel; hence $g_1K = g_2K$.
$\blacksquare$

Well-definedness is the first thing to check: the premise "$g_1K = g_2K$" is the
equation $\mathrm{cls}(g_1) = \mathrm{cls}(g_2)$ between classes, and $\eta$'s value
must not depend on which representative carries it.

```2b4m
import first_iso <<< "std/group/first-isomorphism.b4m"

sort HH = first_iso.HH
func psi = first_iso.psi
func eta = first_iso.eta

theorem etaIsWellDefined: forall a: G; forall b: G;
  cls(a) = cls(b) -> psi(a) = psi(b)
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          @given-same-class |
            assume cls(a) = cls(b) {
              @same-class |
                cls(a) = cls(b)
                [by hypothesis given-same-class]
              @eta-at-a |
                eta(cls(a)) = psi(a)
                [using specialize etaOnClasses(a)]
              @eta-at-b |
                eta(cls(b)) = psi(b)
                [using specialize etaOnClasses(b)]
              @eta-at-a-via-b |
                eta(cls(b)) = psi(a)
                [by rewrite same-class eta-at-a]
              @psi-b-is-psi-a |
                psi(b) = psi(a)
                [using chain eta-at-b eta-at-a-via-b]
              @conclusion-at-a-and-b |
                psi(a) = psi(b)
                [by symmetry psi-b-is-psi-a]
            }
          @conclusion-implication |
            cls(a) = cls(b) -> psi(a) = psi(b)
            [by discharge given-same-class]
        }
      @discharge-b |
        forall b: G; cls(a) = cls(b) -> psi(a) = psi(b)
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: G; forall b: G; cls(a) = cls(b) -> psi(a) = psi(b)
    [by generalize generalize-a]
qed

  eta(x) = eta(y) -> x = y
proof

    fix x: Quot {
      @generalize-y |
        fix y: Quot {
          @given-same-image |
            assume eta(x) = eta(y) {
              @same-image |
                eta(x) = eta(y)
                [by hypothesis given-same-image]
              @x-has-a-rep |
                exists a: G; x = cls(a)

              @with-x-rep |

                    x = cls(a)
                    [by hypothesis with-x-rep]
                  @y-has-a-rep |
                    exists b: G; y = cls(b)
                    [using specialize clsSurjective(y)]
                  @with-y-rep |
                    unpack b: G from y-has-a-rep {
                      @y-is-cls-b |
                        y = cls(b)
                        [by hypothesis with-y-rep]
                      @eta-at-a |
                        eta(cls(a)) = psi(a)
                        [using specialize etaOnClasses(a)]
                      @eta-at-b |
                        eta(cls(b)) = psi(b)
                        [using specialize etaOnClasses(b)]
                      @same-image-with-a |
                        eta(cls(a)) = eta(y)
                        [by rewrite x-is-cls-a same-image]
                      @same-image-at-reps |
                        eta(cls(a)) = eta(cls(b))
                        [by rewrite y-is-cls-b same-image-with-a]
                      @psi-a-is-eta-b |
                        psi(a) = eta(cls(b))
                        [using chain eta-at-a same-image-at-reps]
                      @the-images-agree |
                        psi(a) = psi(b)
                        [using chain psi-a-is-eta-b eta-at-b]
                      // psi(a^-1 b) = psi(a)^-1 psi(b) = psi(a)^-1 psi(a) = e
                      @psi-splits-the-quotient |
                        psi(opG(invG(a), b)) = opHH(psi(invG(a)), psi(b))
                        [using specialize psiPreservesOp(invG(a), b)]
                      @psi-of-the-inverse |
                        psi(invG(a)) = invHH(psi(a))
                        [using specialize psiPreservesInversesHH(a)]
                      @the-quotients-image |
                        psi(opG(invG(a), b)) = opHH(invHH(psi(a)), psi(b))
                        [by rewrite psi-of-the-inverse psi-splits-the-quotient]
                      @with-the-images-equal |
                        psi(opG(invG(a), b)) = opHH(invHH(psi(a)), psi(a))
                        [by rewrite the-images-agree the-quotients-image]
                      @the-inverse-cancels |
                        opHH(invHH(psi(a)), psi(a)) = EHH
                        [using specialize opHHInverseLeft(psi(a))]
                      @the-quotient-is-killed |
                        psi(opG(invG(a), b)) = EHH
                        [using chain with-the-images-equal the-inverse-cancels]
                      @what-the-kernel-means |
                        inN(opG(invG(a), b)) iff psi(opG(invG(a), b)) = EHH
                        [using specialize nIsTheKernel(opG(invG(a), b))]
                      @the-quotient-is-in-n |
                        inN(opG(invG(a), b))
                        [using tautology what-the-kernel-means the-quotient-is-killed]
                      @the-classes-agree |
                        cls(a) = cls(b) iff inN(opG(invG(a), b))
                        [using specialize clsCongruent(a, b)]
                      @the-classes-are-equal |
                        cls(a) = cls(b)
                        [using tautology the-classes-agree the-quotient-is-in-n]
                      @conclusion-at-reps |
                        x = y
                        [using simplify the-classes-are-equal x-is-cls-a y-is-cls-b]
                    }
                  @conclusion-after-y |
                    x = y
                    [by unpacked with-y-rep]
                }
              @conclusion-after-x |
                x = y
                [by unpacked with-x-rep]
            }
          @conclusion-implication |
            eta(x) = eta(y) -> x = y
            [by discharge given-same-image]
        }
      @discharge-y |
        forall y: Quot; eta(x) = eta(y) -> x = y
        [by generalize generalize-y]
    }
  @conclusion |
    forall x: Quot; forall y: Quot; eta(x) = eta(y) -> x = y
    [by generalize generalize-x]
qed
```

Clearly $\eta$ is onto $\psi(G)$: every element of the image is $\psi(g) = \eta(gK)$ by
construction.

## Second Isomorphism Theorem

**Theorem 11.12 (Second Isomorphism Theorem).** Let $H$ be a subgroup of a group $G$
(not necessarily normal in $G$) and $N$ a normal subgroup of $G$. Then $HN$ is a
subgroup of $G$, $H \cap N$ is a normal subgroup of $H$, and
$$H/H \cap N \cong HN/N.$$

**Proof.** We will first show that $HN = \{hn : h \in H, n \in N\}$ is a subgroup of
$G$. Suppose that $h_1n_1, h_2n_2 \in HN$. Since $N$ is normal,
$(h_2)^{-1}n_1h_2 \in N$. So $(h_1n_1)(h_2n_2) = h_1h_2((h_2)^{-1}n_1h_2)n_2$ is in
$HN$. The inverse of $hn \in HN$ is in $HN$ since
$(hn)^{-1} = n^{-1}h^{-1} = h^{-1}(hn^{-1}h^{-1})$.

Next, we prove that $H \cap N$ is normal in $H$. Let $h \in H$ and $n \in H \cap N$.
Then $h^{-1}nh \in H$ since each element is in $H$. Also, $h^{-1}nh \in N$ since $N$ is
normal in $G$; therefore $h^{-1}nh \in H \cap N$.

Now define a map $\phi$ from $H$ to $HN/N$ by $h \mapsto hN$. The map $\phi$ is onto,
since any coset $hnN = hN$ is the image of $h$ in $H$. We also know that $\phi$ is a
homomorphism because $\phi(hh') = hh'N = hNh'N = \phi(h)\phi(h')$. By the First
Isomorphism Theorem, the image of $\phi$ is isomorphic to $H/\ker\phi$; and since
$\ker\phi = \{h \in H : h \in N\} = H \cap N$, we get
$HN/N = \phi(H) \cong H/H \cap N$. $\blacksquare$

Each regrouping inserts a cancelling pair — $h_2h_2^{-1}$ in the product, $h^{-1}h$ in
the inverse — so each is written out below.

```2b4m
  inProduct(x) -> inProduct(y) -> inProduct(opG2(x, y))
proof

    fix x: G2 {
      @generalize-y |
        fix y: G2 {

            assume inProduct(x) {

                    [by hypothesis given-y-in-the-product]

                        exists n: G2; inH(h1) and inN2(n) and x = opG2(h1, n)

                            [using tautology x-data]

                            inN2(n1)
                            [using tautology x-data]
                          @x-is-the-product |
                            x = opG2(h1, n1)
                            [using tautology x-data]
                          @with-y-h |
                            unpack h2: G2 from y-factors {
                              @y-inner |
                                exists n: G2; inH(h2) and inN2(n) and y = opG2(h2, n)
                                [by hypothesis with-y-h]
                              @with-y-n |
                                unpack n2: G2 from y-inner {
                                  @y-data |
                                    inH(h2) and inN2(n2) and y = opG2(h2, n2)
                                    [by hypothesis with-y-n]

                                    [using specialize hClosedOp(h1, h2) h1-is-in-h h2-is-in-h]

                                    [using specialize n2ClosedOp(opG2(opG2(invG2(h2), n1), h2), n2) the-conjugate-is-in-n-plainly n2-is-in-n]

                                  // and the regrouping says that product IS xy

                                      = opG2(opG2(h1, n1), opG2(h2, n2))
                                    [using specialize theProductRegroups(h1, n1, h2, n2)]
                                  @the-product-at-the-reps |

                                    [using simplify x-is-the-product y-is-the-product]

                                    [by symmetry the-regrouping]
                                  @the-product-is-the-regrouping |
                                    opG2(x, y)
                                      = opG2(opG2(h1, h2), opG2(opG2(opG2(invG2(h2), n1), h2), n2))
```

Surjectivity of $\phi$ onto $HN/N$ is the computation "any coset $hnN = hN$": every
element of $HN$ lies in the same $N$-coset as some element of $H$, which with §6.1's
criterion reads $h^{-1}x \in N$.

```2b4m
// φ : H → HN/N is onto: every x ∈ HN has an h ∈ H with xN = hN
theorem everyProductElementSharesACosetWithH: forall x: G2;
  inProduct(x) -> exists h: G2; inH(h) and inN2(opG2(invG2(h), x))
proof
  @generalize-x |
    fix x: G2 {
      @given-x-in-the-product |
        assume inProduct(x) {
          @x-factors |
            exists h: G2; exists n: G2; inH(h) and inN2(n) and x = opG2(h, n)
            [by hypothesis given-x-in-the-product]
          @with-the-h-factor |
            unpack h: G2 from x-factors {
              @the-n-factor-exists |
                exists n: G2; inH(h) and inN2(n) and x = opG2(h, n)
                [by hypothesis with-the-h-factor]
              @with-the-n-factor |
                unpack n: G2 from the-n-factor-exists {
                  @the-factorization |
                    inH(h) and inN2(n) and x = opG2(h, n)
                    [by hypothesis with-the-n-factor]
                  @h-is-in-h |
                    inH(h)
                    [using tautology the-factorization]
                  @n-is-in-n |
                    inN2(n)
                    [using tautology the-factorization]
                  @x-is-h-times-n |
                    x = opG2(h, n)
                    [using tautology the-factorization]
                  // h⁻¹x = h⁻¹(hn) = (h⁻¹h)n = n, which is in N
                  @regroup |
                    opG2(opG2(invG2(h), h), n) = opG2(invG2(h), opG2(h, n))
                    [using specialize subgroup.grpAssoc(invG2(h), h, n)]
                  @h-inverse-cancels-h |
                    opG2(invG2(h), h) = EG2
                    [using specialize subgroup.grpInverseLeft(h)]
                  @the-identity-times-n |
                    opG2(EG2, n) = opG2(invG2(h), opG2(h, n))
                    [by rewrite h-inverse-cancels-h regroup]
                  @n-alone |
                    opG2(EG2, n) = n
                    [using specialize subgroup.grpIdentityLeft(n)]
                  @the-quotient-is-n |
                    opG2(invG2(h), opG2(h, n)) = n
                    [using chain the-identity-times-n-flipped n-alone]
                  @the-identity-times-n-flipped |
                    opG2(invG2(h), opG2(h, n)) = opG2(EG2, n)
                    [by symmetry the-identity-times-n]
                  @the-quotient-at-x |
                    opG2(invG2(h), x) = n
                    [by rewrite x-is-h-times-n the-quotient-is-n]
                  @the-quotient-is-in-n |
                    inN2(opG2(invG2(h), x))
                    [by rewrite the-quotient-at-x n-is-in-n]
                  @the-pair |
                    inH(h) and inN2(opG2(invG2(h), x))
                    [by both h-is-in-h the-quotient-is-in-n]
                  @conclusion-a-representative-in-h |
                    exists h2: G2; inH(h2) and inN2(opG2(invG2(h2), x))
                    [by witness(h) the-pair]
                }
              @conclusion-after-n |
                exists h2: G2; inH(h2) and inN2(opG2(invG2(h2), x))
                [by unpacked with-the-n-factor]
            }
          @conclusion-a-coset-representative |
            exists h: G2; inH(h) and inN2(opG2(invG2(h), x))
            [by unpacked with-the-h-factor]
        }
      @conclusion-at-x |
        inProduct(x) -> exists h: G2; inH(h) and inN2(opG2(invG2(h), x))
        [by discharge given-x-in-the-product]
    }
  @conclusion |
    forall x: G2; inProduct(x) ->
      exists h: G2; inH(h) and inN2(opG2(invG2(h), x))
    [by generalize generalize-x]
qed
```

## Correspondence Theorem

**Theorem 11.13 (Correspondence Theorem).** Let $N$ be a normal subgroup of a group
$G$. Then $H \mapsto H/N$ is a one-to-one correspondence between the set of subgroups
$H$ of $G$ containing $N$ and the set of subgroups of $G/N$. Furthermore, the normal
subgroups of $G$ containing $N$ correspond to normal subgroups of $G/N$.

**Proof.** Let $H$ be a subgroup of $G$ containing $N$. Since $N$ is normal in $H$,
$H/N$ is a factor group. Let $aN$ and $bN$ be elements of $H/N$. Then
$(aN)(b^{-1}N) = ab^{-1}N \in H/N$; hence $H/N$ is a subgroup of $G/N$. Now let $S$ be a
subgroup of $G/N$ and put $H = \{g \in G : gN \in S\}$; then $H$ is a subgroup of $G$,
clearly containing $N$, and $S = H/N$. Finally, suppose $H_1$ and $H_2$ are subgroups of
$G$ containing $N$ with $H_1/N = H_2/N$; since $N$ is contained in $H_2$, every
$h_1 \in H_1$ is in $H_2$, and symmetrically. $\blacksquare$

"$S = H/N$" is agreement of two membership predicates on $G/N$, which is why the
surjectivity result below is an `iff`. Each half is stated at a given subgroup.

```2b4m
          @x-has-a-rep |
            exists h: G; inHsub(h) and x = cls(h)
            [by hypothesis given-x]
          @with-rep |
            unpack a: G from x-has-a-rep {
              @the-data |
                inHsub(a) and x = cls(a)
                [by hypothesis with-rep]
              @a-is-in-h |
                inHsub(a)
                [by and_lhs the-data]
              @x-is-cls-a |
                x = cls(a)
                [by and_rhs the-data]
              @the-inverse-is-in-h |
                inHsub(invG(a))
                [using specialize hsubClosedInverse(a) a-is-in-h]
              @the-inverse-hom-law |
                forall a2: G; invQ(cls(a2)) = cls(invG(a2))
                [using import(group_factor) invQHom]
              @the-class-of-the-inverse |
                invQ(cls(a)) = cls(invG(a))
                [using specialize the-inverse-hom-law(a)]
              @the-inverse-of-x |
                invQ(x) = cls(invG(a))
                [using simplify x-is-cls-a the-class-of-the-inverse]
              @the-witness |
                inHsub(invG(a)) and invQ(x) = cls(invG(a))
                [by both the-inverse-is-in-h the-inverse-of-x]
              @conclusion-at-the-rep |
                inHoverN(invQ(x))
                [by witness(invG(a)) the-witness]
            }
          @after-rep |
            inHoverN(invQ(x))
            [by unpacked with-rep]
        }
      @conclusion-at-x |
        inHoverN(x) -> inHoverN(invQ(x))
        [by discharge given-x]
    }
  @conclusion |
    forall x: Quot; inHoverN(x) -> inHoverN(invQ(x))
    [by generalize generalize-x]
qed

// BACKWARD: the pullback {g : gN in S} is a subgroup of G containing N
theorem thePullbackIsClosedUnderTheOperation: forall a: G; forall b: G;
  inPullback(a) -> inPullback(b) -> inPullback(opG(a, b))
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          @given-a |
            assume inPullback(a) {
              @given-b |
                assume inPullback(b) {
                  @cls-a-is-in-s |
                    inS(cls(a))
                    [by hypothesis given-a]
                  @cls-b-is-in-s |
                    inS(cls(b))
                    [by hypothesis given-b]
                  @the-product-of-classes-is-in-s |
                    inS(opQ(cls(a), cls(b)))
                    [using specialize sClosedOp(cls(a), cls(b)) cls-a-is-in-s cls-b-is-in-s]
                  @the-class-of-the-product |
                    opQ(cls(a), cls(b)) = cls(opG(a, b))
                    [using specialize opQHom(a, b)]
                  @conclusion-the-product-is-in-the-pullback |
                    inPullback(opG(a, b))
                    [by rewrite the-class-of-the-product the-product-of-classes-is-in-s]
                }
              @b-implies |
                inPullback(b) -> inPullback(opG(a, b))
                [by discharge given-b]
            }
          @conclusion-at-a-and-b |
            inPullback(a) -> inPullback(b) -> inPullback(opG(a, b))
            [by discharge given-a]
        }
      @discharge-b |
        forall b: G; inPullback(a) -> inPullback(b) -> inPullback(opG(a, b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a: G; forall b: G; inPullback(a) -> inPullback(b) -> inPullback(opG(a, b))
    [by generalize generalize-a]
qed

theorem thePullbackContainsN: forall g: G; inN(g) -> inPullback(g)
proof
  @generalize-g |
    fix g: G {
      @given-g-in-n |
        assume inN(g) {
          @g-is-in-n |
            inN(g)
            [by hypothesis given-g-in-n]
          @the-kernel-law |
            forall g2: G; cls(g2) = EQ iff inN(g2)
            [using import(group_factor) clsKernelIsN]
          @the-kernel-at-g |
            cls(g) = EQ iff inN(g)
            [using specialize the-kernel-law(g)]
          @g-is-killed |
            cls(g) = EQ
            [using tautology the-kernel-at-g g-is-in-n]
          @the-identity-is-in-s |
            inS(EQ)
            [by cite sHasIdentity]
          @conclusion-g-is-in-the-pullback |
            inPullback(g)
            [by rewrite g-is-killed the-identity-is-in-s]
        }
      @conclusion-at-g |
        inN(g) -> inPullback(g)
        [by discharge given-g-in-n]
    }
  @conclusion |
    forall g: G; inN(g) -> inPullback(g)
    [by generalize generalize-g]
qed

// SURJECTIVITY: that pullback's image IS S
theorem thePullbacksImageIsS: forall q: Quot; inPullbackOverN(q) iff inS(q)
proof
  @generalize-q |
    fix q: Quot {
      // forward: a class of a pullback element is in S by definition of the pullback
      @given-in-the-image |
        assume inPullbackOverN(q) {
          @q-has-a-rep |
            exists h: G; inPullback(h) and q = cls(h)
            [by hypothesis given-in-the-image]
          @with-rep |
            unpack h: G from q-has-a-rep {
              @the-data |
                inPullback(h) and q = cls(h)
                [by hypothesis with-rep]
              @q-is-cls-h |
                q = cls(h)
                [by and_rhs the-data]
              @cls-h-is-in-s |
                inS(cls(h))
                [by and_lhs the-data]
              @conclusion-q-is-in-s |
                inS(q)
                [by rewrite q-is-cls-h cls-h-is-in-s]
            }
          @after-rep |
            inS(q)
            [by unpacked with-rep]
        }
      @image-implies-s |
        inPullbackOverN(q) -> inS(q)
        [by discharge given-in-the-image]
      // backward: q in S has SOME representative (clsSurjective), and that rep is in the
      // pullback precisely because its class q is in S
      @given-in-s |
        assume inS(q) {
          @q-is-in-s |
            inS(q)
            [by hypothesis given-in-s]
          @q-has-a-rep |
            exists a: G; q = cls(a)
            [using specialize clsSurjective(q)]
          @with-rep |
            unpack a: G from q-has-a-rep {
              @q-is-cls-a |
                q = cls(a)
                [by hypothesis with-rep]
              @cls-a-is-in-s |
                inS(cls(a))
                [by rewrite q-is-cls-a q-is-in-s]
              @the-witness |
                inPullback(a) and q = cls(a)
                [by both cls-a-is-in-s q-is-cls-a]
              @conclusion-q-is-in-the-image |
                inPullbackOverN(q)
                [by witness(a) the-witness]
            }
          @after-rep |
            inPullbackOverN(q)
            [by unpacked with-rep]
        }
      @s-implies-image |
        inS(q) -> inPullbackOverN(q)
        [by discharge given-in-s]
      @conclusion-at-q |
        inPullbackOverN(q) iff inS(q)
        [by make_equivalence image-implies-s s-implies-image]
    }
  @conclusion |
    forall q: Quot; inPullbackOverN(q) iff inS(q)
    [by generalize generalize-q]
qed

// INJECTIVITY: equal images force extensionally equal subgroups. This is the step
// where "H contains N" is load-bearing -- Judson's "since N is contained in H_2, we
// know that h_1 in H_2".
theorem equalImagesMakeTheSubgroupsEqual:
  (forall q: Quot; inHoverN(q) iff inH2overN(q)) ->
  forall g: G; inHsub(g) iff inHsub2(g)
proof
  @given-images-agree |
    assume forall q: Quot; inHoverN(q) iff inH2overN(q) {
      @images-agree |
        forall q: Quot; inHoverN(q) iff inH2overN(q)
        [by hypothesis given-images-agree]
      @generalize-g |
        fix g: G {
          // H ⊂ H₂
          @given-g-in-h |
            assume inHsub(g) {
              @g-is-in-h |
                inHsub(g)
                [by hypothesis given-g-in-h]
              @gs-class-is-itself |
                cls(g) = cls(g)
                [by reflexivity]
              @the-h-witness |
                inHsub(g) and cls(g) = cls(g)
                [by both g-is-in-h gs-class-is-itself]
              @gs-class-is-in-the-h-image |
                inHoverN(cls(g))
                [by witness(g) the-h-witness]
              @the-images-agree-at-gs-class |
                inHoverN(cls(g)) iff inH2overN(cls(g))
                [using specialize images-agree(cls(g))]
              @gs-class-is-in-the-h2-image |
                inH2overN(cls(g))
                [using tautology the-images-agree-at-gs-class gs-class-is-in-the-h-image]
              @that-image-has-a-rep |
                exists h: G; inHsub2(h) and cls(g) = cls(h)
                [using tautology gs-class-is-in-the-h2-image]
              @with-the-h2-rep |
                unpack b: G from that-image-has-a-rep {
                  @the-h2-data |
                    inHsub2(b) and cls(g) = cls(b)
                    [by hypothesis with-the-h2-rep]
                  @b-is-in-h2 |
                    inHsub2(b)
                    [by and_lhs the-h2-data]
                  @the-classes-agree |
                    cls(g) = cls(b)
                    [by and_rhs the-h2-data]
                  @conclusion-g-is-in-h2 |
                    inHsub2(g)
                    [using specialize containingNMakesClassesSufficient(g, b) b-is-in-h2 the-classes-agree]
                }
              @after-the-h2-rep |
                inHsub2(g)
                [by unpacked with-the-h2-rep]
            }
          @h-implies-h2 |
            inHsub(g) -> inHsub2(g)
            [by discharge given-g-in-h]
          // H₂ ⊂ H, the same way with the roles swapped
          @given-g-in-h2 |
            assume inHsub2(g) {
              @g-is-in-h2 |
                inHsub2(g)
                [by hypothesis given-g-in-h2]
              @gs-class-is-itself-again |
                cls(g) = cls(g)
                [by reflexivity]
              @the-h2-witness |
                inHsub2(g) and cls(g) = cls(g)
                [by both g-is-in-h2 gs-class-is-itself-again]
              @gs-class-is-in-the-h2-image-again |
                inH2overN(cls(g))
                [by witness(g) the-h2-witness]
              @the-images-agree-at-gs-class-again |
                inHoverN(cls(g)) iff inH2overN(cls(g))
                [using specialize images-agree(cls(g))]
              @gs-class-is-in-the-h-image |
                inHoverN(cls(g))
                [using tautology the-images-agree-at-gs-class-again gs-class-is-in-the-h2-image-again]
              @that-image-has-a-rep-too |
                exists h: G; inHsub(h) and cls(g) = cls(h)
                [using tautology gs-class-is-in-the-h-image]
              @with-the-h-rep |
                unpack b: G from that-image-has-a-rep-too {
                  @the-h-data |
                    inHsub(b) and cls(g) = cls(b)
                    [by hypothesis with-the-h-rep]
                  @b-is-in-h |
                    inHsub(b)
                    [by and_lhs the-h-data]
                  @the-classes-agree-too |
                    cls(g) = cls(b)
                    [by and_rhs the-h-data]
                  @conclusion-g-is-in-h |
                    inHsub(g)
                    [using specialize containingNMakesClassesSufficientInH(g, b) b-is-in-h the-classes-agree-too]
                }
              @after-the-h-rep |
                inHsub(g)
                [by unpacked with-the-h-rep]
            }
          @h2-implies-h |
            inHsub2(g) -> inHsub(g)
            [by discharge given-g-in-h2]
          @conclusion-at-g |
            inHsub(g) iff inHsub2(g)
            [by make_equivalence h-implies-h2 h2-implies-h]
        }
      @all-g |
        forall g: G; inHsub(g) iff inHsub2(g)
        [by generalize generalize-g]
    }
  @conclusion |
    (forall q: Quot; inHoverN(q) iff inH2overN(q)) ->
      forall g: G; inHsub(g) iff inHsub2(g)
    [by discharge given-images-agree]
qed
```

## Third Isomorphism Theorem

**Theorem 11.14 (Third Isomorphism Theorem).** Let $G$ be a group and $N$ and $H$ be
normal subgroups of $G$ with $N \subset H$. Then
$$G/H \cong \frac{G/N}{H/N}.$$

The proof is left to the reader. The route is the one the Correspondence Theorem's last
paragraph sketches: the composite $G \rightarrow G/N \rightarrow (G/N)/(H/N)$ is a
homomorphism with kernel $H$, so the First Isomorphism Theorem gives
$G/H \cong (G/N)/(H/N)$.

> *This needs two nested quotients — $G/N$, then $(G/N)/(H/N)$ — which means forming the
> factor construction a second time with a quotient as its ambient group. The quotient
> template composes over a standalone substrate but not yet over a quotient one.*
