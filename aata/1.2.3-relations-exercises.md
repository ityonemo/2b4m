Exercises for §1.2.3 "Equivalence Relations and Partitions" of Thomas W.
Judson's *Abstract Algebra: Theory and Applications* (source:
`vendor/aata/src/sets.xml`; © 1997–2026 Judson, GFDL 1.3).

## Exercises

**Exercise 24.** Show that the reflexive property is redundant in the axioms
for an equivalence relation. That is, if $\sim$ is symmetric and transitive,
and if for every $x$ there is a $y$ with $x \sim y$, then $\sim$ is reflexive.

If $x \sim y$, then $y \sim x$ by symmetry, and using transitivity $x \sim x$.

> *Judson states this without the hypothesis that every element is related to
> something; we are adding it, since without it the claim is false — the empty
> relation on a nonempty set is vacuously symmetric and transitive but not
> reflexive.*

```2b4m
theorem reflexiveIsRedundant:
  symmetric -> transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
proof
  @given-symmetric |
    assume symmetric {
      @given-transitive |
        assume transitive {
          @given-serial |
            assume forall x: Element; exists y: Element; related(x, y) {
              @symmetric-holds |
                symmetric
                [by hypothesis given-symmetric]
              @transitive-holds |
                transitive
                [by hypothesis given-transitive]
              @serial |
                forall x: Element; exists y: Element; related(x, y)
                [by hypothesis given-serial]
              @every-element-reflexive |
                fix x: Element {
                  @x-relates-to-something |
                    exists y: Element; related(x, y)
                    [by apply_at(x) serial]
                  @with-witness-y |
                    unpack y: Element from x-relates-to-something {
                      @x-related-y |
                        related(x, y)
                        [by hypothesis with-witness-y]
                      @y-related-x |
                        related(y, x)
                        [using specialize symmetric-holds(x, y) x-related-y]
                      @x-related-x |
                        related(x, x)
                        [using specialize transitive-holds(x, y, x) x-related-y y-related-x]
                    }
                  @conclusion-x-reflexive |
                    related(x, x)
                    [by unpacked with-witness-y]
                }
              @conclusion-reflexive |
                reflexive
                [by generalize every-element-reflexive]
            }
          @discharge-serial |
            (forall x: Element; exists y: Element; related(x, y)) -> reflexive
            [by discharge given-serial]
        }
      @discharge-transitive |
        transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
        [by discharge given-transitive]
    }
  @conclusion |
    symmetric -> transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
    [by discharge given-symmetric]
qed
```
