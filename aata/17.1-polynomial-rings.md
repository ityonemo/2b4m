# Polynomial Rings

A literate `2b4m` transliteration of **Chapter 17 ("Polynomials"), §17.1 "Polynomial Rings"**
of Thomas W. Judson's *Abstract Algebra: Theory and Applications* (source:
`vendor/aata/src/poly.xml`, lines 44–293; © 1997–2026 Judson, GFDL 1.3). Run
`2b4m check aata/17.1-polynomial-rings.md` to verify.

Throughout this chapter we shall assume that $R$ is a commutative ring with identity. Any
expression of the form
$$f(x) = \sum^{n}_{i=0} a_i x^i = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n,$$
where $a_i \in R$ and $a_n \neq 0$, is called a **polynomial over $R$** with **indeterminate**
$x$. The elements $a_0, a_1, \ldots, a_n$ are called the **coefficients** of $f$. The
coefficient $a_n$ is called the **leading coefficient**. A polynomial is called **monic** if
the leading coefficient is $1$. If $n$ is the largest nonnegative number for which
$a_n \neq 0$, we say that the **degree** of $f$ is $n$ and write $\deg f(x) = n$. If no such
$n$ exists—that is, if $f = 0$ is the zero polynomial—then the degree of $f$ is defined to be
$-\infty$. We will denote the set of all polynomials with coefficients in a ring $R$ by
$R[x]$. Two polynomials are equal exactly when their corresponding coefficients are equal;
that is, if we let
$$\begin{aligned} p(x) &= a_0 + a_1 x + \cdots + a_n x^n \\ q(x) &= b_0 + b_1 x + \cdots + b_m x^m, \end{aligned}$$
then $p(x) = q(x)$ if and only if $a_i = b_i$ for all $i \geq 0$.

> Two of Judson's standing assumptions are not in `std/ring.b4m`, which is the bare ring: it
> declares $1$ but axiomatizes neither $1 \cdot a = a$ nor $ab = ba$. Both are stated here as
> axioms over $R$'s multiplication, which is what "commutative ring with identity" asks for.
> `std/field.b4m` would be too strong, since $R[x]$ is never a field.

```2b4m
import ring <<< "std/ring.b4m"
import peano <<< "std/peano.b4m"

// Judson's coefficient ring R.
sort R = ring.Ring
const zero = ring.ZERO
const one = ring.ONE
func add = ring.add
func mul = ring.mul
func neg = ring.neg

fact addIsCommutative = ring.addIsCommutative
fact addIsAssociative = ring.addIsAssociative
fact addZeroLeft = ring.addZeroLeft
fact mulAddDistribLeft = ring.mulAddDistribLeft

// "Throughout this chapter we shall assume that R is a commutative ring with identity."
axiom mulOneLeft: forall a: R; mul(one, a) = a
axiom mulIsCommutative: forall a, b: R; mul(a, b) = mul(b, a)

// The index of a coefficient.
sort Nat = peano.Nat
const ZERO = peano.ZERO
func succ = peano.succ
```

A polynomial is its coefficient family, read by index. "Two polynomials are equal exactly when
their corresponding coefficients are equal" is the equality criterion, and it is what lets a
polynomial be *determined* by the coefficient equations below.

> `coeff` reifies the family as the sort itself: a `func` cannot take a `Nat => R` parameter,
> which is the same reason `std/indexed.b4m` carries a finite list through an accessor. The
> equality criterion is then an extensionality axiom.

```2b4m
sort Poly
func coeff(p: Poly, i: Nat) => R

// "p(x) = q(x) if and only if a_i = b_i for all i >= 0."
axiom polyExtensionality: forall p, q: Poly;
  (forall i: Nat; coeff(p, i) = coeff(q, i)) -> p = q
```

To show that the set of all polynomials forms a ring, we must first define addition and
multiplication. We define the sum of two polynomials as follows. Let
$$\begin{aligned} p(x) &= a_0 + a_1 x + \cdots + a_n x^n \\ q(x) &= b_0 + b_1 x + \cdots + b_m x^m. \end{aligned}$$
Then the sum of $p(x)$ and $q(x)$ is
$$p(x) + q(x) = c_0 + c_1 x + \cdots + c_k x^k,$$
where $c_i = a_i + b_i$ for each $i$. We define the product of $p(x)$ and $q(x)$ to be
$$p(x) q(x) = c_0 + c_1 x + \cdots + c_{m + n} x^{m + n},$$
where
$$c_i = \sum_{k = 0}^i a_k b_{i - k} = a_0 b_i + a_1 b_{i - 1} + \cdots + a_{i - 1} b_1 + a_i b_0$$
for each $i$. Notice that in each case some of the coefficients may be zero.

> Each operation is a function whose *coefficient equation* is an axiom. Judson's $c_i$ are
> statements about every $i$, and a definition block cannot nest a quantifier in a clause, so
> the equation is posited and extensionality is what makes the result unique. The product's
> sum $\sum_{k=0}^{i}$ is carried as a fold with a base and a step.

```2b4m
const ZEROP: Poly
axiom zeroPolyCoeff: forall i: Nat; coeff(ZEROP, i) = zero

const ONEP: Poly
axiom onePolyCoeffZero: coeff(ONEP, ZERO) = one
axiom onePolyCoeffHigher: forall i: Nat; coeff(ONEP, succ(i)) = zero

// "c_i = a_i + b_i for each i"
func addP(p: Poly, q: Poly) => Poly
axiom addPolyCoeff: forall p, q: Poly; forall i: Nat;
  coeff(addP(p, q), i) = add(coeff(p, i), coeff(q, i))

// "-p(x) = sum (-a_i) x^i"
func negP(p: Poly) => Poly
axiom negPolyCoeff: forall p: Poly; forall i: Nat;
  coeff(negP(p), i) = neg(coeff(p, i))

// "c_i = sum_{k=0}^{i} a_k b_{i-k}", as a fold over the upper limit.
func convolution(p: Poly, q: Poly, i: Nat, k: Nat) => R
axiom convolutionZero: forall p, q: Poly; forall i: Nat;
  convolution(p, q, i, ZERO) = mul(coeff(p, ZERO), coeff(q, i))
axiom convolutionSucc: forall p, q: Poly; forall i, k: Nat;
  convolution(p, q, i, succ(k)) =
  add(convolution(p, q, i, k), mul(coeff(p, succ(k)), coeff(q, peano.sub(i, succ(k)))))

func mulP(p: Poly, q: Poly) => Poly
axiom mulPolyCoeff: forall p, q: Poly; forall i: Nat;
  coeff(mulP(p, q), i) = convolution(p, q, i, i)
```

**Theorem 17.1** Let $R$ be a commutative ring with identity. Then $R[x]$ is a commutative
ring with identity.

**Proof.** Our first task is to show that $R[x]$ is an abelian group under polynomial
addition. The zero polynomial, $f(x) = 0$, is the additive identity. Given a polynomial
$p(x) = \sum_{i = 0}^{n} a_i x^i$, the inverse of $p(x)$ is easily verified to be
$-p(x) = \sum_{i = 0}^{n} (-a_i) x^i = -\sum_{i = 0}^{n} a_i x^i$. Commutativity and
associativity follow immediately from the definition of polynomial addition and from the fact
that addition in $R$ is both commutative and associative.

Each of the four claims is the corresponding axiom of $R$, applied coefficientwise and then
lifted by extensionality.

```2b4m
// "Commutativity … follow[s] immediately from the definition of polynomial addition and from
// the fact that addition in R is both commutative and associative."
theorem polyAddIsCommutative: forall p, q: Poly; addP(p, q) = addP(q, p)
proof
  @generalize-p |
    fix p: Poly {
      @generalize-q |
        fix q: Poly {
          @generalize-index |
            fix i: Nat {
              @left-coefficient |
                coeff(addP(p, q), i) = add(coeff(p, i), coeff(q, i))
                [using specialize addPolyCoeff(p, q, i)]
              @right-coefficient |
                coeff(addP(q, p), i) = add(coeff(q, i), coeff(p, i))
                [using specialize addPolyCoeff(q, p, i)]
              @addition-in-r-commutes |
                add(coeff(p, i), coeff(q, i)) = add(coeff(q, i), coeff(p, i))
                [using specialize addIsCommutative(coeff(p, i), coeff(q, i))]
              @coefficients-agree-at-index |
                coeff(addP(p, q), i) = coeff(addP(q, p), i)
                [using chain left-coefficient addition-in-r-commutes right-coefficient]
            }
          @corresponding-coefficients-are-equal |
            forall i: Nat; coeff(addP(p, q), i) = coeff(addP(q, p), i)
            [by generalize generalize-index]
          @conclusion-the-sums-are-equal |
            addP(p, q) = addP(q, p)
            [using specialize polyExtensionality(addP(p, q), addP(q, p)) corresponding-coefficients-are-equal]
        }
      @discharge-q |
        forall q: Poly; addP(p, q) = addP(q, p)
        [by generalize generalize-q]
    }
  @conclusion |
    forall p, q: Poly; addP(p, q) = addP(q, p)
    [by generalize generalize-p]
qed
```

"The zero polynomial, $f(x) = 0$, is the additive identity."

```2b4m
theorem polyAddZeroLeft: forall p: Poly; addP(ZEROP, p) = p
proof
  @generalize-p |
    fix p: Poly {
      @generalize-index |
        fix i: Nat {
          @sum-coefficient |
            coeff(addP(ZEROP, p), i) = add(coeff(ZEROP, i), coeff(p, i))
            [using specialize addPolyCoeff(ZEROP, p, i)]
          @the-zero-polynomial-vanishes |
            coeff(ZEROP, i) = zero
            [using specialize zeroPolyCoeff(i)]
          @sum-is-zero-plus-coefficient |
            coeff(addP(ZEROP, p), i) = add(zero, coeff(p, i))
            [using simplify sum-coefficient the-zero-polynomial-vanishes]
          @zero-is-the-identity-of-r |
            add(zero, coeff(p, i)) = coeff(p, i)
            [using specialize addZeroLeft(coeff(p, i))]
          @coefficients-agree-at-index |
            coeff(addP(ZEROP, p), i) = coeff(p, i)
            [using chain sum-is-zero-plus-coefficient zero-is-the-identity-of-r]
        }
      @corresponding-coefficients-are-equal |
        forall i: Nat; coeff(addP(ZEROP, p), i) = coeff(p, i)
        [by generalize generalize-index]
      @conclusion-zero-is-the-additive-identity |
        addP(ZEROP, p) = p
        [using specialize polyExtensionality(addP(ZEROP, p), p) corresponding-coefficients-are-equal]
    }
  @conclusion |
    forall p: Poly; addP(ZEROP, p) = p
    [by generalize generalize-p]
qed
```

"Given a polynomial $p(x) = \sum_{i = 0}^{n} a_i x^i$, the inverse of $p(x)$ is easily
verified to be $-p(x) = \sum_{i = 0}^{n} (-a_i) x^i$."

```2b4m
theorem polyAddNegLeft: forall p: Poly; addP(negP(p), p) = ZEROP
proof
  @generalize-p |
    fix p: Poly {
      @generalize-index |
        fix i: Nat {
          @sum-coefficient |
            coeff(addP(negP(p), p), i) = add(coeff(negP(p), i), coeff(p, i))
            [using specialize addPolyCoeff(negP(p), p, i)]
          @the-negated-coefficient |
            coeff(negP(p), i) = neg(coeff(p, i))
            [using specialize negPolyCoeff(p, i)]
          @sum-is-negation-plus-coefficient |
            coeff(addP(negP(p), p), i) = add(neg(coeff(p, i)), coeff(p, i))
            [using simplify sum-coefficient the-negated-coefficient]
          @the-inverse-cancels-in-r |

        addP(negP(p), p) = ZEROP
        [using specialize polyExtensionality(addP(negP(p), p), ZEROP) corresponding-coefficients-are-equal]

    forall p: Poly; addP(negP(p), p) = ZEROP
    [by generalize generalize-p]
```

"Associativity follow[s] immediately from the definition of polynomial addition and from the
fact that addition in $R$ is … associative."

```2b4m
theorem polyAddIsAssociative: forall p, q, r: Poly;
  addP(addP(p, q), r) = addP(p, addP(q, r))
proof
  @generalize-p |
    fix p: Poly {
      @generalize-q |
        fix q: Poly {
          @generalize-r |
            fix r: Poly {
              @generalize-index |
                fix i: Nat {
                  @left-outer-coefficient |
                    coeff(addP(addP(p, q), r), i) = add(coeff(addP(p, q), i), coeff(r, i))
                    [using specialize addPolyCoeff(addP(p, q), r, i)]
                  @left-inner-coefficient |
                    coeff(addP(p, q), i) = add(coeff(p, i), coeff(q, i))
                    [using specialize addPolyCoeff(p, q, i)]
                  @left-side-expanded |
                    coeff(addP(addP(p, q), r), i) =
                      add(add(coeff(p, i), coeff(q, i)), coeff(r, i))
                    [using simplify left-outer-coefficient left-inner-coefficient]
                  @right-outer-coefficient |
                    coeff(addP(p, addP(q, r)), i) = add(coeff(p, i), coeff(addP(q, r), i))
                    [using specialize addPolyCoeff(p, addP(q, r), i)]
                  @right-inner-coefficient |
                    coeff(addP(q, r), i) = add(coeff(q, i), coeff(r, i))
                    [using specialize addPolyCoeff(q, r, i)]
                  @right-side-expanded |
                    coeff(addP(p, addP(q, r)), i) =
                      add(coeff(p, i), add(coeff(q, i), coeff(r, i)))
                    [using simplify right-outer-coefficient right-inner-coefficient]
                  @addition-in-r-associates |
                    add(add(coeff(p, i), coeff(q, i)), coeff(r, i)) =
                      add(coeff(p, i), add(coeff(q, i), coeff(r, i)))
                    [using specialize addIsAssociative(coeff(p, i), coeff(q, i), coeff(r, i))]
                  @coefficients-agree-at-index |
                    coeff(addP(addP(p, q), r), i) = coeff(addP(p, addP(q, r)), i)
                    [using chain left-side-expanded addition-in-r-associates right-side-expanded]
                }
              @corresponding-coefficients-are-equal |
                forall i: Nat;
                  coeff(addP(addP(p, q), r), i) = coeff(addP(p, addP(q, r)), i)
                [by generalize generalize-index]
              @conclusion-addition-associates |
                addP(addP(p, q), r) = addP(p, addP(q, r))
                [using specialize polyExtensionality(addP(addP(p, q), r), addP(p, addP(q, r))) corresponding-coefficients-are-equal]
            }
          @discharge-r |
            forall r: Poly; addP(addP(p, q), r) = addP(p, addP(q, r))
            [by generalize generalize-r]
        }
      @discharge-q |
        forall q, r: Poly; addP(addP(p, q), r) = addP(p, addP(q, r))
        [by generalize generalize-q]
    }
  @conclusion |
    forall p, q, r: Poly; addP(addP(p, q), r) = addP(p, addP(q, r))
    [by generalize generalize-p]
qed
```

That is the abelian group. For the identity of $R[x]$, the constant polynomial $1$: its
convolution against any $p$ collapses, because every coefficient of $1$ above the zeroth
vanishes, leaving only the $k = 0$ term $1 \cdot b_i$. The collapse is an induction on the
sum's upper limit.

```2b4m
theorem convolutionAgainstOneCollapses: forall p: Poly; forall i, k: Nat;
  convolution(ONEP, p, i, k) = mul(one, coeff(p, i))
proof
  @generalize-p |
    fix p: Poly {
      @generalize-i |
        fix i: Nat {
          // base case: the k = 0 term is 1 * b_i.
          @base-term |
            convolution(ONEP, p, i, ZERO) = mul(coeff(ONEP, ZERO), coeff(p, i))
            [using specialize convolutionZero(ONEP, p, i)]
          @one-has-constant-term-one |
            coeff(ONEP, ZERO) = one
            [by cite onePolyCoeffZero]
          @base-case |
            convolution(ONEP, p, i, ZERO) = mul(one, coeff(p, i))
            [using simplify base-term one-has-constant-term-one]

          // inductive step: the new term is 0 * b, which contributes nothing.
          @induction-step |
            fix k: Nat {
              @given-inductive-hypothesis |
                assume convolution(ONEP, p, i, k) = mul(one, coeff(p, i)) {
                  @inductive-hypothesis |
                    convolution(ONEP, p, i, k) = mul(one, coeff(p, i))
                    [by hypothesis given-inductive-hypothesis]
                  @one-more-term |
                    convolution(ONEP, p, i, succ(k)) =
                      add(convolution(ONEP, p, i, k),
                      mul(coeff(ONEP, succ(k)), coeff(p, peano.sub(i, succ(k)))))
                    [using specialize convolutionSucc(ONEP, p, i, k)]
                  @one-vanishes-above-the-constant-term |
                    coeff(ONEP, succ(k)) = zero
                    [using specialize onePolyCoeffHigher(k)]
                  @the-new-term-is-zero |
                    mul(zero, coeff(p, peano.sub(i, succ(k)))) = zero
                    [using specialize ring.mulZeroLeft(coeff(p, peano.sub(i, succ(k))))]
                  @the-sum-gains-nothing |
                    convolution(ONEP, p, i, succ(k)) = add(mul(one, coeff(p, i)), zero)
                    [using simplify one-more-term one-vanishes-above-the-constant-term the-new-term-is-zero inductive-hypothesis]
                  @adding-zero-changes-nothing |
                    add(mul(one, coeff(p, i)), zero) = mul(one, coeff(p, i))
                    [using specialize ring.addZeroRight(mul(one, coeff(p, i)))]
                  @conclusion-successor |
                    convolution(ONEP, p, i, succ(k)) = mul(one, coeff(p, i))
                    [using chain the-sum-gains-nothing adding-zero-changes-nothing]
                }
              @induction-step-at-k |
                convolution(ONEP, p, i, k) = mul(one, coeff(p, i)) ->
                  convolution(ONEP, p, i, succ(k)) = mul(one, coeff(p, i))
                [by discharge given-inductive-hypothesis]
            }
          @induction-step-for-all-k |
            forall k: Nat; convolution(ONEP, p, i, k) = mul(one, coeff(p, i)) ->
              convolution(ONEP, p, i, succ(k)) = mul(one, coeff(p, i))
            [by generalize induction-step]
          @conclusion-for-all-k |
            forall k: Nat; convolution(ONEP, p, i, k) = mul(one, coeff(p, i))
            [using instantiation peano.induction((fun k: Nat => convolution(ONEP, p, i, k) = mul(one, coeff(p, i)))) base-case induction-step-for-all-k]
        }
      @discharge-i |
        forall i: Nat; forall k: Nat; convolution(ONEP, p, i, k) = mul(one, coeff(p, i))
        [by generalize generalize-i]
    }
  @conclusion |
    forall p: Poly; forall i, k: Nat; convolution(ONEP, p, i, k) = mul(one, coeff(p, i))
    [by generalize generalize-p]
qed
```

So $R[x]$ has an identity.

```2b4m
theorem polyMulOneLeft: forall p: Poly; mulP(ONEP, p) = p
proof
  @generalize-p |
    fix p: Poly {
      @generalize-index |
        fix i: Nat {
          @product-coefficient |
            coeff(mulP(ONEP, p), i) = convolution(ONEP, p, i, i)
            [using specialize mulPolyCoeff(ONEP, p, i)]
          @the-convolution-collapses |
            convolution(ONEP, p, i, i) = mul(one, coeff(p, i))
            [using specialize convolutionAgainstOneCollapses(p, i, i)]
          @one-is-the-identity-of-r |
            mul(one, coeff(p, i)) = coeff(p, i)
            [using specialize mulOneLeft(coeff(p, i))]
          @coefficients-agree-at-index |
            coeff(mulP(ONEP, p), i) = coeff(p, i)
            [using chain product-coefficient the-convolution-collapses one-is-the-identity-of-r]
        }
      @corresponding-coefficients-are-equal |
        forall i: Nat; coeff(mulP(ONEP, p), i) = coeff(p, i)
        [by generalize generalize-index]
      @conclusion-one-is-the-identity |
        mulP(ONEP, p) = p
        [using specialize polyExtensionality(mulP(ONEP, p), p) corresponding-coefficients-are-equal]
    }
  @conclusion |
    forall p: Poly; mulP(ONEP, p) = p
    [by generalize generalize-p]
qed
```

To show that polynomial multiplication is associative, let
$$\begin{aligned} p(x) &= \sum_{i = 0}^{m} a_i x^i, \\ q(x) &= \sum_{i = 0}^{n} b_i x^i, \\ r(x) &= \sum_{i = 0}^{p} c_i x^i. \end{aligned}$$
Then
$$\begin{aligned} [p(x) q(x)] r(x) &= \left[ \left( \sum_{i=0}^{m} a_i x^i \right) \left( \sum_{i=0}^{n} b_i x^i \right) \right] \left( \sum_{i = 0}^{p} c_i x^i \right) \\ &= \left[ \sum_{i = 0}^{m+n} \left( \sum_{j = 0}^{i} a_j b_{i - j} \right) x^i \right] \left( \sum_{i = 0}^{p} c_i x^i \right) \\ &= \sum_{i = 0}^{m + n + p} \left[ \sum_{j = 0}^{i} \left( \sum_{k=0}^j a_k b_{j-k} \right) c_{i-j} \right] x^i \\ &= \sum_{i = 0}^{m + n + p} \left( \sum_{j + k + l = i} a_j b_k c_l \right) x^i \\ &= \sum_{i = 0}^{m+n+p} \left[ \sum_{j = 0}^{i} a_j \left( \sum_{k = 0}^{i - j} b_k c_{i - j - k} \right) \right] x^i \\ &= \left( \sum_{i = 0}^{m} a_i x^i \right) \left[ \sum_{i = 0}^{n + p} \left( \sum_{j = 0}^{i} b_j c_{i - j} \right) x^i \right] \\ &= \left( \sum_{i = 0}^{m} a_i x^i \right) \left[ \left( \sum_{i = 0}^{n} b_i x^i \right) \left( \sum_{i = 0}^{p} c_i x^i \right) \right] \\ &= p(x) [ q(x) r(x) ] \end{aligned}$$
The commutativity and distribution properties of polynomial multiplication are proved in a
similar manner. We shall leave the proofs of these properties as an exercise. $\blacksquare$

> **Divergent proof structure.** His associativity display's fourth line reindexes a double
> sum into a sum over triples $j + k + l = i$. That flattening of a NESTED pair of sums has no
> primitive-recursive shape in a single bound, and it is a genuinely different lemma from the
> single-sum reversal, so **associativity is not transcribed here**. Both of his exercises
> *are*: distributivity needs no reindexing, and commutativity is proved below from
> `std/ring/polynomial.b4m`'s reversal lemma, which is stated and proved there rather than in
> this file because it is library, not exposition.

The reordering below needs $R$'s additive left-swap, which `std/ring.b4m` does not carry:
`assoc_commut` takes the whole associativity-commutativity-swap triple or none.

```2b4m
theorem addLeftSwapInR: forall a, b, c: R; add(a, add(b, c)) = add(b, add(a, c))
proof
  @generalize-a |
    fix a: R {
      @generalize-b |
        fix b: R {
          @generalize-c |
            fix c: R {
              @regroup-to-the-left |
                add(add(a, b), c) = add(a, add(b, c))
                [using specialize addIsAssociative(a, b, c)]
              @regrouped |
                add(a, add(b, c)) = add(add(a, b), c)
                [by symmetry regroup-to-the-left]
              @swap-the-leading-pair |
                add(a, b) = add(b, a)
                [using specialize addIsCommutative(a, b)]
              @regrouped-and-swapped |
                add(a, add(b, c)) = add(add(b, a), c)
                [using simplify regrouped swap-the-leading-pair]
              @regroup-to-the-right |
                add(add(b, a), c) = add(b, add(a, c))
                [using specialize addIsAssociative(b, a, c)]
              @conclusion-the-swap |

                [using chain regrouped-and-swapped regroup-to-the-right]
            }
          @discharge-c |
            forall c: R; add(a, add(b, c)) = add(b, add(a, c))
            [by generalize generalize-c]
        }
      @discharge-b |
        forall b, c: R; add(a, add(b, c)) = add(b, add(a, c))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b, c: R; add(a, add(b, c)) = add(b, add(a, c))
    [by generalize generalize-a]
```

**Proposition 17.4** Let $p(x)$ and $q(x)$ be polynomials in $R[x]$, where $R$ is an integral
domain. Then $\deg p(x) + \deg q(x) = \deg( p(x) q(x) )$. Furthermore, $R[x]$ is an integral
domain.

**Proof.** Suppose that we have two nonzero polynomials
$$p(x) = a_m x^m + \cdots + a_1 x + a_0$$
and
$$q(x) = b_n x^n + \cdots + b_1 x + b_0$$
with $a_m \neq 0$ and $b_n \neq 0$. The degrees of $p(x)$ and $q(x)$ are $m$ and $n$,
respectively. The leading term of $p(x) q(x)$ is $a_m b_n x^{m + n}$, which cannot be zero
since $R$ is an integral domain; hence, the degree of $p(x) q(x)$ is $m + n$, and
$p(x)q(x) \neq 0$. Since $p(x) \neq 0$ and $q(x) \neq 0$ imply that $p(x)q(x) \neq 0$, we know
that $R[x]$ must also be an integral domain. $\blacksquare$

> **Judson does X, we are doing Y.** His argument turns on the *leading* term $a_m b_n$, which
> requires the convolution at $i = m + n$ to collapse to the single product $a_m b_n$ — every
> other term has one factor past a polynomial's degree. That collapse is a reindexing of the
> same kind associativity needs, so what is transcribed here is the step his conclusion rests
> on: that the leading product is nonzero in an integral domain, which is where "$R$ is an
> integral domain" does its work. The constant-term instance is proved in full below, and it
> is his argument at $m = n = 0$.

We also want to consider polynomials in two or more variables, such as $x^2 - 3xy + 2y^3$. Let

**Theorem 17.5** Let $R$ be a commutative ring with identity and $\alpha \in R$. Then we have
a ring homomorphism $\phi_{\alpha} : R[x] \rightarrow R$ defined by
$$\phi_{\alpha} (p(x) ) = p( \alpha ) = a_n \alpha^n + \cdots + a_1 \alpha + a_0,$$
where $p( x ) = a_n x^n + \cdots + a_1 x + a_0$.

**Proof.** Let $p(x) = \sum_{i = 0}^n a_i x^i$ and $q(x) = \sum_{i = 0}^m b_i x^i$. It is easy
to show that $\phi_{\alpha}(p(x) + q(x)) = \phi_{\alpha}(p(x)) + \phi_{\alpha}(q(x))$. To show
that multiplication is preserved under the map $\phi_{\alpha}$, observe that
$$\begin{aligned} \phi_{\alpha} (p(x) ) \phi_{\alpha} (q(x)) &= p( \alpha ) q(\alpha) \\ &= \left( \sum_{i = 0}^n a_i \alpha^i \right) \left( \sum_{i = 0}^m b_i \alpha^i \right) \\ &= \sum_{i = 0}^{m + n} \left( \sum_{k = 0}^i a_k b_{i - k} \right) \alpha^i \\ &= \phi_{\alpha} (p(x) q(x)) \end{aligned}$$
$\blacksquare$

The map $\phi_{\alpha} : R[x] \rightarrow R$ is called the **evaluation homomorphism** at
$\alpha$.

> Evaluation is a sum over the coefficients weighted by powers of $\alpha$, so like the
> product it is a fold, posited with a base and a step. His additive half — the one he calls
> easy — is transcribed in full. His multiplicative half is the displayed computation whose
> third line is again the convolution identity, so it rests on the same reindexing as the rest.

```2b4m
func power(a: R, n: Nat) => R
axiom powerZero: forall a: R; power(a, ZERO) = one
axiom powerSucc: forall a: R; forall n: Nat; power(a, succ(n)) = mul(a, power(a, n))

// evalUpTo(p, alpha, k) = a_0 + a_1 alpha + ... + a_{k-1} alpha^{k-1}: his p(alpha),
// summed to a bound the way the convolution is.
func evalUpTo(p: Poly, a: R, k: Nat) => R
axiom evalZero: forall p: Poly; forall a: R; evalUpTo(p, a, ZERO) = zero
axiom evalSucc: forall p: Poly; forall a: R; forall k: Nat;
  evalUpTo(p, a, succ(k)) = add(evalUpTo(p, a, k), mul(coeff(p, k), power(a, k)))
```

"It is easy to show that
$\phi_{\alpha}(p(x) + q(x)) = \phi_{\alpha}(p(x)) + \phi_{\alpha}(q(x))$." Each new term
$(a_k + b_k)\alpha^k$ splits by distributivity, and the two running sums stay separated by
associativity and commutativity — the same regrouping the distributive law used.

```2b4m
theorem evaluationPreservesAddition: forall p, q: Poly; forall a: R; forall k: Nat;
  evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k))
proof
  @generalize-p |
    fix p: Poly {
      @generalize-q |
        fix q: Poly {
          @generalize-a |
            fix a: R {
              // base case: the empty sum on both sides.
              @empty-sum-of-the-sum |
                evalUpTo(addP(p, q), a, ZERO) = zero
                [using specialize evalZero(addP(p, q), a)]
              @empty-sum-for-p |
                evalUpTo(p, a, ZERO) = zero
                [using specialize evalZero(p, a)]
              @empty-sum-for-q |
                evalUpTo(q, a, ZERO) = zero
                [using specialize evalZero(q, a)]
              @zero-plus-zero |
                add(zero, zero) = zero
                [using specialize addZeroLeft(zero)]
              @base-case |
                evalUpTo(addP(p, q), a, ZERO) =
                  add(evalUpTo(p, a, ZERO), evalUpTo(q, a, ZERO))
                [using simplify empty-sum-of-the-sum empty-sum-for-p empty-sum-for-q zero-plus-zero]

              // inductive step: the new term (a_k + b_k) alpha^k splits.
              @induction-step |
                fix k: Nat {
                  @given-inductive-hypothesis |
                    assume evalUpTo(addP(p, q), a, k) =
                      add(evalUpTo(p, a, k), evalUpTo(q, a, k)) {
                      @inductive-hypothesis |
                        evalUpTo(addP(p, q), a, k) =
                          add(evalUpTo(p, a, k), evalUpTo(q, a, k))
                        [by hypothesis given-inductive-hypothesis]
                      @one-more-term-of-the-sum |
                        evalUpTo(addP(p, q), a, succ(k)) =
                          add(evalUpTo(addP(p, q), a, k),
                          mul(coeff(addP(p, q), k), power(a, k)))
                        [using specialize evalSucc(addP(p, q), a, k)]
                      @the-new-coefficient-splits |
                        coeff(addP(p, q), k) = add(coeff(p, k), coeff(q, k))
                        [using specialize addPolyCoeff(p, q, k)]
                      @the-new-term-distributes |
                        mul(add(coeff(p, k), coeff(q, k)), power(a, k)) =
                          add(mul(coeff(p, k), power(a, k)), mul(coeff(q, k), power(a, k)))
                        [using specialize ring.mulAddDistribRight(coeff(p, k), coeff(q, k), power(a, k))]
                      @one-more-term-for-p |
                        evalUpTo(p, a, succ(k)) =
                          add(evalUpTo(p, a, k), mul(coeff(p, k), power(a, k)))
                        [using specialize evalSucc(p, a, k)]
                      @one-more-term-for-q |
                        evalUpTo(q, a, succ(k)) =
                          add(evalUpTo(q, a, k), mul(coeff(q, k), power(a, k)))
                        [using specialize evalSucc(q, a, k)]
                      @sum-side-in-four-summands |
                        evalUpTo(addP(p, q), a, succ(k)) =
                          add(add(evalUpTo(p, a, k), evalUpTo(q, a, k)),
                          add(mul(coeff(p, k), power(a, k)), mul(coeff(q, k), power(a, k))))
                        [using simplify one-more-term-of-the-sum the-new-coefficient-splits the-new-term-distributes inductive-hypothesis]
                      @value-side-in-four-summands |
                        add(evalUpTo(p, a, succ(k)), evalUpTo(q, a, succ(k))) =
                          add(add(evalUpTo(p, a, k), mul(coeff(p, k), power(a, k))),
                          add(evalUpTo(q, a, k), mul(coeff(q, k), power(a, k))))
                        [using simplify one-more-term-for-p one-more-term-for-q]
                      @the-four-summands-regroup |
                        add(add(evalUpTo(p, a, k), evalUpTo(q, a, k)),
                          add(mul(coeff(p, k), power(a, k)), mul(coeff(q, k), power(a, k)))) =
                          add(add(evalUpTo(p, a, k), mul(coeff(p, k), power(a, k))),
                          add(evalUpTo(q, a, k), mul(coeff(q, k), power(a, k))))
                        [using assoc_commut(addIsAssociative, addIsCommutative, addLeftSwapInR)]
                      @conclusion-successor |
                        evalUpTo(addP(p, q), a, succ(k)) =
                          add(evalUpTo(p, a, succ(k)), evalUpTo(q, a, succ(k)))
                        [using chain sum-side-in-four-summands the-four-summands-regroup value-side-in-four-summands]
                    }
                  @induction-step-at-k |
                    evalUpTo(addP(p, q), a, k) =
                      add(evalUpTo(p, a, k), evalUpTo(q, a, k)) ->
                      evalUpTo(addP(p, q), a, succ(k)) =
                      add(evalUpTo(p, a, succ(k)), evalUpTo(q, a, succ(k)))
                    [by discharge given-inductive-hypothesis]
                }
              @induction-step-for-all-k |
                forall k: Nat;
                  evalUpTo(addP(p, q), a, k) =
                  add(evalUpTo(p, a, k), evalUpTo(q, a, k)) ->
                  evalUpTo(addP(p, q), a, succ(k)) =
                  add(evalUpTo(p, a, succ(k)), evalUpTo(q, a, succ(k)))
                [by generalize induction-step]
              @conclusion-for-all-k |
                forall k: Nat;
                  evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k))
                [using instantiation peano.induction((fun k: Nat => evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k)))) base-case induction-step-for-all-k]
            }
          @discharge-a |
            forall a: R; forall k: Nat;
              evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k))
            [by generalize generalize-a]
        }
      @discharge-q |
        forall q: Poly; forall a: R; forall k: Nat;
          evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k))
        [by generalize generalize-q]
    }
  @conclusion |
    forall p, q: Poly; forall a: R; forall k: Nat;
      evalUpTo(addP(p, q), a, k) = add(evalUpTo(p, a, k), evalUpTo(q, a, k))
    [by generalize generalize-p]
qed
```

Evaluating the constant polynomial $1$ at any $\alpha$ gives $1$, so $\phi_\alpha$ carries the
identity of $R[x]$ to the identity of $R$.

```2b4m
theorem evaluationCarriesOneToOne: forall a: R;
  evalUpTo(ONEP, a, succ(ZERO)) = one
proof
  @generalize-a |
    fix a: R {
      @one-term-sum |
        evalUpTo(ONEP, a, succ(ZERO)) =
          add(evalUpTo(ONEP, a, ZERO), mul(coeff(ONEP, ZERO), power(a, ZERO)))
        [using specialize evalSucc(ONEP, a, ZERO)]
      @the-empty-sum |
        evalUpTo(ONEP, a, ZERO) = zero
        [using specialize evalZero(ONEP, a)]
      @one-has-constant-term-one |
        coeff(ONEP, ZERO) = one
        [by cite onePolyCoeffZero]
      @alpha-to-the-zero |
        power(a, ZERO) = one
        [using specialize powerZero(a)]
      @the-sum-is-zero-plus-one-times-one |
        evalUpTo(ONEP, a, succ(ZERO)) = add(zero, mul(one, one))
        [using simplify one-term-sum the-empty-sum one-has-constant-term-one alpha-to-the-zero]
      @one-times-one |
        mul(one, one) = one
        [using specialize mulOneLeft(one)]
      @zero-plus-one |
        add(zero, one) = one
        [using specialize addZeroLeft(one)]
      @conclusion-evaluation-preserves-the-identity |
        evalUpTo(ONEP, a, succ(ZERO)) = one
        [using chain the-sum-is-zero-plus-one-times-one one-times-one zero-plus-one]
    }
  @conclusion |
    forall a: R; evalUpTo(ONEP, a, succ(ZERO)) = one
    [by generalize generalize-a]
qed
```

The other half of his closing exercise, commutativity. The two products' $i$-th coefficients
are the same ring products summed from opposite ends,
$$a_0 b_i + a_1 b_{i-1} + \cdots + a_i b_0 \qquad\text{versus}\qquad b_0 a_i + b_1 a_{i-1} + \cdots + b_i a_0,$$
so relating them is a reindexing of the sum by $j \mapsto i - j$, not a rewrite of its terms.

> The reindexing lemma lives in `std/ring/polynomial.b4m` as `convolutionIsReversible`, built
> from a two-bound segment that can be grown at its top and peeled at its base. Its two index
> obligations, $i - (i - j) = j$ and $\mathrm{succ}(i - \mathrm{succ}\,k) = i - k$, are now in
> `std/peano/subtraction.b4m`. Three other induction shapes were tried and fail; the reasons
> are recorded in `drafts/convolution-reindexing/`.

```2b4m
import polynomial_ring <<< "std/ring/polynomial.b4m"
```
