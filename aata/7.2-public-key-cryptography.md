## The RSA cryptosystem

The RSA cryptosystem, introduced by Rivest, Shamir and Adleman in 1978, is based on
the difficulty of factoring large numbers. It works as follows. Choose two random
150-digit primes $p$ and $q$, and compute $n = pq$ and
$\varphi(n) = m = (p-1)(q-1)$, where $\varphi$ is the Euler φ-function. Choose a
random $E$ with $\gcd(E, m) = 1$, and use the Euclidean algorithm to find $D$ with
$DE \equiv 1 \pmod{m}$. The numbers $n$ and $E$ are made public.

To send Alice the message piece $x$ (a positive integer less than $n$), Bob forms
$y = x^E \bmod n$. Alice recovers $x$ by computing $y^D \bmod n$; only Alice knows
$D$.

**The worked example.** With $p = 23$, $q = 29$: $n = 667$ and
$\varphi(n) = m = 616$. Take $E = 487$, since $\gcd(616, 487) = 1$. The message 25
encodes as $25^{487} \bmod 667 = 169$ (by repeated squares, §4.3), and the Euclidean
algorithm gives the $D$ that inverts it.

## Why RSA works

Judson's argument: *"We know that $DE \equiv 1 \pmod{m}$; hence, there exists a $k$
such that $DE = km + 1 = k\varphi(n) + 1$. … assume that $\gcd(x, n) = 1$. Then by
Theorem 6.17,*
$$y^D = (x^E)^D = x^{DE} = x^{km+1} = (x^{\varphi(n)})^k x = (1)^k x = x \bmod n.$$
*So we see that Alice recovers the original message $x$."*

That chain is a statement about **group exponents**, not about $\mathbb{Z}_n$
specifically: if $x$ raised to the group's size is the identity, then $x$ raised to
one more than any multiple of that size is $x$ again. So it is proved once over an
arbitrary group, and RSA is what it says when the group is $U(n)$ — where the size is
$\varphi(n)$ and the identity is 1.

```2b4m

// power(g, k·m + 1) = g, given power(g, m) = e. This IS Judson's
// x^{km+1} = (x^m)^k · x = e^k · x = x, with `powerMul`, `powerAdd` and `powerOne`
// doing the three steps.
theorem anExponentOneAboveAMultipleOfTheOrderIsTheIdentityMap = order_divides.anExponentOneAboveAMultipleOfTheOrderIsTheIdentityMap
```

The premise `power(x, m) = e` is Euler's Theorem (§6.3), which supplies it for every
unit once $m$ is the group's size:

```2b4m
theorem anElementToTheGroupsLengthIsTheIdentity = order_divides.anElementToTheGroupsLengthIsTheIdentity
```

**The second case, and what it needs.** Judson continues: *"For the other case, assume
that $\gcd(x, n) \neq 1$. Since $n = pq$ and $x < n$, we know $x$ is a multiple of $p$
or a multiple of $q$, but not both."* That case is **not** a group statement — it needs
$n$'s factorization as $pq$, the bound $x < n$, and the Chinese Remainder Theorem, none
of which exist in `std`. So what is machine-checked here is RSA for units, which is the
case the chapter computes with; the non-unit case is recorded as prose.

**What the exponent relation cannot yet say.** The proved theorem takes the group's
size as a bare integer $m$ with `power(g, m) = e` as a premise. That is the same
content as $m = \varphi(n) = (p-1)(q-1)$, but `φ` itself is not a function in `std`
(see `CHAPTER7-PAINPOINTS`), so the step $m = (p-1)(q-1)$ cannot be written.

Congruence, by contrast, *is* available and this file simply does not reach it:
§3.1 encodes $a \equiv b \pmod n$ as `divides(n, sub(a, b))` on $\mathbb{Z}$, and
`mod_n.clsCongruent` is the bridge `cls(a) = cls(b) iff divides(N, isub(a, b))`. So
$x^{DE} \equiv x \pmod n$ is statable as Judson writes it; what is cited above
concludes `power(g, …) = g`, an equation in the group. Connecting the two is a short
proof that has not been written.

## Message verification

There is a problem of message verification in public key cryptosystems: since the
encoding key is public, anyone can send an encoded message. Suppose Bob's keys are
$(n', E')$ and $(n', D')$, and Alice's are $(n, E)$ and $(n, D)$. Before sending $x$,
Bob *decrypts* it with his own key, $x' = x^{D'} \bmod n'$. Anyone can turn $x'$ back
into $x$ by encryption with Bob's public $E'$ — but only Bob could have formed $x'$,
which is what authenticates it.

The mathematics is the same round trip as above, run in the other order, so the
theorem already cited covers it: the signature verifies because $D'$ and $E'$ compose
to one more than a multiple of the group's size, whichever way round they are applied.
