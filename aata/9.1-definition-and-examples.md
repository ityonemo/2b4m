## Definition

**Definition.** Two groups $(G, \cdot)$ and $(H, \circ)$ are **isomorphic** if there
exists a one-to-one and onto map $\phi : G \rightarrow H$ such that the group operation
is preserved; that is,
$$\phi(a \cdot b) = \phi(a) \circ \phi(b)$$
for all $a$ and $b$ in $G$. If $G$ is isomorphic to $H$, we write $G \cong H$. The map
$\phi$ is called an **isomorphism**.

**Example.** We can define an isomorphism $\phi$ from the additive group of real numbers
$(\mathbb{R}, +)$ to the multiplicative group of positive real numbers
$(\mathbb{R^+}, \cdot)$ with the exponential map; that is,
$$\phi( x + y) = e^{x + y} = e^x e^y = \phi( x ) \phi( y).$$
Of course, we must still show that $\phi$ is one-to-one and onto, but this can be
determined using calculus.

**Example.** The integers are isomorphic to the subgroup of $\mathbb{Q}^\ast$ consisting of
elements of the form $2^n$. Define a map $\phi: \mathbb{Z} \rightarrow \mathbb{Q}^\ast$ by
$\phi( n ) = 2^n$. Then
$$\phi( m + n ) = 2^{m + n} = 2^m 2^n = \phi( m ) \phi( n ).$$
By definition the map $\phi$ is onto the subset $\{2^n : n \in \mathbb{Z} \}$ of
$\mathbb{Q}^\ast$. To show that the map is injective, assume that $m \neq n$. If we can
show that $\phi(m) \neq \phi(n)$, then we are done. Suppose that $m > n$ and assume that
$\phi(m) = \phi(n)$. Then $2^m = 2^n$ or $2^{m - n} = 1$, which is impossible since
$m - n > 0$.

> *Judson opens with a third example, $\mathbb{Z}_4 \cong \langle i \rangle$ via
> $\phi(n) = i^n$, checked against a four-value table, and later compares $U(8)$ with
> $U(12)$ and $S_3$ with $\mathbb{Z}_6$. Those are numeric and are not transliterated
> here.*

## The bijection

Because $\phi$ is one-to-one and onto, it is injective and surjective in the explicit
forms the proofs below use.

> NB: This theorem exists in std in `std/group/isomorphism.b4m:74:phiIsInjective`.
>
> NB: This theorem exists in std in `std/group/isomorphism.b4m:112:phiIsSurjective`.

```2b4m
theorem phiIsInjective: forall a, b: G; phi(a) = phi(b) -> a = b
proof
  @generalize-a |
    fix a: G {
      @generalize-b |
        fix b: G {
          @given-images-agree |
            assume phi(a) = phi(b) {
              @images-agree |
                phi(a) = phi(b)
                [by hypothesis given-images-agree]
              @psi-at-a |
                psi(phi(a)) = a
                [using specialize psiAfterPhi(a)]
              @psi-at-b |
                psi(phi(b)) = b
                [using specialize psiAfterPhi(b)]
              @psi-of-the-shared-image-is-a |
                psi(phi(b)) = a
                [by rewrite images-agree psi-at-a]
              @conclusion-equal |
                a = b
                [using chain psi-of-the-shared-image-is-a psi-at-b]
            }
          @discharge |
            phi(a) = phi(b) -> a = b
            [by discharge given-images-agree]
        }
      @discharge-b |
        forall b: G; phi(a) = phi(b) -> a = b
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: G; phi(a) = phi(b) -> a = b
    [by generalize generalize-a]
qed
theorem phiIsSurjective: forall b: H; exists a: G; phi(a) = b
proof
  @generalize-b |
    fix b: H {
      @round-trip |
        phi(psi(b)) = b
        [using specialize phiAfterPsi(b)]
      @conclusion-preimage |
        exists a: G; phi(a) = b
        [by witness(psi(b)) round-trip]
    }
  @conclusion |
    forall b: H; exists a: G; phi(a) = b
    [by generalize generalize-b]
qed
```

$\phi$ also carries $G$'s identity to $H$'s: from
$\phi(e \cdot e) = \phi(e) \circ \phi(e)$ and $e \cdot e = e$, cancellation in $H$
gives $\phi(e_G) = e_H$.

```2b4m
theorem phiPreservesIdentity: phi(eG) = eH
proof
  @identity-is-idempotent |
    opG(eG, eG) = eG
    [using specialize opGIdentityLeft(eG)]
  @phi-splits-the-product |
    phi(opG(eG, eG)) = opH(phi(eG), phi(eG))
    [using specialize phiPreservesOp(eG, eG)]
  @phi-of-the-identity-is-idempotent |
    phi(eG) = opH(phi(eG), phi(eG))
    [by rewrite identity-is-idempotent phi-splits-the-product]
  @identity-left-at-the-image |
    opH(eH, phi(eG)) = phi(eG)
    [using specialize opHIdentityLeft(phi(eG))]
  @both-products-agree |
    opH(eH, phi(eG)) = opH(phi(eG), phi(eG))
    [using chain identity-left-at-the-image phi-of-the-identity-is-idempotent]
  // H's cancellation law, transferred through HIsAGroup rather than cited in G's sort
  @cancel-right-in-h |
    forall b, a, c: H; opH(b, a) = opH(c, a) -> b = c
    [using model(HIsAGroup) group.cancelRight]
  @identity-is-the-image |
    eH = phi(eG)
    [using specialize cancel-right-in-h(eH, phi(eG), phi(eG)) both-products-agree]
  @conclusion-identity |
    phi(eG) = eH
    [by symmetry identity-is-the-image]
qed
```

## Theorem 9.6 — what an isomorphism preserves

**Theorem 9.6.** Let $\phi : G \rightarrow H$ be an isomorphism of two groups. Then the
following statements are true.

1. $\phi^{-1} : H \rightarrow G$ is an isomorphism.
2. $|G| = |H|$.
3. If $G$ is abelian, then $H$ is abelian.
4. If $G$ is cyclic, then $H$ is cyclic.
5. If $G$ has a subgroup of order $n$, then $H$ has a subgroup of order $n$.

**Proof.** Assertions (1) and (2) follow from the fact that $\phi$ is a
bijection. We will prove (3) here and leave the remainder of the theorem to be proved
in the exercises.

(3) Suppose that $h_1$ and $h_2$ are elements of $H$. Since $\phi$ is onto, there exist
elements $g_1, g_2 \in G$ such that $\phi(g_1) = h_1$ and $\phi(g_2) = h_2$. Therefore,
$$h_1 h_2 = \phi(g_1)\phi(g_2) = \phi(g_1 g_2) = \phi(g_2 g_1) = \phi(g_2)\phi(g_1) = h_2 h_1.$$
$\blacksquare$

**(1) — the inverse map is an isomorphism.** $\phi^{-1}$ is a bijection because
$\phi$ is, and it preserves the operation:

> NB: This theorem exists in std in `std/group/isomorphism.b4m:160:psiPreservesOp`.

```2b4m
theorem psiPreservesOp: forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y))
proof
  @generalize-x |
    fix x: H {
      @generalize-y |
        fix y: H {
          // φ(ψ(x)·ψ(y)) = φ(ψ(x))∘φ(ψ(y)) = x∘y, and ψ∘φ = id finishes it
          @phi-splits |
            phi(opG(psi(x), psi(y))) = opH(phi(psi(x)), phi(psi(y)))
            [using specialize phiPreservesOp(psi(x), psi(y))]
          @phi-psi-at-x |
            phi(psi(x)) = x
            [using specialize phiAfterPsi(x)]
          @phi-psi-at-y |
            phi(psi(y)) = y
            [using specialize phiAfterPsi(y)]
          @first-factor-collapses |
            phi(opG(psi(x), psi(y))) = opH(x, phi(psi(y)))
            [by rewrite phi-psi-at-x phi-splits]
          @image-of-the-product |
            phi(opG(psi(x), psi(y))) = opH(x, y)
            [by rewrite phi-psi-at-y first-factor-collapses]
          @psi-of-both-sides |
            psi(phi(opG(psi(x), psi(y)))) = psi(opH(x, y))
            [by rewrite image-of-the-product reflexivity-at-psi]
          @reflexivity-at-psi |
            psi(phi(opG(psi(x), psi(y)))) = psi(phi(opG(psi(x), psi(y))))
            [by reflexivity]
          @psi-round-trips |
            psi(phi(opG(psi(x), psi(y)))) = opG(psi(x), psi(y))
            [using specialize psiAfterPhi(opG(psi(x), psi(y)))]
          @conclusion-psi-preserves |
            psi(opH(x, y)) = opG(psi(x), psi(y))
            [using chain psi-of-both-sides psi-round-trips]
        }
      @discharge-y |
        forall y: H; psi(opH(x, y)) = opG(psi(x), psi(y))
        [by generalize generalize-y]
    }
  @conclusion |
    forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y))
    [by generalize generalize-x]
qed
```

**(3) — abelian transfers.** Pull $h_1$ and $h_2$ back through $\phi^{-1}$, commute in
$G$, push forward through $\phi$.

> NB: This theorem exists in std in `std/group/isomorphism.b4m:206:abelianTransfers`.

```2b4m
theorem abelianTransfers: (forall a, b: G; opG(a, b) = opG(b, a)) ->
  (forall x, y: H; opH(x, y) = opH(y, x))
proof
  @given-g-abelian |
    assume forall a, b: G; opG(a, b) = opG(b, a) {
      @g-is-abelian |
        forall a, b: G; opG(a, b) = opG(b, a)
        [by hypothesis given-g-abelian]
      @generalize-x |
        fix x: H {
          @generalize-y |
            fix y: H {
              // pull x and y back to G, commute there, push forward
              @x-is-an-image |
                phi(psi(x)) = x
                [using specialize phiAfterPsi(x)]
              @y-is-an-image |
                phi(psi(y)) = y
                [using specialize phiAfterPsi(y)]
              @preimages-commute |
                opG(psi(x), psi(y)) = opG(psi(y), psi(x))
                [using specialize g-is-abelian(psi(x), psi(y))]
              @phi-splits-one-way |
                phi(opG(psi(x), psi(y))) = opH(phi(psi(x)), phi(psi(y)))
                [using specialize phiPreservesOp(psi(x), psi(y))]
              @phi-splits-the-other-way |
                phi(opG(psi(y), psi(x))) = opH(phi(psi(y)), phi(psi(x)))
                [using specialize phiPreservesOp(psi(y), psi(x))]
              @images-of-equal-products-agree |
                phi(opG(psi(x), psi(y))) = opH(phi(psi(y)), phi(psi(x)))
                [by rewrite preimages-commute phi-splits-the-other-way]
              @products-in-h-agree |
                opH(phi(psi(x)), phi(psi(y))) = opH(phi(psi(y)), phi(psi(x)))
                [using chain phi-splits-one-way images-of-equal-products-agree]
              @x-replaces-its-image |
                opH(x, phi(psi(y))) = opH(phi(psi(y)), x)
                [by rewrite x-is-an-image products-in-h-agree]
              @conclusion-h-commutes |
                opH(x, y) = opH(y, x)
                [by rewrite y-is-an-image x-replaces-its-image]
            }
          @discharge-y |
            forall y: H; opH(x, y) = opH(y, x)
            [by generalize generalize-y]
        }
      @h-is-abelian |
        forall x, y: H; opH(x, y) = opH(y, x)
        [by generalize generalize-x]
    }
  @conclusion |
    (forall a, b: G; opG(a, b) = opG(b, a)) -> (forall x, y: H; opH(x, y) = opH(y, x))
    [by discharge given-g-abelian]
qed
```

## Theorem 9.7 — infinite cyclic groups

**Theorem 9.7.** All cyclic groups of infinite order are isomorphic to $\mathbb{Z}$.

**Proof.** Let $G$ be a cyclic group with infinite order and suppose that $a$ is a
generator of $G$. Define a map $\phi : \mathbb{Z} \rightarrow G$ by
$\phi : n \mapsto a^n$. Then
$$\phi(m + n) = a^{m+n} = a^m a^n = \phi(m)\phi(n).$$
To show that $\phi$ is injective, suppose that $m$ and $n$ are two elements in
$\mathbb{Z}$ with $m \neq n$; we may assume $m > n$. We must show that
$a^m \neq a^n$. Suppose to the contrary that $a^m = a^n$; then $a^{m-n} = e$ with
$m - n > 0$, contradicting that $a$ has infinite order. $\blacksquare$

The map is the exponent $n \mapsto a^n$. Operation-preservation is the exponent law:

```2b4m
theorem theExponentMapPreservesTheOperation: forall a: Cyc; forall m, n: Int;
  opCyc(power(a, m), power(a, n)) = power(a, add(m, n))
proof
  @conclusion |
    forall a: Cyc; forall m, n: Int;
      opCyc(power(a, m), power(a, n)) = power(a, add(m, n))
    [by cite powerAdd]
qed
```

And injectivity: for a generator of infinite order, equal powers force equal
exponents.

> NB: This theorem exists in std in `std/group/generated.b4m:1265:equalPowersHaveEqualExponents`.

```2b4m
theorem theExponentMapIsInjective: forall a: Cyc; hasInfiniteOrder(a) ->
  forall s, t: Int; power(a, s) = power(a, t) -> s = t
proof
  @conclusion |
    forall a: Cyc; hasInfiniteOrder(a) ->
      forall s, t: Int; power(a, s) = power(a, t) -> s = t
    [by cite equalPowersHaveEqualExponents]
qed
```

> *There is no sort of groups here, so the relation $\cong$ cannot be named: a group is
> a sort with operations and axioms, not a value to quantify over. Every instance of
> $G \cong H$ is provable — as the halves of the bijection above — but the restatement
> "hence $G \cong \mathbb{Z}$" has no form.*

## Theorem 9.8 and Corollary 9.9 — finite cyclic groups

**Theorem 9.8.** If $G$ is a cyclic group of order $n$, then $G$ is isomorphic to
$\mathbb{Z}_n$.

**Proof.** Let $G$ be a cyclic group of order $n$ generated by $a$ and define a map
$\phi : \mathbb{Z}_n \rightarrow G$ by $\phi : k \mapsto a^k$, where
$0 \leq k < n$. The proof that $\phi$ is an isomorphism is one of the end-of-chapter
exercises. $\blacksquare$

**Corollary 9.9.** If $G$ is a group of order $p$, where $p$ is a prime number, then
$G$ is isomorphic to $\mathbb{Z}_p$.

**Proof.** The proof is a direct result of Corollary 6.11. $\blacksquare$

> *Both are stated over $\mathbb{Z}_n$ for a varying modulus $n$, and our $\mathbb{Z}_n$
> has a single fixed modulus, so "for every $n$" has no form here. The exponent map above
> is the map Theorem 9.8 uses.*

## Isomorphism is an equivalence relation

**Theorem 9.10.** The isomorphism of groups determines an equivalence relation on the
class of all groups.

Judson leaves the proof as an exercise. Each of its three parts is settled by
exhibiting the witness that makes the relation hold: the identity map for
reflexivity, $\phi^{-1}$ for symmetry, and $\chi \circ \phi$ for transitivity.

> NB: This theorem exists in std in `std/group/isomorphism.b4m:662:reflexivityOfIsomorphism`.
>
> NB: This theorem exists in std in `std/group/isomorphism.b4m:631:symmetryOfIsomorphism`.
>
> NB: This theorem exists in std in `std/group/isomorphism.b4m:754:transitivityOfIsomorphism`.

```2b4m
// G ≅ G: the identity map preserves the operation and is its own inverse
theorem reflexivityOfIsomorphism:
  (forall a, b: G; idG(opG(a, b)) = opG(idG(a), idG(b)))
  and (forall a: G; idG(idG(a)) = a)
proof
  @preserves |
    forall a, b: G; idG(opG(a, b)) = opG(idG(a), idG(b))
    [by generalize preserves-at-a]
  @preserves-at-a |
    fix a: G {
      @inner-b |
        fix b: G {
          @id-at-the-product |
            idG(opG(a, b)) = opG(a, b)
            [using specialize idGApply(opG(a, b))]
          @id-at-a |
            idG(a) = a
            [using specialize idGApply(a)]
          @id-at-b |
            idG(b) = b
            [using specialize idGApply(b)]
          @right-side-at-a |
            opG(idG(a), idG(b)) = opG(a, idG(b))
            [by rewrite id-at-a reflexivity-right]
          @reflexivity-right |
            opG(idG(a), idG(b)) = opG(idG(a), idG(b))
            [by reflexivity]
          @right-side |
            opG(idG(a), idG(b)) = opG(a, b)
            [by rewrite id-at-b right-side-at-a]
          @conclusion-preserves-at-b |
            idG(opG(a, b)) = opG(idG(a), idG(b))
            [using chain id-at-the-product right-side-flipped]
          @right-side-flipped |
            opG(a, b) = opG(idG(a), idG(b))
            [by symmetry right-side]
        }
      @discharge-b |
        forall b: G; idG(opG(a, b)) = opG(idG(a), idG(b))
        [by generalize inner-b]
    }
  @round-trip |
    forall a: G; idG(idG(a)) = a
    [by generalize round-trip-at-a]
  @round-trip-at-a |
    fix a: G {
      @outer |
        idG(idG(a)) = idG(a)
        [using specialize idGApply(idG(a))]
      @inner |
        idG(a) = a
        [using specialize idGApply(a)]
      @conclusion-round-trip |
        idG(idG(a)) = a
        [using chain outer inner]
    }
  @conclusion |
    (forall a, b: G; idG(opG(a, b)) = opG(idG(a), idG(b)))
      and (forall a: G; idG(idG(a)) = a)
    [by both preserves round-trip]
qed

// G ≅ H ⟹ H ≅ G: ψ is the witness — it preserves the operation, and the two round
// trips are the SAME axioms read with the roles swapped
theorem symmetryOfIsomorphism:
  (forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y)))
  and (forall b: H; phi(psi(b)) = b)
  and (forall a: G; psi(phi(a)) = a)
proof
  @psi-preserves |
    forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y))
    [by cite psiPreservesOp]
  @phi-after-psi |
    forall b: H; phi(psi(b)) = b
    [by cite phiAfterPsi]
  @psi-after-phi |
    forall a: G; psi(phi(a)) = a
    [by cite psiAfterPhi]
  @preserves-and-forward |
    (forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y)))
      and (forall b: H; phi(psi(b)) = b)
    [by both psi-preserves phi-after-psi]
  @conclusion |
    (forall x, y: H; psi(opH(x, y)) = opG(psi(x), psi(y)))
      and (forall b: H; phi(psi(b)) = b)
      and (forall a: G; psi(phi(a)) = a)
    [by both preserves-and-forward psi-after-phi]
qed

// G ≅ H and H ≅ K ⟹ G ≅ K: χ∘φ preserves the operation and both round trips close
// via ψ∘χ⁻¹. This needs a THIRD group, so K and a second isomorphism are declared.
theorem transitivityOfIsomorphism:
  (forall a, b: G; chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b))))
  and (forall a: G; psi(chiInv(chi(phi(a)))) = a)
  and (forall z: K; chi(phi(psi(chiInv(z)))) = z)
proof
  @composite-preserves |
    forall a, b: G; chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b)))
    [by generalize preserves-at-a]
  @preserves-at-a |
    fix a: G {
      @inner-b |
        fix b: G {
          @phi-splits |
            phi(opG(a, b)) = opH(phi(a), phi(b))
            [using specialize phiPreservesOp(a, b)]
          @chi-splits |
            chi(opH(phi(a), phi(b))) = opK(chi(phi(a)), chi(phi(b)))
            [using specialize chiPreservesOp(phi(a), phi(b))]
          @conclusion-composite-at-b |
            chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b)))
            [by rewrite phi-splits chi-splits]
        }
      @discharge-b |
        forall b: G; chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b)))
        [by generalize inner-b]
    }
  // the composite's inverse is ψ∘χ⁻¹, and the round trip collapses one layer at a time
  @composite-round-trip |
    forall a: G; psi(chiInv(chi(phi(a)))) = a
    [by generalize round-trip-at-a]
  @round-trip-at-a |
    fix a: G {
      @chi-cancels |
        chiInv(chi(phi(a))) = phi(a)
        [using specialize chiInvAfterChi(phi(a))]
      @psi-at-the-inner |
        psi(chiInv(chi(phi(a)))) = psi(phi(a))
        [by rewrite chi-cancels psi-reflexivity]
      @psi-reflexivity |
        psi(chiInv(chi(phi(a)))) = psi(chiInv(chi(phi(a))))
        [by reflexivity]
      @psi-cancels |
        psi(phi(a)) = a
        [using specialize psiAfterPhi(a)]
      @conclusion-round-trip-at-a |
        psi(chiInv(chi(phi(a)))) = a
        [using chain psi-at-the-inner psi-cancels]
    }
  // the other direction: (χ∘φ)∘(ψ∘χ⁻¹) = id on K
  @composite-round-trip-back |
    forall z: K; chi(phi(psi(chiInv(z)))) = z
    [by generalize back-at-z]
  @back-at-z |
    fix z: K {
      @phi-cancels-psi |
        phi(psi(chiInv(z))) = chiInv(z)
        [using specialize phiAfterPsi(chiInv(z))]
      @chi-reflexivity |
        chi(phi(psi(chiInv(z)))) = chi(phi(psi(chiInv(z))))
        [by reflexivity]
      @chi-at-the-inner |
        chi(phi(psi(chiInv(z)))) = chi(chiInv(z))
        [by rewrite phi-cancels-psi chi-reflexivity]
      @chi-cancels-back |
        chi(chiInv(z)) = z
        [using specialize chiAfterChiInv(z)]
      @conclusion-back-at-z |
        chi(phi(psi(chiInv(z)))) = z
        [using chain chi-at-the-inner chi-cancels-back]
    }
  @preserves-and-forward-trip |
    (forall a, b: G; chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b))))
      and (forall a: G; psi(chiInv(chi(phi(a)))) = a)
    [by both composite-preserves composite-round-trip]
  @conclusion |
    (forall a, b: G; chi(phi(opG(a, b))) = opK(chi(phi(a)), chi(phi(b))))
      and (forall a: G; psi(chiInv(chi(phi(a)))) = a)
      and (forall z: K; chi(phi(psi(chiInv(z)))) = z)
    [by both preserves-and-forward-trip composite-round-trip-back]
qed
```

## Cayley's Theorem

**Theorem 9.12 (Cayley).** Every group is isomorphic to a group of permutations.

**Proof.** Let $G$ be a group. We must find a group of permutations $\overline{G}$ that is
isomorphic to $G$. For any $g \in G$, define a function
$\lambda_g : G \rightarrow G$ by $\lambda_g(a) = ga$. We claim that $\lambda_g$ is a
permutation of $G$. To show that $\lambda_g$ is one-to-one, suppose that
$\lambda_g(a) = \lambda_g(b)$. Then
$$ga =\lambda_g(a) = \lambda_g(b) = gb.$$
Hence, $a = b$. To show that $\lambda_g$ is onto, we must prove that for each $a \in G$,
there is a $b$ such that $\lambda_g (b) = a$. Let $b = g^{-1} a$.

Now we are ready to define our group $\overline{G}$. Let
$$\overline{G} = \{ \lambda_g : g \in G \}.$$
We must show that $\overline{G}$ is a group under composition of functions and find an
isomorphism between $G$ and $\overline{G}$. We have closure under composition of functions
since
$$(\lambda_g \circ \lambda_h )(a) = \lambda_g(ha) = gha = \lambda_{gh} (a).$$
Also,
$$\lambda_e (a) = ea = a$$
and
$$(\lambda_{g^{-1}} \circ \lambda_g) (a) = \lambda_{g^{-1}} (ga) = g^{-1} g a = a = \lambda_e (a).$$
We can define an isomorphism from $G$ to $\overline{G}$ by $\phi : g \mapsto \lambda_g$.
The group operation is preserved since
$$\phi(gh) = \lambda_{gh} = \lambda_g \lambda_h = \phi(g) \phi(h).$$
It is also one-to-one, because if $\phi(g)(a) = \phi(h)(a)$, then
$$ga = \lambda_g a = \lambda_h a = ha.$$
Hence, $g = h$. That $\phi$ is onto follows from the fact that $\phi( g ) = \lambda_g$ for
any $\lambda_g \in \overline{G}$. $\blacksquare$

> *Our theory of maps acts on one fixed element sort, so it cannot represent
> permutations of an abstract $G$; the permutations of $G$ are declared here as their own
> sort, with application, composition and extensionality.*

```2b4m
// Judson's argument: "suppose that lambda_g(a) = lambda_g(b). Then
// ga = lambda_g(a) = lambda_g(b) = gb. Hence, a = b." The cancellation is spelled out --
// left-multiply by g^-1, reassociate, and the inverse pair collapses to the identity.
theorem leftTranslationIsInjective: forall g, a, b: G; opG(g, a) = opG(g, b) -> a = b
proof
  @generalize-g |
    fix g: G {
      @generalize-a |
        fix a: G {
          @generalize-b |
            fix b: G {
              @given-equal |
                assume opG(g, a) = opG(g, b) {
                  @ga-is-gb |
                    opG(g, a) = opG(g, b)
                    [by hypothesis given-equal]
                  // left-multiply both sides by g⁻¹
                  @left-refl |
                    opG(invG(g), opG(g, a)) = opG(invG(g), opG(g, a))
                    [by reflexivity]
                  @left-multiplied |
                    opG(invG(g), opG(g, a)) = opG(invG(g), opG(g, b))
                    [by rewrite ga-is-gb left-refl]
                  // (g⁻¹g)a = g⁻¹(ga), and g⁻¹g = e, so the left side is ea = a
                  @assoc-a |
                    opG(opG(invG(g), g), a) = opG(invG(g), opG(g, a))
                    [using specialize opGAssoc(invG(g), g, a)]
                  @inv-collapses |
                    opG(invG(g), g) = eG
                    [using specialize opGInverseLeft(g)]
                  @e-a-is-left |
                    opG(eG, a) = opG(invG(g), opG(g, a))
                    [by rewrite inv-collapses assoc-a]
                  @e-a-is-a |
                    opG(eG, a) = a
                    [using specialize opGIdentityLeft(a)]
                  @a-is-left |
                    a = opG(invG(g), opG(g, a))
                    [using chain e-a-is-a-flipped e-a-is-left]
                  @e-a-is-a-flipped |
                    a = opG(eG, a)
                    [by symmetry e-a-is-a]
                  // the same on the right, for b
                  @assoc-b |
                    opG(opG(invG(g), g), b) = opG(invG(g), opG(g, b))
                    [using specialize opGAssoc(invG(g), g, b)]
                  @e-b-is-right |
                    opG(eG, b) = opG(invG(g), opG(g, b))
                    [by rewrite inv-collapses assoc-b]
                  @e-b-is-b |
                    opG(eG, b) = b
                    [using specialize opGIdentityLeft(b)]
                  @right-is-b |
                    opG(invG(g), opG(g, b)) = b
                    [using chain e-b-is-right-flipped e-b-is-b]
                  @e-b-is-right-flipped |
                    opG(invG(g), opG(g, b)) = opG(eG, b)
                    [by symmetry e-b-is-right]
                  @conclusion-a-is-b |
                    a = b
                    [using chain a-is-left left-multiplied right-is-b]
                }
              @conclusion-at-b |
                opG(g, a) = opG(g, b) -> a = b
                [by discharge given-equal]
            }
          @conclusion-for-all-b |
            forall b: G; opG(g, a) = opG(g, b) -> a = b
            [by generalize generalize-b]
        }
      @conclusion-for-all-a |
        forall a, b: G; opG(g, a) = opG(g, b) -> a = b
        [by generalize generalize-a]
    }
  @conclusion |
    forall g, a, b: G; opG(g, a) = opG(g, b) -> a = b
    [by generalize generalize-g]
qed
theorem leftTranslationIsSurjective: forall g, a: G; exists b: G; opG(g, b) = a
proof
  @generalize-g |
    fix g: G {
      @generalize-a |
        fix a: G {
          // g(g⁻¹a) = (gg⁻¹)a = ea = a
          @regroup |
            opG(opG(g, invG(g)), a) = opG(g, opG(invG(g), a))
            [using specialize opGAssoc(g, invG(g), a)]
          @inverse-right-in-g |
            forall x: G; opG(x, invG(x)) = eG
            [using model(GIsAGroup) group.opInverseRight]
          @g-times-its-inverse |
            opG(g, invG(g)) = eG
            [using specialize inverse-right-in-g(g)]
          @identity-times-a |
            opG(eG, a) = opG(g, opG(invG(g), a))
            [by rewrite g-times-its-inverse regroup]
          @identity-left-at-a |
            opG(eG, a) = a
            [using specialize opGIdentityLeft(a)]
          @translation-hits-a |
            a = opG(g, opG(invG(g), a))
            [by rewrite identity-left-at-a identity-times-a]
          @translation-hits-a-flipped |
            opG(g, opG(invG(g), a)) = a
            [by symmetry translation-hits-a]
          @conclusion-preimage |
            exists b: G; opG(g, b) = a
            [by witness(opG(invG(g), a)) translation-hits-a-flipped]
        }
      @discharge-a |
        forall a: G; exists b: G; opG(g, b) = a
        [by generalize generalize-a]
    }
  @conclusion |
    forall g, a: G; exists b: G; opG(g, b) = a
    [by generalize generalize-g]
qed
```

```2b4m
theorem cayleyPreservesOp: forall g, h: G; lam(opG(g, h)) = composeP(lam(g), lam(h))
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @pointwise |
            forall a: G; applyP(lam(opG(g, h)), a) = applyP(composeP(lam(g), lam(h)), a)
            [by generalize agree-at-a]
          @agree-at-a |
            fix a: G {
              @left-side |
                applyP(lam(opG(g, h)), a) = opG(opG(g, h), a)
                [using specialize lamApply(opG(g, h), a)]
              @split |
                applyP(composeP(lam(g), lam(h)), a) = applyP(lam(g), applyP(lam(h), a))
                [using specialize composeApplyP(lam(g), lam(h), a)]
              @inner |
                applyP(lam(h), a) = opG(h, a)
                [using specialize lamApply(h, a)]
              @outer |
                applyP(lam(g), opG(h, a)) = opG(g, opG(h, a))
                [using specialize lamApply(g, opG(h, a))]
              @split-at-inner |
                applyP(composeP(lam(g), lam(h)), a) = applyP(lam(g), opG(h, a))
                [by rewrite inner split]
              @right-side |
                applyP(composeP(lam(g), lam(h)), a) = opG(g, opG(h, a))
                [using chain split-at-inner outer]
              @assoc |
                opG(opG(g, h), a) = opG(g, opG(h, a))
                [using specialize opGAssoc(g, h, a)]
              @left-is-assoc |
                applyP(lam(opG(g, h)), a) = opG(g, opG(h, a))
                [using chain left-side assoc]
              @conclusion-agree |
                applyP(lam(opG(g, h)), a) = applyP(composeP(lam(g), lam(h)), a)
                [using chain left-is-assoc right-side]
            }
          @conclusion-equal |
            lam(opG(g, h)) = composeP(lam(g), lam(h))
            [using specialize permExtensionality(lam(opG(g, h)), composeP(lam(g), lam(h))) pointwise]
        }
      @discharge-h |
        forall h: G; lam(opG(g, h)) = composeP(lam(g), lam(h))
        [by generalize generalize-h]
    }
  @conclusion |
    forall g, h: G; lam(opG(g, h)) = composeP(lam(g), lam(h))
    [by generalize generalize-g]
qed
theorem cayleyIsInjective: forall g, h: G; lam(g) = lam(h) -> g = h
proof
  @generalize-g |
    fix g: G {
      @generalize-h |
        fix h: G {
          @given-same-translation |
            assume lam(g) = lam(h) {
              @same-translation |
                lam(g) = lam(h)
                [by hypothesis given-same-translation]
              // G's right identity, transferred through GIsAGroup
              @identity-right-in-g |
                forall x: G; opG(x, eG) = x
                [using model(GIsAGroup) group.opIdentityRight]
              // apply both to the identity: lam(g)(e) = g·e = g
              @g-at-identity |
                applyP(lam(g), eG) = opG(g, eG)
                [using specialize lamApply(g, eG)]
              @h-at-identity |
                applyP(lam(h), eG) = opG(h, eG)
                [using specialize lamApply(h, eG)]
              @g-times-identity |
                opG(g, eG) = g
                [using specialize identity-right-in-g(g)]
              @h-times-identity |
                opG(h, eG) = h
                [using specialize identity-right-in-g(h)]
              @g-is-its-value |
                applyP(lam(g), eG) = g
                [using chain g-at-identity g-times-identity]
              @h-is-its-value |
                applyP(lam(h), eG) = h
                [using chain h-at-identity h-times-identity]
              @values-agree |
                applyP(lam(h), eG) = g
                [by rewrite same-translation g-is-its-value]
              @conclusion-equal |
                g = h
                [using chain values-agree h-is-its-value]
            }
          @discharge |
            lam(g) = lam(h) -> g = h
            [by discharge given-same-translation]
        }
      @discharge-h |
        forall h: G; lam(g) = lam(h) -> g = h
        [by generalize generalize-h]
    }
  @conclusion |
    forall g, h: G; lam(g) = lam(h) -> g = h
    [by generalize generalize-g]
qed
```
