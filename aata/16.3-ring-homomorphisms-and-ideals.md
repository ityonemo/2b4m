# Ring Homomorphisms and Ideals

A literate `2b4m` transliteration of **Chapter 16 ("Rings"), §16.3 "Ring Homomorphisms and
Ideals"** of Thomas W. Judson's *Abstract Algebra: Theory and Applications* (source:
`vendor/aata/src/rings.xml`, lines 650–1045; © 1997–2026 Judson, GFDL 1.3). Run
`2b4m check aata/16.3-ring-homomorphisms-and-ideals.md` to verify.

In the study of groups, a homomorphism is a map that preserves the operation of the group.
Similarly, a homomorphism between rings preserves the operations of addition and
multiplication in the ring. More specifically, if $R$ and $S$ are rings, then a **ring
homomorphism** is a map $\phi : R \rightarrow S$ satisfying
$$\begin{aligned} \phi( a + b ) &= \phi( a ) + \phi(b) \\ \phi( a b ) &= \phi( a ) \phi(b) \end{aligned}$$
for all $a, b \in R$. If $\phi : R \rightarrow S$ is a one-to-one and onto homomorphism,
then $\phi$ is called an **isomorphism** of rings.

> *Two rings are needed at once, so each is its own copy of `std/ring.b4m`'s theory — the
> source ring $R$ and the target ring $S$, with their own zero, addition and multiplication.
> $\phi$ is a function symbol between the two carriers.*

```2b4m
import ring <<< "std/ring.b4m"
import target <<< "std/ring.b4m"

// the source ring R
sort R = ring.Ring
const zeroR = ring.ZERO
func addR = ring.add
func mulR = ring.mul
func negR = ring.neg
fact addNegRightR = ring.addNegRight
fact mulAddDistribLeftR = ring.mulAddDistribLeft
fact mulAddDistribRightR = ring.mulAddDistribRight
fact addIsAssociativeR = ring.addIsAssociative
fact addZeroLeftR = ring.addZeroLeft

// the target ring S — a SECOND instance of the same theory
sort S = target.Ring
const zeroS = target.ZERO
func addS = target.add
func mulS = target.mul
fact mulZeroLeftS = target.mulZeroLeft
fact mulZeroRightS = target.mulZeroRight
fact addZeroLeftS = target.addZeroLeft

// the homomorphism, with Judson's two conditions
func phi(a: R) => S
axiom phiPreservesAddition: forall a, b: R; phi(addR(a, b)) = addS(phi(a), phi(b))
axiom phiPreservesMultiplication: forall a, b: R; phi(mulR(a, b)) = mulS(phi(a), phi(b))
```

The set of elements that a ring homomorphism maps to $0$ plays a fundamental role in the
theory of rings. For any ring homomorphism $\phi : R \rightarrow S$, we define the **kernel**
of a ring homomorphism to be the set
$$\ker \phi = \{ r \in R : \phi( r ) = 0 \}.$$

```2b4m
// the kernel, as a membership predicate on R (there is no sort of subsets of a ring)
define inKernel(r) = phi(r) = zeroS
```

**Example.** For any integer $n$ we can define a ring homomorphism
$\phi : \mathbb{Z} \rightarrow \mathbb{Z}_n$ by $a \mapsto a \pmod{n}$. This is indeed a ring
homomorphism, since
$$\begin{aligned} \phi( a + b ) &= (a + b) \pmod{n} \\ &= a \pmod{n} + b \pmod{n} \\ &= \phi( a ) + \phi(b) \end{aligned}$$
and
$$\begin{aligned} \phi( a b ) &= ab \pmod{n} \\ &= a \pmod{n}\cdot b \pmod{n} \\ &= \phi( a ) \phi(b) \end{aligned}$$
The kernel of the homomorphism $\phi$ is $n\mathbb{Z}$.

**Example.** Let $C[a, b]$ be the ring of continuous real-valued functions on an interval
$[a,b]$ as in §16.1. For a fixed $\alpha \in [a, b]$, we can define a ring homomorphism
$\phi_{\alpha} : C[a, b] \rightarrow \mathbb{R}$ by $\phi_{\alpha}(f) = f(\alpha)$. This is
a ring homomorphism since
$$\begin{aligned}
\phi_{\alpha}( f + g ) = (f + g)( \alpha) = f(\alpha) + g(\alpha) = \phi_{\alpha}( f ) + \phi_{\alpha}(g) \\
\phi_{\alpha}( f g ) = (f g)( \alpha) = f(\alpha) g(\alpha) = \phi_{\alpha}( f ) \phi_{\alpha}(g)
\end{aligned}$$
Ring homomorphisms of the type $\phi_{\alpha}$ are called **evaluation homomorphisms**.

> *The second example is the function ring of §16.1, which we did not construct.*

In the next proposition we will examine some fundamental properties of ring homomorphisms.
The proof of the proposition is left as an exercise.

## Proposition 16.8

> Let $\phi : R \rightarrow S$ be a ring homomorphism.
>
> 1. If $R$ is a commutative ring, then $\phi(R)$ is a commutative ring.
> 2. $\phi(0) = 0$.
> 3. Let $1_R$ and $1_S$ be the identities for $R$ and $S$, respectively. If $\phi$ is onto,
>    then $\phi(1_R) = 1_S$.
> 4. If $R$ is a field and $\phi(R) \neq \{0\}$, then $\phi(R)$ is a field.

> Judson's text leaves this proof as an exercise:

**Proof.** Part (2) is the one part expressible without a sort of subsets: $\phi(0 + 0) =
\phi(0) + \phi(0)$ and $0 + 0 = 0$, so $\phi(0) = \phi(0) + \phi(0)$ and cancelling gives
$\phi(0) = 0$. Parts (1), (3) and (4) all quantify over the image $\phi(R)$ as a ring in its
own right, which needs a subring carrying its own structure.

```2b4m
import group <<< "std/group.b4m"

// (2) φ(0) = 0 — the additive-group argument, which is all this part needs.
theorem phiSendsZeroToZero: phi(zeroR) = zeroS
proof
  @preserves-addition |
    forall a, b: R; phi(addR(a, b)) = addS(phi(a), phi(b))
    [by cite phiPreservesAddition]
  @zero-plus-zero |
    addR(zeroR, zeroR) = zeroR
    [using specialize addZeroLeftR(zeroR)]
  // φ(0 + 0) = φ(0) + φ(0)
  @phi-of-the-sum |
    phi(addR(zeroR, zeroR)) = addS(phi(zeroR), phi(zeroR))
    [using specialize preserves-addition(zeroR, zeroR)]
  // so φ(0) = φ(0) + φ(0)
  @phi-zero-doubles |
    phi(zeroR) = addS(phi(zeroR), phi(zeroR))
    [by rewrite zero-plus-zero phi-of-the-sum]
  // cancel: write the left as 0 + φ(0) and cancel φ(0) off the right
  @left-as-zero-plus |
    addS(zeroS, phi(zeroR)) = phi(zeroR)
    [using specialize addZeroLeftS(phi(zeroR))]
  @zero-plus-equals-doubled |
    addS(zeroS, phi(zeroR)) = addS(phi(zeroR), phi(zeroR))
    [by rewrite phi-zero-doubles left-as-zero-plus]
  @cancel-right |
    forall b, x, c: S; addS(b, x) = addS(c, x) -> b = c
    [using model(target.AdditiveGroup) group.cancelRight]
  @zero-is-phi-zero |
    zeroS = phi(zeroR)
    [using specialize cancel-right(zeroS, phi(zeroR), phi(zeroR)) zero-plus-equals-doubled]
  @conclusion |
    phi(zeroR) = zeroS
    [by symmetry zero-is-phi-zero]
qed
```

In group theory we found that normal subgroups play a special role. These subgroups have
nice characteristics that make them more interesting to study than arbitrary subgroups. In
ring theory the objects corresponding to normal subgroups are a special class of subrings
called ideals. An **ideal** in a ring $R$ is a subring $I$ of $R$ such that if $a$ is in $I$
and $r$ is in $R$, then both $ar$ and $ra$ are in $I$; that is, $rI \subset I$ and
$Ir \subset I$ for all $r \in R$.

```2b4m
// An ideal: §16.1's subring conditions plus Judson's two absorption conditions. As there,
// a membership predicate stands in for the subset.
pred inIdeal(r: R)
axiom idealIsNonempty: exists r: R; inIdeal(r)
axiom idealClosedUnderSub: forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, negR(b)))
axiom idealAbsorbsOnTheRight: forall a, r: R; inIdeal(a) -> inIdeal(mulR(a, r))
axiom idealAbsorbsOnTheLeft: forall a, r: R; inIdeal(a) -> inIdeal(mulR(r, a))

// an ideal contains 0 and is closed under negation and addition — the §16.1 argument,
// which the absorption conditions do not change.
theorem anIdealContainsZero: inIdeal(zeroR)
proof
  @closed-under-subtraction |
    forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, negR(b)))
    [by cite idealClosedUnderSub]
  @the-ideal-is-nonempty |
    exists r: R; inIdeal(r)
    [by cite idealIsNonempty]
  @with-a-member-r |
    unpack r: R from the-ideal-is-nonempty {
      @r-is-a-member |
        inIdeal(r)
        [by hypothesis with-a-member-r]
      @r-minus-r-is-a-member |
        inIdeal(addR(r, negR(r)))
        [using specialize closed-under-subtraction(r, r) r-is-a-member r-is-a-member]
      @r-minus-r-is-zero |
        addR(r, negR(r)) = zeroR
        [using specialize addNegRightR(r)]
      @conclusion-zero-is-a-member |
        inIdeal(zeroR)
        [by rewrite r-minus-r-is-zero r-minus-r-is-a-member]
    }
  @conclusion |
    inIdeal(zeroR)
    [by unpacked with-a-member-r]
qed
```

**Example.** Every ring $R$ has at least two ideals, $\{0\}$ and $R$. These ideals are
called the **trivial ideals**.

Let $R$ be a ring with identity and suppose that $I$ is an ideal in $R$ such that $1$ is in
$I$. Since for any $r \in R$, $r1 = r \in I$ by the definition of an ideal, $I = R$.

```2b4m
const oneR = ring.ONE
axiom oneIsAnIdentityR: forall a: R; mulR(oneR, a) = a and mulR(a, oneR) = a

// Judson's one-line argument: if 1 ∈ I then every r = r·1 is in I, so I is everything.
theorem anIdealContainingOneIsEverything: inIdeal(oneR) -> forall r: R; inIdeal(r)
proof
  @absorbs-on-the-right |
    forall a, r: R; inIdeal(a) -> inIdeal(mulR(a, r))
    [by cite idealAbsorbsOnTheRight]
  @one-is-an-identity |
    forall a: R; mulR(oneR, a) = a and mulR(a, oneR) = a
    [by cite oneIsAnIdentityR]
  @given-one-is-in |
    assume inIdeal(oneR) {
      @one-is-a-member |
        inIdeal(oneR)
        [by hypothesis given-one-is-in]
      @generalize-r |
        fix r: R {
          // 1·r is in I because 1 is, and 1·r = r
          @one-times-r-is-a-member |
            inIdeal(mulR(oneR, r))
            [using specialize absorbs-on-the-right(oneR, r) one-is-a-member]
          @identity-at-r |
            mulR(oneR, r) = r and mulR(r, oneR) = r
            [by apply_at(r) one-is-an-identity]
          @one-times-r-is-r |
            mulR(oneR, r) = r
            [by and_lhs identity-at-r]
          @conclusion-r-is-a-member |
            inIdeal(r)
            [by rewrite one-times-r-is-r one-times-r-is-a-member]
        }
      @conclusion-everything-is-in |
        forall r: R; inIdeal(r)
        [by generalize generalize-r]
    }
  @conclusion |
    inIdeal(oneR) -> forall r: R; inIdeal(r)
    [by discharge given-one-is-in]
qed
```

**Example.** If $a$ is any element in a commutative ring $R$ with identity, then the set
$$\langle a \rangle = \{ ar : r \in R \}$$
is an ideal in $R$. Certainly, $\langle a \rangle$ is nonempty since both $0 = a0$ and
$a = a1$ are in $\langle a \rangle$. The sum of two elements in $\langle a \rangle$ is again
in $\langle a \rangle$ since $ar + ar' = a(r + r')$. The inverse of $ar$ is
$-ar = a(-r) \in \langle a \rangle$. Finally, if we multiply an element
$ar \in \langle a \rangle$ by an arbitrary element $s \in R$, we have $s(ar) = a(sr)$.
Therefore, $\langle a \rangle$ satisfies the definition of an ideal.

If $R$ is a commutative ring with identity, then an ideal of the form
$\langle a \rangle = \{ ar : r \in R \}$ is called a **principal ideal**.

```2b4m
// ⟨a⟩ for a fixed generator: "the multiples of a". Judson verifies the ideal conditions
// for it, and each of his verifications is a theorem below.
const gen: R
define inPrincipal(x) = exists r: R; x = mulR(gen, r)

// "Certainly ⟨a⟩ is nonempty since both 0 = a0 and a = a1 are in ⟨a⟩."
theorem thePrincipalIdealIsNonempty: exists x: R; inPrincipal(x)
proof
  @a-times-one-is-a |
    mulR(gen, oneR) = gen
    [using tautology identity-at-gen]
  @identity-at-gen |
    mulR(oneR, gen) = gen and mulR(gen, oneR) = gen
    [using specialize oneIsAnIdentityR(gen)]
  @a-is-a-multiple-flipped |
    gen = mulR(gen, oneR)
    [by symmetry a-times-one-is-a]
  @a-is-a-multiple |
    exists r: R; gen = mulR(gen, r)
    [by witness(oneR) a-is-a-multiple-flipped]
  @conclusion |
    exists x: R; inPrincipal(x)
    [by witness(gen) a-is-a-multiple]
qed

// "The sum of two elements in ⟨a⟩ is again in ⟨a⟩ since ar + ar' = a(r + r')."
theorem thePrincipalIdealIsClosedUnderAddition:
  forall x, y: R; inPrincipal(x) -> inPrincipal(y) -> inPrincipal(addR(x, y))
proof
  @distributes |
    forall a, b, c: R; mulR(a, addR(b, c)) = addR(mulR(a, b), mulR(a, c))
    [by cite mulAddDistribLeftR]
  @generalize-x |
    fix x: R {
      @generalize-y |
        fix y: R {
          @given-x-is-a-multiple |
            assume inPrincipal(x) {
              @given-y-is-a-multiple |
                assume inPrincipal(y) {
                  @x-is-a-multiple |
                    exists r: R; x = mulR(gen, r)
                    [by hypothesis given-x-is-a-multiple]
                  @y-is-a-multiple |
                    exists r: R; y = mulR(gen, r)
                    [by hypothesis given-y-is-a-multiple]
                  @with-the-cofactor-r |
                    unpack r: R from x-is-a-multiple {
                      @x-is-a-r |
                        x = mulR(gen, r)
                        [by hypothesis with-the-cofactor-r]
                      @with-the-cofactor-s |
                        unpack s: R from y-is-a-multiple {
                          @y-is-a-s |
                            y = mulR(gen, s)
                            [by hypothesis with-the-cofactor-s]
                          // ar + as = a(r + s)
                          @the-distributed-sum |
                            mulR(gen, addR(r, s)) = addR(mulR(gen, r), mulR(gen, s))
                            [using specialize distributes(gen, r, s)]
                          @sum-is-the-distributed |
                            addR(mulR(gen, r), mulR(gen, s)) = mulR(gen, addR(r, s))
                            [by symmetry the-distributed-sum]
                          @x-plus-y-with-r |
                            addR(x, mulR(gen, s)) = mulR(gen, addR(r, s))
                            [by rewrite x-is-a-r sum-is-the-distributed]
                          @x-plus-y-is-a-multiple |
                            addR(x, y) = mulR(gen, addR(r, s))
                            [by rewrite y-is-a-s x-plus-y-with-r]
                          @conclusion-sum-is-in |
                            exists t: R; addR(x, y) = mulR(gen, t)
                            [by witness(addR(r, s)) x-plus-y-is-a-multiple]
                        }
                      @conclusion-from-s |
                        exists t: R; addR(x, y) = mulR(gen, t)
                        [by unpacked with-the-cofactor-s]
                    }
                  @conclusion-sum-in-the-ideal |
                    inPrincipal(addR(x, y))
                    [by unpacked with-the-cofactor-r]
                }
              @conclusion-after-y |
                inPrincipal(y) -> inPrincipal(addR(x, y))
                [by discharge given-y-is-a-multiple]
            }
          @conclusion-after-x |
            inPrincipal(x) -> inPrincipal(y) -> inPrincipal(addR(x, y))
            [by discharge given-x-is-a-multiple]
        }
      @conclusion-for-y |
        forall y: R; inPrincipal(x) -> inPrincipal(y) -> inPrincipal(addR(x, y))
        [by generalize generalize-y]
    }
  @conclusion |
    forall x, y: R; inPrincipal(x) -> inPrincipal(y) -> inPrincipal(addR(x, y))
    [by generalize generalize-x]
qed

// "Finally, if we multiply an element ar ∈ ⟨a⟩ by an arbitrary element s ∈ R, we have
// s(ar) = a(sr)." — absorption, which needs commutativity, as Judson's "commutative ring"
// hypothesis supplies.
theorem thePrincipalIdealAbsorbs: (forall a, b: R; mulR(a, b) = mulR(b, a)) ->
  forall x, s: R; inPrincipal(x) -> inPrincipal(mulR(s, x))
proof
  @associates |
    forall a, b, c: R; mulR(mulR(a, b), c) = mulR(a, mulR(b, c))
    [by cite ring.mulIsAssociative]
  @given-commutativity |
    assume forall a, b: R; mulR(a, b) = mulR(b, a) {
      @commutes |
        forall a, b: R; mulR(a, b) = mulR(b, a)
        [by hypothesis given-commutativity]
      @generalize-x |
        fix x: R {
          @generalize-s |
            fix s: R {
              @given-x-is-a-multiple |
                assume inPrincipal(x) {
                  @x-is-a-multiple |
                    exists r: R; x = mulR(gen, r)
                    [by hypothesis given-x-is-a-multiple]
                  @with-the-cofactor-r |
                    unpack r: R from x-is-a-multiple {
                      @x-is-a-r |
                        x = mulR(gen, r)
                        [by hypothesis with-the-cofactor-r]
                      // s(ar) = (sa)r = (as)r = a(sr)
                      @regroup |
                        mulR(mulR(s, gen), r) = mulR(s, mulR(gen, r))
                        [using specialize associates(s, gen, r)]
                      @s-a-is-a-s |
                        mulR(s, gen) = mulR(gen, s)
                        [using specialize commutes(s, gen)]
                      @regroup-commuted |
                        mulR(mulR(gen, s), r) = mulR(s, mulR(gen, r))
                        [by rewrite s-a-is-a-s regroup]
                      @reassociate |
                        mulR(mulR(gen, s), r) = mulR(gen, mulR(s, r))
                        [using specialize associates(gen, s, r)]
                      @s-times-x-is-a-multiple-of-a |
                        mulR(s, mulR(gen, r)) = mulR(gen, mulR(s, r))
                        [using chain regroup-commuted-flipped reassociate]
                      @regroup-commuted-flipped |
                        mulR(s, mulR(gen, r)) = mulR(mulR(gen, s), r)
                        [by symmetry regroup-commuted]
                      @s-times-x |
                        mulR(s, x) = mulR(gen, mulR(s, r))
                        [by rewrite x-is-a-r s-times-x-is-a-multiple-of-a]
                      @conclusion-absorbed |
                        exists t: R; mulR(s, x) = mulR(gen, t)
                        [by witness(mulR(s, r)) s-times-x]
                    }
                  @conclusion-in-the-ideal |
                    inPrincipal(mulR(s, x))
                    [by unpacked with-the-cofactor-r]
                }
              @conclusion-at-s |
                inPrincipal(x) -> inPrincipal(mulR(s, x))
                [by discharge given-x-is-a-multiple]
            }
          @conclusion-for-s |
            forall s: R; inPrincipal(x) -> inPrincipal(mulR(s, x))
            [by generalize generalize-s]
        }
      @conclusion-for-x |
        forall x, s: R; inPrincipal(x) -> inPrincipal(mulR(s, x))
        [by generalize generalize-x]
    }
  @conclusion |
    (forall a, b: R; mulR(a, b) = mulR(b, a)) -> forall x, s: R; inPrincipal(x) -> inPrincipal(mulR(s, x))
    [by discharge given-commutativity]
qed
```

## Proposition 16.10

> The kernel of any ring homomorphism $\phi : R \rightarrow S$ is an ideal in $R$.

**Proof.** We know from group theory that $\ker \phi$ is an additive subgroup of $R$.
Suppose that $r \in R$ and $a \in \ker \phi$. Then we must show that $ar$ and $ra$ are in
$\ker \phi$. However,
$$\phi(ar) = \phi(a) \phi(r) = 0 \phi(r) = 0$$
and
$$\phi(ra) = \phi(r) \phi(a) = \phi(r)0 = 0.$$
$\blacksquare$

```2b4m
// Judson's two displayed computations, each a theorem: the kernel absorbs on both sides.
theorem theKernelAbsorbsOnTheRight: forall a, r: R; inKernel(a) -> inKernel(mulR(a, r))
proof
  @preserves-multiplication |
    forall a, b: R; phi(mulR(a, b)) = mulS(phi(a), phi(b))
    [by cite phiPreservesMultiplication]
  @generalize-a |
    fix a: R {
      @generalize-r |
        fix r: R {
          @given-a-in-the-kernel |
            assume inKernel(a) {
              @phi-a-is-zero |
                phi(a) = zeroS
                [by hypothesis given-a-in-the-kernel]
              // φ(ar) = φ(a)φ(r)
              @phi-of-the-product |
                phi(mulR(a, r)) = mulS(phi(a), phi(r))
                [using specialize preserves-multiplication(a, r)]
              // = 0·φ(r)
              @with-phi-a-zero |
                phi(mulR(a, r)) = mulS(zeroS, phi(r))
                [by rewrite phi-a-is-zero phi-of-the-product]
              // = 0
              @zero-times-anything |
                mulS(zeroS, phi(r)) = zeroS
                [using specialize mulZeroLeftS(phi(r))]
              @conclusion-product-in-the-kernel |
                inKernel(mulR(a, r))
                [using chain with-phi-a-zero zero-times-anything]
            }
          @conclusion-at-r |
            inKernel(a) -> inKernel(mulR(a, r))
            [by discharge given-a-in-the-kernel]
        }
      @conclusion-for-r |
        forall r: R; inKernel(a) -> inKernel(mulR(a, r))
        [by generalize generalize-r]
    }
  @conclusion |
    forall a, r: R; inKernel(a) -> inKernel(mulR(a, r))
    [by generalize generalize-a]
qed

theorem theKernelAbsorbsOnTheLeft: forall a, r: R; inKernel(a) -> inKernel(mulR(r, a))
proof
  @preserves-multiplication |
    forall a, b: R; phi(mulR(a, b)) = mulS(phi(a), phi(b))
    [by cite phiPreservesMultiplication]
  @generalize-a |
    fix a: R {
      @generalize-r |
        fix r: R {
          @given-a-in-the-kernel |
            assume inKernel(a) {
              @phi-a-is-zero |
                phi(a) = zeroS
                [by hypothesis given-a-in-the-kernel]
              @phi-of-the-product |
                phi(mulR(r, a)) = mulS(phi(r), phi(a))
                [using specialize preserves-multiplication(r, a)]
              @with-phi-a-zero |
                phi(mulR(r, a)) = mulS(phi(r), zeroS)
                [by rewrite phi-a-is-zero phi-of-the-product]
              @anything-times-zero |
                mulS(phi(r), zeroS) = zeroS
                [using specialize mulZeroRightS(phi(r))]
              @conclusion-product-in-the-kernel |
                inKernel(mulR(r, a))
                [using chain with-phi-a-zero anything-times-zero]
            }
          @conclusion-at-r |
            inKernel(a) -> inKernel(mulR(r, a))
            [by discharge given-a-in-the-kernel]
        }
      @conclusion-for-r |
        forall r: R; inKernel(a) -> inKernel(mulR(r, a))
        [by generalize generalize-r]
    }
  @conclusion |
    forall a, r: R; inKernel(a) -> inKernel(mulR(r, a))
    [by generalize generalize-a]
qed
```

"We know from group theory that $\ker \phi$ is an additive subgroup of $R$" — the half of
the claim that is about addition: the kernel contains $0$ and is closed under subtraction,
which with the absorption above is the full ideal condition.

```2b4m
theorem theKernelContainsZero: inKernel(zeroR)
proof
  @conclusion |
    phi(zeroR) = zeroS
    [by cite phiSendsZeroToZero]
qed

theorem theKernelIsClosedUnderAddition:
  forall a, b: R; inKernel(a) -> inKernel(b) -> inKernel(addR(a, b))
proof
  @preserves-addition |
    forall a, b: R; phi(addR(a, b)) = addS(phi(a), phi(b))
    [by cite phiPreservesAddition]
  @generalize-a |
    fix a: R {
      @generalize-b |
        fix b: R {
          @given-a-in-the-kernel |
            assume inKernel(a) {
              @given-b-in-the-kernel |
                assume inKernel(b) {
                  @phi-a-is-zero |
                    phi(a) = zeroS
                    [by hypothesis given-a-in-the-kernel]
                  @phi-b-is-zero |
                    phi(b) = zeroS
                    [by hypothesis given-b-in-the-kernel]
                  @phi-of-the-sum |
                    phi(addR(a, b)) = addS(phi(a), phi(b))
                    [using specialize preserves-addition(a, b)]
                  @with-phi-a-zero |
                    phi(addR(a, b)) = addS(zeroS, phi(b))
                    [by rewrite phi-a-is-zero phi-of-the-sum]
                  @with-both-zero |
                    phi(addR(a, b)) = addS(zeroS, zeroS)
                    [by rewrite phi-b-is-zero with-phi-a-zero]
                  @zero-plus-zero |
                    addS(zeroS, zeroS) = zeroS
                    [using specialize addZeroLeftS(zeroS)]
                  @conclusion-sum-in-the-kernel |
                    inKernel(addR(a, b))
                    [using chain with-both-zero zero-plus-zero]
                }
              @conclusion-after-b |
                inKernel(b) -> inKernel(addR(a, b))
                [by discharge given-b-in-the-kernel]
            }
          @conclusion-after-a |
            inKernel(a) -> inKernel(b) -> inKernel(addR(a, b))
            [by discharge given-a-in-the-kernel]
        }
      @conclusion-for-b |
        forall b: R; inKernel(a) -> inKernel(b) -> inKernel(addR(a, b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: R; inKernel(a) -> inKernel(b) -> inKernel(addR(a, b))
    [by generalize generalize-a]
qed
```

**Remark.** In our definition of an ideal we have required that $rI \subset I$ and
$Ir \subset I$ for all $r \in R$. Such ideals are sometimes referred to as **two-sided
ideals**. We can also consider **one-sided ideals**; that is, we may require only that
either $rI \subset I$ or $Ir \subset I$ for $r \in R$ hold but not both. Such ideals are
called **left ideals** and **right ideals**, respectively. Of course, in a commutative ring
any ideal must be two-sided. In this text we will concentrate on two-sided ideals.

## Theorem 16.11

> Let $I$ be an ideal of $R$. The factor group $R/I$ is a ring with multiplication defined by
> $$(r + I)(s + I) = rs + I.$$

**Proof.** We already know that $R/I$ is an abelian group under addition. Let $r+I$ and
$s+I$ be in $R/I$. We must show that the product $(r + I)(s + I) = rs + I$ is independent of
the choice of coset; that is, if $r' \in r+I$ and $s' \in s+I$, then $r's'$ must be in
$rs+I$. Since $r' \in r+I$, there exists an element $a$ in $I$ such that $r' = r + a$.
Similarly, there exists a $b \in I$ such that $s' = s + b$. Notice that
$$r' s' = (r+a)(s+b) = rs + as + rb + ab$$
and $as + rb + ab \in I$ since $I$ is an ideal; consequently, $r' s' \in rs + I$. We will
leave as an exercise the verification of the associative law for multiplication and the
distributive laws. $\blacksquare$

> *What his proof establishes is WELL-DEFINEDNESS, and that is what we transcribe: the coset
> relation here is "$r' - r \in I$", so his claim is that $r' \sim r$ and $s' \sim s$ imply
> $r's' \sim rs$. His displayed expansion is the proof, and the step "$as + rb + ab \in I$
> since $I$ is an ideal" uses absorption on both sides plus closure under addition. $R/I$
> itself exists as a SORT in `std/ring/factor.b4m`, built the way `std/group/factor.b4m`
> builds $G/N$: a quotient sort with a surjective class map, the congruence as an axiom, the
> induced operations posited as class-map homomorphism equations, and all eight ring axioms
> lifted — including the associativity and distributivity Judson leaves as an exercise — so
> that a model carries the whole `std/ring.b4m` corpus onto the factor ring.*

```2b4m
// the coset relation: r' ~ r when r' - r ∈ I
define congruentModIdeal(x, y) = inIdeal(addR(x, negR(y)))

// an ideal is closed under addition (needed for as + rb + ab ∈ I)
theorem anIdealIsClosedUnderAddition:
  forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, b))
proof
  @closed-under-subtraction |
    forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, negR(b)))
    [by cite idealClosedUnderSub]
  @zero-is-in |
    inIdeal(zeroR)
    [by cite anIdealContainsZero]
  @double-negation |
    forall x: R; negR(negR(x)) = x
    [using model(ring.AdditiveGroup) group.invInvolution]
  @generalize-a |
    fix a: R {
      @generalize-b |
        fix b: R {
          @given-a-in |
            assume inIdeal(a) {
              @given-b-in |
                assume inIdeal(b) {
                  @a-is-in |
                    inIdeal(a)
                    [by hypothesis given-a-in]
                  @b-is-in |
                    inIdeal(b)
                    [by hypothesis given-b-in]
                  // -b is in I, as 0 - b
                  @zero-minus-b-is-in |
                    inIdeal(addR(zeroR, negR(b)))
                    [using specialize closed-under-subtraction(zeroR, b) zero-is-in b-is-in]
                  @zero-minus-b-is-neg-b |
                    addR(zeroR, negR(b)) = negR(b)
                    [using specialize addZeroLeftR(negR(b))]
                  @neg-b-is-in |
                    inIdeal(negR(b))
                    [by rewrite zero-minus-b-is-neg-b zero-minus-b-is-in]
                  // a + b = a - (-b)
                  @a-minus-neg-b-is-in |
                    inIdeal(addR(a, negR(negR(b))))
                    [using specialize closed-under-subtraction(a, negR(b)) a-is-in neg-b-is-in]
                  @neg-neg-b-is-b |
                    negR(negR(b)) = b
                    [by apply_at(b) double-negation]
                  @conclusion-sum-is-in |
                    inIdeal(addR(a, b))
                    [by rewrite neg-neg-b-is-b a-minus-neg-b-is-in]
                }
              @conclusion-after-b |
                inIdeal(b) -> inIdeal(addR(a, b))
                [by discharge given-b-in]
            }
          @conclusion-after-a |
            inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, b))
            [by discharge given-a-in]
        }
      @conclusion-for-b |
        forall b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, b))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, b))
    [by generalize generalize-a]
qed
```

> *The congruence itself needs his expansion $(r+a)(s+b) = rs + as + rb + ab$ regrouped so
> that $r's' - rs$ appears as the ideal member $as + rb + ab$. That is a ring-algebra
> rearrangement over a non-commutative `mul`, which `polynomial` does not handle and
> `assoc` handles only one associativity at a time; we state the regrouping as a hypothesis
> and prove the inference Judson draws from it.*

```2b4m
// Judson's conclusion, from his displayed expansion: the product is well defined on cosets.
theorem theProductIsWellDefinedOnCosets:
  forall r, s, a, b: R;
  inIdeal(a) -> inIdeal(b) ->
  addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) ->
  congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))
proof
  @absorbs-on-the-right |
    forall a, r: R; inIdeal(a) -> inIdeal(mulR(a, r))
    [by cite idealAbsorbsOnTheRight]
  @absorbs-on-the-left |

    [by cite idealAbsorbsOnTheLeft]

    forall a, b: R; inIdeal(a) -> inIdeal(b) -> inIdeal(addR(a, b))
    [by cite anIdealIsClosedUnderAddition]

    fix r: R {
      @generalize-s |
        fix s: R {
          @generalize-a |
            fix a: R {
              @generalize-b |
                fix b: R {
                  @given-a-in |
                    assume inIdeal(a) {
                      @given-b-in |
                        assume inIdeal(b) {
                          @given-the-expansion |
                            assume addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) {

                                inIdeal(a)
                                [by hypothesis given-a-in]
                              @b-is-in |
                                inIdeal(b)
                                [by hypothesis given-b-in]
                              @the-expansion |

                              // "consequently, r's' ∈ rs + I"
                              @conclusion-congruent |
                                congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))
                                [by rewrite the-expansion the-whole-remainder-is-in]
                            }
                          @conclusion-given-expansion |
                            addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) -> congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))
                            [by discharge given-the-expansion]
                        }
                      @conclusion-after-b |
                        inIdeal(b) -> addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) -> congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))
                        [by discharge given-b-in]
                    }
                  @conclusion-after-a |
                    inIdeal(a) -> inIdeal(b) -> addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) -> congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))

                [by generalize generalize-b]

          @conclusion-for-a |
            forall a, b: R; inIdeal(a) -> inIdeal(b) -> addR(mulR(addR(r, a), addR(s, b)), negR(mulR(r, s))) = addR(addR(mulR(a, s), mulR(r, b)), mulR(a, b)) -> congruentModIdeal(mulR(addR(r, a), addR(s, b)), mulR(r, s))
```

The ring $R/I$ in Theorem 16.11 is called the **factor** or **quotient ring**. Just as with
group homomorphisms and normal subgroups, there is a relationship between ring homomorphisms
and ideals.

## Theorem 16.12

> Let $I$ be an ideal of $R$. The map $\phi : R \rightarrow R/I$ defined by
> $\phi(r) = r + I$ is a ring homomorphism of $R$ onto $R/I$ with kernel $I$.

**Proof.** Certainly $\phi : R \rightarrow R/I$ is a surjective abelian group homomorphism.
It remains to show that $\phi$ works correctly under ring multiplication. Let $r$ and $s$ be
in $R$. Then
$$\phi(r) \phi(s) = (r + I)(s+I) = rs + I = \phi(rs),$$
which completes the proof of the theorem. $\blacksquare$

In ring theory we have isomorphism theorems relating ideals and ring homomorphisms similar
to the isomorphism theorems for groups that relate normal subgroups and homomorphisms in
Chapter 11. We will prove only the First Isomorphism Theorem for rings in this chapter and
leave the proofs of the other two theorems as exercises. All of the proofs are similar to
the proofs of the isomorphism theorems for groups.

## Theorem 16.13 (First Isomorphism Theorem)

> Let $\psi : R \rightarrow S$ be a ring homomorphism. Then $\ker \psi$ is an ideal of $R$.
> If $\phi : R \rightarrow R/\ker \psi$ is the canonical homomorphism, then there exists a
> unique isomorphism $\eta: R/\ker \psi \rightarrow \psi(R)$ such that $\psi = \eta \phi$.

**Proof.** Let $K = \ker \psi$. By the First Isomorphism Theorem for groups, there exists a
well-defined group homomorphism $\eta: R/K \rightarrow \psi(R)$ defined by
$\eta(r + K) = \psi(r)$ for the additive abelian groups $R$ and $R/K$. To show that this is
a ring homomorphism, we need only show that
$\eta((r + K)(s + K)) = \eta(r + K)\eta(s + K)$; but
$$\begin{aligned} \eta((r + K)(s + K)) &= \eta(rs + K) \\ &= \psi(rs) \\ &= \psi(r)\psi(s) \\ &= \eta(r + K)\eta(s + K). \end{aligned}$$
$\blacksquare$

## Theorem 16.14 (Second Isomorphism Theorem)

> Let $I$ be a subring of a ring $R$ and $J$ an ideal of $R$. Then $I \cap J$ is an ideal of
> $I$ and
> $$I / I \cap J \cong (I+ J) /J.$$

## Theorem 16.15 (Third Isomorphism Theorem)

> Let $R$ be a ring and $I$ and $J$ be ideals of $R$ where $J \subset I$. Then
> $$R/I \cong \frac{R/J}{I/J}.$$

## Theorem 16.16 (Correspondence Theorem)

> Let $I$ be an ideal of a ring $R$. Then $S \mapsto S/I$ is a one-to-one correspondence
> between the set of subrings $S$ containing $I$ and the set of subrings of $R/I$.
> Furthermore, the ideals of $R$ containing $I$ correspond to ideals of $R/I$.

> *Theorem 16.12 is now available: `std/ring/factor.b4m` proves that the class map preserves
> both operations (`clsPreservesAddition`, `clsPreservesMultiplication`) and that its kernel
> is exactly $I$ (`clsKernelIsTheIdeal`), with surjectivity the construction's own axiom —
> which is his statement in full. Theorems 16.13 through 16.16 each conclude with a $\cong$
> between rings, and that relation still cannot be NAMED: there is no sort of rings, the same
> limit §11.2 meets for groups. Stating them needs a second ring-and-ideal pair plus the
> isomorphism as a map, in the shape §11.2 uses for groups.*
