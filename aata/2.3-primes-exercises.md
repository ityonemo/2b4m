## Exercises

**Exercise 17 (Fibonacci Numbers).** With `f₁ = f₂ = 1` and `f_{n+2} = f_{n+1} + fₙ`,
prove (a) `fₙ < 2ⁿ`; (b) `f_{n+1} f_{n−1} = fₙ² + (−1)ⁿ` for `n ≥ 2`;
(c) the closed form `fₙ = [(1 + √5)ⁿ − (1 − √5)ⁿ] / 2ⁿ√5`; (d) the golden-ratio
limit `φ = limₙ f_{n+1}/fₙ = (√5 + 1)/2`; (e) `gcd(fₙ, f_{n+1}) = 1`.

**Proved (a), (b), (e); (c), (d) deferred.** The Fibonacci numbers are naturals, so
this exercise is worked over ℕ (`std/peano.b4m` and its power, divisibility and parity
theories), with the recurrence as a DEFINITION BLOCK: `fib(0) = 0`, `fib(1) = 1`,
`fib(k + 2) = fib(k + 1) + fib(k)`. Judson indexes from `f₁ = f₂ = 1`; extending to
`f₀ = 0` keeps every index the same (`fib(n)` is Judson's `fₙ`).

**(a) `fₙ < 2ⁿ`.** Two consecutive values are needed at each step, so the induction
carries the pair `fₙ < 2ⁿ ∧ f_{n+1} < 2^{n+1}`: `f_{n+2} = f_{n+1} + fₙ < 2^{n+1} + 2ⁿ <
2^{n+1} + 2^{n+1} = 2^{n+2}`, the last step because `2ⁿ` is positive. Three small order
facts over ℕ come first: strict bounds add, a positive number is below its double, and
the powers of two are positive.

```2b4m
fact natLessThanIntro = peano_order.lessThanIntro
fact natLessThanElim = peano_order.lessThanElim
fact natAddZeroLeft = peano.addZeroLeft
fact natAddIsCommutative = peano.addIsCommutative

theorem natSumOfStrictBounds: forall a, b, c, d: Nat; nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
proof
  @generalize-a |
    fix a: Nat {
      @generalize-b |
        fix b: Nat {
          @generalize-c |
            fix c: Nat {
              @generalize-d |
                fix d: Nat {
                  @given-a-below-b |
                    assume nat_less_than(a, b) {
                      @given-c-below-d |
                        assume nat_less_than(c, d) {
                          @a-below-b |
                            nat_less_than(a, b)
                            [by hypothesis given-a-below-b]
                          @c-below-d |
                            nat_less_than(c, d)
                            [by hypothesis given-c-below-d]
                          @shifted-by-c |
                            nat_less_than(nadd(c, a), nadd(c, b))
                            [using specialize natAdditionPreservesOrder(a, b, c) a-below-b]
                          @c-plus-a-commutes |
                            nadd(c, a) = nadd(a, c)
                            [using specialize natAddIsCommutative(c, a)]
                          @c-plus-b-commutes |
                            nadd(c, b) = nadd(b, c)
                            [using specialize natAddIsCommutative(c, b)]
                          @left-sums-ordered-partly |
                            nat_less_than(nadd(a, c), nadd(c, b))
                            [by rewrite c-plus-a-commutes shifted-by-c]
                          @left-sums-ordered |
                            nat_less_than(nadd(a, c), nadd(b, c))
                            [by rewrite c-plus-b-commutes left-sums-ordered-partly]
                          @right-sums-ordered |
                            nat_less_than(nadd(b, c), nadd(b, d))
                            [using specialize natAdditionPreservesOrder(c, d, b) c-below-d]
                          @conclusion-sums-ordered |
                            nat_less_than(nadd(a, c), nadd(b, d))
                            [using specialize natLessThanTransitive(nadd(a, c), nadd(b, c), nadd(b, d)) left-sums-ordered right-sums-ordered]
                        }
                      @c-below-d-implies |
                        nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
                        [by discharge given-c-below-d]
                    }
                  @a-below-b-implies |
                    nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
                    [by discharge given-a-below-b]
                }
              @discharge-d |
                forall d: Nat; nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
                [by generalize generalize-d]
            }
          @discharge-c |
            forall c, d: Nat; nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
            [by generalize generalize-c]
        }
      @discharge-b |
        forall b, c, d: Nat; nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
        [by generalize generalize-b]
    }
  @conclusion |
    forall a, b, c, d: Nat; nat_less_than(a, b) -> nat_less_than(c, d) -> nat_less_than(nadd(a, c), nadd(b, d))
    [by generalize generalize-a]
qed

theorem natPositiveIsBelowItsDouble: forall x: Nat; nat_less_than(NZERO, x) -> nat_less_than(x, nadd(x, x))
proof
  @generalize-x |
    fix x: Nat {
      @given-positive |
        assume nat_less_than(NZERO, x) {
          @positive |
            nat_less_than(NZERO, x)
            [by hypothesis given-positive]
          @gap-exists |
            exists d: Nat; nadd(NZERO, nsucc(d)) = x
            [using specialize natLessThanElim(NZERO, x) positive]
          @with-gap-d |
            unpack d: Nat from gap-exists {
              @gap |
                nadd(NZERO, nsucc(d)) = x
                [by hypothesis with-gap-d]
              @zero-plus |
                nadd(NZERO, nsucc(d)) = nsucc(d)
                [using specialize natAddZeroLeft(nsucc(d))]
              @x-is-succ-d-flipped |
                nsucc(d) = x
                [by rewrite zero-plus gap]
              @x-is-succ-d |
                x = nsucc(d)
                [by symmetry x-is-succ-d-flipped]
              @double-reflexive |
                nadd(nsucc(d), nsucc(d)) = nadd(nsucc(d), nsucc(d))
                [by reflexivity]
              @x-plus-gap-is-double |
                nadd(x, nsucc(d)) = nadd(x, x)
                [by rewrite x-is-succ-d double-reflexive]
              @conclusion-below-double-inner |
                nat_less_than(x, nadd(x, x))
                [using specialize natLessThanIntro(x, d, nadd(x, x)) x-plus-gap-is-double]
            }
          @conclusion-below-double |
            nat_less_than(x, nadd(x, x))
            [by unpacked with-gap-d]
        }
      @positive-implies |
        nat_less_than(NZERO, x) -> nat_less_than(x, nadd(x, x))
        [by discharge given-positive]
    }
  @conclusion |
    forall x: Nat; nat_less_than(NZERO, x) -> nat_less_than(x, nadd(x, x))
    [by generalize generalize-x]
qed

theorem twoToThePowerIsPositive: forall e: Nat; nat_less_than(NZERO, pow(NTWO, e))
proof
  @two-to-the-zero |
    pow(NTWO, NZERO) = NONE
    [using specialize powZero(NTWO)]
  @zero-plus-succ-zero |
    nadd(NZERO, nsucc(NZERO)) = nsucc(NZERO)
    [using specialize natAddZeroLeft(nsucc(NZERO))]
  @succ-zero-is-one |
    nsucc(NZERO) = NONE
    [by symmetry one-is-succ-zero]
  @one-is-succ-zero |
    NONE = nsucc(NZERO)
    [by cite natOneIsSuccZero]
  @zero-plus-succ-zero-is-one |
    nadd(NZERO, nsucc(NZERO)) = NONE
    [using chain zero-plus-succ-zero succ-zero-is-one]
  @one-is-positive |
    nat_less_than(NZERO, NONE)
    [using specialize natLessThanIntro(NZERO, NZERO, NONE) zero-plus-succ-zero-is-one]
  @base-case |
    nat_less_than(NZERO, pow(NTWO, NZERO))
    [by rewrite two-to-the-zero one-is-positive]
  @induction-step |
    fix k: Nat {
      @given-inductive-hypothesis |
        assume nat_less_than(NZERO, pow(NTWO, k)) {
          @inductive-hypothesis |
            nat_less_than(NZERO, pow(NTWO, k))
            [by hypothesis given-inductive-hypothesis]
          @power-below-double |
            nat_less_than(pow(NTWO, k), nadd(pow(NTWO, k), pow(NTWO, k)))
            [using specialize natPositiveIsBelowItsDouble(pow(NTWO, k)) inductive-hypothesis]
          @double-positive |
            nat_less_than(NZERO, nadd(pow(NTWO, k), pow(NTWO, k)))
            [using specialize natLessThanTransitive(NZERO, pow(NTWO, k), nadd(pow(NTWO, k), pow(NTWO, k))) inductive-hypothesis power-below-double]
          @next-power |
            pow(NTWO, nsucc(k)) = nmul(NTWO, pow(NTWO, k))
            [using specialize powSucc(NTWO, k)]
          @next-power-doubles |
            nmul(NTWO, pow(NTWO, k)) = nadd(pow(NTWO, k), pow(NTWO, k))
            [using polynomial(peano)]
          @next-power-is-double |
            pow(NTWO, nsucc(k)) = nadd(pow(NTWO, k), pow(NTWO, k))
            [using chain next-power next-power-doubles]
          @conclusion-next-positive |
            nat_less_than(NZERO, pow(NTWO, nsucc(k)))
            [by rewrite next-power-is-double double-positive]
        }
      @induction-step-at-k |
        nat_less_than(NZERO, pow(NTWO, k)) -> nat_less_than(NZERO, pow(NTWO, nsucc(k)))
        [by discharge given-inductive-hypothesis]
    }
  @induction-step-for-all-k |
    forall k: Nat; nat_less_than(NZERO, pow(NTWO, k)) -> nat_less_than(NZERO, pow(NTWO, nsucc(k)))
    [by generalize induction-step]
  @conclusion |
    forall e: Nat; nat_less_than(NZERO, pow(NTWO, e))
    [using instantiation natInduction((fun e: Nat => nat_less_than(NZERO, pow(NTWO, e)))) base-case induction-step-for-all-k]
qed

theorem fibBelowPowerOfTwo: forall n: Nat; nat_less_than(fib(n), pow(NTWO, n))
proof
  @fib-at-zero |
    fib(NZERO) = NZERO
    [by definition(0) fib]
  @fib-at-one |
    fib(nsucc(NZERO)) = NONE
    [by definition(1) fib]
  @recurrence |
    forall m: Nat; fib(nsucc(nsucc(m))) = nadd(fib(nsucc(m)), fib(m))
    [by definition(2) fib]
  @two-to-the-zero |
    pow(NTWO, NZERO) = NONE
    [using specialize powZero(NTWO)]
  @two-to-the-one |
    pow(NTWO, nsucc(NZERO)) = NTWO
    [using specialize powOne(NTWO)]
  // base: f₀ = 0 < 1 = 2⁰ and f₁ = 1 < 2 = 2¹.
  @one-is-positive |
    nat_less_than(NZERO, pow(NTWO, NZERO))
    [using specialize twoToThePowerIsPositive(NZERO)]
  @zero-below-one |
    nat_less_than(NZERO, NONE)
    [by rewrite two-to-the-zero one-is-positive]
  @fib-zero-below |
    nat_less_than(fib(NZERO), pow(NTWO, NZERO))
    [by rewrite fib-at-zero one-is-positive]
  @one-below-two |
    nat_less_than(NONE, nadd(NONE, NONE))
    [using specialize natPositiveIsBelowItsDouble(NONE) zero-below-one]
  @one-below-two-to-the-one |
    nat_less_than(NONE, pow(NTWO, nsucc(NZERO)))
    [by rewrite two-to-the-one one-below-two]
  @fib-one-below |
    nat_less_than(fib(nsucc(NZERO)), pow(NTWO, nsucc(NZERO)))
    [by rewrite fib-at-one one-below-two-to-the-one]
  @base-case |
    nat_less_than(fib(NZERO), pow(NTWO, NZERO)) and nat_less_than(fib(nsucc(NZERO)), pow(NTWO, nsucc(NZERO)))
    [by both fib-zero-below fib-one-below]
  // step: f_{k+2} = f_{k+1} + f_k < 2^{k+1} + 2^k < 2^{k+1} + 2^{k+1} = 2^{k+2}.
  @induction-step |
    fix k: Nat {
      @given-inductive-hypothesis |
        assume nat_less_than(fib(k), pow(NTWO, k)) and nat_less_than(fib(nsucc(k)), pow(NTWO, nsucc(k))) {
          @inductive-hypothesis |
            nat_less_than(fib(k), pow(NTWO, k)) and nat_less_than(fib(nsucc(k)), pow(NTWO, nsucc(k)))
            [by hypothesis given-inductive-hypothesis]
          @fib-k-below |
            nat_less_than(fib(k), pow(NTWO, k))
            [by and_lhs inductive-hypothesis]
          @fib-next-below |
            nat_less_than(fib(nsucc(k)), pow(NTWO, nsucc(k)))
            [by and_rhs inductive-hypothesis]
          @next-fib |
            fib(nsucc(nsucc(k))) = nadd(fib(nsucc(k)), fib(k))
            [using specialize recurrence(k)]
          @sum-below-sum |
            nat_less_than(nadd(fib(nsucc(k)), fib(k)), nadd(pow(NTWO, nsucc(k)), pow(NTWO, k)))
            [using specialize natSumOfStrictBounds(fib(nsucc(k)), pow(NTWO, nsucc(k)), fib(k), pow(NTWO, k)) fib-next-below fib-k-below]
          @this-power |
            pow(NTWO, nsucc(k)) = nmul(NTWO, pow(NTWO, k))
            [using specialize powSucc(NTWO, k)]
          @this-power-doubles |
            nmul(NTWO, pow(NTWO, k)) = nadd(pow(NTWO, k), pow(NTWO, k))
            [using polynomial(peano)]
          @this-power-is-double |
            pow(NTWO, nsucc(k)) = nadd(pow(NTWO, k), pow(NTWO, k))
            [using chain this-power this-power-doubles]
          @power-positive |
            nat_less_than(NZERO, pow(NTWO, k))
            [using specialize twoToThePowerIsPositive(k)]
          @power-below-double |
            nat_less_than(pow(NTWO, k), nadd(pow(NTWO, k), pow(NTWO, k)))
            [using specialize natPositiveIsBelowItsDouble(pow(NTWO, k)) power-positive]
          @power-below-next |
            nat_less_than(pow(NTWO, k), pow(NTWO, nsucc(k)))
            [by rewrite this-power-is-double power-below-double]

          @next-power |
```

**(b) `f_{n+1} f_{n−1} = fₙ² + (−1)ⁿ`.** Over ℕ there is no `−1`, so the identity is
stated as the pair it alternates between, with the index shifted by one so no subtraction
is needed: `fₙ f_{n+2} + 1 = f_{n+1}²` when `n` is even, and `fₙ f_{n+2} = f_{n+1}² + 1`
when `n` is odd. A single induction carries the disjunction and swaps arms each step: from
`fₙ f_{n+2} + 1 = f_{n+1}²` the next instance is `f_{n+1} f_{n+3} = f_{n+2}² + 1`, because
`f_{n+3} = f_{n+2} + f_{n+1}` and `fₙ = f_{n+2} − f_{n+1}` turn each side into the other
after expanding — the whole step is a ring identity in `f_{n+1}`, `f_{n+2}` once the
recurrence is substituted, so `polynomial(peano)` closes it.

```2b4m
fact natAddCancelRight = peano.addCancelRight

// the two arms, as a define so the induction predicate reads cleanly.
define cassiniPair(n) = (nadd(nmul(fib(n), fib(nsucc(nsucc(n)))), NONE) = nmul(fib(nsucc(n)), fib(nsucc(n))) or nmul(fib(n), fib(nsucc(nsucc(n)))) = nadd(nmul(fib(nsucc(n)), fib(nsucc(n))), NONE))

theorem cassiniIdentityAlternates: forall n: Nat; cassiniPair(n)
proof
  @fib-at-zero |
    fib(NZERO) = NZERO
    [by definition(0) fib]
  @fib-at-one |
    fib(nsucc(NZERO)) = NONE
    [by definition(1) fib]
  @fib-step-clause |
    forall k: Nat; fib(nsucc(nsucc(k))) = nadd(fib(nsucc(k)), fib(k))
    [by definition(2) fib]

  // base: f0 * f2 + 1 = 0 * f2 + 1 = 1 = 1 * 1 = f1 * f1.
  @base-left-at-zero |
    nadd(nmul(fib(NZERO), fib(nsucc(nsucc(NZERO)))), NONE) = nadd(nmul(NZERO, fib(nsucc(nsucc(NZERO)))), NONE)
    [by rewrite fib-at-zero base-left-reflexive]
  @base-left-reflexive |
    nadd(nmul(fib(NZERO), fib(nsucc(nsucc(NZERO)))), NONE) = nadd(nmul(fib(NZERO), fib(nsucc(nsucc(NZERO)))), NONE)
    [by reflexivity]
  @zero-times-anything |
    nadd(nmul(NZERO, fib(nsucc(nsucc(NZERO)))), NONE) = NONE
    [using polynomial(peano)]
  @base-left-is-one |
    nadd(nmul(fib(NZERO), fib(nsucc(nsucc(NZERO)))), NONE) = NONE
    [using chain base-left-at-zero zero-times-anything]
  @base-right-at-one |
    nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO))) = nmul(NONE, NONE)
    [by rewrite fib-at-one base-right-reflexive]
  @base-right-reflexive |
    nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO))) = nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO)))
    [by reflexivity]
  @one-times-one |
    nmul(NONE, NONE) = NONE
    [using polynomial(peano)]
  @base-right-is-one |
    nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO))) = NONE
    [using chain base-right-at-one one-times-one]
  @one-is-base-right |
    NONE = nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO)))
    [by symmetry base-right-is-one]
  @base-even-arm |
    nadd(nmul(fib(NZERO), fib(nsucc(nsucc(NZERO)))), NONE) = nmul(fib(nsucc(NZERO)), fib(nsucc(NZERO)))
    [using chain base-left-is-one one-is-base-right]
  @base-case |
    cassiniPair(NZERO)
    [using tautology base-even-arm]

  // step: substituting f_{k+3} = f_{k+2} + f_{k+1} and f_{k+2} = f_{k+1} + f_k turns each
  // arm into the other.
  @induction-step |
    fix k: Nat {
      @given-inductive-hypothesis |
        assume cassiniPair(k) {
          @inductive-hypothesis |
            cassiniPair(k)
            [by hypothesis given-inductive-hypothesis]
          @next-fib-unfolds |
            fib(nsucc(nsucc(k))) = nadd(fib(nsucc(k)), fib(k))
            [using specialize fib-step-clause(k)]
          @third-fib-unfolds |
            fib(nsucc(nsucc(nsucc(k)))) = nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))
            [using specialize fib-step-clause(nsucc(k))]
          // both arms reduce to the SAME polynomial statement in f_k, f_{k+1} once the two
          // recurrences are substituted, with the roles of the two sides exchanged.
          @conclusion-next-pair |
            cassiniPair(nsucc(k))
            case inductive-hypothesis {
              @when-even-arm |
                assume nadd(nmul(fib(k), fib(nsucc(nsucc(k)))), NONE) = nmul(fib(nsucc(k)), fib(nsucc(k))) {
                  @even-arm |
                    nadd(nmul(fib(k), fib(nsucc(nsucc(k)))), NONE) = nmul(fib(nsucc(k)), fib(nsucc(k)))
                    [by hypothesis when-even-arm]
                  // f_{k+1} f_{k+3} = f_{k+1}(f_{k+2} + f_{k+1}) = f_{k+1} f_{k+2} + f_{k+1}²
                  //   = f_{k+1} f_{k+2} + f_k f_{k+2} + 1 = f_{k+2}² + 1.
                  @odd-arm-expanded |
                    nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))) = nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nmul(fib(nsucc(k)), fib(nsucc(k))))
                    [using polynomial(peano)]
                  @odd-arm-with-hypothesis |
                    nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))) = nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nadd(nmul(fib(k), fib(nsucc(nsucc(k)))), NONE))
                    [by rewrite even-arm odd-arm-expanded]
                  @square-of-next |
                    nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nadd(nmul(fib(k), fib(nsucc(nsucc(k)))), NONE)) = nadd(nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))), NONE)
                    [using polynomial(peano)]
                  @square-folds |
                    nadd(nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))), NONE) = nadd(nmul(fib(nsucc(nsucc(k))), fib(nsucc(nsucc(k)))), NONE)
                    [by rewrite next-fib-unfolds square-folds-reflexive]
                  @square-folds-reflexive |
                    nadd(nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))), NONE) = nadd(nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))), NONE)
                    [by reflexivity]
                  @odd-arm-at-third |
                    nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))) = nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k))))
                    [by rewrite third-fib-unfolds odd-arm-at-third-reflexive]
                  @odd-arm-at-third-reflexive |
                    nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))) = nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k)))))
                    [by reflexivity]
                  @odd-arm-holds |
                    nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))) = nadd(nmul(fib(nsucc(nsucc(k))), fib(nsucc(nsucc(k)))), NONE)
                    [using chain odd-arm-at-third odd-arm-with-hypothesis square-of-next square-folds]
                  @conclusion-odd-arm |
                    cassiniPair(nsucc(k))
                    [using tautology odd-arm-holds]
                }
              @when-odd-arm |
                assume nmul(fib(k), fib(nsucc(nsucc(k)))) = nadd(nmul(fib(nsucc(k)), fib(nsucc(k))), NONE) {
                  @odd-arm |
                    nmul(fib(k), fib(nsucc(nsucc(k)))) = nadd(nmul(fib(nsucc(k)), fib(nsucc(k))), NONE)
                    [by hypothesis when-odd-arm]
                  // f_{k+1} f_{k+3} + 1 = f_{k+1} f_{k+2} + f_{k+1}² + 1 = f_{k+1} f_{k+2}
                  //   + f_k f_{k+2} = f_{k+2}².
                  @even-arm-expanded |
                    nadd(nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))), NONE) = nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nadd(nmul(fib(nsucc(k)), fib(nsucc(k))), NONE))
                    [using polynomial(peano)]
                  @even-arm-with-hypothesis |
                    nadd(nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))), NONE) = nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nmul(fib(k), fib(nsucc(nsucc(k)))))
                    [by rewrite odd-arm even-arm-expanded]
                  @sum-of-products |
                    nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nmul(fib(k), fib(nsucc(nsucc(k))))) = nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k))))
                    [using polynomial(peano)]
                  @product-folds |
                    nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))) = nmul(fib(nsucc(nsucc(k))), fib(nsucc(nsucc(k))))
                    [by rewrite next-fib-unfolds product-folds-reflexive]
                  @product-folds-reflexive |
                    nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k)))) = nmul(nadd(fib(nsucc(k)), fib(k)), fib(nsucc(nsucc(k))))
                    [by reflexivity]
                  @even-arm-at-third |
                    nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))), NONE) = nadd(nmul(fib(nsucc(k)), nadd(fib(nsucc(nsucc(k))), fib(nsucc(k)))), NONE)
                    [by rewrite third-fib-unfolds even-arm-at-third-reflexive]
                  @even-arm-at-third-reflexive |
                    nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))), NONE) = nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))), NONE)
                    [by reflexivity]
                  @even-arm-holds |
                    nadd(nmul(fib(nsucc(k)), fib(nsucc(nsucc(nsucc(k))))), NONE) = nmul(fib(nsucc(nsucc(k))), fib(nsucc(nsucc(k))))
                    [using chain even-arm-at-third even-arm-with-hypothesis sum-of-products product-folds]
                  @conclusion-even-arm |
                    cassiniPair(nsucc(k))
                    [using tautology even-arm-holds]
                }
            }
        }
      @induction-step-at-k |
        cassiniPair(k) -> cassiniPair(nsucc(k))
        [by discharge given-inductive-hypothesis]
    }
  @induction-step-for-all-k |
    forall k: Nat; cassiniPair(k) -> cassiniPair(nsucc(k))
    [by generalize induction-step]
  @conclusion |
    forall n: Nat; cassiniPair(n)
    [using instantiation natInduction((fun n: Nat => cassiniPair(n))) base-case induction-step-for-all-k]
qed
```

**(e) `gcd(fₙ, f_{n+1}) = 1`.** Induction on the invariant itself. At `n = 0` the pair
is `(0, 1)` and `gcd(0, 1) = 1`. For the step, every common divisor `d` of `f_{n+1}` and
`f_{n+2}` divides their difference `f_{n+2} − f_{n+1} = fₙ`, so `d` divides both `fₙ` and
`f_{n+1}`, hence divides their gcd, which is `1` by hypothesis. So the gcd of the next
pair divides `1` and, being a divisor of `1`, is `1` — the gcd of a pair is itself one of
its common divisors (`gcdDividesBoth`), and `gcdGreatest` sends it into the old gcd.

```2b4m
theorem consecutiveFibonacciAreCoprime: forall n: Nat; ngcd(fib(n), fib(nsucc(n))) = NONE
proof
  // base: the pair is (0, 1), and gcd(0, 1) = gcd(1, 0) after the step clause — read it
  // directly off fib's first two clauses and gcdStep is not even needed: gcd(0, 1) = 1
  // because 1 divides both and any common divisor divides 1.
  @fib-at-zero |
    fib(NZERO) = NZERO
    [by definition(0) fib]
  @fib-at-one |
    fib(nsucc(NZERO)) = NONE
    [by definition(1) fib]
  @base-gcd-divides-one |
    ndivides(ngcd(NZERO, NONE), NONE)
    [using tautology base-gcd-divides-both]
  @base-gcd-divides-both |
    ndivides(ngcd(NZERO, NONE), NZERO) and ndivides(ngcd(NZERO, NONE), NONE)
    [using specialize natGcdDividesBoth(NZERO, NONE)]
  @base-gcd-is-one |
    ngcd(NZERO, NONE) = NONE
    [using specialize natDividesOneIsOne(ngcd(NZERO, NONE)) base-gcd-divides-one]
  @base-at-fib-zero |
    ngcd(fib(NZERO), NONE) = NONE
    [by rewrite fib-at-zero base-gcd-is-one]
  @base-case |
    ngcd(fib(NZERO), fib(nsucc(NZERO))) = NONE
    [by rewrite fib-at-one base-at-fib-zero]

  // step: a common divisor of f_{k+1}, f_{k+2} divides f_k = f_{k+2} − f_{k+1}.
  @induction-step |
    fix k: Nat {
      @given-inductive-hypothesis |
        assume ngcd(fib(k), fib(nsucc(k))) = NONE {
          @inductive-hypothesis |
            ngcd(fib(k), fib(nsucc(k))) = NONE
            [by hypothesis given-inductive-hypothesis]
          @fib-step-clause |
            forall k2: Nat; fib(nsucc(nsucc(k2))) = nadd(fib(nsucc(k2)), fib(k2))
            [by definition(2) fib]
          @next-fib-unfolds |
            fib(nsucc(nsucc(k))) = nadd(fib(nsucc(k)), fib(k))
            [using specialize fib-step-clause(k)]
          @new-gcd-divides-both |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(nsucc(k))) and ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(nsucc(nsucc(k))))
            [using specialize natGcdDividesBoth(fib(nsucc(k)), fib(nsucc(nsucc(k))))]
          @new-gcd-divides-middle |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(nsucc(k)))
            [using tautology new-gcd-divides-both]
          @new-gcd-divides-next |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(nsucc(nsucc(k))))
            [using tautology new-gcd-divides-both]
          @new-gcd-divides-difference |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), nsub(fib(nsucc(nsucc(k))), fib(nsucc(k))))
            [using specialize natDividesSub(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(nsucc(nsucc(k))), fib(nsucc(k))) new-gcd-divides-next new-gcd-divides-middle]
          // f_{k+2} − f_{k+1} = (f_{k+1} + f_k) − f_{k+1} = f_k, after commuting the sum.
          @sum-commutes |
            nadd(fib(nsucc(k)), fib(k)) = nadd(fib(k), fib(nsucc(k)))
            [using specialize natAddIsCommutative(fib(nsucc(k)), fib(k))]
          @next-fib-commuted |
            fib(nsucc(nsucc(k))) = nadd(fib(k), fib(nsucc(k)))
            [using chain next-fib-unfolds sum-commutes]
          @difference-cancels |
            nsub(nadd(fib(k), fib(nsucc(k))), fib(nsucc(k))) = fib(k)
            [using specialize natSubAddCancel(fib(k), fib(nsucc(k)))]
          @difference-is-previous |
            nsub(fib(nsucc(nsucc(k))), fib(nsucc(k))) = fib(k)
            [by rewrite next-fib-commuted difference-cancels]
          @new-gcd-divides-previous |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(k))
            [by rewrite difference-is-previous new-gcd-divides-difference]
          @new-gcd-divides-old-gcd |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), ngcd(fib(k), fib(nsucc(k))))
            [using specialize natGcdGreatest(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), fib(k), fib(nsucc(k))) new-gcd-divides-previous new-gcd-divides-middle]
          @new-gcd-divides-one |
            ndivides(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))), NONE)
            [by rewrite inductive-hypothesis new-gcd-divides-old-gcd]
          @conclusion-next-pair-coprime |
            ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))) = NONE
            [using specialize natDividesOneIsOne(ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k))))) new-gcd-divides-one]
        }
      @induction-step-at-k |
        ngcd(fib(k), fib(nsucc(k))) = NONE -> ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))) = NONE
        [by discharge given-inductive-hypothesis]
    }
  @induction-step-for-all-k |
    forall k: Nat; ngcd(fib(k), fib(nsucc(k))) = NONE -> ngcd(fib(nsucc(k)), fib(nsucc(nsucc(k)))) = NONE
    [by generalize induction-step]
  @conclusion |
    forall n: Nat; ngcd(fib(n), fib(nsucc(n))) = NONE
    [using instantiation natInduction((fun n: Nat => ngcd(fib(n), fib(nsucc(n))) = NONE)) base-case induction-step-for-all-k]
qed
```

**Exercise 20.** Using the division algorithm, every perfect square is of the
form `4k` or `4k + 1` for some integer `k`.

The Division Algorithm at divisor `2` writes any `n` as `2q + r` with `0 ≤ r < 2`,
so `r = 0` or `r = 1` (the small-remainder split below). If `n = 2q` then
`n² = (2q)² = 4·q²` (form `4k`, `k = q²`); if `n = 2q + 1` then
`n² = 4q² + 4q + 1 = 4·(q² + q) + 1` (form `4k + 1`, `k = q² + q`). The square
expansions are the ring drudgery Judson elides, so we take them by `polynomial`,
which folds the numeral coefficients (`2·2 → 4`, `2q + 2q → 4q`) directly.

First, the remainder of a division by `2` is `0` or `1`: from `r < 2` the
order-eliminator gives a nonnegative gap `d` with `r + succ(d) = 2`; splitting `d`
by `nonnegCases`, `d = 0` forces `succ(r) = 2`, i.e. `r = 1`, and `d = succ(m)`
forces `r + m = 0`, i.e. `r = 0`.

```2b4m
theorem remainderBelowTwoIsZeroOrOne: forall r: Int; nonneg(r) -> less_than(r, TWO) -> (r = ZERO or r = ONE)
proof
  @generalize-r |
    fix r: Int {
      @given-r-nonneg |
        assume nonneg(r) {
          @given-r-below-two |
            assume less_than(r, TWO) {
              @r-below-two |
                less_than(r, TWO)
                [by hypothesis given-r-below-two]
              @gap-exists |
                exists d: Int; nonneg(d) and add(r, succ(d)) = TWO
                [using specialize lessThanElim(r, TWO) r-below-two]
              @with-gap-d |
                unpack d: Int from gap-exists {
                  @gap-nonneg-and-sum |
                    nonneg(d) and add(r, succ(d)) = TWO
                    [by hypothesis with-gap-d]
                  @gap-nonneg |
                    nonneg(d)
                    [by and_lhs gap-nonneg-and-sum]
                  @remainder-plus-gap-is-two |
                    add(r, succ(d)) = TWO
                    [by and_rhs gap-nonneg-and-sum]
                  @gap-is-zero-or-successor |
                    d = ZERO or (exists m: Int; nonneg(m) and d = succ(m))
                    [using specialize nonnegCases(d) gap-nonneg]
                  @remainder-is-zero-or-one |
                    r = ZERO or r = ONE
                    case gap-is-zero-or-successor {
                      @when-gap-zero |
                        assume d = ZERO {
                          @gap-is-zero |
                            d = ZERO
                            [by hypothesis when-gap-zero]
                          @remainder-plus-succ-zero-is-two |
                            add(r, succ(ZERO)) = TWO
                            [by rewrite gap-is-zero remainder-plus-gap-is-two]
                          @add-succ-zero-unfolds |
                            add(r, succ(ZERO)) = succ(add(r, ZERO))
                            [using specialize addSuccRight(r, ZERO)]
                          @add-zero-right |
                            add(r, ZERO) = r
                            [using specialize addZeroRight(r)]
                          @add-succ-zero-is-succ-r |
                            add(r, succ(ZERO)) = succ(r)
                            [by rewrite add-zero-right add-succ-zero-unfolds]
                          @succ-r-is-two |
                            succ(r) = TWO
                            [using chain add-succ-zero-is-succ-r remainder-plus-succ-zero-is-two]
                          @succ-r-is-succ-one |
                            succ(r) = succ(ONE)
                            [using chain succ-r-is-two]
                          @remainder-is-one |
                            r = ONE
                            [using specialize succInjective(r, ONE) succ-r-is-succ-one]

                            r = ZERO or r = ONE
                            [by either_right remainder-is-one]

                      @when-gap-successor |
                        assume exists m: Int; nonneg(m) and d = succ(m) {
                          @gap-successor-exists |
                            exists m: Int; nonneg(m) and d = succ(m)
                            [by hypothesis when-gap-successor]
                          @with-inner-m |
                            unpack m: Int from gap-successor-exists {
                              @inner-nonneg-and-gap-succ |
                                nonneg(m) and d = succ(m)
                                [by hypothesis with-inner-m]
                              @gap-is-succ-m |
                                d = succ(m)
                                [by and_rhs inner-nonneg-and-gap-succ]
                              @inner-nonneg |
                                nonneg(m)
                                [by and_lhs inner-nonneg-and-gap-succ]
                              @remainder-plus-succ-succ-is-two |
                                add(r, succ(succ(m))) = TWO
                                [by rewrite gap-is-succ-m remainder-plus-gap-is-two]
                              @add-succ-outer |
                                add(r, succ(succ(m))) = succ(add(r, succ(m)))
                                [using specialize addSuccRight(r, succ(m))]
                              @add-succ-inner |
                                add(r, succ(m)) = succ(add(r, m))
                                [using specialize addSuccRight(r, m)]
                              @add-succ-succ-unfolds |
                                add(r, succ(succ(m))) = succ(succ(add(r, m)))
                                [using chain add-succ-outer add-succ-inner]
                              @succ-succ-sum-is-two |
                                succ(succ(add(r, m))) = TWO
                                [using chain add-succ-succ-unfolds remainder-plus-succ-succ-is-two]
                              @one-is-succ-zero |
                                ONE = succ(ZERO)
                                [by cite oneIsSuccZero]
                              @two-is-succ-one-again |
                                TWO = succ(ONE)
                                [using simplify]
                              @two-is-succ-succ-zero |
                                TWO = succ(succ(ZERO))
                                [by rewrite one-is-succ-zero two-is-succ-one-again]
                              @succ-succ-sum-is-succ-succ-zero |
                                succ(succ(add(r, m))) = succ(succ(ZERO))
                                [using chain succ-succ-sum-is-two two-is-succ-succ-zero]
                              @succ-sum-is-succ-zero |
                                succ(add(r, m)) = succ(ZERO)
                                [using specialize succInjective(succ(add(r, m)), succ(ZERO)) succ-succ-sum-is-succ-succ-zero]
                              @sum-remainder-inner-is-zero |

                                nonneg(r)
                                [by hypothesis given-r-nonneg]
                              // r + m = 0 with r, m nonneg forces r = 0: were r a
                              // successor, r + m would be a nonneg successor, hence
                              // != 0.
                              @remainder-zero-or-successor |
                                r = ZERO or (exists j: Int; nonneg(j) and r = succ(j))
                                [using specialize nonnegCases(r) remainder-nonneg-here]
                              @remainder-is-zero-inner |
                                r = ZERO
                                case remainder-zero-or-successor {
                                  @when-remainder-already-zero |
                                    assume r = ZERO {
                                      @conclusion-remainder-already-zero |
                                        r = ZERO
                                        [by hypothesis when-remainder-already-zero]
                                    }
                                  @when-remainder-successor |
                                    assume exists j: Int; nonneg(j) and r = succ(j) {
                                      @remainder-successor-exists |
                                        exists j: Int; nonneg(j) and r = succ(j)
                                        [by hypothesis when-remainder-successor]
                                      @with-remainder-predecessor |
                                        unpack j: Int from remainder-successor-exists {
                                          @predecessor-nonneg-and-remainder-succ |
                                            nonneg(j) and r = succ(j)
                                            [by hypothesis with-remainder-predecessor]
                                          @predecessor-nonneg |
                                            nonneg(j)
                                            [by and_lhs predecessor-nonneg-and-remainder-succ]
                                          @remainder-is-succ-j |
                                            r = succ(j)
                                            [by and_rhs predecessor-nonneg-and-remainder-succ]
                                          @succ-j-plus-m-is-zero |
                                            add(succ(j), m) = ZERO
                                            [by rewrite remainder-is-succ-j sum-remainder-inner-is-zero]
                                          @succ-j-plus-m-unfolds |
                                            add(succ(j), m) = succ(add(j, m))
                                            [using specialize addSuccLeft(j, m)]
                                          @succ-of-sum-is-zero |
                                            succ(add(j, m)) = ZERO
                                            [using chain succ-j-plus-m-unfolds succ-j-plus-m-is-zero]
                                          @inner-sum-nonneg |
                                            nonneg(add(j, m))
                                            [using specialize nonnegAdd(j, m) predecessor-nonneg inner-nonneg]
                                          @succ-of-sum-not-zero |
                                            succ(add(j, m)) != ZERO
                                            [using specialize nonnegSuccNotZero(add(j, m)) inner-sum-nonneg]
                                          @conclusion-remainder-successor-ex_falso |
                                            r = ZERO
                                            [by ex_falso succ-of-sum-is-zero succ-of-sum-not-zero]
                                        }
                                      @conclusion-remainder-successor |
                                        r = ZERO
                                        [by unpacked with-remainder-predecessor]
                                    }
                                }
                              @conclusion-remainder-is-zero |
                                r = ZERO or r = ONE
                                [by either_left remainder-is-zero-inner]
                            }
                          @exported-remainder-is-zero |
                            r = ZERO or r = ONE
                            [by unpacked with-inner-m]
                        }
                    }
                }
              @remainder-cases-exported |
                r = ZERO or r = ONE
                [by unpacked with-gap-d]
            }
          @below-two-gives-cases |
            less_than(r, TWO) -> (r = ZERO or r = ONE)
            [by discharge given-r-below-two]
        }
      @nonneg-gives-cases |
        nonneg(r) -> less_than(r, TWO) -> (r = ZERO or r = ONE)
        [by discharge given-r-nonneg]
    }
  @conclusion |
    forall r: Int; nonneg(r) -> less_than(r, TWO) -> (r = ZERO or r = ONE)
    [by generalize generalize-r]
qed
```

The two square expansions are the ring drudgery Judson elides. `polynomial` now
folds these directly — it expands ring products AND folds numeral coefficients by
expansion (`2·2 → 4`, `2q + 2q → 4q`), so `(2q)² = 4q²` and `(2q+1)² = 4q² + 4q + 1`
are each a single step. Only the odd square, whose form `4·(q² + q) + 1` we reuse
below, needs stating as a named identity.

```2b4m
// The odd square: (2q + 1)² = 4q² + 4q + 1 = 4·(q² + q) + 1. `polynomial` now
// expands the product AND folds the numeral coefficients (2·2 → 4, 2q + 2q → 4q),
// landing directly on the factored form 4·(q² + q) + 1.
theorem oddSquareIdentity: forall q: Int;
  mul(add(mul(TWO, q), ONE), add(mul(TWO, q), ONE)) = add(mul(FOUR, add(mul(q, q), q)), ONE)
proof
  @conclusion |
    forall q: Int; mul(add(mul(TWO, q), ONE), add(mul(TWO, q), ONE)) = add(mul(FOUR, add(mul(q, q), q)), ONE)
    [using polynomial_quantified(int_divides)]
qed
```

Now the exercise proper. `n²` is `4k` when `n` is even and `4k + 1` when `n` is odd.

```2b4m
theorem perfectSquareIsFourKOrFourKPlusOne: forall n: Int;
  exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
proof
  @generalize-n |
    fix n: Int {
      // 0 < 2, so the Division Algorithm applies at divisor 2.
      @zero-below-one |
        less_than(ZERO, ONE)
        [by cite zeroLessThanOne]
      @zero-below-succ-one |
        less_than(ZERO, succ(ONE))
        [using specialize lessThanSuccRight(ZERO, ONE) zero-below-one]
      @two-is-succ-one |
        TWO = succ(ONE)
        [using simplify]
      @zero-below-two |
        less_than(ZERO, TWO)
        [by rewrite two-is-succ-one zero-below-succ-one]
      @quotient-remainder-exist |
        exists q: Int; exists r: Int; n = add(mul(TWO, q), r) and nonneg(r) and less_than(r, TWO)
        [using specialize divisionAlgorithmExists(n, TWO) zero-below-two]
      @with-quotient-q |
        unpack q: Int from quotient-remainder-exist {
          @remainder-exists |
            exists r: Int; n = add(mul(TWO, q), r) and nonneg(r) and less_than(r, TWO)
            [by hypothesis with-quotient-q]
          @with-remainder-r |
            unpack r: Int from remainder-exists {
              @decomposition-and-bounds |
                n = add(mul(TWO, q), r) and nonneg(r) and less_than(r, TWO)
                [by hypothesis with-remainder-r]
              @decomposition-and-nonneg |
                n = add(mul(TWO, q), r) and nonneg(r)
                [by and_lhs decomposition-and-bounds]
              @decomposition |
                n = add(mul(TWO, q), r)
                [by and_lhs decomposition-and-nonneg]
              @remainder-nonneg |
                nonneg(r)
                [by and_rhs decomposition-and-nonneg]
              @remainder-below-two |
                less_than(r, TWO)
                [by and_rhs decomposition-and-bounds]
              @remainder-is-zero-or-one |
                r = ZERO or r = ONE
                [using specialize remainderBelowTwoIsZeroOrOne(r) remainder-nonneg remainder-below-two]
              @square-is-four-k-form |
                exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
                case remainder-is-zero-or-one {
                  // even case: n = 2q, so n² = 4·q², witness k = q².
                  @when-remainder-zero |
                    assume r = ZERO {
                      @remainder-is-zero |
                        r = ZERO
                        [by hypothesis when-remainder-zero]
                      @n-is-two-q |
                        n = mul(TWO, q)
                        [using arithmetic remainder-is-zero decomposition]
                      // n² = (2q)² = 4·q².
                      @square-reflexive |
                        mul(n, n) = mul(n, n)
                        [by reflexivity]
                      @square-left-substituted |
                        mul(n, n) = mul(mul(TWO, q), n)
                        [by rewrite n-is-two-q square-reflexive]
                      @square-both-substituted |
                        mul(n, n) = mul(mul(TWO, q), mul(TWO, q))
                        [by rewrite n-is-two-q square-left-substituted]
                      @even-square-expands |
                        mul(mul(TWO, q), mul(TWO, q)) = mul(FOUR, mul(q, q))
                        [using polynomial]
                      @even-square-is-four-q-squared |
                        mul(n, n) = mul(FOUR, mul(q, q))
                        [using chain square-both-substituted even-square-expands]
                      @even-square-is-four-k |
                        (mul(n, n) = mul(FOUR, mul(q, q))) or (mul(n, n) = add(mul(FOUR, mul(q, q)), ONE))
                        [by either_left even-square-is-four-q-squared]
                      @conclusion-even-witness |
                        exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
                        [by witness(mul(q, q)) even-square-is-four-k]
                    }
                  // odd case: n = 2q + 1, so n² = 4(q² + q) + 1, witness k = q² + q.
                  @when-remainder-one |
                    assume r = ONE {
                      @remainder-is-one |
                        r = ONE
                        [by hypothesis when-remainder-one]
                      @n-is-two-q-plus-one |
                        n = add(mul(TWO, q), ONE)
                        [by rewrite remainder-is-one decomposition]
                      @square-reflexive |
                        mul(n, n) = mul(n, n)
                        [by reflexivity]
                      @square-left-substituted |
                        mul(n, n) = mul(add(mul(TWO, q), ONE), n)
                        [by rewrite n-is-two-q-plus-one square-reflexive]
                      @square-both-substituted |
                        mul(n, n) = mul(add(mul(TWO, q), ONE), add(mul(TWO, q), ONE))
                        [by rewrite n-is-two-q-plus-one square-left-substituted]
                      // (2q + 1)² = 4·(q² + q) + 1.
                      @odd-square-expands |
                        mul(add(mul(TWO, q), ONE), add(mul(TWO, q), ONE)) = add(mul(FOUR, add(mul(q, q), q)), ONE)
                        [using specialize oddSquareIdentity(q)]
                      @odd-square-is-four-k-plus-one |
                        mul(n, n) = add(mul(FOUR, add(mul(q, q), q)), ONE)
                        [using chain square-both-substituted odd-square-expands]
                      @odd-square-is-four-k-form |
                        (mul(n, n) = mul(FOUR, add(mul(q, q), q))) or (mul(n, n) = add(mul(FOUR, add(mul(q, q), q)), ONE))
                        [by either_right odd-square-is-four-k-plus-one]
                      @conclusion-odd-witness |
                        exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
                        [by witness(add(mul(q, q), q)) odd-square-is-four-k-form]
                    }
                }
            }
          @square-form-from-remainder |
            exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
            [by unpacked with-remainder-r]
        }
      @square-form-from-quotient |
        exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
        [by unpacked with-quotient-q]
    }
  @conclusion |
    forall n: Int; exists k: Int; (mul(n, n) = mul(FOUR, k)) or (mul(n, n) = add(mul(FOUR, k), ONE))
    [by generalize generalize-n]
qed
```
