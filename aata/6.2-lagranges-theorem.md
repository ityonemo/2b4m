# Lagrange's Theorem

A literate `2b4m` transliteration of **Chapter 6 ("Cosets and Lagrange's Theorem"),
§6.2 "Lagrange's Theorem"** of Thomas W. Judson's *Abstract Algebra: Theory and
Applications* (source: `vendor/aata/src/cosets.xml`, lines 245–445; © 1997–2026
Judson, GFDL 1.3). The book's prose is reproduced in order — the coset-size lemma,
Lagrange's Theorem, and its corollaries — with a machine-checked `2b4m` proof
following each result. Run `2b4m check aata/6.2-lagranges-theorem.md` to verify.

The theorem lives in `std/group/group_lagrange.b4m`; the order corollaries in
`std/group/order-divides.b4m`.

**A note on counting.** The book writes $|G|$, $|H|$ and $[G:H]$ freely. `2b4m` has
no cardinality function, so every count here is a **listing**: a `Seq` together with
a length $n$ whose entries below $n$ are pairwise distinct and exhaust what is being
counted. `listsTheGroup(g, n)` is "$g$ lists $G$, and $|G| = n$";
`listsTheSubgroup(v, p)` is "$|H| = p$"; `listsCosetReps(r, k)` is "$[G:H] = k$".
Lagrange then reads $|G| = [G:H]\,|H|$ as `listsTheGroup(u, mul(k, p))` — which is
the book's equation, stated about listings rather than cardinals.

```2b4m
import group_lagrange <<< "std/group/group_lagrange.b4m"
import order_divides <<< "std/group/order-divides.b4m"

sort G = group_lagrange.Grp
const e = group_lagrange.E
func op = group_lagrange.op

// the listing vocabulary: Seq and ℕ, with the three "how many" predicates
sort Seq = group_lagrange.Seq
sort Nat = group_lagrange.Nat
func at = group_lagrange.at
func mul = group_lagrange.mul
define listsTheGroup(g, n) = group_lagrange.listsTheGroup(g, n)
define listsTheSubgroup(v, p) = group_lagrange.listsTheSubgroup(v, p)
define listsCosetReps(r, k) = group_lagrange.listsCosetReps(r, k)
```

## Lemma 6.4 — every coset has $|H|$ elements

**Lemma 6.4.** Let $H$ be a subgroup of $G$ with $g \in G$ and define a map
$\phi : H \rightarrow gH$ by $\phi(h) = gh$. The map $\phi$ is bijective; hence, the
number of elements in $H$ is the same as the number of elements in $gH$.

*Proof (Judson).* We first show that the map $\phi$ is one-to-one. Suppose that
$\phi(h_1) = \phi(h_2)$ for elements $h_1, h_2 \in H$. We must show that
$h_1 = h_2$, but $\phi(h_1) = gh_1$ and $\phi(h_2) = gh_2$. So $gh_1 = gh_2$, and by
left cancellation $h_1 = h_2$. To show that $\phi$ is onto is easy. By definition
every element of $gH$ is of the form $gh$ for some $h \in H$ and $\phi(h) = gh$.
$\blacksquare$

Transported to listings, the bijection says: a listing of $H$ of length $p$ becomes a
listing of $gH$ of length $p$. That is §6.1's `everyCosetIsListedByTheSubgroupsLength`,
and it is Lagrange's "each left coset has $|H|$ elements".

```2b4m
theorem everyCosetIsListedByTheSubgroupsLength = group_lagrange.everyCosetIsListedByTheSubgroupsLength
```

## Theorem 6.5 — Lagrange's Theorem

**Theorem 6.5 (Lagrange).** Let $G$ be a finite group and let $H$ be a subgroup of
$G$. Then $|G|/|H| = [G:H]$ is the number of distinct left cosets of $H$ in $G$. In
particular, the number of elements in $H$ must divide the number of elements in $G$.

*Proof (Judson).* The group $G$ is partitioned into $[G:H]$ distinct left cosets.
Each left coset has $|H|$ elements; therefore, $|G| = [G:H]\,|H|$. $\blacksquare$

Both halves of Judson's one-line proof are the results above: §6.1's
`cosetsAreEqualOrDisjoint` gives the partition, Lemma 6.4 gives the common size. The
library assembles them by block decomposition — listing the group as $k$ blocks of
$p$ entries each — and concludes a listing of length $k \cdot p$.

```2b4m
theorem lagrange = group_lagrange.lagrange
```

"The number of elements in $H$ must divide the number of elements in $G$" is the
divisibility reading of the same equation.

```2b4m
theorem theSubgroupsLengthDividesTheGroups = group_lagrange.theSubgroupsLengthDividesTheGroups
```

A listing's length is not *a priori* unique — nothing in the definition forbids two
listings of different lengths — so stating $|G|$ at all requires knowing any two
listings of the same group agree in length. The library proves it.

```2b4m
theorem anyTwoGroupListingsHaveTheSameLength = group_lagrange.anyTwoGroupListingsHaveTheSameLength
```

## Corollary 6.6 — the order of an element divides $|G|$

**Corollary 6.6.** Suppose that $G$ is a finite group and $g \in G$. Then the order
of $g$ must divide the number of elements in $G$.

The order of $g$ is $|\langle g \rangle|$, so this is Lagrange applied to the cyclic
subgroup generated by $g$ — which `std/group/order-divides.b4m` builds as a model of
the subgroup theory, with `inCyclic` for its membership.

```2b4m
theorem theOrderDividesTheGroupsLength = order_divides.theOrderDividesTheGroupsLength
```

## Corollary 6.7 — groups of prime order are cyclic

**Corollary 6.7.** Let $|G| = p$ with $p$ a prime number. Then $G$ is cyclic and any
$g \in G$ such that $g \neq e$ is a generator.

*Proof (Judson).* Let $g$ be in $G$ such that $g \neq e$. Then by Corollary 6.6, the
order of $g$ must divide the order of the group. Since $|\langle g \rangle| > 1$, it
must be $p$. Hence, $g$ generates $G$. $\blacksquare$

```2b4m
theorem primeOrderGroupIsGeneratedByAnyNonIdentity = order_divides.primeOrderGroupIsGeneratedByAnyNonIdentity
```

Corollary 6.7 suggests that groups of prime order $p$ must somehow look like
$\mathbb{Z}_p$ — the classification that §6.3's companions and Chapter 9's
isomorphism machinery make precise.

## Corollary 6.9 — indices multiply along a chain

**Corollary 6.9.** Let $H$ and $K$ be subgroups of a finite group $G$ such that
$G \supset H \supset K$. Then
$$[G:K] = [G:H][H:K].$$

*Proof (Judson).* Observe that
$$[G:K] = \frac{|G|}{|K|} = \frac{|G|}{|H|} \cdot \frac{|H|}{|K|} = [G:H][H:K].$$
$\blacksquare$

With counts as listings there is no division, so the chain is stated
multiplicatively: from $|G| = a\,|H|$ and $|H| = b\,|K|$ conclude
$|G| = (a b)\,|K|$. Judson's cancelling fractions is associativity of $\cdot$, and
the content is pure arithmetic once Lagrange has supplied both factorizations.

```2b4m
theorem indicesMultiplyAlongAChain = group_lagrange.indicesMultiplyAlongAChain
```

**The converse of Lagrange's Theorem is false.** A divisor of $|G|$ need not be the
order of any subgroup: $A_4$ has order 12 but no subgroup of order 6. Judson proves
this by exhaustion over $A_4$'s elements; it is recorded here as prose, not
transliterated.
