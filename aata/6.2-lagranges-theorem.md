A literate `2b4m` transliteration of **Chapter 6 ("Cosets and Lagrange's Theorem"),
§6.2 "Lagrange's Theorem"** of Thomas W. Judson's *Abstract Algebra: Theory and
Applications* (source: `vendor/aata/src/cosets.xml`, lines 245–445; © 1997–2026
Judson, GFDL 1.3). The book's prose is reproduced in order — the coset-size lemma,
Lagrange's Theorem, and its corollaries — with a machine-checked `2b4m` proof
following each result. Run `2b4m check aata/6.2-lagranges-theorem.md` to verify.

> *The book writes $|G|$, $|H|$ and $[G:H]$ freely, but there is no cardinality
> function here, so every count is a **listing**: a sequence together with a length
> $n$ whose first $n$ entries are pairwise distinct and exhaust what is being counted.
> Lagrange's $|G| = [G:H]\,|H|$ is then the book's equation stated about listings
> rather than cardinals, and since there is no division, the corollaries are stated
> multiplicatively.*

## Lemma 6.8 — every coset has $|H|$ elements

**Lemma 6.8.** Let $H$ be a subgroup of $G$ with $g \in G$ and define a map
$\phi : H \rightarrow gH$ by $\phi(h) = gh$. The map $\phi$ is bijective; hence, the
number of elements in $H$ is the same as the number of elements in $gH$.

**Proof.** We first show that the map $\phi$ is one-to-one. Suppose that
$\phi(h_1) = \phi(h_2)$ for elements $h_1, h_2 \in H$. We must show that
$h_1 = h_2$, but $\phi(h_1) = gh_1$ and $\phi(h_2) = gh_2$. So $gh_1 = gh_2$, and by
left cancellation $h_1 = h_2$. To show that $\phi$ is onto is easy. By definition
every element of $gH$ is of the form $gh$ for some $h \in H$ and $\phi(h) = gh$.
$\blacksquare$

In the form Lagrange needs it, the bijection says that a count of $H$ of size $p$
gives a count of $gH$ of size $p$ — "each left coset has $|H|$ elements".

```2b4m
theorem everyCosetIsListedByTheSubgroupsLength: forall g: G; forall v: Seq; forall p: Nat;
  listsTheSubgroup(v, p) -> exists u: Seq; listsTheCoset(g, u, p)
proof
  @generalize-g |
    fix g: G {
      @generalize-v |
        fix v: Seq {
          @generalize-p |
            fix p: Nat {
              @given-lists |
                assume listsTheSubgroup(v, p) {
                  @lists |
                    listsTheSubgroup(v, p)

                    forall i: Nat; less_than(i, p) -> inH(at(v, i))
                    [using tautology lists]

                    forall i: Nat; forall j: Nat; less_than(i, p) -> less_than(j, p) -> at(v, i) = at(v, j) -> i = j
                    [using tautology lists]
                  @covers |
                    forall h: G; inH(h) -> exists i: Nat; less_than(i, p) and at(v, i) = h
                    [using tautology lists]
                  @translate-exists |
                    exists u: Seq; forall j: Nat; less_than(j, p) -> at(u, j) = op(g, at(v, j))
                    [using specialize group_sequence.translatedSequenceExists(g, v, p)]

                    unpack u: Seq from translate-exists {
                      @translate |
                        forall j: Nat; less_than(j, p) -> at(u, j) = op(g, at(v, j))
                        [by hypothesis with-translate]
                      // every entry of u lies in gH
                      @entries-in-coset |
                        forall i: Nat; less_than(i, p) -> inCoset(g, at(u, i))
                        [by generalize entry-in-coset]
                      @entry-in-coset |
                        fix i: Nat {
                          @given-below |
                            assume less_than(i, p) {
                              @below |
                                less_than(i, p)
                                [by hypothesis given-below]
                              @entry-is-translated |
                                at(u, i) = op(g, at(v, i))
                                [using specialize translate(i) below]
                              @subgroup-entry |
                                inH(at(v, i))
                                [using specialize entries-in(i) below]

                              @conclusion-entry-in |

                                [by rewrite entry-is-translated translated-in-coset]

                            [by discharge given-below]

                                      @given-entries-equal |

                                            [by hypothesis given-i-below]

                                            [using chain u-at-i-flipped entries-equal u-at-j]

                                            [by symmetry u-at-i]
                                          @originals-equal |
                                            at(v, i) = at(v, j)
                                            [using specialize translationIsInjective(g, at(v, i), at(v, j)) translates-equal]
                                          @conclusion-indices-equal |
                                            i = j
                                            [using specialize injective(i, j) i-below j-below originals-equal]

                                      @equal-implies |

                                    [by discharge given-j-below]

                                less_than(i, p) -> less_than(j, p) -> at(u, i) = at(u, j) -> i = j

                            forall j: Nat; less_than(i, p) -> less_than(j, p) -> at(u, i) = at(u, j) -> i = j

                        }
                      // u covers gH: x in gH is g·h, h is v_i, so x is u_i
                      @covers-the-coset |
                        forall x: G; inCoset(g, x) -> exists i: Nat; less_than(i, p) and at(u, i) = x
                        [by generalize covers-x]
                      @covers-x |
                        fix x: G {
                          @given-in-coset |
                            assume inCoset(g, x) {
                              @in-coset |
                                inCoset(g, x)
                                [by hypothesis given-in-coset]
                              @h-exists |
                                exists h: G; inH(h) and x = op(g, h)
                                [using specialize everyCosetMemberIsATranslation(g, x) in-coset]
                              @with-h |
                                unpack h: G from h-exists {
                                  @h-facts |
                                    inH(h) and x = op(g, h)
                                    [by hypothesis with-h]
                                  @h-in |
                                    inH(h)
                                    [by and_lhs h-facts]
                                  @x-is-translated |
                                    x = op(g, h)
                                    [by and_rhs h-facts]
                                  @index-exists |
                                    exists i: Nat; less_than(i, p) and at(v, i) = h
                                    [using specialize covers(h) h-in]
                                  @with-index |
                                    unpack i: Nat from index-exists {
                                      @index-facts |
                                        less_than(i, p) and at(v, i) = h
                                        [by hypothesis with-index]
                                      @i-below |
                                        less_than(i, p)
                                        [by and_lhs index-facts]
                                      @v-at-i-is-h |
                                        at(v, i) = h
                                        [by and_rhs index-facts]
                                      @u-at-i |
                                        at(u, i) = op(g, at(v, i))
                                        [using specialize translate(i) i-below]
                                      @u-at-i-is-g-h |
                                        at(u, i) = op(g, h)
                                        [by rewrite v-at-i-is-h u-at-i]
                                      @x-is-u-at-i |
                                        op(g, h) = x
                                        [by symmetry x-is-translated]
                                      @u-at-i-is-x |
                                        at(u, i) = x
                                        [using chain u-at-i-is-g-h x-is-u-at-i]
                                      @witnessed |
                                        less_than(i, p) and at(u, i) = x
                                        [by both i-below u-at-i-is-x]
                                      @conclusion-index-inner |
                                        exists i2: Nat; less_than(i2, p) and at(u, i2) = x
                                        [by witness(i) witnessed]
                                    }
                                  @conclusion-index-mid |
                                    exists i: Nat; less_than(i, p) and at(u, i) = x
                                    [by unpacked with-index]
                                }
                              @conclusion-covers-x |
                                exists i: Nat; less_than(i, p) and at(u, i) = x
                                [by unpacked with-h]
                            }
                          @in-coset-implies |
                            inCoset(g, x) -> exists i: Nat; less_than(i, p) and at(u, i) = x
                            [by discharge given-in-coset]
                        }
                      @all-three |
                        listsTheCoset(g, u, p)
                        [using tautology entries-in-coset translate-injective covers-the-coset]
                      @conclusion-coset-listed-inner |
                        exists u2: Seq; listsTheCoset(g, u2, p)
                        [by witness(u) all-three]
                    }
                  @conclusion-coset-listed |
                    exists u: Seq; listsTheCoset(g, u, p)
                    [by unpacked with-translate]
                }
              @lists-implies |
                listsTheSubgroup(v, p) -> exists u: Seq; listsTheCoset(g, u, p)
                [by discharge given-lists]
            }
          @discharge-p |
            forall p: Nat; listsTheSubgroup(v, p) -> exists u: Seq; listsTheCoset(g, u, p)
            [by generalize generalize-p]
        }
      @discharge-v |
        forall v: Seq; forall p: Nat; listsTheSubgroup(v, p) -> exists u: Seq; listsTheCoset(g, u, p)
        [by generalize generalize-v]
    }
  @conclusion |
    forall g: G; forall v: Seq; forall p: Nat; listsTheSubgroup(v, p) -> exists u: Seq; listsTheCoset(g, u, p)
    [by generalize generalize-g]
qed
```

## Theorem 6.9 — Lagrange's Theorem

**Theorem 6.9 (Lagrange).** Let $G$ be a finite group and let $H$ be a subgroup of
$G$. Then $|G|/|H| = [G:H]$ is the number of distinct left cosets of $H$ in $G$. In
particular, the number of elements in $H$ must divide the number of elements in $G$.

**Proof.** The group $G$ is partitioned into $[G:H]$ distinct left cosets.
Each left coset has $|H|$ elements; therefore, $|G| = [G:H]\,|H|$. $\blacksquare$

Both halves of that one-line proof are the results above — §6.1 gives the partition,
Lemma 6.8 the common size — and they assemble by block decomposition: the group is $k$
blocks of $p$ entries each, so a count of $k \cdot p$.

> NB: This theorem exists in std in `std/group/lagrange.b4m:1792:lagrange`.

```2b4m
theorem lagrange: forall r: Seq; forall k: Nat; forall v: Seq; forall p: Nat;
  listsCosetReps(r, k) -> listsTheSubgroup(v, p) ->
  exists u: Seq; listsTheGroup(u, mul(k, p))
proof
  @generalize-r |
    fix r: Seq {
      @generalize-k |
        fix k: Nat {
          @generalize-v |
            fix v: Seq {
              @generalize-p |
                fix p: Nat {
                  @given-reps |
                    assume listsCosetReps(r, k) {
                      @given-subgroup-listed |
                        assume listsTheSubgroup(v, p) {
                          @reps |
                            listsCosetReps(r, k)
                            [by hypothesis given-reps]
                          @subgroup-listed |
                            listsTheSubgroup(v, p)
                            [by hypothesis given-subgroup-listed]
                          @k-reaches-itself |
                            less_than(k, k) or k = k
                            [by either_right k-is-k]
                          @k-is-k |
                            k = k
                            [by reflexivity]
                          @all-blocks-exist |
                            exists u: Seq; listsTheBlocksBelow(u, r, k, p)
                            [using specialize everyPrefixOfBlocksIsListed(r, k, v, p, k) reps subgroup-listed k-reaches-itself]
                          @with-all-blocks |
                            unpack u: Seq from all-blocks-exist {
                              @blocks |
                                listsTheBlocksBelow(u, r, k, p)
                                [by hypothesis with-all-blocks]
                              @group-listed |
                                listsTheGroup(u, mul(k, p))
                                [using specialize allTheBlocksAreTheGroup(r, k, p, u) reps blocks]
                              @conclusion-group-listed-inner |
                                exists u2: Seq; listsTheGroup(u2, mul(k, p))
                                [by witness(u) group-listed]
                            }
                          @conclusion-group-listed |
                            exists u: Seq; listsTheGroup(u, mul(k, p))
                            [by unpacked with-all-blocks]
                        }
                      @subgroup-listed-implies |
                        listsTheSubgroup(v, p) -> exists u: Seq; listsTheGroup(u, mul(k, p))
                        [by discharge given-subgroup-listed]
                    }
                  @reps-implies |
                    listsCosetReps(r, k) -> listsTheSubgroup(v, p) -> exists u: Seq; listsTheGroup(u, mul(k, p))
                    [by discharge given-reps]
                }
              @discharge-p |
                forall p: Nat; listsCosetReps(r, k) -> listsTheSubgroup(v, p) -> exists u: Seq; listsTheGroup(u, mul(k, p))
                [by generalize generalize-p]
            }
          @discharge-v |
            forall v: Seq; forall p: Nat; listsCosetReps(r, k) -> listsTheSubgroup(v, p) -> exists u: Seq; listsTheGroup(u, mul(k, p))
            [by generalize generalize-v]
        }
      @discharge-k |
        forall k: Nat; forall v: Seq; forall p: Nat; listsCosetReps(r, k) -> listsTheSubgroup(v, p) -> exists u: Seq; listsTheGroup(u, mul(k, p))
        [by generalize generalize-k]
    }
  @conclusion |
    forall r: Seq; forall k: Nat; forall v: Seq; forall p: Nat;
      listsCosetReps(r, k) -> listsTheSubgroup(v, p) ->
      exists u: Seq; listsTheGroup(u, mul(k, p))
    [by generalize generalize-r]
qed
```

A count's size is not *a priori* unique — nothing in the definition forbids two
listings of a group having different lengths — so writing $|G|$ at all requires
knowing that any two listings of the same group agree in length.

> NB: This theorem exists in std in `std/group/lagrange.b4m:1876:anyTwoGroupListingsHaveTheSameLength`.

```2b4m
theorem anyTwoGroupListingsHaveTheSameLength: forall m: Nat; forall v: Seq; forall n: Nat; forall w: Seq;
  listsTheGroup(v, m) -> listsTheGroup(w, n) -> m = n
proof
  @generalize-m |
    fix m: Nat {
      @generalize-v |
        fix v: Seq {
          @generalize-n |
            fix n: Nat {
              @generalize-w |
                fix w: Seq {
                  @given-v-lists |
                    assume listsTheGroup(v, m) {
                      @given-w-lists |
                        assume listsTheGroup(w, n) {
                          @v-lists |
                            listsTheGroup(v, m)
                            [by hypothesis given-v-lists]
                          @w-lists |

                            forall x: G; exists i: Nat; less_than(i, n) and at(w, i) = x

                                        [by both index-below entries-agree-flipped]

                                        [by witness(i) witnessed]

                                    exists i: Nat; less_than(i, n) and at(v, j) = at(w, i)
                                    [by unpacked with-covering-index]
                                }
                              @j-below-implies |
                                less_than(j, m) -> exists i: Nat; less_than(i, n) and at(v, j) = at(w, i)
                                [by discharge given-j-below-m]
                            }
                          @w-drawn-from-v |
                            forall j: Nat; less_than(j, n) -> exists i: Nat; less_than(i, m) and at(w, j) = at(v, i)
                            [by generalize w-entry-is-in-v]
                          @w-entry-is-in-v |
                            fix j: Nat {

                                assume less_than(j, n) {

                                    exists i: Nat; less_than(i, m) and at(v, i) = at(w, j)

                                    unpack i: Nat from entry-is-covered {

                                        [by both index-below entries-agree-flipped]

                        listsTheGroup(w, n) -> m = n
                        [by discharge given-w-lists]
                    }
                  @v-lists-implies |
                    listsTheGroup(v, m) -> listsTheGroup(w, n) -> m = n
                    [by discharge given-v-lists]
                }
              @discharge-w |
                forall w: Seq; listsTheGroup(v, m) -> listsTheGroup(w, n) -> m = n
                [by generalize generalize-w]
            }
          @discharge-n |
            forall n: Nat; forall w: Seq; listsTheGroup(v, m) -> listsTheGroup(w, n) -> m = n
```

## Corollary 6.10 — the order of an element divides $|G|$

**Corollary 6.10.** Suppose that $G$ is a finite group and $g \in G$. Then the order
of $g$ must divide the number of elements in $G$.

The order of $g$ is $|\langle g \rangle|$, so this is Lagrange applied to the cyclic
subgroup generated by $g$.

## Corollary 6.11 — groups of prime order are cyclic

**Corollary 6.11.** Let $|G| = p$ with $p$ a prime number. Then $G$ is cyclic and any
$g \in G$ such that $g \neq e$ is a generator.

**Proof.** Let $g$ be in $G$ such that $g \neq e$. Then by Corollary 6.10, the
order of $g$ must divide the order of the group. Since $|\langle g \rangle| > 1$, it
must be $p$. Hence, $g$ generates $G$. $\blacksquare$

```2b4m

  ((forall i: Nat; forall j: Nat; less_than(i, n) -> less_than(j, n) -> at(gl, i) = at(gl, j) -> i = j) and (forall x: G; exists i: Nat; less_than(i, n) and at(gl, i) = x)) ->
  forall y: G; exists e2: Int; y = power(gen, e2)

  @generalize-r |

                                                    [using tautology group-listed]
                                                  @group-covers |
                                                    forall x: G; exists i: Nat; less_than(i, n) and at(gl, i) = x
                                                    [using tautology group-listed]
                                                  @conclusion-full-order-generates |
                                                    forall y: G; exists e2: Int; y = power(gen, e2)
                                                    [using specialize counting.fullOrderGenerates(n, gl, gen) group-injective group-covers has-full-order]
                                                }
                                            }
                                        }
                                      @group-listed-implies |
                                        ((forall i: Nat; forall j: Nat; less_than(i, n) -> less_than(j, n) -> at(gl, i) = at(gl, j) -> i = j) and (forall x: G; exists i: Nat; less_than(i, n) and at(gl, i) = x)) -> forall y: G; exists e2: Int; y = power(gen, e2)
```

## Corollary 6.12 — indices multiply along a chain

**Corollary 6.12.** Let $H$ and $K$ be subgroups of a finite group $G$ such that
$G \supset H \supset K$. Then
$$[G:K] = [G:H][H:K].$$

**Proof.** Observe that
$$[G:K] = \frac{|G|}{|K|} = \frac{|G|}{|H|} \cdot \frac{|H|}{|K|} = [G:H][H:K].$$
$\blacksquare$

Stated multiplicatively, the chain is: from $|G| = a\,|H|$ and $|H| = b\,|K|$
conclude $|G| = (a b)\,|K|$. The cancelling of fractions is associativity of $\cdot$,
and the content is pure arithmetic once Lagrange has supplied both factorizations.

> NB: This theorem exists in std in `std/group/lagrange.b4m:2127:indicesMultiplyAlongAChain`.

**The converse of Lagrange's Theorem is false.** A divisor of $|G|$ need not be the
order of any subgroup: $A_4$ has order 12 but no subgroup of order 6. Judson's
argument: since $[A_4 : H] = 2$, the left and right cosets coincide, so
$gHg^{-1} = H$ for every $g \in A_4$; and since $A_4$ contains eight $3$-cycles, at
least one — say $(1\,2\,3)$ — lies in $H$, along with its inverse $(1\,3\,2)$.
Conjugating, $(1\,2\,4)(1\,2\,3)(1\,2\,4)^{-1} = (2\,4\,3)$ and
$(2\,4\,3)(1\,2\,3)(2\,4\,3)^{-1} = (1\,4\,2)$ are in $H$ too, with their inverses,
so $H$ has at least the seven elements $(1)$, $(1\,2\,3)$, $(1\,3\,2)$, $(2\,4\,3)$,
$(2\,3\,4)$, $(1\,4\,2)$, $(1\,2\,4)$ — more than six. That argument is recorded
here as prose.
