Definition blocks

A pred or oper followed by : carries the clauses that characterize it, ;-separated. Each clause is written exactly as the axiom it becomes.

pred isZero(n: Nat):
  isZero(n) iff n = ZERO

oper add(a: Nat, b: Nat) => Nat:
  add(ZERO, b) = b;
  add(succ(k), b) = succ(add(k, b))

oper gcd(a: Nat, b: Nat) => Nat:
  gcd(a, b) = a                  when b = ZERO;
  gcd(a, b) = gcd(b, mod(a, b))  when b != ZERO

Every clause states its own condition in full. Clauses are not ordered and there is no first-match-wins — each is a standalone axiom, and axioms have no precedence.

Prefer a definition block to a bare declaration plus a separately named axiom: the reader sees at the declaration what the symbol means, and --axioms reports it as a definition rather than an assumption to weigh.

Refined sorts

sort H = G where inH carves out the elements of G satisfying inH. A binder at H carries the guard with it, so a term that needs inH is well-formed without an extra antecedent.

pred invertible(f: Fn)
sort Perm = Fn where invertible
oper inverse(f: Fn) => Fn requires invertible(f)

theorem t: forall p: Perm; inverse(inverse(p)) = p

Inside fix h: H { … }, recover the guard with [by predicate <fix-block>]. A generalize over a refined binder concludes the relativized forall x: G; inH(x) -> P(x).

Formulas

Connectives are words. Quantifier binders end with ;.

->implication, right-associative

(not (p or q)) -> ((not p) and (not q))

Mixed boolean operators require explicit parens.

model

A model interprets a theory’s symbols with yours and discharges its axioms; in return its theorems become true of your symbols, citable as [using model(M) src.thm]. It is not an import — it puts no name into your scope, so a transferred fact has no bare local name until you write one.

src.sym: localmap a symbol
src.axiom <- factdischarge an axiom
src.C: TGT(fact, …)a const also nominates its ground membership fact, one per guard predicate of the target sort
src.op: F -| closure, …an operation also nominates its closure fact — that F preserves membership

: on an axiom, or <- on a symbol, is a hard error. A source theorem is not mappable — it transfers for free, that being the point. The -| reads like <-: obligation-bearer on the left, discharging fact on the right; parens on an operation, or -| on a const, is an error.

When a sort-mapping’s target is a refined sort, every transferred theorem is relativized — an inH(x) -> guard is injected at each binder over the mapped sort, and a multi-qualifier sort injects the conjunction. The nominated facts are what discharge those guards: at each obligation the transfer walks the witness term, so a const cites its ground fact, a fix-bound variable uses its block guard, and a composite op(a, b) applies op’s closure and recurses on the arguments. An unconditional source axiom mapped to itself is auto-weakened (∀a; P ⊢ ∀a; inH(a) -> P).

sort GrpH = Grp where inH
axiom identityInH: inH(E)
axiom invClosed: forall a: Grp; inH(a) -> inH(inverse(a))

model SubgroupIsGroup {
  group.Grp:     GrpH
  group.E:       E(identityInH)        // const → ground fact
  group.op:      op -| opClosed        // oper  → closure fact
  group.inverse: inverse -| invClosed
  group.opAssoc  <- group.opAssoc      // unconditional: auto-weakened
}

Proofs

A proof is a sequence of steps. Each is an @-sigiled label on its own line, then the formula and its bracketed justification, indented beneath:

theorem q: ...
proof
  @have-imp |
    p -> q
    [by cite pImpliesQ]
  @conclusion |
    q
    [by modus_ponens have-imp have-p]
qed

The @ marks a definition and sits in the left gutter so labels form a scannable column. Citations are bare — no @. The final step must state the theorem’s formula. Refs are space-separated, never commas.

The label column is the proof outline. Strip every formula and justification, and the remaining labels should let a reader reconstruct the argument. 2b4m query outline <file> <theorem> prints exactly that.

Two justification keywords

The parser enforces the split.

[by …]kernel primitives — pure inference, always checked.
[using …]accelerants, plus instantiation, model, import — engine proof-generation.

by on an accelerant, or using on a primitive, is a hard parse error.

Subproof blocks

A block is opened by a step and discharged by a separate step — the block is not itself the conclusion.

assume P { … }

Opens a block under a hypothesis. discharge yields the implication; contradiction yields the negation. Restate the hypothesis inside with [by hypothesis <block>].

fix x: S { … }

Opens a block with a fresh arbitrary variable; generalize yields the universal. One binder per fix — fix a, b: Nat is a parse error, so nest them. Fix variables must be globally fresh in the proof.

unpack u: S from WIT { … }

Names the witness of an established existential. unpacked exports a witness-free conclusion — one mentioning u is a kernel error.

case DISJ { … }

States a goal, then proves it by splitting a disjunction into one assume arm per disjunct, each concluding that same goal. Sugar for a nested common_conclusion; a left-nested (A or B) or C fans out automatically, so you write N arms rather than a hand-built tree.
