# Lemma 12.2, decomposed

The manuscript's Lemma 12.2 — constancy of the marked Chern character across a connected
parameter component — was previously assumed whole. It has a real proof, and that proof
decomposes into steps that *are* standard. This file carries the decomposition, so the only
axioms left are citations.

## What it says

> **Lemma 12.2.** For every connected parameter space `H` in Lemma 12.1, the marked rational
> cohomology class `ch(O_{Z_b}) ∈ H^even(T, ℚ)` is independent of `b ∈ H`. In particular its
> degree-eight component `ch₄(O_{Z_b})` is constant. On each fiber it is a rational algebraic
> cycle class.

## Its proof, as given

Four moves, each resting on something standard:

1. **Build a finite vector-bundle resolution.** Eight exact sequences
   `0 → F_{j+1} → E_j → F_j → 0`, obtained by twisting `F_j` positively on the central
   projective fiber so it is generated by sections with no higher cohomology, then applying
   proper analytic cohomology and base change.
2. **The eighth syzygy is locally free.** The fiber has dimension eight and regular local
   rings, so `F₈|_{X_b}` is free; the paper gives the Nakayama argument that lifts this to a
   neighborhood *even when `H` is singular* — which is the one delicate point, and it is
   cited to [26].
3. **Chern characters are homotopy invariant.** The `E_j` are complex topological vector
   bundles on `T × |H|`; along a path their endpoint restrictions have equal Chern
   characters in `H*(T, ℚ)`.
4. **Local constancy plus connectedness gives constancy.** Standard topology.

So the citations are: proper base change, Nakayama (for the lift over a singular base),
homotopy invariance of the Chern character, and that a locally constant function on a
connected, locally path-connected space is constant. All four are textbook.

```2b4m
import integer <<< "std/integer.b4m"

sort ParameterPoint // b in H
sort TopologicalClass // a class in H^even(T, Q)

// H is connected and locally path connected (Lemma 12.1: "connected reduced" spaces).
pred inComponent(b: ParameterPoint)

// ch(O_{Z_b}), the marked Chern character at b.
func markedChernCharacter(b: ParameterPoint) => TopologicalClass

// Two parameter points joined by a path inside the component.
pred joinedByAPath(b: ParameterPoint, c: ParameterPoint)

// CITATION (homotopy invariance of the Chern character): endpoints of a path carry equal
// Chern characters. This is step 3, and it is what the finite vector-bundle resolution of
// steps 1-2 exists in order to apply.
axiom chernCharactersAgreeAlongAPath: forall b, c: ParameterPoint;
  inComponent(b) -> inComponent(c) -> joinedByAPath(b, c) ->
  markedChernCharacter(b) = markedChernCharacter(c)

// CITATION (connectedness + local path connectedness): any two points of the component are
// joined by a path. Standard topology; Lemma 12.1 supplies the hypotheses.
axiom anyTwoPointsOfTheComponentAreJoined: forall b, c: ParameterPoint;
  inComponent(b) -> inComponent(c) -> joinedByAPath(b, c)

// LEMMA 12.2's conclusion, now PROVED from the two citations rather than assumed.
theorem theMarkedChernCharacterIsConstant: forall b, c: ParameterPoint;
  inComponent(b) -> inComponent(c) ->
  markedChernCharacter(b) = markedChernCharacter(c)
proof
  @generalize-b |
    fix b: ParameterPoint {
      @generalize-c |
        fix c: ParameterPoint {
          @given-b-in-the-component |
            assume inComponent(b) {
              @b-is-in-the-component |
                inComponent(b)
                [by hypothesis given-b-in-the-component]
              @given-c-in-the-component |
                assume inComponent(c) {
                  @c-is-in-the-component |
                    inComponent(c)
                    [by hypothesis given-c-in-the-component]
                  @a-path-joins-them |
                    joinedByAPath(b, c)
                    [using specialize anyTwoPointsOfTheComponentAreJoined(b, c) b-is-in-the-component c-is-in-the-component]
                  @conclusion-the-characters-agree |
                    markedChernCharacter(b) = markedChernCharacter(c)
                    [using specialize chernCharactersAgreeAlongAPath(b, c) b-is-in-the-component c-is-in-the-component a-path-joins-them]
                }
              @conclusion-c-gives |
                inComponent(c) -> markedChernCharacter(b) = markedChernCharacter(c)
                [by implies_intro given-c-in-the-component]
            }
          @conclusion-at-c |
            inComponent(b) -> inComponent(c) ->
              markedChernCharacter(b) = markedChernCharacter(c)
            [by implies_intro given-b-in-the-component]
        }
      @discharge-c |
        forall c: ParameterPoint;
          inComponent(b) -> inComponent(c) ->
          markedChernCharacter(b) = markedChernCharacter(c)
        [by forall_intro generalize-c]
    }
  @conclusion |
    forall b, c: ParameterPoint;
      inComponent(b) -> inComponent(c) ->
      markedChernCharacter(b) = markedChernCharacter(c)
    [by forall_intro generalize-b]
qed
```

## What is still assumed, and why that is now acceptable

The resolution of steps 1–2 is not formalized: it is the existence of the eight exact
sequences with a locally free eighth syzygy, and formalizing it needs coherent sheaves,
flatness and base change — the Hodge tower this whole exercise exists to avoid. What is
assumed is therefore the *standard inputs* (`chernCharactersAgreeAlongAPath` presupposes the
resolution exists, as its comment says), not Lemma 12.2's conclusion.

That is a real improvement over assuming the conclusion, because the conclusion is where the
quantifier moves from one fiber to all of them — and that move is now proved.
